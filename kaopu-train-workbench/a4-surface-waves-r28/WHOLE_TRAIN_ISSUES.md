# A4 整车研究问题与证据

结论：可检查的整车函数研究台，不是可制造机车、准确 60009 或机械验收通过。所有机构在同一个 Time 下检查；中央安装暂停扩形，不挖车架、不凭画面避让。

| 整体关系 | 已建立证据 | 失败或仍缺 | 下一条必要依据 |
|---|---|---|---|
| 轮组 → 曲柄 → 主连杆 → 滑块 → 活塞/环 | 同 Time 解析位置和刚体场变换核验；轮径对应滚动相位；候选三缸环随活塞 | 真实曲柄相位、负载/弹性、蒸汽循环未标定 | A4 相位与装配资料；不能以运动画面替代 |
| 外侧牵引 → Walschaerts → 阀杆 | 固定倒车设定 .75 的有限连杆闭合，阀杆来自同一曲柄/滑块，不是另造正弦 | 活动倒车、阀事件、汽口和密封未证 | 阀动图、阀口与行程资料 |
| 外侧两阀杆 → 中央共轭机构 | 有限 2:1 / 等臂 / 短连杆代数闭合；独立中央错层候选保留杆厚、声明开孔及销套间隙 | **当前函数整车失败：中央两杆穿未开槽的左右车架场；水平中阀轴穿中活塞和前后缸盖场。** 官方资料记载真实两杠杆穿过车架专用槽，所以前者可能是函数车架漏槽，不是实际 A4 必然冲突，也不能由此断定机构应搬高。 原中央同层杆重叠也保留。固定 O 承载、端锁、中阀导向均未知 | 实际中央机构相对于车架前端、缸鞍、汽室的安装图/剖面与标高；不能从内闭合反推正确安装 |
| 中缸安装 → 中主连杆 → 前动轴避让 | 原 .11 rad 基线有 28.74 mm 包络穿透；.126 rad 候选仅该局部扫掠超过假定 5 mm | 倾角、中心高度、杆长、曲柄横向位置并非实车校准；局部可行不能消除上述中央全车失败 | 原始中心线/轴距/安装尺寸；保留 observed / inferred 区分 |
| 压力容器 → 汽缸/汽室 → 供给/排汽 | 已有函数容器与可剖视整车体积、外侧已证阀杆联动 | 中汽室/汽管/完整汽水网络、缸鞍承载没有完成；不添加无证中汽室 | 系统流路与安装图，连接端口与支撑关系 |
| 制动、驾驶室控制、悬挂与外形 | 现有车架/轮组/锅炉/煤水车保留整车检视 | 制动、控制、悬挂位移、完整流线外罩及实车外观未完成；不含煤炭 | A4 对应结构资料及功能连接，不用静态外观冒充 |
| 表面与材质 | 自写解析造波 CPU 研究；不使用对象三角网格或贴图 | 完整渲染接入正在验证；微法线造波不改变实体几何 | 同局部坐标随动、粗糙度照明及整车浏览器验证 |

证据边界：0.5 mm 射线命中阈值无法证明 0.15 mm 销套间隙；间隙依据解析标量而非截图。中央区间证书仅以外侧输入位于指定区间为条件，不是全车连续证明。SwiftShader 浏览器检查是软件 WebGL，不是硬件 GPU 速度承诺。

来源：参见 PHASE_EVIDENCE.md、PROVENANCE_REVIEW.md、各数值核验及新增整车邻件见证。原模型观察、1935 Silver Link 文献尺寸与自写推断不能混成 60009 真值；研究归属保持，不发布无署名最终成品。

官方安装新证据：SNGLT https://sirnigelgresley.org.uk/overhaul-1522/overhaul-19.shtml 记载 2:1 和 1:1 杠杆穿过车架槽，战争期间增阀行程曾加长槽；NRM https://blog.railwaymuseum.org.uk/sir-nigel-gresley-restoration-update-12/ 同样标出右缸前方共轭机构开口。该架构事实不提供当前函数可直接采用的开口形状、标高、边距或 60009 尺寸，不能当任意挖槽授权。
