# A4 整车研究问题与证据

结论：可检查的整车函数研究台，不是可制造机车、准确 60009 或机械验收通过。所有机构在同一个 Time 下检查；R29 按官方侧置阀胸与专用车架槽口拓扑建立整车候选；尺寸标为推断，不挖轴、不凭画面避让。

| 整体关系 | 已建立证据 | 失败或仍缺 | 下一条必要依据 |
|---|---|---|---|
| 轮组 → 曲柄 → 主连杆 → 滑块 → 活塞/环 | 同 Time 解析位置和刚体场变换核验；轮径对应滚动相位；候选三缸环随活塞 | 真实曲柄相位、负载/弹性、蒸汽循环未标定 | A4 相位与装配资料；不能以运动画面替代 |
| 外侧牵引 → Walschaerts → 阀杆 | 固定倒车设定 .75 的有限连杆闭合，阀杆来自同一曲柄/滑块，不是另造正弦 | 活动倒车、阀事件、汽口和密封未证 | 阀动图、阀口与行程资料 |
| 外侧两阀杆 → 中央共轭机构 | 有限 2:1 / 等臂 / 短连杆代数闭合；独立中央错层候选保留杆厚、声明开孔及销套间隙 | **R28 保留失败：中央两杆穿未开槽车架；中阀轴穿动力缸。R29 改为侧置阀胸，按杠杆实际扫掠截面建立条件包络槽口，并有框架连接支承；尚无整车总验收。** 官方资料记载真实两杠杆穿过车架专用槽，所以前者可能是函数车架漏槽，不是实际 A4 必然冲突，也不能由此断定机构应搬高。 原中央同层杆重叠也保留。R29 已有固定 O 枢轴至两侧车架的显式候选支承、套孔和紧固件及中阀导向；制造锁止和承载强度未证 | 实际中央机构相对于车架前端、缸鞍、汽室的安装图/剖面与标高；不能从内闭合反推正确安装 |
| 中缸安装 → 中主连杆 → 前动轴避让 | 原 .11 rad 基线有 28.74 mm 包络穿透；.126 rad 候选仅该局部扫掠超过假定 5 mm | 倾角、中心高度、杆长、曲柄横向位置并非实车校准；局部可行不能消除上述中央全车失败 | 原始中心线/轴距/安装尺寸；保留 observed / inferred 区分 |
| 压力容器 → 汽缸/汽室 → 供给/排汽 | 已有函数容器与可剖视整车体积、外侧已证阀杆联动 | 中汽室/汽管/完整汽水网络、缸鞍承载没有完成；不添加无证中汽室 | 系统流路与安装图，连接端口与支撑关系 |
| 制动、驾驶室控制、悬挂与外形 | 现有车架/轮组/锅炉/煤水车保留整车检视 | 制动、控制、悬挂位移、完整流线外罩及实车外观未完成；不含煤炭 | A4 对应结构资料及功能连接，不用静态外观冒充 |
| 表面与材质 | 自写解析造波 CPU 研究；不使用对象三角网格或贴图 | 12 个整车浏览器视图、同灯光波幅 0/1 像素对照已通过；微法线造波不改变实体几何 | 同局部坐标随动、粗糙度照明及整车浏览器验证 |

证据边界：0.5 mm 射线命中阈值无法证明 0.15 mm 销套间隙；间隙依据解析标量而非截图。中央区间证书仅以外侧输入位于指定区间为条件，不是全车连续证明。SwiftShader 浏览器检查是软件 WebGL，不是硬件 GPU 速度承诺。

2026-10-25 实照纠正：SNGLT 2016-12-23 中缸铸件原图 https://www.sirnigelgresley.org.uk/overhaul-1522/pics/o240.jpg 已实际放大检查，官方图注明确小孔是中阀胸，位于大动力缸孔旁。撤销当前 X=0 / Y=1.48 水平中阀为可信实车安装关系，仅保留失败试验以便复核；不能靠上下搬动假装解决。照片没有标尺、轨面/车架基准或标定相机，不能给绝对偏置、倾角或直接充当 60009 尺寸。仍需可读 K438（1938，替 K413）及其引用汽缸安装剖面，或等效带基准图。公开 1935 原始文章只有外部尺寸图，未解除这个缺证。此轮只改知识记录，不改函数几何、不改 Git；详见 public-drawing-evidence 两份研究记录，包内不含官方原照片/图纸。

R29 最新整车装配约束：独立阀胸与共铸腹板保留双孔；侧置 X=.38、标高和全部新增安装尺寸是推断。全倾角范围可拆动力缸盖前后分离有保守边界，阀头/导向/杆用同一 Time 作 1,441 相位检查；早期新阀胸与前后可拆缸盖相交见证保留，不能归为共铸融合。新阀胸前后端面、阀头间距由整个装配空间与行程约束推导，不是拿到原图。原基线仍519场，R29候选636场。车架槽口证明以外侧输入区间为条件，外侧全相位包含尚未连续证明。无完整汽口/蒸汽循环、强度或60009一比一认证。

官方端盖构造修订：前端 o1332 的外贴轮廓盖、周边紧固和中央填料孔进入候选；后端 e1857 的外贴盖与中央管状凸壳单独建模。局部收边、六螺柱模式和尺寸仍为推断，后端收边不冒称照片可见。取消无证端塞替代路线。当前三种倾角的整车字段搜索未再找到新端盖、紧固件、导向、车架槽/支承的负见证；未找到不是全局无碰撞证书。仍保留两处继承的外侧阀杆尾端与组合杆铰接穿入，需真实叉头/横销装配证据与实体修正。强度只列边界，当前目标是游戏形态、从属、运动和连接检查，不是压力容器认证。
