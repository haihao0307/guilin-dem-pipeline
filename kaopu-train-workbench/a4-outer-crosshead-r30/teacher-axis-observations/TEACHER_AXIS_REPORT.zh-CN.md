# A4 教师模型轴向实测：可观测部分与证据边界

日期：2026-10-25。只读研究，不修改教师模型，不将教师网格作为自写机构成品。

## 结论先行

1. **不能用这份教师模型校定中缸倾角或中间主连杆。** 已检查的实际几何中，可辨认的长连杆与往复杆位于左右外侧；在规定的中央空间截取范围内，未识别出可以独立测量的中缸、内部主连杆及完整曲柄腹板机构。这是“缺少可辨认观测证据”，不是证明任何隐藏、合并或未表达的结构绝对不存在。
2. **两层坐标旋转互相抵消。** 不能额外再套一次 X 轴 ±90° 旋转或 Y/Z 交换。完整世界坐标为 X 横向、Y 向上、Z 向车头，附加整体 Y 平移 0.476383。
3. **rest/default 不是动画首帧。** 部分节点默认姿态没有首帧旋转，长杆会朝反方向，滑杆也会横置。只看节点名称、默认 translation 或局部包围盒，会得到错误安装关系。
4. **现有候选的碰撞不能由这些教师变换自动解释或修复。** 候选明确自写、未使用源模型，倾角 0.11、相位 1.7/4.3 和杆长 3.5 均是推定值。源模型没有提供可验证的中缸轴线，让这些推定值变成测量值。

## 坐标与姿态：实际矩阵证据

节点 0 为约 −90° 的 X 旋转，节点 2 为约 +90° 的 X 旋转；节点 1 为恒等。按 glTF 列主序正确读取并逐级相乘后，节点 2 世界矩阵的旋转部分为恒等，平移为 (0, 0.4763830006, 约 0)。没有根级统一缩放。某些零件有自己的非均匀缩放，不能忽略局部矩阵。

动画 rotation 是 XYZW 四元数，不是角度列表。本测量对四元数归一化并使用最短弧球面插值，不对四元数分量做度/弧度转换。

姿态差异的直接例子：

- 节点 102 / mesh 节点 103：rest 的世界 Z 范围约 −2.85815 至 1.83949；首帧约 1.58473 至 6.28191。
- 节点 111 / mesh 节点 112：rest 的世界 Z 范围约 0.17921 至 4.05681；首帧约 3.80438 至 7.67008。
- 节点 100 与 293 的首帧绕 Y 约 89° 的旋转，将原局部杆几何转到纵向。省略该动画旋转会把结构误读成横向杆。

因此，恢复“完整节点层级 + 动画首帧”与“只把节点默认值摆上场景”不是一回事。

## 可测的外侧往复杆与长连杆

先对真实索引拓扑按 10⁻⁶ 源单位坐标焊接、分连通分量，再据几何形状与动画轨迹定位。名称仅用于回查，不是机械分类证据。

### 外侧纵向圆柱杆

在节点 100/101 分量 2 与节点 293/294 分量 3 中识别出约 1.34 长、约 0.129 横截面直径的纵向圆柱杆。它们是可辨认的外侧往复杆；本报告不据此宣称已验证其整个缸体、缸孔或活塞结构。

|---|---|---|
| t=0 几何轴方向，朝 +Z | (−0.00504905, 0.00000011, 0.99998725) | (0.01228910, 0.00000006, 0.99992449) |
| t=0 包围盒中点 | (1.010635, 1.4628145, 8.216477) | (−0.979743, 1.4628145, 8.2029845) |
| 根节点平移轨迹方向 | (0, 0, 1) | 约 (0, 0, 1) |

根节点平移直线拟合的最大垂直误差分别为约 2.2×10⁻¹⁶、6.0×10⁻⁷ 源单位。两杆几何轴在水平面存在轻微偏航，并有极小动画摆动；不能把根节点纯 Z 平移误述为每个网格点都走同一条精确直线。

外侧杆轴 Y≈1.4628145，比中驱动轮圆心低约 0.0357612 源单位。其几何方向没有可测的显著纵向上仰。这里不包含中缸信息。

### 两根外侧长连杆

- 根节点 98 / mesh 节点 99：首帧 X 范围约 0.95969 至 1.08664；PCA 长轴方向约 (−0.000238, 0.092285, 0.995733)。60 个姿态中的纵向俯仰约 −6.1455° 至 +5.3767°。
- 根节点 111 / mesh 节点 112：首帧 X 范围约 −1.09793 至 −0.97148；PCA 长轴方向约 (−0.002385, 0.085337, 0.996349)。60 个姿态中的纵向俯仰约 −6.4819° 至 +4.9706°。

这些是**实际杆几何的统计长轴**，不是精确铰点拟合。首帧 Z 包围跨度约 3.8741、3.8657，也不是铰点中心距。不得将它们改写成“实测杆长 3.5”或“缸体倾角约 6°”。随转动变化的连杆俯仰和固定往复轴倾角是两个不同量。

## 中央区域检查与中轴的细节

检查先覆盖全部 200 个挂载 mesh 的节点。中央细查使用世界坐标 |X|≤0.5、Y=0.7～2.5、Z=2.7～10.3：

1. 以实际位置缓冲及三角索引建立连通分量，保存可能与该区域相交的分量数值摘要，共 56 个候选。
2. 对三角形做包围筛选，并对 X=±0.5 平面进行真实多边形裁剪，再在侧视图检查。因此不会仅因“三角形顶点不落在中央”就漏掉跨越中央的面。
3. 实际可辨的中央结构包含驱动轮轴、车架/车体边面、前转向架及支承件。在这一检查范围内，没有可独立追踪的中缸长轴、内部连杆两个端点及配套曲柄腹板。

这不构成对其他高度、区域、未表达结构或合并语义的绝对排除。也不能由“名字没有 middle cylinder”推导不存在。本结论来自所述空间与拓扑检查，但仍保留模型简化/合并的可能。

还需纠正“教师所有驱动轴完全笔直”的过度概括：

- 中驱动轮 mesh 节点 97 在局部 X=0 有一个圆环；拟合半径约 0.07122799，圆心局部 (Y,Z)=(-0.08530710, 0.05275864)，偏离轮轴线约 0.10030342。
- 前后驱动轮相应圆环偏移仅约 0.009467。
- 中轴有 128 个左半侧三角形直接连接 X≈−0.519458 与 X=0，体现分段倾斜/折弯的轴面。此观测不是完整的工程曲轴、曲柄销、腹板或内部连杆连接的证据。

圆环的功能解释标记为 UNRESOLVED。圆环拟合 RMS 约 1.8×10⁻⁷ 源单位。此细节只应按教师几何记录，不能借它补出尚不可辨认的内部机构。

## 对当前自写候选的约束

检查的候选文件为 r22/reference/driving_crank_assembly.py 与 cylinder_actuation_assembly.py：

- 倾角 0.11 直接进入 NumPy 的 sin/cos，语义为弧度，即约 6.30254°。
- 相位 1.7 与 4.3 同样是弧度，约 97.40283° 与 246.37185°。代码未显示把度误当弧度的二次转换。
- 杆长 3.5、相位与安装参数明示为推定；source_model_used=False。

所以，目前没有证据把前驱动轴与中杆碰撞归因于“教师坐标没转对”或“已证实的度/弧度错误”。源模型确实存在默认姿态/首帧差异，但它未直接驱动此自写候选。也不能把 0.11 擅自解释成 0.11° 来制造通过。

应保留当前碰撞失败，等待独立内部机构证据，或把后续参数搜索明确标注为新的自写推定实验。教师外侧杆约 5～6° 的瞬时摆角不能转移成中缸安装倾角。
