# 《Survivor: Palau》1944 飞行员求生与捕鱼线｜全量包 R2

这是本条项目线的统一交接包。后续讨论、研究、实现和验收都以本包中的 `01_MASTER_SPEC_ZH.md` 为主控文件。

## 使用规则

1. 先读 `01_MASTER_SPEC_ZH.md`。
2. 新结论追加进主控文件和 `07_CHANGELOG.md`，不要另起互相冲突的说明。
3. 历史事实、游戏改编和待核查项必须分开标记。
4. `03_LOCKED_DECISIONS_AND_REJECTED_ROUTES_ZH.md` 中的禁用路线，不得重新引入。
5. 没有直接证据的装备，不得写成真实飞行员当天“肯定携带”。
6. 所有三维、交互和关卡实现必须服务于“水面观察—手线钓鱼—简单木鱼叉—后期自由潜”这条主线。

## 当前一句话方向

飞行员先用求生包手线钓鱼；随后把航空眼镜或镜片改成水面观察工具，配一根短呼吸管，脸朝下漂在水面，一边持续看鱼一边钓鱼；再制作最简单的削尖木鱼叉，在岸边、潮池和浅水近刺或短距离投刺；后期才逐渐学会自由潜，始终不发展弹力鱼矛或机械鱼枪。
