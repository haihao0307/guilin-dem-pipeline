# 游戏执行简报

## 1. 第一阶段：迫降

目标：让玩家保住最核心装备，而不是立即进入捕鱼。

关键交互：

- 发出遇险呼叫
- 锁开座舱盖
- 受控迫降
- 离开飞机
- 充气救生衣
- 展开单人筏
- 判断浅礁、浪和岸线

失败风险：

- 飞机下沉
- 被浪卷回机体
- 装备丢失
- 救生筏损伤
- 伤口和疲劳

## 2. 第二阶段：手线钓鱼

资产：

- 少量鱼线
- 少量鱼钩
- 简单坠子
- 小刀
- 饵料

交互：

- 放线
- 调整深度
- 观察浮动或拉力
- 收线
- 挂礁
- 鱼线断裂

## 3. 第三阶段：水面观察钓鱼

必须实现的姿态：

- 腹部朝下漂浮
- 双腿轻微平衡
- 脸在水下
- 呼吸管顶部在水面上
- 一手控线
- 一手划水或扶礁

摄像机：

- 主视角在水下
- 能看见水面波纹和呼吸管
- 能看见鱼饵
- 能看见鱼群靠近
- 不应频繁强制抬头

关键反馈：

- 呼吸正常
- 管口被浪淹没时短暂呛水
- 镜片轻微起雾或渗水
- 鱼对手部和身体动作产生反应

## 4. 第四阶段：木鱼叉

制作：

- 选择直木棍
- 削尖
- 可选绑扎小金属尖
- 检查是否开裂

动作：

- 岸上短投
- 浅水下刺
- 向前近刺
- 收回
- 卡在珊瑚
- 鱼挣脱

不得实现：

- 弹力
- 扳机
- 滑轨
- 水下远距离高速发射

## 5. 第五阶段：自由潜

成长参数：

- 放松程度
- 屏气时间
- 耳压平衡
- 下潜姿态
- 上浮判断
- 潮流理解
- 接近鱼的能力

风险：

- 耗氧
- 迷失方向
- 潮流
- 珊瑚割伤
- 独潜失去意识
- 疲劳、饥饿和脱水

## 6. 验收门槛

- 浏览器中可直接看到完整水面观察流程
- 控制台 0 错误
- 鱼饵、鱼钩、鱼线与鱼群真实可见
- 呼吸管口与水面的关系正确
- 不抬头也能持续观察
- 鱼对玩家行为有反应
- 木鱼叉遵守近距离和水阻限制
- 没有任何弹力或机械鱼枪内容
