# 已锁定结论与永久禁用路线｜R5

本文件是硬限制。除非用户后续明确推翻，否则任何执行端、资产端、代码端和研究端均不得自行弱化、替换或恢复被否决路线。

## 一、统一世界与靠谱体系

1. 所有系统必须运行在同一个世界、同一物理、同一个 `worldTime` 上。
2. 游戏可玩世界统一从 **1944-12-31 05:00 Palau 本地时间**开始；历史原型日期仍为 1944-11-21。
3. 天空、风、浪、潮汐、鸟、果蝠、蜥蜴、海洋生命、火、腐败、身体、巡逻艇和日记不得各自维护独立时钟。
4. 大生态量是项目目标，不是需要缩减的问题。移动端必须通过实例化、群体场、更新频率、缓存、远中近分层和逐步细化运行。
5. 不得以“移动端会炸”“普通项目做不了”为理由删除鸟潮、果蝠潮、夜海、森林、花、鲸、manta、翼鼓瑞鱼、海龟或其他生态。
6. 远中近表达必须属于同一群体和同一时间，不能通过随机刷新伪造连续世界。

## 二、Stone Money Island 生态钟

1. 天微亮、约五点多至六点，不同海鸟分批出岛觅食，形成成千上万只的晨间出海潮。
2. 天黑以前，不同海鸟分批归岛，形成成千上万只的黄昏归岛潮。
3. 天堂鸟在林冠、树间、屋顶、海滩和玩家脚下林谷中飞翔。
4. 石钱洞及相关洞穴中有数万只食果果蝠，夜间成群出洞，清晨返回。
5. 蜥蜴暮鸣是立即返洞的生存信号；暮鸣后入夜极快。
6. 夜间海洋保持活跃，包含荧光藻和大型海洋生命。
7. 远处鲸与脚下 manta、翼鼓瑞鱼、海龟等是本岛已锁定景观与生态，不得因通用数据库未命中而删除。
8. 后续研究只完善物种名、数量层级、季节、动作和资产，不重新讨论这些现象是否存在。

## 三、洞穴、雨水与住所

1. 主角长期住在 Stone Money 洞穴；一端通森林，一端可从高处观察海洋和巡逻艇方向。
2. 主角把单人橡皮艇搬进洞穴，作为集雨、储水缓冲、干燥平台、物资托盘和紧急浮具的一部分。
3. 降落伞伞布或可用塑料布负责集雨，竹槽和竹管导水，容器与筏体负责接水和储备。
4. 椰壳、椰纤维、沉淀和椰壳炭只用于改善已收集雨水，不得表现为海水直接过滤成饮用水。
5. 第一段脏水、树叶、泥沙、鸟粪、果蝠污染、溢流、泄漏和滤材失效必须进入物理关系。
6. 水系统稳定后才逐步解锁清洗、洗衣和洗澡；不得开局无限用水。
7. 海盐通过海水蒸发/浓缩获得，与饮水系统严格分离。
8. 椰子油是后续生活生产线，需要椰子、时间、火和工具，不是免费资源。

## 四、持续火种系统

1. 火是连续生命系统，不是“还剩几根火柴”的短线资源。
2. 玩家必须每天维护余烬、干引火物、干燃料、防潮层、灰床和通风。
3. 白天不得出现从海面可见的火光或烟；夜间只能使用遮光、低烟小火。
4. 火状态至少包括稳定余烬、低火、烹饪火、烟过大、燃料不足、受潮、濒熄和完全熄灭。
5. 火完全熄灭后不能一键重启；重新准备和获得稳定火种通常占用约一个完整白天。
6. 熄火必须连锁影响饮水处理、烹饪、照明、驱虫、保温、伤口处理、椰壳炭、盐、椰子油和食物保存。
7. 风暴、持续雨、湿燃料、伤病、巡逻艇逼近、错误通风和忽视维护都可导致熄火。
8. 昨天是否维护火，必须真实决定今天能完成哪些工作。

## 五、食物与捕鱼成长顺序

1. 开局不依赖金属鱼钩，也不以金属钩作为普通项目式平衡拐杖。
2. 最早食物来自贝、螺、蟹、林中果实、椰子和椰子蟹等可验证来源。
3. 第一种捕鱼能力是站在较高礁石、台地或岸边，从上往下对极浅水中的鱼进行近距离插刺。
4. 早期插鱼必须受反射、折射、浪、鱼变向、杆长、落点、潮位和身体平衡影响。
5. 主角之后才制作水面观察镜与短呼吸管。
6. 再之后才以降落伞伞绳/拆分纤维、植物纤维、木、骨、贝壳等制作鱼线、结和鱼钩。
7. 手工钩、线会高频磨损、挂礁、变形、断裂和丢失；稳定性来自持续生产和知识改进，不是无限库存。
8. 水面观察手线、较深水近刺和自由潜依次后置。
9. 永久禁止弹力鱼矛、橡胶动力 pole spear、Hawaiian sling、扳机鱼枪、机械鱼枪和远距离高速水下发射。
10. 玩家只取当前能吃、能处理和能保存的数量；过量捕获通过腐败、燃料、搬运、烟和暴露产生真实成本。

## 六、每日行为与纸面日记

1. 每日循环锁定为：微亮醒来 → 看鸟潮和天气 → 检查水与火 → 安排任务 → 取水/修补/取食/插鱼 → 躲巡逻艇 → 蜥蜴暮鸣后立即返洞 → 黄昏鸟潮 → 夜间低烟火与食物处理 → 果蝠出洞、观星和看夜海 → 写纸面日记 → 睡眠或特殊事件。
2. 每一个行为都消耗真实时间和体力；不能在一个下午完成所有生产线。
3. 蜥蜴暮鸣后仍留在山林，必须承担快速入夜、迷路、跌伤、坠崖和死亡风险。
4. 每天/每次游戏结束后，根据当天真实行为生成一页纸面故事，不得输出与玩家经历无关的模板散文。
5. 日记必须记录水、火、食物、工作、生态、巡逻艇、错误、情绪、记忆碎片和次日计划。
6. 日记使用纸、铅笔/炭笔、草图、折痕、水渍、油渍和删改的质感；现代 iPad/平板只负责阅读和整理，不改变 1944 年纸本逻辑。
7. 日记同时承担存档、复盘、知识积累和人物成长证据。
8. 写日记需要真实照明；光、烟、燃料、洞穴氧气与敌情必须共享同一物理。

## 七、Pacific 女神

1. Pacific 女神只在台风、风暴、睡梦、昏迷、中毒、高烧、严重脱水、Power Tree 或少数重大选择后出现。
2. 她不是每日任务 NPC，不固定每晚出现。
3. 她使用原创、预言式、带太平洋岛屿感的语言和意象；在完成真实语言研究前不得冒充现实 Palauan、Yap、Carolinian 或其他语言。
4. 她提示“该看什么”和“关系是什么”，不提供 GPS、精确坐标、敌人位置、剩余资源或最优答案。
5. 她不能挡子弹、自动灭风暴、补满物资、恢复火种或取消错误后果。
6. 她代表岛屿私性、神秘和照应的一面；玩家仍必须靠劳动、观察和选择活下来。

## 八、巡逻艇与战争威胁

1. 巡逻艇不是 Boss，不发展交火、血条和躲弹系统。
2. 威胁接近时，小鱼、苏眉、海龟和其他可见动物撤离，形成“珊瑚还在、动物突然消失”的空海。
3. 玩家必须在第一发子弹之前停止活动并隐藏。
4. 火烟、洞口反光、暴露伞布、晾晒物、鱼血、划水、水面身体轮廓和夜间照明都可增加发现风险。
5. 玩家附近第一批日军子弹入水水花出现即 Game Over，不存在最后逃生窗口。
6. 数日后三股浓烟、鲸鲨和两只海龟事件是游戏改编，以残留物、烟和生态静默表达，不做血腥奖励。
7. 巡逻艇离开后动物逐步返回，不得瞬间刷新。

## 九、第一集范围

1. 第一集只完成：活下来、维持水与火、学会取食、读懂生态钟、躲敌人、每天记录、逐渐喜欢并敬畏海洋。
2. 主角不会在岛上立刻成为国家地理科学家。
3. 战后才可能成为野外科学家、摄影记录者、海洋保护者或救援飞行员。
4. 后续爱情线属于未来故事，必须是成年、平等、具体人物关系，不在当前求生循环提前完成。

## 十、永久禁用

- 以移动端性能为理由删掉生态量；
- 多个互相漂移的世界时钟或独立物理；
- 开局普通手线/金属钩成为唯一食物解法；
- 无限金属鱼钩、无限鱼线、无限火、无限水、无腐败食物；
- 椰壳炭直接把海水变成饮用水；
- 火熄灭后按一个按钮立即恢复；
- 白天公开生火而没有巡逻艇发现风险；
- 蜥蜴暮鸣后仍可无风险在山上活动；
- 模板化自动日记、与玩家经历无关的漂亮散文；
- Pacific 女神每日播报任务或自动救场；
- 环保分、道德条、海洋亲和力、导航 +20 等抽象数值；
- 把天堂鸟、鸟潮、果蝠潮、夜海和大型海洋生命降级为可删装饰；
- 把未来科学家、守护者或爱情线提前做成当前岛上身份。

## 十一、不得偷换的逻辑

- “生态量巨大”不等于“移动端必须砍内容”；靠谱体系必须承担运行问题。
- “所有系统共享一个时间”不等于“所有对象每帧都用最高成本更新”；允许分层调度，不允许世界分裂。
- “没有金属鱼钩”不等于“没有稳定食物路径”；热带潮间带、浅水插鱼和可持续手工钩线共同形成循环。
- “火是持续系统”不等于“火永远不会灭”；维护失败必须产生一整日复燃代价。
- “椰壳过滤雨水”不等于“雨水一定安全”；污染、滤材和煮沸仍需判断。
- “天堂鸟是实地真值”不等于“无需核查具体物种标签”；现象锁定，命名和资产继续研究。
- “每天写日记”不等于“每天出现相同模板”；世界行为决定文本与页面。
- “Pacific 女神说岛屿语言”不等于“可以拼贴或伪造现实名族语言”。
- “游戏很容易死”不等于“随机死亡”；死亡必须由水、火、时间、地形、敌情、天气或身体状态连续导致。
