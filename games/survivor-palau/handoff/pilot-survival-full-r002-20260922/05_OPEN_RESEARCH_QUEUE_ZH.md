# 待继续研究与生产阻断队列｜R4

按优先级排列。已锁定的玩法规则不因研究尚未完成而反复回退；研究的作用是提高史实、天文、海况、物种行为、文化边界和视觉表达精度。

## P0：R4 最小循环进入代码前的硬阻断

1. 建立唯一 `worldTime`，同时驱动天空、潮汐、风浪、动物、巡逻艇、腐败、体力和资源账本。
2. 建立 `ResourceLedger`：水容器、食物批次、鱼钩、鱼线段、火种、医疗、修补、信号物资、身体状态和应急承诺量必须独立记录。
3. 建立 `ObservationLedger`：保存原始征兆、时间、位置、能见度、玩家解释、置信度、线索冲突和后续验证。
4. 建立 `KnowledgeGraph`：只记录在特定条件下验证过的关系，不使用抽象技能点。
5. 制作第一条竖切片：至少三类自然征兆 → 清点一天资源 → 做一次有限选择 → 发生一个意外损耗或误判 → 后果进入下一轮。
6. 建立“玩家实际可知信息”和后台真值的隔离层，防止 UI 泄漏天气、敌情、岛屿方位或身体精确数据。
7. 在连续可玩闭环、桌面截图、390×844 截图和控制台 0 错误形成前，不得宣布 R4 可玩。

## P0：直接影响故事与开局装备

1. 找到 VMF-122 在 1944 年 11 月的具体航空求生装备配发表。
2. 核对 FG-1 Corsair 中单人筏的具体固定位置、释放方式和动画步骤。
3. 核对飞行员当天可能使用的航空眼镜型号。
4. 确认后背包是 Original、Modified、M-592，还是其他过渡组合。
5. 确认 1944 年海军航空求生包内捕鱼套件的准确数量和外形。
6. 确认开局容器容量、口粮份量、鱼线长度、鱼钩数量、火柴和信号物资，使账本不是任意数值。

## P0：巡逻艇系统进入代码前的硬阻断

1. 确定当前可用日军巡逻艇资产的真实尺寸、吃水、发动机位置、航速、转向半径和尾迹关系；低质量占位船不能冒充生产资产。
2. 建立唯一 `ThreatState`，统一 Patrol Boat、Fish、Turtle、Bird、Ocean、Player 与 UI，不允许各模块自行计时和判断威胁。
3. 建立玩家暴露模型：身体、水面轮廓、呼吸管、鱼线、划水、露头、移动速度、光照、阴影、礁石和红树林水线。
4. 建立真实世界空间掩体查询，不能把“按隐藏键”直接等同于隐藏成功。
5. 建立第一批近身子弹水花触发即时 Game Over 的单一权威入口，确保不会同时进入扣血、逃跑或反击逻辑。
6. 确认现有 Fish、苏眉、海龟和鸟类资产是否具备可用动作与事件接口；没有可见生产成果时不得只在状态变量中宣称生态撤离完成。
7. 完成桌面与 390×844 静音视觉验收。

## P1：星辰、日月与 1944 年帕劳天空

1. 按帕劳实际纬度、经度和 1944-11-21 起始日期生成太阳、月亮、星辰升落与夜长。
2. 确定故事各月份可见、辨识度高且适合教学的星或星群；不能直接照搬夏威夷或其他地区的完整星罗盘。
3. 验证低纬度环境下北天与南天参照的可用性、地平线高度和季节变化。
4. 建立云遮、月光、雨幕、树冠和地形遮挡下的替代判断，不让星图成为永久可用 HUD。
5. 核实 1944 年飞行员可能掌握的基础天文导航，与后续向岛民或 Pacific 女神学习的知识严格区分。

## P1：涌浪、风、潮与远方云层

1. 建立帕劳外海主涌浪、局地风浪、季节风、礁盘折射、反射、水道和破浪的基础模型。
2. 明确哪些波形可由身体、筏体和漂浮物读取，哪些只能由长期经验判断。
3. 研究高岛地形云、潟湖或浅水反光、云底颜色、湿度和天气变化，不把云固定成陆地箭头。
4. 建立至少两种可靠组合和两种误判案例，例如云存在但无可登陆地、鸟在觅食但不返巢。
5. 把烟、火焰、树叶、海面细纹、云移动和体感接入同一风场。
6. 核查潮汐、日照和风浪对取水、捕鱼、礁盘通行、隐藏和巡逻艇可见性的共同影响。

## P1：鸟类作为线索

1. 建立 Palau/Airai/Koror 周边近岸与海鸟物种表，不用泛化的“海鸟”占位。
2. 记录物种的巢地、日出出海、日落归巢、觅食半径、繁殖季、天气反应和水面行为。
3. 明确哪些鸟可能提示近岸、鱼群、天气或漂浮物，哪些远洋鸟不提供直接陆地方向。
4. 建立异常行为：低飞、盘旋、突然离开、携食返航、避风和受巡逻艇惊扰。
5. 所有鸟类提示必须允许被时间、季节、个体行为和天气改变。

## P1：Pacific 女神与文化边界

1. Pacific 女神保持原创虚构，不借用、拼贴或改名现实 Palau、Yap、Caroline、Hawaiian 或其他太平洋神祇。
2. 查证帕劳本地海洋知识、人物与语言时，优先使用帕劳机构、口述史、博物馆、大学或可靠民族志。
3. 将一般 Pacific wayfinding 原理与 Palau-specific 知识分栏，不把 Hōkūleʻa 的夏威夷系统直接标成帕劳传统。
4. 设计梦境触发频率和信息上限，避免女神成为任务导航器或剧情补丁。
5. 建立“自然解释 / 神性解释均成立”的场景语言，不用特效直接证明所有事件都由神力造成。

## P1：白沙滩三股浓烟事件

1. 确认白沙滩在当前世界中的准确位置、巡逻艇可达水深、登陆点和玩家隐蔽观察位置。
2. 三股烟必须由三个真实火源、风场和燃料状态生成，而不是静态贴图。
3. 鲸鲨和海龟的体型、搁置、处理、血迹、油脂、烟和遗留后果需要物理一致。
4. 事件明确标为游戏改编；除非找到具体史料，不写成 1944 年某支日军的已证实事件。
5. 残酷清楚但不猎奇，不重复近距离展示；核心是过度取用、浪费与生态静默。
6. 玩家当时不能正面介入的原因必须由火力、距离、伤病和资源差距明确呈现，而不是强制锁键。
7. 敌人离开后，三股烟、残留物、海面动物缺席和玩家资源选择必须继续影响后续循环。

## P1：直接影响水面观察系统

1. 调查 Palau/Airai/Koror 可作为短呼吸管的真实空心植物。
2. 排除有毒、刺激性、易碎或管径过小的植物。
3. 核查航空镜片与临时面垫的可行固定方式。
4. 找到 1940 年代当地或军方可获得的安全填缝材料。
5. 研究水面观察镜在波浪、起雾和渗水下的真实表现。

## P1：巡逻艇历史与感知依据

1. 查清 1944 年 Koror—Malakal—Airai 一带日军小型巡逻艇的类型、巡逻范围和常见任务。
2. 核对该类船只的发动机声、航速、尾迹、船影和观察高度。
3. 确定玩家在水面、浅潜、贴礁、阴影与红树林水线中的可见性差异。
4. 研究子弹入水水花、声音和间距，使失败因果清楚，但不发展成可躲避枪战。
5. 核实战争环境下夜间、雨天、强浪和逆光对双方发现能力的影响。

## P2：捕鱼、保存与有限获取

1. 建立帕劳浅礁常见鱼种表。
2. 记录鱼种的栖息水深、群游、警觉、食性和咬钩行为。
3. 标注可食风险、毒棘、雪卡毒素和处理方式。
4. 确定哪些鱼适合早期手线，哪些适合浅水木鱼叉。
5. 核查 1944 年当地季节、潮汐和日照对鱼群活动的影响。
6. 建立捕获后的清理损耗、可食重量、盐分、烹饪燃料、腐败速度和保存上限。
7. 让“捕太多”通过腐败、燃料消耗、搬运、暴露和鱼群变化产生实际成本，而不是扣道德分。
8. 建立可以选择放弃、释放或只观察的 Encounter 结果。

## P2：生态危险语言

1. 分别研究小型群鱼、苏眉等大型礁鱼、海龟和近岸鸟类对船影、发动机、尾迹、冲击声和大型移动物的反应。
2. 在保留物种差异的同时，建立统一、强可读的“生态撤离”事件；不能让少数未响应个体破坏危险信号。
3. 定义巡逻艇离开后各类动物的渐进返回顺序、最短等待和空间来源，避免一帧刷新。

## P2：长期守护者与人物关系

1. 决定主角战后职业的年代可行路径：野外科学、摄影调查、航空搜救、海洋保护或其组合。
2. 若使用 National Geographic 名称、标志、杂志页面或正式雇佣关系，核查品牌授权与具体年代。
3. 设计主角帮助岛民但不取代当地人主体性的任务结构。
4. 爱情线必须建立完整成年角色：姓名、家庭、职业、知识、愿望、冲突和选择；不能只写“岛国女朋友”。
5. 第一集只埋下长期关系与责任，不提前完成职业、婚恋和守护者全部终点。

## P3：实现与验收

1. 制作水面观察相机测试页。
2. 制作短呼吸管波浪淹没测试。
3. 制作鱼线、鱼钩和鱼饵可见性测试。
4. 制作木鱼叉岸上短投、浅水近刺测试。
5. 制作自由潜耳压、耗氧和潮流测试。
6. 制作资源账本计划/实际消耗/意外损耗测试。
7. 制作星辰、涌浪、风、鸟和云的交叉判断与误判测试。
8. 制作 Pacific 女神梦境只提示关系、不泄漏答案的测试。
9. 制作白沙滩三股烟从生成、观察到余波的连续测试。
10. 制作巡逻艇远端接近、生态撤离、隐藏成功、被发现和即时 Game Over 的连续自动化夹具。
11. 制作静音、无震动模式下的视觉可读性测试。
12. 制作动物渐进返回测试，验证没有突现和全量重建卡顿。
13. 固定所有结果到同一在线工作台和同一 Markdown。

## 已解决、不得继续占用研究队列

- 历史原型日期已经锁定为 1944-11-21。
- 巡逻艇威胁不采用“子弹出现后仍有短暂逃生窗口”。
- 第一批近身子弹水花出现即 Game Over。
- 不制作对日军的战斗系统、生命值消耗或反击路线。
- 前台不显示危险进度条、发现百分比或敌人视野扇形。
- 玩家可以获取自然资源；“有限获取”不是全面禁止捕鱼或使用材料。
- Pacific 女神不提供无敌、自动导航或自动资源答案。
- “海岛子民背离海洋”不作为对真实帕劳人的概括。
