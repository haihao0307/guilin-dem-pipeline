# R9｜相互因果链总账

> 本文件把人、食物、痕迹、猫、资源地点、火、水、巡逻艇与日记连接成可执行的长期因果关系。它不是剧情脚本，而是供 `DeferredConsequenceGraph`、`HumanTraceField`、`PatrolInferenceState`、`HarvestPatchRegistry` 和 `JournalArchive` 共同使用的关系合同。

## 1. 因果系统的基本规则

1. 任何后果必须有世界原因，不得凭空惩罚玩家。
2. 任何延迟后果必须留下至少一种可回溯证据：日记、物件、脚印、路线、气味、动物行为、资源变化或敌方行动。
3. 同一行为可以同时产生好处和代价。
4. 因果链允许被玩家中途改变，不得固定播放唯一结局。
5. 猫只是生态行动者与情感伙伴，不是敌情报警器。
6. 真正致命结果一般由多条链交汇产生，不应由单个微小旧选择无条件触发。
7. 运行时只在相关事件发生时更新稀疏关系，不逐帧遍历全部历史。

## 2. 沙滩痕迹链

### 2.1 反复上岸

同一白沙滩反复上岸
→ 湿沙脚印与拖痕重复
→ 林缘形成固定入口
→ 草叶折向一致、泥土压实
→ 雨水沿路线流动，路径更清楚
→ 日军某次登陆注意到异常
→ 之后提高该海滩检查频率
→ 数周后将搜索范围推进到高地。

可中断方式：轮换上岸点、减少重物拖行、在真实潮窗内活动、改变进林路线、降低重复频率。

代价：更远路线、更高体力消耗、迷路和暮色风险。

### 2.2 清理不足

捕鱼返岸后立刻回洞
→ 沙滩留下脚印、血水、鱼鳞和骨片
→ 食腐动物聚集
→ 海上巡逻者先注意到异常鸟群或动物集中
→ 登陆后发现人为切割和处理痕迹
→ `PatrolInferenceState` 从单一异常上升为“可能有人长期生活”。

### 2.3 清理过度

整片沙滩被规则刷平
→ 自然波纹、蟹孔和鸟脚印被统一抹去
→ 形成过度整齐的人造面
→ 登陆者注意到与周边不同
→ 下一次高潮后再次检查
→ 清理行为本身成为长期重复模式。

## 3. 鱼获—遗留物—动物链

### 3.1 丰收但处理不足

幸运日获得大量鱼
→ 搬运和处理时间暴增
→ 暮色前无法完全清理
→ 内脏、血和骨留在沙滩或洞口
→ 猫、椰子蟹、虫、鸟形成固定取食路线
→ 食物残留被拖向林缘
→ 人与动物共同强化通往洞穴方向的路径
→ 登陆搜索把骨头、脚印与路径连成生活证据。

### 3.2 适量捕获

玩家在鱼群丰富时主动停止
→ 鱼获可在安全时间内处理
→ 骨与硬组织被分类保存
→ 沙滩清理时间缩短
→ 余烬维护和返洞窗口保住
→ 第二天体力、水和火都更稳定
→ 数周后积累可用骨钩、针和锥。

### 3.3 内脏利用与污染

把少量内脏用于诱集椰子蟹
→ 当晚诱集效率提高
→ 若持续在同一地点使用，气味和动物路线固定
→ 蚊虫、腐败和水源污染风险增加
→ 必须轮换诱饵点并控制数量。

## 4. 猫—食物—住所链

### 4.1 第一次偷鱼

鱼在夜间可达位置保存
→ 气味进入风场
→ 猫夜间路线与洞穴重合
→ 鱼少一块、骨头被拖动
→ 玩家第二天从物理痕迹推断“有东西来过”
→ 后续决定挂高、盖住、移动或主动留食。

### 4.2 主动喂食

连续数次留下少量鱼
→ 猫形成固定来访时间
→ 更愿意在洞口附近睡觉
→ 食物消耗增加，猫路线更明显
→ 洞口周围毛、脚印和骨头增加
→ 玩家需要调整处理和清理方式。

这条链不产生敌情预警。猫是否出现、离开或睡觉，都不能被当作巡逻艇信号。

### 4.3 猫拖骨

猫偷走鱼头或骨头
→ 沿自己的隐蔽路线拖入林缘
→ 骨头散落在玩家未检查的位置
→ 几周后登陆人员可能把骨头与人类处理痕迹联系起来
→ 玩家必须在日记中记录猫的路线和遗留物，而不是认为“猫吃掉就等于消失”。

## 5. 路线—体力—暮色链

### 5.1 最短路线依赖

每天走同一条最短路
→ 节省体力和时间
→ 道路越来越明显
→ 雨后泥沟、断枝和脚印方向更稳定
→ 日军更容易追踪。

### 5.2 轮换路线

改走不同路线
→ 暴露分散
→ 路程、坡度和摔落风险提高
→ 捕鱼、清理或护火时间减少
→ 若没有预留返程，暮蜥鸣后可能被困在山里。

### 5.3 标记路线

玩家用绳结、刻痕或石堆标记夜间路线
→ 降低迷路概率
→ 人工痕迹增加
→ 标记必须隐蔽、有限且可撤除
→ 太明显时会帮助登陆搜索者而不是只帮助玩家。

## 6. 火—烟—清理链

### 6.1 护火优先

玩家为保住余烬提前离开沙滩
→ 火系统稳定
→ 沙滩痕迹未完全处理
→ 日军长期怀疑增加。

### 6.2 清理优先

玩家花更多时间处理脚印和骨头
→ 沙滩暴露下降
→ 回洞过晚、余烬变弱
→ 次日饮水、烹饪、椰壳炭和椰子油生产受损。

### 6.3 烧毁遗留物

把骨头、鳞和纤维全部焚烧
→ 表面证据减少
→ 燃料消耗、烟和气味增加
→ 灰堆和炭屑仍是证据
→ 白天或靠海焚烧可能直接暴露位置。

## 7. 水—卫生—痕迹链

### 7.1 洗净处理区

用储水清洗鱼血和容器
→ 卫生改善
→ 饮用水储备下降
→ 若把污水倒向集雨区，反而污染水系统。

### 7.2 海水清洗

用海水清洗处理区
→ 节省淡水
→ 盐、血和气味可能在退潮带集中
→ 动物聚集和表面痕迹依然存在。

### 7.3 分区成功

把取水、食物处理、火种和睡眠区长期分开
→ 水污染、虫害和猫偷食减少
→ 洞穴空间与搬运成本上升
→ 但数月后感染和食物腐败显著降低。

## 8. 资源地点轮换—痕迹链

### 8.1 同一礁台过度使用

连续插鱼
→ 鱼更警觉、靠岸减少
→ 玩家停留更久、动作更多
→ 脚印、血、工具痕迹与返洞路线加深
→ 收益下降而暴露上升。

### 8.2 轮换与休息

切换至另一礁台
→ 原地点鱼群逐渐恢复
→ 旧路线自然退化
→ 新地点返洞更远、更危险
→ 玩家需要在生态恢复与个人安全之间平衡。

### 8.3 根茎地留种

不把芋头或木薯全部挖净
→ 短期食物减少
→ 该地点脚印和翻土更少
→ 数月后形成稳定食物区
→ 长途觅食次数下降
→ 整体暴露减少。

## 9. 漂流物—材料—痕迹链

### 9.1 大型漂木搬运

发现优质漂木
→ 可以制作工具、竹槽支架或修舟
→ 拖行会在沙滩形成深痕
→ 若直接拖向洞穴，等于画出路线
→ 玩家需要分段搬运、临时藏放或等待合适潮位。

### 9.2 稀有铁钉

从旧船板找到一根铁钉
→ 做鱼钩可迅速提高某次捕鱼机会
→ 做锥可长期支持骨钩、伞布和篮具生产
→ 修锅架可提高根茎、盐和椰子油处理
→ 修旧舟可改变数月后的移动范围
→ 任一用途永久记录，不能无限补充。

## 10. 洞穴设施—可见性链

### 10.1 集雨面扩大

展开更多伞布
→ 雨水量增加
→ 反光、轮廓与风中摆动更明显
→ 巡逻艇从海面发现异常的概率增加。

### 10.2 竹槽外延

把竹槽延伸到更好的集雨位置
→ 收水效率和生活质量提高
→ 被砍竹、固定绳和直线结构形成明显人造关系
→ 必须用地形、植被和材质降低暴露。

### 10.3 洞口整理过度

清除洞口全部植被
→ 进出和观察更方便
→ 洞穴、火光和物资从海上更可见
→ 雨、风和热也更直接进入住所。

## 11. 敌方推断链

### 11.1 单一异常

一处脚印或鱼骨
→ 可能是偶然，不足以定位玩家。

### 11.2 多次一致异常

相同海滩反复出现处理痕迹
+ 林缘固定路线
+ 海上观察到偶发烟或反光
→ 敌方形成“岛上可能有人”的假设。

### 11.3 登陆搜索

登陆人员发现新旧脚印、拖痕、骨头和断枝
→ 判断活动发生时间
→ 记录进林方向
→ 后续巡逻提高频率。

### 11.4 住所缩小

多次搜索发现路线通向同一高地区域
→ 结合水源、洞穴和观察点推断住所
→ 最终可能发现集雨设施、火床、日记或储存物。

## 12. 发现后的后果层级

玩家被发现不一定在第一枚脚印后立即死亡。可能依次发生：

1. 巡逻艇更靠近海岸；
2. 某些捕鱼窗口变得不可用；
3. 登陆搜索增加；
4. 玩家必须暂时停用白沙滩；
5. 资源路线被迫更换；
6. 需要拆除、搬迁或放弃部分设施；
7. 猫仍按自己的食物和路线行动，不提供警报；
8. 最终洞穴被发现时，触发死亡、俘获或艰难迁移。

这样长期暴露会逐步压缩生活空间，而不是无预警地瞬间结束游戏。

## 13. 日记回溯要求

每条重大后果至少必须能够回到以下一种证据：

- 当天原始日记；
- 后来边注；
- 被使用或丢失的物件；
- 地点使用记录；
- 猫拖动物的路径；
- 骨头、灰、脚印或植被状态；
- 巡逻艇停留和登陆变化；
- 火、水、食物和身体状态。

系统不能替玩家总结出唯一答案，但必须保证玩家有机会理解“为什么会变成这样”。
