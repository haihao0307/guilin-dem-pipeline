# R3 当前实现状态｜2026-09-22

## 一、已经完成并可作为权威输入的内容

- 今天早上的巡逻艇、生态预警和致命失败规则已经写入主控 Markdown。
- 小鱼、苏眉、海龟及其他可见动物在明确威胁范围内撤离，珊瑚仍在，形成“空海”。
- 玩家必须在第一发子弹之前隐藏。
- 第一批玩家周围的日军子弹入水水花出现即 Game Over。
- “中弹后仍有极短逃生窗口”的旧候选已经失效。
- 前台不显示危险进度条、发现百分比、敌人视野扇形、红色警报或伤害数字。
- 巡逻艇不是 Boss；玩家没有交火、反击或多次中弹生存路线。
- 若玩家成功隐藏，巡逻艇远离后动物按胆量、距离和遮蔽逐步返回。

## 二、已经存在但不能冒充 R3 完成的基础

现有原型已经有水面观察、短呼吸管、鱼群可见、鱼对玩家动作响应、手线咬钩、收线、断线和捕获等基础。这些能够支撑后续 R3，但不等于巡逻艇威胁已经可玩。

## 三、仍未进入可玩代码的关键缺口

1. 唯一权威的巡逻艇 `ThreatState`。
2. Patrol Boat、Fish、Turtle、Bird、Ocean 和 Player 共用的威胁事件总线。
3. 小鱼、苏眉、海龟及其他动物的真实撤离动作和遮蔽目标选择。
4. 珊瑚、礁缝、洞穴、阴影和红树林水线提供的世界空间掩体查询。
5. 玩家身体、水面轮廓、呼吸管、鱼线、划水、露头和光照造成的暴露判定。
6. 巡逻艇在确认发现后转向、加速、尾迹增强和射击的因果链。
7. 第一批近身子弹水花与即时 Game Over 的单一原子状态切换。
8. 巡逻艇通过后动物分批、渐进返回。
9. 桌面和 390×844 静音视觉验收。
10. 实体 iPhone/Safari 的触控、发热和帧稳定性测试。

## 四、当前最危险的错误完成方式

- 只把鱼设为 `visible=false`，但没有撤离动作、遮蔽位置和渐进返回。
- 只做一艘远处船模型，不建立发现、转向、加速与射击因果。
- 用红色 UI、进度条或警告文字代替生态变化。
- 子弹水花出现后仍允许玩家继续游泳、扣血或逃跑。
- 使用独立计时器，让 Fish、Patrol Boat 和 Ocean 对“威胁是否存在”产生不同答案。
- 只给自动化状态值，没有浏览器画面证据。
- 用软件渲染器 FPS 冒充实体手机性能通过。

## 五、生产顺序

1. 选定并验真一艘巡逻艇资产。
2. 建立全局唯一 `ThreatState` 与玩家暴露/掩体查询。
3. 接 Fish、苏眉、海龟和鸟类的生态撤离。
4. 接船影、尾迹、发动机与静音视觉信号。
5. 接隐藏成功和动物渐进回归。
6. 接被发现后的转向、加速与第一批子弹水花。
7. 水花出现同状态立即 Game Over。
8. 完成桌面与 390×844 浏览器证据；最后做实体 iPhone 验收。

## 六、当前结论

R3 已经完成的是**方向、故事和规则冻结**；尚未完成的是**可玩实现、跨模块接入和视觉验收**。在第三区列出的缺口全部关闭前，不得把本线描述为生产完成。
