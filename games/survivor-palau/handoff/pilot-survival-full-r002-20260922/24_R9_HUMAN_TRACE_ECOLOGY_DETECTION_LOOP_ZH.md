# R9｜人类痕迹—沙滩清理—食物遗留—敌方追踪—生态节点循环

> 本文件是 R8 之后的权威续章。凡与 R8 关于猫的报警作用、人类痕迹、沙滩清理、鱼骨与尸体处理、日军搜索方式、长期暴露和“人是生态一环”的描述冲突之处，以本文件为准。R8 其他已锁定规则继续有效。

- 修订日期：2026-09-23
- 统一世界起点：1944-12-31 05:00，Palau 本地时间
- 状态：故事逻辑、运行时合同和验收边界已锁定；可玩代码、资产和视觉证据尚未完成

## 1. 最高原则：人永远是生态系统中的一个节点

玩家不是站在自然之外管理资源的人，也不是进入地图后不留下任何影响的幽灵。

每次行动都会进入同一个生态与物理世界：

- 人脚踩过湿沙，会留下脚印、压实层和行进方向；
- 搬运鱼会留下血、水、鳞、拖痕、气味和落下的碎片；
- 清理鱼会改变猫、椰子蟹、虫、鸟和其他食腐动物的路线；
- 砍竹、折枝、开路和反复行走会形成可识别的人类路径；
- 火、灰、炭、油、烟与烹饪气味会进入风场；
- 洞穴、水、火、食物、猫、资源地点、巡逻艇和日记都通过同一因果图相连；
- 今天留下的一个痕迹，可能几天、几周或几个月后才被另一种生命或敌人读懂。

本作的目标不是把玩家训练成“完全不触碰自然”的人，而是让他理解：**只要活着，就会改变世界；真正的能力是看见、控制、修复并承担这些改变。**

## 2. 沙滩不是重置区，而是会保存故事的表面

### 2.1 每次上岸都会留下真实痕迹

玩家从海里回到沙滩、把鱼拖上岸、搬运木头或橡皮艇时，至少可能留下：

- 裸足、鞋底或膝跪脚印；
- 从水线到林缘的连续行进方向；
- 鱼、木头、筏体、独木舟或重物拖痕；
- 血水、鱼鳞、内脏、骨头、贝壳、蟹壳和切割痕迹；
- 绳索勒痕、木杆孔洞、篮筐压痕和竹器印记；
- 伞布、纤维、布片、线结和工具碎屑；
- 火灰、炭屑、油迹、盐结晶和食物残渣；
- 被砍断、踩倒或刻意拨开的植被；
- 反复从同一处进林形成的小路。

这些痕迹不以贴图装饰存在，而是 `HumanTraceField` 中具有位置、方向、形成时间、强度、气味、材质和可见性的世界对象。

### 2.2 痕迹会自然变化，但不会自动消失

痕迹的保存时间取决于：

- 干沙、湿沙、泥、礁石、落叶层和植被等基底；
- 潮位、浪、雨、风、日晒和蒸发；
- 螃蟹、鸟、猫、蜥蜴、椰子蟹和其他动物经过；
- 玩家是否再次踩踏、清理或掩盖；
- 日军巡逻艇或登陆人员到达的时间。

湿沙脚印可能很清楚；一场大浪可能冲淡水线痕迹，却保留林缘脚印；雨可能毁掉细节，也可能让压实的泥路更明显。游戏不能使用“离开区域后痕迹立即清空”的普通关卡逻辑。

## 3. 每次离开沙滩前必须完成 Trace Sweep

### 3.1 沙滩清理是生存任务，不是清洁小游戏

玩家每次在沙滩登陆、捕鱼、处理食物、收集漂流物或搬运材料后，都必须判断是否有时间完成一次 `TraceSweep`：

1. 回看自己从水线到林缘的移动路径；
2. 收回落下的绳、布、鱼鳞、骨头、碎木和工具零件；
3. 处理血水、内脏与集中食物气味；
4. 检查是否形成明显直线脚印、拖痕或反复路线；
5. 清理或重新安排暴露的伞布、竹槽、筏体和晾晒物；
6. 确认返洞路线没有持续形成一条直接指向住所的人类路径；
7. 在暮蜥鸣、潮水、巡逻艇与体力之间决定何时停止清理并撤离。

### 3.2 清理本身也会留下痕迹

游戏不能提供一个“清除全部证据”按钮。

- 用树枝把整片沙滩刷成规则平面，可能比自然脚印更反常；
- 把所有骨头堆进一个坑，会形成集中气味和翻土；
- 把血水全部冲向同一水沟，会建立食腐动物路线；
- 为掩盖一条路而大量折断植被，会形成另一种人类痕迹；
- 为等高潮冲掉脚印而停留过久，可能错过返洞时间或遭遇巡逻艇。

正确玩法不是“把世界抹干净”，而是让人类活动重新融入当时的潮、风、动物和地形，不形成持续、集中的异常。

### 3.3 清理存在机会成本

Trace Sweep 会消耗：

- 时间；
- 体力；
- 水；
- 绳与容器；
- 可用于维护火、水和住所的工作窗口。

玩家若捕鱼过多，清理、搬运和处理时间会显著增加。这使“只取够吃的数量”不仅是价值观，也是降低暴露与劳动成本的现实选择。

## 4. 食物尸体、骨头和内脏必须进入完整处理链

### 4.1 不存在凭空消失的鱼尸

每次捕获的动物都必须拆分为真实部分：

- 可食肉；
- 皮、鳞、壳；
- 头、骨、刺、爪和钳；
- 内脏与血水；
- 可制作工具的材料；
- 不可用或暂时不会用的遗留物。

`CarcassAndBoneLedger` 保存来源、重量、处理地点、处理方式、气味、污染和最终去向。

### 4.2 遗留物的多种用途

骨、壳和硬组织可以逐渐被学习为：

- 手工鱼钩、针、锥、刮具和尖头；
- 汤与有限食物利用；
- 火旁干燥后保存的材料；
- 日记中的标本和临摹对象；
- 无法利用时进入分散、掩埋、远离饮水和住所的处理流程。

但“全部利用”也不是瞬间完成。玩家早期不懂用途，会浪费；后来才知道自己第一周丢掉的骨头本来可以做什么。

### 4.3 不正确处理的后果

若长期把内脏、骨头和鱼头丢在洞口或同一沙滩：

- 猫、椰子蟹、虫、鸟和其他食腐动物形成稳定路线；
- 气味进入风场；
- 雨水和径流可能把污染带进集水系统；
- 苍蝇、腐败和伤口感染风险增加；
- 沙滩出现不自然的骨堆、鳞片和切割痕迹；
- 日军登陆后更容易推断附近有人长期生活；
- 动物可能把骨头拖向玩家本来想隐藏的路线。

猫在这里是生态中的一个行动者。它会偷、吃、拖走食物，但**不承担报警、侦察、预警或巡逻艇提示功能**。

## 5. 猫的角色永久修正

从 R9 起，任何“猫可能比玩家先发现巡逻艇”“猫异常缺席提示敌情”“猫作为夜间警报”的设计全部取消。

- 猫不是狗；
- 猫没有敌方识别职责；
- 猫不会成为可靠或半可靠警报器；
- 不允许通过猫的叫声、逃跑、凝视或缺席向玩家编码巡逻艇信息；
- 猫可能在发动机响时继续睡觉，也可能因为鼠、蟹、鸟、风或自己的路线离开；这些行为不得被系统设计成敌情提示；
- 猫的作用是偷鱼、吃鱼、陪伴、睡眠、独立狩猎、来去自由和改变食物/动物路线。

`CatCompanionState` 不提供 `alertEnemy`、`patrolSense`、`warningLevel` 或同类接口。

## 6. 日军不是靠魔法发现玩家，而是逐步建立“有人存在”的推断

### 6.1 巡逻艇观察与登陆搜索分开

海上的巡逻艇可以观察：

- 烟；
- 火光；
- 反光；
- 伞布、竹槽、筏体和晾晒物；
- 人体或划水轮廓；
- 沙滩上异常集中的鸟、猫、椰子蟹和食腐动物；
- 反复出现的岸边活动。

真正细读脚印、骨头、拖痕和路径，需要登陆人员进入沙滩或林缘。

### 6.2 `PatrolInferenceState`

敌方不会因为一枚脚印立刻知道洞穴位置，而是逐步积累：

1. `NO_HYPOTHESIS`：没有认为岛上有人；
2. `ANOMALY_NOTED`：看到烟、脚印、骨头或不自然路径中的单一异常；
3. `HUMAN_PRESENCE_POSSIBLE`：多个时间点出现相互支持的痕迹；
4. `SHORE_SEARCH`：开始在特定海滩登陆和搜索；
5. `ROUTE_HYPOTHESIS`：根据脚印、拖痕、砍折植被与动物路线推测进林方向；
6. `HABITAT_AREA_NARROWED`：逐步缩小水源、洞穴、高地和观察点范围；
7. `HIDEOUT_DISCOVERED`：洞穴、集雨设施、火种区或物资被发现；
8. `CAPTURE_OR_FORCED_RELOCATION`：玩家被击毙、俘获，或必须放弃已建立的生活系统。

怀疑不会因为一次清理自动归零。天气可以毁掉证据，玩家也可以改变路线和地点，但敌方已经学到的“这座岛可能有人”会持续一段时间。

### 6.3 追踪必须有可见因果

玩家几个月后被发现时，必须能回到旧证据：

- 日记中多次记录使用同一白沙滩；
- 同一位置反复出现脚印和拖痕；
- 某次丰收后留下未处理的骨堆；
- 猫或椰子蟹把遗留物拖向林缘；
- 反复搬运在植被中压出路线；
- 一场雨后，压实泥路比周边更明显；
- 巡逻艇从远海观察到同一海滩多次出现活动；
- 登陆搜索最终把零散痕迹连成一条人类生活链。

不得在没有世界证据时凭空触发“日军突然找到洞穴”。

## 7. 路线本身会成长、退化和暴露

`HumanRouteMemory` 保存每一条玩家常用路线：

- 通过次数；
- 脚步压力；
- 折断植被；
- 泥土压实；
- 雨后排水；
- 滑坡与崖边风险；
- 夜间触觉标记；
- 敌方可读性；
- 动物是否也开始使用。

反复走最短路线的好处是节省体力和时间，坏处是：

- 路越来越清楚；
- 雨后可能形成排水沟；
- 被猫、蟹和其他动物共同强化；
- 登陆搜索更容易沿路进入高地。

轮换路线可以降低单一路径暴露，但会增加迷路、耗能、暮蜥鸣后无法返洞和跌落风险。没有免费答案。

## 8. 沙滩清理、资源轮换与生活生产线互相影响

### 8.1 丰收日的代价

巨大鱼获会同时增加：

- 沙滩脚印和拖痕；
- 处理时间；
- 血水、鳞、骨和气味；
- 猫、椰子蟹和虫的聚集；
- 搬运路径压力；
- 火、盐、容器和保存需求；
- 暮蜥鸣前返洞失败的概率；
- 日军从海上或登陆后发现异常的概率。

因此玩家即使“运气很好”，也必须决定何时停止捕鱼。

### 8.2 处理地点轮换

玩家需要把捕鱼地点、处理地点、骨头处理地点和住所分开，并进行轮换：

- 同一处长期处理鱼会形成气味和动物路线；
- 离洞太远处理会增加返程和敌情风险；
- 离水源太近会污染雨水或淡水；
- 利用高潮线可减少部分表面痕迹，但潮汐不保证清除林缘路径和集中骨头；
- 分散处理可降低集中异常，却增加体力和工具搬运。

### 8.3 清理与火种冲突

玩家花太久清理沙滩，可能来不及补余烬；火弱后第二天无法处理水和食物。反过来，急着回洞护火，也可能把脚印、鱼骨和拖痕留给下一次登陆搜索。

这个冲突必须真实进入每日计划，而不是由一个统一“完成日常”按钮自动解决。

## 9. 相互因果示例

### 9.1 脚印—路线—敌方搜索链

同一海滩连续登陆
→ 湿沙留下重复脚印
→ 林缘出现固定进入点
→ 植被与泥地形成常用路线
→ 一次登陆搜索发现路线
→ 日军之后优先检查同一海滩
→ 数周后缩小洞穴所在山体范围。

### 9.2 丰收—骨头—猫—路径链

丰收后鱼太多
→ 洞口处理不完
→ 骨和内脏留在同一区域
→ 猫、椰子蟹和虫长期聚集
→ 猫拖骨进入林缘
→ 人和动物共同压出路线
→ 登陆人员发现鱼骨与路径组合
→ “偶然漂来一条死鱼”被提升为“附近有人长期生活”。

这条链中的猫没有报警能力，它只是按食物行动。

### 9.3 清理过度—异常表面链

玩家用树枝规则刷平整片沙滩
→ 自然波纹和动物脚印被整齐抹去
→ 留下一块过于均匀的人造表面
→ 巡逻者注意异常
→ 之后在高潮后再次检查同一区域。

### 9.4 伞布—雨水—反光—敌方链

为增加雨水量，把亮色伞布向洞口外展开
→ 水储备改善
→ 日照或月光产生反光
→ 巡逻艇从海面注意高处异常
→ 玩家被迫在收水效率和隐蔽之间重新设计集雨面。

### 9.5 路线轮换—体力—暮色链

为避免固定路径，玩家选择更隐蔽的绕行路线
→ 单一路径暴露下降
→ 行程增加、体力消耗提高
→ 捕鱼时间被压缩
→ 暮蜥鸣前返洞余量不足
→ 玩家必须减少鱼获或冒夜路死亡风险。

### 9.6 骨头再利用正向链

把部分鱼骨清洗、干燥并分类保存
→ 沙滩遗留减少
→ 后期获得鱼钩、针、锥和工具材料
→ 稀有金属压力下降
→ 多月后旧骨制工具帮助修理伞布、篮或伤口处理用品。

### 9.7 分散处理正向链

轮换鱼处理地点
→ 单一地点气味和食腐动物压力下降
→ 洞穴卫生改善
→ 猫仍会来，但不能沿一条固定骨头路线直达所有食物
→ 日军登陆时难以从一个集中遗留点重建完整生活路线。

## 10. 日记成为痕迹审计与因果证据

每晚纸面日记新增“今天留下了什么”这一层：

- 今天在哪个海滩上岸；
- 是否留下脚印、拖痕和鱼血；
- 哪些骨头被利用、保存、分散或未处理；
- 是否清理沙滩；
- 是否因清理耽误火、水、捕鱼或返洞；
- 猫有没有偷鱼或拖走骨头；
- 哪条路线开始变明显；
- 是否看见巡逻艇更靠近、停留更久或登陆；
- 哪些痕迹已被潮、雨和动物改变；
- 明天是否要更换登陆点、处理点或路线。

玩家后来理解新的因果，只能在旧页面旁边增加边注，不能改写当时的原始记录。

## 11. R9 验收门槛

### 沙滩与痕迹

- 脚印、拖痕、血水、鳞、骨、灰、纤维和植被扰动在世界中持续存在；
- 潮、雨、风和动物会改变痕迹，但不会按离开区域立即删除；
- 清理行为需要时间、体力和工具，且可能产生新的异常；
- 玩家可通过真实画面判断，而不是查看“痕迹值”。

### 食物遗留

- 一条鱼被完整拆分并记录各部分去向；
- 骨、壳和内脏不会凭空消失；
- 猫、椰子蟹、虫和鸟会根据气味与可达性接触遗留物；
- 遗留物可污染水、吸引动物、产生工具材料或成为敌方证据。

### 日军推断

- 海上观察与登陆搜索是两个不同阶段；
- 敌方怀疑由多个可追溯证据逐步积累；
- 没有证据时不得自动知道洞穴位置；
- 重复痕迹可以在数周或数月后改变巡逻频率、登陆点和搜索路线。

### 猫

- 猫没有报警、敌人侦测或预警接口；
- 猫的行为只能由食物、睡眠、狩猎、路线、天气和自身状态驱动；
- 不得通过猫异常行为向玩家编码巡逻艇信息。

### 长期因果

- 至少验证一个“重复脚印导致登陆搜索”的负向链；
- 至少验证一个“骨头再利用降低长期材料压力”的正向链；
- 至少验证一个“清理与护火/返洞冲突”的日常取舍；
- 所有延迟结果必须能从日记、物件或环境痕迹回溯。

## 12. R9 当前一句话版本
