## R5 已锁定的生存逻辑

- 主角在白沙滩醒来，短期失忆，先听见巡逻艇发动机并正确躲藏；随后逃入山林、昏迷，在 Power Tree 附近再次醒来。
- 他把单人橡皮艇搬进石钱洞，洞穴一端连森林，一端可以从高处观察海面与巡逻艇方向。
- 橡皮艇、降落伞伞布或塑料布、竹槽和容器共同组成雨水收集系统；椰壳和椰壳炭只处理已经收集的雨水，用来改善沉淀、异味和杂质，不承担海水淡化。
- 白天不能出现可从海面发现的火与烟；夜晚只能使用遮光、低烟的小火。
- **火种是持续维护系统**：玩家每天必须检查余烬、干燥引火物、防潮覆盖和燃料。若火完全熄灭，重新获得稳定火种将占用约一个完整白天，并造成饮水处理、烹饪、照明、驱虫、保温和食物保存连锁损失。
- 不以金属鱼钩作为前期平衡拐杖。帕劳热带海洋提供丰富的贝、蟹、林果和椰子蟹；最早的捕鱼能力是站在高处或礁石边，从上往下近距离插浅水鱼。
- 后续成长顺序是：浅水插鱼 → 做观察镜与短呼吸管 → 学会水面观察 → 用降落伞伞绳、植物纤维、木、骨、贝壳等制作线与鱼钩 → 手线捕鱼 → 再学习较深水域的近距离插鱼和自由潜。
- 信号弹退出常规资源与玩法，不作为长期生存依赖。
- 玩家每天清晨醒来观察、取水、检查火种、计划工作、获取够吃的食物、躲巡逻艇，并在蜥蜴暮鸣后立即返洞；岛上入夜极快，错过返回窗口可能迷路、坠崖或死亡。
- 夜晚海洋仍然活跃：果蝠出洞、海面有荧光藻、鲸、manta、翼鼓瑞鱼和海龟经过。玩家在安全照明下把当天真实行为写成一篇纸质日记。
- Pacific 女神只在台风、风暴、睡梦、昏迷、中毒、高烧或其他边界状态出现，以原创、预言式、太平洋岛屿感的语言提示关系与征兆，不替玩家完成行动。
- 第一集只讲“活下来—学会和自然相处—逐渐喜欢上海洋”。战后成为科学家、飞行救援者、海洋守护者和后续爱情，都属于未来故事，不在当前生存阶段提前完成。

## 每日核心循环

**微亮醒来 → 看鸟潮与天气 → 检查水和火 → 安排体力与任务 → 取水/修补/觅食/插鱼 → 观察巡逻艇与生态变化 → 蜥蜴暮鸣后立即返洞 → 黄昏鸟潮归岛 → 夜间小火与食物处理 → 果蝠出洞、观星与看海 → 写下当天纸面日记 → 睡眠、风暴、病痛或特殊梦境 → 次日继承全部后果。**
