# R5 当前实现状态｜2026-09-22

## 一、已经完成并可作为权威输入的内容

- 游戏可玩世界统一起点已经锁定为 `1944-12-31T05:00:00+09:00`。
- 历史事件 1944-11-21 与游戏起点的差异已经明确标为游戏改编。
- 所有系统共享同一 `worldTime`、同一环境物理和同一事件总线的合同已经冻结。
- 靠谱体系不以移动端为理由删除巨大生态量；远中近不同表达必须属于同一逻辑群体。
- 清晨海鸟出海潮、黄昏归岛潮、天堂鸟、数万果蝠、暮蜥鸣、活夜海、荧光藻和大型海洋生命已经锁定为 Stone Money Island 世界事实。
- 石钱洞、橡皮艇、伞布/塑料布、竹槽、容器和椰壳过滤构成雨水生活系统。
- 椰壳过滤只处理已收集雨水，不处理海水淡化。
- 火被锁定为持续余烬系统；完全熄灭后通常需要约一整日复燃，并影响全部生产线。
- 早期食物与捕鱼顺序已经纠正：贝/蟹/林果/椰子蟹 → 高处向浅水插鱼 → 观察镜与短呼吸管 → 手工线钩 → 水面手线 → 深水近刺与自由潜。
- 开局不依赖金属鱼钩；信号弹退出常规玩法。
- 每日纸面日记、Pacific 女神特殊触发和第一集人物范围已经锁定。

## 四、靠谱体系的正确性能合同

R5 不接受“信息量太大所以删内容”的方案。正确实现是：

- 一个逻辑世界；
- 一个统一时间；
- 一个逻辑种群状态；
- 远处群体场和实例；
- 中景波次、路线和物种层；
- 近景个体细化与交互；
- 按距离和重要性调整更新频率；
- 缓存、实例化、空间格和 GPU 批处理；
- 状态连续，不因 LOD/细化切换而更换群体；
- 性能优化只改变表达成本，不改变生态总量和世界逻辑。

## 五、当前最危险的错误完成方式

- 每个模块各用一套时间，导致鸟、火、天气和日记不同步。
- 用静态鸟贴图或随机粒子冒充成千上万只真实群体。
- 移动端直接删除果蝠、鲸、夜海或植物。
- 把橡皮艇只留在海边，不进入洞穴生活系统。
- 把椰壳过滤写成海水淡化。
- 火熄后点击按钮立即恢复，取消整日代价。
- 开局直接给稳定金属鱼钩和成熟手线，绕过高处插鱼与手工生产。
- 蜥蜴叫后仍能开导航箭头无风险返洞。
- 每晚输出与实际行为无关的模板日记。
- Pacific 女神每日出现并告诉正确答案。
- 只写状态 JSON，没有浏览器中的可见、连续、可操作证据。

R5 已经完成的是**统一世界与每日循环的方向、逻辑、边界和运行时合同冻结**；尚未完成的是**三维可玩实现、生态群体资产、三日连续运行和真实设备验收**。任何只有一段旁白、一个 UI 或一张静态生态图的版本，都不能称为 R5 完成。
