# 游戏执行简报｜R3

## 0. 当前执行状态

- 今天早上的 R3 故事与规则已经锁定。
- 现有水面观察、手线和鱼群原型可以作为基础，但**不包含完整巡逻艇威胁闭环**。
- 当前仍缺：巡逻艇运行状态机、全局生态撤离事件、玩家掩体/暴露判定、被发现后的致命水花链、巡逻艇通过后的动物渐进回归。
- 在浏览器中完成并形成截图、控制台 0 错误和移动端证据之前，`visualAcceptance` 与 `productionReady` 必须保持 `false`。

## 1. 第一阶段：迫降

目标：让玩家保住最核心装备，而不是立即进入捕鱼。

关键交互：

- 发出遇险呼叫
- 锁开座舱盖
- 受控迫降
- 离开飞机
- 充气救生衣
- 展开单人筏
- 判断浅礁、浪和岸线

失败风险：

- 飞机下沉
- 被浪卷回机体
- 装备丢失
- 救生筏损伤
- 伤口和疲劳

## 2. 第二阶段：手线钓鱼

资产：

- 少量鱼线
- 少量鱼钩
- 简单坠子
- 小刀
- 饵料

交互：

- 放线
- 调整深度
- 观察浮动或拉力
- 收线
- 挂礁
- 鱼线断裂

## 3. 第三阶段：水面观察钓鱼

必须实现的姿态：

- 腹部朝下漂浮
- 双腿轻微平衡
- 脸在水下
- 呼吸管顶部在水面上
- 一手控线
- 一手划水或扶礁

摄像机：

- 主视角在水下
- 能看见水面波纹和呼吸管
- 能看见鱼饵、鱼钩和鱼线
- 能看见鱼群靠近、试探和吞钩
- 不应频繁强制抬头

关键反馈：

- 呼吸正常
- 管口被浪淹没时短暂呛水
- 镜片轻微起雾或渗水
- 鱼对手部和身体动作产生反应
- 不用进度条代替鱼的真实动作

## 4. 第四阶段：木鱼叉

制作：

- 选择直木棍
- 削尖
- 可选绑扎小金属尖
- 检查是否开裂

动作：

- 岸上短投
- 浅水下刺
- 向前近刺
- 收回
- 卡在珊瑚
- 鱼挣脱

不得实现：

- 弹力
- 扳机
- 滑轨
- 水下远距离高速发射

## 5. 第五阶段：自由潜

成长参数只存在于后台，不直接显示数值：

- 放松程度
- 屏气时间
- 耳压平衡
- 下潜姿态
- 上浮判断
- 潮流理解
- 接近鱼的能力

风险：

- 耗氧
- 迷失方向
- 潮流
- 珊瑚割伤
- 独潜失去意识
- 疲劳、饥饿和脱水

## 6. 第六阶段：Silent-First 巡逻艇威胁系统

### 6.1 目标

巡逻艇不是战斗关卡，而是检验玩家是否真正学会观察海洋、控制暴露和提前隐藏。核心学习发生在第一发子弹之前。

### 6.2 权威状态机

#### S0｜平静海域

- 鱼群、苏眉、海龟、鸟类按各自正常行为活动。
- 玩家可以捕鱼、观察或移动。
- 前台没有敌人雷达、发现值或巡逻艇图标。

#### S1｜远端接近

- 巡逻艇尚未明确发现玩家。
- 可出现船影、水面移动遮挡、异常尾迹、远处发动机低频或鸟群变化。
- 这些信号必须在静音画面中仍有至少一条可见线索。

#### S2｜生态撤离

- 小鱼快速钻入珊瑚、礁缝、洞穴或贴底。
- 苏眉等大型礁鱼退出开阔区域。
- 海龟改变路线并下潜或远离。
- 其他可见动物停止悠闲行为并退出玩家附近。
- 珊瑚仍在，形成明显“空海”。
- 不允许留下几条完全无反应的鱼在玩家面前游荡，破坏危险语言。

#### S3｜玩家隐藏窗口

- 玩家停止捕鱼并收拢或放弃暴露装备。
- 可降低身体轮廓、贴礁、进入阴影、靠近红树林水线，或进行有限时间屏气下潜。
- 掩体必须由世界空间关系判断，不能只按一个“隐藏”按钮。
- 初期屏气不能成为无限安全区。

#### S4A｜隐藏成功

- 巡逻艇没有建立稳定目视或射击解算，继续通过或偏离。
- 玩家继续保持安静，不能马上大幅划水或露头。
- 巡逻艇远离后，动物按照距离、胆量和遮蔽条件逐步返回：胆大的小鱼先出现，其余鱼群、苏眉和海龟更晚恢复。
- 不得一帧全部重生。

#### S4B｜玩家被发现

- 巡逻艇明确转向玩家位置。
- 发动机转速和尾迹增强，船体加速逼近。
- 这是最后的因果确认阶段，但不是枪战或躲弹小游戏。

#### S5｜致命射击

- 一旦玩家周围出现第一批日军子弹入水水花，即判定已经被发现并遭到有效射击。
- 立即 Game Over。
- 不扣血，不进入受伤状态，不提供子弹出现后的逃生宽限期，不允许反击。
- Game Over 回顾可以提示玩家回想先前漏掉的生态、船影、尾迹或暴露行为，但不得用数值评分替代复盘。

### 6.3 前台表达合同

必须依靠：

- 鱼、苏眉、海龟和鸟的行为变化
- 珊瑚仍在但动物消失的空海画面
- 船影、尾迹、发动机与船体逼近
- 玩家身体、呼吸管、鱼线和水面轮廓是否暴露
- 可选声音与原生 iPhone 触觉增强

禁止使用：

- 危险进度条
- 发现百分比
- 敌人视野扇形
- 红色警报箭头
- 敌人头顶图标
- 生命值和伤害数字
- 自动弹出“快躲起来”的文字指令作为主要预警

### 6.4 跨生产线依赖

- Patrol Boat：真实船体尺寸、航速、转向、尾迹、发动机和射击因果。
- Fish：统一威胁事件接口，以及按物种、个体、距离和遮蔽产生不同撤离动作。
- Turtle / Bird：接收相同威胁事件，但保留各自动作差异。
- Coral / Reef：提供可读遮蔽、礁缝、洞穴和贴底空间；珊瑚自身不“消失”。
- Ocean：提供尾迹、浪、声音传播、子弹入水和水面可见性。
- Player：提供身体轮廓、呼吸管、鱼线、划水、露头、屏气和掩体判定。
- Runtime：统一 worldTime 和威胁状态，不允许每个模块各自生成一套巡逻艇时间。

## 7. 验收门槛

### 7.1 水面观察与捕鱼

- 浏览器中可直接看到完整水面观察流程
- 控制台 0 错误
- 鱼饵、鱼钩、鱼线与鱼群真实可见
- 呼吸管口与水面的关系正确
- 不抬头也能持续观察
- 鱼对玩家行为有反应
- 木鱼叉遵守近距离和水阻限制
- 没有任何弹力或机械鱼枪内容

### 7.2 巡逻艇威胁闭环

必须提供至少以下连续证据：

1. 正常生态画面。
2. 巡逻艇仍在远端，但环境已出现可见征兆。
3. 鱼、苏眉、海龟等撤离，珊瑚仍在。
4. 玩家及时隐藏，巡逻艇经过且未开火。
5. 巡逻艇远离后动物分阶段返回。
6. 另一轮中玩家保持暴露，巡逻艇转向并加速。
7. 第一批近身子弹水花出现的同一状态立即进入 Game Over。
8. 子弹出现后不得继续游泳、逃跑、扣血或进行反击。

### 7.3 设备与性能

- 桌面浏览器真实渲染截图，控制台 0 错误。
- 390×844 移动视口截图；危险信息在静音、无震动条件下仍清楚。
- 实体 iPhone/Safari 测试触控、发热和帧稳定性；自动化软件渲染数据不能冒充实体手机通过。
- 状态切换不允许让全部 Fish/Turtle/Bird 逐帧重建导致明显卡顿。

## 8. 当前最直接的生产顺序

1. 先接入一艘可运行巡逻艇，不扩展船队。
2. 建立唯一 ThreatState 与玩家暴露/掩体判定。
3. 让 Fish、苏眉、海龟先完成生态撤离和渐进回归。
4. 接入船影、尾迹和发动机增强提示。
5. 接入被发现后的转向、加速与第一批子弹水花。
6. 锁定水花出现即 Game Over，不制作枪战或伤害系统。
7. 完成桌面与 390×844 浏览器证据，再进入实体 iPhone 测试。
