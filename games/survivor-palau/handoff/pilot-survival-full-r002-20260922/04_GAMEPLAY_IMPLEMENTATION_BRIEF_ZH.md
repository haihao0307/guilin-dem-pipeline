# 游戏执行简报｜R4

## 0. 当前执行状态

- R4“资源核算—海洋识读—有限获取—守护者成长”规则已经锁定。
- 现有水面观察、手线和鱼群原型可以作为基础，但**不包含完整资源学习循环，也不包含完整巡逻艇威胁闭环**。
- 当前仍缺：精确资源账本、环境征兆记录与交叉判断、计划/实际消耗差异、Pacific 女神边界式提示、白沙滩三股浓烟事件、守护行为反馈、巡逻艇状态机、生态撤离、玩家掩体/暴露、致命水花链和动物渐进回归。
- 在浏览器中形成连续可玩证据、控制台 0 错误、390×844 移动证据和实体 iPhone 测试之前，`visualAcceptance` 与 `productionReady` 必须保持 `false`。

## 1. 第一阶段：迫降

目标：让玩家保住最核心装备，而不是立即进入捕鱼。

关键交互：

- 发出遇险呼叫
- 锁开座舱盖
- 受控迫降
- 离开飞机
- 充气救生衣
- 展开单人筏
- 判断浅礁、浪和岸线

失败风险：

- 飞机下沉
- 被浪卷回机体
- 装备丢失
- 救生筏损伤
- 伤口和疲劳

## 2. 第二阶段：手线钓鱼

资产：

- 少量鱼线
- 少量鱼钩
- 简单坠子
- 小刀
- 饵料

交互：

- 放线
- 调整深度
- 观察浮动或拉力
- 收线
- 挂礁
- 鱼线断裂

## 3. 第三阶段：水面观察钓鱼

必须实现的姿态：

- 腹部朝下漂浮
- 双腿轻微平衡
- 脸在水下
- 呼吸管顶部在水面上
- 一手控线
- 一手划水或扶礁

摄像机：

- 主视角在水下
- 能看见水面波纹和呼吸管
- 能看见鱼饵、鱼钩和鱼线
- 能看见鱼群靠近、试探和吞钩
- 不应频繁强制抬头

关键反馈：

- 呼吸正常
- 管口被浪淹没时短暂呛水
- 镜片轻微起雾或渗水
- 鱼对手部和身体动作产生反应
- 不用进度条代替鱼的真实动作

## 4. 第四阶段：木鱼叉

制作：

- 选择直木棍
- 削尖
- 可选绑扎小金属尖
- 检查是否开裂

动作：

- 岸上短投
- 浅水下刺
- 向前近刺
- 收回
- 卡在珊瑚
- 鱼挣脱

不得实现：

- 弹力
- 扳机
- 滑轨
- 水下远距离高速发射

## 5. 第五阶段：自由潜

成长参数只存在于后台，不直接显示数值：

- 放松程度
- 屏气时间
- 耳压平衡
- 下潜姿态
- 上浮判断
- 潮流理解
- 接近鱼的能力

风险：

- 耗氧
- 迷失方向
- 潮流
- 珊瑚割伤
- 独潜失去意识
- 疲劳、饥饿和脱水

## 6. Silent-First 巡逻艇威胁系统

### 6.1 目标

巡逻艇不是战斗关卡，而是检验玩家是否真正学会观察海洋、控制暴露和提前隐藏。核心学习发生在第一发子弹之前。

### 6.2 权威状态机

#### S0｜平静海域

- 鱼群、苏眉、海龟、鸟类按各自正常行为活动。
- 玩家可以捕鱼、观察或移动。
- 前台没有敌人雷达、发现值或巡逻艇图标。

#### S1｜远端接近

- 巡逻艇尚未明确发现玩家。
- 可出现船影、水面移动遮挡、异常尾迹、远处发动机低频或鸟群变化。
- 这些信号必须在静音画面中仍有至少一条可见线索。

#### S2｜生态撤离

- 小鱼快速钻入珊瑚、礁缝、洞穴或贴底。
- 苏眉等大型礁鱼退出开阔区域。
- 海龟改变路线并下潜或远离。
- 其他可见动物停止悠闲行为并退出玩家附近。
- 珊瑚仍在，形成明显“空海”。
- 不允许留下几条完全无反应的鱼在玩家面前游荡，破坏危险语言。

#### S3｜玩家隐藏窗口

- 玩家停止捕鱼并收拢或放弃暴露装备。
- 可降低身体轮廓、贴礁、进入阴影、靠近红树林水线，或进行有限时间屏气下潜。
- 掩体必须由世界空间关系判断，不能只按一个“隐藏”按钮。
- 初期屏气不能成为无限安全区。

#### S4A｜隐藏成功

- 巡逻艇没有建立稳定目视或射击解算，继续通过或偏离。
- 玩家继续保持安静，不能马上大幅划水或露头。
- 巡逻艇远离后，动物按照距离、胆量和遮蔽条件逐步返回：胆大的小鱼先出现，其余鱼群、苏眉和海龟更晚恢复。
- 不得一帧全部重生。

#### S4B｜玩家被发现

- 巡逻艇明确转向玩家位置。
- 发动机转速和尾迹增强，船体加速逼近。
- 这是最后的因果确认阶段，但不是枪战或躲弹小游戏。

#### S5｜致命射击

- 一旦玩家周围出现第一批日军子弹入水水花，即判定已经被发现并遭到有效射击。
- 立即 Game Over。
- 不扣血，不进入受伤状态，不提供子弹出现后的逃生宽限期，不允许反击。
- Game Over 回顾可以提示玩家回想先前漏掉的生态、船影、尾迹或暴露行为，但不得用数值评分替代复盘。

### 6.3 前台表达合同

必须依靠：

- 鱼、苏眉、海龟和鸟的行为变化
- 珊瑚仍在但动物消失的空海画面
- 船影、尾迹、发动机与船体逼近
- 玩家身体、呼吸管、鱼线和水面轮廓是否暴露
- 可选声音与原生 iPhone 触觉增强

禁止使用：

- 危险进度条
- 发现百分比
- 敌人视野扇形
- 红色警报箭头
- 敌人头顶图标
- 生命值和伤害数字
- 自动弹出“快躲起来”的文字指令作为主要预警

## 7. Resource Ledger｜精确资源账本

### 7.1 数据合同

每种资源必须独立记录，不允许压成通用“生存点”：

- `waterContainers[]`：容器容量、当前水量、盐/污染、泄漏、来源、可饮用状态；
- `foodLots[]`：种类、可食重量、处理损耗、捕获时间、保存方式、腐败剩余时间、风险；
- `hooks[]`：尺寸、状态、是否挂礁、是否变形；
- `lineSegments[]`：长度、磨损、结点、承重、是否可修复；
- `ignition[]`：火柴、火种、干燥引火物和防水状态；
- `medical[]`：逐件物品、用途、剩余量与污染；
- `repair[]`：补片、绳、布、金属片、可拆材料与原设备完整性；
- `signal[]`：信号镜、烟火、灯具、燃料和可见条件；
- `bodyState`：脱水、能量、盐分、睡眠债、伤口、感染、体温与疲劳；
- `commitments[]`：已经为明日饮水、返航、紧急信号或修理预留的资源。

### 7.2 每日计划

玩家每天至少完成一次：

1. 清点当前库存；
2. 估算到下一次可靠补给前的天数；
3. 设定最低应急储备；
4. 为捕鱼、取水、修理、信号、休息和移动分配时间与物资；
5. 执行后记录实际损耗、浪费和意外事件；
6. 重新计算下一轮，而不是沿用昨天的计划。

### 7.3 前台表现

- 已知离散物品显示真实数量；
- 已知容器可显示刻度、半满、四分之一等物理信息；
- 未测量的体力、天气和风险用动作、症状、环境与区间表达；
- 不出现自动最优配给按钮；
- 可以提供纸面/布面/木片式简易账本，但玩家仍需选择。

## 8. Ocean Literacy｜海洋识读运行时

### 8.1 Observation 数据

每条观察记录至少包含：

- `cueType`：star/sun/moon/swell/wind/cloud/bird/tide/debris/waterColor/animal/patrol；
- 世界时间和地点；
- 玩家视角与能见度；
- 原始观察，不提前写入正确答案；
- 玩家解释；
- 置信度；
- 与其他线索的一致或冲突关系；
- 后续验证结果。

### 8.2 星辰与日月

- 运行时使用实际日期、纬度、时间与云量生成天空；
- 教玩家读取升落方位和星序，不提供永久罗盘箭头；
- 云遮后必须转用涌浪、风、时间记忆等替代线索；
- 具体星名和 1944-11-21 帕劳天空需经天文核验。

### 8.3 涌浪与风

- 同时存在主涌浪、次涌浪和局地风浪；
- 岛礁、水道和浅滩可以折射、反射和破碎涌浪；
- 玩家通过筏体摆动、身体压力、浪峰方向和岸礁破浪学习；
- 风通过烟、火、树叶、海面细纹、云移动和体感进入判断；
- 不得直接把世界向量画成 UI 箭头作为主要玩法。

### 8.4 鸟与云

- 鸟类线索必须由物种、日时、巢地、觅食、天气和繁殖状态驱动；
- 清晨出海与傍晚归巢只是候选规律，不是所有鸟的固定脚本；
- 远处云可受高岛地形、浅水反光、湿度和天气影响；
- 云与鸟都必须存在误判案例；
- 玩家只有在多线索一致时才获得较高可信判断。

### 8.5 Knowledge 状态

知识不是技能点，而是可复用的关系：

- 玩家曾观察过什么；
- 是否验证过；
- 在什么条件下成立；
- 哪些例外曾导致失败；
- 玩家是否能把关系教给其他角色。

## 9. Pacific 女神照应系统

### 9.1 触发条件

- 高烧、昏迷、严重脱水或食物中毒；
- 风暴前夜；
- Power Tree 下休息；
- 重大资源或生命选择后；
- 多次忽略同一自然征兆但仍有学习机会时。

### 9.2 允许的作用

- 重放白天被忽略的鸟、浪、云、星或动物画面；
- 用象征场景改变玩家注意方向；
- 提出问题或关系，不给唯一答案；
- 在绝望时保存行动意愿；
- 把“活下来”逐步连接到“保护其他生命”。

### 9.3 禁止的作用

- GPS 路线、精确坐标和敌人透视；
- 自动算出最优资源计划；
- 挡子弹、让巡逻艇失明或取消 Game Over；
- 瞬间补满水、食物、体力或伤口；
- 一次梦境直接学会完整传统航海；
- 以神谕替代当地人物、科学证据或玩家观察。

## 10. 白沙滩三股浓烟事件

### 10.1 状态链

1. `dreamBoundary`：主角在 Pacific 女神梦境或极度虚弱状态中获得“先看关系”的提示；
2. `wakeWhiteBeach`：主角在白沙滩醒来；
3. `smokeRead`：看到三股烟，先读取风向、距离、火势与人类活动；
4. `stealthObserve`：从遮蔽处发现巡逻艇人员杀死鲸鲨和海龟并烧烤；
5. `cannotIntervene`：当前力量差距使正面阻止等同于死亡，玩家必须隐藏并观察；
6. `departureTrace`：记录船的航向、尾迹、人数、离开时间与烟变化；
7. `aftermath`：巡逻艇离开后查看弃置残骸、油污、血迹、烧灼、动物消失和食物浪费；
8. `meaning`：不弹出环保分，而由主角对自己捕鱼行为、保存能力和真正需求的重新计算形成转变。

### 10.2 表现边界

- 这是游戏改编，不写成已证实历史事件；
- 残酷必须清楚，但不反复进行猎奇特写；
- 鲸鲨和海龟不成为可收集高级肉；
- 三股烟同时承担叙事、风向、敌情与资源浪费信息；
- 场景针对具体行为，不把所有日本人、所有军人或所有岛民写成同一种人。

## 11. Limited Taking｜有限获取决策

每次获取前，运行时至少检查：

- 当前真实需求；
- 可保存和可烹饪能力；
- 物种与个体风险；
- 是否存在更小、更安全或已经死亡的替代来源；
- 捕获对熟悉个体、繁殖点、清洁站和局部鱼群的影响；
- 获取行为是否增加巡逻艇暴露或天气风险；
- 捕获后无法处理的部分是否会腐败和浪费。

玩家可以捕鱼、取木、取水和用火。系统不奖励“不做任何事”，而是奖励准确判断与减少浪费的实际结果；前台不显示道德分。

## 12. Guardian Arc｜守护者成长

### 12.1 第一集终点

- 能维持资源账本；
- 能交叉读取多类自然征兆；
- 能为生存进行有限获取；
- 能识别过度杀戮与浪费；
- 能用所学保护自己、熟悉动物或另一名岛民；
- 愿意承担离开帕劳后的长期责任。

### 12.2 后续职业候选

- 野外科学家、自然史记录者或摄影调查者；
- 珊瑚、鲨鱼、鲸鲨和海龟保护工作；
- 飞机或水上飞机搜救、送药和灾后援助；
- 与岛民共同调查和保护，而不是外来英雄取代当地人；
- 平等、成年人之间的爱情线，可来自长期合作和共同生活，不作为任务奖励。

真实机构名称、标志和正式雇佣关系另行做年代与授权核查。

## 13. 跨生产线依赖

- Runtime：唯一 worldTime、ResourceLedger、ObservationLedger、KnowledgeGraph、ThreatState 和 consequence pipeline。
- Weather：真实云、风、雨、日照、能见度与天气演化。
- Ocean：主/次涌浪、局地风浪、潮汐、流、浅滩、反射和水色。
- Sky：1944 日期、帕劳纬度、星辰与日月运行。
- Bird：物种化的出海、归巢、觅食、盘旋和天气反应。
- Fish / Turtle：捕食、熟悉、撤离、返回与有限获取后果。
- Coral / Reef：栖息、清洁站、遮蔽、礁缝、潮池与破浪关系。
- Patrol Boat：真实船体、航速、尾迹、发动机、观察和射击因果。
- Player：账本、身体状态、观察、暴露、掩体、动作和记忆。
- Narrative：Pacific 梦境、白沙滩事件、人物弧线和长期职业候选。
- UI：只呈现玩家实际可知的信息，不泄漏后台真值。

## 14. 验收门槛

### 14.1 水面观察与捕鱼

- 浏览器中可直接看到完整水面观察流程；
- 控制台 0 错误；
- 鱼饵、鱼钩、鱼线与鱼群真实可见；
- 呼吸管口与水面的关系正确；
- 鱼对玩家行为有反应；
- 木鱼叉遵守近距离和水阻限制；
- 没有任何弹力或机械鱼枪内容。

### 14.2 巡逻艇威胁闭环

必须提供正常生态、远端征兆、生态撤离、隐藏成功、动物分阶段返回、暴露失败、巡逻艇转向加速和第一批近身子弹水花同状态即时 Game Over 的连续证据。

### 14.3 R4 最小完整循环

必须提供一段连续玩法证据，其中玩家：

1. 读取至少三类环境征兆；
2. 在记录中保留不确定性；
3. 清点水、食物、时间、体力和应急储备；
4. 制定计划并实际执行；
5. 发生至少一个意外损耗或误判；
6. 选择获取、等待、返航、隐藏或放弃；
7. 世界产生物理与生态后果；
8. 结果改变下一轮资源账与知识；
9. Pacific 女神只帮助重新理解，不替玩家完成；
10. 玩家最终用新知识保护自己、动物或其他人。

### 14.4 设备与性能

- 桌面浏览器真实渲染截图，控制台 0 错误；
- 390×844 移动视口，静音、无震动仍可读取关键自然信号；
- 实体 iPhone/Safari 测试触控、发热和帧稳定性；
- 环境状态、动物群和账本更新不能造成明显整帧重建卡顿；
- 自动化软件渲染数据不能冒充实体手机通过。

## 15. 当前生产顺序

1. 建立 `ResourceLedger`、`ObservationLedger`、`KnowledgeGraph` 与唯一 `worldTime`。
2. 先做一个可玩的“看三类征兆—算一天资源—做一次选择—产生后果”竖切片。
3. 接入真实天空、涌浪、风、鸟和云，不做自动箭头。
4. 接入 Pacific 女神的边界式复盘梦境。
5. 制作白沙滩三股浓烟事件及其前后生态后果。
6. 把有限获取接入捕鱼、保存、腐败与资源账本。
7. 完成巡逻艇 ThreatState、生态撤离、隐藏和即时 Game Over。
8. 形成第一集守护者转变的结尾，不提前完成全部后续职业。
9. 完成桌面、390×844 与实体 iPhone 验收。
