# Stone Money Island / Airai R12 接手审计

日期：2026-09-21  
状态：执行中；`visualAcceptance=false`；`productionReady=false`

## 1. 直接结论

R11 交接包可以继续工作，但它不是可从 Git 分支独立复现的“完整生产基线”。问题不在于原始 TIFF 必须被复制进仓库——现有章程明确允许原始 TIFF 由用户外部保管——而在于：交接文档、回执与实际文件之间存在关键断层。

1. R10 Git 分支只提交了进度回执，没有提交回执所描述的单文件运行时源码。
2. R11 包没有历史候选水深、误差、语义和 DEPARE GeoTIFF；JSON 仍引用这些栅格。
3. 使用包内现存且哈希可核对的矢量与脚本重新计算，可以复现网格形状、有效格数量和 DEPARE 覆盖数量，但不能复现历史 R11 的水深分布。
4. 因而继续把 R11 回执当作数值真值会产生错误谱系；R12 必须作为“由现存证据重新生成”的新候选基线，而不是冒充历史 R11 字节复原。

## 2. 已完成的 R12 增量

- 新建可重复构建器 `build_runtime_evidence_r12.py`。
- 使用 392 个核心 SOUNDG 测深点与 663 个 DEPCNT 约束点重建 25 m 候选场。
- 生成 56,874 个有效格，39,226 个 NoData 格。
- 生成 50,334 个 DEPARE 覆盖格；深度不被 DEPARE 或语义改写。
- 生成水深、不确定度、最近证据距离、相对证据质量、Allen 语义、DEPARE 支持、LNDARE 陆岸掩膜及残差字段。
- 新建浏览器运行时 `PalauWorld.sample(lon,lat,t)`，保持 `traditionalLOD=false`。
- 新建真实 WebGL2 三维诊断台；支持轨道相机、缩放、字段切换、证据叠加和坐标采样。
- 新建确定性复算与浏览器验收脚本。

## 4. 当前浏览器验收

- 桌面 1440 × 900：真实 WebGL2；控制台 0 错误；页面错误 0；`glError=0`；软件渲染约 7 FPS。
- 手机 390 × 844：真实 WebGL2；控制台 0 错误；页面错误 0；`glError=0`；软件渲染约 11 FPS。
- 轨道拖动、滚轮缩放、模式切换与 `PalauWorld.sample()` 均已实际操作。
- 页面横纵溢出均为 0。

这些性能数据来自 Xvfb + SwiftShader，只能证明最低限度可运行，不能替代真实桌面 GPU、手机 GPU 或最终世界场景的性能验收。

## 5. 仍然阻断成品的条件

1. **完整帕劳第一视图权威图及其可追溯源码未恢复到 Git 基线。** 当前 R12 仅覆盖 Airai 核心证据区，不能替代完整帕劳首屏。
2. **接受的 Palau 陆地 DEM 数值体未进入可复现运行时。** LNDARE 只能提供水平陆岸掩膜，不能提供岛屿高程。
3. **局部图表基准到 MSL 的转换模型不存在。** 不能把当前正向向下水深直接宣称为 MSL 高程。
4. **R10 实际工作台源码缺失。** 文件库中的页面存在性不能替代 Git 中的可审计源码与提交。
5. **NOAA 证据质量混合。** 核心 392 个测深点包含 274 个 CATZOC B、118 个 CATZOC D；相对权重不是 IHO 精度换算。
6. **公共发布未执行。** 没有经过 HTTPS、浏览器和 `PUBLICATION_PROOF.json` 的发布证据，因此禁止对外提供“可验收成品链接”。

## 6. 下一条生产路径

在不伪造数据的前提下，后续顺序固定为：恢复完整帕劳权威首屏资产与 R10 源码 → 接入接受的陆地 DEM 数值存储 → 建立明确垂直基准关系 → 将 Ocean Mother 海面与 R12 `PalauWorld.sample()` 同一运行时耦合 → 完整帕劳/故事区域/Airai 三层连续视觉验收 → 再发布公共 HTTPS 页面。
