# V0.2.0 审查补记

以 releases/v0.2.0/BUILD_RECEIPT.json 的运行文件身份及最终 PUBLICATION_PROOF.json 为准；工作流绿色本身不代表通过。旧 V0.1.6.0 与 Mother 原件不覆盖。

## 已实际发现与修正

第一轮真实浏览器截图显示水面穿入新岩棚和岸边。检查发现第一人称投影 near=.08，与冻结海面 near=.15 不同。已统一游戏投影到 .15；没有修改冻结海面/云着色器。新石钱与落叶的位置也从岩壁/坡边调整到可接近的位置。岩棚的新形体由刚性方盒调整为有圆钝起伏的参数曲面；当前接触和遮挡仍使用保守包围体，不得将其声称为完全精确的曲面碰撞。

旧 ?qa 会降低测试场景的地面和岩体表示。本轮已固定 QA_MODE=false，让测试和普通入口使用同一生产表示；?qa 只提供受控检查入口及保留绘制缓冲。最终公网另使用不带 ?qa 的普通地址测试移动、蹲下和日记。

一次鱼叉回归失败发生在拾取后的动作冷却尚未结束时，测试连续点击过快。测试补充了明确的受控时间推进，没有改成任意点击即可捕获，也没有扩大命中范围来掩盖失败。

## 已有测试与边界

第一章事务检查涵盖：步行输入、木枝/石块拾取、制作鱼叉与重复结算保护、椰子一次性消耗、实际瞄准命中、同一条鱼移入库存、损坏电台状态、岩棚床铺、Day 2、日记、刷新恢复存档、遮挡保护与暴露失败。任务点之间使用受控定位，巡逻使用受控时间；这不等于真人连续走完整张地图的体验验收。

截图来自实时三维浏览器，无生成图替代。第一人称脚下高度读取实际显示地面的三角面插值。自然岩体仍继承高度场式查询，岩棚仍是保守边界；悬挑/洞穴附近完整接触问题未宣称解决。

## 仍然明显的不足

近岸破浪仍有台阶/浪墙感，浅水接触处仍需继续核对。洞穴岩体、树冠、鱼鸟外形的自然程度和整体美术水准不足，均不做 3A 通过声明。鱼鸟为程序形态候选，暂不标注已核验的真实物种。鸟目前主要是滑翔表达，并非完整鸟类动作系统。

巡逻节奏是首章的确定性测试安排，不是已完成的长期非定时航线系统。当前关闭未接入生存关系的原演示篝火/烟雾，没有实现烹饪或火烟暴露。空椰壳不是无限淡水源。捕获的鱼仍未烹饪。求生装置只能保存，修复、发报、PBY 接应与半年的完整进程都尚未制作。

主标题入场与简单原创程序音乐已经接入；不是完整配乐或战斗机飞行序章。音乐需用户点击开启，浏览器验证只证明音频上下文状态，不代表音乐审美或扬声器实听已经验收。

没有引入 LOD/外部网格/贴图素材/外部 CDN。对象定义、身份、状态及事件留在可编辑源文件里；临时显示缓冲不是新的母体真值。本轮也不等于完整靠谱世界内核已验证。
