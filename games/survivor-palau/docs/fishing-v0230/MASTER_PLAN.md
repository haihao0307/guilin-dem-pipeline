# Stone Money Island 生存垂钓完整生产计划 V0.2.3

## 目标体验

首条垂直切片应在 5–8 分钟内让玩家经历完整闭环：观察水域、选择钓位、准备简易钩线、抛投或放线、读鱼、咬钩、搏鱼、一次可能的出水/落水、上岸或失败、处理捕获物。

玩法的核心不是“按一下得到鱼”，而是“从环境中读出信息并管理风险”。

## 完整循环

### 1. 观察

玩家从水色、底质、鸟群、鱼影、拍水、潮位、风和水道判断鱼可能在哪里。

- 白沙浅湾：小鱼、低风险、易登陆；
- lagoon 草床与沙沟：鱼迹清楚，但易挂草；
- 珊瑚块群：鱼多，磨线和钻洞风险高；
- 窄水道：流速与巡逻视线风险；
- 礁缘：较大鱼、浪和深水风险；
- 外坡：中后期内容，不进入首条切片。

### 2. 准备

工具路线：现有木鱼叉、简易手线、后续浮标/沉底/拖线、独木舟垂钓。任何 1944 飞行员生存钓具或残骸材料，在历史证据核实前都保持候选标签。

首版不做“上千钓具组合”，只做少量但真正改变行为的变量：线强度、钩大小、饵类型、配重和线长。

### 3. 投放

抛投至少记录起点、方向、速度、风、线长、接触点和入水角。接触水面时生成：

- `lure_water_entry` 事件；
- 局部飞沫；
- 环形波；
- 水下气泡/短尾迹；
- 对附近鱼的听觉/压力扰动。

### 4. 诱鱼与判断

鱼 AI 使用状态机：

`forage → notice → orient → approach → inspect → reject / strike → hooked`

状态转换由物种、饥饿、光照、饵、速度、距离、遮蔽、玩家噪声和同伴反应决定。玩家可以通过收、停、抖、换深度改变鱼的判断。

### 5. 咬钩与钩牢

咬钩后提供短而可读的窗口：线先松、轻抖或突然走线，玩家选择提线。过早会拉空，过晚会吐钩或吞钩。首版避免毫秒反应游戏。

### 6. 搏鱼

玩家只有三个主要动作：

- 收线：缩短线长，提高张力；
- 放线：降低张力，允许鱼冲刺；
- 抬线/换方向：改变线角，使鱼离开珊瑚或朝浅水移动。

玩家移动本身也是策略。搏鱼结果由线张力、钩牢度、鱼体力、玩家体力、线磨损、水流、浪、障碍物和登陆区域共同决定。

### 7. 出水与落水

鱼接近水面并满足物种、速度、线角和体力条件时进入：

`surface_approach → breach_takeoff → airborne → splashdown → recovery`

鱼体不换实体。出水前应有影子、露背、泡沫或线角变化。空中阶段继续受重力、角动量和线约束。落水事件以相对速度、质量、接触面积和浪面法线计算飞沫强度。

### 8. 登陆与处理

登陆不是“瞬间进入背包”。玩家需要把鱼引入浅水、拖上沙地、用手/工具固定。之后才进入食用前处理、烹饪、切取鱼肉、小鱼作诱饵和腐败/气味系统。

## 摄像机与信息反馈

正常玩法保持玩家视角，不给永久水下透视。信息层级：

1. 线的方向与松紧；
2. 手部、手线/工具和身体受力；
3. 水面扰动、鱼影、露背；
4. 线鸣、手线滑动、拍水、浪和鱼体撞击；
5. 极简张力带，作为辅助而不是唯一信息；
6. 调试模式可显示水下 AI、力和路径；
7. 回放/宣传模式可采用水下切镜，但不得改变实际状态。

## 跨介质技术模型

所有系统读取 Ocean Mother 的统一查询：

`surfaceAt(x,z,t) -> eta, normal, velocity, breaker, depth, clarity`

当前 `waveAt` 已能提供 `eta / bed / depth / breaker / slopeEnergy`，但 `normal` 仍为固定 `[0,1,0]`，也缺少明确的水平表层速度。因此首轮增加适配层，而不是修改冻结海天源。

Fish Mother 输出同一个鱼体状态：位置、速度、朝向、角速度、骨架姿态、体力、受惊、钩点、介质比例与生境意图。显示网格只是派生输出。

线是连续约束，不是视觉直线。首版采用有限段绳链或稳定离散曲线，支持线长、弹性、阻尼、断裂强度、磨损和障碍接触。

飞沫由事件驱动：饵入水、鱼露背、鱼跃出、鱼落水、线扫水、玩家涉水和独木舟尾流。

## 鱼行为分层

首条切片只需要两类行为模板，不急于堆鱼种：

1. lagoon 中层小型鱼：谨慎、短冲刺、少量出水；
2. 礁缘较强鱼：长冲刺、钻珊瑚、在高线角下可能跃水。

物种名在证据确定前不锁死。每种模板都需有舒适水深、速度、转弯半径、饵偏好、群游倾向、掩体使用、冲刺、疲劳、跃水边界和受伤阈值。

## 环境与游戏风险

- 珊瑚提供遮蔽、觅食和磨线点，不是装饰；
- 潮位改变可钓区域与登陆区；
- 风改变投放和水面可读性；
- 浪改变线张力和落水效果；
- 大声拍水或长时间站在开阔岸边可能提高巡逻暴露；
- 夜钓可能提高机会，但降低礁体和巡逻可见性；
- 独木舟钓鱼增加范围，也增加漂移和翻覆风险。

## 生产阶段与门禁

### P0：合同冻结

完成共享鱼体、线、水面、障碍、生境、事件、存档与 QA 合同。任何 Mother 不得在合同外私建同名状态。

通过条件：同一录制输入在纯逻辑测试中得到可重复结果；保存/恢复后鱼 ID、线长、张力、体力与状态一致。

### P1：手线垂直切片

在白沙湾/浅 lagoon 放入一条候选鱼和一个简易手线循环。先不做大量珊瑚与鱼种。

通过条件：能完成上鱼、脱钩、断线三种结果；玩家可在不看水下调试镜头时作出合理判断。

### P2：水面跨越

接入 `surface_approach / breach / splashdown`，同一鱼体连续穿越水面。

通过条件：位置连续；没有穿水面闪烁、替身和瞬移；线不穿断；落水事件与速度成比例。

### P3：珊瑚与生境

接入浅礁、草床、沙沟、珊瑚障碍和线磨损。

通过条件：鱼会利用环境，玩家能主动改变线角避免磨断；珊瑚位置来自同一底质/生境查询。

### P4：独木舟与 lagoon

在独木舟上加入漂移、站位、手线操作和登陆。

通过条件：鱼、船、线、水面和相机共享同一世界时间；没有船动鱼不动或线端点漂移。

### P5：外礁与内容扩展

添加更强鱼、外坡、天气、昼夜和完整生存收益。只有 P0–P4 稳定后才增加鱼种数量。

## 性能策略

- 不建立第二套高/低精度鱼身份；同一鱼状态驱动所有显示；
- 首版同时只允许一条被钩鱼；
- 非搏鱼鱼群继续使用低成本生境行为，但不丢失稳定 ID；
- 飞沫采用事件预算和共享粒子池；
- 线段数有硬上限并按误差自适应求解；
- QA 记录 CPU 逻辑、GPU 绘制、粒子数、线段数与水面事件数；
- 390×844 作为正式验收视口。

## 首版明确不做

- 不做 70+ 鱼种；
- 不做现代比赛、等级和奖杯陈列；
- 不做持续水下透视；
- 不做所有鱼都跃水；
- 不做独立于世界水面的假水花；
- 不做鱼被捕后直接消失进背包；
- 不为了镜头漂亮而暂停物理或偷偷传送鱼。
