# Mother 并行工作包与边界

所有工作线从同一个协调基线读取合同。任何工作线若需要修改其他 Mother 的权威定义，先提交接口请求，不得复制后自行改名。

## 0. 小妈 / Coordinator Mother

职责：冻结合同、建立分支、维护任务依赖、合并、回归测试、证据边界和最终发布。

首轮交付：`fishing_core` 纯逻辑原型、跨介质状态与事件合同、统一鱼 ID / 世界时间 / 存档结构、P0 回归测试、所有 Mother 的白名单文件边界。

禁止：以“大家都在做”为理由跳过实际回执。没有 commit、测试与截图就不算完成。

## 1. Game Mother

职责：玩家意图、手线/钩线交互、张力反馈、失败/成功、背包、烹饪与生存后果。

输入：Fish 状态、Ocean 水面、Habitat 障碍查询、Human 动画事件。

输出：`cast / reel / give / lift / move / land` 玩家动作；任务、UI、存档和结果交易。

首轮只做一套简易手线、一个钓位、一个完整闭环。

验收：不看水下调试镜头也能理解咬钩和高张力；上鱼、脱钩、断线均可复现。

## 2. Fish Mother

职责：鱼体参数、骨架/形体、游动、感知、饵判断、咬钩、冲刺、疲劳、掩体、出水与恢复。

输入：水深、水面、流速候选、底质、掩体、线力与钩点。

输出：唯一鱼实体状态、姿态和事件意图。

禁止：钓鱼时换成另一套“被钩模型”；禁止预烘焙跳鱼动画无视线力与水面。

验收：同一 `fishId` 在自由游、咬钩、水下搏鱼、出水、落水和登陆全过程连续。

## 3. Ocean Mother

职责：统一水面查询、局部扰动、飞沫、环波、水下光学、介质音频参数。

输入：鱼/饵/线/船的水面事件。

输出：`surfaceAt`、`splashResponse`、水下可见度与声音滤波参数。

约束：冻结海天原件不被重写；所有新增效果为适配层且能关闭对照。

验收：鱼与水花在同一个波面交点发生；波面变化后事件仍贴合；水上水下声音转换无爆音。

## 4. Coral / Habitat Mother

职责：沙、草床、块礁、珊瑚缝、深槽、礁缘的统一生境与线碰撞/磨损查询。

输入：G05/G06 实景证据、海床、水深、受浪与光照。

输出：`habitatAt`、`coverAt`、`snagAt`、`landingSuitability`。

禁止：为了钓鱼另画一套不可见障碍；显示珊瑚、鱼的掩体和线的挂点必须来自同一对象。

验收：玩家能通过改变站位与线角绕开同一块可见珊瑚；不可出现视觉上无物却磨断线。

## 5. Human / Tool / Audio Mother

职责：手线、抛投、收放线、身体受力、手部接触、登陆鱼、声音反馈。

输入：Game 动作、线张力、鱼冲刺与水面事件。

输出：人物姿态、手部和工具端点、受力动画、线声、拍水声与呼吸声。

首轮不要求完整角色重做，但工具端点必须与线端点一致，不能视觉脱节。

验收：线拉力方向与手臂/身体重心一致；移动时无抖动和手线穿手。

## 6. QA / Mobile Mother

职责：确定性、保存恢复、跨介质连续、移动端操控、性能和视觉对照。

必须测试：30 / 60 / 120 fps；暂停与恢复；保存于咬钩、水下搏鱼、出水、空中和落水后；390×844 触控；鱼跃水面附近的相机裁切；线磨损和珊瑚障碍；波浪时间跳转；失败后重新开始不残留旧鱼和旧线。

验收：所有结果有机器记录和可视证据，不能只写“看起来正常”。

## 合并顺序

1. Coordinator 合同与纯逻辑核心；
2. Ocean 查询适配 + Fish 状态接入；
3. Game 输入与张力反馈；
4. Habitat 磨线/掩体；
5. Human/Tool/Audio；
6. QA 全量回归；
7. 才进入内容扩张。
