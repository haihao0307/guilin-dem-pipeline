# 《Fishing Planet - Official Trailer | PS4》逐段分析

视频技术信息：114.136 秒，1280×720，H.264，约 29.97 fps。以下结论只针对用户提供的这段宣传片，不把宣传片中的文案当作当前版本事实。

## 00:04–00:14：先让环境变得值得停留

视频先展示晨昏、远山、湖面反光和大范围水域，没有立即用 UI 或鱼种数字轰炸玩家。它先建立“我愿意在这里等待”的情绪。对 Stone Money Island 的迁移不是照搬山地湖泊，而是先让白沙湾、浅 lagoon、喀斯特水道、外礁和天气各自具有可辨认的光、水、声与风。

## 00:18–00:30：抛投动作被拆成可读事件

先出现人的动作与钓具，再给饵/线触水。00:26 左右的水面接触被放大为独立视觉事件：接触点、冠状水花、环波、线的方向和饵的落点都清楚。随后切入水下，展示饵在生境中的运动。

可迁移部分：

- 水面接触点必须精确对应同一条线和同一个饵；
- 飞沫、环波和声响应由落水速度、质量、角度和浪面法线决定；
- 饵进入水下后应继续沿线约束运动，而不是换成另一个镜头里的假饵；
- 珊瑚、海草、沙沟和深槽应改变饵的可见性、挂底风险与鱼的接近路线。

## 00:36–00:55：用场景和工具差异制造选择

视频展示不同水域、钓位、鱼种和钓具组合。可迁移的是“选择带来后果”，不是现代钓具数量。Stone Money Island 的选择应来自：岸钓、涉水、独木舟、浅 lagoon、窄水道、礁缘、潮位、风向、饵料、线材和隐蔽风险。

## 00:58–01:18：鱼不是奖励箱，而是会判断的对象

水下镜头反复显示鱼接近、转向、保持距离、重新对准目标。水面镜头同步给出竿尖和收线动作。真正有价值的是：

- 鱼并非一看到饵就咬；
- 鱼的身体朝向与速度变化构成预兆；
- 玩家动作会改变鱼的下一步，而不是只等随机计时器。

## 01:20–01:31：刺激峰值来自跨介质连续链

这一段的高潮链为：

1. 竿弯和线向提示鱼在发力；
2. 鱼在水下快速转向；
3. 水面先出现线向、鱼影或背部轮廓；
4. 鱼体部分穿出水面；
5. 飞沫扩大，鱼体完全出水；
6. 鱼在空中仍受线约束；
7. 落水或被拉向岸边。

最关键的不是“跳”，而是玩家提前约 1–2 秒读到它将要跳。没有预兆的跳只是随机动画；有预兆，玩家才能决定放线还是硬顶。

## 01:32–01:38：快速确认结果

视频以持鱼展示收尾，提供尺寸和成果确认。Stone Money Island 不应复制现代奖杯姿势，但必须有清晰结果反馈：鱼是否活着、是否受损、重量/可食部分、能否做诱饵、是否需要立即处理、捕获行为是否吸引巡逻或掠食者。

## 水面—水下—出水为何刺激

刺激来自六种连续信息叠加：

1. **看不全**：玩家不能一直看见鱼，只能从迹象推断；
2. **线是信息通道**：线向、振动和张力把水下行为传到玩家手里；
3. **水面是阈值**：鱼接近水面时，影子、背部、泡沫逐渐显现；
4. **介质突然改变**：水中高阻力变为空中低阻力，鱼的轨迹、声音和视觉瞬间变化；
5. **风险峰值**：出水时最容易脱钩、甩线或改变方向；
6. **落水冲击**：飞沫、声响和重新入水后的加速完成第二次高潮。

## 不能照搬的内容

- 宣传片靠切镜强化水下可见性；正常玩法若持续给玩家水下上帝视角，会消灭判断与紧张感。
- 画面中的大幅飞沫具有宣传片夸张性；Stone Money Island 要根据鱼体、速度和浪况缩放。
- 宣传片是淡水运动钓为主；本项目需要海水鱼的物种行为、礁体躲避、潮流、浪和珊瑚磨线。
- 现代竿、轮、彩色商品饵、比赛服与奖杯展示不属于 1944 求生语境。
- 片中的鱼体和水面接触是否完全物理连续无法由画面证明。我们必须自己建立可测试的连续合同。

## 最有价值的五项迁移

1. 把“落水点”做成真实事件，而不是一张贴花；
2. 把“鱼的接近—试探—咬钩”做成可读状态，而不是随机倒计时；
3. 把“线”做成玩家与水下世界之间的实时传感器；
4. 把“出水—空中—落水”做成同一鱼体的连续跨介质过程；
5. 把捕获结果接入生存、天气、巡逻、资源和生态，而不是只加分。
