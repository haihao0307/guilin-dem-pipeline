# Survivor: Palau V0.1.0

First Game-line fork from the frozen Ocean Mother R018 V0.3.6 unified-seascape baseline.

This package intentionally does not claim the full survival game is complete. It establishes the world foundation requested for the next gameplay pass: naturalized breaker foam, visible clouds, Palau-style karst masses, procedural vegetation, canoe prototype and deep-fishing viewpoint.
