## 2. 片区选择

在阳朔漓江沿线提出 2 至 4 个候选真实片区。每个候选必须给出：

```text
中心坐标
CRS
像元窗口
范围和面积
源 DEM 哈希
漓江或批准水系版本
真实高程预览
坡度与曲率预览
河流、峰体和低廊道关系图
片区选择理由
已知缺口
```

候选片区优先包含：

1. 漓江主河道。
2. 独立塔状峰和峰丛。
3. 峰间连续低地。
4. 贴水陡崖或石灰岩峰壁。
5. 沿江低岸、滩地、沙洲或洪泛平地。
6. 稻田、田块、田埂和灌排沟渠适生的平坦谷地。

在用户确认片区以前，不开始最终地貌生成。

## 3. 地貌生成

用户确认片区后，建立以下层：

```text
z_truth_m
z_base_resampled_m
z_macro_delta_m
z_micro_delta_m
z_visual_m
```

`z_macro_delta_m` 负责：

```text
塔状峰侧壁陡化
峰冠圆钝、偏斜、凹口和鞍部
峰脚短促转折
峡谷和贴河崖壁
沿江低地与台地边界
河岸坎和滩地骨架
```

`z_micro_delta_m` 负责：

```text
岩壁台肩
竖向溶蚀沟
裂隙和凹腔
坡脚崩积
河岸冲刷槽
田埂
田块微高差
灌排沟渠
沙洲与滩地微起伏
```

## 4. 漓江和稻田关系

1. 主河道与水面位置服从批准水系。
2. 河流沿低廊道连续前进并绕开峰体核心。
3. 外弯、峡谷段和贴崖段可以形成局部陡岸。
4. 内弯和宽谷段可以形成低滩、点坝、低岛和冲积平地。
5. 稻田只进入低坡、低曲率、适宜湿润和可灌排的沿江平地。
6. 田块需要多尺度、不规则边界，禁止统一棋盘格。
7. 田埂和沟渠进入可逆几何层，稻作植被继续排除。

## 5. 材质和近景

石灰岩地表应表现灰白、灰褐、湿润暗色、层带、裂隙和局部裸岩。禁止整座山使用统一土褐色。

```text
微地形增量分辨率
视觉三角间距
```
