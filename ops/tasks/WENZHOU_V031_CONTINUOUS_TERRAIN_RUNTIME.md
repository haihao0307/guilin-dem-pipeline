1. 全域只允许一个真值 DEM、一个坐标系、一个像元原点、一个 terrain runtime 和一个世界变换。

4. 总览使用完整拼接 COG 生成的 2048 × 2048 全域资产。近距细看使用同一 COG 派生的连续瓦片金字塔或自适应局部网格。禁止为四个地点制作彼此独立的高程源。
