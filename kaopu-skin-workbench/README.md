# 共模皮肤实验 R01

独立目录。复用已验收共模的 25,417 顶点、50,624 三角面及完全相同的 Anny/GNM 求值器、固定颈部适配器。没有修改教师或原共模。MHR 仍只覆盖身份 1/45、姿态 0/204、表情 0/72。

## 实现

MeshStandardMaterial GGX PBR + 自有 GLSL SkinProfile：肤色深浅、血色、斑驳、毛孔强度/尺度、粗糙度、雀斑、细纹、暖边近似、随机种子。三种配方不改变模型。层开关、白模 A/B、暖/冷/掠/背光、头颈和皮肤近景用于比较。

运行不需要皮肤图片或烘焙纹理。GNM 的实际容器有 component_id、material_id、region_id，但没有 UV。直接通过既有 canonical.gnmRecipes 的源顶点对应读取官方区域和材质标签；嘴唇区结合原头中性坐标缩窄唇红边界，区域权重仅作拓扑邻接平滑。眼球、牙齿、牙龈和舌头分别着色，不把皮肤毛孔覆盖到它们。眼睛目前简单分区，非完整角膜/虹膜渲染。

skinRest 保存统一中性模型的米制坐标，每个顶点固定一次。变体和骨架改变 position，但不改变 skinRest，噪声因此固定在材质表面。颈部采用同一个连续三维参考场，无独立头身 UV 拼缝。变形会按固定材质坐标伸缩细节，未实现对任意伸缩保持严格物理毫米尺度。所有原几何数据和顶点索引不变。

微表面高度通过视空间曲面梯度转换成法线扰动，在几何法线上叠加，而不是把任意噪声 RGB 当作法线。高频毛孔使用屏幕导数减弱远景混叠。层切换不换材质、不重新创建 WebGL 上下文。按需渲染，没有动画时间参与噪声。

## 明确边界

这不是 SkinGen 的复制或同等替代。SkinGen 官方演示依赖 Substance 图层及授权微纹理；本实验未使用其专有贴图、CC 基模、Texturing.xyz 或真人素材。

“透光”只是很弱的视角相关暖边近似，不是厚度驱动、光源透射或真实 SSS。没有扫描皮肤精度保证、毛发、眉毛、睫毛、血管图谱或真实皮肤光谱。GNM 区域标签对其他人体模型不能直接互换。本版仅适配这一份固定共模，不能宣称三家全部模型无损通用。

## 资源

皮肤图片/纹理下载为 0；新增材质顶点属性 813,344 字节，GPU 纹理数应为 0。整个角色仍依赖原共模几何教师：GNM 34,937,952 字节，Anny 压缩 45,650,600 字节（解压117,588,304字节），另有固定适配器约0.61MiB压缩。函数驱动的轻量皮肤配方不代表整个角色已是轻量运行时。

GPU 属性字节是逻辑缓冲数据估计，不是驱动实际显存。浏览器统计会报告 renderer.info.memory 纹理、几何和程序数量，无法准确计量所有驱动显存。

## 验证

独立只读 CI 使用 Chromium / Linux WebKit，检查固定几何、固定参考坐标、多肤色实际像素差异、微表面开关像素差异、多形体/姿态、20轮进退、相机往返、上下文恢复、移动布局和无写请求。必须检查产出近景截图才能判断视觉表现；像素数量不是写实证明。实体 iPhone 尚未验证。
