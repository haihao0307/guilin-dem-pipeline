# R11 蓝灰鱼群与自然注视

用户明确要求主要在蓝色系内轻微变化，眼睛动作更自然。本版以 R10 为完整表面和精简运行基线，只修改表面着色与眼睛注视控制。

交付仍为一个 `dist/KAOPU_FISH_BLUE_GAZE_R11.html`，双击离线打开，全部资源内嵌。重建：`node local-r11/scripts/build.mjs`，直接读取冻结 R10 HTML 的精确 compact score，不重新压缩素材，不新增模型、图片或运行依赖。

鱼群采用很接近的蓝灰 tint；明暗约 ±2.5%，saturation 与通道抖动范围很窄。shader 按原图的 luminance 加少量冷蓝色倾向，保持原鳞片、明暗和斑纹的空间信息。原图集本身逐字节保留。十五条鱼的尺寸/体型/phase/tempo和群体路线保持 R10，颜色是用户授权的新外观，不声称为真实物种色彩标定。

眼睛改为确定 seed 的轻扫、注视停留和回到中性视线：普通扫描目标 yaw 约 ±0.047rad、pitch ±0.023rad；每次注视停留约1.9–4.4秒，目标过渡0.12–0.22秒，再经过阻尼传导。每个个体、左右眼的时序不同，微小瞳孔变化保持原范围，手动偏置和眼睛追踪演示保留。REST 是静态参考。KFE1 眼球几何、眼位、虹膜、角膜和光照未改；没有添加缺乏参考的眼睑或眨眼。时序和阻尼是动画工程参数，未作生理标定。

完整采样网格、曲面函数、残差、UV、法线、连续鱼鳍绑定、中心脊椎与尾鳍耦合、44字节尾尖包、CPU静态副本释放均保留 R10。源码和结果证据留在本项目，不写入全局记忆。人工 visualAcceptance、motionAcceptance、productionReady 继续为 false。
