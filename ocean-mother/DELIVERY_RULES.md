# Ocean Mother user-facing delivery rules

1. The default delivery is an interactive three-dimensional HTML runtime.
2. Image generation and image delivery are prohibited unless the user explicitly requests an image.
3. Screenshots may be created only for private QA and may never replace the HTML delivery.
4. Every review build must include a directly openable single-file HTML.
5. For R018 nearshore correction, preserve the established rocks, sand geometry and rotation, fires, smoke, and camera composition. Limit edits to water-surface quality, foam continuity, and curling-wave visibility.
6. Restore the deep-sea module to the previous accepted baseline and keep it frozen until the user gives an explicit deep-sea change instruction.
