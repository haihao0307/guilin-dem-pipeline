日期：2026-09-01。工作台版本：0.1.0。打包版本：1.0.0-clean-full。

## 先从这里开始

这是当前已发布海洋工作台的完整可编辑源码与必要知识交接包。日常只读本文件；文件身份、版本和未完成项见 HANDOFF.json。没有删减已发布运行功能，没有修改任何原运行代码，也没有降低采样。

在线入口：https://haihao0307.github.io/guilin-dem-pipeline/ocean-mother/v001/

## 使用方法

把整个包解压到一个目录。Windows 已安装 Python 3.10 或更高版本时，双击 START_LOCAL.bat；脚本会先核验文件，再启动仅本机可访问的服务并打开浏览器。首次进入需要生成云密度与光照缓存。

其他系统执行 `python3 -B tools/serve.py`。浏览器需要 WebGL2。离线使用不需要 npm、CDN、API 密钥、外部图片或模型；Python 只用于提供本地 HTTP 服务。

网站部署直接使用 workbench/ 目录，保持其中所有相对路径。也可以托管整个包，根目录 index.html 会跳转到 workbench/。请勿用 file:// 双击运行实际渲染入口，因为程序需要通过 HTTP 读取着色器及启动 Worker。

## 包内组织

workbench/：当前海洋网页、可编辑 JavaScript、GLSL、CSS，以及一套完整原字节天气依赖。cloud-atlas.frag 是程序源码，负责运行时计算，不是图片文件。

knowledge/：八项数学物理技能、规则合同、已蒸馏研究、统一方法论接收文本及 JSON、必要来源和接收回执。bridge-v1 是独立参数接入研究代码与测试；当前网页使用 workbench/weather-contract.js。两者没有自动合并。

tools/：文件核验与本地启动工具。SOURCE_LOCK.json 对应每个保留源文件的仓库、精确提交、路径和哈希。MANIFEST.json 覆盖本包文件，校验器不会修改它们。

## 当前完成与边界

现有网页提供六种海况、几何波动、风向风力、涌浪尺度与周期、独立云漂移、日照、水色、暂停、视角拖动、观察高度和参数 JSON 导出。海面采用解析多波分量；天空与倒影使用运行时显存缓存。泡沫与水色仍属于图形近似。

未完成：浮力与碰撞求解器、真实岸线与海底、潮汐、破碎浪、持久泡沫输运、中性/工作室/诊断三模式完整接入、共同严格 Schema 及运行门禁。人工视觉与生产批准都保持 false。

统一方法论保留 1.0.0 候选身份。包中是仓库已归档的全文接收文本和提取 JSON；原附件字节身份、配套严格 Schema 与原校验器仍未证实取得。已收到的规则没有被重写为替代版本。
