# 交接范围

本包包含当前 R018.11 完整单文件运行时、可重建源码、独立导出的近岸着色器、冻结深海文档与模块、R018.10 差异基线、原 V0.3.0 全量包及其全部展开源码、历史天气依赖、知识/规则/工具、继承测试原件、修复字节差量、当前未完成事项和包校验器。

顶层 `index.html` 是唯一当前运行入口；`history/` 是只读历史，不参与默认导航。`source/page.template.html` 和 `source/inline-*.js` 重建结果须与当前 HTML 完全相同。导出的 `shaders/` 和 `frozen-deep/` 便于阅读，直接改它们不会自动改动主运行时，应使用源码模板的实际消费者并重新构建校验。

`tools/r01811.delta.json` 只可应用到指定 R018.10 SHA，反向操作不得将故障基线重新发布。原始 V0.3.0 ZIP 的 117 个文件全部保留；旧 Manifest 列出 113 个有效被校验文件，余下 4 个为 Manifest 文件。本次记录实际数量，不改写历史 Manifest。

需要真实确认的三个独立状态：归档成功、网页运行可靠、视觉达到用户要求。目前归档可以校验，后两项仍存在未完成工作。没有图片、模型、第三方 CDN 或安装包混入当前交付。
