## 来自官方说明的关键区别

E16：液体以粒子和网格共同组织状态，并独立重建可见表面。物理尺度和 voxel size 需要显式确定。Rasterizer 与 Path Tracer 是两种不同的显示选择。

E17：PIC/FLIP ratio、Pressure 的目标与迭代预算、Collider、Whitewater、Meshing 各有职责。PIC 引入的数值耗散需要与材料黏度分开。Meshing 的固定阶段为 SDF Generation、Smooth SDF、Curvature Flow、Reshape、Mesh generation、Simplification、Clipping、Smooth Mesh、Snap to Colliders、Normals。源文件对表面张力单位的文字仍有疑义，不能直接用它建立单位换算。

E18：Smooth SDF、Curvature Flow 与 Smooth Mesh 解决不同层次的问题。过强平滑会压平飞溅，Min neighbors 也可能去掉支撑薄片的粒子。Clipping 和 Snap to Colliders 处理显示网格的位置与裁切，不能据此单独判断求解边界是否防漏。

E19：官方 Diagnostics 明确区分几何、速度、涡量、曲率、白沫生成信号、粒子状态、碰撞场和活动域。诊断需要检查底层数据。

E21/E22：体素烟火有独立的速度、烟、燃料、温度和火焰状态。Combustion 与 Colored Smoke 具有不同字段；Colored Smoke 没有温度。Projection 提供 Multigrid、SOR、Correction 和防薄壁速度泄漏控制，上一帧压力复用对强爆发等情形有适用限制。Flames 的发光与烟的受光另行组织。

E23：压力投影质量会影响后续细节；添加涡量或更复杂输运不能单独替代合适的压力求解。该文也列出预条件共轭梯度作为可选方法。本文实现 PCG 参考算子，不声称复现厂商 Multigrid。

E20/E24/E25：子图、输入输出、参数暴露、时间曲线和调制帮助组织复杂效果。接口组织与具体介质方程分别维护。

## 当前 Coast 的实际问题

下面内容来自本线精确代码的复算，属于本项目审计结论。被审运行源码 aeeafa124d79f9cb3df2345b0563929ef9f1b47f；本轮开始远端 head 5ab8b9bd98ba9c79ccda173af9870c7ed0b99db1。

1. 当前水体仍是深度平均高度场，烟仍是有限数量的扩张烟团。它们没有粒网液体自由界面、气体压力场或燃烧过程。这一版可以保留为旧实验，不能据其自动测试宣称已复刻目标体系。
2. 精确执行旧 grid 与 makeSlab 的 CPU 几何函数后，水面上层网格有 704 条开边，缺少水体剖切侧面。地形侧板只用四个角点连接，与实际弯曲床面不一致；在现有边缘顶点处测得最大高差约 0.293 m。它们足以解释明显的侧边缺口，但开边数量本身不能证明数值质量丢失。
3. 水的横向边界为周期连接，泡沫采样却被钳制到边缘，显示又是有限剖切块。注入的域外浪花探针在一步后仍存在。总体水量残差很小也不能替代这些边界检查。
4. 岩石是椭圆高度隆起，缺少真正独立的三维断面和底部结构；着色条纹无法补回这些几何。参考要求应先约束块体轮廓、断面方向、倾斜和埋入关系，再安排细纹与湿润光学。

## 已实现的独立小样

labs/r006-reference-v010/ 中新增 particle-transfer.mjs、pressure-projection.mjs、boundary-geometry.mjs、fracture-solid.mjs。

粒网小样明确给出 P2G 权重、PIC 和 FLIP 更新以及混合系数。三线性权重属于本线实现选择，没有伪称原工具使用相同权重。网格变动为零时，纯 FLIP 保留粒子速度；PIC 从新网格采样。越过声明域的粒子会被拒绝，机器舍入误差有独立界定。

三维 MAC 压力小样使用常密度、静止体素固体和闭合滑移边界。以每个连通水域的独立压力规范处理零空间；实测修正后的散度达标才返回可接受速度。超过迭代预算时返回拒绝。它没有平流、自由表面、膨胀源、移动碰撞体或 GPU 运行时，所以不能称为完整液体/烟火系统。

封闭几何小样共享顶部和侧面的边缘顶点并补底。断面岩石小样由封闭半空间交集生成真实三维面，表面和点内外判定来自同一组平面。其场值具有正确的内外符号，外部角点处不具有精确欧氏距离含义。拓扑通过仍不代表形态已像参考。

本轮 23 项本地自动测试通过，0 失败；包括算子、边界、单位、拒绝条件、重现性、封闭几何和面积间距检查。当前 16×12×10 三维闭域投影实例的最大散度从约 29.41 /s 降至约 7.98e-9 /s。该小样不支持气体膨胀，也不代表整个效果的真实程度。

## 复刻顺序与范围

先建立边界一致的几何与物理定义。剖切面是观察窗口，不能自动充当实体水槽墙。入口、出口、吸收区域和固体壁分别声明，真实通量记账；只裁掉越界像素不算防漏修复。

扩大实验为 96×84 m，同时由 144×112 增到 216×168 单元，保持两个方向的原有物理间距。面积增至 2.25 倍。这个设置只完成两秒数值探针，不具有在线画面或帧率结论；不能用旧网格拉伸或同时放大岩石和砂粒来代替。

岩石先做与参考相符的三维块体和破裂面，中性灯下检查轮廓、厚度、接触和投影。再引入细微起伏、颗粒差异和受水状态，避免统一波纹和撒点。当前凸体只是数学底件；岩石家族、裂缝、磨蚀和参考相似性仍需单独制作。

然后完成局部三维液体最小复现：粒网往返、适用的自由表面压力边界、固体碰撞、重力与尺度、持续历史，以及能够表达翻卷浪唇的界面重建。大尺度海面继续保留，局部域的接合不可伪装成已完成耦合。泡沫、飞溅和气泡保持独立状态与生命周期。

烟火复刻随后基于体积场检查来源、输运、压力、热浮升、冷却和发光。源项、温度、烟密度及展示曝光分别控制。复杂爆发、冲击和湿热效果另立有证据的小样，不能用现有发光锥体统一代替。

最后同一组对象、物理时刻和相机分别用中性、工作室、诊断检查，再与参考画面逐项比较轮廓、运动时序、材料和光照。渲染后端和参考镜头参数未知时保留未知，不承诺逐像素或相同数值结果。
