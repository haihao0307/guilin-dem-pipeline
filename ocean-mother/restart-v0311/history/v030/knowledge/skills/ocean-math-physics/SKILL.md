## OM-M01 统一时钟与积分 [U01][E03]

输入：桥接的 simulationSeconds、discontinuity、wind.velocityMps、日照及按模拟时刻记录的环境变化。

公式与规则：delta = t_source - t_previous。物理步长 h 固定，初始实验可取 1/120 s，此数值属于项目选择，必须做步长收敛实验。累积 delta 后逐个 h 积分；性能计时可使用现实时间，物理不另外累计现实时间，不再乘 timeScale。

每个子步在其模拟时间查询波面与环境输入。环境变化必须有时间戳和明确插值策略；仅固定 h 仍不足以保证随渲染帧率变化的输入完全一致。相同输入时序与种子需可复测，不承诺跨 GPU 逐位一致。

超过追帧预算时保留未积分时间并报告欠账，或显式暂停重同步；禁止静默丢弃大 dt 后假装追上源时钟。物体与海面展示必须使用同一展示时刻，延迟展示须标明。

来源丢失时停止消费。时间倒退、配置载入、来源替换按桥接 discontinuity 重置积分缓存、接触缓存和历史资源；刚体状态需要相应快照或明确重置，不能只把计时器清零。

输出：physicsTimeS、pendingTimeS、stepCount、sourceEpoch、inputRevision。验收：暂停零推进；时间倍率不重复应用；30/60/144 渲染帧率输入夹具在同一模拟时刻对比；大间隔、向前载入和回退均显式可见。

## OM-M02 无图波面与查询 [E07][P01]

输入：worldXZ、模拟时刻 t、稳定种子、平均水位 eta0、波参数 A_i、lambda_i、单位传播方向 d_i、omega_i、phase_i。

对初始参数化单值高度场，定义：

```text
k_i = 2*pi/lambda_i
theta_i = k_i*dot(d_i, worldXZ) - omega_i*t + phase_i
eta = eta0 + sum(A_i*sin(theta_i))
eta_x = sum(A_i*k_i*d_ix*cos(theta_i))
eta_z = sum(A_i*k_i*d_iz*cos(theta_i))
eta_t = -sum(A_i*omega_i*cos(theta_i))
normal = normalize([-eta_x, 1, -eta_z])
```

以上导数假设波参数在求导时不随空间和时间变化；参数过渡、空间掩膜或域扭曲需要相应链式求导。omega 为角频率，不等同于 cycles/s；相速 omega/k 不直接取风速，也不能当作水粒子速度。此参数化外观模型未声明满足完整海浪谱或流体方程。

几何与物理读取同一配置、坐标、时刻和种子。查询输出 heightM、normal、heightRateMps、waterVelocityMps、modelRevision、sampleTimeS。缺少水流模型时 waterVelocityMps=null；heightRateMps 不能冒充完整三维流速。

大尺度涌浪、风浪与微细波分开。影响轮廓与碰撞的细节需进入几何/物理查询；着色独有细节必须限制误差并标注。无图法线由导数产生，禁止改为法线图片。纯函数噪声允许，预烘焙噪声图、运行后保存噪声图禁止。

网格间距须依据最短几何波长和近景误差制定并做收敛测试；不能仅因满足两点采样下限就声称波形足够精细。有限窗口内正弦均值可能不为零，不按相机窗口每帧重算水位。平均水位独立；新增偏置噪声须采用明确零均值构造或固定标定。

若后续采用水平位移/尖峰参数化，世界水平坐标到参数坐标需要求逆，法线由完整曲面切向叉积计算；不允许继续套用上述高度场公式。翻卷破碎不在单值高度场适用范围内。

验收：零振幅平面；峰谷差 2A；传播方向；解析导数对有限差分；CPU/GPU 同坐标同时间误差；原点重定位后波相位不变。误差阈值须在实验任务中冻结，未测不填通过。

## OM-P01 浸没体积与浮力 [E02][DERIVED]

输入：真实排水体的封闭几何或明示非重叠体积单元、位姿、重心、质量、水密度、重力向量和波面查询。不可用碰撞 AABB 的体积代替排水体积。空腔、开口和进水须有明确排水定义。

静水、恒定密度、均匀重力下：

```text
Vsub = integral_over_displacing_body(inside_water(p)) dV
Fb = -rho_water * Vsub * gravityVector
Fg = mass * gravityVector
cb = integral_submerged(p dV) / Vsub
```

Vsub=0 时 Fb=0，cb=null，禁止除零。Fb 反向于重力，不沿渲染水面法线硬推。平衡检查为 rho*Vsub=mass；有其他约束或外力时需计入总受力。

球形样件的静水平面解析基准：半径 R>0，球心高度 yc，水面 eta；h=clamp(eta-(yc-R),0,2R)，Vsub=pi*h*h*(R-h/3)。此式由球截面积积分推导，适用于球与水平面，不泛化到任意旋转船体或大浪。

使用随时间起伏的波面截取体积并施加竖直浮力属于准静态近似。大坡度、砰击、翻卷、通气、进水、附加质量和波辐射等须另建模型。多个采样点只计对应非重叠体积份额，禁止每点重复计算全船排水量。

输出：submergedVolumeM3、buoyancyN、centerOfBuoyancyWorldM、approximationModel、errorEstimate。验收：离水为零、半浸/全浸球解析量、静水排水平衡、超重下沉、旋转体积守恒、采样加密收敛。

## OM-P02 力矩与相对水流阻力 [E04][E05][DERIVED]

作用点相对重心 r=p-cm，力矩 tau=r cross F。刚体作用点速度为 vpoint=vcm+omega cross r。采用准静态分布浮力时，sum(tau_i)产生俯仰与横滚；禁止把姿态直接设成水面法线或把物体高度锁到波面。

阻力的教学参考模型：

```text
vrel = vpoint - vwater(p,t)
Fdrag = -0.5 * rho * Cd * A * length(vrel) * vrel
```

Cd>=0，A 为与模型一致的参考面积，采用浸湿/迎流投影面积需另定求法；干燥部分不受水阻力。E05 给的是一般阻力形式，应用于水体时的 Cd、面积和流况由本项目另作校准，不能照搬空气参数。vrel=0 时阻力为零，不归一化零向量。Fdrag dot vrel<=0 是相对运动耗散检查，不表示有运动水流时物体世界动能永远减少。

没有 vwater 模型则阻力耦合保持未实现。可另用显式静水夹具 vwater=[0,0,0] 做单元测试，不能伪称真实海流。全部力与力矩由固定步长的刚体积分器处理。

验收：作用点在重心时力矩为零；对称浮力水平夹具净力矩为零；偏心力方向正确；静水阻力反向；相对流速为零阻力为零；无外部输入的能量增长需诊断。

## OM-P03 碰撞筛选与触发 [E01][E06]

AABB 是轴对齐包围盒。两个闭区间盒相交条件：对 j in x,y,z，Amin_j<=Bmax_j 且 Amax_j>=Bmin_j 全部成立。相切是否触发由业务明确；此处公式把相切视为候选。

先更新相关父子世界变换，再求世界包围盒。旋转对象的 AABB 通常包住较大空区；它适合宽阶段筛选，不能直接证明船壳接触、接触点、冲量或渗透深度。再按实际碰撞形状做窄阶段。

传感事件、物理接触、受力响应分开。事件定义 begin/stay/end、实体 ID、stepId、sourceEpoch；合并重复候选后再修改实体列表，禁止遍历时破坏候选集合。是否产生损伤或浪花由独立模块决定。

验收：分离、相切、重叠、父节点变换、旋转假阳性、一次入水事件、重复采样不重复计数，以及不同物理用途使用独立掩膜。

## OM-P04 接触响应与连续检测 [E03][E04][DERIVED]

包围盒返回 boolean 的能力不包含刚体响应。下式是由动量与恢复关系推导的无摩擦单接触参考，只用于解释和测试基准，不构成完整接触求解器。

设接触法线 n 从 A 指向 B，rA/rB 为接触点相对各自重心的向量，Iinv 为世界空间逆惯量，vrel=vB+omegaB cross rB-vA-omegaA cross rA，vn=dot(vrel,n)：

```text
K = invMassA + invMassB
  + dot(cross(rA,n), IinvA*cross(rA,n))
  + dot(cross(rB,n), IinvB*cross(rB,n))
j = -(1+e)*vn/K   only when vn<0 and K>0
P = j*n; impulseA=-P; impulseB=P
```

e 在 [0,1] 内。vn>=0 时不得继续施加吸引冲量。静态体逆质量和逆惯量按零处理。多接触、摩擦、穿透修正、休眠与约束排序要独立求解；不能在复杂船体接触上只调用一次上述公式。摩擦可使用切向冲量上限 length(Jt)<=mu*Jn 的独立约束，mu>=0。

高速运动需沿上一与下一位姿之间检查 swept shape 和首次接触时刻。每帧只看终点会漏过薄障碍物，传感器也需自己的连续相交检查。旋转、动态对动态碰撞是否覆盖必须明示，单条射线不自动代表有体积船体的扫掠。

验收：等质量无摩擦正碰的动量与恢复率；静态墙不移动；分离接触无拉力；高速跨薄障碍不漏检；接触容差与步长收敛。全部为待执行物理验证，知识入库不替代运行证据。
