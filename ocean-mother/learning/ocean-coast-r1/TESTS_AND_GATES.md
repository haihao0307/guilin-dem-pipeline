## B. 第一项生产候选门禁

对象：当前近岸 `breaker` 镜头周围 16 米乘 16 米小海面。

固定量：R018.11 HTML 哈希、波参数、绝对时间、相机、岛形、海床、材质、太阳、泡沫、烟火和渲染尺寸。

唯一新增能力：近岸 `sampleSurfaceWorld` 查询。

逐点检查：

1. GLSL `waterHeightAt` 与 JavaScript 查询高度。
2. GLSL `waterNormal` 与 JavaScript 同源法线。
3. `traceWater` 可见交点与世界查询位置。
4. 暂停、恢复和相同绝对时间回放。
5. 相机移动不改变世界海面身份。

报告必须包含米制最大误差、均方误差、采样点数量、浏览器与 GPU、内部渲染尺寸、帧时间和失败点位置。

## C. 后续门禁

### Test 02 水平位移恢复

先保持水平位移为零。启用横向位移后，世界查询必须反求参数坐标。`A_horizontal=0` 要精确恢复第一项基线。

### Test 03 潮位与海底

关闭风浪，只改变 `eta_tide`。水深和 wet shoreline 随潮位更新。程序化海床或未来 DEM 真值保持，canonical shoreline 保持。

### Test 04 水面界面与 Weather

固定波面、法线、粗糙度、泡沫、相机和太阳方向。唯一变量为云光学厚度乘数。它只改变直射太阳与天空入射项。

### Test 05 水下介质

选择多个已知水深和光程。验证透射连续性、射线步长收敛、浅水底部贡献和深水衰减。表面粗糙度固定。

### Test 06 泡沫历史

固定破浪源，分别检查产生、输运、寿命和消退。停止生成后，泡沫应沿声明的速度移动并按时间衰减。改变帧率不能改变同一世界时刻的状态超过记录误差。

### Test 07 单烟源与开放边界

只保留一个烟源。检查浓度总量、峰值、质心、厚烟腹、薄边、长尾、岛体防穿透和离域消失。关闭高频细节后恢复同一粗状态。

### Test 08 多烟源和岛体交互

单烟源门禁通过后，再扩展到多处烟火。至少一股烟需要在风场下接近岛体，并通过真实边界形成绕行或阻挡关系。

### Test 09 观察带宽和性能

从高空到近岸改变观察 footprint。主波与 WaterBody 身份连续，高频逐步展开。报告视觉带宽、物理带宽、GPU 时间、显存、缓存、射线步数和目标设备稳定性。

## D. 升级顺序

1. Render Query 通过后，才能修改复杂主波。
2. 潮位与海床关系通过后，才能推进复杂近岸。
3. 表面和水下介质分开后，才能进行最终调色精修。
4. 一个烟源通过后，才能增加更多烟火。
5. 目标设备测量完成后，才能声明性能结论。
6. 用户视觉接受需要单独记录，自动测试不能代签。
