# Ocean Mother / Coast V0.1.0

2026-09-01。首个可交互近岸候选。只有用户实际批准后才能更新批准状态。

## 本轮范围

Coast 是 Ocean Mother 下的子系统。一个 HTML 入口内切换近岸与现有深海。深海读取 ../v001/，文件不改。近岸独立单画布共同渲染沙滩、岩石、动态水面、喷溅点和体积烟火。图片、贴图、外部模型和外部 CDN 均为零。深度和场景颜色只在显存临时存储当前帧，不保存为资产。

64 × 56 m 程序化实验域，岸形为生成参数，无实测地貌或海底身份。144 × 112 单元水深网格，固定步长 1/120 s。来源文件及共同政策的原字节身份在启动时校验。复用既有公开候选的天气接口和原天空函数，原始天气文件不改。近岸暂未接入体积云缓存；深海原显示保持。

## 实际实现

coast-core.mjs：水深及两个水平动量的有限体积更新、静水平衡重构、数值通量、反射边界、记录过的西侧造波源区、摩擦与显式风应力近似。边界横向周期，仅作为有限实验域。统计实际水量、源区增减、水深正性修正与残差。水体几何由实际 h+b 派生。

同文件记录半拉格朗日表面覆盖白沫、接触湿润与延迟干燥、受重力的浪花点、受风拖曳的扩张烟团、相对热态及带时间戳参数事件。白沫、烟、湿润速率与光学系数未标定。烟团为外观粒团，最大出生率受显式容量预算限制，按年龄消散。火焰为基于相对热态和数值噪声的发光体积，未求解化学燃烧。

coast-app.mjs：真实几何上传、相机、参数更新、输入历史重演、四种查看模式与导出。所有过程共享固定物理时间。播放倍率只改变目标展示时刻，求解步长不变。设备跟不上时保留欠账并显式暂停，禁止丢时间冒充实时。

shaders.mjs：无图片的沙纹、岩石分层、海水着色、白沫细部及共享深度遮挡的烟火体积射线积分。纯着色小波对碰撞无效，未声明其为实测细节。火光局部影响地面与水面，烟的光照和自遮挡为近似。

模式：环境日照、中性检查、工作室打光、诊断。中性锁定曝光与固定照明，工作室主光/辅光/轮廓光具有独立强度、方位、仰角和颜色。强度为相对辐照度，不标 lux。颜色从 sRGB 转线性，曝光及显示变换只有末级合成负责。诊断有水深、泡沫、湿润与烟火图例，显示修改不回写过程数据。

## 与完整三维液体路线的差距

本候选是深度平均上冲与回流实验。真正悬沿翻卷、气液混合的三维自由表面、破碎物理、泥沙与渗透、刚体浮力/碰撞、双向流固反馈仍未实现。没有声称复现参考工具内部算法。局部三维翻卷路线继续保留，不能由高度场或当前泡沫外观宣布完成。

固体岩石从床面几何采样进水深网格，碰撞能力受其采样和深度平均表示限制。烟目前不绕过复杂固体求解压力，燃烧源设在干燥沙面，海水灭火/热交换尚未接入。每项缺失在 UI 明示。

## 共同规则

policy.json 原字节保留版本 1.0.0 候选。生成、参数更改、导出前执行只读政策身份及领域参数检查。配套原严格 Schema、原 validator、完整语义发布门禁仍缺，所以 sharedStrictSchemaIntegrated=false。这个 preview guard 不冒充完整共同校验器。公开页面保持研究候选与批准阻断标签。
