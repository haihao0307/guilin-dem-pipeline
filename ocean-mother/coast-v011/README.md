# Ocean Mother / Coast 0.1.1

本轮 R007 只推进侧边结构、96 × 84 m 域和独立岩石，继续保留深海 ../v001/ 与冻结天气原件。

## 已实现

216 × 168 数值网格，间距 4/9 m 与 1/2 m；面积 8064 m²，是旧版 2.25 倍。沙滩 384 × 336 展示网格，水面 288 × 240，不用拉伸旧网格代替新增空间。

南北水界默认 open_extrapolated，采用零梯度外推面通量，逐步记录流入与流出；它是近似开放边界，尚未验证无反射。西界在闭合参考面旁设置记账造波源，东界为岸内闭合边界。closed_reflecting 仅用于独立对照测试。有限剖切面是观察几何，不产生额外液体碰撞。泡沫离开横向域被带出，外部泡沫输入为零；域外浪花属于无水量的外观示踪，独立统计退出数量，不用删粒子修水量。

侧面水位使用与水顶面一致的位置及高度，地形侧板沿真实沙面边缘逐段生成，补底。该接缝证明不替代通量测试。水体仍为深度平均模型，无法模拟悬空翻卷浪唇。

十个独立封闭三维断面岩石，渲染面、点内外判定与垂向碰撞床面共享平面集合。它们是程序形态候选，尚未达到参考批准，凹洞和侵蚀未完成。海水与岩石仍采用高度包络边界，不能通过岩石悬沿下方。

实际固体阴影缓冲 2048 × 2048，主光随方向更新，中性模式和环境日照共用；辅光和轮廓光暂未实现独立投影。缓冲为临时数值数据，未保存图片资产。三检查模式保留，灯光不修改物体历史。

## 仍缺

R006 三维压力与粒网算子没有接入本版水体或烟；完整三维自由表面、体积烟流和燃烧化学仍待独立实现。烟火继续为已有未标定外观模型。深海仍独立显示，未提供本版数值入射条件。原严格共享 Schema/validator 未取得，完整共同规则验收阻断。
