# R04 执行顺序：普通螃蟹老师 → 椰子蟹修正

## 阶段 A：普通螃蟹老师完整表面

1. 校验 ZIP、glTF、BIN 和三张纹理的 SHA-256。
2. 读取所有 POSITION、NORMAL、TANGENT、TEXCOORD、INDEX、JOINTS 和 WEIGHTS。
3. 按完整三角连接和 UV 连续域建立参数曲面，不按骨骼或零件先拆造形。
4. 输出位置误差、法线误差、轮廓误差和六视图比较。
5. 静态表面未验收前，不允许用动画掩盖形体误差。

## 阶段 B：老师骨架和动作蒸馏

1. 读取 126 个 joint、父子层级和 inverse bind matrices。
2. 统计每个 joint 的顶点覆盖、权重分布和真实影响范围。
3. 对 66 条动画通道提取相位、幅度、左右配对与身体耦合。
4. 区分变形骨、末端骨和 IK 控制节点，不把 IK 控制器直接作为蒙皮骨。
5. 将公共能力写入 Crab Instrument；老师对象的具体比例和关键帧写入外部 Score。

## 阶段 C：最初椰子蟹完整性修复

1. 从最初老师完整表面重新确定统一静态形体。
2. 检查背甲、腹面、腿根、螯足根部、眼柄和口器是否存在裂缝、重复面、缺面或错误法线。
3. 先修连续表面，再建立椰子蟹自己的骨架位置和权重。
4. 硬壳主体近刚性；关节膜和附着区连续混合。
5. 不复制普通螃蟹的体形、腿长、姿态或完成动画。

## 阶段 D：基础生命活动

- 静息：轻微姿态维持、触角与眼柄探索、螯钳张力。
- 侧行：足端支撑相和摆动相、固定长度腿链、身体重心补偿。
- 转向：左右足链不同相位和步幅。
- 警戒：螯钳、身体抬升、后退准备和视觉朝向联动。
- 觅食：螯钳—口器—触角联合，不做单一部件循环。

## 阶段 E：验收

静态形体、表面、骨架、权重、动作、移动端和固定网址分别验收；工程测试不能替代用户视觉批准。
