# TEN24 原扫描恢复 · 2026-10-07

## 真实完成的部分

本轮从官方原 ZIP 使用严格 HTTP Range 读取目录及所需条目，没有重新下载整个约 2 GB ZIP。原 Blender 场景、HDRI、JPG 共 26 文件，解压后 300,113,494 字节，逐文件 SHA-256 与既有 72 文件清单一致。其余 ZTL、FBX、OBJ、TGA、PSD、TIFF 未获取；本轮不声称整个原包校验完成。

Blender 4.3.2 实际打开原场景，全部 10 原部件及 2/2 细分保留，原 .blend SHA 未改变。恢复历史 R10 接发并运行 R11 点/中点修复，拒绝 2 条不安全生成子发，保留 376 原导向，得到 13,998 条发丝。密度、截短、宽度、表面跟随及重置均经过本轮 Blender 求值验证。最终有限半径控制点/中点接触计数为 0；这不是连续样条/胶囊碰撞证明，也没有动力学。

对全部 10 原部件求值原细分 2，导出 4,935,456 三角形、147,446,880 字节几何。仅合并字节完全一致的位置/法线/UV 元组，未减面、改脸、补眼球、删透明眼层或替换耳廓。运行数据保留为私人文件，未上传仓库。

原材质、原贴图及接发已实际通过 Cycles 输出诊断画面：700×900、128 samples、无降噪。本次诊断输出不是原 2800×1216/4096 samples 的最终质量验收；源场景渲染设定没有改写。

## 仍未完成

- `runtime-import/` 是浏览器本地目录导入候选。原扫描资料不随公共页面分发，必须由用户选择私人转换目录
- 浏览器图形运行验收被环境/授权阻挡：shell Chromium 的 socket 被环境拒绝；云浏览器访问原模型需要额外明确授权。本轮没有伪称 WebGL 已通过
- 浏览器材质只映射原颜色/法线/粗糙度/反射图、透明眼层和分件；原节点曲线、微法线混合、SSS、眼球位移、Filmic 与 Cycles 光照未等价复现
- 浏览器接发为三角截面管线显示候选；与 Blender 原曲线着色不同，其长度/宽度修改后的连续碰撞尚未验收
- 设备需要支持 8192 纹理；导入前告知约 2–3 GB GPU/解码内存需求，用户确认后才加载。设备不足时不静默减面或降纹理。实测 Blender 诊断峰值约 4.4 GB，手机不能假定可运行

## 可复现恢复

仅把代码放在仓库。将输出父目录选在 Git checkout 外的私人位置，保留现有原男性和旧案例。已有本机 Blender 4.3.2 可直接使用，不自动安装或更改版本。5.2 的历史场景报告存在，但本轮工具的完整流水线测试版本为 4.3.2。

```text
python rebuild_private.py --private-parent "<现有私人父目录>" --blender "<已有 Blender 可执行文件>" --groom-data "<原工作台 qa/gnm-groom-editor/data/teacher-groom.js>"
```

工具创建全新带随机后缀目录，不覆盖原资产或旧工作副本。下载严格要求 206 和精确 Content-Range，每条目解压后校验 SHA；服务器不支持区间、原文件变更、Blender Python 异常或数值验收失败均停止。原件完整保留，路径只做等价重定位。源场景打开禁用 auto-exec。
