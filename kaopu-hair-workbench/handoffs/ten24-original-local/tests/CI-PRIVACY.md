# Temporary private CI technical test

This personal, non-commercial test acquires the free original directly from its author's public source into a fresh runner temporary directory. It never uploads or caches the scan, textures, Blender work copies, browser geometry or image buffers. No GitHub secret or additional repository permission is used. The job retains contents:read.

The official source permits personal projects and 2D/portfolio images, but prohibits model redistribution and commercial use of freebies without permission. This test exports no images at all: screenshots remain in process memory and are reduced to numeric pixel checks. Public artifacts contain only numeric test JSON. There is no anatomy-viewer product distribution or commercial-use authorization.

The runner checks the author's exact file hashes, preserves all ten original parts and original subdivision 2, and uses disabled auto-execution when opening .blend. A tested official Blender 4.3.2 download is pinned to its published SHA256. Blender and Chromium run in sequence. The test does not modify production entries or original male cases.

A WebGL2 capability probe runs before acquiring the scan. This verifies actual software WebGL execution in a disposable GitHub runner, not physical device/GPU performance. No existing cloud browser security setting is changed. Numeric checks cover original geometry/eye components, a nonempty frame, rotation, real groom controls, repeated import and GPU-resource counts. This is not human visual acceptance, material equivalence or continuous collision certification.

Temporary source/output data is cleared in an always-run cleanup step. Job timeout is bounded. No cache action, raw browser traces, video, screenshots or console buffers are retained. The artifact allowlist is *.json within a separate small result folder; each file has a size limit and rejects unexpected binary/source-payload extensions and base64 data.
