## 绑定与计算

完整人物运行时自带原生头部参数模板及到共同网格的精确顶点配方。F06仅把该模板用作稳定的毛根种子坐标图；不是加载或显示旧参考头。沿用的F02.1参数域函数保存在只读 `src/approved`，但实际根点、导向及接触查询都使用P01当前表面。

每个激活毛根的支持面都核对到共同人物的原生有向三角面，并按实际顶点次序调整重心坐标。3300个工程根槽中激活3067个，192条稳定导向；当前3067个激活根全部找到精确支持，没有缺失时的参考头回退。新共同网格绑定签名为 `b0f64ef`，原参数图种子签名 `a624b76f` 不再冒充最终人物绑定。

计算在Worker中使用当前完整人物的头、颈、肩及身体三角面。坐标通过眼眶和下颌原生支撑构成的刚性坐标架对齐，只做坐标转换，不缩放骨骼、改变体型或替换表面。根域投影后的工程面积约634.2812 cm²，是P01网格数值，非生物毛囊测量。旧参考头的范围批准不自动等于P01范围已被用户验收。

## 不与表现工作台重复建设

当前仍用基本线条检查结构，没有新增密发、材质、高光、风、惯性、发发碰撞或动态解算器。头部转动是继承人物骨架的绑定测试，不是毛发物理。

`design / rest / equilibrium / runtime` 分开；后面三项未求解时保持null。下垂设计曲线不是材料标定后的无应力参考或重力平衡。未来物理工作台需建立自己的状态，不能再把设计中的下垂当一次额外重力位移。

本轮完成的是同人物基础接入和可消费交接包，尚未修改独立质感/物理工作台，也未向其他会话发送消息。任意体型、换身份、复杂动作与动态碰撞未认证；当前三套方案的静态中心线检查不代表有限半径连续接触或发发自碰撞通过。

## 构建与复现

`python build.py` 下载并校验固定人物平台HTML；也可设置 `NATIVE_PERSON_HTML` 指向同字节的本机来源。Three.js来自该平台已使用的库，存于 `vendor/` 并核对SHA256；原许可保留。`ESBUILD` 可指定esbuild@0.25.0，`GITHUB_SHA`写入本轮源码提交。

发布采用分块压缩的原始运行HTML；每块与完整解压结果均核对SHA256，分块固定在独立提交。先生成并记录payload，再设置NATIVE_PAYLOAD_REF构建固定预览。这样大文件载入可分块重试，人物源码、材质和参数不变。

没有把人物运行时生成的表面顶点保存成生产资产。数值测试需要实际人物运行时的临时捕获：

```text
node tests/native-browser.mjs <本机或固定公网网址> candidate
node tests/native-core.mjs
node tests/native-browser.mjs <固定公网网址> public
```

浏览器测试将实际完整人物输入存入忽略的 `.build/native-input.json`，核心测试可用 `TEST_NATIVE_INPUT` 指定该文件。可选 `TEST_NATIVE_POSES` 指向实际原生头关节姿态捕获，验证真实人物变形后的绑定。没有数据时测试阻止运行，不退回独立参考头。

候选/公网检查包括实际完整人物、原生转头后换方案、保存与刷新、参考图、旧方案迁移、实际下载绑定包并重绑人物、静态原生面检查和手机视口。手机不是实机性能证明。原图测试为16×16纯色程序测试夹具，不冒充用户照片或发型参考成果。

截图来自独立无界面Chrome的真实WebGL；不控制桌面鼠标，不调用图像生成。公网交付状态与版本见 `DELIVERY.json`；证据不是用户美术批准。
