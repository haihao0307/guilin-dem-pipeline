**坐标不能混用。** 原人物模型内部还有Z向上的模型坐标；本包采用其三维viewer已经转换成Y向上的显示坐标。相同索引不代表坐标相同。消费方应调用 `nativeDisplayHead(model,viewer)`，不能把 `model.positions` 直接伪装成同一接口。人物viewer的mesh矩阵在绘制时只应用一次；包中的placement仅记录导出时状态，不替代消费方的当前人物矩阵。

```javascript
import {nativeDisplayHead,attachGroom} from './src/GuideExchange.mjs';

const {controller,viewer} = fullCommonWorkbench.motion();
const head = nativeDisplayHead(controller.model,viewer);
const attached = await attachGroom(head,pack);
// attached.guides[].points 属于当前完整人物的显示网格局部坐标。
// 渲染时沿用 viewer.mesh.matrixWorld，不能重复施加人物放置矩阵。
```

适配器核查目标、坐标声明、实际三角面数组SHA256、根点与权重、导向数量与有限数值。源模板顶点到共同网格的映射必须精确，支持面缺失时阻止接入；不悄悄投到另一个头上。

每条导向的局部位移由原生三角面的双精度边坐标架定义，和着色法线分开。预览每次绘制前从当前人物表面更新该坐标架，面编号和重心坐标保持不变。更新挂在scene的绘制入口，避免原生眉毛重建其viewer包装时覆盖毛发更新。改变方案从中立人物参考建立局部导向，转头后再换方案也不把中立世界点错误地绑定到已转头表面。

`coverage.bindings` 给每个激活根点最多三个同区域导向及归一权重。当前图搜索沿原生网格边，以参数域控制允许路线，以当前人物真实表面距离计权；不是连续精确测地线，也没有生成密发。跟随发构建和身体穿入检查由消费方另行完成。

本版测试覆盖P01静态三套长度、真实原生头关节的轻微转头和还原。任意身份、体型、表情极值与动作时的接触未认证；绑定稳定不等于物理质感或动态碰撞正确。
