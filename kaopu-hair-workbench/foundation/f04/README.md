# F04 · 重力下垂预设与提前接触避让

用户反馈 F03 后脑走向没有合理遵循重力，并要求自主检查、调整后交付下一版。F04 在独立目录迭代，F03 和已通过的 F02.1 生长域保持原样；本轮不代表用户已验收 F04。

## 设计与实际实现

`src/GravityPreset.mjs` 构建静态导向：世界坐标 Y 向下，出根角、近根梳理和释放后的下垂分别处理。由沿发丝弧长渐变代替旧版固定头部高度切换，后脑、后颈不再延续横向分缝场。近根保留原生绑定方向，梳理影响随弧长减弱。1 mm 等长步进，最长缓存 240 mm，按各区目标弧长截取；改长度保持前缀和其他区域。

耳廓、头部、后颈和肩部使用同一原生三角面查询。提前检查前方 12 mm 接触，再平滑偏转；近表面使用插值法线作防穿约束，不吸附发丝。最终仍用原三角面检查每段。构建的约 0.4 mm 中心线缓冲不等于有限半径发丝的连续接触证明。头部截断开口之外没有完整身体碰撞约束。

默认出根角由 F03 的 `[29,18,18,35,22,14]` 调低为 `[22,14,14,20,16,12]`，减少头顶拱起；弯曲过渡尺度默认 10 mm。新增“下垂趋势”和“弯曲过渡尺度”控件，均为静态造型参数，没有以 m/s²、杨氏模量等物理量标注。

这是一套重力方向驱动的静态参考构造，**没有新增动态解算器，不是材料标定后的静力平衡**。不存在风、惯性、发丝自碰撞或真实运动跟随。路径剪短不重新求整根平衡，因此不能把这个缓存结果直接当最终动力学。未来需明确 design / rest / equilibrium / runtime 状态，避免把下垂预设再次当重力位移叠加。

既有路线文档 `kaopu-hair-workbench/scalp/s01b/REFERENCE_DRIVEN_ROUTE_20261013.md` 仍是上层要求：参考证据 → HairRecipe → 原生绑定 GuideGroom → HairPhysicsState / DenseStrandRenderer。用户提供照片或名称后，由系统整理参考并做出完整可编辑发型；不应让用户自己逐条梳理。本轮只修基础稀疏导向，尚未完成参考照片发型、密发或根到导向覆盖映射。冠旋仍为人工方向参数场，不冒充实测毛囊方向。

## 验证与复现

`evidence/core.json`：默认和 14 个参数情形，原生中心线检查、3067 条 8 mm 探针、根点漂移、弧长、缓存前缀、版本迁移，以及默认后脑下垂与肩部转折检查。`evidence/gravity-comparison.json`：F03、相同旧出根角的 F04、F04 默认的几何对比。它们是指定情形检查，不证明所有连续参数组合。

`tests/browser.mjs <URL> candidate|public` 检查实际 WebGL、8 个观察方向、层切换、控件、保存、JSON 进出、过期任务、审计、拖动及移动视口。截图来自独立无界面 Chrome，不控制用户鼠标。手机尺寸是视口检查，未测手机硬件或连续动态帧率。交付版本与公开 URL 见 `DELIVERY.json`。

构建需要 Python、esbuild@0.25.0，设置 `ESBUILD` 可指向可执行文件；`python build.py`。`GITHUB_SHA` 写入来源提交。需保留相邻 F01 / F02.1 冻结依赖，构建会校验其哈希。`node tests/core.mjs` 默认读取构建产生的 head.json，也可用 `TEST_HEAD` 指定。浏览器测试可用 `PLAYWRIGHT_PATH` 与 `CHROME_PATH` 指定本机依赖；生成的 `.build` 和 head.json 不提交。
