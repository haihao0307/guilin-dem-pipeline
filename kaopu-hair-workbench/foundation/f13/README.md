# F13 · 参考发型、发丝表现与人物动作

按用户要求，将 F12 的参考照片造型接到毛发工作台的发丝表现和人物动作上，供下一步方向审核。保留 F12、原毛发工作台和人物平台所有者文件。

## 已接入

- F12 固定版本 `da948d38d8a14519a9ff56420a47417ddc69d720` 的完整 P01、共享皮肤 R02、13 个参考深度组、43 个子发束及 114171 条完整路径，每条 49 点。新材质不重新抽样毛根、不替换发型。
- 从本机 R08 独立快照复用毛发 R / TT / TRT 光照、单丝像素覆盖、跨原生皮肤三通道的透过率合成，以及原生骨骼动作、完整权重、细分祖先和 GPU 姿态缓存。复制文件及原始散列见 DONOR_SNAPSHOT.json。R08 当时仍在迭代，其旧发布元数据描述 R07，因此本候选自行验证，不继承旧检查结论。
- 在原始皮肤三角面的根坐标架中存储每根完整发丝。动作时，GPU 从同一人物的原生姿态缓存重建根位置和坐标架；人物、发根和头发均只应用一次宿主变换。
- 行走、跑步、跳跃；静止恢复、暂停、半速、四分之一速度、全身及头部多角度。近景相机跟随实际头部位置，跳跃时也可查看发丝。
- 自然黑、深棕、暖棕、浅金；完整头发、原分组着色、原半透明发块对照。页面以审核结果为主，原造型编辑器在本候选隐藏。

## 运动适配

每个 F12 子束选取一条实际完整路径作为运动代表，沿真实弧长重采样为 25 个控制点，接入复制的 R08 XPBD 弯曲、长度、身体代理接触与导向间摩擦。原造型保持独立；求解后的运动以相对中性平衡态的位移传递给原发丝。F12 的局部定型、活动权重和发泥配置参与位移权重，近根归零；主发束与刘海分别使用 35 mm / 8 mm 的平滑活动包络。

这是 43 条代表路径驱动的审核候选，不是 114171 根独立杆求解。导向的身体代理接触不代表每根显示发丝的有限半径连续碰撞已经通过。未接入 R08 的完整显示丝表面投影、远近多人系统或外物交互；不宣称材料标定、电影质量、逐丝自碰撞或实时性能达标。本轮也没有进一步修改 F12 的分缝、刘海大型或发尾层次。

## 验证

`evidence/verification.json` 记录实际浏览器检查。GPU 检查直接用正式顶点着色器读取横跨整头的 86 条发丝、4214 个点，核对静止完整路径及动作中的原生根位置；这不是所有发丝、所有动作的碰撞认证。真实截图与动作 GIF 来自独立无界面 Chrome，不操作桌面鼠标。失败的黑色输出和第一次近景跳跃取景问题保留为开发记录，不作为最终效果证据。

初次黑色输出由光源 Color 到 Vector3 的错误复制产生非有限值；已改为明确复制 RGB 分量。原生皮肤使用多通道合成，头发同时复用 R08 HairPassCache，避免在皮肤各通道重复参与散射。停止动作时刷新阴影；切换到近景时用头部实际变换重新定位观察目标。

## 构建与查看

在本目录执行 `node tools/build.cjs`，再执行 `node tools/serve.cjs`，打开 `http://127.0.0.1:8783/preview.html`。本机开发服务器仅把已缓存的人物资源映射到本地；公开页面不使用本机缓存或网络拦截。

`preview.html` 为完整可读运行页；`public.html` 为带长度和 SHA256 校验的无损压缩加载器，固定 payload 提交后发布。PUBLIC_BUILD.json 记录压缩部件、解压运行页和加载器摘要；PUBLICATION.json 记录不可变公开链接。构建依赖的 F12 运行页同样校验原始散列。

动作数据来源和原有署名见 [docs/MOTION-SOURCES.md](docs/MOTION-SOURCES.md)，人物、库和原平台声明见 [docs/CHARACTER-SOURCES.md](docs/CHARACTER-SOURCES.md)。用户参考照片未公开；没有导入新的外部发型资产。
