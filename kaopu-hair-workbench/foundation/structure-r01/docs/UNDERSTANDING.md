# 结构理解与开发边界 · R01

依据：用户提供的《KAOPU 程序化头发结构学习指南 R01》。原文保存在同目录，优先于之前 F14 的自然垂落方案。F14 留作未验收的旧实验，不把它的密集发丝、动力学或外观修复直接称作新体系。

## 十个问题的明确回答

1. **发际线、分缝、旋涡、普通头皮**：发际线决定生长域边界和边缘密度过渡；分缝是方向场的分离边界，两侧方向不同，不靠亮线或整条剃空表现；旋涡是带位置、旋向、半径和强度的局部旋转约束，中心允许有小范围低密度与不可定向点；普通区域承担连续梳理方向。四者分别进入域、密度和方向数据，不能用一个颜色遮罩代替。
2. **位置与方向分开**：位置由原生三角面和重心坐标决定“从哪里长”，方向在该处的切平面与法线组成“往哪里长”。梳理可以改变方向而不能移动毛囊；人物变形后，绑定更新位置和局部坐标，不能重新随机采样。
3. **不能全沿法线**：法线只代表皮肤朝向，单独沿它生成会形成刺猬和发帽。根方向要组合切向发流、适度抬升、分缝分侧、旋涡与耳周约束；离开头皮后还有沿整条 Guide 的空间梳理路径。
4. **必须分区**：刘海受额头、眉线和侧扫轮廓控制；顶部决定高度与分缝；侧发决定脸框和耳前/耳后路径；后枕决定后脑体积；后颈决定底边和颈部关系。它们可在边界平滑过渡，但长度、剪裁与束群的所有权独立。
5. **完整 Guide**：绑定毛囊 + 连续有序的根到梢曲线 + 弧长 + 各点切向及运输坐标 + 剪裁终点 + 区域和束群归属。只有头顶短箭头属于方向诊断，不属于完整 Guide。
6. **三级束群**：大束组织整体轮廓与主发流；中束组织刘海片、耳前/耳后和后枕片等可辨认分组；小束承载局部聚合与散开。子发丝必须保留根、完整 Guide 和三级父链，不能把彩色随机分组当层级关系。
7. **低频与高频**：轮廓、侧扫、绕耳、后枕体积和末端走向属于低频结构；卷曲、细小摆动与毛躁属于附加细节。先关闭所有细节检查 Guide；细节不能弥补错误轮廓。
8. **三种长度不能缩放**：耳边剪裁会改变耳周露出、内外层差和后颈底线；长发要绕颈肩并形成不同层次。必须分别拥有启用毛囊、长度场、剪裁场、Guide、束图、静止形态与物理配置。共享候选毛囊仅保证位置一致。本轮只建立一个当前长度结构，另外两版不自动复制或缩放。
9. **静态必须成立**：发型是输入给物理的静止目标与约束。重力只改变力学平衡，不能推断分缝、剪裁、刘海和束层。物理关闭时不成立，就没有可接受的静止目标，继续增加阻尼或风只是掩盖问题。
10. **根中梢不能相同**：根受绑定和梳理影响较大，中段维持形状和主要高光条带，梢端随剪裁、磨损和束群散开而变化。半径、聚合、色素、粗糙度和碎发概率要按实际弧长表达，参数变化保持连续。上轮“多数发丝保持等粗、只在末端极短范围收细”的规定不再作为结构标准；第二轮需同时表达根到梢连续变化以及不同剪裁端型，不能统一削成长针。

## 数据和阶段门禁

`HairStyleProfile` 是唯一发型入口。字段由 `src/HairStyleProfile.mjs` 定义；离线生成器读取它，输出带来源散列的结构数据。查看器只展示数据，不另藏一套发型规则。

第一轮输出：头皮域、十区、候选/启用根、方向场、分缝/旋涡、区域长度、完整 Guide、三级束图、灰色静态结构。完整发丝与物理保留为明确锁定的第二轮入口。Guide 的线宽只作结构可读性放大，不是实际发丝直径。

自动检查覆盖绑定、有限数、Guide 连续性/弧长、父链、方向分侧、旋涡影响和原生人体交叉。轮廓、刘海层次与照片对应关系仍须多视图人工验收；程序通过不能改写该状态为通过。第一轮视觉验收状态未确认时，第二轮代码不得启用。


## 2026-10-17 补充：批准生长域不能被造型系统二次裁切

保留原模块文件并不等于保留了实际生长域。必须核对最终映射网格、可生长根掩码和实际启用根，而不是把新设截止线写进测试后自证正确。F02.1 源图表曲线通过原生三角面/重心坐标映射；原生高度、头发剪裁高度、碰撞避让和诊断显示都无权重画这个边界。后发范围修复与防回退见 SCALP-AUTHORITY-04.md。
