# 静态侧后轮廓与耳前中束 · R08

本轮按[用户学习文件对照表](LEARNING-CHECKLIST-R08.md)实施“整体轮廓 → 完整 Guide → 中型 Wisps”。第一轮仍未全部验收，不解锁第二轮。原文见 `KAOPU_HAIR_STRUCTURE_LEARNING_GUIDE_R01.md`，字节校验由独立锁保护。

## 本轮实际改变

保留原九个状态，新增两个当前长度研究：

- **立体侧后轮廓**：以 R07 轻层次曲线为来源，保留原发尾高度和根部路径，在来源中束局部坐标下重设侧后下垂轮廓。
- **立体轮廓 / 耳前渐层**：再用同侧原鬓角的实际终点，确定耳前长束的渐层截止参考；鬓角自身不改。

每版仍为 165 条、每条 97 点；117 条主体下段参与设计，48 条刘海/鬓角保留全部几何。候选 3,300、合格根 3,067、启用根 2,737、后部 Guide 58 条均不变。新状态的根缓冲与原版逐字一致，实际 F02.1 分区网格与原生三角形/重心映射也不变。

## 与原有保护规则的关系

F02.1 生长域锁没有改。R06 的 85/50 mm 梳理规则和 R07 的前缀剪裁规则仍适用于各自原状态；没有为了本轮放宽它们。只有新的两个 `silhouette-*` 状态，由 `locks/silhouette-edit-r08.json` 单独授权下段重设与耳前渐层。

`locks/retained-studies-r08.json` 从本轮之前的固定提交 `4ca6c9a` 提取九个状态的曲线、实际束图、参数、根、分区和发缝等摘要。构建不自动刷新它。它是历史对照保护，不是将 R07 尚有问题的发型宣布为解剖或视觉权威。新的造型继续用新状态，避免把前面已确认的结果覆盖掉。

## 边做边检查的失败记录

1. 初版按分组名末尾判断左右，漏掉恢复区的 `/restored-domain` 后缀，造成部分路径换侧，最大移动约 145 mm。改为使用既有终点的实际材料侧别；增加恢复区换侧的拒绝例。Guide 数量和人体零相交都不能替代这条关系检查。
2. 初版只对终点做保持高度的排斥，个别肩颈末端出现约 57° 折角。改为平滑肩颈轮廓，并对全部可变点使用一致的保持高度修正，最终下段最大折角约 11.50° / 13.05°；回归限制为小于 20°，未将 57° 放宽为可接受。
3. 强度扫描发现需要明确零强度恒等，并避免耳前抬高量和混合强度重复相乘。现在零强度完整保留来源，起始间隙随混合连续变化；两版各 21 个状态，强度步进 0.05，最大点步进分别约 4.803 / 4.810 mm，无历史依赖。
4. 所有阶段保持原 Guide 数和毛囊，未用删发避免穿模。最终实际中心线人体相交为零，但没有因此声称自碰撞、有限半径或物理已经正确。

## 本轮证据与实际画面判断

固定模型截面 y=0.17 m 上，101 条后向路径都参与比较；落在旧 z=-0.083±0.006 m 平面邻域的数量从 80 降到 24。16 条耳前长束到同侧鬓角终点的中位距离从 51.65 mm 降到 15.52 mm。它们仅用于检查本次设计是否确实作用，不能作为自然度分数或所有角色通用标准。

新状态有两组 21 状态扫描、七个拒绝例、真实人体逐段检测、根部保护、材料侧别、实际弧长/标架及完整束图检查。原 R06 的 49 状态、R07 的 25 状态和九个历史状态保护继续运行。浏览器另核对 221 个实际绘制/可见性条目，新方案六机位、所有检查层、蓝线开关和导出，并绑定当前运行页散列。

本轮实际看过左右侧、背面和蓝色中束参照：侧后下段不再全部挤入原后平面，耳前末端的分级也更连贯。上部和耳周仍有局部交叉，稀疏 Guide 下的完整体积与中束外形仍需进一步审查。没有将静态自然发型写为通过，也不以增加发丝和改粗线宽遮盖问题。

## 研究与未完成的算法

继续阅读 [Example-Based Hair Geometry Synthesis](https://research.lvdi.wang/publications/hairsynthesis/2009_hairsynthesis.pdf) 的 4.1、4.2、5.3 节：完整曲线形状、局部相对关系和空间切向一致性要分别考虑。本轮仍采用项目自己的全曲线 complete-link 束图与下段作者轮廓；尚未实现论文的头皮邻域连通聚类、三维切向场重追踪或层级细节合成，不能把束图结构合格称为论文复现。

下一步先继续审查上部/耳周发流与中束空间连贯性，再落实原文中的边缘细毛、三套独立长度与子发。真实直径渐细、光学、有限半径/自碰撞和动态物理仍留在后续阶段；加载性能单独实测，未达标就继续明示。
