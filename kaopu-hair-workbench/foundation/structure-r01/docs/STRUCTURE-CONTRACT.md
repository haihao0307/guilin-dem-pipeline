## 数据所有权

| 数据 | 权威来源 | 约束 |
|---|---|---|
| 人物支持面 | inputs/native-input.json.gz | 原生 P01，保留拓扑、来源与适配器指纹 |

| Guide 与束图 | tools/compile-structure.mjs → assets/structure.json.gz | 完整根到梢，弧长和运输框架，显式 macro/mid/micro 父链与真实代表曲线 |
| 输入合法性和阶段门禁 | src/StructureContract.mjs | 浏览器和构建共同执行，拒绝缺字段、断裂路径、无效绑定和提前开启第二轮 |
| 显示 | src/StructureLab.mjs | 只读结构数据；诊断头皮片只出现在分区查看层，不用于遮挡错误发流 |

毛囊记录：三角面、重心坐标、位置、法线、切向、根方向、头皮参数坐标、抬升、直径、长度种子、卷曲种子、稳定阈值、区域、密度、启用状态。位置经绑定决定，梳理方向单独计算。Float32 保存带来微小舍入，不能称作无限精度。

头皮 UV 是当前对齐坐标上的诊断参数化，不是新的人体材质 UV。分区边界、旋涡位置、耳周路径和隐藏后脑的设计属于作者推定，不冒充照片测量或解剖标注真值。

完整 Guide 先在每个语义区形成较丰富的路径候选池，再用完整曲线距离选代表并做三次近似 k-medoids 更新。该有限池优化不等于全局最优，也不等于论文生成网络。根的候选覆盖与曲线代表选择是两个步骤。

束群按区域、分缝侧与路线分组；各层拥有成员和代表 Guide。小束细分在头皮位置上建立初始关系，后续仍需依据完整轨迹检查分束、合束及截面厚度。目前尚未实现全体积连通聚类或密集子发丝，不能以三级标签已存在就宣布束群美术通过。

区域长度以米表示完整曲线弧长的独立范围；剪裁场以空间终止边界表示。静态路径跟踪与约束平滑不使用动力学寻找造型，不调用 F14 物理、光学或密集头发代码。

## 第二轮进入条件

先完成第一轮多视图轮廓与参考关系验收，再另立变更：运输坐标中的子发丝、连续根梢半径场、聚合与散开、局部毛躁/婴儿发、根中梢光学差异，然后才是碰撞和惯性。三种长度各自持有最终启用根、剪裁、Guide、束图、静止形态和物理配置；当前版本不以缩放或截短自动生成另外两版。

第二轮必须测定关闭物理时的静止形态，重力开启后的保型、动作后弧长漂移小于 1%、人体接触、肩部滑动/堆积与束群响应顺序。当前静态中心线不穿人体的检查不包含有限发丝半径、发束自接触或运动保证。
