# 耳周完整束群 / S1.B4.1 · R13

本轮落实原学习文件 III.Level2/3、V.Round1：完整根—中—梢与有关联的中束。只处理当前长度，第一轮整体仍未验收。

## 问题与方法

上一轮只做了加载优化和三维诊断，没有改变耳周几何。顶部投影中 guide/2714 的交叉两段相隔约 17.33 mm，不能当作真实相交拉直；本轮该孤立 Guide 保留。另一个可处理的问题是：不同发根高度、不同长度的同束曲线，用相同归一化弧长聚拢时，段落实际高度不对应。

新增独立 EarRestField：在同一实际高度取得同路线、同原生根连接中束的下降段截面，只小幅聚拢 X/Z。较短成员进入/退出公共高度带时连续淡入淡出，不把耳前、绕耳、耳后或左右两侧混合。每束共用一个身体安全回退比例，避免逐节点裁剪造成折角，也避免每根各自退让破坏关系。保留有高度差的有效投影交叉。

这不是论文完整复现，不导入现成头发或人体；使用学习文件所要求的完整路径、层级关系与多视角校对原则。等高截面是本项目当前直垂造型的作者实现，不是所有卷曲发型的通用对应方式。
