# 显示修复与生长域恢复的区别

用户指出的是后发生长边界被抬高。最初将其主要解释为“分区层隐藏头发”判断错误，不能把显示可见当作分布正确。

分区切换隐藏完整 Guide 的独立显示缺陷也已修正：完整头发对象常驻，诊断和区域筛选仅叠加标记，默认查看完整静态结构，相机保持发尾在画面内。九层、多区域、多视角和故意隐藏/移除/清空绘制三个反例继续检查。

**本次真正的域修复、批准来源与防回退规则，以 [SCALP-AUTHORITY-04.md](SCALP-AUTHORITY-04.md) 为准。** 之前临时建立的 R03 错误域锁已删除，没有把那条高截止线固定为正确基线。
