# 静态结构修订 02

用户在阅读进度说明后要求开始下一步。本轮继续第一轮静态结构，未启用密集子发丝、质感、风或物理。

## 问题与修改依据

旧路径各自向终点收拢，下半段出现后颈交叉；部分旧启用根位于本次设定的头皮/颈部分界以下。原发束主要按根位置网格分组，未充分考虑完整发流。原相机还裁掉部分发尾，无法完整检查剪裁。

1. 保留全部候选根的三角面、重心坐标与位置，启用域与候选库分开。在继承域内增加 P01 专用的下发际线、鬓角过渡和 8 mm 密度淡出；这是作者设定的边界，不是扫描获得的真实毛囊图。当前停用 520 个旧启用点，候选身份未变。
2. 让每条 Guide 保持从根到梢的语义路线，区分耳前、耳后、后枕和刘海。离开颅骨后的下垂段不再持续朝较窄的后颈收缩。转向、层次及肩前/肩后的路线属于静态造型约束，不用重力寻找发型。
3. 区域剪裁由发根所在连续层次场控制，保留小幅稳定变化；未加入末端毛躁或真实根梢材质。低密度线宽仍仅为诊断显示。
4. 大束保留语义区与分缝侧，中、小束在路线边界内按完整曲线距离进行 complete-link 聚类。距离采用实际弧长比例上的 13 个采样，末段权重较高。每组保留真实代表曲线并验证父子包含关系。这是项目自己的有限离散实现，不是论文完整复现，也不是物理接触半径。
5. 相机按结构检查调整目标和距离，正、侧、背完整显示发尾。检查覆盖九层 × 六视角、十区筛选和三个束群层级。

`lowerWidth`、`lowerDepth` 和下发际线以当前 P01 的头部坐标及人体表面查询为依据设定，不能直接推广到所有人物。约束只作用于曲线，不创建可见发帽或体积壳。根部逐渐进入约束，避免低位发根被一步横向拉开。

## 保留问题

- 整体仍是稀疏静态导向线；不能据此验收遮盖、透明度或真实发尾质感。
- 顶部与耳周仍有投影交叉和局部转折，需要继续判断实际层次及曲率，不能只追求投影不交叉。
- P01 下发际线与区域边界仍需美术判断；其他人物需要独立标定。
- 没有足够完整的原始参考图片来验证正、侧、背一致性，未宣称发型还原完成。
- 第二轮保持锁定，R08 密集渲染及物理仍需按本结构适配。
