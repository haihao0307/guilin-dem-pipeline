## 观察、假设与权威

- 观察：本次照片可见偏中分、少量碎刘海、两侧圆润轮廓、肩部附近内收发尾。
- 推定：后脑截面、侧向厚度、发顶旋涡和隐藏发际线。采取低复杂度的平顺连接，保留修改入口。
- 工程假设：P01头部尺度上的截面和长度、近根过渡、0到1权重、活动包络、代理碰撞半径。不是生物测量或材料标定。
- 人物权威：完整P01原生运行时；形体和导向均增加在其场景上，不改所有者的人体/皮肤源码。
- 造型权威：HairDesign.recipe、HairVolumes、PortraitBob；参考图不自动重建，毫米数为作者值。
- 物理权威：未来消费方的求解器和标定；本版只提供可核查的交接约定。

## 失败和修正

1. 只给稀疏导向加宽，会留下发顶缝隙和条带轮廓，也不能直接代表整体体积。改为先放样大型，刘海独立保留原生根点。
2. 所有后脑导向都推向左右两侧，会把背面掏成不合理的V形。改为按根点方位分配环向截面目标，后脑保留连续体积。
3. 每段截面用零端导数的平滑函数，会形成可见的层层台阶。改为单调三次Hermite插值，数值核查连接处一阶连续。
4. 在肩部逐顶点推出，会令内外层折叠、发尾出现碎面。改为按环向列取肩部支撑高度、单调调整下部发尾，不颠倒放样行。
5. 分缝改变后复用旧覆盖，会让根点混到另一侧。每次造型编辑使覆盖缓存失效，按区域和分缝侧重算。
6. 权重颜色检查必须与实际活动程度一致；0.45自由度下发梢不会达到1.0的最蓝端。检查实际颜色差和固定根，不强求错误的色值阈值。

## 证据与后续

数值证据在`evidence/shape-core.json`，真实交互、导出重绑、分组、UV和材质替换在候选/公网报告。最终图片必须来自当前实际WebGL版本。分辨率、通过检查和截图均不等于用户已认可造型。

后续收到新视图时：只把可见区域提升为观察，不覆盖已有来源；收到表现资产时：先核对坐标、根归属、分组和UV，再比较替换前后轮廓，最后才调整材质细节。收到物理实现时：先校验固定根、段长、无应力参考与重力，再测试小动作、强风和极端姿态。
