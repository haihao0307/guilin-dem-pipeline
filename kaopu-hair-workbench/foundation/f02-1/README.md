## 用户要求与修改边界

用户确认 F02 其他位置没有问题，只要求剔除两张近景图中侵入耳廓的那一小片，让边界绕开耳廓、沿耳前接入鬓角。另询问黑点是否表示全部毛囊，要求快速修正后再次验收。

本轮没有重画整头范围，没有更改原生人物网格、额头发际线、头顶、已确认的后脑/后颈主体或旧短发，没有增加长发、密发与物理。用户截图和原参考照片未上传公开仓库，未使用生成图片作为几何依据。

## 实际代码

src/EarClearance.mjs 在当前原生 GNM 耳根前上侧定义小范围禁长约束。该约束只做减法，不新增生长区域；通过同一 growth 函数作用于填色、边界和根点激活。不是单独隐藏黑点或画一条新线。

边界采用无超调的单调三次曲线接续耳前到鬓角。首个候选的椭圆修剪出现额外小隆起，实际查看公网近景后改为更窄的连续轮廓，再完整重跑同一套回归检查。最终减去约 3.144 cm² 原生表面积，约原 F02 域的 0.498%；这些是目标网格工程面积，不是人的生理测量。

F02Boundary.mjs 是冻结 F02 源码的逐字复制。其 rootBank 被直接复用，3,300 个根点的编号、原生面、重心坐标、位置和阈值完整保持不变，签名仍为 a624b76f。最终只禁用局部 32 个原激活诊断点：F02 默认 3,099 激活，F02.1 默认 3,067 激活，禁用槽位保留不删除也不重新随机撒点。

对照按钮现在切换 F02 修剪前与 F02.1 修剪后，填色和实际根点一起变化。新增“耳前近看”“另一耳近看”相机，查看同一原生头部，没有替换成图片。原有全貌、前/后/顶/侧视角、局部微调、独立存档和 JSON 功能保留；新存储键 kaopu.scalp.F02.1，不写旧版存档。

## 黑点到底是什么

黑点是本轮用于检查生长范围与表面绑定的稀疏诊断根点。不是完整的人体毛囊分布，也不是已经生成完全部毛囊后仅隐藏大部分；完整密发尚未生成。页面图例、说明和数据字段已明确标注 diagnosticOnly=true、finalHairCount=null。最终发量不以这 3,300 个诊断槽位作为上限，后续密发应在已确认的有效生长域内独立构建。

## 核验

33 项内核检查通过。保留原回归门槛，并新增耳根桥接面检查：旧 F02 在选定 16 个原生耳根/缓冲带顶点上给出允许生长，新版全部排除；这些同样在默认和支持的编辑极值下保持禁长。此前只检查突出耳廓顶点的做法确实漏掉了耳根接续片，本轮增加该反例。

173,740 个原生三角面顶点/边中点/面中心采样检查中，范围变化仅发生在局部耳前禁长区，未发现范围外收缩或新扩张；额头场值直接保持旧版一致，已选鬓角主体点仍允许生长。该采样包含共享顶点的重复检查，不冒充同等数量独立场景或全部头型认证。

30 项候选浏览器检查及 30 项实际固定 HTTPS 浏览器检查通过；两者测试范围重叠，不相加冒充独立情形。包含实际 WebGL2 画面、新旧范围切换、两侧近景、其他视角、短桩、密度不重采样、局部微调、保存恢复、JSON 文件导入导出、刷新、拖动旋转、手机面板与无 JavaScript 错误。

已查看最终公网的耳前修剪后、另一耳近景、正面、后脑/后颈截图，并与修剪前对照；原先侵入耳廓的折角片已剔除，耳前边界接到鬓角。手机只验证 390×844 浏览器视口，不是实机。测试使用 Chromium/SwiftShader，当前是静态范围版本，不声称改进了长发物理性能。

最终公网导航至可操作的一次样本为 2.806 秒，不是对任意用户设备或网络的保证。HTML 为 1,412,903 字节。
