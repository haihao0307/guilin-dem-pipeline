# F12 · 连续梳理、细碎分缝与局部定型

用户指出 F11 头顶转折生硬、分缝过直过宽，并要求把发泥/凝胶带来的局部保型与活动区别落实为权重。F12 保留完整原生 P01、实际 114171 根头发、每根 49 个三维点和固定原生毛根，重做路径连续性与定型规则。

## 本次形体变化

F11 把不同高度的毛根过早汇入少数平均路径，近根归并和截面增长形成成排转折。第一轮试验只沿头皮走一段再混回旧场，产生了新的环状折痕；该失败接法已经移除。当前 RootFlow 让每个源点从自己的原生表面出发，沿连续梳理、头皮避让、下落及内收方向走完整条路径，没有中途接回平均大束的固定接缝。

前部偏分中心随纵向缓慢变化，根附近可有少量交叠；接近发旋时，左右梳理逐渐过渡为后向旋流。源区身份和原生绑定不动，几何发流可在近缝处交叠，避免把边界显示成宽直沟。没有覆盖头皮颜色、额外发帽或移动根点。

每束保留二维厚度及独立源区，横向变化沿路径运输框架展开。显示体积由同一根路径生成。65 个导出截面从实际体积测得，是观察包络，不是再次生成路径的唯一控制场；完整密集文件是逐根数据权威。

## 局部定型

StylingMap@1 包含自然未定型、柔性发泥、较强凝胶三种工程档位、整体定型量，以及分缝、发顶、刘海、发尾四个区域权重。可为一束设定根到梢的局部区间，边缘平滑过渡；零权重可放开某一段，毛根始终单独固定。

每个采样点分别得到 shapeHold、bendHold、twistHold、sectionHold、clumpHold、windInfluence、dampingWeight、mobility 和活动/扭转包络。改变定型只更新权重与方案，不重新生成头发形体。全部发丝权重视图中，红色较保型，蓝色较自由。保留灰色形体、分组、单束、源区、体积、截面及原生转头检查，并新增发顶近景。

这些是无量纲艺术控制初值，不是测得的发泥或凝胶参数。真实质量、弯曲/扭转模量与阻尼系数待标定；完整动力学、有限半径、自碰撞和大幅非刚性变形尚未认证。

## 验证

bundle-core 检查原生根、面积、实际截面、导向及交接；dense-core 检查实际全量路径、逐根绑定、静态中心线与格式；styling-core 检查档位、固定根、局部边缘、隔离、迁移与历史。浏览器检查包含真实全量 WebGL、局部设置、密度、扭转、原生转头、下载、保存恢复及手机布局。截图来自独立无界面 Chrome，不控制桌面鼠标。数值检查不代替美术审阅。

发尾长短层次：按本次参考的肩长外轮廓、内侧贴脸层与短顶层重新分配。LayerLengths 在头皮源坐标上给邻近毛囊连续的长短场；部分冠部发丝在耳旁或下颌附近自然收尾，保留另一部分长冠层和较低源区长层补足肩上轮廓。不把所有发丝延长至统一底边，也不在生成后裁一个壳。隐藏层与精确毛根分配仍属人工推定。界面可沿整根着色追溯短、中、长层，完整导出保留实际终点与分层方法。

体量与局部外旋：侧边、后脑及内层在同一源区连续路径上占据不同深度；主体横截面的厚度分布加宽，不将全部毛根归并成一层外皮。若干外侧及侧后发束中段逐渐外翻并回收，运输截面同步转向，根部与发尾平滑衔接。最大轮廓和真实人物表面避让另行检查，避免以突然横向鼓包冒充厚度。

按新提供的三分之四角度分组参考建立 DepthRelations@1：43 个原生源区子束各自属于一个参考深度组，颜色沿完整发丝和实际体积一致显示。记录局部遮挡关系及适用视角，避免把同色、左右或投影上的相邻误当成同一个深度。左颞侧路径向耳后过渡；较后冠部的外层支撑轮廓，更前的中层位于其内侧与前方；右侧保留更前的贴脸层，不镜像左侧。隐藏根区和精确深度保持推定标记。
