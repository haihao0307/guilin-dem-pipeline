# F05 · 基础发型方案与人物绑定交接

用户在 2026-10-14 明确要求：暂缓具体毛发表现、物理质感，另一个工作台处理这些内容；这里先用基础实现继续推进。F05 据此推进方案工作流和数据连接，不继续调发丝外观或新增动力学。当前 F04 页面被用作接续基础，不把这次指令解释成其美术质量已被验收。

## 已实现

- 三套基础长度方案：短发、中长、长发。它们是工程模板，不是参考照片重建的发型。中长保持 F04 默认参数。复杂参数折叠，主要操作是选择、命名、保存、撤销、重做和导出。
- `HairDesign@1` 把命名、修订、目标人物锁、F04 导向配方和参考证据放进完整文档。最多40步本次会话撤销/重做；保存和恢复保存完整文档，重做分支在新编辑后清空。导向计算失败时不提交待定文档；过期 Worker 结果不替换最新文档。
- 本机参考图关联：PNG / JPEG / WebP，12MB以内，最多12张。读取真实图片、计算 SHA256、保存尺寸和用户选择的视角。原图存在本机 IndexedDB，JSON 只保存证据记录，不含原图像素。原图丢失可重新关联同一哈希文件。当前保持 `unanalysed`、`hiddenAreas:unobserved`、`fitStatus:not-fitted`，不以“导入照片”冒充自动重建。
- `GuideGroom@1` 导出完整192条三维导向、原生面与重心坐标、局部坐标架、局部点位、目标弧长及3067个激活根点到导向的覆盖关系。同区最多3个导向，权重归一；导向自身毛根权重为1。覆盖映射按原生网格边最短路近似计算，当前没有未覆盖根点。它是数据映射，没有在这里生成密发。
- 提供不依赖渲染器或物理系统的消费适配器 `attachGroom(head, pack)`。核对真正的三角面索引 SHA256，再把导向还原到相同拓扑的头部。已验证原位还原及刚性转头、平移；非刚性头型变化未认证。

## 与表现工作台的边界

F04 的 `GuideKernel.mjs`、`GravityPreset.mjs`、`SurfaceQuery.mjs` 逐字沿用，构建时校验。原生灰模、灯光、毛根、生长域不改。没有新增材质、高光、密发、风、惯性、发丝碰撞或动态解算器。

导出包明确保存 `states.design = static-gravity-directed-reference`，`rest / equilibrium / runtime = null`，表现和物理扩展也为 null。表现工作台可以消费同一根库和导向；物理工作台仍需构建其自己的无应力参考与平衡过程，不能把已经下垂的设计曲线再直接当无应力状态施加一次重力。

本轮交付的是可消费接口和经过测试的绑定包，**尚未实际修改另一个工作台或宣称双方集成完成**。接口、单位、校验与接入示例见 [CONTRACT.md](CONTRACT.md)。未向其他会话发送消息。

## 复现与证据

需要相邻 F01 / F02.1 / F04 冻结依赖。`ESBUILD` 可指定 esbuild@0.25.0；`python build.py` 生成内嵌资源的独立页面。`GITHUB_SHA` 写入源码来源。缓存和大体积测试下载存于忽略的 `.build/`；不把用户原图或运行曲线大缓存默认提交 GitHub。

```text
node tests/core.mjs
node tests/workflow-core.mjs
node tests/workflow-browser.mjs <HTTP或HTTPS网址> candidate
node tests/workflow-browser.mjs <固定公网网址> public
```

`PLAYWRIGHT_PATH`、`CHROME_PATH`、`TEST_HEAD` 可指定本机依赖和原生头部。`evidence/core.json` 为继承导向检查；`workflow-core.json` 为新文档、覆盖和绑定检查；候选/公网 `report.json` 为真实浏览器操作。浏览器实际下载绑定包，再通过消费适配器重绑原生头部；报告保存下载文件哈希、大小和误差，不提交大下载缓存。

参考图测试使用16×16纯色程序生成的测试夹具，不是用户照片或生成发型证据。截图来自独立无界面 Chrome 的真实 WebGL，未控制桌面鼠标。手机仅检查390×844视口，未宣称手机硬件或动态帧率通过。固定版本、URL和交付范围见 `DELIVERY.json`。

## 明确限制

网格边最短路是离散表面距离近似，边中点允许3mm域外缓冲，候选顶点允许8mm缓冲或必要的原生根三角面顶点；不是对精确裁剪生长域的连续测地线证明。跟随发生成后仍必须独立检查头耳肩穿入。这里只验证已有静态导向中心线，不代表有限半径连续接触或发发自碰撞。

超过当前截断胸肩的长发无完整身体约束。参考图不自动决定造型；背面、内层和物理材料参数不会由文件名或视角记录自动推断。
