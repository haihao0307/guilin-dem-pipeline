## 实际代码

src/BoundaryKernel.mjs：由原照可见鬓角尖端、耳前上升段、耳上轮廓、耳后连接和侧后颈位置作人工观察，转成当前原生头模耳周的 YZ 控制轮廓。不是用旧的全头帽状阈值继续扩大圆洞。原 F01 的耳上候选边界约在 Y=.329，而当前原生耳廓顶部约在 Y=.301，造成留白过大；F02 候选轮廓已收向耳廓上方，并向下延伸鬓角和耳后。

原前额 |atan2(x,z-.015)|≤.60 的场值直接调用冻结 F01 原函数；.60–.90 范围仅作颞侧接续。前额编辑锁定。SIDE_PROFILE、OBSERVATION 和微调参数分开保存。模型毫米只表示目标头模编辑量，不是照片的实测尺度。

边界、填色、根点激活读取同一生长函数。边界附近细分原生三角面并求交，仍保存原生面编号和重心坐标。F01 2,400 个根点的 ID/面/重心坐标/位置/阈值完整保留，另外补充 900 个稳定槽位到以前漏掉的侧后区域。默认激活 3,099 个；诊断数量不是生物毛囊数。旧根签名 b5672c1d，新总库 a624b76f。

src/App.mjs：同一原生 GNM 17,821 顶点、35,324 三角面。可以切换 F01 原域和 F02 新域，实际填色、面积与激活根点一同切换；可叠加旧边界虚线。提供正侧面、照片近似侧向、另一侧、后脑、正面、头顶；允许旋转/缩放、根点查看、透明度、密度和短桩探针。短桩仅检查根点位置，不是新短发造型。没有运行新的物理模拟。

src/Worker.mjs：初次构建和边界编辑离开交互线程，复用根点库，拒收过期任务结果。耳上、鬓角、后颈有小范围微调；本机存档键 kaopu.scalp.F02，JSON 导入前验证拓扑、前额锁定和数值范围，不写旧 F01/短发存档。
