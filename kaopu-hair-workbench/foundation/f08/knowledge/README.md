# F08 · 头皮根区驱动的发束知识与失败记录

## 用户已明确的规则

先描照片，分析层次；再从已通过头皮范围中的根区开始，沿明确方向连续长到发型终点。刘海从额头上方毛囊范围长出，不能脱离发际线。分组必须对应完整发束的起点、路径、终点，不能将一个壳按高低切几块来代替。所有人物绑定在完整的清俊 P01 上继续，不回到参考头。

发束形体以半透明形式检查；外轮廓要允许符合造型的逐束外突与长短错落。当前优先结构和形体，表现材质、密发丝与真实物理由后续工作衔接。

## 观察和补全分开

正面照片：偏中分、左斜刘海、中央少量碎刘海；贴脸长层在外长层内部，肩附近有内收；并非齐平帽壳。线稿保持照片原始 688×832 坐标。隐藏根区、后部深度、耳后内层、后冠和后颈层均是推定，不能说成单张照片已经提供的信息。

补全规则：后上层从后冠/上枕沿后脑向后下，侧后层与可见侧面长度接续；后颈内层走短路线并被外层遮挡。尽量少引入未经看到的卷束或装饰；新背面照片到来后允许替换这些假设。

## F07 被否定的原因及本次修正

- 原 HairVolumes 按截面先造封闭壳，再按高度/方位给面上色。名字虽叫分组，却没有从根区长到梢的整束对应。F08 不再调用或渲染该模块。
- 刘海单独细带与外壳是两套几何。即使根点数值误差为零，视觉上仍可能脱离发际线。F08 每条从 native 根点贯穿到底，带的中线与导向完全一致。
- F08 第一次路径实现直接追逐过渡点，在到达过渡高度后可能围着目标盘圈。实际侧视图暴露了此问题，虽然没有穿面。修正为持续下行的方向场并逐步切换侧向目标，增加所有导向确实到达终点高度、弧长不过长的检查。没有用穿面测试通过掩盖路径错误。
- 一圈相同长度会制造齐整壳边。现在长度随各根稳定变化，少量外层使用较大的侧向铺开目标，变化连续地从固定根发展到中梢部。

## 函数归属

BundlePlan：根区互斥、组内配额采样、完整组到终点的契约。PortraitBob：每组从根到梢的方向场和独立终点，调用同人物 SurfaceQuery 静态避让。GuideKernel：根探针、连续采样、静态审计。ShapeView：同路径半透明带/线/根点检查，不参与决定路径。GuideExchange：同组覆盖、原生坐标重建和校验。NativeApp：同一个原生人物场景、一次 placement、真实头部随动。StyleRules：工程活动权重，非物理求解器。

## 既有研究的使用边界

此前记录的 [Disney Hair Pipeline](https://www.disneyanimation.com/publications/disneys-hair-pipeline-crafting-hair-styles-from-design-to-motion/)、[Tonic](https://disneyanimation.com/technology/tonic/)、[Hair Meshes](https://www.cemyuksel.com/research/hairmeshes/hairmeshes.pdf) 仅作设计、导向、模拟和表现分层的参考。它们不能证明本项目任意外壳分面等价于发束分组。当前明确以用户要求的根区到完整发束链为生成权威；没有复现上述论文完整算法。

[Holding the Shape in Hair Simulation](https://history.siggraph.org/wp-content/uploads/2022/09/2019-Talks-Iben_Holding-the-Shape-in-Hair-Simulation.pdf) 作为此前保型规则的原则来源，当前依旧不声称完成材料或预载标定。

## 核对证据

数值：真实 P01 网格、原生根点、独占根区、连续段长、终点、静态穿面、同组覆盖、错误数据拒绝。视觉：照片叠线只在忽略的私人 QA 目录保存；公开线稿不含原图。真实 WebGL 截图覆盖正面/侧面/背面/头顶、单组刘海、半透明/透视和转头。通过测试不是用户美术验收。
