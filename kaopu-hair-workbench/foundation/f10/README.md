# F10 · 有截面厚度和连续扭转的根区发束

本版修正 F09“虽有盖面、看起来仍像薄帘”的问题。在完整「清俊 P01」上，先裁分头皮源区，再长成有宽度、厚度和截面转向的发束。用户照片及用户分束示例只作人工三维造型参考；此前被否定的助手手绘分区图不参与生成。

## 本次自查与修正

F09 的刘海终点偏平直，中央碎束过宽；长束近似平行薄帘，缺少照片中两侧鼓起后向肩部收拢的形体。仅有根绑定、闭合盖面或中心线避让，不能证明发型正确，更不能证明发束有合适的体积。

F10 将斜刘海改为向画面左下斜梳、不同位置分别结束；中央保留少量小束。贴脸源区向颞侧扩展，侧后层补长，减少内外层断开的空档。主体路径在面颊外逐渐铺开，再向肩部内收。补厚后又收小了侧向路径，避免厚度与宽度叠加造成新的鼓包。主体子束到接近发梢才逐渐收拢，避免提前分离成粗绳。

当前仍是人工造型初稿。刘海边缘与小束衔接仍较概括，不能据技术检查声称与照片一致。背面、遮挡根区、侧向深度和照片裁切外的发顶体积属于推定。最终细发丝、贴图、材质和物理不在这一版中完成。

## 生成结构

六个层组保留前额刘海、左右贴脸层、左右外层、后脑及遮挡内层。它们先分为 11 个头皮主源区；默认分缝下再裁为 **43 个有独立源面积的体积子束**。子束数可随分缝变化而减少：没有面积的根区不建立虚构的空束。所有裁分均发生在已通过的原生头皮小三角形上，不是在头发外壳上给面片分组。

完整头皮源面积仍约 634.2812 cm²，3067 个工程根样本和原生发际线没有改变。源区和子束边界继承当前所有者，不在边界点重新分类。每个体积顶点保留原生三角面及重心坐标，生长进度为零时精确落在自己的头皮源点。

每个子束建立 65 个沿路径分布的椭圆截面。源区的两个内在坐标映射为截面中的二维坐标，因此宽度与厚度是独立维度，不是单张带子的正反面。近根按原生表面方向出根，再平顺汇入完整发束；主体截面保持体积，末端逐渐减小。实际显示几何的中段宽度和厚度另行检查，不只检查参数声明。

截面先沿中心路径作最小旋转平行运输，再叠加少量人工造型扭转。弯曲改变路径切线，扭转围绕该切线转动宽度轴与厚度轴；二者不混为世界坐标的随机摆动。`twistGain` 调整造型扭转，零值仍保留路径弯曲所需的截面运输。该参数不表示正在运行物理扭转模拟。

## 查看方式

默认显示 28% 不透明度的体积代理。整组和独立子束均可选择，能查看本束真实头皮出发面积和目标数量。支持正面、两侧、斜前、后脑、头顶、完整人物及抬高视角的“体积”检查。

“显示体积截面与扭转方向”显示三个截面环：白轴为宽度方向，橙轴为厚度方向。它们是辅助标记，完整发束体积始终是主要对象。“不透明轮廓检查”使用同一三维几何，打开深度写入，便于识别鼓包、空档和截边；它不是最终头发材质。

源区盖面只在显示时沿原生法向抬高 0.8 mm，避免与高密度皮肤互相遮盖。真实 source cells、毛根绑定和导出根点不抬高。

## 人物、数量与交接

人物仍是原生总平台提交 d413d108704af47cf531ee8c25d93f682c3176e3 的完整 P01，公共拓扑 25417 顶点 / 50624 三角面，原生渲染 266098 顶点。人物网格、骨架、面部、皮肤、眉毛和 viewer.mesh 保持原平台所有权，毛发跟随同一实际表面。

默认密度 180 根/cm² 是可调工程目标，总预算 114171 根，非照片测得的毛囊数。数量先按主源区分配，再按子束源面积分配整数余数，子束之和等于父源区数量。同一原生 source cell 面积 CDF 可生成稳定、可复现的最终根绑定。当前显示体积，尚未生成这些密集发丝。

`GuideGroom@5` 使用新的 `bundleVolumes@2` 扩展：包含子束根区映射、65 个真实三维截面、宽度轴、厚度轴、扭转角、原生锚点和整数目标数量。导向由同一截面场生成，并对中心线局部避让原生身体；密集发丝与完整有限厚度接触仍由消费方检查。导出路径、控制点和截面统一转入 `native-common-viewer-Yup`，内在头皮图表坐标保留为独立元数据。详见 CONTRACT.md。

`StyleRules@2` 补充 `twistHold`、`sectionHold` 和允许扭转角包络。它们是无量纲工程优先级，非真实扭转模量；材料弯曲/扭转模量、无应力参考和动力学状态仍为 null。
