# HAIR-FOUNDATION-S01 — 头皮生长域与根点诊断

基线：guilin-dem-pipeline@c89ebc4da8d24ef3decfad85336c5dffb2c471c8（R14.2-L03）。本版本只新增 foundations/s01，旧发型、L03 性能工作、人物总台和其他工作台不改；保持 Draft，不合并、不强推。

本阶段是可交互的基础诊断候选，不是新发型，也不是已经确认的解剖分割。使用原 GNM 3.0 中性模板的 17821 个顶点、35324 个原三角索引。灰模仅为看清结构的诊断显示，不把它当作 ET18 皮肤/眼/唇画质升级。

## 学到并落实的范围
SideFX 官方工作流 https://www.sidefx.com/docs/houdini/fur/workflow.html ；Guide Groom https://www.sidefx.com/docs/houdini/nodes/sop/guidegroom.html ；Hair Generate https://www.sidefx.com/docs/houdini/nodes/sop/hairgen.html 。学习的是生长域/属性/导向/密发分离。没有复制 Houdini 代码、HDA、商业发型或运行时，不声称复刻其全部工具。

运行时读取显式顶点标量蒙版和独立密度属性，不按新头部的世界坐标再猜发线。原始发线通过中性头上的作者样条初始化，保留作者控制点和方法，不冒充医学分区。初始边界仍需用户视觉验收，能用表面画笔改正。三角形内以线性标量的零等值线作为连续边界；面积对裁切后的多边形计算，不把整片跨界三角形都算入。距离从边界交点沿原网格边 Dijkstra 传播，是边路径近似，不是精确连续测地距离。

候选根点池在原皮肤上按面积随机提出，再以表面弦距作硬间距拒绝。固定种子与原三角面/重心坐标；显示密度、短针长度、相机和同拓扑形变不重撒根点。根点池包括未激活的面部/颈部候选，只在正蒙版内显示；候选池的点不全是真正毛囊，不能用其数量声称真实密度。生物毛囊单位聚组尚未实现。弦距不等于精确测地间距。

支持生长域/边界/距离/密度/灰模/根点/法线短针/测试切向，真实表面点选根 ID，沿连通网格边的局部蒙版与密度画笔，撤销重做，本机保存/读取、JSON 导入导出和严格拓扑/数值检查。短针沿皮肤法线，是可视化标记，不是头发曲线或完整碰撞证明；测试切向箭头只是正交切向检查，不是已完成的生长方向场。

横向变形仅为同拓扑绑定压力测试，不是完整身份参数迁移；不同拓扑必须另做映射。不自动接入总平台 SharedWorker；当前独立诊断文档与窗口显示状态分离，S01 本机存储有独立键。
