数值门槛与范围

根部误差 < 1e−7；每段相对长度误差 < 0.2%，整条弧长 < 0.1%；胶囊与体表穿透上界 < 0.00045（模型单位），接触违规数必须为 0。弯曲残差 < 0.01 rad，根颈残差 < 0.005 rad。

尚无残差数据

相邻且属于同一触手的局部连续胶囊不彼此碰撞；根部有限附着领区允许与自己的口盘相交。范围外的整段胶囊均参与验算。以上是有限容差的离散接触，不是跨时间的防穿越保证。

耗时是当前设备上测得的 CPU 求解时长，不是 FPS、GPU 时长或硬件性能保证。求解受限时会减小推进量；无法通过门槛时保留最近合法姿态。

当前最大差异

本页用新的共同放射外展引导构建合法接触母本，没有复用 r03 的曲线形状。摄影参考中的肉质簇、局部不规则弯曲与环境仍未还原；接触母本和参考外观仍需视觉核对，不能因数值门槛通过而视为形态验收。

薄组织透光只是局部厚度衰减与定向散射近似，不是完整 SSS。没有生成小丑鱼、实测生物收缩、连续碰撞检测或完整流固耦合。
