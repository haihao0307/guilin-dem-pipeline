原始 bunnyUV.json、cloth.json、纹理与渲染模块内嵌在文件中。未使用外部 CDN。模型不是独立程序生成的成品资产。
对照方式
两边使用同一份未改动的老师渲染与着色器模块。工作台替换外围界面、离线资源加载与输入适配；为可重复比较，两个视口固定相同的 Fin 随机 UV 种子。初始相机、光照、参数与模型相同。“同步老师”还原至当前老师对照值；“完整恢复源码默认”还原模型默认参数、灯光、相机与梳理方向。原始源码附在源码包内。绑定适配层修复了原框架对无效属性位置 -1 的调用；原始着色器和模型字节不变。
真实功能与边界
可编辑层数、毛长、波浪、Shell/Fin 纹理缩放、Perlin 持续度与频率倍率、毛色、光照、高光、渲染层和 GPU 梳理。源代码的 textureDensity、diffusePower 与 shadowsEnabled 没有接入有效绘制，因此本页没有将它们列为可用功能。当前没有独立动态阴影、长发物理、碰撞、骨骼蒙皮、触手或 Unity/Unreal 导出。
离线与设备
用支持 WebGL 2 的现代浏览器打开本 HTML。拖动旋转，滚轮或双指缩放；选择梳理后在工作副本拖动。4096² 噪声纹理初始化可能耗时。采用按需绘制、1:1 CSS 像素渲染；本机验证不等于实机 iPhone 验收。若文件管理器只展示静态预览，请选择在浏览器中打开。
保存什么
导出 JSON 保存数值参数、模型、相机与光照。GPU 梳理方向暂不写入参数文件，导入会还原原始方向。保存视图导出当前工作副本 PNG。
