# HAIR-FIBER-R03-S1 / 动态颗粒专项，单帧覆盖实验

2026-10-14。用户已认可R02静态材质，要求优先消除运动颗粒。本轮是实际运行时开发；R02固定网页、全部光学参数、10000根/80段曲线、根库eaadb8b8和批准头皮保持不变。只新增本目录与专用CI，沿用Draft PR272，不合并、不强推。

## 实现与取舍

先实现上轮方案A：无随机二值取舍的单帧覆盖。按像素足迹计算细丝连续覆盖率，将-log(1-alpha)分配到相邻的8个深度层，再由前向后组合。层间分配连续，不突然跳层；颜色在同层内混合，末层容纳更深贡献，是有界近似，不是精确OIT排序或完整体渲染。

光学函数从R02冻结shaders.mjs直接导入；单丝R/TT/TRT、吸收、粗糙度、灯位、能量标定、原阴影均不调整。先在810000个原曲线节点计算当前辐亮度，沿原细丝插值。亚像素丝沿用R02稳定seed的截面光学；可分辨的粗丝计算四个截面位置并插值。该辐亮度插值有近似误差，不能声称逐像素与旧着色器数学上完全相同。

渲染用加宽的像素足迹承载抗锯齿，物理直径仍为原参数且参与面积积分，不把头发加粗成不透明线。没有整屏模糊，没有减根或更换发型，没有动作缓存/固定距离LOD。

R03-S1默认不读取任何旧颜色帧；优先检查单帧能否压低颗粒，因此本阶段没有实现运动重投影。不会以简单保留旧帧换取拖影。几何缓存和辐亮度缓存分开失效，曝光只改显示映射。光源巡游按时间而非按帧加角度。

## 对照与测试

页面可切换R03连续覆盖、R02单样本、R02的16样本静帧。导入原随机覆盖与原光学着色器作同几何A/B，不用生成图片。新增相机往返和原灯光巡游；两者都是显示测试，不是发丝物理。

12项本地数值/冻结哈希测试已通过。浏览器测试在实际WebGL执行后记录单帧相机和灯光姿态序列、回到原视角的重复性、单样本与32样本参考、四材质、逆光、近看、曝光失效和手机视口。序列按固定姿态逐帧测，不等于实时30/60fps证明。最终状态以当前DELIVERY.json和evidence/public.json为准，不继承R02绿勾。

本地容器Chromium未建立WebGL上下文，未把JS语法和本地数值通过当视觉通过；实际GPU绘制交由本轮CI的Chromium/SwiftShader执行并保留原始画布。SwiftShader是软件显卡，不是用户独显或手机实机性能。需实际检查是否保留已认可的发色/光泽/通透和细丝，测试全绿不能代替美术评审。

## 现实边界

8层缓存、节点辐亮度、全量细丝重绘有显存/带宽成本。光学插值、深度层混色以及近景截面采样可能改变高光细节；相互交叉与新显露区域必须检查。若单帧质量/速度未达标，应继续改渲染，不先上复杂物理。时间重投影、真实弯扭/碰撞、整头发型、EB1和WebGPU不在本阶段完成清单。
