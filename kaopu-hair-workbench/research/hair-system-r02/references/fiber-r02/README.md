# HAIR-FIBER-R02 — 一束头发，质感优先

用户于2026-10-14批准实际制作，并明确顶级质感是首要任务。这里只制作可观察、可调参数的独立三维发束，不更换人物，不修改已通过的 F02.1/F03 头皮、生长范围或其他工作台。沿用研究分支与 Draft PR272，不合并、不强推。

## 实际实现

10000条稳定种子的空间细丝，17个相关小束，80段中心线、发梢渐细和少量游离发。每丝独立位置、切向、粗细和色素差异，不使用发型图片或头发贴图。逐丝窄带是渲染原语，真实丝径和亚像素覆盖补偿分开。根库eaadb8b8是合成光学夹具，不是假称完整生物毛囊，也不来自批准头皮。

公开技术依据为 Chiang/Disney 及 PBRT 4e §9.9 的纤维散射方程，自写GLSL计算R、TT、TRT和更高阶内部路径，带方向性分布、折射、吸收和鳞片倾角。RGB/log-I0近似、三方向灯、八层透光深度和少量艺术性束间补光不是完整光谱路径追踪；高阶内部反射也不等于束间多重散射。

GPU缓存全部810000个曲线节点，仅改形状时重算。基于实际几何的随机覆盖和深度缓冲选择可见细丝，再在屏幕空间做复杂散射；16次确定种子与亚像素采样减少轮廓噪点。样本完成后停止持续绘制，修改参数/视角即丢弃旧历史，GPU fence完成后才计已出画。这里没有动作缓存、LOD分档、删减发量或WebGPU运行时。

网页可旋转、缩放、近看；同一几何切换自然黑、栗棕、蜜金、银白，正侧逆光、曝光、发丝粗糙度、细微游离发和分项R/内部路径检查。保存按钮写入本机参数，本轮不宣称已经实现重开页面自动还原。

## 视觉复核后的修正

第一轮真正通过浏览器的e144候选并未直接作为美术完成：检查实际截图发现栗棕过浅、补光掩盖束内暗部。后续候选把栗棕吸收改为[.40,.80,1.30]、束间艺术补光系数由.045降到.008、所有材质共用灯光标定系数.35。保持原根库、曲线、视角、曝光不变，不靠切换发型掩盖差异。系数是本轮美术实验值，不是生物测量。

## 验收状态与限制

固定HTTPS和本地候选分别用真实浏览器检查，不以基础单元测试或JS启动冒充渲染。每次截图使用16个实际完成样本；另检查非背景像素、GPU节点非零、源提交、材质保持几何、真实颜色变化、反射/透射分项、遮挡、近看、旋转和390×844视口。最终交付以DELIVERY.json及对应public.json为准；其source必须对应本轮源码，旧版本通过不能自动继承为新版本通过。

本轮是光学候选，不含弹性杆、动态接触、人体/衣领、整头发型或EB1接入。光源巡游只移动灯光，不能当发丝物理。有限采样可能有颗粒，曲线分段和发束层次仍需改善。没有电影级美术通过，也没有普通集显/手机60fps的证明。测试SwiftShader是软件显卡，CPU提交时间不是GPU时间，GPU fence墙钟也不是独显基准；手机只验视口，不是实机。

先保留和验证单丝光学知识，之后再学习和改进束间散射、轮廓稳定、真实发束结构与动力学；不会把本样本宣布成最终整头毛发系统。
