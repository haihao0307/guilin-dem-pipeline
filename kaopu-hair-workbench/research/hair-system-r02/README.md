# 柔顺发束 R02：男士中长发与长发

本版是两个独立发束检查入口，分别以 14 cm、34 cm 为长度基准，保留自然长短差异。检查对象是头发的质感、分束和运动，不是整头发型。没有底绒、针毛分类或毛皮填充层。R01 与人物工程保持原样。

- `preview-medium.html`：男士中长发束。
- `preview-long.html`：长发束。
- `preview.html`：默认中长发，可在页面切换。

三个入口都是可离线打开的完整单文件实时三维页面。也可运行 `node tools/serve.cjs`，访问 http://127.0.0.1:8766/ 。

## 本轮真正重做的内容

毛根改为有厚度、有弧度的椭圆生长区域，不再沿一条平直切口排成矩形带。每根显示发丝在 shader 中使用四条导向发的归一化空间权重；24 个主束中心提供从零根部权重逐渐增加、到发梢适度散开的聚合。导向曲线先平滑，纤维微小变化再沿随曲线运输的局部法向与副法向生成。柔顺度控制相关微弯和游离细节，聚合程度可单独调节；不通过加粗丝径、贴图或模糊整张图来遮掩结构。

运动取消了 R01 对各节点原始世界位置的弹簧拉回。现在包含重力、横向/纵向不同的空气阻力、固定毛根与生长方向、沿实际长度衰减的根部支撑、具有方向的局部内禀曲率、分段质量和变细导致的弯曲刚度差异。弯曲约束以带状矩阵求解，长度约束以全链耦合投影求解，减少逐节点迭代次数对整体刚度的影响。两种长度使用同一类方程，实际节长、质量、弯曲柔度和惯性不同，不只是把同一动作缩放。

保留 R05 的逐丝 R/TT/TRT 和内部路径近似、81 个光学节点、连续像素覆盖及 8 层合成；增加有限距离的三点线光源近似，使细丝切向与柔和高光相互配合。阴影仍为中央光样本的 8 档深度透光近似。

## 怎样检查

先看两种长度的整体、近看和侧面，再试自然黑或栗棕。可单独调整柔顺度、分束聚合、丝径、粗糙度及光位。点击“局部拨毛”后拖动实际发束位置并松手；“拨动一次”施加瞬时速度；“轻摇发根”只移动固定端，由求解器产生中段和发梢的滞后。“查看根梢权重”显示根部弯曲支撑的连续衰减，红色强、蓝色弱。

`qa/motion-comparison.gif` 是两版在相同发根轻摇输入下的真实 WebGL 连续帧，分别求解、分别拍摄；不是把截图平移或用曲线播放器模拟运动。`qa/*-full.png`、`*-macro.png`、`*-pointer-grab.png`、`*-weights.png` 等供交叉复核。浏览器报告记录当前源文件与预览的 SHA-256。测试和数值收敛不代表用户已认可柔顺观感。

## 实现与限制

10,000 根长发，80 段/根；85 条导向，33 个非均匀分布节点/条；固定 120 Hz 求解。导向的实际长度约束与显示发丝的加权插值分开，不能以导向长度误差推断每根显示丝均严格不可伸长。局部曲率求解使用冻结运输坐标的线性化近似，不是完整弯扭 Cosserat 杆。有效束刚度、空气阻力、阻尼与梳理曲率是本样本的工程/美术先验，未测量标定。没有逐丝自碰撞、束间接触或人体/衣领接触。

单文件使用 WebGL2 浮点渲染，需要相应浏览器支持。显示的已完成帧墙钟包含渲染等待，不是纯 GPU 时间或通用帧率认证。手机检查仅指视口适配。

## 源码与复现

- `src/specimen.mjs`：两种长度、弧形根域、稳定根库、主束中心、导向初始曲率。
- `src/physics.mjs`：重力、有效束刚度、根梢支撑、弯曲与长度耦合求解、抓取和根部驱动。
- `src/shape-shader.mjs`：四导向权重、主束聚合、曲线平滑、运输坐标、丝级残差。
- `src/app.mjs`：光学、光照、交互和参数连接；这是当前直接维护的入口。
- `tools/build.cjs`：打包三个单文件。使用工作区已有 esbuild；换机器可安装 esbuild 并调整依赖路径。
- `tests/physics.mjs`、`tests/browser.cjs`：物理和实际页面交互检查。
- `tools/capture.cjs`、`tools/motion_gif.py`：后台渲染和实际动态对照，未控制桌面鼠标。

`tools/archive/prepare-r02-initial.py` 仅保留初次适配过程，不用于覆盖当前维护的入口。失败候选仅在本地 `qa/` 中留档，不进入运行时。详细方法、原网页观察和来源见 [研究记录](docs/research.md)。Three.js r169 的 MIT 许可随 `references/fur-r02/THREE-LICENSE.txt` 保留。
