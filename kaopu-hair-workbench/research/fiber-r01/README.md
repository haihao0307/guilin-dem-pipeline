## 研究结论与下一实验

先分离「批准的生长域 / 发型静止形态 / 单丝光学 / 动力学 / 绘制与采样」。形态从参考图和既有规则来；光学和动力学不能反过来移动已批准的毛根。

第一优先级是同一束发丝的材质对照：发丝方向高光、内部透射及吸收、发束遮挡、轮廓亚像素稳定。保持形状、曝光、相机和灯光可对照，再改变光学参数。第二优先级是同一束头发的摆动、停止、接触和回弹。两者过关后，才把能力装回同一已批准头皮上的完整发型。

工作台验收仍必须是固定提交对应的公网 HTTPS、真实三维、实际交互与版本检查。研究文档、数值探针、AI 图或旧 F03 网页均不替代新的发丝质感验收。当前没有新网页链接，电影级交互成品尚未交付。
