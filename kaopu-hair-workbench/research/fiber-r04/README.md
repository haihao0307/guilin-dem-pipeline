# HAIR-FIBER-R04-FUR1 — 自有毛领运动逻辑移植到原发束

用户指定 Humanoid-Rig-Lab-Next@e845835b3e04c56a65c405ff87aece955b161b4d/fur-workshop/r02/preview.html，要求借用其流畅自然的毛发运动，保持本头发研究质感。本轮不是重新研究方案，而是实际移植候选。交付与测试以 DELIVERY.json 和 evidence/public.json 为准。

## 源码事实

FUR R02 C3 的构建源为 f0fa23fc92ae3848be9dca7dd29ac56a0b782b74；app.js SHA256 8515146fbf1e788a70624a8aee47dc9a2a1b597405c9013e057c5b6e5e3f5842。其 integrate(dt) 是固定1/120秒的有界导向毛梢弹簧，回复系数33、阻尼8.5；风场是若干相关正弦作用力，局部拨动加外力。GPU将导向偏移按t²传给细丝，根部不动。它不是完整弹性杆、逐丝自碰撞或长发衣物碰撞系统。它流畅还与渲染架构有关，不能只移植弹簧就保证原头发复杂光学同样流畅。

## 本轮接入

在原17个发束横向区域上构建17×5=85个导向状态，通过连续双线性绑定给每根独立发丝传递运动。保留源弹簧/阻尼/风作用力、35mm界限；法向限制转到向下生长的样片坐标。增加抵达位移界限时的向外速度消除、暂停、关风后回落、本地屏幕拨毛范围与复位。空间导向分布是头发样片适配，不是复制毛领几何。局部拨毛采用导向投影近似拾取，非真实手指/碰撞工具。

CPU求导向，GPU更新曲线、切向、阴影和光学。CPU固定步长循环不必等待上一帧GPU完成；绘制只保留一个未完成帧，避免积压。极慢设备仍会丢弃过长时间间隔，droppedSeconds显式记录；不能用慢放伪装实时时间。形变按t²叠加，所以不是严格不可伸长杆；此轮不声称长度、扭转或碰撞已解决。

原R02的10000根、80段/根、eaadb8b8根库、发色、丝径、粗糙度、三灯、纤维光学函数全部保持。R03连续覆盖与8层透明合成继承，不搬毛领深色底绒/不透明遮底/简化着色。81点光学模式用于锁定静态回归；另提供21点沿丝光学插值实验，几何仍80段，公式未换，有限采样误差必须与同状态81点图量化。不是固定距离LOD，也不是动作烘焙；不把近似模式说成逐像素完全一致。

## 可复用模块和边界

motion.mjs：不依赖Three的导向弹簧，可单元测试。
motion-shaders.mjs：根绑定、GPU动态位置、原光学采样适配。
runtime.fragment.js：本轮交互和调度桥接。
prepare.py：对哈希冻结R03作有检查的派生，展开可阅读app.mjs与index.html，不修改原文件。
build.py：组合锁定Three r169与本项目模块，输出自包含网页；无需CDN、外部模型或毛发图片。

运动模块与光学模块的输入输出分离，后续可接骨骼最终姿势/批准头皮，不新建人物。现在仍为单束验证，不接人体或EB1，不覆盖原网页。独立研究分支/PR272保持Draft，不合并、不强推、不改gh-pages。

## 本轮验收

要求真实GPU根不漂、毛梢变化、局部拨动后耗散、微风开启的原生循环有实际新帧、原静态81点与固定R03参考图对照、21/81点普通/近景差异、四种材质、逆光与手机视口。既要看误差，也要看细丝和高光有没有变软；图像误差不是电影质量或运动自然性的证明。实际源毛领网页另作独立读取/启动微风记录，不把毛领性能外推到头发。

本地10项运动数值测试已通过；CI补齐冻结基线、真实WebGL、固定HTTPS。没有目标用户显卡或手机实机，软件显卡只能发现功能与成本问题，不作为硬件帧率认证。代码/网页成功不等于已达到用户顶级质感目标。
