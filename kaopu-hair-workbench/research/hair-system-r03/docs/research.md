# R03 光泽与风中运动修正记录

## 用户要求

换白色背景，修正特定角度下黑发变白、栗棕发像金属的问题；先研究真实头发在风中的运动，再修正中长发 / 长发的刷状整束运动。继续排除短绒逻辑。

## 观察、来源与解释

2026-10-15 读取并检查以下第一方资料；仅借鉴原理，没有使用其中的发型、视频重建模型或图片作为本系统材质。

1. [Xu et al. 2014, Dynamic Hair Capture using Spacetime Optimization](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/12/2014_haircap.pdf)，[作者的演示说明](https://www.microsoft.com/en-us/research/video/dynamic-hair-capture-using-spacetime-optimization-2/)：检查论文图 1 的真实受风发型与图 13 的真实动态帧；正文强调相邻发丝可能运动不同，以及过度平滑会抹掉动态细节。图 1 的受风照片中外层 / 梢部能分离，整体走向仍连续。视频网页需要 cookie 同意，本次没有把它写成已完整观看的视频。论文重建效果与真实输入照片分别辨认，不能把重建的成束条带当成真实参考。
2. [McAdams et al. 2009, Detail Preserving Continuum Simulation of Straight Hair](https://graphics.cs.wisc.edu/Papers/2009/MSWST09/hair-mcadams.pdf)：粗层运动与细层相对运动应区分；过少导向或把所有发丝绑定到同一个平滑体会丢失细节。本版采用这一职责区分，没有实现论文的 FLIP / 自碰撞算法。
3. [Selle et al. 2008, A Mass Spring Model for Hair Simulation](https://www.andyselle.com/papers/9/)：逐丝交互和分束之间的区别；真实相互摩擦、碰撞与粘附是独立物理职责。本版仍不含这些接触功能，因此不声称“完整真实头发物理”。
4. [PBRT 4, Scattering from Hair](https://www.pbr-book.org/4ed/Reflection_Models/Scattering_from_Hair)：头发外界面为粗糙介电体，表面反射可近乎无色，发色主要由内部吸收决定。由此推断：黑发出现少量中性反光正常，大片变白需要检查能量、光源角度分布与显示映射，而非简单把高光涂黑。

最初两个固定网页的来源仍见 `references/manifest.json`，R02 的历史实现保留在原独立目录与原公开提交中。

## R02 实际分项诊断

重新渲染 R02 的完整 / R / TT+TRT 模式，结果暂存本地 `qa/before-*.png`。黑发 R 分项出现大片银灰反光，栗棕的内部项也形成大块金白色。代码检查发现灯光高能量、窄且近乎同步的切向高光、较浅栗棕吸收和逐通道 ACES 压缩共同促成这一结果；没有发现 MeshStandardMaterial 的 metalness 开关。不能将其诊断为“metalness 设置错了”。

运动检查发现 10,000 根显示丝主要共用 85 条导向与 24 个固定吸引中心；局部残差很小且几乎静态。气流在整束内高度相似，导向物性也基本相同。这解释了像平滑刷片移动的观感。

## 最终实现与归属

|职责|实现|近似 / 限制|
|---|---|---|
|纯白背景|光学 resolve 输出预乘发丝颜色与覆盖率；显示阶段先处理发丝亮度，再与背景合成|白底不受曝光压灰；边缘半覆盖发丝自然与白底混合|
|柔和反光|`optics.mjs`，五点有限软光源平均，放宽粗糙度与方位分布|有限样本积分；透光阴影用中央灯位近似|
|保留发色|`specimen.mjs` 色素吸收；显示按共同亮度压缩 RGB|RGB 实时近似，未做光谱 / 测量匹配|
|减少固定刷片|`shape-shader.mjs` 默认聚合 .22，并在末端显著释放|仍有作者设定的梳理聚合|
|整体风响应|`physics.mjs`、`wind.mjs`，空间连续的平流扰动、横向阻力、暴露程度、导向直径变化|程序风场与遮风权重，不是流体求解|
|每根丝相对运动|`detail-dynamics.mjs` 两个横向弯曲模态，固定步长受力积分；shader 在运输坐标重建|20,000 个模态、每个两个横向坐标；不是逐节点完整弹性杆，也不严格约束每根显示丝弧长|
|强风稳定与回落|模态几何硬化、阻尼；停风继续积分|硬化为降阶模型近似，无真实接触摩擦|
|检查视角|整体、近看、侧面、发梢；微风可单独启停|微风连续帧固定发根，没有用发根摇摆代替|

导向质量使用非均匀节点的相邻段长计算，EI 有效束系数从 8 降到 3，作为当前样束的作者设定；不当作实测头发杨氏模量或粘附量。

## 检查过程中的修正

- 第一轮仅减照明会让样束过于暗、近乎哑光；重新平衡共同光能，并保留宽而柔的中性光泽。
- 第一轮局部模态仍携带较多共同偏移；改为相对粗层风响应，独立灵敏度与刚度种子，局部位移可向两侧分开。
- 强风下稀疏游离长丝的降阶位移过大；加入几何硬化，避免直接按预设时间曲线夹紧位置。
- 独立 HTML 打包曾把 JS 中的 `$&` 当字符串替换标记展开，导致脚本错误。本地服务器补载模块掩盖了问题。改用替换回调，并用语法解析和真实 file URL 打开两种 HTML，确认无外部脚本请求。本次不忽略该错误。

## 实际证据与验收边界

`qa/browser-report.json` / `interaction-report.json` / `standalone-report.json` / `optics-report.json` / `wind-report.json` 关联 `BUILD_MANIFEST.json` 的源码与 HTML 哈希。物理报告分别检查根固定、长度、释放、长短惯性差异、局部相对位移、停风衰减、暂停和强风有限性。

光学只统计不透明内部像素，避免把白底或半透明发梢误算成白发；同时保留实际截图供目视检查。144 组检查并不穷尽所有角度或参数，也不证明观感已完全真实。连续 GIF 由真实 WebGL 帧缩放拼接；没有生成图片代替运行效果，也没有控制用户桌面鼠标。
