# R06 性能与连续距离显示

测试使用后台 Chrome、RTX 4070 Ti SUPER / ANGLE D3D11、1500×1050 窗口。用户桌面的鼠标未被控制。GPU 使用计时查询，暖机后分别测带发与仅载体的完整绘制；差值是头发额外 GPU 时间的估计。CPU 是 180 次每次 1/120 秒更新的平均，不含画面绘制。实时帧率另测。结果会随系统负载与显卡时钟变化，约 60 FPS 也受刷新率上限限制。

## 工作量如何随距离变化

毛囊和种子顺序固定。屏幕投影面积决定可见前缀预算，数量在约 120 ms 时间尺度内趋近目标，逐丝淡入/淡出。覆盖率用透过率补偿维持远处发量，直径仍是原物理直径；发型没有替换成发片或另一套模型。屏幕尺寸同时决定曲线采样，整根长度保持完整。共享发丝预算为 128,000，加上各头部少量淡入边界；视锥外不绘制。投影采样是工程配置，不是严格的曲线屏幕误差界。

远处不推进 192×25 导向接触及 128,000 逐丝细节模态。每个载体各有四个受力坐标和速度，风场按其世界位置取样，停风先衰减。最近对象接近时从同一静止场平滑回到当前导向、原生根与可见丝细节。刚进入精细范围时从低维状态暖启；焦点过渡也渐变。测试台目前只有一个精细求解器，不代表多个近处人物已有彼此独立的完整物理。

## 缓存与内存

`RestFiberCache` 将原有四导向加权静止曲线一次写为 25 个局部空间样本 / 丝。RGBA16F 缓存约 12.8 MB，由同一发型所有载体共享；没有为每人复制一张缓存。远处顶点通常读取相邻两个缓存点；近处仍用完整加权导向和当前接触。量化误差、同构建直接/缓存 GPU 样本和画布差异见 `qa/cache-quality-report.json` / `qa/cache-visual-difference.json`。

`HairPassCache` 对全部可见头发合计只画一次，并复用于原人物 full / diffuse / albedo 三阶段。屏幕缓冲为画布宽×高×8 字节，跟人数无关。原生人物动作的完整位置与 3×3 法线/形变矩阵也只按可见姿态计算一次，MRT 为约 12.8 MB，按需创建。导向固定矩阵、根局部更新和逐丝风场谐波缓存继续复用。

## 正确性与边界

`qa/character-report.json` 检查人物绑定、两款发型、多视角/颜色、风后衰减、原生待机、人物切换、移动布局与真实采样器阶段上限。`qa/motion-contact-report.json` 检查走跑跳、落地、蓬松外物接触、原生缓存位置/完整矩阵，以及外部矩阵/缩放和快速相对扫掠。`qa/cache-quality-report.json` 检查同一毛囊/几何跨距离使用、一次共享绘制、远处停风休眠。图形错误修正及基准人物隔离见 `HOST_COMPATIBILITY.json` 和 `docs/research.md`。

48 个测试载体来自原人物基础头型，材质用于检查头发遮盖；只有主人物为原完整平台。这个压力场景隔离了头发数量，不测 48 套独立高精度人物、动画、网络或不同发型资产。身体包络仍是近似，显示接触不等于逐丝自碰撞。数据不构成所有硬件或多人项目帧率保证。
