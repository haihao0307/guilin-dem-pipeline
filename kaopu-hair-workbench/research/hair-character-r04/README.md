# R04 · 两款完整发型接入人物总平台

本轮把中长发与长发从孤立样束改为完整发型，直接加到已有“人物总平台 · 整合审核版”的原人物网格上。头、眼睛、皮肤、眉毛与身体继续使用固定原平台运行时；新增头发全部由源码生成，没有导入发型模型、短绒层或头发图片贴图。

- 偏分中长发：偏分发际线、侧扫头顶、耳侧层次、后脑与颈后收短。
- 中分披肩长发：中分、前侧面部框架、后脑连续披发与长发尾。
- 自然黑 / 栗棕、白背景、前侧后与分缝检查、微风启停、原生人物待机、六个人物预设均保留在可交互页面中。

本机完整构建入口为 `preview-medium.html` 与 `preview-long.html`；公开入口为 `public-medium.html` 与 `public-long.html`，只对同一 HTML 做无损压缩传输，运行前验证解压后的摘要。发布地址见 `PUBLICATION.json`；完成公开验证后记录在 `PUBLIC_VERIFICATION.json`。可以拖动旋转、滚轮缩放。原生待机首次点击会加载已有平台的动作数据。

## 实现入口

| 职责 | 源码 |
| --- | --- |
| 当前人物头皮取样、原生三角形重心绑定与 morph 跟随 | `src/NativeHeadBinding.mjs` |
| 分缝、生长区域、梳理方向、长短层次与四导向权重 | `src/Groom.mjs` |
| 重力、惯性、弯曲、段长与碰撞约束 | `src/GuideDynamics.mjs` |
| 逐丝受力的两个横向细节模态 | `src/detail-dynamics.mjs` |
| 连续空间风场 | `src/wind.mjs` |
| 当前头部径向表面与原身体截面近似 | `src/CollisionProxies.mjs` |
| 发丝几何、覆盖率、柔和介电体光泽、原生光源 | `src/HairRenderer.mjs` |
| 人物平台接口与发型选择 | `src/app.mjs` |

192 条导向、每条 25 个节点；64,000 根显示发丝，每根有独立种子和两个受力细节模态。导向与显示丝都参与碰撞近似，发根读取原网格的当前 morph 变形结果。发丝色素吸收与中性界面反光分开处理。

`references/character-platform.html` 为原平台固定运行依赖，摘要见 `references/CHARACTER-PUBLICATION.json`；许可与原有资产来源仍沿用原平台记录。复制的原生表面查询器保留在 `src/SurfaceBVH.mjs`，Three.js 依赖保留其原许可声明。没有修改原人物工作目录。

## 本机检查

`node tools/build.cjs` 重新装配三个独立 HTML。当前机器的 esbuild、Playwright、浏览器及原平台资源缓存路径配置在工具文件中；应用网页本身不依赖这些本机路径。

`node tools/serve.cjs` 启动本机检查服务器。它仅在本机响应中把固定 GitHub 资源改写到原平台已校验缓存，公开 HTML 保留固定 HTTPS 来源。

`node tests/detail-cache.test.mjs` 检查缓存谐波与直接风场求值的数值一致性。`node tools/test-character.cjs` 在后台浏览器检查两款发型、多视角/发色、微风与回落、真实人物待机、人物切换、移动布局和 GPU 程序。`qa/character-report.json` 关联最终构建摘要；截图与动画帧均来自真实 WebGL 页面。

## 验证边界

这是可运行的发型与人物整合候选，仍需用户判断发型审美与真实感。材质参数、导向有效束刚度、遮风和体积支撑为作者配置，没有做真人测量标定。头部径向表面与身体截面不等于完整三维 SDF；身体截面适用于当前静态身形和轻微待机，不覆盖任意肩臂大动作。没有逐丝自碰撞、摩擦、湿发粘附、完整多次散射或深度透明阴影。显示丝降阶模态不严格保证每根显示丝弧长。

普通单层阴影图在密发上出现块状投影，本版没有把它当作正确的深度透明阴影继续使用；头发接收原人物灯光与阴影，头发向皮肤投影暂未启用。白底半覆盖边缘会混合白色，但这不等于黑发色素变成白色。

研究、失败修正与依据见 `docs/research.md`。数值测试和截图不构成影视级真实感认证。
