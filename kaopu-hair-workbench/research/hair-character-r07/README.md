# 头发 / 人物接触 R07

两款原有完整发型：偏分中长发与中分披肩长发。保留同一个原生人物、白背景、程序化毛囊、行走/跑步/跳跃与连续距离采样；没有添加短绒毛、外部头发贴图或替代发型模型。

本版重点是人物接触、黑发遮盖与远处运动。头部接触直接绘制当前人物的完整细分几何，动作复用原生 GPU 姿态缓存，待机复用原始几何和形变存储。身体接触使用原生皮肤三角面生成的六向深度/法线场。这是保守表面近似，不是精确体积 SDF。

显示发丝按发根到发梢依次限长、检查线段接触并滑动，避免只把端点分别推出身体后，让中间的线段穿过脸、耳朵或肩颈。该缓冲只保留一份，随当前关注人物复用；远处关注人物也继续执行较少采样的接触。

导向束使用重力、杆弯曲、长度约束、身体相对速度摩擦，以及相邻导向束的空间哈希接触与库仑滑移。近处导向更新为 60 Hz。参数属于工程调校值，尚未按具体真人发质测量；显示丝没有独立求解每根的质量、扭转和两两摩擦。

远处每人保留四个方向、共十二个受力坐标与速度，响应风、行走/跑步/跳跃的线性、角向和向心惯性。离开近景时拟合当前导向位移及速度，接近时用远处状态暖启。毛囊顺序固定，以投影大小连续调整可见数量、采样和细节权重。

密发使用实际合成透过率识别内部覆盖，内部完全遮盖底色；单丝抗锯齿、稀疏边缘与真实缝隙仍保留。黑白背景 GPU 对照检查见 `qa/surface-opacity-distance-report.json`。

## 运行与检查

在本目录运行 `node tools/build.cjs`、`node tools/serve.cjs`，打开 `http://127.0.0.1:8771/preview.html`。服务器复用已在本机保存的人物资源。

完整检查：`python -X utf8 tools/run-final-checks.py`。额外细分表面检查：`node tools/test-refined-surface.cjs`。所有浏览器检查均在后台运行，没有控制桌面鼠标。

独立接触检查读回最终 GPU 发丝位置，检查端点与线段。常规检查针对 40,120 个原生皮肤基础三角面；细分检查读取原生 GPU 姿态与完整绘制索引，对发丝周围实际细分表面单独检查。详细范围、阈值和原始结果在相应 JSON 报告中，不能把抽查解释为所有动作、所有发丝的数学无穿透保证。

## 范围

压力场景包含一个完整原生人物和最多 47 个原生头部载体，不是 48 套独立完整身体、骨骼或联网角色。一个关注对象使用精细导向；其他对象使用独立简化运动。外物通过两个椭球接触入口接入；人物和外物采用单向运动输入。没有湿发黏附、逐丝自接触、头发投射深度阴影或多人联网开销的完整实现。

当前构建摘要在 `BUILD_MANIFEST.json`，发布地址与不可变提交记录在 `PUBLICATION.json`。源人物保持原始数据，头发基于 R06 的独立副本修改，未覆盖原 R06 或其他皮肤任务。

耳廓外侧另有依据原生耳部范围建立的保守支撑，按自由发长渐入，避免粗导向束钻入很小的耳褶后无法保持长度。最终显示丝仍对实际人物细分表面执行接触检查。
