# HAIR-FIBER-R02 — 一束头发，质感优先

2026-10-14。用户批准开始实际制作，并明确顶级质感为首要任务。本轮独立发束光学候选；原 F02.1/F03 生长范围、人物和其他工作台均不修改。延续研究分支与 Draft PR272，不合并、不强推。

## 实际实现

10000 条稳定种子的独立空间细丝，17 个相关小束，80 段连续参数曲线、末梢渐细与少量游离发；不是头发图片或大张透明贴片。渲染原语为逐丝相机朝向窄带，物理直径和亚像素覆盖补偿分离。发样是合成光学夹具，不冒充用户照片发型或真实生物毛囊数，也没有从批准头皮移走毛根。

以 Chiang/Disney 和 PBRT 的公开纤维散射方程为依据，自写 GLSL 计算 R/TT/TRT 与更高阶内部路径，轴向散射、周向分布、折射、吸收和鳞片角偏移。当前使用 RGB、log-I0 近似、方向光与可调的束间散射近似，不是完整光谱路径追踪或完整论文性能复现。只增加普通塑料双高光不能等同这一路线。

三个光源的八层累积透光深度，实际从同一束几何绘制；静帧 MSAA 与 16 次亚像素积累，换颜色/视角/形状时清除旧历史。达到样本数后停止持续绘制。四种材质预设不改几何种子，正侧逆光与反射/内部路径分项可对照。没有为好看的截图换模型或上传 AI 生成图。

## 当前边界

本轮静态光学优先；没有弹性杆、动态接触、整头发型、人体/衣领或 EB1 接入。光源巡游只是光照观察，不冒充头发物理。多个透光层仍为近似，浅色发的束间能量和复杂环境尚未标定；艺术效果须用户评审。没有运行时 WebGPU。几何细丝数量固定；没有整头高低模切换，也不宣称完整连续资源调度器已经完成。

需要 WebGL2 浮点渲染和硬件加速。测试软件显卡不证明真实独显/集显帧率；手机截图只代表视口尺寸而非实机。镜头切换、换光与高分辨率都有计算成本，不宣称电影画面与任意设备60fps同时达标。
