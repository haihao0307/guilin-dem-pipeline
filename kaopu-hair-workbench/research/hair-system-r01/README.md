# 头发材质与运动样束 R01

当前仅制作长发样束，供质感和运动检查。2026-10-15 根据用户纠正，移除了毛皮样片、底绒、针毛分层及相应几何分支；没有通过隐藏短绒或使用底绒填充来遮底。

直接打开 `preview.html`，或运行 `node tools/serve.cjs` 后访问 http://127.0.0.1:8765/ 。单文件预览包含运行依赖，不需要联网获取纹理或模型。

## 当前结构

10,000 根独立长发，每根 80 段。稳定根库、长发长度差异、丝径差异、相关弯曲、少量游离长发、逐丝渐细与色素变化。原来的三模式弯曲已替换为 85 条、每条 25 节点的导向链。两个根部节点固定；以 120 Hz 固定步长积分外力，交替投影局部形状及长度，最后进行沿链长度重建，再更新速度。

用户可切换四种发色，调节粗糙度、丝径、微卷、光照、风、刚度、阻尼；可在实际鼠标位置抓取发束并释放。参数可导出。渲染亚像素覆盖与真实丝径分开处理。

## 已检查与边界

- 后台真实 Chrome / WebGL 渲染，截图位于 `qa/`，没有控制桌面鼠标。
- `tests/physics.mjs`：固定根部与根部方向、导向链长度、有限位移、释放耗散、局部作用、暂停、固定步长输入一致性。
- `tests/browser.cjs`：实际页面指针抓取、GPU 毛根不动、根库稳定、释放恢复、光学分项、最大风力及暂停。报告记录对应源码哈希。

长度约束针对导向链；显示发丝通过空间插值跟随，不能因此宣称每根显示丝均严格不可伸长。静态形态是作者设定的平衡梳理形态，没有生物物性测量标定，也没有完整重力平衡求解、扭转杆、逐丝自碰撞或人体接触。R/TT/TRT、8 层合成、RGB 吸收与深度透光均为实时近似。测试通过不等于用户美术验收。

## 文件与复现

`src/specimen.mjs` 管理长发根点和梳理形态，`src/shape-shader.mjs` 管理长发曲线及导向位移采样，`src/physics.mjs` 管理运动，`tools/prepare.py` 将冻结的 R05 渲染入口适配到当前模块。`python tools/prepare.py` 后运行 `node tools/build.cjs` 构建单文件。构建器使用本机已有 esbuild；换机器可安装 esbuild 并调整对应依赖路径。

来源 URL、冻结提交和源文件 SHA-256 记录在 `references/manifest.json`；当前构建哈希记录在 `BUILD_MANIFEST.json`。
