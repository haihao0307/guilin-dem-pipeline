# HAIR-FIBER-R05-M3

用户否决R04效果，要求继续迭代。本轮保持已认可发丝光学，改进长发运动自由度、真实鼠标位置抓取和重复绘制开销。状态以DELIVERY.json/evidence/public.json为准，测试通过不是用户美术通过。

## 变化

R04将一个导向毛梢偏移乘t²叠加到整根发丝，只有一种弯曲形态；把毛领的短毛参数接进来不等于得到长发的丰富弯曲。R05用三个根部位置/斜率为零的悬臂弯曲基函数，分别积分惯性和阻尼，85个空间导向连续驱动同一10000根×80段细丝。第一模式的回复尺度33及相关风场继承自有FUR教师，阻尼/高阶模式按本样片重新标定。只是低维弯曲响应，不是完整不可伸长/弯扭杆，没有人体、衣领或自碰撞。

抓取不再用鼠标移动速度形成持续推力；鼠标按住后使用命中弧长位置与屏幕面上的目标位置，松手释放约束，阻尼自然耗散。拾取依据导向投影，而非逐根丝精确命中。可比较中段和末段拨动。

恢复并固定每根81个光学计算节点，不再默认21点稀疏光学插值。原R/TT/TRT、色素、丝径、粗糙度和三灯保留；把视角/材料共用计算从三灯循环提出。支持八输出的GPU把原两次四层透明几何绘制合成一次八层输出；不支持时仍用两次四层，不少层。阴影仍为相同八个深度值，将两个半图分开绘制改成双输出后无损打包，三个灯从六次几何绘制变成三次。没有减发量、加粗、不透明底绒遮底或全屏模糊。

网页保留原分离通道模式，用于同一机器、同一发样、同一运动状态的画面和帧耗对照。测试可显式开启gl.finish分通道审计，正常运行没有该强同步。旧R01-R04、毛领源仓、人物与批准生长域均只读。运动、光学与窗口数据继续分层。

## 证据和局限

单测包括根部边界、多模式独立性、固定步长输入一致性、抓取局部性、有限位移与释放耗散。浏览器检查固定原图回归、合并/原分离通道误差、GPU根/梢、运动帧、真实鼠标按住/释放、原生微风/暂停、四色/逆光/近景和手机视口。性能必须来自同一runner交替测试，不能把不同软件runner耗时相除。尚无用户显卡或手机实机认证。

三个模式是线性小变形的降阶近似，不能替代所有长发行为；大位移会有弧长误差，弯曲空间由有限基函数限制。风力和刚度没有真人测量标定。毛束宽带感/逐丝细节仍须用户审美验收。旧版网页全部保留。
