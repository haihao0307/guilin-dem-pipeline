# R12.0 毛发融合接手精修

## 冻结来源与范围
接手的是已实际保存的 R11（653c9ec7f7fce99d19e69a5cf99f66c7e96f6cbd），不是将中断窗口的进度文字视为完成。R11 的 R3/R9 融合、14 款 Mindfront CC0 眉毛和 Perm / Digital Salon 数据层改作均属于继承能力，详细来源见 TEACHERS.md 与原许可文件。

只新增 fusion/r12 和 hair-r12-takeover.yml。R3、R9、R10、R11、原女性目录及其他工作台不写入；分支保持独立，不自动合并、不强推。

## 本轮实际改动
耳周和后颈新增四项参数：渐短、轮廓不规则疏密。确定性连续噪声只让边界向原安全域内退让，发根仍是同一三角形和重心坐标；不会把毛发生长域扩进耳朵，也不会移动头顶主发根。局部渐短采样真实皮肤导向支持点，不是把贴图拉短。固定镜头下可按 R11 边缘对照 / R12 自然边缘切换。

胡须新增五区独立长度比例和须流偏差，共十项新分区参数。五区覆盖、长度、方向使用连续权重混合，不再用主区域标签作为硬边界。卷曲横向轴从当前变形后的导向计算，不使用世界轴。上唇须、山羊胡、唇须加下巴预设显式清除不属于该预设的覆盖，避免继承全脸胡须残留。

发根检查隐藏所有眉毛网格，返回时恢复唯一活动眉毛层。R12 存档不覆盖 R11 本机存档；可读取旧存档，缺少的新控制补默认值。

完整原 GNM 二进制使用无损 gzip 传输，解压后仍核验原始字节数与 SHA-256；不减面，不换头模，不降发丝质量。主资源失败会尝试同一个固定版本的原数据；读取有体积上限、空闲/总时长中止和错误显示。压缩降低传输量，不降低解压后内存，也不构成帧率提升证明。

## 原女性入口的界限
female.html 打包的是原 TEN24 私有文件查看器代码。空入口可启动、有文件选择与原质量确认，不依赖跨目录 ES 模块；返回链接指向同一固定提交的融合台。原女性资产仍必须由用户在本地选择，未公开复制、上传，也没有用其他人物替代。原女性的实际 3D 自动展示、完整材质等价性和性能验收仍未完成。该入口启动不等于原女性模型已加载。

## 复现与验收
`python kaopu-hair-workbench/fusion/r12/refine.py` 从冻结 R11 生成可读新源码；`build12.py` 的 assets / stamp / female 模式负责无损资产与单文件入口；esbuild 打包。GitHub Actions 独立分支发布可复现源、资产、HTML、测试证据和 PUBLIC_URL.txt。

`tests/fields.mjs` 检查区域连续性、界限、五区混合和读取失败；继承的 StrandCore 单元测试检查表面采样、表示往返与拓扑；`tests/verify12.mjs` 在真正的 WebGL 浏览器检查六发型、14眉型、局部曲线变化与根稳定、保存迁移、胡须预设、原女性空入口、96k桌面与390×844的36k手机视口，并核验浏览器收到的HTML与资产哈希。

新版本不继承旧版本的测试成功。完成结果由本次 evidence/local/report.json、evidence/public/report.json 与 BUILD_MANIFEST.json 登记。截图是浏览器实际渲染，不是生成图。

## 未完成与成本
这是可调精修候选，尚不满足影视级验收。耳周、发际线与胡须自然度仍需用户视觉判断。没有运行 Perm 神经模型或 Digital Salon CUDA物理；全局动态碰撞、自碰撞、真实毛囊统计和影视多重散射没有完成。表面导向采样及正向局部间隙不等于连续发丝全域不穿模。96k 发根的CPU/GPU内存仍高，软件渲染检查不代表 Windows 显卡或手机实机帧率。
