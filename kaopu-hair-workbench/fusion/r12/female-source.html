首次准备原件 · 已有官方 ZIP / 解压目录
  1. 下载私人准备工具（仅代码）

    解压到任意代码目录。需要 Python 3.10+ 和已安装的 Blender；整套流程已测试 Blender 4.3.2，不自动安装或升级。

  2. 在解压后的工具目录打开终端，把下面三个路径换成你现有的位置。私人父目录必须已存在，且在所有 Git 仓库之外。

    python rebuild_private.py --private-parent "<私人输出父目录>" --blender "<Blender可执行文件>" --source-zip "<官方原ZIP>"

    已有解压文件时，将最后一项换为 --source-root "<直接包含 Blender 和 Textures 的目录>"。已有完整毛发项目会复用原导向；否则只获取该项目固定版本的约 650 KB 导向，不换发型或人物。

    没有原包时可省略最后一项，工具仅从作者官方来源按区间获取约 300 MB 原场景/贴图子集，不下载整个 2 GB 包。原文件只读，逐文件 SHA 校验，输出总是新建目录。

  3. 看到终端输出“Private browser import folder”后，回到本页选择它指出的 runtime 目录。目录要完整包含 runtime.json、全部 10 件几何、groom.bin 和贴图；不要只选原 ZIP 或原 Blender 文件。
