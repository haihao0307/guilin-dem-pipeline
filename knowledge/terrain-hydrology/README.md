# 地形、台地与水系知识库

本目录是桂林、温州、昆明三地地貌工作台的 GitHub 知识落点。

## 目录

```text
shared/inbox        三地共同资料原件和导出的工作台入库包
shared/distilled    三地共同方法、术语、判据和生产规则
<region>/inbox      某一地区的参考图、文字、来源收据和任务说明
<region>/distilled  某一地区经过审查的地貌、水系和台地知识
```

## 入库原则

1. 原图和原文保留文件名、来源、上传时间和地区归属。
2. 蒸馏文档引用原始资料 ID，不覆盖原始资料。
3. 参考图只能约束程序化增量，不能替代真实 DEM。
4. 冲突资料并列保存，等待人工决策。
5. 植被资料转交独立植被生产系统，本目录只保留与坡度、湿度、河距和硬禁入有关的接口知识。
