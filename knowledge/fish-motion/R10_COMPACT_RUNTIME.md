# R10 离线来源与轻量成品

用户最新纠正优先：采用原模型后，网页运行时不再携带完整来源重建数据。原 R14 和 R07 档案只在离线制作、测量和对照验收中保留，不随 R10 发布页加载。

生产链：离线测量 → 形体/鳍域/材质约束的数学优化 → 紧凑成品 → 首次上传共享几何与材质 → 逐帧只更新生物状态和 GPU 变形。30 条不复制静态几何和纹理。

当前 R10 是派生的紧凑网格/材质成品，不是仅用少量函数生成全部形体和外观；`fullyProceduralAppearance=false`。不得把改包名或烘焙顶点宣称为完整数学生成，也不得用通用几何体替代测量形体。

正式成品保留海狼与其他五鱼的原已重建形体、全部属性与三角索引，以保护可见表面插值、既有口和鳍映射；丢弃运行时已不需要的 base/paramAddress/residual 和源系数。UV、法线、12 个权重、鳍内地址及根部约束始终属于同一个成品拓扑。下面的减面参数仅记录被拒的离线实验，不是正式生产默认值。

R10 第一候选的真实渲染未通过保真检查。隔离诊断中，原几何搭配新纹理的画面 MAE 约 0.5；减面几何即使搭配全部原纹理仍约 5.0–5.4。主因是三角重组改变 UV/法线插值，不能通过恢复原纹理或放宽验收门槛解决。修复候选将 UV 属性权重从 0.6 提升到 8，法线权重从 0.025 提升到 1，归一化误差上限从 0.00035 收紧到 0.0001；保留更多几何后重新独立验收。原始与失败候选只作为离线证据，不进入网页回退链路。

第二候选仍未通过固定 MAE<2 的门禁，已经执行 ROOT_CAUSE_REVIEW，停止继续调减面参数。新的有限任务 `FISH_R10_EXACT_ADOPTION_AFTER_ROOT_CAUSE` 保留已重建成品的完整拓扑与静态属性，移除来源拟合步骤，通过无损数值编码减轻传输，优先满足“不重复加载来源、不损失表面”的用户约束。当前完整几何仍是运行所需的成品，不是来源 chart/residual；不能声称几何显存减小。编码版本 0 每字段必须逐字节回读一致，版本 1 在 Uint16 UV 字段遇到位级差异已被构建器拒绝。该回归检查应保留在每次编译环节。

进一步独立 WeakRef 实测发现：meshopt 无损解码器比字节分层差分包仅节省 175,077 字节，却留下 16,646,144 字节 WASM 常驻线性堆，切换鱼种并 GC 后仍在；CDP `backingStorageSize` 未计入这部分，不能仅凭 CDP 数字宣称内存优化。正式运行时改用自有 `BYTE_PLANE_DELTA_1`，不用常驻 WASM 解码器。公式为每条字节通道 `d_i=(b_i-b_(i-1)) mod 256`，初值 `b_-1=0`；读取时前缀和 `b_i=(b_(i-1)+d_i) mod 256`，再恢复原元素内字节顺序。保持所有浮点位、UV 位、权重位和三角顺序，逐字段回读验证后发布；仅一次读取，之后静态资源共享。

贴图保持原分辨率，记录实际再编码误差和 alpha；法线不通过误差门禁时改用有界通道量化，不能用随机噪声假冒原材质。全局 PSNR 不代表视觉通过，头部/轮廓/高对比条纹/最大摆幅仍要真实三维对照。
