# R06: selected-source startup

The rejected R05 public page is 103,675,602 bytes. Its first executable script starts at byte 102,839,320. The initial shell can therefore appear while the fish catalog and renderer remain uninitialized. A 47,361,706-byte unselected tuna source is embedded before that script. This matches the user's empty catalog and unchanged loading text; it is a download-order defect, not evidence that the geometry should be simplified.

R06 retains one completely inline offline HTML artifact. The online mirror carries the same program, source thumbnails and manifest in a roughly 1 MB entry. It downloads only the selected original source from a content-addressed, same-origin binary. All six source payloads retain their exact original bytes; length and SHA-256 are checked before decoding. The original R14 HTML is unchanged. Geometry, UVs, indices, source texture pixels, spine/fin animation, R05 eye fit, ocular/oral controllers and automatic motion cycle are preserved.

The catalog is present in the initial HTML. A small early script shows actual streamed byte progress, verification/decode/prepare phases, visible failure and retry. A thirty-second no-progress timeout prevents a permanently pending download. Changing the requested fish aborts unused pending source downloads. Every successful selection sets the public ready flag, including recovery after an initial failure. Main and legacy iframe boot errors are surfaced. No substitute images or low-quality meshes are used to pretend startup succeeded.

Offline verification must show zero external core resource requests. Online verification permits only the six named, integrity-checked source assets, and must show no unselected initial prefetch. Independent checks cover slow streaming, interrupted/corrupt payloads, retry, selection during startup, unavailable WebGL, six-source switching, 30-fish groups and desktop/mobile. Publication requires the frozen entry and payload hashes to match actual HTTPS responses and a browser run on the public URL. Local load times are measurements, not a promise for every user's connection.

Verification completed on 2026-10-02 for frozen source `9a36778ae6ac794138487bcee7fe4073b930b805`. The independent verifier passed 66 startup checks, 42 integrity checks and complete original-source array retention. The deliberately slowed local stream showed six images at78ms and three-dimensional readiness at13,750ms. Actual public HTTPS entry and all six complete asset bodies matched the frozen hashes. Public headless Chromium passed six-source desktop1440x950 and mobile390x844 switching, complete30-fish school and zero unexpected requests/errors. Initial selected-source readiness measured9,886ms/3,873ms in those runs; these are specific measurements, not device/network guarantees. The offline file passed with zero external core requests.
