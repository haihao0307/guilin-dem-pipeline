# R02 运动修订与接触根因

任务 `FISH_UNIFIED_SURFACE_MOTION_R02_20261002`；R01 基线 `e6c15fe` 已被用户拒绝，不能因旧数值测试通过继续称为视觉通过。此文件只记录本轮动作诊断与工程改动，最终 GPU、统一入口、材质与公开验收由总装/独立验证记录。原海狼 R14 不改。眼睛实现、参数和随机流冻结。

## 来源动线必须按原资产量测

鲱鱼来源是 Atlantic herring，并非从用户“飞鱼”的口述改判为飞鱼。原主链 `28→29→30→31→32→33` 的规范轴向位置为 `u=[.293599,.416867,.531702,.687729,.813842,.916635]`。R08 已量测局部摆角约 `[11.28,19.91,19.96,20.03,19.91,20.02]°`，展开相位约 `[-101.92,-161.89,-222.19,-281.92,-341.89,-281.92]°`。最后一个关节回到第四关节相位，不能用一个全身等距正弦波冒充该来源。来源证据见本库 `README.md` 与原模型 `local-r08/reference/herring/`。

R02 用原非均匀轴向位置、局部角振幅和相位构造平滑分布关节场：关节影响区是连续五次过渡，沿主轴累加局部关节响应，再作材料应变约束并积分单位切线。它是程序化重定向，不直接播放原蒙皮，也不声称已逐点复现原硬权重动画。尾柄的实际角度及角速度驱动局部尾鳍响应，避免鱼体和尾鳍分别使用不相干时钟。

黄鳍标签素材的源中央四元数通道主频约 `0.9215409756 Hz`，片段时长 `2.1667s` 本身不能用倒数推断摆尾频率。R02 保留来源标签与未确认分类，以该通道频率作为动作起点，用每条鱼独立随机流生成慢变的推进需求目标（0.84–1.16工程范围），平滑关联速度、频率、振幅和鳍的转向配平。没有突然重置相位或让眼睛共享此随机流。

## 连续脊椎并不自动证明表面不拉伸

R01 只证明中心弧长为1、截面正交、同一源位置映射连续；弯曲截面外侧的长度因子仍约为 `1−κz`。因此还必须测原三角边的实际动态长度，以及每个轴向段的可见半径。

最初仅使用 `finId=0` 身体点测半径是错误的：鲱鱼尾鳍在 `u≈.95` 的源横向距离接近 `.095 BL`，按身体尾柄的 `.015 BL` 限曲率会放过可见尾鳍拉伸。独立GPU验证具体捕获原尾鳍边 `2218/2492` 的1.441倍拉伸。R02 改为每段包含全部可见原顶点（身体、背/臀/胸/腹/尾鳍）的横向范围，鲱鱼末两站半径改为 `.094632/.09993 BL`；曲率约束在每段应用，而非偷偷缩小整条鱼的幅度。

机器指标（完整原身体三角边、64相位，鳍局部旋转与最终GPU另验）：鲱鱼最大边长比 `1.14187→1.11968`，最小 `0.85801→0.88021`；黄鳍标签最大 `1.04130→1.03388`，最小 `0.95872→0.96606`。输入幅度仍为 `.36/.28 rad`；新增门禁直接测尾端横向位移，必须不小于R01的98%，配置值不算实际幅度证据。

## 接触失败不能靠只放大包围盒修

R02 首轮新波使用瞬时脊椎最大横向位移作碰撞包围，盒子随摆尾扩张/收缩，其扩张可能超过每帧有界位移修正速度。另一个缓存错误把蓝鳍标签盒固定成初相位的窄值。固定整个动作范围的保守包围可消除这两种错误，但仍不足以解决持续拥挤。

第二轮固定包围诊断进入 `ROOT_CAUSE_REVIEW`：30条鱼的游动指令速度会同时把个体压入邻居，单独的有限预算位置投影可能无法全部恢复间隔。增加投影轮数或者扩大展台边界不能消除相向速度这个输入原因。

R02 接触更新顺序为：`旧位置/新朝向的固定动作包围 → SAT分离轴上的相向速度约束 → 位置积分 → 原有有界PBD修正`。接触速度投影是展示用技术约束，不是假称真实鱼脑或流体仿真。盒不随瞬时拍尾呼吸、校正不靠位置瞬移；原positive-clearance与最大位移预算门禁保持不变。每种新的动作母型必须同时做全相位动态表面包围与群体接触预算测试，不能从单鱼中心线正确推断群体正确。
