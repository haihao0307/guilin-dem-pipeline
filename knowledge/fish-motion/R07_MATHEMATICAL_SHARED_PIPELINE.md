# R07 数学制谱与资源所有权

任务：FISH_MATH_MEMORY_PERFORMANCE_R07_20261003。基线为本次任务前冻结的 R06。目标是同一制作系统、六种源鱼、单鱼和30条群游、原表面及纹理不缩水。源码已修改；成果是实时可交互三维 standalone HTML 和在线镜像；截图仅作内部 QA。公网验证见本轮 PUBLICATION_PROOF；人工 visualAcceptance/productionReady 保持 false。

## 完整复刻的数学边界

源表面的参数图函数加逐样本残差才是生产真值。简化成几个椭球或一条旋转曲面，会丢失鱼鳍、轮廓、嘴部与原纹理细节，不属于优化。五种鱼保留 Float64 参数地址、基函数与残差，按原运算顺序生成原 Float32 GPU 顶点；法线、UV、索引、鱼鳍权重与梯度完整保留。海狼保留 KFC13 原表面包和完整 GPU 几何，只有读取方式改为 FBR7 二进制。

纹理保留原编码字节与像素分辨率。黄鳍标签源的六张4096²贴图已是无损 WebP，46.2MB 编码图片是主要文件体积；仅靠重新包装无法得到数量级压缩。若以后要将纹理也改成函数场，必须先完整测量并通过实际像素和光照误差门禁。本轮不以猜画细节代替原图。

## 计算一次，共享完整表面

身体使用原 InstancedMesh/海狼实例绘制，并共享完整源几何。海狼整体朝向是每条鱼的刚体旋转，不随顶点变化，六项 sin/cos 从颜色和阴影的每顶点计算移到每实例数学缓存；只有朝向变化才更新矩阵。脊椎连续函数、尾柄传导、鱼鳍权重、雅可比法线与行为积分保持原逻辑。

五种鱼的眼球每侧合为一个实例批次，共2批，完整原36×24球面、物理材质、虹膜着色与每鱼独立眼动保留。注意眼球椭球缩放后再扫视会产生非正交矩阵；Three 默认实例法线近似不能直接用。必须上传每实例完整逆转置3×3矩阵，否则位置相同而光影会变。CPU等价测试与实际 GPU/固定姿态图像检查分开记录。

热循环复用向量、矩阵、姿态纹理缓冲；暂停时只在姿态/骨架/参考状态改变时上传。模拟仍为原确定性积分，不用改变运动幅度或减少鱼群数量换速度。

## 紧凑数据与有界缓存

FSP7 是 JSON 元数据加8字节对齐 TypedArray/原编码图像块。worker 直接创建视图并一次转移共同 ArrayBuffer，成功、失败、取消均 terminate。图片从原字节创建临时 Blob URL，仍用原 HTMLImageElement 解码与 flipY 语义；完成即 revoke。兼容 URI 是按需重建的诊断 getter，生产不构造庞大 base64字符串。

当前源是唯一长期缓存。选择开始取消过期下载/worker；新源完成解码后原子提交、释放旧几何/纹理/源缓冲。请求 token 保证迟到结果不能覆盖当前选择，同种鱼重新请求不误释放共享纹理。精确相同的贴图描述符可共享 Texture，色空间/UV通道/变换不同的描述符不得合并。dispose 用 Set 去重。

海狼 FBR7 将原31MB HTML中的30MB ASCII数据块移出，只保留约1MB程序与24MB完整源二进制。跨 iframe 时必须用子窗口 Uint8Array 构造同一 ArrayBuffer 的视图；父窗口数组不满足旧程序子窗口 instanceof 检查。在线用 Blob 导航并及时 revoke；file:// 用小 srcdoc 保持同源入口。

海狼完成 GPU 上传后释放全量源 CPU 诊断数组，只保留七组鱼鳍根/端点和动力学尾端样本。完整几何可由 GPU readback 审核；骨架线继续使用原37点数学采样。切换其他鱼后销毁海狼渲染器/场景资源并 loseContext，避免隐藏的海底几何、纹理、绘制缓冲继续常驻；返回海狼重新挂载。

## 验收与后续生产

独立验证必须绑定冻结源码与 HTML哈希：全部源数组及编码图像字节，实际 GPU 顶点/法线/索引、固定姿态画面、扫视与五种运动、单鱼/30条群游、鼠标交互、跨鱼缓存/取消/失败重试、file:// 零核心网络、真实公网 desktop/mobile。

性能在同一硬件、同一 viewport、同一动作和数量上比较帧时间分布与绘制调用。CDP heapUsed/backingStorage不是浏览器总内存；显式 WebGL buffers/textures/renderbuffers不是物理显存读数。记录口径与 instrumentation 持有资源句柄的影响，主动释放的上下文按已释放处理。不得把 Node 解码堆下降宣传成整机内存下降，也不得把60Hz上限误称额外帧率提升。
