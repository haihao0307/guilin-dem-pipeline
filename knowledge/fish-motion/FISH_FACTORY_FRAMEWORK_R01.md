# 鱼类生物制作框架 R01：来源表面、连续脊椎、独立鱼鳍、行为系统

任务：`FISH_FIVE_PROCEDURAL_FACTORY_R01_20261002`。当前五个素材是鲱鱼、两份来源标签为黄鳍/蓝鳍的 Tuna、彩色珊瑚鱼来源单体、Picasso 标签模型。两份 Tuna 的目录名和 Picasso 来源标题不等于已经确认的生物学物种。海狼 R14 保持暂停。本文记录生产规则和可复用关系，不能替代当前版本的独立验收。

## 1. 共同结构与差异边界

这一代核心面向有轴向脊椎、独立鳍区的硬骨鱼模型。共有接口是头/吻与眼、鳃盖区域、身体主轴、尾柄/尾鳍、成对胸鳍和腹鳍，以及中线背鳍和臀鳍。具体鳍数量、位置、鳍条和硬棘不能固定为一张通用模板；缺失或融合结构必须由原模型/身份资料证明，未知保持 `MEASUREMENT_REQUIRED`。NOAA 的可比形态指标包括椎骨、胸/腹/背/臀/尾鳍元素以及鳃相关指标，说明制作卡应存组件与量测，而不是只存一个“鱼”标签。[NOAA 形态指标定义](https://apps-afsc.fisheries.noaa.gov/ichthyo/use.php)、[Florida Museum 外形与标准测量](https://www.floridamuseum.ufl.edu/discover-fish/fish/anatomy/features-measurements/)。

来源标题 `Picasso Fish (for the ScubeVerse)` 不足以确认其分类为 Rhinecanthus aculeatus；当前表面颜色和形态存在需要独立核对的身份问题。因此界面与档案应保留“Picasso 来源标签，具体物种未确认”。后述炮弹鱼研究是一个可选运动母型的依据，不能直接成为该来源模型的生物学证明。

| 结构 | 共同生产接口 | 必须逐来源量测的差异 |
|---|---|---|
| 头、吻、口、鳃盖 | 头段与主体同步但不软化，口/鳃只有可测绑定时独立运动 | 头长、口位、鳃盖范围、眼窝位置；不可新增模型未有的缝和孔 |
| 脊椎与身体截面 | 主轴弧长位置、截面运输、后向传播弯曲 | 身体长宽高、柔性起点、截面形状、尾柄位置 |
| 尾柄与尾鳍 | 身体传导之后叠加局部鳍响应 | 尾叉、叶宽、尾柄长度、鳍根与关节方向 |
| 胸鳍/腹鳍 | 左右分开、鳍根固定、鳍端递增柔性 | 根部位置、鳍条方向、扇面范围、用途差异 |
| 背鳍/臀鳍 | 鳍区连续权重、根部零位移、允许逐鳍条相位 | 一个/多个背鳍、硬棘/软条、波动推进比例 |
| 眼 | 原眼窝锚点 + 独立、限幅、停留/扫视 | 眼半径、光轴、遮挡、眼窝与皮肤接触；不把人类眼球比例移植到鱼 |
| 表面与材质 | 原拓扑、UV、法线和贴图通道继承，程序形变不撕裂 | 各种真实颜色/反光/纹路；不可把海狼的蓝色限制套到所有鱼 |

软骨鱼、鲨鱼、鳐/蝠鲼需独立母型和鳍推进路线；海龟和海洋哺乳类不属于这套硬骨鱼生产链。成对/中线鳍划分可以复用接口，不意味着它们执行相同推进功能。

## 2. 运动共性不能压平成同一动作

身体—尾鳍推进（BCF）与中线/成对鱼鳍推进（MPF）作为可切换的控制组成。鱼类的身体波形存在可共享规律，但身体形态和运动并非只凭“金枪鱼/鳗鱼”等传统名称就能锁死，需保留原动作和观测证据，不能把模式标签当作精确参数。[原始比较研究，di Santo 等，PNAS 2021](https://pubs.usgs.gov/publication/70226746)。

炮弹鱼可作为运动母型中的一个例外：研究表明炮弹鱼慢速推进主要由软背鳍和臀鳍协同波动完成，身体与尾鳍较稳定；提高速度后可加入身体—尾鳍推进。MPF 候选模块因此提供弱身体摆动、增强背/臀鳍，胸鳍参与转向/悬停，突进增加身体摆动。不能让已确认炮弹鱼像鳗鱼一样全身蛇形摆动，也不能误把胸鳍设为唯一主推进器。本代 Picasso 标签模型的 MPF 配置仍为实验选项，身份未确认以前不得称为已校准的炮弹鱼动作。[JEB 2019 炮弹鱼与单棘鲀类研究](https://journals.biologists.com/jeb/article/222/8/jeb194704/34045/Functional-morphology-of-endurance-swimming)、[JEB 2002 包含 Rhinecanthus aculeatus 的实验](https://pubmed.ncbi.nlm.nih.gov/11948202/)。

中线鳍不是只能“装饰性跟随”。太阳鱼实验证明背鳍、胸鳍和尾鳍可以协调产生推进及转向力。该结果支持独立鳍控制的必要性，不能直接转化成五种素材的数值动作。[JEB 背鳍水动力原始实验](https://journals.biologists.com/jeb/article/204/17/2943/32831/Locomotor-function-of-the-dorsal-fin-in-teleost)。

## 3. 原表面采样是形体真值

1. 读取完整 glTF/GLB/FBX：原静止几何、所有节点变换、蒙皮绑定矩阵、UV、法线、材质与贴图。多格式同一源要去重；格式缺贴图不允许替换成随意颜色。
2. 选单个完整来源单体：群体源要按原网格/骨骼身份提取，不凭空间裁切砍掉鳍或身体；来源包含多个形态时，记录当前选择和其余源对象。
3. 在测得的规范坐标里存原顶点、索引和连续轴向参数。核心鱼体不是球/胶囊/圆柱/低面拼接，不改原索引补洞，不用新通用形体替代原鱼。
4. 形态变体在原表面参数域里做小范围算子，算子须在缝两侧一致；颜色继承原贴图，变化以来源/用户约束为界。参数化形变不等于从零发明新鱼种。
5. 静止候选必须复现原表面；固定同相机、相同光照，先比整体比例、尾柄、鳍位置、吻/眼窝，再微调运动。

原模型有边界或非流形时，先定位、记录。嘴缝、薄鳍边和UV拆点不等于可见破洞，不能自动补洞。连续性门禁关注来源原有对应点是否在候选中分开、动态边缘是否产生新缝及法线是否失效。

## 4. 连续脊椎与鳍绑定分权

`fish-five-r01/src/behavior.js` 提供连续脊椎。规范坐标头为 `x=-0.5`、尾为 `x=+0.5`，一个体长 BL；规范化并不证明真实厘米尺寸。主轴角度由后向渐增的平滑柔性包络、传播相位、弱转向曲率共同定义。积分单位切线得到中心线，再用正交截面搬运整块来源表面。前部头段保持稳定；不是对鱼体各块分别线性权重摆动。

身体弯曲与鳍局部形变的关系：

`来源静止表面 → 已测鳍根/鳍条局部形变 → 同一连续身体截面运输 → 整体位置/朝向`

鳍权重只服务独立鳍区，不能扩散到整条鱼体。根部必须接近零位移，边缘和鳍尖递增柔性。左右胸鳍分别控制；转弯两侧响应可不同，但身体和鳍根共用同一空间变换。GPU 与 CPU 使用相同中心线与截面定义，法线必须随形变或导数更新。

API：`create(id,count,seed)`、`update(state,dt,input)`、`reset(state)`、`snapshot(state)`、`sampleSpine(actor,profile,samples=65)`、`deform(point,actor,profile,optionalCachedSpine)`。`sampleSpine` 返回中心、切线、竖直法向和侧向副法向的 `vector[3][]`；每个截面的方向单位正交。

```text
specimenId / sourceTitle / speciesIdentityStatus / credits / license

selectedSourceMeshIds / selectedSkeletonIds / sourceJointCount

```

证据分类：`SOURCE_MEASURED`（实际模型/动作量测）、`RESEARCH_RELATION`（研究支持的方向）、`ENGINEERING_CANDIDATE`（当前可测试包络）、`UNKNOWN`。动作片段长度不等于摆尾频率，不能从 2.1667 秒片段直接推算鱼以 0.4615 Hz 游动。

| 当前来源 | 已知原动作基础 | 本代行为包络的地位 |
|---|---|---|
| 鲱鱼 | 原六鱼素材；R08 已有单鱼相位约 1 Hz 的测量 | 相位继承用于起点，速度/转弯/群体是工程候选 |
| 黄鳍标签 Tuna | 原 Swim 片段 2.1667 s | 低前部柔性、后部波动；需逐帧拟合来校准Hz/幅度 |
| 蓝鳍标签 Tuna | 普通/快速两片段，登记时长 1.1667 s | 稳定巡游与突进过渡；物种和绝对速度未确认 |
| 彩色珊瑚鱼来源 | 原片段 21.6667 s，来源有多个网格 | 单体选择后独立主体/鳍动作；不声称所有网格是一种鱼 |
| Picasso 标签模型 | 来源静态，无绑定与动画；生物分类未确认 | MPF→BCF 为实验母型配置，非该来源已验证的自然行为；全部数值待校准 |

## 6. 自主活动、眼睛与鱼群

统一行为接口包括巡游、低活动休息、突进、有限速转弯、悬停。速度变化平滑带动摆幅与频率变化；相位连续积分，切换模式不重置摆尾，转向有角速度上限。展示单鱼默认居中，速度是运动通道的虚拟推进速度；群游模式位置是真正积分的体长空间轨迹，不把单鱼展示速度谎称为实测位移速度。

眼睛使用每条鱼独立种子的停留时间、限幅目标和快速但连续的扫视过程，左右眼可弱差异；不让整群同一秒转眼，也不使用显眼周期性转圈。鱼眼自然度是浏览器视觉项，数字测试只证明有界与独立。

同类群体独立计算邻居分离、方向对齐和凝聚；转向和位置通过速度积分更新，不用固定网格排布。鼠标传感点触发躲避/局部两侧分流；传感点离开后威胁衰减，邻居和聚合逻辑重新组织群体。展台边界使用提前转向和减速，不硬夹位置制造弹墙。30 条是展示容量，不是五个物种均天然具有30条紧密群游的生物学断言。

**群体接触约束是工程规则**：只靠有限转速的 Boids 排斥会发生贴近交叉，不能宣称没有穿插。当前从每种完整来源顶点测得规范静止包围盒，加解析身体弯曲上界和鳍摆空间裕量，随每条鱼的 `Ry(yaw)·Rz(-pitch)·Rx(roll)` 运输该包围盒；采用完整15轴 OBB 分离判据和位置约束投影 PBD。初始化在显示第一帧前消除重叠，运行时每步修正位移限制为 `3.5 BL/s × dt`。该技术约束防止展示中的包围体穿插，不等于真实水动力、鱼的认知或逐三角形碰撞。`configureShape(state,{min,max,finSweepMargin,gap})` 可接收总装重新测量的源/动态包围值，裕量若不能包住最终变形顶点，必须扩大而不能把包围检测当作真实网格通过。

## 7. 批量生产与验收

`SOURCE_READY → 单体/坐标/外形对应 → 连续身体与独立鳍绑定 → 参数化动作 → 行为 → 工作台 → 独立验证`。单个来源局部阻塞不得卡住其他来源；未知鳍不能编造，先保留来源合法状态并标注测量项。

数值门禁见 `fish-five-r01/scripts/verify-behavior.mjs`：五个来源各120秒/30鱼多模式有限状态、固定种子可复现、有限转速、独立摆尾/眼睛相位、威胁释放和聚合、中心线弧长、正交截面、静止表面恒等与连续性。测试报告 `evidence/BEHAVIOR_REPORT.json` 不是独立视觉或科学校准通过。

整体工作台需另验：五份来源完整性、原与候选同相机保真、源表面动态接缝、鳍根稳定、眼球接触、实时三维、可选物种单一显示、桌面/移动、`file://` 无核心网络依赖、最终公开地址与当前版本一致。人工 `visualAcceptance` 和 `productionReady` 不由制作端自动置真。
