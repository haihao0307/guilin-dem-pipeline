# R04：更可见的扫视与有来源依据的口部活动

本轮用户明确解除眼睛动作冻结，要求看出到处观察的灵动感，并让嘴部按实际结构活动。仍是“鱼类的制谱师”同一六来源制作系统，承接公开验证过的 R03；R03 身体、鱼鳍、鱼群与来源数据不改。

## 眼睛

`ocular-r04.js` 使用独立种子、短平滑扫视和停留；左右眼有共同注意线索但不机械同步。最大候选 yaw 为 .18 rad、pitch 为 .075 rad，受既有虹膜/角膜域限制；这些是工程表现范围，不能声称已量得这六种鱼的生理角度或扫视频率。原眼球、外形、虹膜材质、瞳孔和源眼位保持。

五来源不是简单扩大 XYZ 旋转。先取得既有眼材质实际光轴经原椭球比例缩放后的方向，投影头向/背向基底；新目标光轴转回源局部坐标，再除原椭球半径，驱动单位球内的 gaze 四元数。这样 .18 rad 对应头部局部光轴范围，彩色鱼的扁眼不会因长短轴比例将眼动放大，REST 恢复原光轴。外层椭球包络不动。海狼沿原 tangent/up/outward 框架写 gaze，保留批量提交和原角膜/瞳孔实现。

## 口部

口部审计、原骨时序与完整来源证据在 `R04_MOUTH_SOURCE_AUDIT.md` 和 `data/oral-r04.json`。内嵌工作台仅带 50 KB 的 `oral-runtime-r04.json`，无需重复携带完整骨动画审计。两种金枪鱼仅使用原下颌子树一次，不能再次旋转下唇或叠加 direct/subtree；原枢轴、轴、地址映射、约束后的权重与梯度都可审计。黄鳍标签范围 0..+.03 rad，蓝鳍标签 0..+.05 rad。口腔和牙齿不新增。

海狼原 FBX 是静态形体，R14 下颌/鳃盖是来源采样后的派生控制，并非原 FBX 自带的皮肤骨。下颌和鳃盖均未过最终实际表面门禁，正式下颌/鳃盖为 HOLD_LOCAL，严格保持源姿态；不存在“海狼开合已完成”的声明。原 carrier 与文件保留。金枪鱼用冲压通气表现候选：游动时小开口、随需求缓慢调节，不按尾摆节拍反复完全闭嘴。角度与约 .8–1 Hz 工程时钟未被冒称现场生理测量。

鲱鱼泛名下头骨不能证明独立口唇，硬权重试转会严重拉裂。彩色与毕加索来源缺少已确认的独立口部结构。这三个口部是明确的 HOLD_LOCAL，保留原姿态；眼动、身体和群游继续可用。不能用通用下颌、虚构内腔或切断源拓扑补位。

## 连续性、法线与运行

金枪鱼采用源下颌刚体变换与 identity 的 LBS 混合，并将源约束权重的切向梯度纳入完整 Jacobian/cofactor 法线。数值全范围检查：黄鳍边比 .9640..1.0263、面积 .9636..1.0707；蓝鳍边比 .9871..1.0299、面积 .9793..1.0304；最小 Jacobian 行列式均 >.97，有限差分法线误差 <.000002 度。嘴与鳍权重没有重叠。

研究验证了口部 Jacobian/cofactor 简式，但最终海狼两口部通道都停用，不将这些研究法线进入正式渲染。生产 shader 只删除原下颌/鳃盖变形块，完整其它源位置、原眼窝 recess、鱼鳍与脊椎不变；注入非零口部 uniform 也不能改变表面。完整原面数与68次绘制保持，不删面或降贴图。

冻结候选 4584 被独立复核拒绝，不能把此前未冻结的根工位 16.7ms 探针当作交付证明。独立分通道测量显示阴影 GPU 时间约5.01→5.05ms、主通道13.57→15.08ms，同时慢帧导致原运动积分子步增加、CPU进一步变慢。采样调度修复只跳过当时未被消费的六片鳍中间行；真实消费者、完整状态逐帧等价与载体保护见 `R04_RUNTIME_ROOT_CAUSE.md`。实际浏览器帧率必须在下一冻结构建重新验证。

同一候选的完整海狼口部 GPU 检查也失败：原量化下颌权重在0.5897mm源边上从0直接变成1，.038rad时边长6.920倍，并产生19次倒面。仅减到.001rad才通过抽样，无法满足可见活动，因此拒绝以近乎静止的幅度遮盖问题。连续来源表面过渡场须另过全拓扑门禁；原载体、顶点、索引、UV和贴图保持，不能切开网格或捏造内腔。失败证据保留在 REJECTED_4584 报告。

两次连续下颌场候选也未通过。第二次吻端有实际4.5mm活动、边比与无倒面门禁通过，但原三角27216的最小高只有11.17µm，边图距离插值产生实际面梯度495.7/m，面积放大2.317倍。顶点平均 Jacobian 正常不能替代逐三角面积校验，换LBS也不解决。独立重算确认真实失败，保留原0.7..1.4面积门禁，不增加瘦面排除、不删面、不再盲调宽度。下颌进入后续 triangle/FEM 连续场研究；本轮 jawWeight/jawGradient 全0，shader也不使用下颌旋转。鳃盖单独全范围的CPU边比 .9399..1.0644、面积 .8788..1.2305、det≥.93068，可继续独立 GPU 复核，不能把鳃盖活动冒称嘴开合。

随后 a1e41 候选的真实 GPU 复核否定了鳃盖候选：继承眼窝 recess 后的中性三角159544=[317240,316795,316645]比 raw 源面更薄，实际鳃盖边比1.374、面积3.420，仍不合格。raw 源 CPU 证明不能代替最终运行表面。鳃盖场移入 `scripts/research-fixtures/legacy-gill-socket-rejected-r04.js`，正式构建不引用；两通道全部权重与梯度为0，控制器也保持0。海狼完整口部暂停，继续六眼与两原生嘴；不进行第三轮盲调或降低门禁。

眼睛最终真实12秒光轴对比也有边界：海狼与两金枪鱼幅度增大，鲱鱼左右增幅不一致，彩色/毕加索因旧 Euler 被扁椭球放大，新的实际角范围较旧峰间值小。六来源均有可见短扫视、停留和独立时钟，但不能写“六种的幅度都更大”；“更灵动”的主观验收保留给用户。

“头部”按钮自动进入单鱼并按来源眼位/头界近看，不新增权重或个体参数面板。暂停保存当前眼/嘴，REST 为中性。群体时每条鱼保持自己的眼与口部相位。

最终只能以 R04 冻结构建、独立 GPU/画面报告和固定公网入口的真实浏览器证据确认交付；数值/截图单独不能批准。用户的 visualAcceptance、motionAcceptance、productionReady 不自动设真。
