## 实际单步数学

采用源坐标 head=-X 与 `Ry(yaw) Rz(-pitch) Rx(roll)`。世界前进单位向量为

`h = [-cos(yaw) cos(pitch), sin(pitch), sin(yaw) cos(pitch)]`。

候选中心 `x' = x + dt v h'`。对固定单位法线 n，完整源 OBB 支撑为

`S(n,R) = Σ_k half[k] |(R e_k)·n|`。

旧平面间隙 `C = n·(x_j-x_i)-S_i-S_j-gap`，精确单步间隙变化率为

`F(u) = n·(v_j h'_j-v_i h'_i) - [(S'_i-S_i)+(S'_j-S_j)]/dt`。

当前 `normalGradient` 返回 F 和关于 `[v_i, yawRate_i, pitchRate_i, rollRate_i, v_j, yawRate_j, pitchRate_j, rollRate_j]` 的解析 Jacobian。支撑的 abs 在**候选轴**上求值，包含轴跨过零的真实端点支撑差。abs 角点不可微；`sign(0)=0` 只是一个选择，随机中央差分结果不构成角点处的通用导数证明。

约束 `F >= -max(0,C-reserve)/barrierTime` 在本例 `dt << barrierTime` 且实际约束满足时，可给旧固定平面的端点证据；不能仅凭目标 clamp 或若干求解轮数声称约束满足。

## 诊断偏移已修正

旧 `R08_CONTROL_ROOT_CAUSE_TRACE.json` 曾用 `Σ G_q u_q` 代替实际 F，没有非齐次偏移。先前隔离探针中偏移 `F-G·u` 的绝对值达到 `0.48805` 世界单位/秒，旧 `bestFeasibleRate` 数值不能证明真实控制盒为空。

当前源码已使用 `actualEndpointRate=F(u)`，并计算 `F(u)+G·(u_box-u)`，名称改为 `tangentUpperBound`，明确标注它只是切线估计。有限角度的 trig/abs 支撑不是在整个角速率控制盒上全局仿射；该切线估计仍不是非线性 box maximum 的严格上界。不得把旧日志错误继续当作当前生产公式错误。

## 连续帧扫掠证据

只检查端点，不能排除两帧之间的姿态旋转碰撞。对已接受的 60 Hz 步，假设中心线性插值、yaw 取短弧、pitch/roll 连续线性插值，定义

`A_i = |Δyaw_short| + |Δpitch| + |Δroll|`，`rho_i = norm(half_i)`。

源 OBB 内任一点因旋转产生的路径长度至多 `rho_i A_i`。中心相对投影的最小值由线性插值端点确定，因此旧分离平面在整个步内的保守间隙下界为

`C_swept >= C_old + min(0, n·(Δx_j-Δx_i)) - rho_i A_i - rho_j A_j`。

源点总位移还有较粗的界 `norm(Δx_i)+rho_i A_i`。以上界是由源半径和实际接受姿态得到的保守证据，不需要额外重网格碰撞。它依赖原 source whole-gait envelope 对实际动画仍有效，以及展示插值确实遵守上述路径；不覆盖任意曲线插值或包络外的新变形。

## 长期 guard 的结构原因

`R08_ENVIRONMENT_ROOT_CAUSE.json` 是 core 的匹配 A/B：相同 source、seed、30 鱼、完整包络、初始余隙、模式和 120 秒，改变环境 bounds。旧隐藏箱让低转向能力、惯性制动和墙边持续向内的目标共同形成拥挤条件。源码虽然没有“硬墙约束”，墙的持续社会驱动会让多个近邻约束竞争，有限循环的局部投影可能留下真实 residual，再由 guard 急停。A/B 支持隐藏箱是该场景的根因；它不等于证明每次失败都属于数学上不可行。

当前五种群游使用 `bounds:null`，其开放海水空间由展示相机跟随；单鱼工作区与海狼有限栖地另行保留。扩大隐藏箱只延后问题，缩小 source collision envelope 或把紧急急停做显示平滑都会掩盖约束问题。

纯 bearing attraction 在邻鱼严格前后时 `sin(bearing)=0`，持续个体速度变异因而产生纵向中性漂移。当前加入局部速度协调与前后 gap feedback，对准这一缺项，避免要求大鱼横向急转去纠正纵向离群。这是工程反馈候选，不是对这些来源标签的实际物种标定。

## 尚存的数学边界及小修正规则

1. **有限求解不是全局证书。** 多 pair 顺序投影互相影响，abs 角点、trig 支撑及控制盒饱和会使 12×8 次局部求解留下 residual。验收应读取最终精确 `allowed-F`、guard 和空区间统计，不由“求解轮数已跑完”推断通过。当前 `reviewMetrics` 已能提供实际最终 residual；其中历史命名 `infeasible` 是超阈值 residual 的数量，并不是数学上已证明不可行的 pair 数量。
2. **有限范围不是普适预测保证。** 安全 pair 收集仍用固定 `.8 BL` 余隙窗口及球形 broad phase；社会 CPA 有速度相关的 stopping distance，但二者不是同一个严格可达集合。若以后提升最大速度、放大 dt 或改变源半径，应根据最大相对平移、转动支撑与制动距离重新检查窗口；不宜仅盲调 gap。当前短窗未出现漏入对。
3. **控制盒需源状态可行。** pitch/roll 的离散制动上限已同时包含一步推进与后续停止余量，优于单纯 clamp。它仍假设旧姿态和旧速率处于可制动域；构造器没有完整检查这些输入，也不拒绝 `lower>upper`。当前初始化短窗没有空区间。今后外部导入姿态应显式检查，不能让 `clamp` 在空盒内返回一个看似合法控制。
4. **guard 是异常路径。** 安全层的因子同时改变朝向和推进距离，其间隙不是因子的全局线性函数；secant 因子加三轮检查不是所有姿态的严格单调解法。factor 降低还会超出原加速度包络。应把 guard 作为可见的异常计数与实际运动门禁，不能以显示插值抹掉该事实。
5. **需要三维速度证据。** 当前候选的速度方向确实等于三维 h；短窗最大 3D 角误差 `2.98e-8 rad`，速度模长误差 `2.91e-14 BL/s`。现 snapshot 的 `meanHeadingSlip` 只检查 yaw 投影，不能单独验证 pitch 或竖向倒游；零速度时 heading 也没有定义。
6. **不同量纲的投影是工程取舍。** Euclidean 投影混用 BL/s 与 rad/s，隐含了代价尺度；它不是鱼类控制能耗最优解。只有未来证据指向不良条件数时，再考虑按各控制可达区间做无量纲条件化，不应为已有正常场景盲改。
