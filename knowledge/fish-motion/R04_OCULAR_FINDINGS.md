## 生物学证据与边界

鱼眼需要区分停留与短扫视，而非持续周期摆动。斑马鱼幼体研究直接记录了共轭、单眼、会聚及分散扫视；另一个研究显示扫视既可以配合游动，也可在鱼体静止时重定向视线。这里仅迁移“短扫视和停留分层、眼动不必固定跟随尾摆”的结构；没有把幼体斑马鱼的角度、速度或概率当作六个输入模型的实测参数。[Leyden 等，2021](https://pmc.ncbi.nlm.nih.gov/articles/PMC8209155/)、[斑马鱼行为研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC7618497/)

两眼的关联因物种和刺激而异。比较研究中蝴蝶鱼多为耦合眼动，海龙和沙鳚可表现出不同程度的独立眼动。自由游动金鱼的三维追踪则记录了按邻鱼所在侧调整视线的行为。不能总结成“所有鱼永远完全独立控制两眼”，也不能把特定捕食鱼的会聚行为推广到全部来源。[Fritsches 与 Marshall，2002](https://pubmed.ncbi.nlm.nih.gov/11948201/)、[Wu 等，2024](https://www.nature.com/articles/s42003-024-07322-y)

本版本提供共享注意线索与独立左右时钟的混合工程控制，不声称已识别全部源模型的精确物种或眼肌生理。源标题仍是源标签；具体物种眼动标定为 `UNKNOWN`。

## 源几何约束与可见幅度

原五来源的 `.047/.023 rad` 是此前的动画幅度帽，不是测得的生物眼窝角度。新候选内参数帽为 yaw `.18 rad`、pitch `.075 rad`，分别约为旧帽的 3.83、3.26 倍；它们是工程参数。完整二维目标处于椭圆界内，组合方向没有超出半径 `.18` 的参数锥。

五来源继续使用现有源测量眼球中心、局部半径和 sourceFrame。其眼球单位球面旋转后再按固定半径缩放，任何旋转都不平移、不扩大原 ellipsoid 包围。现有着色器虹膜域外阈值为 `.81`，对应单位球面的半角 `asin(.81)`；额外转动 `.18` 仍有前半球余量。这个着色域余量不等同于原生眼肌极限。Picasso 输入的眼睛是已接受的源可见贴图片区适配，不新增“已经测得原模型完整眼球”的结论。

现有 KFE 海狼适配几何（记录在 `local-r09/data/score-metadata.json`，后续保留同一几何构造）globe 半径 `.0125`、iris 半径 `.0073`、cornea 半径 `.01285`。现有 cornea 构造覆盖角为 `0.30π`。最外虹膜在 `.18` 参数锥下投影仍小于该 cornea 开口，模型单位余量为 `.00139721`。原 KFE 已有硬角度帽 `.32/.18`，新帽也位于其内部。源码模块接受实际传入的半径，若真实接入数据更窄则按 cornea/iris 比自动收窄；不硬套旧尺寸。以上都是已有模型适配尺寸，不能用来推断野生鱼眼的毫米尺寸。

源眼球的非均匀缩放会使内参数角与最终可见光轴角不同，扁眼尤其明显。因此记录为 controller 参数，不能把 `.18 rad` 写成已测最终光轴角或物种实测值。主工位必须围绕实际 opticAxis 接入并记录缩放后的真实可见方向，同时检查最终光轴、瞳孔不穿出可见虹膜/角膜区域。若按目标头局部角反算单位球面方向，需要先除以局部半径再归一化；但该映射也会改变眼动的屏幕可见增量，必须与旧网页实拍比较。

## Controller API

模块导出 `create`、`update`、`angles`、`eyeBasis`、`snapshot`、`VERSION`。

```js
const c = create(id, 90401, actorIndex, measuredEyes);
const gaze = update(c, dt, {
  mode: 'cruise', // REST/rest 输出严格中性
  paused: false,
  turnRate: 0,
  pointerLocal: null // 与 measuredEyes.center 同坐标/单位的头局部点
});
const left = angles(c, -1); // { yaw, pitch }
const basis = eyeBasis(c, -1);
```

`gaze` 是复用对象：`leftYaw/leftPitch/rightYaw/rightPitch/yaw/pitch`。side `-1` 对应左输出，side `+1` 对应右输出；旧 KFE 的 side 映射可能不同，必须按 `angles(c, side)` 直接读取。不输出或修改 pupil。不能继续用旧 `.047/.023` clamp 把新输出截回原范围。

`eyeBasis` 输出头局部 `optic/anterior/up` 与源 frame 局部 `localOptic/localAnterior/localUp`；正 yaw 指向头部 `-X`，正 pitch 指向背侧 `+Y`。近球形的 yellow 输入在 PCA frame 中不朝局部 +Z：实际 optic 根据左右眼中心的横向方向恢复，或接收显式 `opticAxis`。其他输入保留实测外向法线。渲染器应围绕真实光轴处理此映射，不可直接固定 XYZ 欧拉旋转。

## 时序与冻结

源 id、seed 与演员编号共同决定时钟，同一种 30 条和切换鱼种后的轨迹都可复现。每眼扫描时刻独立；约 25% 的目标来自共享注意线索，余下为每眼独立目标，参数比例不是生物实验拟合。目标在扫视开始时确定；扫视中移动鼠标不会中途重新瞄准。

五次缓动连接两次注视，首尾速度和加速度为零；根据距离延长扫视以保证向量角速度不超过 `1.65 rad/s`。停留 `1.15–3.60 s`，扫视通常约 `0.18–0.4 s`，极端反向扫视会自动延长。静止注视期间无周期噪声、眨眼或瞳孔跳变。轻微转向/指针关联只在新目标选择时发生。

REST 进入后输出严格全零，扫描时钟停止；返回巡游从中性位置连续重新扫视。`paused` 优先保持当前输出、时间和事件状态，不能仅停止身体却让眼睛时钟继续跑。暂停时同时切换 mode 的情况保持暂停姿态，解除暂停后才应用 REST。

## 数值验证与真实网页边界

`verify-ocular-r04.mjs` 与 `evidence/R04_OCULAR_REPORT.json` 共 33 项通过。覆盖六来源各 30 控制器、120 秒双重确定重放、严格角度/速度/步长、C2 首尾、变化步长的事件时刻一致、暂停冻结、REST 全零、恢复首帧不跳、实测 frame/角膜余量，以及 30 控制器 CPU 更新探针。
