# 全部 Mother 共用：真实三维工作台硬门禁

版本：1.0.0

适用范围：Ocean Mother、Weather Mother、Cloud Mother、Landscape Mother、Farmland Mother、Brick Mother、Tiles Mother、建筑、人物、动物、飞机、Object DNA、Three.js 以及后续全部生产线。

本门禁优先于赶进度、概念展示、视觉提案和临时占位。

## 一、默认任务解释

用户提出“做一版”“重新做”“继续做”“给我看”“做个东西看一下”“按照参考做”“展示效果”时，默认含义是：

1. 修改真实项目源码；
2. 生成真实三维几何、材质、动作或程序化场；
3. 交付可以旋转、缩放、切换镜头或操作参数的三维工作台；
4. 使用 Three.js、WebGPU、UE 或项目既定三维运行时；
5. 给出经过真实浏览器验证的固定公网 HTTPS 工作台入口。

上述表达绝不解释为生成概念图、效果图、海报、缩略图、静态预览图或伪造的界面截图。

## 二、图像工具硬禁令

除非用户在当前对话中明确要求“生成图片”“画一张图”“修改这张图片”“给我截图”，否则：

- 禁止调用任何图像生成工具；
- 禁止调用图像编辑或风格迁移工具；
- 禁止把参考截图转成新的效果图交付；
- 禁止用静态图片、视频或 Canvas 假画面替代真实三维实现；
- 禁止因为真实三维尚未完成，就先生成一张图填补进度。

如果暂时没有可运行的三维成果，正确处理是继续修改源码并明确“尚未形成可验收三维版本”，而不是生成图片。

## 三、图片和截图只允许作为内部证据

浏览器自动化和人工检查可以保存截图，但用途只能是：

- 检查构图、穿模、材质、镜头和运行错误；
- 与上一版本进行视觉对照；
- 记录 QA 证据；
- 支持内部回归测试。

未经用户明确要求，不得把 QA 截图当作创作成果、版本交付或三维工作台的替代品发送给用户。

## 四、每一份计划、任务卡和交接清单必须包含

所有 Mother 的规划、任务卡、会议纪要、执行清单、交接包、README、START_HERE、AGENTS、发布说明和验收报告，都必须逐字或等义包含以下检查项：

- [ ] 本任务没有用生成图片代替真实三维实现；
- [ ] 已实际修改生产源码，而不是只做视觉提案；
- [ ] 用户看到的是可交互三维工作台，不是静态图片、视频或占位页；
- [ ] 画面来自实时三维运行时；
- [ ] 镜头、控制和用户要求的交互可以实际操作；
- [ ] 公网固定链接已回读并通过真实浏览器检查；
- [ ] 如果只有截图而没有工作台，本轮判定失败，不得交付。

## 五、交付前硬门禁

任何成果发给用户以前，必须同时满足：

1. `sourceModified=true`：真实生产源码已修改；
2. `interactive3D=true`：存在真实可交互三维画面；
3. `staticImageSubstitute=false`：不存在图片代替三维的情况；
4. `publicHttpsPassed=true`：固定公网 HTTPS 地址可访问；
5. `browserPassed=true`：真实浏览器完成启动和关键交互；
6. `visualAcceptancePending=true/false`：视觉状态诚实记录，不自动宣称通过。

任一项未满足，就不允许把静态图、概念图或截图包装成“进展”或“完成版”。

## 六、失败处理

如果误用了图片作为三维任务成果：

1. 立即停止该路线；
2. 图片不进入生产继承链；
3. 不在图片上继续做更多图片；
4. 返回真实源码和三维运行时；
5. 重新建立可交互工作台后再交付。

本规则是全部 Mother 的永久执行边界。
