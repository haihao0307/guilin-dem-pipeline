# Mother 共用在线网页交付门禁

版本：1.2.0

适用范围：DEM、Cloud Mother、Weather Mother、Ocean Mother、Coast、Landscape Mother、Brick Mother、Tiles Mother、建筑、人物、动物以及后续全部在线工作台。

交付前同时读取 `knowledge/REAL_3D_WORKBENCH_ONLY_GATE.md`。本文件负责公网发布闭环；后者负责禁止用静态图片替代真实三维实现。

## 核心规则

用户通过公开在线网页验收。任何 HTML、工作台、预览页和测试入口，在真实公网地址完成回读以前，均不得向用户报告“已经上线”“可以打开”或“发布完成”。

链接属于交付成果的一部分。404、403、空白页、错误重定向、资源缺失、旧版本缓存、页面启动失败，均视为交付失败。发现后立即重新发布并重新验证，不把排错成本转交给用户。

## 真实三维前置门禁

任何“做一版”“重新做”“继续做”“给我看”“按参考做”的任务，在进入发布闭环以前必须先满足：

1. 真实生产源码已经修改；
2. 页面包含可交互三维运行时，而不是静态图片、视频、Canvas 假画面或占位页；
3. 镜头、缩放、旋转、参数、动作或任务要求的交互至少有一项可实际操作；
4. 未经用户明确要求，不得调用图像生成或图像编辑工具；
5. QA 截图只能作为内部证据，不能作为创作成果；
6. 如果只有截图而没有工作台，本轮判定失败，不进入发布。

## 唯一用户可见交付格式

每次常规成果交付只向用户展示一个公开网址。该网址必须可以直接点击，并自动进入最终在线工作台。不得让用户下载 HTML、压缩包或修正版全量包后再打开。

同一生产线拥有多个模块时，只分享总工作台入口，由页面内部导航进入各模块。不得把多个模块地址、研究入口、测试入口或资源地址同时发给用户。

全量包、源文件、清单、提交 SHA、内容哈希、QA 数据、截图、构建产物、沙箱链接和发布回执继续在内部生成、保存和验证。用户没有明确索要时，不在回复中展示这些内容。

用户明确索要文件、全量包、源码、截图、哈希或验收报告时，才允许额外提供。除此以外，回复中的可操作交付信息只保留一个直接网址。

## 强制发布闭环

1. 生成目标文件，并确认目标目录中存在大小大于零的 `index.html`。
2. 确认该页面是实时三维工作台，不是静态图片、视频或截图包装页。
3. 将文件提交到实际发布分支或实际部署系统。仅存在于本地、构建产物、功能分支或聊天沙箱不算上线。
4. 等待部署传播完成，从最终公开网址发起全新 HTTP 请求。
5. 最终地址必须返回 HTTP 200。重定向后的最终地址也必须返回 HTTP 200。
6. 回读正文必须包含本版本唯一标识，且不得包含 `404`、`File not found`、`Page not found` 或托管平台错误模板。
7. 对页面依赖的关键脚本、数据和样式执行资源回读。关键资源任一 404，整页判定失败。
8. 使用真实浏览器完成启动检查，至少确认三维画布或主要界面出现、无页面异常、无控制台致命错误、无关键资源失败。
9. 实际操作至少一个三维交互：旋转、缩放、镜头切换、参数调节、动作触发或项目指定操作。
10. 桌面与手机入口分别检查。涉及触控、麦克风、摄像头或 WebGL 的功能，继续完成对应设备检查。
11. 保存公开网址、HTTP 状态、回读字节数、内容哈希、提交 SHA、验证时间和浏览器证据。
12. 只有 `shareAllowed=true` 才能把链接发给用户。任何一项失败时，修复并从第 3 步重新执行。

## 防止重复浪费时间

禁止根据仓库路径猜测公开网址。禁止在部署尚未传播时先发链接让用户试。禁止把本地截图当作在线发布证据。禁止把构建成功当作公开访问成功。禁止沿用尚未回读的旧链接。禁止用下载文件替代在线页面。禁止在一个回复中堆叠多个交付入口。禁止用生成图片、效果图、概念图、静态截图、视频或占位页冒充三维进展。

发布说明中的状态必须区分：

1. `sourceModified`：真实生产源码已修改。
2. `interactive3D`：真实三维工作台可交互。
3. `staticImageSubstitute`：必须为 `false`。
4. `buildPassed`：文件生成完成。
5. `deployed`：文件已进入实际发布系统。
6. `httpPassed`：最终公网地址返回 200 并匹配版本标识。
7. `browserPassed`：真实浏览器已启动并完成关键交互。
8. `shareAllowed`：上述要求及任务要求的设备检查全部通过。

## 自动化要求

各生产线应建立公开地址烟雾测试。每次发布后轮询最终网址，确认 200、版本标识和关键资源，再生成 `PUBLICATION_PROOF.json`。工作流失败时不得发链接。旧版入口在新版公开验证通过以前保持可用，以便回滚。

`PUBLICATION_PROOF.json` 至少包含：

```json
{
  "sourceModified": true,
  "interactive3D": true,
  "staticImageSubstitute": false,
  "publicHttpsPassed": true,
  "browserPassed": true,
  "shareAllowed": true
}
```

该门禁优先于赶进度。少发一次链接的成本很低；让用户打开一次 404，或用一张无用图片代替三维成果，都会损失真实的操作时间和判断节奏。
