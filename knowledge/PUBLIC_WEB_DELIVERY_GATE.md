# Mother 共用在线网页交付门禁

版本：1.0.0

适用范围：DEM、Cloud Mother、Weather Mother、Ocean Mother、Coast、Landscape Mother、Brick Mother、Tiles Mother、建筑、人物、动物以及后续全部在线工作台。

## 核心规则

用户通过公开在线网页验收。任何 HTML、工作台、预览页和测试入口，在真实公网地址完成回读以前，均不得向用户报告“已经上线”“可以打开”或“发布完成”。

链接属于交付成果的一部分。404、403、空白页、错误重定向、资源缺失、旧版本缓存、页面启动失败，均视为交付失败。发现后立即重新发布并重新验证，不把排错成本转交给用户。

## 强制发布闭环

1. 生成目标文件，并确认目标目录中存在大小大于零的 `index.html`。
2. 将文件提交到实际发布分支或实际部署系统。仅存在于本地、构建产物、功能分支或聊天沙箱不算上线。
3. 等待部署传播完成，从最终公开网址发起全新 HTTP 请求。
4. 最终地址必须返回 HTTP 200。重定向后的最终地址也必须返回 HTTP 200。
5. 回读正文必须包含本版本唯一标识，且不得包含 `404`、`File not found`、`Page not found` 或托管平台错误模板。
6. 对页面依赖的关键脚本、数据和样式执行资源回读。关键资源任一 404，整页判定失败。
7. 使用真实浏览器完成启动检查，至少确认画布或主要界面出现、无页面异常、无控制台致命错误、无关键资源失败。
8. 桌面与手机入口分别检查。涉及触控、麦克风、摄像头或 WebGL 的功能，继续完成对应设备检查。
9. 保存公开网址、HTTP 状态、回读字节数、内容哈希、提交 SHA、验证时间和浏览器证据。
10. 只有 `shareAllowed=true` 才能把链接发给用户。任何一项失败时，修复并从第 2 步重新执行。

## 防止重复浪费时间

禁止根据仓库路径猜测公开网址。禁止在部署尚未传播时先发链接让用户试。禁止把本地截图当作在线发布证据。禁止把构建成功当作公开访问成功。禁止沿用尚未回读的旧链接。

发布说明中的状态必须区分：

1. `buildPassed`：文件生成完成。
2. `deployed`：文件已进入实际发布系统。
3. `httpPassed`：最终公网地址返回 200 并匹配版本标识。
4. `browserPassed`：真实浏览器已启动并完成关键交互。
5. `shareAllowed`：前三项及任务要求的设备检查全部通过。

## 自动化要求

各生产线应建立公开地址烟雾测试。每次发布后轮询最终网址，确认 200、版本标识和关键资源，再生成 `PUBLICATION_PROOF.json`。工作流失败时不得发链接。旧版入口在新版公开验证通过以前保持可用，以便回滚。

该门禁优先于赶进度。少发一次链接的成本很低，用户打开一次 404 会损失真实的操作时间和判断节奏。
