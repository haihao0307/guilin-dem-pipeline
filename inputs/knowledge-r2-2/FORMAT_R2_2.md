# 温州对象与证据格式 R2.2（实验草案）

2026-09-09。范围是 R1 已验证资料的明确表达，不是通用标准定稿或新三维生产完成声明。

对象分为资料集、查询位置和有证据的实际物体。查询位置不能转记为土壤实体或地形生成规则。身份与修订分开，坐标父架与组成归属分开；坐标记录必须带参考架。所有未知量用 null 配合原因，禁止以零代替未知。

每个测量记录保存值、单位、方法、数据支持范围、基准、误差和来源引用。高程的 12.5 m 是归档格距；土壤的 250 m 是预测网格间距；均不代表独立实测精度。数值回环误差和物理位置误差分开。预测分位区间不是仪器测量误差。

连接单独记录双方、各自连接点、接触区域、允许状态及证据。当前只有同位置取数，因此 connections.status=unknown、items=[]；这不等于断言没有实际连接。shapeRules 同理，未知曲面规则不由三角面列表补全。资料时间、观测时间、知识时间分别保存，当前不创建统一物理时刻。

R1 知识图及查询文件按原字节保留。R2 增加引用与对象封装，所有查询值逐项回比 R1。证据以相对路径、SHA256和字节数锁定；来源更改需新修订，不覆盖旧快照。dependencies 指向带修订的对象或锁定来源；修订影响仅用于重新验收，不自动把新结论传播成事实。

显示是独立派生层：网页只显示现有查询点、统计图和记录。它不建立地形资产或替代曲面规则。网页文件量、对象档案量与旧DEM载荷量分别计量。清理完成共同证据仍缺失，新三维资产和新生产工具继续暂停。

验收顺序：身份唯一 → 来源完整 → 框架引用 → 坐标/组成独立 → 未知与误差 → 显式连接 → 曲面边界 → 显示。三维生产的后续验收还须有清理完成证据、明确的曲面规则与边界、参考架/误差、相机对照和固定公网版本验收。
