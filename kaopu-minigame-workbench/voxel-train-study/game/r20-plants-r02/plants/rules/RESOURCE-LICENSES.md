# Resource provenance

New plant-family geometry and embedded RGBA materials are generated by this project. No externally downloaded plant models have been added. Surface69 introduces the explicitly licensed photographic sources below. Fixed resources retain provenance and hashes; algorithm changes require a new generator version and must not overwrite historical assets.

This work does not separately change the licensing of code or generated results, and procedural generation does not imply public-domain status. Existing `public/assets` and `public/bases` come from the frozen 1.14 source and retain their original provenance and licenses. This document does not grant new rights to third-party content.

Runtime and SDK distributions retain their respective LICENSE files. Third-party dependency licenses are those shipped with the versions in the lockfile. Reference pages were used to study structure, interaction and composition; their models, textures and scripts were not copied.

## 4.1 procedural natural-grass texture

`natural-grass-neutral-1` is a project-generated 16 x 64 neutral RGBA texture. It does not copy reference-site textures, models or scripts. It retains the existing resource-1 contract metadata `source.license: CC0-1.0`. That metadata applies only to this procedural texture; it does not change licenses for code, user scenes, third-party plant models or existing public resources. Groundcover fields are derived user-scene data and are not relicensed as public textures.

## Geometry-based groundcover

Cushion short grass, rosette groundcover and their distributions are generated by this project. The live rendering and public client of [TUMBLE](https://grass-world-meadow.netlify.app/) were studied for grass crowns, layering and ground-conforming meshes. Its scripts, models and textures are not included in the product.

## Ngellil 4.3 candidate

The tropical geometry, leaf/bark RGBA surfaces, litter and support meshes are procedural project outputs. Four shared 256 x 256 RGBA resources use the existing CC0-1.0 resource metadata for those generated pixels only. No third-party photographs, models or texture bytes are redistributed. Historical Ngellil EA and Kew links are evidence references, not claims of a license to redistribute their content. The previous geometry, resource and package licenses remain unchanged.

## Tropical forest 4.4

The revised tropical plants use fourteen project-generated 512 x 512 colour/normal/roughness leaf atlas sets. Each tile contains one organ, with four outline variants and four leaf-age cohorts. Forest bark version 3 uses two project-generated 256 x 256 colour/normal/roughness sets. These saved procedural pixels carry CC0-1.0 metadata. Reference photographs and the Ngellil assessment are linked for evidence; no image, texture or model from those sources is redistributed. Existing code and geometry licenses remain unchanged.

## Healthy broad-leaved herb surface68

Eight 256x256 RGBA8 lamina textures are generated by `src/Shared/TropicalHerbSurface68.ts` and carry CC0-1.0 provenance in the saved resource table. Botanical sources are references for morphology only; no source photograph or illustration is redistributed in the textures or review. The review images are screenshots of this project.

## Scanned bark proxies69

Two CC0 sources from Poly Haven are included: [Japanese Camphor Bark](https://polyhaven.com/a/japanese_camphor_bark), by Charlotte Baglioni, and [Bark Willow 02](https://polyhaven.com/a/bark_willow_02), by Charlotte Baglioni. [Poly Haven asset licence](https://polyhaven.com/license): CC0-1.0. Maintained original colour/OpenGL-normal/roughness/displacement maps, URLs and verified hashes live in `data/bark69/`; deterministic derived maps are baked by `scripts/bake-bark69.py`. Saved resources carry `kind: derived-cc0`, the exact source URI and source asset ID. These are calibrated surface proxies; they are not scans of Artocarpus mariannensis or Calophyllum inophyllum. Existing code/geometry licences remain unchanged.

## Independent tropical library76

The new library includes a third CC0 source: [Bark Platanus](https://polyhaven.com/a/bark_platanus), by Dimitrios Savva, alongside the existing camphor and willow originals above. Maintained source URLs, authors and MD5 checks live in `data/tropical-library/bark76/`; `scripts/bake-bark76.py` verifies all twelve original maps before deriving twenty independently bounded species proxy sets. Source proxies are not photographs of the target species. Each saved resource records its actual Poly Haven asset and the botanical reference that bounds its use. [Poly Haven licence](https://polyhaven.com/license) remains CC0-1.0.

Native leaf atlases, quiet support/leaf-base scar atlases and neutral bract maps are project-generated pixels with CC0-1.0 resource metadata. Bract pigment, tissue age, geometry, organ graphs and wind frames are authored project data. Resource CC0 metadata does not relicense this project code, geometry, scenes or packages; no new general software licence is asserted. Kew, NParks, floras, herbarium sheets and scientific figures are research links only. Their photographs, figures and models are not included in the production assets.
