# FH88 驾驶动力模块 R01：模型和边界

本包是供既有游戏接入的自有 JavaScript 运行时与 SI 参数 JSON，不是另一个网站。旧 R02、热台架、旧游戏与生产发布均未更改。这里的参数文件 schema 是本包明确约定；尚未通过 KAOPU 编辑器真实原生存档编码器验证，不能仅凭 JSON 文件名宣称可直接导入编辑器。

## 已实现

- 油门 0–1；换向 -1/0/+1；截断 0.10–0.80；制动 0–1；供煤 kg/s；线路坡度 rise/run。
- 固定 1/120 s 步长，唯一 tick 时钟，车体距离、速度、轮角与连杆输入同步。
- 用缸压、双作用总排量、截断和多变膨胀求每转功，再除每转行程得到有限零速力。没有“恒定 2 MW ÷ 一个很小速度”的起步伪公式。
- 有限汽阀通量、热储能、煤和可用补水库存，火床 45 s 热滞后，供汽热量支出与牵引机械功分别记账。
- 黏着牵引上限、列车制动黏着上限、制动建立/释放滞后、滚动/气动阻力及坡度力。
- 静止保持与停止事件分段积分，制动力不把停下的车“刹成倒车”。上坡停住后若保持力不足，可真实向坡下溜。
- 正向、倒车、滑行、制动、供汽耗竭、暂停、长帧积压、复位与非法输入拒绝。

## 每步所算的公式

全部采用 kg、m、s、N、Pa（绝压）、J、W，角度 rad。

双作用三缸每米扫气容积：

V' = 2 n (πd²/4) stroke / (πD)  [m³/m]

油门是“有效入口压强控制”简化，零速目标 p_target = p_exhaust + throttle (p_boiler - p_exhaust)。这不是实测调节阀开度-压力关系。气流质量容量采用明确的平方根压差近似：

m_dot_cap = m_dot_ref · throttle · sqrt((p_boiler - p_chest)/(p_reference - p_exhaust))

循环需求 m_dot = cutoff · V' · p_chest/(R_steam T) · |v|。每 tick 以不低于本步可能最大速度的保守估计求入口压力，避免零速第一步穿透流量上限。这是理想气体/孔口近似，没有声称使用 IF97 蒸汽物性或真实阻塞喷嘴求解。

阀开时缸压 p_in；有效行程 u 超过 cutoff=c 后 p(u)=p_in(c/u)^n，降到背压后视为释放，不继续给出负膨胀功。积分 ∫ max(p(u)-p_exhaust,0) du 得循环平均有效压。指示力按排量积分并乘 diagramFactor，且受到每米供汽热量 × maxIndicatedHeatFraction 的能量上限约束；轮周力再乘 mechanicalEfficiency。除的是车轮每转的几何行程，没有速度分母，静止可产生有限力。

这仍是循环平均起步：默认三缸有可用配汽，不能断言某个瞬间的阀位、第一缸冲程或死点扭矩已被仿真。连杆显示可按精确机构几何运动，但循环平均力不能伪装成三根活塞的瞬时载荷。

牵引限幅 |F| ≤ μ M_adh g。超限时按相同比例降低力与耗汽，相当于理想即时供汽调节，不模拟打滑，不代表历史机车装有真实防滑控制。轮角是距离/R；不存在一个空转轮速被错误当成列车前进速度。

机械方程：M_effective a = F_drive - F_resistance - F_brake + F_grade。
M_effective = mass × equivalentMassFactor；后者是旋转惯量等效假设。
F_resistance=A+B|v|+Cv²；F_grade=-mg sin(atan(grade))。
一次 tick 内取常力，在越过零速时分段。位移用 v₀dt+½adt²，所以每段动能变化严格等于合力×位移；阻力系数随速度的冻结误差仍需步长收敛检查。

热模型：可用热储能 E=C(p-p_exhaust)。初始参数 C=1500 J/Pa 是设计假设。它不是水汽两相状态方程，也不是把 R02 的总内能直接兑换成全部可用机械功。火床输入 = 实际供煤质量 × LHV × 吸热比例；火床向锅炉释放用一阶滞后的解析更新。锅炉依次计入释放、散热、达到研究上界的卸能损失和主机用汽热支出。使用每 kg 蒸汽固定 2.8 MJ 的相对给水热需求，另以可调指示效率上限约束机械功。上界是游戏研究参数，不是可施工安全阀设定。

实际耗汽质量 = 当前每米耗汽 × 实际走行距离；每米耗汽与力同时受理想黏着调节和剩余库存限制。停车时不模拟汽缸容积初次充填、泄漏和辅机用汽，因此“停住开着汽门无主机流量”是模型简化，不是对真实机车的描述。

## 能量账

thermalEnergyJ = Δ(锅炉热储能 + 火床储能) - 煤化学能 + 未吸收燃料热 + 散热 + 卸能 + 蒸汽热支出。

mechanicalEnergyJ = Δ(½M_effective v²) - 轮周功 - 坡度功 + 滚动损失 + 制动损失。

engineEnergyJ = 蒸汽热支出 - 轮周功 - 机械损失 - 排汽/转换余热。

煤、水也有独立质量残差。倒向汽力若吸收车体动能，这部分进入余热，不虚构回充锅炉。守恒残差小只说明这组模型闭合，并不验证真实锅炉参数、持续额定功率、最高速度或时刻表。

## 参数来源与 R02 审读

继承的候选几何为 3 缸、缸径 0.457 m、行程 0.711 m、动轮 1.90 m。205 t 总质量、1.08 等效惯量、60 t 黏着重、μ=.15 沿用既有研究假设。未知参数全部集中在 parameters.json，可调但没有称为实测。

R02 原热台架只接受预设速度，≤0.1 m/s 无起步输出；同一 speed 同时用于轮转速和黏着功率上限。旧交叉审读的 120 s 案例压力由 18 降至 12.743 bar，耗用 739.19 MJ 储能。不能把该案例的 2 MW 目标误报为持续额定功率。本包不直接移植那份 Python IF97 模型，而给出明确更低阶、可在浏览器实时积分的模型；因此本包数值与旧热台架不可当成同一校准模型相互替代。

### 已查验的一手依据（2026-10-10）

- NASA Glenn, Work Equals Force Times Distance: https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/work/ 。用于功=力×位移、功率=力×速度及零位移不产生平移机械功的基本关系；不为本包参数背书。
- 英国 RAIB, Autumn Adhesion Investigation Part 3, PDF 第6页（印刷页码6）: https://assets.publishing.service.gov.uk/media/547c906840f0b602440001ad/R252006_070108_Part_3_Adhesion_Review.pdf 。用于区分轮滑/空转与车速，及黏着受轮轨条件变化影响；本包μ=.15仍为研究假设。
- IAPWS R7-97(2012): https://iapws.org/technical-guidance/release/IF97-Rev 。用于界定严谨水汽物性方法；本包未实现该物性求解，不能借此声称已验证。

## 未实现与不能声称

总质量在本次运行内冻结，煤水消耗不回写车辆惯量；大库存变化时需要进一步处理变质量与排汽动量。

没有逐阀事件、独立缸压状态、连杆/曲轴受力反馈、独立轮滑动力学、真实轮缘轨型、碰撞脱轨、曲线附加阻力、车钩缓冲、逐车制动传播、锅炉水位/注水器、冷炉升火、详细热交换器、故障保护或蒸汽工程认证。没有真实线路/信号调度，也没有将研究用参数自动变成120 km/h的运行许可。真正旧游戏场景交互测试、KAOPU原生保存/重载、生产部署必须另有真实宿主证据。
