# FH88 驾驶机构研究台 R04

这是可操控的原创函数机构研究入口，当前不替换已认可的列车游戏模型，也不声称实现用户定稿的88罩形和全套品牌。

## 当前入口

index.html（drive.html同一入口）是驾驶研究台；mechanism.html保留R03常速机构实验。默认只显示新机构，旧函数试验壳为可选对照。它的鼻端、缓冲梁、走台和悬挂仍粗糙，不能当成88外观交付。

驾驶使用120Hz固定步长的循环平均蒸汽/纵向动力模型。油门、截汽、制动、换向和供汽储备影响同一物理时钟；车辆世界位置、轮角、不同直径承载轮和三根主杆从该状态求值。模型包括明确的黏着牵引限幅，尚未积分真实轮滑。轮轨截面、曲线、逐缸阀时序、内曲轴实体和完整结构安全不在通过范围内。

压力储备、质量和阻力等均是原创可调假设，不是实车测值；锅炉热状态不使用完整水蒸汽状态方程。真实限制详见physics/MODEL.md。高速度的数值输出不代表真实性、线路许可或安全认证。

## 操作

开始驾驶后先缓解制动，再开油门。W/S调油门，空格关闭油门并施加制动；换向必须近停且关油门。暂停会冻结物理时间，复位回热启动状态。离开页面时自动暂停，不按隐藏页面经过的时间瞬移。

.KaoPu保存设置使用真正SQLite原型容器及明确FH88实验profile，规则依赖SHA必须匹配。本步保存驾驶参数、启动配方、视角和仅供检查的完整快照；重载始终暂停、以配方重新热启动，不假称继续旧锅炉或动力断点。它不是所有KAOPU软件通用格式，旧图像reader和旧函数reader不支持此profile。

## 几何与边界

动轮1.900m、主杆3.200m、行程0.711m。轨内侧距1.435m是名义矩形轨头代理；实际踏面轮缘尚未设计。外形坐标是明确新采用的比例，而非历史精准标定。当前为净空而将旧试验壳刚性抬高260mm，最高点4.205792m，重心及悬挂影响未知。下一步应重设计走台/轮罩、鼻端与支撑、机架承载，不能把该抬升当最终设计。

原点契约为(positionM−rollingOriginPositionM)=R×wheelAngleRad，初始主曲柄相位可明确指定，不能把世界位置直接换成轮角。载入失败、坏参数、错误轮径均须保持既有状态。

## 依赖与许可

本体由参数、规则依赖、部件/连接规则身份和实例状态组成；显示面由函数临时生成，无老师网格、贴图或采样动画。Three.js MIT许可随frozen/learned-shape/vendor目录保留。现有用户定稿的Flying Hongkonger、左右C天使及公司牌仍待原生化/布局验证，本候选未用新图替换它们。

数值、SQLite独立读回与真实浏览器结果分别保存，不能用机构截图替代驾驶验收。最终准确测试与固定提交信息见随版验收记录。

## 本轮实际验收

冻结原生机构、120Hz驾驶内核与SQLite profile已通过真实Chrome/WebGL2按钮操作回归：起步、收油滑行、刹停后不反弹、倒车、暂停、非零世界起点、初始相位及坏档拒绝。地面代理跟随世界位置的小修另轮重跑通过。对应精确函数哈希与实测数值见QA/REAL_BROWSER_VALIDATION.json。

浏览器确实下载135168B的.KaoPu SQLite文件并通过界面重载，独立sqlite3检查完整性为ok。载入为暂停的热启动配方；保留旧快照供查验，不恢复旧热力断点。原始CI字库缺失造成方框，最终证据改用Ubuntu官方Noto中文字库，未重画UI或修改中文标签。
