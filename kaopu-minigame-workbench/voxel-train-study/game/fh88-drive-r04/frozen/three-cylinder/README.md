# 88原创：米制轨距与三缸传力接口 R01

2026-10-10。独立候选，不修改已冻结的学习外形或运行入口，不复原A3/A4小零件。

复跑：

    node test-three-cylinder.mjs

## 本轮选择

轨距1.435 m指本代理模型的两轨头内侧面距离，不能误写成轮心距。自选70 mm矩形轨头代理后，轨头中心及名义滚动接触圆位于Y=±0.7525 m。轮半径0.950 m时，轴心Z=0.950 m，轮底名义接触点落在轨顶Z=0。实际轨头曲面、轮缘、轮对背距仍为空，因此不宣称真实轮轨匹配。

三缸为本轮原创、全水平、轴线穿过驱动轮心的台架候选；轴向Y分别−0.9075、0、+0.9075 m。外缸Y由接触线、45 mm轮包络半宽和110 mm杆平面间隔组成，不是爱好者模型采样或实车厂图测量。机架/缸体/曲轴空间可装入性尚未检查。

每缸相位明确写入设计输入：0、120、240°。这次选择的理由是同质量、同杆长和行程的平行缸可消去前两阶纵向往复惯性谐波；不是历史A3/A4曲柄角度的自动套用。倾斜内缸直接拒绝此简化接口，须另用明确坐标关系求解。

三缸共用一个世界时间标记、曲轴角、角速度和角加速度，分别叠加显式相位。缸力是外部输入，不含连杆反力；等效往复质量也必须显式输入。真实质量在design.json保留null，程序不偷偷填80 kg。

## 已验证的结果

6组测试检查名义轨距/轮轨接触基准、正反向无滑动运动学、非零滑速检测、三缸杆长闭合与总功率账、谐波/空间力偶、质量不等反例及单位/缺输入门禁。

功率账：三个活塞输入功率之和 = 轴功率 + 三个滑块动能变化率。仅考虑等效滑块质量；杆、车轮和曲轴惯性都未接入。

在规定120 km/h无滑动角速度、每缸80 kg敏感性输入下，7201相位采样的纵向惯性合力峰值约0.127 N；但绕轮轴中心标定点的Z向摇头力偶峰值约56.31 kN·m。该力偶来自不同横向缸位，不能因为纵向合力小就说整机平衡。它只是此候选、此质量假设、仅滑块惯性的载荷诊断。

把右缸假设质量改为88 kg、另两缸仍80 kg，纵向惯性合力峰值约3.890 kN。实际组件质量和质量中心因此属于下一步关键输入。
