# A4 原件轮／槽杆局部规则实验 R01

这是从完整老师原件重新开始的小范围保真实验。当前用户老师入口不变；本实验没有使用弃用的 student-native 或 A6 形体代码。

## 真实生成与原件回退

- 原节点 8/9/10：轮辋采用实际母线站点旋转面；一对辐条采用椭圆截面径向扫掠及根部位移规律。24588 三角中 7914 完整规则生成，86 混合，16588 完全原件保留。按源三角面积统计生成部分为 38.55%，不是整轮完成率。
- 轴毂复杂体的 3010 独立位置／6016 三角保留原件。截面中的圆环不证明贯通轴孔，未擅自填实或挖孔。
- 原节点 103：七个截面尺寸决定真实浅 C 形槽身，在指定长向范围挤出。1712 原三角不变，108 原端部裁片，16 生成槽身三角。原眼部、圈套、紧固件不改。生成段占源三角面积 58.50%，不是整杆完成率。
- 节点103位于 Main Gear_42，名称不能证实真实机械身份；其三眼布局可能是联动杆，当前不用“已核定主连杆”表述。
- 其他196 primitive、全部331节点层级、原材质与原动画保持。源动画相位应用于两格相同节点。

## 已测与未测

轮组同三角对应可得连续双向表面距离上界 3.221e-6 源单位；杆身双向采样最大 2.179e-7，不能冒称连续 Hausdorff 证明。原轮索引、UV及作者分裂法线仍使用原件；新杆槽中央 UV 没有纹理使用条件下的升级验收。当前材质均不绑定纹理，凹槽／辐条是真几何。

只替换已验证部分。当前不是独立小包或全轮／整车程序化完成。保留源缺陷不是机械安全认证。

## 对照方法

两格共享同一相机、同一联合包围盒、同材质、同光照和同 CSS 像素／源单位。每焦点／视图的相位前后尺度锁定，不独立 auto-fit。默认正侧，另有端面／顶面。section-comparison.png 叠加实际三角截面；这是几何图，不是渲染验收。

本次尺度为源单位。博物馆给出真实 A4 驱动轮径 2032 mm，但外轮缘网格直径不能自动当踏面直径；未偷偷按此缩放老师。可靠尺寸出处见 real-dimension-evidence.json。

## 验收入口

index.html 由浏览器恢复完整老师一次，克隆为候选并局部替换。browser.cjs 检查同材质、未改196primitive、相位同步、近远同长度投影及七组实际截图。真实浏览器图审结果另行记录，CPU通过不能替代形体检查。
