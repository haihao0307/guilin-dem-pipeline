## 操作

直接点击原件可选作者组或单 mesh。显示源 ID、点击三角及字段 ID、原节点局部尺寸、当前姿态世界尺寸、作用候选、已核证据和未知边界。尺寸以真实顶点测量，源单位未标定为米。

可隐藏、隔离和对准所选；“全部复位”恢复所有原件与首关键帧。九系统、主覆盖剥离、十轮对、外杆系、煤水车均只改变可见性，不重建或删除几何。完整原件保留 N55 的跨车合并组；煤水车单独组模式明确不把整组 N55 搬过来。

原动画时间轴、静态原姿态、首关键帧可比较。动画是源烘焙姿态，不是动力学或闭链机构解算。正侧、正面、俯视使用正投影，自由观察使用透视。

27 个真截面含全部 10,113 条原三角交线，逐条留有 mesh / 原三角 / 字段见证。没有补封口或造内壁。N55 每个原三角对应原几何分量；命中时可看 496 分量的空间区和最近原表面见证，不推断安装、铆钉身份或传力。

## 验证与复现

`python tests/validate_candidate.py` 检查索引闭包、全部截线平面、N55 原三角映射及语法。浏览器测试使用仓库原有只读 Chromium Actions 工作流；候选阶段仅拦截新目录，全部原件与依赖从同域实际加载。软件 GPU 的结果不代表用户设备帧率。
