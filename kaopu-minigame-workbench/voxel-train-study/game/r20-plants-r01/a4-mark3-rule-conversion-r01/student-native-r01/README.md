1. 第一方真实A4测量证据及单位清单；未知尺寸明确unknown，不从源模型推为真实米。
2. 少量可编辑截面与扫掠/曲面构成机车、后部壳及车厢；法线/UV随参数生成。
3. 机械逐部件原生重建并对照完整清单，保留驱动、连杆、制动和悬挂构造，禁止把占位示意说成完整。
4. 固定已有自有PBR大师适配，质感以实际画面验收；不把代码调用成功当视觉质量通过。
5. 正侧/正前/顶面正交、统一米制标尺。未证尺寸显式标注，用户视口不提供自由orbit或斜视。
