# 06 主壳转换核查候选

这是独立候选；05已发布入口及原A4/A6外观版本保持不变。仍未完成整车规则转换。

## 本轮范围

- Mark3大壳：五个窗带形体函数族通过X/Z镜像应用于20窗，完整XYZ覆盖13,852点，较05净增11,801点。
- 另6,727个侧板采样位置的XY由24控制点自由截面求值，Z为原采样；不能计入完整XYZ生成点数。
- A4最大壳片：真实7×24拓扑网格的X/Z通道生成784标量，Y保留自由值，完整XYZ点新增0。
- A4 Y的有限低阶实验：32系数B样条及58边界值Coons仍有0.017366/0.008055源单位形状偏差。明确保残差，不把它们称作浮点舍入或已学会全部曲面。

所有原件字段、拓扑、材质、UV和动画仍要求完整逐位复述。未解释位置与数值/形状纠正分别记账；仅gzip或模板复用不冒充形体函数。

## 自有材质候选 v3.1

复用固定R06金属、R03玻璃与原R08 paint工厂，按实际部件用途配置。新增22个明确漆面用途，默认clearcoat=0，防止把原粗糙黑顶强制变成清漆亮面。保源C/M/R、UV/贴图及alpha，原工厂微表面/粗糙场变化作为候选差异记录。所有纹理域仍是未米制标定的休止坐标。

默认显示源精确材质；自有材质需显式切换。Shader编译不等于视觉通过，必须检查实际截图、原对象恢复及几何不变。

## 核查

只用固定正侧/正前/顶面正交，所有格共同源单位/像素，不允许orbit或各格独立fit。两源尚未物理米制校准。

`browser.cjs`要求全字段校验后加载，三时刻世界矩阵与全帧像素等于原件，转换层原编码图片请求被阻断，纹理由规则区域和显式RGBA残差直接产生DataTexture。当前候选实际浏览器结果尚待执行。
