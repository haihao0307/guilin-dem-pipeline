# A6 原生连编可编辑 R01

独立新增版本；student-native-r01 与 student-native-r02 保留不改。

## 场景与交互

- 同一 Three.js 场景包含 A6 机车、油水车、车厢、全部继承的原生底盘机械和六个驱动轮实例。
- 默认全列正侧正交。正前、顶面均为标准正交投影；自由观察需要显式开启，并始终标注不能用于尺寸验收。
- 滚轮、＋／−、滑条、键盘加减键缩放。自由模式中可鼠标或单指旋转，双指缩放；方向键旋转，Escape 返回标准观察模式。
- 全列／机车／车厢三个焦点只切换初始固定观察中心，不改变比例、不自动放大、不改变任何模型变换。缩放需单独操作。
- 初始场景边界只采集一次。外壳编辑、结构切换、焦点与自由观察均不重新采集边界或自动取景。视口尺寸或标准方向改变时，仅根据同一冻结边界计算基础米／像素。
- 结构模式同时隐藏三个外壳和品牌字形，保留全部机械。

## 可编辑参数

| 参数 | 范围 / 默认 | 实际生成作用 |
|---|---|---|
| commonRoofHeight | 3.98–4.15 m / 4.03 m | 同时传入机车 topHeight、油水车与车厢 crownHeight，三者主车体冠高一致；排口与密封／弓框高度另计 |
| cabForwardShift | −0.15–＋0.15 m / 0 | 传入机车 cabShift 的相反数；正值向前，默认眼点 z=3.1664 m，在第一驱动轴 z=3.5814 m 前 0.415 m |

NATIVE_QA.heightMetrics 分别记录具名主车体曲面的实测冠高、含排口／附件的整体几何最高点及最高组件名称；不会把排口总高冒充车体冠高。

这些是 A6 外壳设计控制，不是整车历史尺寸、操作安全性或机械联动的验收。

## 冻结机械与连接布局

直接调用 R01 的 buildLocomotiveMechanics、buildMark3Mechanics、buildDrivingWheel：

- 机车及油水车机械：338 个原生命名组件
- 车厢机械：238 个原生命名组件
- 原生驱动轮：6 个实例；直径 2.032 m，轴 z=3.5814 / 5.7912 / 8.001 m
- 编辑外壳不重新生成或变更任何机械数组、材质实例、世界矩阵或对象身份
- 车厢外壳与其完整机械共享刚性平移 z=32.34 m，不缩放、不逐件调轴、不改源数组

布局公式：油水车末端 20.50 m ＋ 显示间距 0.35 m − 车厢机械局部最前端 −11.49 m = 车厢原点 32.34 m。该 0.35 m 仅为显示布局间距，不能当作已验证车钩长度、实际机械连接或运动净空。

## 独立新增静态连接

buildA6StaticCoupling 在机车／世界米制坐标中新增 6 件设计组件：降位适配板、水平拉杆、两端环眼及两支销。适配板连接原油水车后 dragbox 区域，把 1.30 m 原构造中心降至 0.82 m；后端接到已整体平移的原车厢前连接头中心，处理 0.48 m 高差。

这些是单独标注的新设计件，不纳入冻结的 338＋238 件机械或 6 个驱动轮实例，也不修改、替换任何旧件。它们只构建一次，外壳编辑保持其数组、世界矩阵与对象身份不变；结构模式中继续可见。NATIVE_QA 单独提供 staticCouplingGroup、staticCouplingEvidence 和 newDesignConnectionParts=6，总组件数另加这 6 件。

该连接是明确的临时静态设计展示；实际连接制式兼容性、承载路径、强度、运动、间隙、碰撞和运营安全均未验证。不得据此称列车机械连接或工程认证已经完成。浏览器测试保留连接处正侧局部截图，供核对实际显示。

## 原生材质和资产边界

a6-materials.mjs 在现有自有 native master 工厂上提供明确的 A6 实例配方。每个网格保存初始米制 restMatrix；车厢整体平移纳入同一米制材质域。皮肤、衣服、座椅为原生占位人形的外观实例，不是皮肤／布料的物理模型。

品牌沿用既有获授权的轮廓母版，通过 a6-branding.mjs 作为独立放置实例构建。无原模型 GLB、teacher mesh、位置数组、残差流或模型解码器请求。

## 验证

CPU-only：

    node a6-native-r01/interaction.test.mjs
    node --check a6-native-r01/view.mjs
    node --check a6-native-r01/browser.cjs

browser.cjs 只允许在获批准的 GitHub Actions 环境运行，编辑环境不启动浏览器或本地监听。candidate-workflow.yml 是待父任务审阅的 CI 配置，不代表已运行。真实 Chromium 检查包括：

- 338＋238 机械与 6 个轮实例、数组 SHA-256／世界矩阵／对象身份跨编辑一致
- 正侧／正前／顶面在前后深度的同单位等投影长度
- 三个实际 roof 参数联动、驾驶室前后微调、快速重复编辑、恢复、结构隐藏
- 固定初始边界、焦点仅移相机、可见缩放按钮、真实鼠标拖动／滚轮
- 390×844 触摸模拟的单指旋转与双指缩放
- 零源模型／数组／残差网络请求，材质工厂来源与 GPU fence 状态
- 保存正侧、正前、顶面、改后正侧、自由观察、结构、机车前侧三分之四视角、司机局部、驾驶室正前、手机全列、手机机车局部与手机自由观察截图
