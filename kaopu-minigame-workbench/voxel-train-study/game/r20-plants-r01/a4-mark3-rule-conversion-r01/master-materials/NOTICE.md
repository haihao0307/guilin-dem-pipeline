# Existing material master runtime closure

This train adapter calls the unchanged existing KAOPU R06 metal field and R03 finite-glass receiver. It does not reimplement their field equations. The glass module statically imports the full existing timber module, which is therefore retained even when only glass is selected.

The user-selected R06 release anchor is commit `7577ae37c8bc13bc3f7c0204c1857e83074c257a`. Full R01–R06 provenance (165 files and SHA-256 locks) is preserved separately in the research evidence. This runtime copy contains only the three imported vendor modules, two train adapter modules and necessary notice/license text. No R07 module is substituted.

Three r170 is injected by the train viewer. Its source `three.module.js` is byte-identical to the master R02 copy (SHA-256 `ce1fa418de16a19495a9f72495580e3015d7745c296d3ce0485897f902ddedfb`). The Three MIT license is included. KAOPU/FH88/timber original source and inherited rights remain their own; this notice does not relabel all code as MIT.

The user has selected the existing master baseline. That does not mean every family or its new train adaptation has passed visual or physical acceptance. Exact source mode remains available. Upgrade mode is explicitly different and uses a labelled uncalibrated fixed rest/reference domain unless actual calibration evidence is supplied.
