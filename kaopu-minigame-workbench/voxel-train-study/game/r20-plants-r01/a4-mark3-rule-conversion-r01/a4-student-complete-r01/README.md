# 完整 A4 学生单独入口

从保留的 `../viewer/` 完整转换读取路径建立。只执行 `converted('a4')`；不导入老师恢复器，不加载 Mark3、A6 或简化 native。共享 Three.js、GLTFLoader 等通用代码不属于老师几何资产。

## 保留
- 精确解码器、实现锁、所有残差分片和形体文件的完整性验证。
- 原完整节点、网格、材质、纹理规则和动画片段。
- 原源坐标与尺度；未把源单位标成真实米。
- 旧对照页、旧学生原生版和全部 A6 页面。

## 交互
默认正交侧视；正面、顶面、正侧重置为审阅视图。自由观察是主动进入的独立模式，可拖动旋转、滚轮缩放、右键平移；自由观察不用于尺寸比较。播放／暂停使用完整解码后的原动画片段，“原姿态”恢复原节点姿态。

## 旧入口诊断范围
旧页并行四模型，convertedOnly 仍加载两套学生；首次完整 A4 加载含多个顺序依赖。下载重试覆盖具体路径，未显示 error 字段，其他任务还可能覆盖致命错误。当前核对的远端实现锁、残差、形体与纹理规则均可达且哈希匹配，因此尚不能确定用户那次网络失败的具体原因。

新页单任务且错误包含具体 URL。没有通过跳过校验、删模型细节或替换简化生成器降低体积。仍含显式原残差，不能称全部原生函数化完成。

## 浏览器验收
`browser.cjs`：单模型 331 节点／200 网格／1 动画片段；播放改变姿态，暂停与复位；正侧／前／顶按钮，自由旋转改变相机；桌面与移动视口；拒绝老师源资产、老师恢复器、Mark3、A6、native 请求；统计实际网络字节。移动视口不等于 iOS 实机验证。
