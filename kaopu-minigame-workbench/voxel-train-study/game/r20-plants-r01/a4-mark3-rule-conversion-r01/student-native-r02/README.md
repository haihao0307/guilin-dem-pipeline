# 原生列车交互工作页 R02

本页基于已交付学生原生R01，复用全部曲面/轮组/底盘/材质函数。旧R01保留。它仍是原生学习结构，未完成A6既定造型、运动/受力/全局干涉验证。

## 用户主动观察与尺寸检查

- 默认正侧；正侧、正前、顶面为标准正交检查，两个面板始终共同米/像素。
- 自由观察仅由用户主动切换，可拖转、滚轮/双指缩放；标为观察模式，不作前后形体尺寸判断依据。
- 缩放同步作用两格。壳参数变化不自动fit，不改变模型缩放和真实轮径/轴距。切回标准视图恢复标准朝向；复位恢复初始参数和标尺。
- 参数只作用未标定外壳设计层；机械组件不被重建、隐藏删减或跟随壳缩放。结构解剖按钮仅可逆隐藏壳。
- 手机使用触控；设备模拟测试不等于iOS实机验收。

## 不变的依据

主轮名义踏面直径2.032m，三驱动轴中心z=3.5814/5.7912/8.001m，来自R01记录的一手尺寸。其它已核或未核尺寸、函数和材料语义沿用R01。运行不读取老师几何/残差，原件仅研究归档。
