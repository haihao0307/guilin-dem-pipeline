# 本版大师材质实例

机械原有 paint/blackPaint/brushedMetal/rubber/dark-iron 的颜色、金属度、粗糙度、环境强度和着色器保持R01原配方；测试逐值对照。

新增金字是既有R06参数化金属实例：#d6af60、metalness1、roughness0.32、env0.75，同时修改真正的金属着色器uniform，不能只改材质表面属性。红标使用既有漆面实例。司机skin/uniform/seat仅为已有大师漆面基础上的布局示意配方，不称生理皮肤、真实织物或人物项目成果。

玻璃保留R03有限厚度透射工厂，opacity1、depthWrite true，没有改为透明洞。新增实例env0.12、transmission0.96、IOR1.45、roughness0.045；R03着色器自身粗糙度下限为0.045，本版不谎称更低值有效。光学/几何14mm匹配需要生成器与GPU实际检查。有限屏幕空间透射不证明多层光学或真实车窗安全。

全部图案使用静态米制休止坐标。微表面仍为自有大师既有解析场，不预烘高密度点云；本轮不增加随机锈污。不把代码编译成功当质感验收，须观察真实正侧/正前/驾驶舱裁图。

## 首轮实际图后的清晰玻璃候选（1.1）

首轮司机可见但大罩乳白、模糊；不能将其称材质完成。第二轮明确A6实例：颜色#eef5f0、transmission1、env0.035、roughness0.012、IOR1.45。R03原厂玻璃着色器强制粗糙度下限0.045，使单改材质roughness无效；本版在独立A6适配层用受保护的单条替换把下限设为0.008，保留同一R03介电透射与沉积场、真实14mm玻璃、opacity1。旧vendor文件和机械材质不变。CPU真实onBeforeCompile已核替换唯一生效，实际质感仍待新CI图审。

灯投光元件独立8mm几何，其光学thickness也单独设为8mm，不继承窗厚14mm。
