# A6 R02 动态与审阅门禁

2026-10-18 用户明确要求修复自由观察误判，继续连接、动态干涉和动态按钮。旧 R01 保留。手机样式不改。

## 观察
仅固定正侧/正前/顶面，以及正侧左右20°、俯仰15°受限审阅。进入受限审阅须从侧向重置，不继承端视角。相机保持正交；不独立缩放单车，不改模型来伪修投影。自由斜看虽正交仍可能缩短和遮挡，这是 R01 错误来源。

## 机械
2.032 m 大轮、已核轴距、0.3302 m 曲柄和0.6604 m 标称活塞行程保持。未核定的学生原生刹车瓦、轴承套、支架、缸与导轨布局可以有记录地修正以得到实际闭环和净隙；原 R01 不覆盖，所有构件必须保留。

运动不是任意摆动：使用固定长度杆、销点闭合和滑块约束，每个周期检测。无法闭合的阀动/内缸/轨道关系要明确。局部运动学验证不等于整列工程安全认证。

连接必须给出两端关节、牵引路径、刚性长度和罩体随动。固定罩偏航穿插不能靠隐藏删除来通过。演示角度是明确限定的台架输入，不冒称特定曲线半径的铁路行驶。

## 材质
沿用固定版本自有 PBR 大师。漆层剥离使用同一因果场联动覆盖、底材、金属度、粗糙度和法线；原绿漆、金色字标保持，禁止灰色配方覆盖所有材料。

## 验证顺序
保存旧失败；修正并逐项 CPU 扫查；真实桌面 Chromium/软件 GPU 截图与交互；根实际图审；独立预览；公网同提交哈希与浏览器。手机仅回归现有布局，不声称 iOS 实机。每个通过的子系统与未完成清单分开列示。
