# A6 R02：同一因果层场的漆层、底漆与金属底材

## 这次实际接入了什么

R02 独立增加 `a6-causal-coating.mjs`。它直接导入锁定版 `master-materials-v3-1/r06-source-parameters.mjs` 的 `PARAMETERIZED_METAL_FIELDS`，继续使用 R06 `metalField` 的涂层损失、解析梯度、米制边界、附着力底漆残留，以及覆盖率驱动的 PBR 输出。

绿色和红色漆继续创建真正的 R08 `createTrainMatter(T).paint` 实例，经原有 native transport 进入 A6；并非另造一个灰色材质代替它。原有 R08 20 微米、65/m 的漆面微高度在完整漆层处保留；脱落处由同一个层场切换到薄底漆和钢底材。黑色涂装钢本来就在 R06 工厂上，本版只在 A6 独立适配层替换其场前缀。

旧 R01、固定母版 vendor 和其他材质工作台不修改。新增字段为运行时连续解析场，没有预烘颜色图、预存脱漆点云或密集采样阵列。测试用采样仅用于数值验证，不作为绘制数据。

## 保留 A6 的身份

- 原车绿色 `#103e35`、A6 红色 `#a62b24`、原黑漆的颜色与原粗糙度、环境反射强度仍作为完整表层配方。
- 金色字与装饰 `#d6af60`、其它金属件、玻璃、轮胎、司机及座椅不加入这项涂层损失。
- 不通过加随机 RGB 噪声或均匀灰色覆盖制造“旧”。
- 裸露区采用低明度钢色 `#535b59`；底漆采用低饱和 `#746b50`。两者为明确自有候选配方，没有历史漆料、合金或实测颜色认证。
- R06 的氧化类别、腐蚀坑与污渍分支在 A6 派生场中明确置零。湿润、历史时间、假接缝源均不启用。已有母版的锈蚀能力不等于本次有证据应当锈蚀。

## 参数与米制含义

公共接口：

```js
const library = createA6MaterialLibrary(THREE, {coatingWear: 0.32});
library.setCoatingWear(0.65);
const state = library.getCoatingState();
```

`coatingWear` 必须为有限数值 0–1。它控制既有层场的阈值 `1.02 - 0.50 * wear`，使涂层在局部损失势超过阈值后露出底层。它不是年限、全车脱漆百分比、腐蚀速度或力学疲劳寿命。0 为完整表层；1 为本场可调范围的最高损失，仍不意味着 100% 脱漆。修改时仅更新 uniform，不重建几何、不重编译着色器。

默认 0.32 用于保留大面积完整品牌漆。测试平面 2,813 个连续米制坐标的样本，默认损失均值约 0.11%，0.65 时约 5.30%；这些只描述测试采样，不能当作全车真实面积比例。全景中细小的漆口可能不明显，应在车身近看；比较磨耗阶段可用 0、0.32、0.65，不能把高值当成默认验收目标。

米制结构来自既有 R06：

- 漆层高度 0.140 mm，底漆高度 0.055 mm
- 横向剥离/底漆残留范围 0.180–1.100 mm，与纵向膜厚独立
- 主损失势为 13/m 的三倍频程场，配合已有空间扭曲；频率是格点尺度，不是周期条纹的波长
- 边界扰动幅度 1.200 mm、0.320 mm，频率 137/m、517/m，按像素足迹退隐
- 裸露钢微高度系数 6 µm、490/m，使用同一已有微结构场驱动局部粗糙度
- 所有输入坐标继承已声明的固定米制休止框架，不随着列车整体移动而游动

这些为母版已有设计尺度与本次明确的钢材微表面候选，不代表对某辆历史列车的测量。

## 一张层覆盖同时决定四类输出

场返回完整漆、残存底漆、裸露钢三份覆盖率，总和为 1。相同覆盖率同时控制：

1. 漫反射与导体 F0，避免仅做颜色斑点
2. 金属度，裸露钢才是金属反射
3. 粗糙度，漆、底漆和裸钢各用自身尺度
4. 0.140/0.055 mm 层高和微高度，进一步生成表面法线

R08 的完整漆微高度仅乘完整漆覆盖率；钢微高度仅存在于露出的底材。底漆由 R06 附着力袋状残留决定，未画一圈整齐的装饰轮廓。原 R08 clearcoat 如果有，则同步随完整漆覆盖退去。

## 柔性罩形变：显式材质休止属性

只固定 `restMatrix` 并不能冻结已经由 CPU 重建的形变顶点。若直接采样新的 `position`，弯曲过程中漆口仍会滑动。因此对需要形变的罩体材质，调用独立绑定：

```js
import {bindA6RestAttributes} from './src/a6-causal-coating.mjs';
const material = library.create('paint', {restMatrix, units: 'm'});
bindA6RestAttributes(material);
```

相应几何必须提供两个 vec3 属性：`a6RestPosition`、`a6RestNormal`。它们是形变前、已经置于既定米制材质休止框架中的坐标和法线，不再二次乘 `restMatrix`。休止几何与实时几何必须有相同顶点数、顺序和镶嵌拓扑；位置仍使用实时形变顶点，普通 `normal` 仍使用实时照明法线。不能把此材质缓存共享给缺少这两个属性的非罩体几何。

绑定在原有工厂和 A6 涂层回调执行后，以唯一命中检查改写 R06 `vRestM/vSurfaceN` 以及 R08 `vKP/vKN`。它只改变材质场坐标，不改变片元照明代码、几何位置或照明法线，程序缓存键有独立后缀。重复绑定安全且不会套多层回调。

新增 CPU 着色器钩子测试覆盖绿色、黑漆、红色三种实例，核对片元代码逐字保持不变、顶点只改变上述场赋值、程序缓存键隔离、重复绑定、实时磨耗 uniform 与源码漂移报错。几何属性对应关系须由罩体生成器/集成测试另验；仅调用这个材质函数不会假称已经验证几何。实际弯曲姿态下是否锁住漆口，仍需浏览器帧间对照确认。
