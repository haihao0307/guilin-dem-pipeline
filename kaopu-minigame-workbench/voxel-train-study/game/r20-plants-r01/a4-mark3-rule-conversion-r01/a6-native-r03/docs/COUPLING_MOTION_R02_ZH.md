# R02 双销连接与随动过渡罩

## 这次实际解决的范围

新增的连接设计有两个独立竖轴销接点、带真实孔洞的环眼、双耳叉、固定长度拉杆、油水车降位座及其焊缝、车厢原有柄轴外的双片夹箍及紧固耳/螺栓。新增设计件共 34 件。原机车/油水车 338 件、车厢 238 件和六个驱动轮实例都保留；此连接模块不改动原机械数组；测试使用 R02 的 correctA6Mechanics 整车修正结果，并单独保存 R01 源数组和 R02 运行数组的 SHA-256。新增设计没有使用 teacher 几何或运动数据。

油水车后 dragbox 的原构造中心是 y=1.30 m，车厢原柄轴中心是 y=0.82 m，需处理 0.48 m 高差。新前销为世界坐标 [0, 0.82, 20.18]，后销为车厢局部 [0, 0.82, -11.60]。车厢直线位置仍为 z=32.34 m，因此实际两销距离为 0.560 m。新后销与保留的原车厢连接头分开，避免在原头上凭空假定销孔。

## 闭环求解与牵引关系

车厢偏航角 α 和拉杆角 β 是检查输入；缺省 β=α/2。前销 A 固定，后销 B=A+R(β)[0,0,L]；车厢原点 O=B-R(α)b。这是两销与等长刚性杆的显式闭环约束。车厢及其全部机械、原连接头、转向架、车轮、车体和端部结构一起做同一刚体变换，不能单独摆动车壳掩饰断开。

输入角不由牵引力或钢轨解出，因此这是关节检查姿态，不是列车沿轨行驶。前后两端的演示拉力沿同一杆轴，大小相等、方向相反。100 kN 仅作说明时，0.48 m 降位产生约 48 kN·m 弯矩，不能把连接外观当成已通过承载验证。夹箍预紧、轴向抗滑、焊缝尺寸/强度和疲劳仍待工程设计。

机车与油水车保持刚性检查单元。既有三条并列拉杆的两端销、环眼都在原网格内；直接给油水车独立偏航会过约束这些杆件。本版不伪造这部分关节解。

## 绿色过渡罩的真实端点随动

R01 的静态过渡罩作为失败基线保留。R02 中油水车前端圈不动、车厢后端圈严格跟随整车刚体变换；两端之间使用五次平滑权重分布形变，两端权重导数为零，保留端部切向关系。内壁按变形后曲面的三维法线内偏 16 mm 重新计算，前后端缝维持约 6 mm。

机车—油水车段保持原位。绿色表面始终显示；不通过隐藏表面、只摆外壳或缩小原机械来获得“通过”。这解决的是显式端点约束下的几何随动，不是橡胶/金属材料弹性、应力或疲劳仿真。

## 验证与边界

- 两销闭环在 ±12°、0.1° 步进的解析姿态测试中误差小于 1e-12 m
- R02 展示范围为车厢偏航 ±3°；全机械和外壳干涉检查以 0.25° 步进覆盖
- 检查完整车厢对固定机车/油水车、随动罩对两端、拉杆对双耳叉/销及全部原机械
- 单独记录原柄轴与夹箍、原 dragbox 与降位座/焊缝的有意连接接触；不把这些接触藏在“零碰撞”统计中
- 比较所有原机械和车厢外壳的数组 SHA-256，确认检查前后不变
- 对随动罩采样检查纵向导数、曲面雅可比与 16 mm 法向厚度

本版的 ±3° 是离散姿态已检查范围，不是连续扫掠、运营转弯半径或车辆安全认证。全局罩体自接触、材料应变、轮轨/转向架约束、纵向间隙、缓冲、俯仰/侧滚、制动与动力传动仍未解决。

## 集成 API

buildA6CouplingMotion() 返回 partsByBody.fixed / drawbar / coach，三组新件都是直线状态的世界坐标。solveA6CouplingPose() 的 transforms.fixed / drawbar / coachDesign 分别施加给这三组。原有车厢局部坐标根节点使用 transforms.coach，不能把 coachDesign 用于原车厢局部数组。

buildA6FlexibleTransitions({crownHeight, coachOffsetZ, couplingPose}) 生成当前姿态的世界坐标过渡罩。姿态更新仅重建这六件罩体；相机取景基准、原机械数组和旧版本不变。

prepareA6CouplingInterference() 对输入完整网格建立三角形 AABB 树，剩余对使用三角形/线段交叉及点-面、边-边距离检查。结果没有命中仅表示搜索距离内无表面接近，不会编造一个精确最小间距。测试记录见 tests/coupling-motion.qa.json、tests/coupling-flexible-sweep.qa.json；用户可读结果见 qa/COUPLING_SWEEP_PUBLIC.json。
