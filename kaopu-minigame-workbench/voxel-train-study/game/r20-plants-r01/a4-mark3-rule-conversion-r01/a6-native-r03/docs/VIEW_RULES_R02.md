# A6 R02 侧向审查视角规则

## 修正目标

用户提供的手机画面显示，旧自由观察可以转到接近车尾轴向的位置，使整列纵向投影大幅缩短。正交相机能消除距离导致的近大远小，但不能消除观察方向导致的几何缩短。因此 R02 同时保留正交投影，并限制可拖动的观察方向。

本次交互修改只影响观察状态，不修改几何数组、机械尺寸、对象缩放或手机布局。

## 固定测量视图与侧向审查

- 正侧、正前、顶面仍是独立、显式的固定测量按钮。选择它们恢复各自的标准方向和 1× 缩放。
- 侧向审查每次进入都先恢复正侧：yaw = −90°，pitch = 0°。从正前或顶面进入也采用这个起点，不能继承车头、车尾或顶面的旋转姿态。
- 拖动范围固定为正侧左右各 20°，即 yaw ∈ [−110°, −70°]；俯仰 pitch ∈ [−15°, 15°]。
- 每一步拖动都立即钳制到范围内，不做角度环绕，不积累越界拖动量；反向拖动可立即离开边界。
- 进入侧向审查保留用户选择的观察中心与缩放数值，同时使用正侧的既有基准取景比例。它不对机车或车厢单独自动取景。
- 从侧向审查退出时，现有固定视图流程恢复标准正侧与 1× 缩放。正前和顶面只能通过各自按钮进入。
- 侧向审查仍有小幅几何缩短，不用于直接尺寸验收。尺寸检查使用对应固定测量视图。

## 投影约束

全列继续使用同一台正交相机、同一米制空间。相机水平与垂直视锥共用 metres-per-CSS-pixel 标量；同样尺寸的物体在相同姿态下移近或移远，投影尺寸相等。切换观察中心只平移相机目标，外壳编辑不会重算取景边界或自动缩放。

车长沿世界 Z 轴。对上述侧向范围，其水平投影长度系数是 |sin(yaw)|，至少为 cos(20°) ≈ 0.93969262；加入受限俯仰后，屏幕上的总投影长度不会小于这个值。也就是说，在同一缩放下，纵向线段最多因允许的观察角产生约 6.03% 缩短，无法再旋转到接近端面的轴向压缩画面。这一界限不是物理尺寸验收结论。

## 实现接口

- `enterSideInspection(state)`：建立上述标准正侧起点，返回同一状态对象。
- `INSPECTION_LIMITS`：冻结的 yaw / pitch 上下限、侧向锚点以及拖动灵敏度。
- `orbitView(state, deltaX, deltaY)`：固定视图不旋转；审查视图仅接受有限拖动数值，并在每次更新时约束姿态。旧调用路径若直接从正前或顶面设置 `free`，首次拖动也会先恢复正侧。
