# A6 原生连编可编辑 R02

本独立版本接续用户 2026-10-18 的视角、关节、动态干涉和油漆要求。旧 [R01](../a6-native-r01/index.html) 保留。

## 使用

- 正侧／正前／顶面为固定正交检查。侧向审阅仅能在正侧左右20°、俯仰15°内旋转，禁止沿车尾看向车头的近轴向角度。
- 展开“动态演示与连接检查”，可播放、暂停、单步5°、动态复位，设置相位速度。
- 连接关节角度限定±3°，松手后求解。完整车厢与关节同步，柔性罩由两端截面连续生成，不通过隐藏罩体消除穿插。
- “查看周期干涉检查”“查看连接检查”呈现绑定本版本的真实检查范围、失败与未解项。改变外壳高度后不能沿用默认外壳扫查结论。
- “漆层磨耗”控制自有 PBR 大师的涂层损失阈值，底漆、钢材、粗糙度和法线使用同一场；不是年龄或锈蚀百分比。

## 尺寸与原件

驱动轮2.032 m，三主轴3.5814/5.7912/8.001 m，曲柄0.3302 m，标称活塞行程0.6604 m不变。338件机车/油水车、238件车厢机械构件及六个大轮实例保留。R02针对学生原生未核定的缸/导轨布局、刹车瓦/轴承位置与支架路径做有记录修正；原R01源数组与版本保留。新增隐藏活塞杆延长段、双销连接架另列，不混作原机械。

## 边界

这是固定轮轴的局部运动学及连接关节台架。原阀动、内缸和共轭机构尚未完成闭环，不能把它当整台A4/A6已可运行。机车与油水车仍作为刚性整体，车厢转动为给定台架输入，不是轮轨转向求解。材料强度、夹紧预载、焊缝疲劳、承载、制动作用、弹簧动力与运营安全均未验证。界面始终保留未解部件及明示清单。

周期、接头和护罩的几何检查不等于工程认证。具体离散步长、保守包络、接触排除及实际三角面结果分别见检查报告。人体仍为布局示意；玻璃、长亮带与最终漆面质感继续待审。

GPU回压会放慢展示相位时间；相位速度不是列车时速，不声称手机/iOS实机或所有设备流畅。手机CSS沿用R01。
