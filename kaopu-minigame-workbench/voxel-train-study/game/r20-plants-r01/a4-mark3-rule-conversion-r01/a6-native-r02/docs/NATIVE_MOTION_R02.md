# A6 R02 原生轮杆、活塞与扫掠检查

## 结论与边界

这是明确标注的「设计运动学候选」。外侧驱动轮、联动杆、主连杆、十字头、活塞杆与缸内活塞使用同一个解析约束解；不是分别摆动的装饰动画。历史 A4 左右／内侧曲柄相位、完整配气、密封、载荷和整车动力学仍未核定。

- 保留 R01 文件与输入对象；没有修改原始 `locomotive-mechanics.mjs`、`driving-wheel.mjs` 或其数组。
- R02 保留全部 338 个原生机械组件名称。修改未核定的放置／结构时逐项记录，未删除、降面或以代理几何替代组件。
- 新增 4 个明确标记的原生件：2 段隐藏活塞杆延长件、2 个缸内活塞头。
- 六个驱动轮实例的全部轮胎、轮毂、20 根辐条、曲柄销与配重共同刚性转动。
- 核定尺寸保持：踏面直径 2.032 m；驱动轴 z=3.5814 / 5.7912 / 8.001 m；曲柄半径 0.3302 m；缸径 0.4699 m；行程 0.6604 m。
- 其他车轮、悬挂、制动、缓冲器、车钩和车厢没有假装随轮杆工作的独立摆动。

## 解析运动

坐标沿用母体：x 横向、y 轨面上高度、z 向后。相位 0 是当前 R02 的精确静态装配，0 和 360° 的矩阵完全相同。负角度与多周输入也归一到同一结果，不累积上一帧误差。

各轮销使用 y=R+r cosθ、z=z轴+r sinθ。左右同相是继承参考姿态的候选设定，不能当成历史 A4 相位。左轮先保留原镜向，再围绕世界 x 轴旋转；不会因镜向而把轮销与连杆转到相反方向。

两根联动杆的轴间距恒为 2.2098 m。主连杆为完整刚体，长度固定 3.317672901296931 m。R02 把整组外侧缸、十字头与导轨的轴线校到 y=1.016 m，滑块解析解为：

`z十字头 = z中轴 + r sinθ − sqrt(L² − (r cosθ)²)`

因此全周期滑块范围为 z=2.143327098703069～2.803727098703069 m，差值 0.6604000000000001 m。原先未核定的 y=1.346 m 偏置会产生约 0.66375874 m 行程，已保留在失败报告中，未通过改真实行程来迁就旧占位尺寸。

轮杆只使用刚性 4×4 变换。没有杆件伸缩、逐点蒙皮、按相位采样的动作字典或播放参考模型动画。

## R02 的实际修正

全部记录见 `MOTION_CORRECTED_SWEEP.json` 的 `corrections`。这些是明示的设计参数，不是新增的历史尺寸证据。

1. 外侧缸／活塞杆／十字头／导轨整体与轴高对齐，并向外移 10 mm。主连杆用原构造规则重新生成，保留完整杆身、环眼、截面和采样。
2. 六块驱动轮刹车瓦保持尺寸，外移 16 mm，避开内侧轮缘。轮胎斜面处名义最小径向间隙约 10.72 mm，外缘超出轮胎约 0.6 mm。
3. 六个轴颈衬套保持尺寸，内移 6 mm，消除原先 4.6 mm 轮毂重叠，留下 1.4 mm 轴向间隙。轴、轴箱和轮不动。
4. 前／后联动杆分别向外／向内移 30 mm，形成两个共轴关节平面。中间环眼端面相隔 5 mm，后杆最内面离轮毂 4.5 mm；杆长不变。
5. 主连杆向外移 180 mm，避开十字头实体、活塞杆与导轨。扩大后的十字头—主杆侧向间隙为 10.5 mm。十字头原销保留，并原生增加 180 mm 共轴销段。
6. 主连杆大端销采用明确的 270 mm 原生轴向堆叠，绝对 x 端点 0.987～1.257 m，接通原曲柄延长销和外置主杆。其内端离前联动杆端面 2.5 mm。
7. 两侧运动支架、膨胀连杆固定支架改为外侧立柱、轮缘上方横桥、内侧车架立柱。横桥中心 y=2.18 m，绕开原本横穿第一驱动轮的直梁；保留组件名称、承托功能与旧版原形。
8. 原缸体外半径 0.235 m 与核定内半径 0.23495 m 仅差 0.05 mm，无法直接挖成可用缸壁。R02 明示采用外半径 0.255 m、壁厚 20.05 mm；保留双盖、全部 24 个盖螺栓和阀室承托形体。
9. 后缸盖有真实半径 40 mm 通孔；杆半径 38 mm。缸体有真实 469.9 mm 内孔。活塞头半径 232.95 mm、厚 60 mm，与杆刚性连接；名义径向间隙 2 mm。没有将实心盖穿透当成通过。
10. 两段 420 mm 杆延长件让整个行程保持插入缸体。活塞头在前盖内表面前留至少 18.33 mm、后盖内表面前留至少 51.27 mm 轴向间隙。壁厚、活塞厚度及间隙均是设计假设，尚非压力／密封／制造验收。

## 未解机构不能冒充完整联动

原配气与内侧机构保留为静态参考，界面断开距离随相位明确给出。没有把一根回动曲柄单独转起来却声称整套配气已经接通。

原外侧配气若按最直接的四杆解释：回动偏心点轨道半径约 0.585423 m，固定支点距约 2.311076 m，偏心杆长约 2.096910 m，摇杆半径约 0.272947 m。整周所需最大距离约 2.896499 m，而后两者长度和仅 2.369857 m，缺约 0.526642 m。这说明现有占位关节不能直接闭合整周，并不证明这套占位拓扑就是历史 A4 的真实拓扑。

内侧缸、活塞杆、导轨的原始方向分别约 −10.30°、−4.71°、−2.93°，并不共线；其真实曲柄相位和导向拓扑也未核定。两类问题均不能通过装饰正弦动画掩盖。

## 扫掠检查究竟证明了什么

`screenA6SweptInterference` 使用渲染所用的全部原生顶点和三角形，包括完整机车外壳；不使用简化碰撞网格。

每个 1° 区间在中点精确变换所有顶点，再按该刚体的解析最大顶点速度 × 半区间角度扩大包围盒，并加浮点保护量。因此包围盒不重叠可以排除整个该区间的相交；不是只检查 360 张截屏。包围盒重叠只是候选，不能直接叫实际碰撞。

候选再执行原始三角形 BVH／SAT 表面相交测试，含共面三角形分离轴。输出具体组件、角度和两个三角形编号。它检查表面相交／接触，不测穿透深度，也不替代实体包含测试或连续精确三角形接触时刻求解。

只明确豁免刚性装配内的轮轴／轮毂、曲柄延长销／原轮销、同轴销段、活塞杆／十字头、杆／活塞头连接。关节环眼、刹车瓦、轴承、导轨、支架、缸孔、活塞头与缸盖仍受检查。原缸盖缺孔的旧版例外仅用于归档基线，R02 的杆／缸盖和活塞／缸体不再被豁免。

静态—静态整车碰撞不是这次动态扫掠的覆盖范围；另对新缸体与全部前导轮组件执行原始三角形检查。轨道、未传入的车辆外壳和未解运动的真实未来轨迹不在本次结果内。

报告文件：
- `MOTION_BASELINE_FAILURES.json`：原母体的行程偏差和原始碰撞证据
- `MOTION_PRE_GLAND_SWEEP.json`：修正轮杆后、真实缸孔前的中间结果
- `MOTION_CORRECTED_SWEEP.json`：最终修正、源码 SHA-256、1441 姿态约束检查、1° 连续包络和三角形证据
- `../qa/MOTION_SWEEP_PUBLIC.json`：界面读取的简洁报告

任何 `fullVehicleApproval`、`allMechanismsSolved` 都保持 false。没有离散表面相交不能被写成「整车无碰撞」。修改外壳参数后应重新生成对应报告。

## 集成 API

```js
const original = buildLocomotiveMechanics();
const {mechanics, corrections} = correctA6Mechanics(original);
const model = createA6MotionModel({mechanics, wheel: buildDrivingWheel()});
// exactly 338 retained names, plus model.supplementalParts (4 explicit new parts)
const renderParts = [...mechanics.parts, ...model.supplementalParts];
const pose = evaluateA6Motion(model, phaseRad);
```

`pose.partTransforms[name]` 是相对于 R02 静态原生缓冲区的列主序刚体矩阵。`pose.wheelTransforms` 含 `name / axleIndex / side / matrix`，matrix 是包括左轮镜向的完整本地到世界矩阵。运动组件必须按名称独立挂载，不能与静态件按材质合批。静态件不在变换字典内，保持原位。接口不要求某个渲染器，也不修改数组。

`correctA6Mechanics` 对已经修正的结果幂等，不会重复叠加偏移。初始姿态精确重置，轮杆评价与播放帧率无关。

运行：

```sh
node a6-native-r02/tests/motion.test.mjs
node a6-native-r02/tests/motion-sweep-report.mjs
```

第一项检查名称／原数组哈希保留、完整周回、镜向、刚性、固定杆长、关节误差、轮轴固定、活塞边界和非法输入。第二项重建失败基线与最终全壳扫掠报告；出现已支持机构或外壳的实际表面相交会失败，并先保存诊断结果。未解配气参考件的相交始终保留报告，不被吞掉。
