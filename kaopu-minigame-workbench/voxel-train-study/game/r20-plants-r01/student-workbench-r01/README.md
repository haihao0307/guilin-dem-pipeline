# 88 学生版独立工作台

本入口直接调用同目录上一级 train-model.mjs 的 createGameTrain()，继承主游戏的车体、煤水车、轮组、宽槽主连杆、十字头、制动及原生品牌。没有老师模型、来源 fields.bin、外来贴图或老师动画。

技术边界：既有自有函数生成 THREE BufferGeometry，再以网格和实例批次渲染。这不是纯无面或全隐式 KAOPU 实现；本次恢复没有擅自进行技术迁移。

初始基线：主游戏 desktop-r01 发布提交 bddecf6bf68acc23d218fef477b41a8442a28d02。入口运行时引用同一现行模块，不复制一份车体生成器。

## 已有和可用

- 直接调用已留下的 91 分件自有函数形状层。
- 当前 20 个机车/煤水车轮；3 根主连杆、4 根联杆、14 组制动。
- 完整装配、轮组、主连杆/联杆、制动、煤水车独立观察；固定尺度切换，不自动适配不同零件尺寸。
- 播放/暂停、行进距离、速度、制动压力。
- 实际节点目录与单独观察。选定节点可以试改局部位置及统一缩放，并导出这次试调参数。父架有缩放时局部单位不等于世界米。
- 只影响本页实例，未自动回写主游戏。缩放等局部试调可能破坏机械约束，不能据此声称结构正确。

## 尚未提供

完整生成器配方表单及修改后的自动机械验证。现在的节点试调不能替代生成器级设计参数。原生配方/尺寸/杆件截面源仍在上一级 native-a4/ 中，独立候选后续应按具体修改回写这些有名参数，而非藏在节点缩放中。

既有形态与运动不是完整工程验收。制动靴/吊杆为可动视觉重建，尚无完整制动拉杆传力链；历史 A4 倾斜内缸和共轭阀动、完整动力载荷与整车干涉仍不在已完成范围。

## 验证

34 个实际导入依赖逐文件与冻结桌面发布 Git blob 比对，均一致。CPU 实测 20 轮在推进 0.5 米时的角位移为 0.5 / 各自半径，保持和倒退通过，3 根主连杆端点发生运动，14 组制动往返 11.5 mm。

已用预装真实 Chrome/ChromeDriver 在隔离私有测试中载入同一组公开源及本入口，测试固定相机分类切换、原生品牌、轮组推进、暂停、单件隔离和播放，不加载老师资产。实际视觉仍需按用户目标逐件评审，不能用存在/运动通过代替形态正确。
