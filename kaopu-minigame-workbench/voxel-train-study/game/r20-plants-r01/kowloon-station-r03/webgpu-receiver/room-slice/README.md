# KAOPU native-WebGPU function-room candidate

The room wall, openings, stone frame/floor, metal rails, 8mm glass pane, continuous cable, timber bed, hanging authored cloth surface and yarn sections are evaluated in WGSL. The receiver uploads an 80-byte camera/state uniform and draws a three-vertex full-screen execution proxy. It generates no CPU surface meshes, per-brick or yarn records, appearance images or sampled numeric-field volumes. The depth attachment and browser swapchain remain real GPU allocations. Source/score size is not runtime memory or a performance claim.

Brick family 0, plaster macro/micro, V26 water/weather, Library v3 wood, STONE_STUDY stoneFields and MP02-S1 woven/cotton preserve original source algebra with explicit WGSL syntax and physical-footprint bridges. This is not a claim of original GLSL pixel equivalence. Shared wall age/rain/repair state controls retained plaster geometry and PBR. Microscope height influences the actual query field. New bridges include continuous sampling (rather than old vertex interpolation), implicit cloth section inversion, causal metal corrosion/contact polish, glass Fresnel plus straight transmission, and dark cable dielectric finish. The source wood/cloth did not have unified age/wet/repair physics. Cloth macro drape is authored, not a mechanics solver.

The glass is a finite shell with secondary reflection and straight transmission; there is no full refractive path transport. Function displacements and cloth section inversion are not proven strict distance fields. Conservative tracing, signed-crossing refinement, grazing views and explicit diagnostic rays are acceptance checks, not a mathematical Lipschitz proof.

Run `node qa/source.test.mjs` for static contracts. Official Playwright Actions performs actual WebGPU compilation, five views, age A/B and compute diagnostic rays. No WebGL fallback is enabled. QA starts at 480x320 internal render resolution in a 960x640 viewport. Real-device performance and final appearance remain unaccepted until separately verified.

This directory is the requested room deliverable, not the independent cave demonstration. It contains no cave mapM/mapC, cave camera or prebaked cave fields. The original baseline and its failed compiler evidence remain unchanged outside this directory.

Execution uses 32x32 scissor tiles with GPU-completion waits and an outer conservative wall envelope. The same surface functions run at candidate intersections; no stored geometry/field volume is substituted. The full frame includes all tiles and real depth.

Sampling revision: world geometry/age retain fixed metre-domain fields. Screen footprint (distance × vertical FOV / internal height) filters surface evaluation and normal integration only. Near yarn hit tolerance is now micrometre-scale. Original raw-denim arguments are restored, with source offset recentered to zero as a host translation. Wood cavity/specular/clearcoat feed host GGX; original coarse parallax iteration is explicitly not yet supported.

## Ray-state correction, 2026-10-11 15:06 UTC (pending GPU)
The prior 180-step receiver conflated budget exhaustion with true far exit. Cloth near-tangent rays exhausted, returned depth=1 and failed the strict less test, leaving the clear colour as a false vertical gap. Hit / true miss / exhausted are now distinct. Exhausted primary/secondary rays are explicitly magenta and counted in a 32-byte GPU statistics buffer per submitted frame/crop. Background uses less-equal depth. A finite analytic cloth envelope (fold + yarn-query bound) gets its own at-most-512-step local refinement budget; other traversal remains 180. This changes evaluation allowance only, not world shape, hit epsilon, age, mother functions or yarn colour. It is bounded conservative stepping, not a certified exact SDF solver. Small-crop A/B is required; whole-scene exhaustion counts are not yet verified.
