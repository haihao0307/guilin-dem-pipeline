# Kowloon R03 source and adaptation record

This independently added station candidate preserves the R02 spatial layout and the existing train host. It is an imagined upgrade, not a surveyed historical replica. Reference photographs and scanned meshes are not distributed.

- Existing game iron: actual FH88 `material(role,color,seed)` function, reused by invocation and chained original compilation. Corrosion loss, located drainage, contact polish and repair are new bounded artistic mappings. No recovered mature corrosion mother is claimed.
- Timber: original Library v3 `createHewnBoxGeometry`, `materialFor`, original shaders and original uniform binder. The core SHA256 is `ce6a10b73516cb3fe64b389c167daab6625354e2ea9a67c08ca6ab94c8b5df9c`. New authored age controls true original geometry amplitude and its finish parameters. Original fixed light remains; source displaced depth shadows are not transplanted.
- Fired brick: original R3.12 HTML SHA256 `1532ea02c31f014c23390fa028385338c3d2caa572f3a36511db81d6609e1581`, exact original `brickExactWorld`, `brickNormal`, and `processMaterial` function bodies. Lower hall facing uses a new 30-sample/76-triangle receiver. Its real return edges close into the opaque wall core, not across openings. The coarse chart is not the original dense mesh's pixel-equivalent replacement. Other wall masonry uses the declared original-field surface LOD. Three lighting is a new host bridge.
- Stone: STONE_STUDY same-page original `createSDF/buildMesh` and `stoneFields`. Source HTML SHA256 `ad02a23d6a95a4c269b93beef614a97a9c330edda2214d9e3f9812de02e0ab5a`. Four near platform copings use two shared original whole-mesh templates at original quality .56, mobilePreview false. No single-layer radial approximation is used: detected multi-crossing pores rejected that approach. Original marching-tetra interpolation is discrete and has nonzero local SDF residuals; full analytic topology is not claimed. Remote platform slabs retain their existing declared receiver, not full pore meshes.
- Stone archive attribution: Stone Brick by LuthBird1, https://sketchfab.com/3d-models/stone-brick-8a31a831769f491f849f20715127d239 , CC BY 4.0, https://creativecommons.org/licenses/by/4.0/ . This new station receiver is adapted from the user's existing procedural study and retains the source record. Neither the original scan nor its images is shipped. Source-unit measurements were not calibrated; station dimensions are explicitly authored in metres.
- Leather: existing MP02-S1 pure-function shell and LeatherKernel, source commit `23c34ca5699e388d2b9ab2502fb91480e6628b5c`, originally published in `kaopu-tailor-workbench/material-products/mp02-s1-23c34ca5699e`. Preserved `SOURCE_LOCK.json`, `INHERITANCE.json`, `THIRD_PARTY_NOTICES.md` and the MIT project licence accompany the copied original functions. New station seats and host lighting require their own visual review. No scanned R10 appearance images are included. The small source hash function's separate provenance audit remains unresolved; this candidate is not blanket commercial-IP certification.
- Native platform lettering: existing finite Noto Serif CJK outline function subset and its OFL notice remain with `station-labels-LICENSE.txt`.

No ceramic mother was recovered in this pass. Generic game glass/enamel is not relabelled as mature ceramic. Characters remain the existing train placeholders. Authored ages are dimensionless design state, not measured historical years, structural certification, or calibrated corrosion simulation.

Native R03 parameters use an independent experimental SQLite envelope with inert JSON, exact source pins, SHA256 and CRC32. It is not a universal .KaoPu reader. The small score file is not the complete runtime memory or download size. The original game save button still belongs to the driving session; station save/restore is the separate API.
