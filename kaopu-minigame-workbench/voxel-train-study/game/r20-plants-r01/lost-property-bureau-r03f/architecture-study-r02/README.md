# 失物招领局 · 建筑关系试作 02

这是可连续旋转、缩放、进入和剖切的原创三维空间候选，尚未通过用户美术验收。它不是 Waterhouse 建筑复刻，也不是结构、消防、无障碍或容量认证。

## 学习依据与原创边界

- Waterhouse / 曼彻斯特市政厅：借鉴外围办公、公众大厅与员工交通分别组织，以及入口、竖向交通和主厅之间有明确关系的方法。本案矩形场地、塔位置和尺度为项目推演，没有照搬市政厅三角平面。原始平面：[CCA DR1993:0035](https://www.cca.qc.ca/en/search/details/collection/object/2570)；[曼彻斯特市议会](https://www.manchester.gov.uk/the-council-and-democracy/town-hall-complex/town-hall/the-building)。
- 用户旧建筑照片：采用下层厚拱、上层独立柱廊、连续檐口及木柜台所形成的空间分层。照片未随源代码公开；黑白照片不能证明这里的配色。
- Crossness：学习工业厅真实柱跨、铁柱与屋架关系，以及动力建筑、服务院和维修运输各有空间。这里三跨库房的 24 米跨、屋脊采光、锅炉服务翼和烟囱都是原创提案，不是原工程测绘。[官方场地资料](https://crossness.org.uk/the-whole-picture-at-crossness/)、[官方梁式蒸汽机资料](https://crossness.org.uk/beam-engines/)。

## 本轮可检查

- 公共入口 → 门塔前厅 → 低连接厅 → 通高办事大厅；柜台后的员工带与公众带分开。
- 后场收货 → 横向后通道 → 接收室 → 库房入库口 → 中央库道 → 柜台交接通道。
- 门塔中的两跑楼梯及逐层楼板开口；屋面、上层楼板可单独隐藏。
- 仓库三跨与屋脊实际采光开口；东侧服务通道和后侧工业附属院。
- 屋面来自有确定边界的实体面片；拱洞墙体从外圈边界开洞，再设置独立内圈，避免旧版本重合内壁。

仓库内部矩形为 4,536 平方米，扣除柱脚平面交集后约 4,521.3 平方米。这个数包含货架和通道，不是净货架面积或容量承诺。货架容量、原始锅炉房照片和大师原始可量测剖面仍未证实。

## 仍需审查

上层办公室尚未建立完整连续步行连通图，楼梯踏步/平台和头部抽样通过不能推导为全楼可步行。门塔逐层退台仍有堆叠感，长立面等距开间的主次较弱，主入口与大厅轴线尚不够鲜明。完整空间与通达性供用户先检查；构件数量不能证明建筑品位。整体建筑及材质是候选，不能据技术测试称“大师达标”。

## 使用

拖动旋转，滚轮缩放；WASD 平移，Q/E 升降，Shift 加速。视角按钮可以进入大厅、仓库、楼梯及后场。剖切滑杆和屋面/楼板开关帮助检查内部。相机是检查相机，没有碰撞体，不代表每条自由飞行路径都能步行。

旧 SDF 与 geometry-orbit-r01 候选保留。当前页面使用已保留的 Three.js r170 与 OrbitControls，遵循相邻 vendor/THREE-LICENSE.txt 的 MIT 许可；没有引入第三方建筑模型或受限照片。
