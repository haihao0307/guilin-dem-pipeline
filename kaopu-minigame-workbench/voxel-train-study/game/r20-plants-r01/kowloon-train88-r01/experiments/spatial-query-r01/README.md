# Bounded physical-query experiments

No production field or public game entry is changed. Three independently compiled variants share the same point inputs, construction, age, skip modes and mothers:

- reference: original hall function with diagnostic counters only
- hierarchy: original 87 group blocks kept byte-for-byte and ordered, wrapped in 63 conservative far-space nodes; payload remains 96 slots
- capacity: only the proven terminal outer payload changes from 96 to 1 slot; original 96 raw-count/overflow threshold and all functions are unchanged; no hierarchy

The terminal if/else enqueues one hall winner or one far bound. Static domain SHA and recursively checked pure helper graph guard the one-slot proof. Other potential one-slot groups are not included in this first capacity test.

The hierarchy is allowed to skip only when its padded box is more than 0.06 m away AND cannot beat the current strict winner. It never returns a parent-box substitute. The original far proxy, material displacement, window/door openings, labels and surface ties remain as authored. Nodes enclose float32 original boxes with 0.01 m padding and use a further 0.005 m comparison guard; |p| >= 2048 m falls back to all original blocks. A separate reviewer checked 20,237,287 descendant decisions without a CPU f32 counterexample. This is not GPU proof.

`emit.mjs` preserves the 940 point inputs and emitted field source. The current bounded execution defaults to capacity alone, age 0.05 / skip mode 0, three identical draws in one compiled pipeline. Its reference is the successful original raw readback from run 38266480107, compressed without loss. The fixture locks the complete generated manifest, original source, original and capacity WGSL and GLSL, parameters, and original raw SHA256. Actual uniform IEEE bits are checked. Thirteen GeometryHit/source/raw-overflow channels compare bitwise. This establishes only that fixed state, not the unrun age/skip grid.

Each requested variant owns a fresh browser process and context. A failed hierarchy cannot contaminate capacity. The default does not repeat the 122-second original first draw. All returned IEEE bits are saved before validation, even if NaN or infinity occurs; GL errors per attachment, context-loss state, non-finite count and all-zero status are distinct. Timings include draw-through-readback, API draw/finish return and readback separately. The old `gpuCompleteMs` name was misleading because readPixels absorbed deferred work; it is no longer used. Each process has a 200-second progress watchdog and 300-second overall bound plus verified owner cleanup.

This does not claim a full ray-traced shadow image, complete scene, native hardware performance or public delivery. None of the variants is selected for production until numerical and measured-cost results are reviewed. No private reference photos or external meshes are included.
