# A6 · 88 / R08 尺寸化原生三维 R01

本目录是独立的新设计候选，不替换 R08 概念图、旧 A4、学生 A6、旧 88 或 Mark3，不接入香港地图。

## 模型与审看

打开 `index.html` 的 HTTP 服务即可审看自包含 `app.js`。包含整列、尺寸侧面、机车、正面、配套客车、连接端、长驾驶舱、客厢内装八个视角，可旋转、缩放、开关尺寸、剖开外壳和低速杆件运动。

所有主体是可编辑程序化几何；并非把概念图作为立体贴片，也不加载图生三维模型。`src/dimensions.mjs` 是尺寸权威；`src/model.mjs` 是组件结构与几何；`src/app.mjs` 是审看器。原始渲染引擎为 Three.js 0.170.0。

## 对 R08 的落实

- 长鼻、前置单驾驶位、后置柴油加热蒸汽锅炉，连续油水车。
- 四个可见大驱动轮每侧，保留原踏面轮缘、铸造轮心、锻造连杆母体；新四轴运动使用明确的滑块曲柄闭合。
- 延长整块玻璃座舱，侧窗下沿下降到金线附近，启动阀与站立工作区留在后段。
- 鳃口置于长座舱之后；双蒸汽出口布置在机车后部；平滑表皮不设外露铆钉排。
- 车尾用可连接客车的平直匹配截面，配套通勤客车与机车一致的绿色、金线和圆肩顶。
- 客厢为排椅、站立区、扶杆、吊环和木条顶棚，没有酒店式吊灯。
- Flying Hongkonger 字标与红色飞行人物沿用已有原生轮廓资产，未新造公司标志。

## 可复现测试

`npm install` 后执行 `npm run build`、`npm test`。浏览器验收使用 Playwright 1.55 的 Chromium：`node tests/browser.cjs`，截图与报告写入 `qa/`。

CPU 校核：四驱动轴、轴距、轮轨名义接触、65 相位杆件端点闭合、成人实际高度、有限顶点、玻璃/金线差和连接段长度。

浏览器验收：真实 WebGL 首帧、八视角、驾驶舱剖面、相位变化、手机布局、控制台与资源错误。只有实际成功的浏览器报告才能说明渲染完成。

## 工程边界

这是按米制构建并检验几何关系的第一版设计候选，不是制造图。未验证压力容器、锅炉安全、车体承载、轮轨动力学、限界、最小曲线半径、转向架实际回转包络、制动距离或 250 km/h 能力。外观连续不等于结构刚性连接；各车体分开，连接处保留几何间隙。内置低速运动只是几何相位演示，不是运行性能模拟。

## 首轮真实渲染后的修正
采用连续圆角超椭圆截面场，玻璃与漆面共享同一壳面；轮区切口由连续曲线定义。驾驶舱地板提升至2.180 m，位于2.032 m驱动轮冠之上148 mm。原生成人仍保持1.750 m。字标正向，客厢共享扶手之间净宽0.700 m。

截面插值限幅，避免平段三次插值使2.950 m宽度或4.150 m座舱冠高发生过冲。地板结构厚100 mm，底面相对踏面冠的静态净距48 mm、相对28 mm轮缘最高点净距20 mm；悬挂行程与动态限界仍未验证，不据此声称已满足制造或运行标准。

## 当前交付状态与可见限制
这是首轮尺寸与整体造型三维候选，不表示已达到R08概念图的完整外观或精工品质。鼻尖、灯具轮廓、曲面肩线、真实材质与内饰工艺仍需进一步设计。当前先供旋转、缩放、侧面、整列比例和连接关系审看。冠线玻璃已精确闭合，鼻88字样跟随外壳曲率；成人与整列保持真实米制尺度。

### 正面视图审查：仍未达到 R08 外观

最后一轮修复仅确认玻璃冠线真实闭合，以及两侧的 88 字样完整贴合鼻壳。正面仍存在以下明确差距：
- 灯具朝向过于偏侧，正面几乎看不见，未形成 R08 的正面灯具识别。
- 鼻体高度与形体遮住较多驾驶舱，中央绿色段遮挡司机；司机实际视线尚未校核。
- 88 目前是两侧标识，从正前方不可见，不能称正面标识通过。
- 鼻体、驾驶舱及肩线的连续曲率、灯具、材质工艺，与 R08 正面参考仍有明显差距。

因此本包只交付尺寸、几何与整列关系的初版审看，浏览器测试通过不代表外观通过。下一轮应直接对照 R08 正面参考复核鼻体高度、灯朝向、驾驶视线与正面识别，而不能用侧面可见代替正面验收。
