# R04 construction and matter audit

This is a candidate implementation audit, not a visual quality certificate.

## Actual construction path

`stationDomain → procedural candidate records (distance, family, local frame, extent, seed) → resolveCandidates → evaluateStationGeometry (shared material state) → union`. A bounded list carries analytic construction records, not mesh vertices or cached material samples. Material evaluation is called at one dynamic loop site, rather than being expanded independently into each part call.

Matter is evaluated before the union selects the nearest component. This fixes a real earlier weakness: selecting a nominal box first, then displacing only that selected box could miss a neighbouring coating. Each `HitField` retains the nominal `baseD`, material family, metric frame and seed. Shading reuses that same record and the same `evaluateStationGeometry` closure and common source state, with only the declared pixel footprint changing. Normals query the same final distance field. No second coplanar shell is drawn.

`resolveStationState` is the single authored age, wetness and repair resolver. The state is not measured history. Original material functions are not rewritten to claim that they already contained station construction or calibrated ageing.

## Construction-specific bindings

- Brick walls: solid hall/tower wall sections and true opening subtraction carry explicit front/return axes. The R3.12 individual brick distance and original material field share the same metric cell, seed and variation. The original material geometric surface relief plus the common retained age/wetness drives bounded section loss; its amount also controls local tone/roughness. This is a new station erosion bridge, not a recovered original erosion simulation. The wall core is still a continuous structural recipe: interior brick-to-mortar volumetric interfaces and individually bonded arch voussoirs are not claimed.
- Iron: thin barrel shell, separated truss members, cast fluted columns, rail heads and brackets retain different physical thicknesses in their construction functions. The same FH88-derived corrosion field gives section loss, colour and roughness. Roof intersection acceleration excludes only a proved non-intersecting outer cylinder; it retains other barrels, chords, columns and rails.
- Timber: 38–96 mm slats, real gaps, axial grain frames and end cuts are construction inputs. The source macro-displacement and original surface channels receive one `stationWoodParams` result. End classification is shared; platform-bench normals use the same axis permutation as grain coordinates. Source micro-height is a PBR-normal term, explicitly separate from source macro geometry. The benches have been moved halfway between column stations to remove the actual pillar/seat collision seen in the previous GPU image.
- Platform: the ordinary deck is bound to the existing KST1 concrete branch, with its original aggregate/chip height now entering the physical distance and the same chip field entering colour. The mineral coping and entrance steps retain STONE_STUDY. A visually prominent veined stone is not spread across the entire platform merely because a stone function was available. The concrete WGSL translation is new and has not yet established cross-backend numeric equivalence.
- Coated architectural trim: a solid mineral core carries a finite 13–20 mm original R3.12 plaster finish. Thickness and coverage come from the original macro field and the same retained age/wetness/repair state. Coverage tending to zero retracts the actual outer distance toward the substrate and reveals the substrate material at that exact boundary. This is one composite-material solid, not two co-located rendered faces. Full material fracture/topological detachment is not implemented.
- Clock and windows: clock paint is authored, not claimed to be a recovered ceramic mother. Tower windows are actual recessed apertures and frames. No fake opaque pane is labelled mature glass; transmission/refraction remains an explicit missing capability.

## Verification gates

Source locks and static tests check the actual imports, absence of scene meshes/appearance textures, physical clearances, shared material evaluation, separate macro/micro channels, domain clipping and source frames. Real WebGPU QA records exterior, hall, platform, tower and bench images from one commit, visible ray exhaustion, and a 192-point age contrast. The point contrast must show both physical field and surface response for each native material family. These tests establish a limited implementation contract, not 3A/photoreal quality.

The 2188851f predecessor produced all five views without exhausted rays, but failed art review because a column pierced a bench, the platform looked like strongly veined decorative stone, and close timber lacked readable grain. It remains rejected and is not a delivery baseline. The new common-matter version requires new GPU images and renewed review.

No reference photograph, external mesh, raster appearance map, per-brick vertex array or copied room scene is shipped. R02 remains unchanged. No public stable preview has been replaced by this candidate.

## Local coordinates and compiler audit

The 8c92 run failed during GPU pipeline creation without a WGSL diagnostic, with “A valid external Instance reference no longer exists.” This proves a backend failure, not a measured out-of-memory cause. The next candidate removes the large per-part call-site expansion without changing material-before-union ordering.

All 17 coated-member recipes now carry their real centered local frame and half extents. For example a cornice is (30.7, 0.13, 0.64) m, a column shaft (0.43, 4.4, 0.43) m, and each window frame uses its own width and height. Mother normalization receives those extents, while station wetness/repair still use the separate world point. There is no world coordinate interpreted as a fixed four-metre wall. Current weather resolver remains an authored station-wide drainage approximation, not measured drain topology.

The 7f13591 candidate also lost its backend Instance before any image. This is retained as a failed attempt, not an art result. The next version explicitly separates geometry-required source signals from pigment and filtered micro-surface evaluation. Stone and concrete geometry-only expressions retain the source zero-footprint height algebra; plaster uses its original macro/thickness with geometryMicro=0. Shading calls that exact geometry closure for loss and coating exposure. This is computational staging of the same material, not a separate surface decoration. Shader stage diagnostics and a temporary watchdog-disabled software QA context make future backend stalls observable; no local browser was used.

The 783bf75 pipeline reached the first render submission but the backend Instance failed before completing its first tile. Primary intersection and shading are therefore split into two actual GPU stages. Each pixel carries its full 80-byte current-frame Trace (physical distance, component, local coordinates and extent) into shading. This storage is neither scene geometry nor a cached sampled world field. Both stages import the exact same construction/material functions; no lower-quality substitute field is used. Four-tap normal and micro-height evaluation now use loops rather than duplicated call sites.

The staged 6d352fb exterior completed on real WebGPU with zero exhausted rays, zero device errors and max 709 steps. Its 480×320 image is still art-rejected: excessively distant gray composition and inadequate harbor context. The next review uses native 960×640, a land-side camera prioritizing the hall/tower rather than the unvalidated sea, and a GGX direct-light closure consuming mother roughness/color. Skylight remains approximate, not path-traced GI. Iron contact coordinates now use the actual station height datum (rail crown maps to the original 1.07 m contact location), shared by section loss and surface; centered column y is no longer misread as a joint height.

## Bounded timber and lighting diagnosis

The completed 6d352fb five-view run is technically valid (zero unresolved rays and device errors; all six families changed distance and surface under a 192-point age contrast), but remains art-rejected. The close timber still reads as flat brown boards; floor highlights form unnatural bright contours. The hall entrance frame is not sufficient evidence of the waiting-room interior.

The next bounded-crop candidate gives every timber slat and sleeper its actual member-local cut, half-dimensions and a separate source-seed input. The previous role code remains only a role; it is no longer overloaded as material variation. End cuts are determined from the actual member faces rather than a fixed proximity threshold. Original timber formulas and all locked leaves remain byte-identical. Under completely intact plaster, the physically invisible stone surface appearance evaluation is skipped by an exact zero-weight branch; physical geometry is unchanged. Diagnostic crops keep the full 960×640 camera/footprint but compute only explicitly reported eight-pixel-aligned rectangles. They are not full scene screenshots or final five-view verification.

## Reference-led site revision, 2026-10-12
The four new private reference images were actually viewed. The third image sets warm red brick, cream/grey stone and dark roofing; the fourth establishes the landward hotel/road and waterside parallel working-track relationship. Freight assignments are authored interpretation, not an asserted historical survey. No private reference pixels are part of this repository.

`station-score.mjs` now generates the WGSL shed bounds and coastline from the same site recipe: 135m passenger sheds; a separate low parcel shed/loading deck and parallel siding; a covered public route beyond the siding end. The landward hotel is an unbuilt reservation, with no substitute building. Berths reserve room without any boats. Dimensions remain design choices. The hall camera is now inside the actual waiting hall, rather than merely at the entrance.

Roof charcoal is a specified steel-paint ingredient: the unchanged source iron noise and rust are retained, the authored pigment replaces the source green pigment term, and the same corrosion coverage removes 60µm of physical paint from the intersection field. It is one composite steel field, not an extra shell draw. This bridge is new station recipe work, not an independently validated historical finish.

Bench timber uses source-supported contrast .36 and physical textureScale 4 through the SAME `stationWoodParams` in macro intersection and surface evaluation. The mother file is unchanged. Default scale gave a ~197mm coarse cross-grain period on a ~100mm slat; scale4 gives ~49mm coarse / ~6.1mm fine periods. This is an explicit member material selection, not recovery of the original default setting. The close diagnostic footprint is ~2.3–2.7mm, so finer detail is close to Nyquist. A light-facing reverse inspection camera is included with unchanged scene sun; the previous close crop looked at the unlit +X face. POM coarse height is still unconsumed and must not be mislabeled as geometry.

Visibility adopts the independently image-verified bureau correction (source commit c54cccad): conservative pruning and material advance shells only advance rays; only actual opaque near-surfaces occlude. An upward ray above y46m is outside the highest station envelope. Budget exhaustion is counted as `visibilityUnresolved`, rendered magenta and fails QA. This is hard point-sun visibility, not soft area-light transport or GI. AO queries explicit geometry closure rather than conservative shell distances. Ground acceleration uses analytic boxes expanded 1mm around the source concrete height range [-.00091,.00021]m; all eight floor domains are considered, and an origin within any bound disables the skip. These changes await the next GPU crop receipt.

The level front forecourt now physically joins hall threshold to the covered quay walk; its front steps replace the earlier disconnected hall-only steps. This fixes an architectural circulation gap found in CPU review before image testing.
