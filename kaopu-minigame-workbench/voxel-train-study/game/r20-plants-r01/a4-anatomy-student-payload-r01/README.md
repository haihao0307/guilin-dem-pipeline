# A4 学生独立载荷候选 R01（独立进行中检查页）

范围：沿完整 A4 原件进行解剖式函数学习。默认只加载一个完整学生场景；函数尚未覆盖的几何属性、材质贴图及原动画保留明确残余。不得称全车转换完成。原始 A4 入口与局部 R02/R03 锚点保持不变。

## 本批门禁
- 已解释轮 POSITION 不再读取原 POSITION；依据母线、辐条及轴毂参数和紧凑顶点绑定生成。
- 铆钉结构族按实际可解释组件覆盖；其余逐项回退，不以名字数量替代形体。
- 全部 331 节点、200 网格、材质/贴图/采样、原动画目标/插值/时序保留；71 通道不等于 71 个运动部件。
- 原字段与候选字段分账：未替换字段逐字节核验；生成位置用已测几何误差、焊接等价与材料边界核验。
- 默认正交正侧。内部 A/B 共用标尺和相机；不以两格独立 auto-fit 隐藏尺寸误差。源单位尚未标定为米。
- 独立学生入口网络不得请求完整老师 object/fields 或老师贴图；保留贴图的有权副本应同 SHA 并附出处。
- 原动画与老师在相同时间核对。静止原姿态与动画第零帧分开。
- 计量整个运行闭包：解码代码、规则、绑定、残余、清单、贴图、库依赖，分别列原始/压缩/浏览器实际传输量，不只报模型体积。
- CPU 与真实浏览器均须验证；手机视口不称 iOS 实机。

当前 scene-from-fields.mjs 只负责从已核验字段恢复 glTF 语义。它不读原老师包，不创建简化替代部件。独立载荷 CPU 和 Chromium/SwiftShader 检查已通过，本批仍未完成整车函数化。详细范围见 VALIDATION_LIMITS.md。
