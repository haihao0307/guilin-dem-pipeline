# 城寨相邻住户组：施工与验收记录

## 当前状态
这是同一列车工程中的独立三维模块。当前还未通过旧城美术和可交互性能验收，未接线上列车。

已由一份米制 recipe 生成 3 个相邻空间、16 级回折楼梯、上层外廊、跨楼借道、3 扇真实可开关木门、真实窗口、床架桌凳、修理台架、可追踪供排水管与屋顶天线。参考图只用于生活/空间关系，图上配色、像素、重复人形没有作为油漆、米制或人口数据。

真实人物与真实成衣仍缺：原完整人物核虽可离线运行，但已发现衣服仅表面染色、坐姿未实现，详见 actor-audit/。本模块没有插入替代方块居民、简画T恤或假床品。

## 原函数复用
- Brick Mother R3.12：8 个精确种子模板一次采原形体和法线，实例共享，帧内原 processMaterial/shadeBrick。顶点法线插值有明确误差，不声称像素等同。
- R3.12 shadeSoil：真实砂浆棱柱接收原表面函数；棱柱是新配方几何，不声称原墙 SDF 几何等同。
- Library 历史建筑木材 v3：原 createSubdividedBoxGeometry/materialFor/GLSL/uniforms；实例刚体变换，长轴纤维对齐构件。
- FH88 当前金属 material() 原闭包：钢/铁源参数，0图片纹理。

## 可达关系
街面 → 回折楼梯 → 上层外廊 → B 入户门 → B 住户边缘借道 → 借道门 → 跨楼廊 → C 入户門。A 从街面进入，公共服务位单独从街面到达。
B 借道门关闭会明确拒绝 C 的路线，并保留 A/B 可达。navigation.mjs 只接宿主世界秒，不创建计时器、渲染器、动画循环或假人。

## 已验证证据
- 单砖 GPU：commit c894cfa5，run38121805091，原/适配相同冷帧+2暖帧、完整像素读回。母砖暖 6.4–6.7ms，种子312暖 4.4–6.3ms；共享实体 MAE 0.449–0.469/255，轮廓差约2.2%。不能外推整屋。
- 整组 GPU 第一轮：commit170a6926，run38122151463，800×600，8模板构建2.564s、4644砖/2,897,856砖三角，外观398calls/2,928,868总三角，暖1.179–1.199s；门近暖3.66–3.71s。软件 WebGL GPU 完整读回，性能未通过。0运行图片纹理，153木件、80金属件。
- 第一轮真实图在 qa/full-scene-170a6926/，仅证明空间和原函数实际运行。该轮右上支撑、扶手不完整和木板透缝问题已识别，不能作为成品图。

## 施工中的确定修复
右上单元落地柱梁、楼梯/平台连续护栏、拼板连续底板、构件长轴木纹已经本地补齐；等待下一轮真实 GPU。原墙湿痕能力另审，不把烧制深浅当雨水老化。剔除隐藏三角只能在同一个凸砂浆实体严格包住三角3顶点时进行；不凭平均差、视线猜测或删背墙伪优化。

## 宿主接口
`buildNeighbourhood({THREE,renderer,recipe})` 返回 root、setDoor、setCutaway、update(worldSeconds)、reachable、metrics、dispose；不创建独立renderer、camera或rAF。当前仅隔离QA接入，正式挂载须另经整体图像与成本验收。
