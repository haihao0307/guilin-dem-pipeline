# 完整原A4加载修复 R02

只修传输、校验过程提示与失败边界。完整原件的几何、材质、贴图、层级、动画和原尺度不变；默认正交正侧。原公开锚点不修改。

旧加载器无字节进度、无网络deadline，页面在下载、解压、942字段校验、GLTF解析、GPU首帧任一阶段等待都会只显示“正在加载全部原件”。用户截图不能确定实际停在哪一阶段。

本入口显示阶段与字节；网络连续30秒无新数据中止，最多2次串行尝试；持续有数据允许最多15分钟。失败保留阶段及完整URL，不无限重试。解压与解析限时120秒，不并发启动另一份原件。已被服务器解压的响应通过原始字节数与SHA继续核验。贴图只下载、验证一次，再用相同字节创建临时URL；解析后释放下载缓存。gzip解压直接写入锁定大小的缓冲区，避免再保留整份解压chunk列表。

942字段、整体payload、object及2张原贴图的SHA校验仍然必须通过。test-source-semantics.py检查从原node恢复开始的所有几何/材质/层级/动画代码逐字节不变。

browser-network.cjs在CI运行正常加载、半包断流恢复、永久失败及慢速连续下载；测试使用真实原模型，不缩减。非iOS实机验收。缺少浏览器解压／SHA／WebGL支持会具体报错，不以替代模型充当成功。
