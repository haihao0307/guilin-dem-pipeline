# KAOPU 尺寸与结构验收视图强制规范 R01

## 统领硬规则

所有 KAOPU 项目的模型、结构与尺寸对比，禁止使用会造成大小、远近或比例误判的视角展示。默认必须采用正侧面、正面、顶面标准正交视图；同源对比必须同方向、同比例，禁止自行使用斜视、透视、广角或独立缩放。只有用户明确要求时才可单独展示特殊视角，且不得将其作为尺度验收依据。本规则必须绑定默认相机设置与交付检查；不符合者不得作为模型、结构或尺寸对比交付，不应等待用户再次提醒。

状态：规则文件已制定；各项目须分别接入默认设置、测试与发布门禁。本文的写入不代表所有项目已完成改造。

## 1. 适用范围与优先级

适用于所有 KAOPU 项目及工作台中用于判断尺寸、比例、结构和相互位置的视图、对照图、截图与验收报告。

尺度验收不得由美术展示镜头代替。用户未明确要求特殊镜头时，尺寸与结构验收默认仅展示正交标准视图；透视、斜视及其他美术镜头只能在用户明确要求后单独展示，并明确标注“展示视图，不用于尺寸验收”。

## 2. 默认视图与坐标约定

1. 默认提供正侧面、正面、顶面三种标准正交视图，并记录各视图的观察方向、屏幕横纵轴及正方向。
2. 镜头观察方向必须与项目约定坐标轴对齐，不得用倾斜镜头冒充正侧面、正面或顶面。不同项目可有不同坐标约定，但必须明确标注。
3. 正交投影消除透视缩放，不会自动消除朝向错误、投影缩短或遮挡。必须同时检查对象朝向、观察方向、遮挡关系和实际投影长度。
4. 若存在重叠或遮挡，应增加独立正交视图、线框或剖视辅助检查；不得静默旋转镜头后继续把图称作标准尺寸视图。

## 3. 同源对象对照

A4/A6 等同源对象必须满足以下条件：

- 使用同一源单位与转换规则、同一坐标轴约定、同一对象对齐方向、同一观察方向。
- 使用相同的 world-units-per-pixel（每像素对应的世界单位），采用相同截图输出与像素计量口径；每个对照面板标出比例尺或该数值。
- 禁止分别 auto-fit、独立归一化、独立缩放对象或裁剪后拉伸图片，以免造成假等大或假差异。
- 如需调整取景，先计算所有对照对象的联合包围范围，再统一确定镜头尺度；各面板只允许保持尺度不变的平移，必要时扩大统一画布。
- 同源对象的配准基准、旋转与原始变换必须记录。若比较本身涉及旋转或非均匀缩放，必须单独标明，不能伪装成原始尺度比较。

## 4. 单位与数值证据

1. 报告源单位、单位标定依据、导入缩放和最终变换；没有可靠标定时必须写“源单位未标定”，使用“源单位”或“世界单位”，不得称为米制、厘米制或真实物理尺寸。
2. 至少报告所选对象在约定坐标系中的 X/Y/Z 包围尺寸，以及本次判断涉及的关键长度或结构间距。包围尺寸不得代替全部局部结构验收。
3. 标注尺寸必须来自实际几何数据；显示文本、UI 参数或手写标签不能单独作为几何正确的证据。

## 5. 可测试验收与交付门禁

每个接入项目必须在测试配置中预先固定数值公差和截图像素误差阈值，并记录其理由，不得看到结果后放宽阈值。至少通过以下检查后，才可宣称该项目符合本规范：

- **默认设置检查：** 初次加载、重置、切换案例后均保持标准正交视图；投影类型、观察方向和屏幕轴符合配置。
- **共同比例检查：** 对照面板的 world-units-per-pixel 一致；镜头更新、窗口调整和截图导出后仍成立；独立 auto-fit 不得生效。
- **数值回归：** 从实际几何读取关键尺寸、变换及单位状态，对照旧锚点与预期值，误差在预设范围内。
- **真实截图回归：** 使用实际工作台渲染截图，记录案例、版本、视图、画布尺寸、像素计量口径和镜头配置。检查屏幕轴与方向、遮挡和已知几何的投影长度，不接受仅用相机参数或代码审查代替截图验证。
- **投影核验：** 对已知方向的测试线段，依据标准视图计算其屏幕平面投影长度；预期像素长度等于该投影长度除以 world-units-per-pixel。截图测量须在预设像素误差范围内。朝向屏幕的线段不能直接用三维长度计算像素长度。
- **反例回归：** 至少覆盖大小不同的同源对象、沿观察方向前后移动的等大对象、朝向不同的对象及遮挡场景。前后移动不得改变正交投影尺度；朝向变化或遮挡必须能够被检查识别，不能被解释为真实尺寸变化。
- **交付门禁：** 缺任一证据、单位标注不实或任一检查失败，均不得标记“尺度验收通过”。报告未通过项、影响范围及后续处理，不能以美术图代替证据。

## 6. 旧锚点与回退

保留既有案例、已认可的尺度锚点、旧版本和可恢复的配置。新规则接入不得覆盖或静默改变旧数据。每次更新记录变更范围、测试证据和可用回退版本；出现回归时，应能恢复到已验证版本，并注明该版本对本规范的符合情况。

## 7. 为什么写过规则仍会重复出错

文字规则若没有绑定到工作台的默认镜头、共享尺度计算、自动测试和交付门禁，就仍依赖每次操作时人工记住，切换案例、重置或导出时也可能失效。本规范的落实标准是上述设置和证据实际生效，而不是仅存在这份文档。各项目须逐项验证并分别报告状态，不得把单项目通过写成所有项目已完成。
