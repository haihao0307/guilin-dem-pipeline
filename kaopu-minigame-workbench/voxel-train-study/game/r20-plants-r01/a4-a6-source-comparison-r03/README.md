# A4 → A6 / unified source-backed exterior R03

Independent R03 candidate. R01/R02 and all original source assets remain unchanged. Open index.html over HTTP. Default side, front and top views are fixed axial orthographic, with one numerical source-world-unit-per-CSS-pixel across all four windows and no free orbit. Cross-source physical metres and rail-contact reference remain uncalibrated.

## Design requirements and separate acceptance

This revision studies a continuous curved locomotive canopy above the three original main axles, shorter A4-related nose, visible driver upper body/hands with concealed feet, and usable declared forward sight rays. The coach must receive its own modern continuous rounded-shoulder shell, real source-window apertures, shared deep-green/gold material language and short open-bottom end collars. A source-only duplicate is not accepted as completed coach conversion.

Source integrity, visible original mechanics, static source-triangle clearances, sight rays, rendered design fidelity and physical engineering are separate checks. A passing node count or browser test does not certify the design or real operation. All geometric numbers use uncalibrated source units; the digital occupant is not a calibrated human-scale model.

## Complete originals

A4:331 nodes,200 meshes, original material/texture bindings and71 animation tracks. Mark3:145 nodes,89 meshes, original material/texture bindings. No generated replacement wheelsets, bogies, brakes, suspension or transmission are permitted. Pure original exterior primitives may be reversibly substituted only with an explicit per-primitive reason; source data, original matrices and materials remain unchanged. The design toggle must restore both complete source scenes.

Display registration uses a separate parent translation based on identified wheel-mesh minimum Y; this is not a certified tread/rail datum. All original root-local data remain intact. Real source data use the existing lossless typed-field reader; conversion to a complete pure-function authoring system remains unfinished.

## Regression inherited from R02

Byte-verified cached source transport, image/payload hashes, finite retry/deadlines, stage/byte progress and independent source-pair first frames remain required. Fixed-axis numerical projection and real rendered equal-size pixel probes, synchronized scale/zoom, no orbit, original animation and full restoration are tested.

R02's wheel-top-only cab floor check omitted a higher original underframe surface. R03 must check actual retained underframe triangles as well, retain the negative regression evidence, and never call a wheel-only gap full chassis clearance. Forward sight must be checked against actual retained source and authored opaque meshes, not only a glass material property.

## Actual review findings retained

The first rendered coach crown showed tube-like highlights. Its interpolated shoulder had curvature sign reversals; R03 now uses one strictly convex analytic ellipse and separate cap normals, preserving the crown height and original windows/mechanics. Front-view review also rejected a waved windshield edge; the authored opening now follows one smooth transverse arc and is checked on actual boundary vertices. These geometric tests still require screenshot review. Original 88 and company-plaque vector masters remain byte-identical; their design instances sit beneath/behind the driver. The large Flying Hongkonger lettering is unchanged.

The original A4 rest pose contains a laterally projecting grey source mechanism (primitive node 294, parent 293). It is visible in both original and A6 front views and is preserved, not a newly designed attachment. Coach original end faces/coupling parts remain visible behind the new compact collar; a fully integrated end-interface design remains unfinished.

The coach's long convex crown reflected several bright rectangular environment panels as longitudinal bands. Only the new coach paint instance is separately tuned: base #064631, metalness 0, roughness 0.36, clearcoat 0.48, clearcoat roughness 0.32, environment intensity 0.10. The existing FH88 paint shader callbacks are retained. This is the same color/material family with different optical values, not a claim of identical finish parameters. Original source materials and the locomotive paint remain untouched.
