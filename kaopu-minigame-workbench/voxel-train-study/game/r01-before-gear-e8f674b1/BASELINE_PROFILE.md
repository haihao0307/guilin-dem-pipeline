User subsequently reported that stutter was largely gone on their phone. That is user feedback, not instrumented hardware telemetry.

R20 preserves R19's scalar typed-array packing, stable44m spatial cells, culling bounds, shared material tables and resource release. Changes here are structural facade/roof/window choices, unique tenant/glyph recipes, localized existing shader masks and first-two-station boards.

The official R20 visual comparison uses identical explicit camera/distance fixtures in actual WebGL for R19 and R20. Native driving is a separate test. Predeclared candidate cost bounds: streaming update p95≤1.25×R19; source triangles≤1.20×; packed geometry bytes≤1.35×; readback-synchronized complete software-frame median≤1.30×. These are regression bounds for this candidate, not a statement that physical devices will meet a target FPS.

Historical old-vector and global-batching files under tests/fixtures are test-only frozen controls. The R20 production import graph contains no previous Rxx runtime. All file-transfer/CPU generation/GPU allocation/render measurements must be distinguished in the result.
