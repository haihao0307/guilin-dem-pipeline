# 静物室机制候选

这是原创控制与事件候选宿主，供接入已经认可的人物、植物和材质。它不是 P.T. 一比一复刻成品，也不是已完成的最终美术展示。没有新造人物或植物，没有使用 P.T. 原始资产或布局。发布用于测试，不代表已通过最终画质验收。

## 已写出的内容

- 一间有精细分层结构、曲面标本和程序材质的观察室。
- 三个确定性状态：持续观察后，只有移开视线才发生变化。
- 第一人称查看和行走、展台与边界碰撞、近看、暂停和重置。
- 点击进入才启用 Web Audio 的合成环境声与空间事件声。
- 单独的检查界面与测试接口。

使用此前工作台已有的 Three.js r170，不另写渲染引擎；音频使用浏览器 Web Audio。导航属于有限室内运动约束，没有宣称具备完整刚体物理或动力学模拟。

## 验证结果

JavaScript 语法检查通过。10 项纯机制/镜头数学检查、9 项 Three 几何/射线检查，以及 8 项接入适配契约检查通过（合计 27 项，第三轮 CI 已复验）。几何检查共统计到 161 个网格、22,207 个三角形、2 个投影灯；这些不是性能基准。

几何测试明确使用 Canvas2D 绘制桩，只检查几何、变换与射线，没有验证纹理画面。接入测试使用合成三顶点夹具，没有执行现有人物模型。

首轮 [GitHub Actions 实测](https://github.com/haihao0307/guilin-dem-pipeline/actions/runs/37854318109) 已真正运行浏览器，锁定提交 8edc2b65a1a2cf8ca407baadcb6a5823b274de6c：数值检查通过；房间完成 WebGL 渲染、进入后启音和真实镜头凝视触发；现有人物完成原权重、版本指纹、固定拓扑和 CommonSkinLayer 的实际载入。已取得一张真实房间入口图。

随后房间与人物测试均在截图操作上超过 30 秒，首轮 job 因此失败。在首轮结束时，完整三阶段、更多控制、人物同场画面、声音听感及移动端尚未验收。首张房图只支持“空间可读的机制候选”，墙地、木饰和间接光距离最终目标仍有明显差距，不能称为已验证的高保真美术。

本次修订让静止场景按需渲染，两张完整分辨率的阴影只在物体或灯光改变时更新，并为软件图形环境延长截图等待。没有降低几何、纹理或阴影分辨率；这一修订已在第二轮消除截图超时，并通过静止场景不持续重绘的检查。[首轮实际证据附件](https://github.com/haihao0307/guilin-dem-pipeline/actions/runs/37854318109/artifacts/11583940632)

## 后续验证方法

在允许本地 Chromium 的环境中，用已有 Node 与 Playwright 执行 tests/browser.cjs。它自动启动仅监听本机的静态文件服务，验证进入、实际镜头凝视、移开视线、阶段像素变化、暂停、完整三阶段、空间音位置、重置、近看、键盘与触摸、碰撞、失焦、静音和外部请求情况，并保存真实截图。

core.test.mjs、scene-numerical.mjs、adapter-contract.mjs 是已通过的数值检查。浏览器测试必须实际通过后才可称相应交互已验证。测试报告分别保存在 tests 目录。

## 人物接入

integration/CommonPersonSceneAdapter.mjs 是已编写的窄接口适配器。它接收现有 CommonPerson 与 CommonSkinLayer，沿用固定拓扑、相同坐标转换及皮肤字段，把几何接到宿主场景，不创建新渲染器，不降级替换为泥模，不创建新人物。

页面包含可选的“载入现有人物”入口，直接读取现有工作台原运行时和权重，校验版本指纹，并沿用 CommonSkinLayer。默认不下载人物大权重，可以取消或释放，失败时不会显示替代模型。第二轮 CI 已验证实际加载、固定拓扑、原皮肤层、画布变化和完整释放，取得真实同场截图。第二轮图像审查发现了人物因源模型原点约定而半身埋地；第三轮已通过外层整体落地修复和真实图复验，原人物形体、拓扑与皮肤保持不变。当前成立的是运行时与放置接入，不是最终电影级观感。具体版本、入口、范围与阻塞见 docs/existing-assets-integration-audit.md。

## 从老师学到什么

从 [P.T. PC Port](https://github.com/LoreanXavier/pt-pc) 学习的是阶段状态、观察历史、移开视线后触发，以及分开检查事件和表现的做法。本候选的空间、结构、曲面标本、材质、声音、状态代码、控制器和测试均为独立编写，没有复制该项目源码或游戏数据。

复用运行库为 Three.js r170，保留 MIT 许可在 vendor/LICENSE-THREE.txt。完整原版复现所需数据、模块和验收，另见 docs/pt-1to1-reproduction-checklist.md。
