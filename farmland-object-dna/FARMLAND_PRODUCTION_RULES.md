# Farmland Object DNA 严谨生产规则 V1.0

生效日期：2026-09-07

状态：强制执行

适用范围：Farmland Object DNA 的研究、对象建模、程序生成、三维工作台、公开发布、复盘与后续农业类型扩展。

## 一、总原则

1. 证据先行。对象的名称、功能、位置、平面、截面、材料、施工方式、维护方式、尺度范围、状态变化和失效方式没有查清以前，不得进入正式几何生产。
2. 系统先行。先建立地形、水源、森林、村落、道路、田块、渠道、进水、蓄水、出水、排水、劳动和季节之间的闭环关系，再进入局部造型。
3. 结构先行。宏观位置、中观拓扑、真实截面和物理尺度通过后，才能进入材质、色彩、微观变化和装饰层。
4. 未知必须保留为 unknown。推断必须记录前提。程序生成必须记录方法和种子。任何空缺都不能靠漂亮画面掩盖。
5. 时间可以延长，质量门槛不能降低。赶进度不得成为发布粗糙对象、错误结构或虚假逻辑的理由。
6. 每一个公开候选都要达到可供用户进行有效视觉判断的最低完成度。仅有简单体块、装饰线和临时代理体的页面只能留在内部诊断区。
7. 用户拥有人工视觉接受权。构建成功、浏览器启动成功、测试成功和公开网址可访问都不等于视觉接受或生产批准。

## 二、对象研究卡为开工前置

每种构件必须先建立 Object Source Card，至少包含：

1. 对象名称与地区称谓。
2. 适用地区、经纬度、海拔、时代、季节和生产方式。
3. 功能以及与相邻对象的关系。
4. 平面形态。
5. 横断面与纵断面。
6. 尺寸范围、常见值、极端值和测量依据。
7. 材料组成与施工方法。
8. 水力、土壤、作物或劳动功能。
9. 正常维护方式和维护周期。
10. 老化、堵塞、破坏、渗漏、坍塌和弃耕表现。
11. 地区变体和禁止跨地区套用的条件。
12. 来源、证据等级、置信度、争议和待查项。

缺少平面、截面或尺度依据时，该对象不得标记为 production candidate。

## 三、水田必须形成完整系统

### 平坝水田最小闭环

水源或上游来水 → 取水口 → 引水渠 → 主渠 → 支渠或分水点 → 田间进水口 → 田内蓄水 → 控制出水口或溢流口 → 汇水沟或排水渠 → 下游受体。

### 山地梯田最小闭环

山顶及上部集水森林 → 裂隙水、泉水、溪流或蓄水节点 → 干渠 → 支渠 → 分水设施 → 上部梯田 → 逐级串联或局部分流 → 下部梯田 → 坡脚排水系统 → 河谷受体。

### 强制检查

1. 每一块显示为灌溉水田的田块都必须能追溯到水源。
2. 每一块田都必须具有可解释的进水、蓄水和出水关系。
3. 所有水最终必须进入明确的下游受体，禁止无来源、无去向和无限循环。
4. 地理邻接、水力连通、产权归属和维护责任必须分开记录。
5. 平坝与梯田可以使用不同拓扑，二者都要通过同一套水量守恒与高程检查。
6. 渠道必须以真实沟槽或构筑物表达，禁止使用浮在地表上的蓝色圆管代替渠道。
7. 进水点、出水点和分水点必须连接真实边，禁止用孤立球体或图标冒充水力节点。

## 四、元阳哈尼梯田专项规则

元阳及红河哈尼梯田只允许在专门区域配置中使用，不得扩张成全球梯田默认模板。

建模时必须同时表达森林、水源、村落、梯田与下游河谷。山顶和上部森林承担集水、涵养和水源保护功能。村落位于上部森林与下部梯田之间的关系必须由地形、取水、生活用水、交通和历史证据共同解释。梯田的方向、宽度、级数和密度要响应等高线、沟谷、坡度、地质和水路。

UNESCO 的世界遗产材料把森林、供水、梯田和房屋描述为一体化系统，并记录了山顶森林、泉水、干渠、支渠、村落和梯田之间的整体关系。正式元阳样板开工前必须完整阅读 UNESCO 页面、提名评估与后续保护材料。

关于传统分水，UNESCO 评估材料记录了以木刻或木柱标记组织水量分配的制度。用户补充了以木棍数量和位置形成分水比例的现场知识。下一步必须查明当地名称、构造、插设方式、分流比例、渠槽截面、管理权、维护方式和地区差异。取得足够证据前，只登记为 research target，不生成自以为是的装置。

任何元阳样板都必须通过以下问题：

1. 水源地在哪里，为什么能持续出水。
2. 哪些森林属于水源保护和坡面稳定系统。
3. 村落为什么位于当前高程带。
4. 生活用水与灌溉水怎样分配。
5. 干渠和支渠怎样跨越山脊、沟谷和村落。
6. 分水权怎样对应农户、田块和时间。
7. 每一级梯田怎样进水、保水、溢流和排水。
8. 暴雨、干旱、堵塞、破埂和滑坡时系统怎样响应。
9. 谁负责清渠、修埂、护林和解决用水冲突。
10. 水到达山脚以后进入哪里。

## 五、渠道与分水构件的截面规则

每条渠道必须区分类型：引水渠、干渠、支渠、田间渠、排水沟、截水沟、溢洪沟和临时导水沟。

每条渠道至少保存：

1. 渠底高程和纵向坡降。
2. 渠底宽度、顶宽、有效水深和超高。
3. 两侧边坡比例、岸顶宽度和稳定方式。
4. 土渠、石砌、木构或其他材料身份。
5. 糙率、渗漏、淤积、冲刷、杂草和维修状态。
6. 当前流量、流速、水位和流向。
7. 取水、分流、跌水、渡槽、涵洞、闸口和出水构件。
8. 与人行路径、田埂、道路、房屋和天然溪沟的交叉关系。

分水设施必须在平面、纵断面和横断面中同时成立。分水比例必须由开口、堰顶、槽宽、水头、阻力和操作状态支持。图形上的均匀分叉不能代替真实分水。

## 六、田埂、田坎与田面截面规则

### 田埂

田埂必须有埂顶、内侧坡、外侧坡、基底、压实土体、湿润线、植被和通行面。相邻田块共享的田埂只能生成一份物理对象，并保存两侧田块关系。

埂顶宽度由人的步行、挑担、工具、畜力、维修需求和地区传统共同约束。界面不得提供脱离人体和生产方式的任意宽度滑杆。局部狭窄点、转弯点、交会点和休息点需要单独处理。

### 田坎与梯壁

梯田必须区分水平田面、田埂、上缘、下缘、田坎、坡脚、排水和渗水。田坎高度、坡度和材料受原始坡度、土壤、岩石、平台宽度、降雨和维护能力限制。田坎不得悬空，不得互相穿透，不得用等距圆环代替地形适配。

### 田面与土层

田块截面至少保存田面高程、泥化层、耕作层、犁底层或低渗层、下伏土层和地下水关系。整地状态还要保存土块尺度、泥浆稠度、脚印、牛蹄印、耙痕和局部高差。

## 七、真实水深与水量守恒

每块水田至少保存：

1. 田底和泥面高程。
2. 当前水面高程。
3. 当前平均水深与空间变化。
4. 田埂顶高程和安全超高。
5. 进水口底高程和出水口底高程。
6. 田块有效蓄水面积与体积。
7. 入流、出流、降雨、蒸发、渗漏和溢流。
8. 时间步长和守恒误差。

蓄水整田状态必须在画面中明显看见水体，并能观察泥面、浑浊度、反射、波纹、湿润线和水深标尺。界面显示的厘米值必须与世界坐标一致。

每次水力测试都要运行正常供水、无水、堵塞、过量来水、破埂和下游受阻六种情形。水量守恒超出声明误差时，禁止进入视觉验收。

## 八、水稻生命周期与种植规则

水稻必须至少区分：育秧、起秧、插秧、返青、分蘖、拔节、孕穗、抽穗、开花、灌浆、成熟、收割和残茬。地区和品种允许合并阶段，合并理由必须记录。

插秧配置必须保存秧龄、每穴苗数、株距、行距、插植深度、插植角度、缺株率、补苗率、田面水深和作业方式。IRRI 的一般资料可作为起始校验，例如浅插、每穴苗数和常见株行距。任何数值进入地区 DNA 前都要核对当地品种、年代和生产方式。

每个阶段必须具有独立的形态模型：

1. 插秧期表现少量细叶、浅根、较小株丛和大量可见水面。
2. 返青及分蘖期增加分蘖数量、叶片数量、株丛宽度和根区。
3. 旺长期形成明显冠层、叶片交叠和风致群体运动。
4. 生殖期出现节间伸长、孕穗、抽穗与开花结构。
5. 灌浆和成熟期出现穗重增加、颜色变化、穗部下垂、局部倒伏和逐步排水。
6. 收割后保留割茬、泥面扰动、稻草、脚印和运输路径。

禁止使用同一个圆锥、四棱锥或简单杆体通过缩放和换色冒充全部生育阶段。近景候选必须能看到叶片、茎秆、分蘖节点和稻穗结构。

## 九、田块尺度属于模数关系

田块尺度由地形、水力、土壤、劳动、交通、工具、畜力、产权和历史共同求解。不得用一个全局缩放值决定全部田块。

至少需要考虑：

1. 坡度、坡向、曲率、沟谷和脊线。
2. 渠道位置、可用水头、供水时段和排水能力。
3. 土壤稳定、渗漏与田坎可承受高度。
4. 人的步行、转身、挑担和维修空间。
5. 牛耕、人工整田或其他时代工具的转弯和作业空间。
6. 插秧、除草、收割和运输路径。
7. 农户数量、劳动日、季节性劳动峰值和离村距离。
8. 分家、合田、道路切割、灾害和弃耕历史。

生成器只能在合法解空间内变异。缺少足够劳动力、水源或稳定地形时，系统必须减少田块规模、改变用途或拒绝生成。

## 十、Microscope 使用次序

Microscope 只用于通过宏观系统、中观拓扑和截面检查后的对象。

允许的 Microscope 任务包括：

1. 田埂压实、土块、裂缝、草根、石块、鼠洞、湿润线和踩踏。
2. 渠底泥沙、冲刷、藻类、杂草、渗水、修补和木石构件连接。
3. 田面泥浆、犁耙痕、脚印、牛蹄印、漂浮物和微小高差。
4. 水稻叶脉、叶缘、叶鞘、分蘖节点、穗轴、籽粒和成熟变化。
5. 石块、土壤和植物之间的接触、遮挡、湿润和沉积。

Microscope 不能用于掩饰错误的渠道、断裂的水网、重复田埂、错误梯级、虚假水深或错误作物阶段。

## 十一、3A 视觉门槛

公开候选至少通过：

1. 大尺度轮廓和地形关系。
2. 中尺度田块节奏、水路拓扑、村落与道路组织。
3. 近尺度截面、接触、厚度、变形和维护痕迹。
4. 土、泥、水、石、木、草和水稻的材料身份。
5. 季节、湿度、太阳、天空、风和空气透视的一致性。
6. 同一区域内部的苗龄、水深、泥色、维护程度和微地形变化。
7. 人体、工具、牲畜、房屋和路径提供的真实尺度参照。
8. 六视角、俯视、地面视角、剖面和 Microscope 近景检查。
9. 平坝与梯田两类样板均通过结构检查。
10. 桌面和 390×844 手机真实浏览器运行与性能检查。

简单圆管、圆锥、平面贴片、规则棋盘和无厚度边界不能作为最终可见对象。临时代理体必须带 debug 标识，并在公开候选中关闭。

## 十二、强制停工条件

出现任一情况时，立即停止视觉堆料并回到研究或结构阶段：

1. 对象没有来源卡。
2. 缺少横断面或纵断面。
3. 水源、进水、蓄水、出水或下游任一环节断裂。
4. 水深与世界坐标不一致。
5. 相邻田块重复生成共享田埂。
6. 不同生育阶段只有缩放或换色差异。
7. 田块尺度脱离人体、劳动、工具和水力约束。
8. 用装饰线、孤立节点或材质效果代替结构。
9. Microscope 先于宏观和中观检查。
10. 公开候选仍能直接看出简单代理几何。
11. 测试结论、浏览器状态和用户视觉接受相互混淆。

## 十三、V0.1 处理规则

公开工作台 FARMLAND_DNA_WB_V0.1.0_20260907 已被用户明确否决。它只保留为失败对照，用于防止圆管渠道、圆管田埂、假水深、圆锥秧苗、断裂水网、机械格网和低完成度视觉重新出现。

禁止在 V0.1 的造型路径上继续装饰。下一候选从结构真值台、水力图、截面和独立水稻阶段模型重新开始。
