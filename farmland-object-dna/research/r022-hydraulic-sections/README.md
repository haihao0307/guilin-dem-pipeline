# R022 截面与理想水力研究

状态：研究实现。继承 R021，未发布新视觉候选。

## 本轮形成的可执行内容

* 土渠梯形截面：渠底、边坡、水面宽、面积、湿周、水力半径和超高分开计算。
* 田埂截面：平坦埂顶和两侧不同高程的坡脚；不使用圆管。
* 共享边注册：在已统一的顶点拓扑中，两田共用一个边对象，反转绕向不重复建边。
  它还不能发现空间上重叠但顶点身份不同的边，也不保证转角接缝或曲线网格闭合。
* 理想矩形开口：根据两侧水头计算正向、停流或反向流量，支持干口、部分淹没、
  全淹没与声明的开口堵塞比例。所有算例用 Cd=1；不冒用实测装置系数。
* 水平蓄水池网络：源池、渠首调蓄池、两块田面控制体和末端受体均有限储水，
  开口流量进入 R021 一次扣账/一次入账的原子提案。

这里的渠首池是集中蓄水单元，不是完整渠槽。Manning 仅用于独立的均匀流算例，
并未接成非恒定渠流或浅水田面流求解器。模拟结果不能认证元阳或桂林实际渠系。

## 来源与采用边界

读取日期：2026-09-09。下列均为本轮直接读取的机构原件。

1. [FAO，Irrigation System §5.2](https://www.fao.org/4/r4082e/r4082e06.htm)
   支持土渠截面、渠底纵坡、超高、维护、渠道分水和排水构件的区分。
   采用其通用构件语义，不采用现代混凝土装置充当传统地方真值。
2. [USBR，Normal Flow Equations §2.16](https://www.usbr.gov/tsc/techreferences/mands/wmm/chap02_16.html)
   均匀流需水面坡度与渠底坡度一致；下游控制可能破坏此前提；经验阻力公式
   对很浅水流存在限制。本轮不把床坡直接当成顶托情形的能量坡降。
3. [USBR，Orifice Relationships §2.8](https://www.usbr.gov/tsc/techreferences/mands/wmm/chap02_08.html)
   理想速度关系与收缩修正分开；非标准装置需标定。本轮只实现理想参照。
4. [USBR，Submerged Rectangular Orifice §9.5](https://www.usbr.gov/tsc/techreferences/mands/wmm/chap09_05.html)
   标准装置的实验系数有水头和安装条件限制。因此本轮明确拒绝把0.61当作
   小水头乡土木口的默认系数。
5. [FAO，Land levelling §6.2](https://www.fao.org/4/t0231e/t0231e08.htm)
   支持传统小尺度整地利用积水观察高低差、逐季维护；不证明任意历史田面绝对平整。

## 理想开口方程

对高、低侧水位 Hu、Hd，开口底 z0、顶 z1、宽 b：

`Q = sign(Ha-Hb) * b * integral[z0,min(z1,Hu)] sqrt(2g*(Hu-max(z,Hd))) dz`

低于低侧水面的部分按恒定压差积分，其余按自由射流积分。
前提是静水压力、忽略进口速度、理想无损、自由段通气；实际土口粗糙、收缩、
浸没跃变、泥沙和冲刷均未标定。该混合区积分是团队根据理想压力关系的推导，
不是直接声称采用某个机构的完整混合流标准。

## 时间与稳定性

使用显式中点预测；预测结果不提交，不重复扣外部供水。
每个开口以供体储量和两池水位均衡交换量限制通量，并公开限流次数。
限流是数值稳定措施，不是现实过水能力。干湿转换附近不承诺二阶收敛。

首次1秒/2秒比较中，强顶托末态水位差约0.00049 m，未达本轮0.0002 m门槛。
没有放宽门槛；时间账本扩展为整数/有理数秒，保留精确分子分母。
正式探针比较1/4秒与1/2秒；完整结果由 `PROBE_RESULTS.json` 提供。
旧整数秒调用兼容。浮点时钟不接收，`interval_s` 是显示值，
`interval_rational_s` 保留精确时间身份。

## 六种情形的准确含义

`normal`：有界源池经渠首池和进水口供田，两田向末端受体排水。

`no_water`：源池和渠首池初始为空，田内原有水可继续排走。

`blocked`：进水口通宽完全关闭；上游可蓄水或从指定泄水口排走。

`excess_inflow`：额外有界合成输入抬高上田水位，越过指定泄水口后产生泄流。
池壁高于泄水口；未建模的池壁漫顶一旦出现即判算例失败，绝不暗中裁水位。

`prescribed_breach`：预先扩大并降低上田开口，观察失水。不是土体破坏或冲刷扩口预测。

`downstream_backwater`：末端受体初始水位提高，但受体仍是有限动态池；允许向上游倒流。

六种均为生成的理想算例；尺寸、储量、扰动不是地方实测。
通过只说明声明模型下的水头响应、收支和数值一致性。
