# 昆明 DEM 云南卫星图式与真实 OSM 水系 V004

本版将桂林生态地表原型中“程序字段负责表现、权威数据负责空间位置”的方法迁移到昆明：

- 地形来自冻结的 12.5 米输出网格 DEM 浏览资产。
- 云南式色彩由高程、坡度、局部起伏、湿润谷地、坡向、红土和裸岩字段确定性生成。
- 河流中心线和湖泊边界来自现代 OpenStreetMap 参考数据。
- 河宽只做横向显示扩展，中心线不移动。
- 湖面在固定岸线内按每个水体的 DEM 中位高程形成显示平面。
- 河流动画按 OSM 下游方向运行，并对自然河流与溪流做 DEM 端点方向审计。
- 手绘水系数量固定为 0。
- 1940 至 1945 年历史已核验水系数量暂为 0。

网页取消总览、俯视、朝北等相机预设。左键旋转，右键或 Shift 加拖动平移，滚轮缩放。

权威无压缩 float32 DEM 不进入网页，也不会被网页回写。网页中的 RG16、高度纹理、色彩图和水系字段均为可再生成的显示缓存。
