# DEM 地貌母体三维生产规则

状态：强制执行
生效日期：2026-08-30
适用范围：桂林、温州、昆明及后续全部 DEM 地貌母体样板和生产成果

## 1. 唯一可交付视觉形态

所有面向用户的地貌成果必须来自当前代码、当前数据与当前参数实时生成的可交互三维运行时。

允许的交付形态：

1. WebGL2、WebGPU 或 Three.js 可交互三维网页。
2. 当前三维运行时在真实浏览器中产生的截图与录屏证据。
3. 与当前三维运行时一一对应的参数、种子、数据身份、哈希与 QA 回执。

禁止的交付形态：

1. 二维概念图。
2. AI 生成效果图。
3. 手工绘制的伪三维画面。
4. 无法回到当前代码和当前数据的宣传图。
5. 用二维图像替代尚未完成的三维几何、材质、水系或田块工作。

二维资料只可作为研究证据，不得作为成果、完成证明或视觉验收候选。

## 2. 三维证据门

每次视觉提交必须同时满足：

```text
renderMode = interactive-3d
runtimeDataBound = true
browserRenderedEvidence = true
conceptImageCount = 0
aiGeneratedAcceptanceImageCount = 0
visualAcceptance = false
productionReady = false
```

自动 QA 必须检查：

1. 页面存在实际 WebGL2 或 WebGPU 画布。
2. 页面能够旋转、缩放、平移和切换相机。
3. 截图由本轮网页运行时直接产生。
4. 当前代码能够复现截图中的几何与材质。
5. 页面没有使用概念图覆盖三维画布。
6. 视觉批准前，所有人工批准字段持续为 false。

## 3. 真实 DEM 与精细化分层

12.5 米真实 DEM 保存宏观地理身份，始终只读。显示网格可以在源像元之间细分，用于承载可回滚的中观与微观程序层。源像元交点必须精确回到原始高程。

```text
z_truth_12p5m
  + z_karst_additive_visual
  + z_field_bund_channel
  + shader_meso_relief
  + shader_micro_normal_roughness
```

所有增量层必须独立命名、独立种子、可关闭、可对照、可回滚。任何程序增量不得冒充原生测绘高程。

## 4. 当前桂林第二版规则

1. 删除植物、树木、竹林、草地和生态实例。
2. 只保留地形、喀斯特形体、岩壁、坡脚、田块、田埂、沟渠、湿度和真实水系。
3. 原生 81 × 81 真值窗口保持不变。
4. 三维显示网格提升到至少 321 × 321，并在原生交点执行零误差复核。
5. 喀斯特增强必须形成清晰峰冠、陡壁、短峰脚、鞍部和谷地关系。
6. 材质吸收 Brick Mother 的多尺度形成场、分层色差、域扭曲、脊状噪波、细胞场、分离遮罩、凹腔、粗糙度和程序微法线。
7. 色彩、凹凸、粗糙度、AO 与湿度读取同一批事件场。
8. 远景先读到宏观地貌，中景读到田块与岩层，近景读到裂隙、冲刷、泥土与矿物变化。

## 5. 停止规则

出现以下任一情况时，禁止提交给用户验收：

1. 页面仍表现为低分辨率大网格。
2. 山体仍以圆滑馒头形为主。
3. 植物层仍在画面或控制面板中出现。
4. 细节主要来自均匀噪点。
5. 颜色与凹凸没有空间关联。
6. 田块、田埂、沟渠和水系关系无法在三维近景中辨认。
7. 截图来自概念图或任何脱离运行时的二维生成流程。
