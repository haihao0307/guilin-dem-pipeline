# 未解决项与禁止补写

## 1. “大象在森林”原始例子

当前恢复记录中没有找到用户早先那一段完整原话。

已经发生过一次错误：助手自行编造了“大象在森林里移动、休息、进食”等内容，用户明确指出这是瞎编。

因此后续任何执行器都必须遵守：

**在用户再次重述这个例子以前，不得把任何具体大象行为、时间顺序、位置变化或数据字段冒充用户原意。**

可以只保留：这个例子曾用于解释 TLO 的信息传达逻辑，但具体逻辑待用户重新给出。

## 2. TLO 仍是讨论中的候选格式

已确认：T=Time，L=Location，O=Object，四维世界文件定位，人机沟通减少信息流失。

尚未确认：扩展名、编码、chunk、索引、压缩、事件日志格式、关系 ontology 等。

## 3. 不能把“我总结过”当作用户验收

每次从讨论变成 schema/函数/生产合同都需要区分：

- assistant synthesis
- user confirmed
- tested
- adopted

当前 TLO R0.1 只属于 assistant synthesis based on explicit user statements，尚未作为生产格式冻结。
