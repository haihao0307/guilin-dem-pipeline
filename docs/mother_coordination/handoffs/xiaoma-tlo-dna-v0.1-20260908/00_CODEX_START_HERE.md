## 当前最重要的新定义

TLO = `Time + Location + Object`。

TLO DNA 文件被定义为候选“4D 文件”：它不以 TXT/PNG/OBJ 的媒体维度作为本体，而以三维空间中的 Location 加第一坐标 Time 共同描述对象在世界中的存在、状态和变化。`Object` 是文件所承载的对象身份与对象 DNA，不是第五个几何维度。

用户明确把 TLO 的首要目标定义为：提高人和机器之间的信息交流效率与准确性，减少长对话、跨窗口、跨执行器时的信息流失。
