# 全温州三维世界谱主计划

## 总链路

```text
Source Truth Capsules
→ Canonical World Truth
→ World Spectrum Address
→ Authoritative Full Score
→ Conductor Plans
→ Streaming Decode
→ GPU Terrain and World Voices
→ Human View and Machine QA
```

## 权威总谱

完整温州地形只保存一份多尺度可逆表示。总谱包含父谱、横向声部、纵向声部、耦合声部、有效性掩膜、来源身份和精确残差。

每个读取单元使用以下地址：

```text
WorldVersion
SpectralPage
Level
Band
CodeBlock
PrecisionLayer
```

完整解码必须逐像元恢复 Canonical Truth，差异为零。

## 谱页体系

以全域固定谱页组织数据。每页保留共享边和足够的变换重叠区。层级至少覆盖 800、400、200、100、50、25、12.5 米。

共享边 QA 同时检查高程、法线、水陆掩膜、来源身份和环境声部采样一致性。

## 多指挥

总览、近景、水文、物理、海岸、农业、精确导出和档案扫描均通过小型指挥索引读取同一份总谱。指挥只保存页面、频带、精度、时序和优先级。

相机精度、交互精度、物理精度、水文精度和安全精度取当前最高需求。过时请求必须取消。

## 环境声部

土壤、水文、地质、土地覆盖、植被、海床、潮汐、洋流、农业、居民地和历史证据共享世界谱地址，同时保留各自的原生分辨率、时间、单位、基准、不确定性和来源版本。

## 三维工作台

主画面覆盖完整地图。支持全域高空、山谷、平原、河口、海岸和贴地镜头。支持鼠标与触摸旋转、平移、缩放、自动飞行、真值比较、声部静音和数据身份查看。

工程热力图与 QA 放入可展开验证台，不占据主视觉。

## 验收

机器门禁包括精确恢复、共享边、NoData、水陆拓扑、主峰、鞍部、脊谷、河网和海岸稳定性。

视觉门禁包括轮廓稳定、缩放连续、瓦片边界不可见、材质尺度合理、移动端可用和真实地貌可辨认。
