# 靠谱世界大合唱交接状态

日期：2026-09-09

## 一、这一阶段已经确定的内容

### 1. 正式名称

共同语义与度量体系的正式工作名称为“靠谱”，机器标识暂用 `KAOPU`。

靠谱首先是一套语义，不绑定某一种文件后缀、数据库、二进制布局或传输容器。编码可以随技术变化，Identity、Space、Time、Scale、Quantity、Relation、Observation、Claim、Provenance、Uncertainty、Change 和 View 的含义必须稳定并可版本转换。

### 2. 中性定位

靠谱处在人、机器和现实世界之间，负责客观说明对象身份、时空、尺度、量值、关系、来源、处理链、独立观察、误差、未知与冲突。

它不承担审美、文化优劣、政治立场和个人偏好判断。一栋现代新建的传统风格建筑可以完整记录，同时保持自己的建造时间、材料、结构和对象身份。它不能自动取得早期历史建筑的身份。

### 3. 世界大合唱

世界被组织成一场持续演奏的大合唱。

世界总谱保存共同语义、全球参考、时间基准、对象地址、尺度规则、证据规则、低频主体、变化入口和残差索引。

地区谱承接世界总谱。温州是第一份完整地区谱。

场景谱继续展开城市、街区、村落、山谷、岛屿、机场、建筑群和房间。

对象谱继续展开房屋、人物、动物、植物、飞机、武器、道路、桥梁和杯子。

部件谱与材料谱继续展开屋顶、墙、瓦、骨骼、肌肉、机翼、发动机、金属、木材、陶瓷、孔隙、风化和微观结构。

天气、海洋、侵蚀、生长、行为、交通等属于横向过程声部。照片、航拍、卫星、地图、测绘、文字和回忆属于证据声部。

### 4. 总指挥关系

用户决定世界最终值得走向什么方向。

小妈承担世界大合唱总指挥与 Judgment，负责共同节拍、Context、问题树、路线判断、资源重分配、停止重复、冲突处理、候选晋级、跨 Mother 方法迁移和阶段冻结。

各 Mother 是声部长。各 AGO 负责独立搜索、继承前人成果、建立实验、质疑和验证。Critic 专门攻击候选路线。Verifier 负责机器可检查的不变量。

### 5. 造波定义

项目内所有“造波”均指统一的世界生成与重建算子体系。它包括基础波、噪波、相位、频率、振幅、方向、旋转、尺度、域变换、调制、耦合、随机种子、时间演化、边界条件和必要残差。

任何造波输出都要绑定具体量值类型、定义域、参考系、适用尺度、时间含义、单位和误差。高度、速度、密度、温度、浓度、消光与亮度不能混成同一种无类型数值。

连续世界通过带类型的造波、场和残差表达。离散身份、事件、社会关系和证据依赖通过图表达。

### 6. 历史世界

系统不宣称一次性拥有完整过去。历史世界随着新 Observation 和 Claim 持续收敛。

照片、航空摄影、卫星影像、地图、测绘、传感器、回忆和文字都可以成为 Observation。Observation 的几何精度、社会关系记忆和情绪信息可以具有不同可靠程度。

某个时代真实形成的误测或错误回忆仍然可以保存为 Perceived World 的历史 Observation。它不能直接冒充 Physical World 的状态。

### 7. 独立观察

文件数量不能直接代表独立证据数量。

扫描件、网络复制件和压缩版如果来自同一底片，只形成同一个 Observation Root。不同机构或不同观察者也可能共享同一个地图基准、控制点、标定、假设或上游档案。

Evidence Independence 由 lineage、dependency、shared calibration、shared assumption 和 systematic bias 图推导，不能只手填一个分数。

### 8. 当前最小数据流

当前最稳定的候选链条为：

`Source Event -> Evidence Asset -> Observation -> Claim -> Evidence Graph -> Current Best View`

Transformation Process 可以出现在资产转换、观测解释、Claim 推导和 View 生成之间。每次处理保存输入、输出、方法、版本、参数、执行者、时间和哈希。

Current Best View 是由指定证据集、查询范围、时间、尺度、政策版本和 transaction time 计算出的可重算视图。它不能静默覆盖原始证据和冲突 Claim。

## 四、已经完成的实验

### OpenAI Pilot Round 01

使用明确声明为 synthetic 的翠湖历史建筑微型案例，检查 Source Event、Asset、Observation、Claim、World Object、Process 和 Current Best View 分层。

主要结果：

1. 同一航空底片的扫描件和网络复制件不增加独立观测根。
2. 回忆图的空间位置 Claim 可以与航空定位冲突，同时保留邻居和饭馆关系 Claim。
3. 现代同址建筑保持独立 Object ID。
4. AI 重建明确标记为 synthetic，并排除于直接历史证据。
5. 没有观测覆盖的西立面保持 Unknown。
6. Verifier 实际结果为 `16/16 PASS`。

该实验验证语义流程，不代表真实翠湖历史。

### 靠谱世界大合唱 AGO 对话实验

当前 GPT-5.6 Sol 通过六次上下文隔离角色审查、交叉质询、红队攻击和小妈 Judgment，形成七层闭环、十项风险闸门、十二项候选核心语义和二十四条不变量。

主要结果：

1. 现实层、靠谱语义层、证据陈述层、世界总谱层、造波与图层、指挥演奏层、学习治理层闭合。
2. Scale 作为通用语义，Spectrum 作为连续场扩展。
3. 造波不能替代离散身份、关系和证据图。
4. View 必须公开查询范围、时间、尺度、政策和预算。
5. 压缩必须保护罕见细节、一次性事件和必要残差。
6. Verifier 实际结果为 `20/20 PASS`。

该实验只证明候选逻辑链内部闭合。真实温州谱页尚未接入。
