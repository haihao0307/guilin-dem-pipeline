## 3. 为什么称为全量包

“全量”表示当前这条知识与架构主线的可恢复载荷完整，包括阶段冻结、候选增量、两个实验、验证器、失败边界、未完成项和新对话启动入口。

它不表示整个温州生产数据或整个 GitHub 仓库均被复制进 ZIP。

## 4. 原始与派生状态

原始 Git 提交继续作为权威来源。ZIP 是固定来源提交的可携带快照。

包内任何文件发生变化时，`MANIFEST.sha256` 验证将失败。应回到交接分支或固定提交重新下载。

## 5. 安全边界

1. 包内 synthetic fixture 不得被解释为真实昆明或翠湖历史。
2. 候选 R2 逻辑不得冒充正式冻结规范。
3. 任何现代重建或 AI 重建不得取得历史原始观测身份。
4. Unknown、Not Observed、Observed Absent 和 Not Applicable 必须继续区分。
5. 同源复制不得增加独立 Observation Root。
6. 新对话应继续从温州真实小样例开始，而后再考虑扩大规模。
