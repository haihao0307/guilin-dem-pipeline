# Pending gates at handoff

This is a prioritization aid, not permission to execute all items at once.

## First gate — coordination concurrency

Before research:
1. re-fetch the authoritative learning branch head;
2. read any commits newer than the handoff base;
3. read current Mother feedback/routing acknowledgements;
4. select exactly one bounded question.

If another coordinator has advanced the branch, inherit that work and do not reproduce it.

## Important unresolved gates

### R32 Substance runtime replay
Unknown until a real, version-locked Substance Engine/SBS/SBSAR execution exists.

### R31 Tiles real shader A/B
Unknown until the actual Tiles functions are compared in the target WebGL path with fixed camera/seed/light/tone mapping, including linear height/normal behavior, near/far shimmer, 390x844 performance and human visual acceptance.

### R30 Tellux target-runtime trial
CPU semantics are not browser/GPU/iPhone evidence. A single Mother trial may test the revision cache Candidate; do not roll it system-wide before target-runtime evidence and Mother feedback.

### Source-audit separation
Do not collapse:
- schema conformance,
- raw-data replay,
- evidence-root independence,
- coordinate/reference-frame reconciliation,
- human acceptance.

A mismatch between reference frames is not by itself an evidence contradiction.

## Selection rule

Choose the next question by expected cross-Mother value and uncertainty reduction, not by recency or novelty. A user-supplied reference receives triage priority but not automatic adoption.
