# 07｜跨对象应用图谱

## 地形与喀斯特

观测 DEM + 岩性域 + 构造方向 + 排水 + 溶蚀/崩塌过程 + 多尺度形体展开。必须保留真实断裂和山脊，消除无因果的密集针尖。

## 海岛与海岸

基岩主体 + 波浪暴露 + 潮位 + 岸线侵蚀 + 崩塌 + 泥沙输运 + 沙滩沉积 + 盐风化 + 植被稳定。海水不能只是平面，岸线也不能只靠噪声锯齿。

## 土壤

颗粒分布 + 团聚体 + 孔隙 + 水分 + 干湿循环 + 根系 + 有机质 + 压实 + 冲刷。颜色应由成分和状态派生，而不是先画褐色噪点。

## 瓦、砖、土坯和石材

主体成型过程 + 材料域 + 烧结/干缩 + 颗粒 + 孔隙 + 边缘损伤 + 风化 + 潮湿 + 维护。函数框架可共享，但每类材料的方向、尺度、幅度和时间规律不同。

## 建筑、街道和村落

地形 + 水源 + 可达性 + 结构技术 + 土地/产权 + 人口 + 风险 + 历史扩建。建筑和道路相互侵占、让步和继承，生成的是路径依赖的局部均衡，而非一次性整齐规划。

## 植被

光、水、土、风、竞争、年龄和扰动决定生长。树形不应由随机枝条独立拼接，而应由资源场和结构约束驱动。

## Ocean / Weather

流体和天气不仅提供视觉背景，也应作为其他对象的驱动场：湿度改变砖瓦和土壤，风改变植被和浪，降雨改变径流、冲刷和农田水位。

## 人和动物

身体函数需受骨骼、肌肉、接触、意图和环境约束；动作不是预制位移，而是状态、任务、感知和物理关系共同演奏的结果。

## 统一接口

所有对象至少应暴露：

- `identity()`
- `observationRoot()`
- `coordinateDomains()`
- `functionGraph()`
- `fields()`
- `constraints()`
- `interactions()`
- `step(dt, events)`
- `evaluate(view, budget)`
- `evidence()`
- `rollback(time/version)`
