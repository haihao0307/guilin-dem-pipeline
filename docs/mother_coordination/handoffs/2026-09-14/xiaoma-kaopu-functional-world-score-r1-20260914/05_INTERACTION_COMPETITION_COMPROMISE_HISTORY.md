# 05｜相互侵占、妥协、共生与历史

## 1. 世界不是对象的独立叠放

房屋侵占院落和街道，街道切开地块，排水沟依附道路，树根寻找缝隙，河流阻挡又吸引聚落，农田争取可耕坡面。真实世界的丰富性来自对象关系长期累积，而不是每个对象单独做得复杂。

## 2. 交互算子

对对象 A、B 定义关系算子 \(I_{AB}\)：

- `occupy`：争夺空间；
- `repel`：保持距离；
- `attach`：依附边界或骨架；
- `block`：形成不可穿越区；
- `yield`：一方在代价下让步；
- `share`：共享墙、渠、道路或边界；
- `transform`：一方改变另一方状态；
- `repair`：恢复或覆盖损伤；
- `inherit`：新结构沿用旧结构；
- `cooperate`：互相提高收益。

结果不是简单优先级覆盖，而是受成本、权利、时间和状态调节。

## 3. 局部均衡而非全局最优

可以用成本函数描述冲突，但不能把世界误认为一次性全局优化：

\[
x^*=\arg\min_x \sum C_i(x)
\]

真实形成过程更接近：

\[
x_{t+1}=G(x_t,local\ information,limited\ resources,existing\ commitments)
\]

人只在当时条件下做局部可行决策。旧道路、产权、家族关系、已有房屋和历史事件会锁定后续形态。

## 4. 妥协应留下痕迹

好的世界乐谱不只存最终边界，还要存冲突解决方式，例如：

- 房屋退让后形成不规则街角；
- 道路拓宽留下旧墙基；
- 水渠绕过岩体形成弯折；
- 梯田扩张到成本边界后停止；
- 修缮瓦片与旧瓦产生年代差；
- 河流改道留下旧河床。

这些痕迹是“真实感”的重要来源，不能被统一平滑掉。

## 5. 戏剧、生态、物理和博弈

“戏剧”适合表达角色、关系、事件和时间；“生态”适合表达竞争与共生；“物理场”适合表达连续作用；“博弈”适合表达有限资源和局部决策。靠谱世界乐谱应吸收四者，而不是仅选择其中一种比喻。
