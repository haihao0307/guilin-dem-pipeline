# 03｜函数语法与组合

## 1. 统一形式

一个受约束的多尺度形体展开可写成：

\[
p'=p_0+\sum_{s=0}^{N-1} w_s(view,budget)\,a_s\,M_s(p,S)\,V_s\big(f_s(T_s(p,S))\big)
\]

其中：

- \(p_0\)：观测或冻结主体上的点；
- \(T_s\)：第 \(s\) 个尺度的稳定域变换；
- \(f_s\)：该尺度的基础函数；
- \(V_s\)：把标量/向量场转成合法位移方向；
- \(M_s\)：材料、坡度、水、历史等调制；
- \(a_s\)：尺度幅度预算；
- \(w_s\)：观察和性能门控，需平滑过渡。

最终结果还要经过约束投影：

\[
p''=\Pi_C(p')
\]

## 2. 原语家族

### 坐标原语

平移、旋转、缩放、对数径向、角度、沿曲线坐标、流线坐标、表面测地坐标、材料随动坐标。

### 形态原语

距离场、球/柱/平面 SDF、ridge、valley、terrace、layer、cell、crack、pore、blob、skeleton。

### 组合原语

加权和、乘积调制、min/max、smooth-min、布尔、掩膜、形态学膨胀/腐蚀、域扭曲、重复与嵌套。

### 微分原语

梯度用于方向；曲率用于边缘和沉积判断；拉普拉斯用于平滑、扩散和异常尖点诊断。

### 动态原语

扩散、对流、侵蚀、沉积、反应扩散、生长前沿、裂纹传播、资源消耗、维护恢复。

## 3. 组合不等于相加

简单形式：

\[
F=F_1+F_2+F_3
\]

很容易造成互相放大、狗牙和不可解释细节。更可靠的组合应包含：

- 每层职责；
- 幅度预算；
- 方向预算；
- 作用掩膜；
- 前后依赖；
- 约束投影；
- 证据等级。

例如高频孔隙只能在材料域内部和允许的风化区生效，不能移动建筑锚点、破坏接触或改变山脊主体。

## 4. 稳定随机性

需要随机性的地方，种子必须来自：

\[
seed=Hash(ObjectID,MaterialDomain,LocalRegion,Scale,Epoch)
\]

不能来自帧号、当前镜头或不稳定遍历顺序。镜头只能决定是否求值，不得改变对象自身结构。

## 5. 参数不是越多越好

函数库需要控制可辨识性：

- 参数应具有物理、材料或设计含义；
- 相互高度相关的参数需合并或约束；
- 每个尺度有明确单位；
- 必须能从观测、文献或实验校准；
- 参数变化应有单调或可解释结果；
- 不能依赖“碰巧调出一个好看画面”。
