# 10｜验收测试

## 核心正确性

1. 同一 Object ID、位置、材料域、时间和参数重复访问，结果一致。
2. 镜头移动只改变求值层级，不改变对象本身的随机结构。
3. 关闭颜色和材质后，灰模与轮廓仍显示真实形体变化。
4. 高频层关闭后，低频主体与 Observation Root 不漂移。
5. 无因果依据的密集狗牙、针尖和帧间闪烁消失。
6. 每一尺度可单独显示，并能解释其职责、单位和幅度。

## 跨对象反证

7. 同一内核用于山、瓦和 Farmland 时，不产生同一种表面外观。
8. 材料或过程参数改变，应产生符合方向的可解释变化。
9. Worley/Cellular 关闭后，Farmland 仍保持水力、土方和经营逻辑；说明它只是原语之一。

## 约束与历史

10. 田、树、建筑和瓦片不得悬空、穿透或破坏接触。
11. 水路具有连续高程和质量预算，不能倒流或凭空消失。
12. 历史阶段前后可回放，修缮、侵蚀、扩建和废弃留下可解释痕迹。
13. 生成细节与观测真值在数据层和界面上均可区分。

## 性能与交付

14. 记录设备、分辨率、对象数、活跃尺度、帧时间和显存/内存。
15. 移动端与桌面端使用不同预算，但对象身份一致。
16. LOD 进入/退出平滑，无跳变、重随机和明显接缝。
17. 缓存失效条件明确；状态变化只更新受影响局部。
18. 用户视觉审批前，版本标记为 Candidate，不得写成 Accepted。
