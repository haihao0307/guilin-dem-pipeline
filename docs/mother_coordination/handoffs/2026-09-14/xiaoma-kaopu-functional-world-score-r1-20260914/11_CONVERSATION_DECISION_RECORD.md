# 11｜本轮讨论决策记录

## 用户提出的核心意图

本轮用户反复强调：

- 看任何事物时，应优先思考“用什么函数表达它”；
- 函数变量和组合应能形成极其丰富的对象与地貌；
- 该思维应贯通地形、海岛、土壤、Farmland、道路、建筑和材料；
- 从地球到山河、石块、田块和土粒，不同尺度应属于一个连续体系；
- 世界丰富性来自对象之间相互侵占、克制、妥协和共生；
- 目标不是只看表面，而是理解世界为何形成；
- Mesh、PBR 和贴图应退到间接输出位置；
- Yohei 的体系需要先彻底学明白，再进入靠谱内核；
- Farmland 应被理解为人顺山就势、在水、劳力和风险允许下尽量提高生产力的空间生长过程。

## 小妈形成的当前解释

1. 核心不是“万能噪声库”，而是可组合的函数、场、约束、交互、过程和历史。
2. Microscope 提供跨尺度展开方法，靠谱提供对象身份、物理因果、证据和历史边界。
3. 世界乐谱必须既能表达物理，也能表达有限理性的人类决策和路径依赖。
4. “细菌感”应提炼为空间组织语法，不应复制为所有对象的外观。
5. Farmland 的合理生成对象是“经营和灌溉系统”，不是单个台阶模型。
6. 函数源表达与 Mesh/PBR 输出应形成编译关系，而不是非此即彼。

## 本包冻结的决定

- 正式确立 `Functional World Score / World Function Grammar` 为靠谱核心研究主线。
- Yohei 代码级学习为当前第一优先级。
- 温州低频大形冻结，小 patch 先行。
- 三类反证 probe 为内核成立的最低证明。
- Farmland 后续必须接入地形流形、水力、土方、竞争、历史与生产目标。
- 所有生成细节必须携带证据等级和可回退路径。
