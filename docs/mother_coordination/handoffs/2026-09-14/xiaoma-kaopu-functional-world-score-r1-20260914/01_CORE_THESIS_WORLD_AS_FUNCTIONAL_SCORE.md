# 01｜核心命题：世界应被表达为函数化乐谱

## 1. 从“资产”转向“形成机制”

传统三维生产通常以 Mesh、UV、贴图、PBR 参数为源文件。这种表达能够保存一个时刻、一个尺度下的外观，却通常丢失：

- 对象为什么在这里；
- 边界为什么这样弯曲；
- 形体由什么材料和过程形成；
- 与邻居发生过什么争夺、避让和修补；
- 缩放到另一尺度时应出现什么结构；
- 时间继续前进时会怎样变化。

因此，靠谱体系的源表达应当从“外观快照”升级为“形成和演化的乐谱”。

## 2. 形式化定义

设对象集合为 \(O\)，观测为 \(Q\)，函数图为 \(\Phi\)，约束为 \(C\)，关系为 \(R\)，历史为 \(H\)，环境为 \(E\)。世界状态可写为：

\[
S_t=(O,Q,\Phi,C,R,H,E)_t
\]

连续过程、对象交互和离散事件共同推动状态：

\[
S_{t+\Delta t}=\Pi_C\left(S_t+\Delta t\,[P(S_t,E_t)+I(S_t)]+J_t\right)
\]

其中：

- \(P\)：侵蚀、生长、沉积、腐朽、修缮等过程；
- \(I\)：对象之间的占据、阻挡、吸引、共享、替换；
- \(J_t\)：洪水、坍塌、火灾、建设、拆除等事件；
- \(\Pi_C\)：把结果投影回不违反结构、拓扑、接触和物理约束的合法状态。

面向观察者的输出是：

\[
Y=\mathcal R(S_t,view,platform,budget)
\]

因此 Mesh/PBR/贴图是 \(Y\) 的一部分，而不是 \(S_t\) 的全部。

## 3. 函数不是“噪声”的同义词

函数体系至少包含四种性质不同的表达：

1. **描述函数**：表示脊、谷、孔洞、裂纹、层理等形态。
2. **过程函数**：表示水流、侵蚀、风化、生长、修复等变化。
3. **约束函数**：表示不可穿透、必须接地、水不能自然逆坡等合法性。
4. **决策函数**：表示人在有限信息、劳动力、产权和历史条件下作出的局部选择。

只叠加 noise 会得到纹理；组合这四类函数，才可能得到世界。

## 4. 为什么它与“靠谱”吻合

靠谱一直强调：

- TLO 统一时间、位置、对象；
- Object DNA 保存身份、部件、锚点、材料、能力和关系；
- Observation Root 保存来源、分辨率和置信度；
- 稳定低频主体与局部高频展开分层；
- 乐谱与编码、渲染容器分离；
- 历史可回放、可逆、可追溯。

函数世界乐谱不是另起一套概念，而是把这些原则连接成可运行的数学和计算内核。

## 5. 需要修正的一点

“Mesh/PBR/贴图有损”并不能推出“它们应被抛弃”。现实约束是：

- 扫描、照片和纹理本身也是观测证据；
- GPU、游戏引擎和移动设备仍需要可缓存的几何与材质；
- 某些历史偶然细节无法由简洁函数可靠推导；
- 与外部工具交换时，Mesh/PBR 仍是重要公共格式。

正确关系是：**函数乐谱为源，传统资产为观测输入、缓存结果、交换格式和验证证据。**
