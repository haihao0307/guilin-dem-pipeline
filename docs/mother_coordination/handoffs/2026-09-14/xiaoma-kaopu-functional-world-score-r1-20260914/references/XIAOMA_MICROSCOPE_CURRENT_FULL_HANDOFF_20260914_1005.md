## Microscope 的形体逻辑

应把 Microscope 实现为“稳定坐标域 + 多尺度场 + 受约束形体位移”，而不是 noise texture。

建议逻辑：世界/对象坐标 -> 稳定局部或材料坐标 -> 每尺度稳定域变换 -> 尺度场 -> 材料/地貌控制的幅度与方向 -> 多尺度位移累加 -> 更新真实表面位置/高度/轮廓 -> 再由最终几何的曲率、坡度、凹陷、暴露度等派生颜色、粗糙度、湿度、苔藓等表现。

低频层控制主体，高频层不能推翻主体；高频幅度必须随尺度受限。保护拓扑、锚点、边界、接触和建筑结构关系。旋转/域变换应随石块、矿物区、局部位置等稳定变化；两个固定旋转可以合并，不能堆无意义旋转。细节必须位移表面，但不能超过该尺度可解释的范围。

## 跨对象关系

同一方法要贯通地形、瓦、砖、土坯、石材，但共享的是尺度、坐标、累加、稳定性和保护约束，不共享同一种外观。每种对象必须有自己的材料、成因、状态和方向规律，禁止把山、砖、瓦全部做成同一种“细菌表面”。

Object DNA 决定对象身份、部件、锚点、材料域、状态和关系；TLO / World Kernel 管时间、位置、身份、依赖和观察上下文；Microscope 负责在给定对象、材料、尺度和观察条件下从稳定主体展开更细形体。随机种子、相位和域变换必须绑定对象身份、材料域和局部位置，不能绑定帧号或镜头随机数。

## 必须避免的逻辑错误

1. 文件小不等于算力一定小。17 层若全世界每帧求值仍可能很贵，必须按需层级、缓存、距离门控和实测。
2. 程序生成得自然不等于恢复了真实测量。12.5 m DEM 没测到的厘米裂隙只能是受规律约束的生成细节，除非有更高分辨率 Observation Root。
3. 连续圆润不等于全部抹平。真实成因支持的断裂、层理和局部锐边必须保留。
4. 多尺度不等于多层随机噪声相加。每层必须有尺度职责、方向/域、幅度预算和跨层约束。
5. 看起来像不等于理解规律。体系应能解释为什么该处产生这种形状，并能在不同对象、尺度和状态下复用。
