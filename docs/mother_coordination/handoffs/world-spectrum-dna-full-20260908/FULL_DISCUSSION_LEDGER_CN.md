# 世界谱 DNA 讨论全量纪要

本文件按照讨论推进顺序保存语义完整的会议纪要。它覆盖本轮所有关键概念、纠正、例子和未决问题。措辞经过整理，未作为逐字录音稿使用。

## 第一阶段，三种波形参考进入 DEM 研究

用户提供三张参考图。

第一张来自 Yohei Nishitsuji 的极短 GLSL 波场。关键结构包括固定旋转、沿深度的重复采样、频率按倍率递增、振幅按频率衰减、相位随时间变化，以及颜色累积。用户要求系统学习其完整网格与逻辑，重点吸收它以极小程序生成极复杂自然形态的能力。

第二张是 Ridged Multifractal。它通过 `1 - abs(noise)` 形成脊线，再平方强化尖锐区域，并使用上一层权重控制下一层细节。用户认为它适合补足卡斯特、崎岖山地、尖锐山脊和谷地。

第三张是 Unknown Pleasures 式剖面线。单根线是一维高度信号，多根相邻线叠放后形成二维高度场。继续增加另一个方向或垂直维度，可以重建三维空间关系。

## 第二阶段，自然生成 DNA

讨论确认 Yohei 方法的价值远超单一视觉效果。

候选自然生成链：

`旋转 -> 频率增长 -> 振幅衰减 -> 相位变化 -> 多尺度累积`

它拥有规律、连续性和非机械重复。它可以迁移到山体、岩石、细胞、金属氧化、锈蚀、木纹、云、烟、水面与材料微结构。

候选公式：

`NatureField(P) = sum(A_n * F(R_n(P) * f_n + phi_n))`

其中 `R_n` 控制方向，`f_n` 控制频率，`A_n` 控制衰减，`phi_n` 控制相位，`F` 可以选择余弦、ridge、距离场、cellular 或其他基础函数。

## 第三阶段，长波固定与真实 DEM 约束

用户提出必须研究如何固定很长的波。真实 12.5 米 DEM 保存山峰、主山脊、谷底、河道、坡折和鞍部。高频生成只能在真实结构允许的地方展开。

候选分层：

`真实 DEM 主形`
`受约束的中频山脊与谷地`
`旋转衰减高频`
`材料微观频率`

候选表达：

`W(u,v) = W_base(u,v) + Detail(u,v) * Constraint(u,v)`

细节强度可以由坡度、曲率、岩性、水系距离和地貌类型决定。平原压制高频，卡斯特和崖壁允许更多 ridge。

## 第四阶段，两部谱与唯一交点

用户提出地球可以理解为一部横向乐谱和一部纵向乐谱。横谱与纵谱在某个位置相交，交点形成 location。

候选地址：

`SurfaceLocation = Intersection(Sigma_u, Sigma_v)`

每条谱拥有整数相位。联合相位形成位置签名：

`LocationSignature = (u_phase, v_phase)`

交点是地址。交点处两部谱的联合振幅、频率、相位和层级形成地表高度及自然属性。

为了覆盖球面，R0.1 增加 `atlas_page` 处理极点、闭合接缝和双交点歧义：

`EarthLocation = (earth_id, atlas_page, u_phase, v_phase)`

## 第五阶段，一维、二维与三维

一根横向剖面是 `H(u)`。

一族相邻横向剖面形成 `H(u,v)`。

横谱声部与纵谱声部的乘积构成一个二维地貌分量：

`H(u,v,t) = H0 + sum(lambda_k * X_k(u,t) * Y_k(v,t)) + R(u,v,t)`

多组声部叠加可以表达更复杂的地表。地表高度与局部法线共同给出三维位置。离开地表的对象使用沿法线的有符号偏移 `d`。空中为正，地下为负。

## 第六阶段，绝对位置产生相对关系

同一连续谱决定相邻位置，所以绝对位置一旦确定，局部坡度、曲率、山脊方向、水流方向和邻域关系可以从谱的导数计算。

候选量：

`dH/du`
`dH/dv`
`normal = cross(dP/du, dP/dv)`

在没有显式结构边界时，相邻点应保持连续。悬崖、断层、建筑边缘和洞穴入口必须由边界事件或层级变化说明。

## 第七阶段，时间进入世界

时间决定世界版本与对象状态。

候选世界查询：

`World = Decode(Time, SpectralLocation, Level, ObjectDNA, State, History)`

事件地址：

`Event = Who + When + Where + WhatChanged`

同一谱位在不同年份可以拥有不同道路、稻田、建筑、植被、水位和对象关系。稳定山体可能只记录极少变化。变化密集区域保存更多事件和残差。

## 第八阶段，Object 与父子关系

所有对象拥有稳定身份和局部位置。移动对象优先保存在父对象内部的位置，世界位置沿父链递归求得。

`WorldPose(child,t) = WorldPose(parent,t) composed LocalPose(child,parent,t)`

B24 是某挺 Browning M2 的父对象。M2 在飞机的具名枪位中定位。机匣、枪管、撞针、枪机、枪架和螺丝继续作为 M2 的子对象。

父子关系必须保存：

`child`
`parent`
`relation_type`
`slot`
`start_time`
`end_time`

飞机移动时，M2 和所有仍连接的子件自动跟随。发生拆卸、抛出、断裂或坠落时，detach 事件结束旧关系，子对象开始独立轨迹或连接到新父级。

## 第九阶段，Object DNA 蒸馏

一个对象家族学会以后，共同规律应进入可复用 DNA。新型号与新实例只保存差异。

`NewObject = SharedDNA + TypeDifference + InstanceDifference`

机械对象的候选继承链：

`UniversalDNA -> MechanicalDNA -> FirearmDNA -> BrowningFamilyDNA -> M2ModelDNA -> VariantDNA -> InstanceDNA`

飞机、人体、动物、建筑和植物可以采用同样结构。人体公共 DNA 保存骨骼、器官和面部部件的关系。个体只保存尺寸、比例、左右差异、材料状态和必要残差。

## 第十阶段，人类与智能体共享语言

用户提出核心系统需要自己的统一语言，避免度、弧度、投影和引擎坐标之间不断翻译造成误差。

机器层使用固定点整数相位、整数时间、唯一对象 ID 和具名槽位。

人类层使用同一语义的可读地址：

`1944 年 / 某架 B24 / 左腰枪位 / 某挺 M2 / 机匣 / 左侧第三颗螺丝`

机器可以解析成稳定路径和相位地址。传统经纬度、卫星资料、DEM 和 OSM 仍可从边界转换进入。核心对象身份不依赖旧坐标格式。

## 第十一阶段，自适应地球压缩

不同区域使用不同复杂度。

海面宏观部分可由基础海平面、潮汐和波状态表达。海床仍属于地形真值。

平原使用少量低频声部与水系约束。

沙漠使用方向明确的风成谱和少量局部残差。

丘陵增加中频声部。

山地、卡斯特和峡谷增加局部谱页、旋转声部、Ridged 声部和真实残差。

总体原则：

`数据 = 可生成规律 + 真实锚点 + 无法预测的差异`

数据量跟随信息密度，不平均分配给地球表面。

## 当前共识

1. 这是一套候选世界描述语言。
2. DEM 是第一个验证对象。
3. B24 和 M2 是第一个移动对象与父子关系验证对象。
4. 谱、时间、Object 和父子关系需要在同一文件结构中闭合。
5. 简单地区采用简单表达，复杂地区增加局部声部与残差。
6. 真实来源与生成规律必须分开。
7. 当前架构仍需数学证明、误差实验、球面拓扑处理和二进制实现验证。
