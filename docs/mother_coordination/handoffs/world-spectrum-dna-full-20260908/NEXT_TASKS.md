# 下一阶段任务

## P0，固定概念边界

1. 为谱位、谱页、声部、锚点、残差、对象路径和事件建立术语表。
2. 明确永久身份与计算缓存的边界。
3. 明确地表位置与完整三维位置的区别。
4. 明确 Type DNA、Variant DNA、Instance 和 State 的区别。

## P1，DEM 实验

1. 读取真实 12.5 米小窗口。
2. 建立低秩可分离基线。
3. 建立局部谱页。
4. 测试平原与山地的不同 rank。
5. 引入旋转衰减自然谱。
6. 在真值层之外测试 Ridged 子测量尺度细节。
7. 输出完整误差和字节报告。
