# Codex 工作规则

本目录是候选研究包。所有工作先在本目录或独立实验目录中完成。

## 必须保持

1. 时间是事件查询的第一条件。
2. 地球表面核心地址采用 `earth_id + atlas_page + u_phase + v_phase`。
3. 地表高度由谱耦合、锚点和残差共同重建。
4. 传统经纬度、投影坐标和引擎 XYZ 只作为兼容转换接口。
5. Object Type DNA、对象实例、父子关系和事件历史分开保存。
6. 子对象世界位姿由父对象世界位姿与局部位姿递归合成。
7. 父子关系必须带生效时间、结束时间、关系类型和槽位。
8. 网格与纹理属于缓存，不能冒充权威对象本体。
9. 所有随机过程必须有稳定种子和明确随机域。
10. 所有重要输出必须附误差、证据等级和有效范围。

## 禁止事项

1. 禁止直接修改冻结的 DEM、B24、M2、人物、建筑或其他生产分支。
2. 禁止宣称本体系已经取代测地学或现有坐标系统。
3. 禁止在没有证明时宣称全球交点唯一。
4. 禁止把视觉相似当作真实地理验证。
5. 禁止用程序化高频覆盖真实山峰、河谷、岸线、建筑槽位和机械接口。
6. 禁止把来源截图、参考网格或第三方代码直接升级为生产资产。
7. 技术研究优先使用论文、作者主页、官方文档和原始仓库。不要使用中文网站作为信源。

## 代码要求

1. Python 原型只使用标准库，除非实验文档明确记录新增依赖。
2. 二进制写入必须确定性，字节序固定为 little endian。
3. 浮点数不得直接承担永久地址身份。地址相位使用整数固定点。
4. 同一输入必须产生同一哈希。
5. 新增功能必须增加测试。
6. 任何格式变更必须提升格式版本并补迁移说明。

## 首轮完成条件

首轮 Codex 工作只有在下列输出同时存在时才算完成：

1. 小窗口 DEM 谱分解实验。
2. 原始 DEM 与重建 DEM 的误差报告。
3. 平原与山地的自适应复杂度对照。
4. B24 与 M2 父子关系示例的可执行验证。
5. WSD0 容器的确定性往返测试。
6. 全部未知项和失败项公开记录。
