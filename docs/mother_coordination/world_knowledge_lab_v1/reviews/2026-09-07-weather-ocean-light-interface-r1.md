## 明确退回的内容

自动草稿曾提出把 Houdini 体积密度直接映射成 Substance PBR 的表面贴图与参数。这个连接不采用。Substance PBR 主要描述表面及分层材料；云烟的密度、吸收、散射、相位和发光继续属于体积介质。体积对表面的影响应通过入射光、沉积、湿润或真实接触事件传递，不能把密度字段直接复制进粗糙度、法线或金属度。

自动草稿把风速、波幅和光照统一写成零到一归一化值。这个表述不采用。风速、波高、距离和时间应尽量保存米、秒、米每秒等物理单位。只有缺乏标定的艺术参数可以使用归一化范围，并且必须记录其校准对象和有效范围。

自动草稿提到云密度对海面法线的影响。云密度不能直接改变海面法线。海面法线由水面几何或波场决定；云通过遮挡太阳、改变天空辐亮度和环境反射影响海面的可见亮度。

自动草稿还混用了水下介质与湿润固体。水下介质保存水体吸收与散射；湿润岩石或建筑表面保存覆盖水膜、粗糙度和颜色变化。二者分开建模。

## 重新收敛的接口

Weather 与 Cloud 对外提供只读光照接口候选：

`sunDirection(t)`，世界空间单位方向。

`sunRadiance(t)`，太阳入射辐亮度或经过项目标定的等价量。

`sunTransmittance(x,t)`，从太阳到世界点 `x` 的无量纲透射率，范围零到一。

`skyRadiance(x,omega,t)`，位置 `x`、方向 `omega` 和时间 `t` 下的天空辐亮度候选。

`windVelocity(x,t)`，世界空间风速，优先使用米每秒。

Cloud 内部继续保存包络、非负密度、消光、散射相位、状态推进和历史。Ocean 无权改写这些内部量。

Ocean 对外保存自己的自由表面状态：高度、水平位移、速度、法线、泡沫和接触查询。海面着色读取 Weather 的太阳与天空接口，再结合水的折射率、微表面粗糙度、波面法线和观察方向计算反射及透射。云影改变入射光强度，不改变水的材料身份和波面几何。

水下介质单独保存吸收、散射和光程。Coast 浓烟也读取同一太阳与天空接口，同时使用自己的密度、温度、速度、消光和地形边界。云、海水与烟只能共享光照和环境查询接口，不能共享密度参数、相位函数、吸收系数或运动方程。

## 第一性关系

对一条从太阳到海面点 `x` 的光路，可先用云体积给出光学厚度：

`tau_cloud(x,t) = integral sigma_t_cloud(s,t) ds`

对应透射率：

`T_sun(x,t) = exp(-tau_cloud(x,t))`

Ocean 接收到的直接太阳项按 `T_sun` 缩放。海面镜面反射方向仍由波面法线、入射方向和观察方向决定。于是，云可以让海面局部变暗，同时不会让水面粗糙度、波高或法线发生无依据变化。

这是一条候选接口关系。多重散射、云下天空光变化、色散和真实单位标定仍需另行验证。

## 单对象、单区域、单参数实验

对象：一块现有 Ocean 海面小区域。

固定项：海面几何、波场、法线、粗糙度、水色、相机、曝光、太阳方向和天空颜色。

唯一参数：云光学厚度乘数 `A`，只通过 Weather 接口形成 `T_sun = exp(-A * tau_reference)`。

恢复条件：`A = 0` 时必须精确回到清空云遮挡的光照基线，海面位置、法线、粗糙度和泡沫状态逐值不变。

观察证据：直接太阳亮度应随透射率下降；高光方向、波峰位置、法线诊断和几何查询应保持；天空反射与直射太阳项应能够分开展示。如果调整 `A` 时水面粗糙度、波形或法线发生变化，就说明 Weather 与 Ocean 的职责发生泄漏。

这个实验只验证大气光照输入与海面表面响应的接口，不验证完整云模拟、水下光学、海岸烟、Lumen 等价性或最终视觉质量。
