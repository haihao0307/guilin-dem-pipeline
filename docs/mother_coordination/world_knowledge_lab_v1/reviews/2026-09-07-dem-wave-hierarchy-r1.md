# DEM 波形层级与自适应重构候选 R1

日期：2026年9月7日。来源：用户关于温州约12.5米规则DEM、横纵波、少量锚点、视距适配和Macroscopic microscope近景细节的构想。当前仅为协调知识设计，不修改温州DEM生产分支、canonical数据、COG、GIS真值或公开工作台。

## 一，先把问题写成矩阵

规则DEM可以写成高度矩阵 H[i,j]。X、Y坐标通常由CRS、原点、像元尺寸和行列号决定：

x_i = x0 + i * dx

y_j = y0 + j * dy

因此规则栅格无需为每个点重复保存X、Y。主要数据量来自Z值、NoData掩膜、必要的地理参考和附加约束。

以一万乘一万样点为例，约一亿个高程值。float32仅Z值约400MB，int16约200MB，和用户观察的数百MB量级一致。实际文件大小还取决于源量化、压缩、掩膜和容器格式。

## 二，用户的横纵两组波可以形式化为可分离基

一个直接表达是：

H(x,y) = sum from r=1 to R of lambda_r X_r(x) Y_r(y) + E(x,y)

X_r是沿X方向的一维波形，Y_r是沿Y方向的一维波形。每一对波在交点贡献一个高度分量，多个分量相加形成最终Z。R较小时，这相当于低秩或张量分解，能够用O(R(Nx+Ny))的主干参数描述大尺度表面。

只使用一条X波和一条Y波无法表达任意复杂地形。即使每一行和每一列都保存独立复杂波形，若其参数量足以恢复所有细节，信息量仍可能接近原始矩阵。真正的压缩来自地形在某个基底中的低秩、稀疏性和可预测残差。

E是残差。要求数学无损时必须保存足以精确恢复原采样值的残差；要求显示误差受控时可以按允许误差丢弃细小残差。极端压缩且绝对无损不能对任意DEM保证，压缩下限受数据熵约束。

## 三，更贴合该构想的工程底座是二维可分离小波

二维可分离小波先对每一行做一维变换，再对每一列做一维变换。这与“横向一组波，纵向一组波，相交恢复表面”的直觉高度一致。

每一级产生四类频带：

LL负责粗表面。

LH负责一类方向细节。

HL负责另一类方向细节。

HH负责对角和更局部的细节。

继续分解LL可以形成从整个区域到12.5米网格的层级。采用可逆整数小波并保留全部系数，可做严格重建；压缩率取决于系数统计和熵编码。采用误差阈值后，可以得到更高压缩率并明确最大高程误差。

全局傅里叶波对局部悬崖、岸线和山脊容易产生长程影响与振铃。具有局部支撑的小波更适合按区域解码和视距加载。方向性很强的山脊、断崖和河谷以后可研究方向基或显式特征残差，不能在第一阶段一次引入全部方法。

## 四，建议采用三层真值结构

### 第一层 Canonical Truth

保存12.5米原始DEM的可逆表达。候选为：地理参考 + NoData/岸水掩膜 + 可逆二维小波系数 + 熵编码 + 哈希。

这一层必须能够逐样点恢复源DEM。它服务归档、分析和真值回放，不因相机而改变。

### 第二层 Runtime Reconstruction

运行时只解码当前视域和当前屏幕足迹能够产生可见贡献的频带。

定义一个像素在地表对应的近似尺寸 f_mpp，单位米每像素。只计算波长大于某个与f_mpp相关阈值的频带。远景每像素覆盖几十到几百米时，12.5米细节无需进入着色和几何；相机靠近后逐层增加细频带。

这一层改变的是评估带宽和解码量，不改变地形身份。相机坐标不能成为DEM取样坐标。相机只决定哪些已有频率值得计算。

### 第三层 Procedural Subgrid Detail

12.5米以下缺乏真实测量时，Macroscopic microscope、多尺度侵蚀和材料函数只能生成明确标注的程序化近景细节。

候选：

H_render(x,y) = H_truth_12.5m(x,y) + G(f_mpp) * delta_micro(x,y)

G由屏幕足迹平滑启停。delta_micro使用稳定世界/材料参考坐标、地貌类型、坡度、曲率、岩性或其他已有依据生成。

程序化细节必须与canonical真值分层。没有更高分辨率实测数据时，不得把它记录成真实子12.5米高程。可以约束其在基准像元内均值为零、在受保护锚点上为零或幅度受限，从而避免近景细节暗改宏观高程。

## 五，少量XYZ锚点的正确角色

几十到一两百个XYZ点不能单独保证恢复一亿个任意高程样点。它们适合承担硬约束和质量门禁：

已知测量基准点。

关键峰顶、鞍部、河口、岸线或工程控制点。

跨块连续性锚点。

拟合低秩主干时的强制约束。

重构QA中的固定检查点。

完整真值仍由波形主干和残差共同承担。

## 六，运行时查询复杂度

若每次查询都叠加一万条横波和一万条纵波，计算成本很高。小波层级具有局部支撑，一个世界点只需读取其所在层级附近的少量系数。对于约一万像素边长，层级数量约14级。远景只使用前几个粗层，近景才进入更多细层。

因此更合理的目标是“每个查询点访问O(log N)层级的少量局部系数”，而非“每个点遍历两万条全局波”。

## 七，严格无损、误差受控和视觉细化分成三种产品

A. 归档无损：逐样点恢复完全一致，最大绝对高程误差必须为零。压缩率由数据本身决定。

B. 运行误差受控：允许设定厘米、分米或项目认可的高程误差阈值，同时单独检查坡度、曲率、河网、岸线和关键控制点。远景还增加屏幕空间误差门槛。

C. 近景视觉细化：12.5米以下的程序化信息，改善视觉与材料关系，永远单独标记synthetic_detail，不能参与DEM真值分析。

这三类文件和验收状态必须分开。

## 八，建议第一项实验证明或推翻路线

选一个能同时包含山地、河谷、平地和海岸的2048×2048原始12.5米DEM子区，物理范围约25.6公里见方。固定源文件、CRS、NoData、像元尺寸和哈希。

实验A：可逆二维小波 + 无损熵编码。验收：逐样点max_abs_error=0，NoData和地理参考逐项一致；报告压缩前后字节数、编码时间、随机点查询时间和峰值内存。

实验B：保留粗频带，逐步阈值细频带。每一档报告max_abs_error、RMSE、坡度误差、关键河谷/岸线检查和屏幕空间误差。寻找远景几乎无可见差异的最低带宽。

实验C：只在固定小区域开启一个MicroDetail强度A。A=0严格返回重构DEM；A>0只增加12.5米以下的程序化细节。检查像元平均高程、固定锚点、主山脊、河槽和岸线不被暗改。

第一轮不同时引入低秩SVD、方向小波、神经网络或完整Microscope视觉。先用可逆小波建立一个可证伪基线。

## 九，若第一轮成立，第二阶段再加入“波主干 + 稀疏残差”

可比较：

H = sum_r lambda_r X_r Y_r + sparse_wavelet_residual

低秩部分负责区域级大结构，小波残差负责局部山脊、河谷和高频变化。只有当它在相同误差门槛下明显优于纯小波，才采用该复杂路线。

## 十，当前结论

用户提出的“横纵波 + 视距适配 + 近景Microscope”方向在数学和运行时架构上可成立。最关键修正有三点：

一，横纵波应落到可分离多尺度基和稀疏残差，交点本身不构成压缩保证。

二，绝对无损依赖残差完整保存；视觉无损和真值无损分开验收。

三，12.5米以下的Microscope属于程序化细化，只有存在更高分辨率真值时才能升级为真实地形数据。
