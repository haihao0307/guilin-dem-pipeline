# DEM 锚点、按需频带与潮汐海洋场 R2

日期：2026年9月7日。来源：用户继续讨论温州规则DEM、山峰河谷岸线锚点、按需重构、海面不作为DEM静态对象保存，以及潮汐、海底、流体与近景细节的统一表达。本文是候选世界架构，不修改温州DEM、Ocean、Weather或任何生产基线。

## 一，核心判断

当前路线可以收敛成一个统一的“场与约束”世界模型：

1. DEM真值负责12.5米采样尺度的地形骨架。
2. 锚点和特征曲线负责保护山峰、鞍部、河谷、左右岸、海岸线和其他强约束。
3. 可逆多尺度基负责压缩和按需恢复地形。
4. 相机只决定当前需要解码哪些尺度，不改变地形身份。
5. 12.5米以下的程序化细节单独生成，永远与canonical DEM分层。
6. 海面不需要作为静态DEM几何保存。海面由时间相关的水位与波场定义，海底继续属于地形真值。
7. 水深、岸线、潮汐、波浪、光学与局部流动都从同一地形和水状态查询中派生。

这套体系的价值在于减少重复数据与无效计算，同时让每个对象拥有清晰的数学职责。

## 二，锚点从点扩展为“点 + 线 + 掩膜”

少量XYZ锚点适合保护关键极值和检查点。对于河岸和海岸，只保存孤立点还不够稳定，建议增加稀疏特征线：

* 山峰、鞍部和控制测量点用点约束。
* 河谷中心线和河流左右岸用曲线约束。
* 海岸线、断崖、堤岸和明显地形折线用曲线约束。
* NoData、水陆分类、不可跨越的保护区域用掩膜约束。

这些约束规模远小于完整栅格，却能保护最容易被平滑基底破坏的强结构。

## 三，地形重构仍采用多尺度真值层

规则DEM记为H_truth(x,y)。候选采用可逆二维小波或其他局部多尺度基：

H_truth = H_coarse + sum_l D_l

H_coarse保存区域大形，D_l为逐层细节。

在归档无损模式下保留全部系数与必要残差，逐采样点恢复误差为零。

在运行模式下，相机给出屏幕足迹f_mpp，单位米每像素。只解码能够产生可见贡献的尺度：

H_runtime(x,y,f_mpp) = H_coarse + sum_{l in visible bands} D_l

相机离得远时，树、石块和子像元微结构都不进入计算。山体轮廓、峰位、河谷和岸线继续由低频真值与特征约束保护。

## 四，海面改成“水状态场”，不在DEM中保存静态海平面

海底属于地形：

z_bed(x,y) = H_truth(x,y)

海面属于动态水状态：

eta(x,y,t) = eta_tide(x,y,t) + eta_wave(x,y,t) + eta_local(x,y,t)

其中：

eta_tide负责潮汐和更慢的大尺度水位变化。

eta_wave负责海浪和风浪。

eta_local只在需要时表达港湾、近岸、障碍和局部流体响应。

某世界点的瞬时水深定义为：

h(x,y,t) = max(0, eta(x,y,t) - z_bed(x,y))

水陆边界由h=0自然产生。这样无需在DEM中预存一大片固定海面，也无需通过删除静态海面网格来改变水位。

海岸线可以同时有两种身份：测绘或历史时刻的canonical岸线作为验证约束；当前时刻的湿润边界由地形与eta相交产生。两者不可混为同一对象。

## 五，潮汐、海底和颜色可以从同一关系产生

潮汐改变eta，直接改变水深h和湿润范围。海底高程影响浅水区域、岸线位置和波传播条件。

视觉上的深浅颜色不应由固定颜色带决定。候选输入包括：

水深h。

太阳和天空入射光。

水面法线与粗糙度。

水体吸收与散射。

海底材质和悬浮物。

浅水区可看到更多底部贡献，深水区由更长光程产生不同透射。水的深浅过渡因此与真实海底和当前水位相连。

## 六，流体只在需要的地方升级

整个30,000平方公里区域不需要做完整高分辨率流体求解。建议三层：

第一层，远海和大尺度使用解析潮汐、谱波或其他低成本波场。

第二层，近岸使用浅水或地形感知的局部近似，处理水深变化、折射、浪高变化和岸线湿润。

第三层，只在港口、岛体、礁石、船体或B24风洞式研究等小区域建立更完整的局部速度场或连续流体求解。

这些层读取同一世界时间、地形、水位和边界接口。高成本局部求解不能反向改写canonical地形。

## 七，Microscope层进入12.5米以下

最终显示可以写成：

H_render = H_runtime + G(f_mpp) * delta_micro

G由屏幕足迹平滑启停。delta_micro使用稳定世界或材料坐标，受到坡度、曲率、地貌类型、岩性、水文和特征保护约束。

A=0或G=0时必须回到runtime DEM。程序化细节尽量满足像元均值近零、关键锚点为零、河槽和岸线受保护等条件，避免微细节积累改变宏观地形。

树木、石块、草地等对象继续拥有独立的出现条件。它们在远景完全不生成，进入可见尺度后按环境和人口、土地利用等实际规则出现。

## 八，系统真正值得研究的创新点

多尺度小波、地形LOD、潮汐、水面和程序化细节各自都有成熟先例。不能仅凭使用这些方法宣称数学基础独一无二。

值得形成项目方法论的部分，是把以下内容统一为一个可查询、可恢复、可证伪的世界协议：

* canonical真值和程序化细节严格分层。
* 点、线和掩膜锚定真实结构。
* 多尺度系数按屏幕足迹解码。
* 地形与水面共享世界坐标和时间。
* 潮汐和波场自然产生瞬时水陆边界。
* 局部流体只在必要区域升级。
* 视觉、碰撞、水位、浮力和环境查询读取同一状态来源。

如果这些关系在温州完整验证成功，它可以成为后续各区域DEM和海岸世界的统一模板。

## 九，下一项最值得做的实验

仍建议先选一个2048×2048、12.5米的真实温州子区，最好同时含山地、河谷、平地、海岸与一部分海底。

阶段一只验证地形：可逆多尺度压缩、逐点零误差恢复、锚点和特征线保持、按频带关闭后的屏幕误差。

阶段二加入一条时间变化的潮位eta_tide，不加风浪。检查水深、湿润范围、canonical岸线对照和水位查询。

阶段三加入一个解析波场，检查可见海面、法线、水位、碰撞和浅深水光学是否来自同一状态。

阶段四只选几十到几百米的近岸小区，加入一个局部流体或地形感知波实验。

阶段五才打开Microscope微细节，并证明A=0完全返回真值重构。
