### 第一轮与第二轮暴露的问题

自动草稿能够召回 Houdini 场、Substance PBR、Lumen、体积光学和 Weather/Ocean 等主题，也会产生错误的跨域连接。

已退回的主要错误包括：

1. 将云烟体积密度直接转成 PBR 表面贴图。
2. 把风速、波幅和光照无依据地统一成零到一。
3. 让云密度直接影响海面法线。
4. 混用水下介质与湿润固体。
5. 把运行时光照反馈当成材料或流体真值。

这些错误说明自动草稿适合拓展问题空间，不能自行进入生产知识。

### 人工复核后的新结论

Weather 与 Ocean 之间优先建立只读光照接口。Weather 与 Cloud 提供太阳方向、太阳辐亮度、世界点到太阳的透射率、方向天空辐亮度和风速查询。Ocean 保留自己的海面高度、水平位移、速度、法线、泡沫与水位查询。

云影通过太阳光路的光学厚度改变海面接收到的直射光：

`T_sun(x,t) = exp(-tau_cloud(x,t))`

这一关系只改变入射光，不改变水面波形、法线、粗糙度或材料身份。水下介质与 Coast 烟雾分别保存自己的吸收、散射、密度和状态。

### 下一项最小验证

只选择一块 Ocean 海面小区域。固定波场、几何、法线、粗糙度、相机、曝光、太阳方向和天空颜色，只改变云光学厚度乘数 A。

A 等于零时必须回到清空云遮挡的光照基线，海面几何与材料状态逐值不变。若高光方向、波峰位置或法线随 A 改变，说明 Weather 与 Ocean 的职责发生泄漏。
