# 小妈长期蒸馏日志

## 2026年9月7日，GitHub 主存储决定

### 当前问题

长期研究需要一个可持续、可追溯、体积小且不会暗改生产线的载体。

### 实际检查

Make 能够连接、创建场景和设置周期。两条人工智能执行路线均未成功完成一次研究运行。失败包括连接 ID 缺失、模块参数校验失败、套餐限制和临时请求频率限制。故障场景已经关闭。

### 采用决定

以 GitHub 协调分支作为长期知识主存储。Issue 用于收件和讨论，Markdown 与 JSON 用于稳定知识，提交历史用于差异和恢复。生产代码、模型、图片、视频和大型二进制不进入本目录。

### 第一批长期主题

1. Houdini 的场、体积、依赖和显式状态。
2. Adobe Substance 3D Designer PBR 与 OpenPBR。
3. Unreal Engine Lumen 和实时光照反馈。
4. Yohei Nishitsuji 的多尺度生成、射线推进和审美。
5. Multiscale MIP Fluid。
6. Boids 群体行为。
7. 眼球有界微动。
8. Weather、Cloud、Ocean 和 Coast 的对象级适配。
9. 后续 B24 风场观察。

### 当前综合原则

共同层保存坐标、时间、环境输入、稳定身份和数学函数。对象层保存自己的结构、物质属性、状态历史和执行约束。形态、材质、运动、光学与观察分别生成证据，再在同一个世界时间和坐标体系中结合。

### 下一次研究入口

Weather 先选择一团现有云，固定主形、相机、太阳和风，逐层检查包络、非负密度、多尺度细节、体积光学和真实输运。

Ocean 与 Coast 先选择一个烟源，固定海岛、海面、相机、日照和风，检查烟腹厚度、峰值保持、长尾连续、边缘透光、障碍绕行和实际资源成本。

### 状态

本轮只建立知识主存储和主题总账。没有修改 Weather、Cloud、Ocean、Coast、Landscape、B24 或其他生产线。没有启动新的外部人工智能自动研究。
