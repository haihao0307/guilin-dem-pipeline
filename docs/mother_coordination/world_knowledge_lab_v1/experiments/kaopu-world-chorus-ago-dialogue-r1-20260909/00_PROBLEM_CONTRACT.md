## 0. 术语锁定

本实验中的“造波”统一指世界生成与重建中的造波体系。它是一族带类型的生成算子，可以包含基础波、噪波、相位、频率、振幅、方向、旋转、域变换、调制、耦合、边界条件、随机种子、时间演化和不可推导残差。

噪波可以成为造波体系中的一种成分。造波不缩减为单一噪声函数，也不把所有离散关系强行变成波。

## 1. 问题

把以下思想闭合成一条可以实施、可以反驳、可以验证的完整逻辑链：

1. 靠谱是人、机器和现实世界之间的中性共同语义与度量体系。
2. 世界总谱把全球、地区、场景、对象、部件、材料、过程、证据和时间组织为同一体系。
3. 温州是首个完整地区谱试验场。
4. 连续世界通过多尺度造波、场和必要残差表达。
5. 离散身份、关系、事件和证据通过图表达。
6. 多种指挥依据任务读取同一总谱，不能改写证据身份。
7. 小妈负责世界大合唱的总指挥、Judgment、资源分配和冻结。
8. AGO 负责独立探索、对抗、验证与方法抽象。
9. 体系必须与物理、化学、生物、历史、时间和人的不同观察相容。

## 2. 禁止偷换

1. 不把“世界可以用造波近似或生成”偷换成“所有存在都只是一种噪声”。
2. 不把时间滑块偷换成物理过程必然可逆。
3. 不把数字资产来源真实偷换成其中历史 Claim 真实。
4. 不把文件数量偷换成独立观察数量。
5. 不把 Current Best View 偷换成终极真相。
6. 不用零值、空字符串、原点、单位矩阵或对称补全代替 Unknown。
7. 不把现代重建、仿建和创作混入历史原始证据。
8. 不让某个指挥或 Mother 私自改变共同单位、时间、参考系和对象身份。
9. 不调用 Anthropic、Claude Code 或 Make。
10. 不修改任何生产 Mother 和既有冻结稿。

## 3. 本轮角色

AGO A：语义与计量审查。

AGO B：造波、物理与化学审查。

AGO C：时间、身份、历史证据与独立观察审查。

AGO D：世界大合唱、指挥、并发和跨 Mother 协作审查。

AGO E：对抗型红队，专门寻找会让体系失控或污染的漏洞。

AGO F：最小实现与温州落地审查。

六个角色先分别工作，再交叉质询。小妈只在最后做 Judgment。
