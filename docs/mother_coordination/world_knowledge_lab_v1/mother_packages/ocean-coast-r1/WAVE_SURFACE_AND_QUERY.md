# Ocean 造波、自由表面与世界查询 R1

## 1. “造波”先从最小波分量开始

一个解析波分量可以写成：

`eta_i(q,t) = A_i * cos(k_i · q - omega_i * t + phi_i)`

总波面可以由少量不同方向、波长和相位的分量叠加：

`eta(q,t) = sum_i eta_i(q,t)`

这里的目标是组织尺度、方向和时间关系，不是把随机噪声直接当海浪。

## 2. 大尺度与小尺度分工

低频波承担远处可辨认的大波群和海面整体运动。

中频波承担可见波脊、方向差异和局部起伏。

高频只在观察带宽需要时加入细小波纹和局部粗糙变化。

新增高频时，不允许重新归一化后暗改既有主波。

## 3. 水平位移必须进入同一表面

自由表面建议保留参数坐标 `q`：

`X(q,t) = (q.x + dx(q,t), eta(q,t), q.z + dz(q,t))`

法线、速度和切线从同一个 `X(q,t)` 导数得到。

这可以形成更可信的波峰形状，但会带来世界查询问题。

## 4. 世界水位查询不能偷懒

如果 `dx=dz=0`，世界 x,z 可以直接对应 q。

如果存在水平位移，查询世界位置 `(x,z)` 的水位需要反求：

找到 `q*` 使：

`q*.x + dx(q*,t) = x`

`q*.z + dz(q*,t) = z`

然后：

`waterHeightWorld(x,z,t) = eta(q*,t)`

可以使用迭代、局部近似或缓存加速，但必须有误差测试。

近期合成检查已经证明，忽略水平位移直接用世界 x,z 查询会产生明显误差，因此 render/query 同源是硬门。

## 5. 潮汐与波分开

潮汐属于更慢的大尺度水位状态：

`eta_tide(x,t)`

风浪和涌浪属于更快的自由表面变化：

`eta_wave(q,t)`

局部近岸流体可以再提供：

`eta_local(x,t)`

组合时：

`eta_total = eta_tide + eta_wave + eta_local`

这几层的时间尺度和物理职责必须分开。

## 6. 海底如何影响近岸

最基础的当前水深：

`h = eta_total - z_bed`

在浅水区域，波传播、方向和破碎条件会受水深影响。简单浅水近似中，传播速度与 `sqrt(g*h)` 有关。

这只是近岸研究入口。Ocean Mother 后续必须自己继续查证波浪变浅、折射、绕射、破碎和底摩擦等模型，不能把一个公式当完整海岸动力学。

## 7. 多尺度 Microscope 的 Ocean 用法

Microscope 只用于观察尺度下的细节组织。

远处：主波群和大轮廓。

中景：波脊和主要细碎结构。

近景：细波纹、泡沫边缘和微表面。

任何子尺度细节都不能改变 canonical water query，除非它被明确提升为真实自由表面状态。

## 8. Observation Bandwidth

当前需要的海面频带由屏幕 footprint、关注点、交互和物理需求共同决定。

视觉远景可以很低频。

局部浮力或碰撞即使不在视觉焦点，也可以单独请求更高物理精度。

因此 visual bandwidth 与 physics bandwidth 允许不同。
