# Ocean / Coast 第一批测试与门禁 R1

## Test 01 Render / Query 同源

对象：一块固定海面。

固定：时间、相机、波参数、太阳、材质。

检查：可见网格高度与 `waterHeightWorld(x,z,t)` 在采样点一致。

存在水平位移时，禁止直接把世界 x,z 当参数 q，必须记录反求或近似误差。

## Test 02 水平位移恢复

唯一参数：水平位移强度 `A_horizontal`。

`A_horizontal=0` 时世界查询应退化到直接高度查询。

增加水平位移后，波峰形状和法线可以变化，但查询必须继续与可见表面一致。

## Test 03 云光学厚度

固定海面几何、法线、粗糙度、泡沫、水体参数、相机和太阳方向。

唯一变量：Weather 提供的云光学厚度乘数 `A_cloud`。

要求：只改变入射直射光。波高、法线、泡沫、水位查询逐值保持。

## Test 04 潮汐

先不加浪，只改变 `eta_tide(t)`。

检查：

水深随潮位更新。

wet shoreline 自然移动。

canonical shoreline 不被改写。

DEM/海底真值保持。

## Test 05 水深光学

固定水面和底部，选择多个已知水深点。

只改变观察光程，检查浅水底部可见度与深水衰减是否连续。

射线步长变化时结果应在记录误差内收敛。

## Test 06 Coast Smoke 细节

对象：一个烟源，一个有限三维烟域。

固定：基础风、源、岛体边界、相机、太阳和粗状态。

唯一变量：`A_smoke`。

`A_smoke=0` 恢复粗浓度。

要求：烟腹、质心和长尾关系保持；细节随烟走；不能相机游泳。

## Test 07 Coast 开放边界

让烟或示踪状态离开域边缘。

要求：离开后不从另一侧重生；岛体附近不穿透。

## Test 08 观察带宽

固定同一 WaterBody DNA，从高空到近岸改变观察 footprint。

要求：主波和水体身份连续；只逐步展开需要的高频；没有模型切换、海面跳变或随机重置。

## 每项必须报告

固定量和唯一变量。

恢复路径。

数值误差。

目标设备 CPU/GPU 环境。

帧时间、显存、字段数和缓存。

固定相机截图或浏览器证据。

当前 evidenceLevel。

用户视觉接受单独记录。
