# Weather 多尺度场与“造波”知识 R1

## 1. 先区分两种“波”

Weather Mother 会同时遇到两类可以被口语称作“波”的东西。

第一类是生成结构的数学基函数或多尺度场。它负责形态组织，例如团块、层次、卷曲、空区和尺度连续。

第二类是真正具有传播、输运或动力学意义的场变化。它必须受速度、边界、时间步长和状态方程约束。

两者可以共享坐标和频率思想，但不能互相冒充。

## 2. 多尺度结构的核心

一个稳定细节场可以写成：

`D_N(p) = sum_j a_j C(s_j p)`

其中 `s_j` 控制尺度，`a_j` 控制幅度，`C` 是连续基础函数。

这两天从 Macroscopic Microscope 学到的关键点：

尺度之间必须相关，避免每层都是独立白噪声。

新增加高频层时，已有低频前缀必须保持，不能重新归一化后暗改大形。

高频层的函数值幅度可以很小，但链式法则会让其梯度仍然很大，因此会显著改变法线、亮边和视觉粗糙感。

用于云时，大尺度先控制包络和空区，中尺度再控制团块和卷边，微尺度只在观察带宽需要时展开。

## 3. 对数尺度与尺度连续

Macroscopic Microscope 的对数径向映射说明，可以使用对数空间组织尺度，使缩放后的结构在不同观看尺度保持相似关系。

这个思想可用于云的细节坐标和频带组织，但它只提供尺度组织方法，不自动提供天气物理。

对 Weather Mother 的用法：

包络使用稳定世界或云局部坐标。

细节读取声明过的多尺度坐标。

镜头靠近时增加可观察频带，不能通过相机移动改变云对象内部身份。

## 4. 空间扭曲与卷曲

连续坐标扭曲可以把规则场变成更自然的弯曲结构：

`q = p + W(p)`

但必须注意导数。若后续根据 `D(q)` 求梯度、法线代理或光学变化，必须考虑扭曲的雅可比或至少用数值检查确认结果。

对于速度场，散度接近零的 curl 构造可以生成局部旋转结构，但“散度小”不等于满足真实边界，也不等于不会穿墙或穿山。

## 5. Multiscale MIP Fluid 的可吸收知识

当前吸收的是方法，不复制其油亮显示结果。

可迁移部分：

跨帧反馈状态。

速度场平流。

旋度和涡量增强。

压强投影思想。

多尺度速度/细节组织。

显示与模拟状态分离。

必须保留的限制：

原始示例含周期式 `fract` 包裹，这不适合要求烟云离开区域后不重生的世界边界，除非明确选择周期世界。

自动转换代码中存在类型和未初始化变量风险，不能直接视为可靠生产实现。

MIP 示例的最终油亮高度感显示只是诊断/渲染映射，不代表烟、云和海水应采用同一材质。

## 6. 云细节的候选公式

`rho_render(x,t) = max(0, B(x,t) * (rho_sim(x,t) + A * M(x,t) * D(q(x,t))))`

这里：

`B` 保护大形和空区。

`rho_sim` 保存有历史的粗状态。

`D` 只提供有界多尺度细节。

`M` 限制细节出现位置。

`q` 必须来自稳定坐标，或来自与速度一致的回溯/输运坐标。

`A=0` 是核心恢复门。

## 7. 观察带宽如何决定频带

定义当前一个像素在云体上的有效空间尺度 `footprint`。

远景时只保留包络和低频密度。

中景时打开团块和主要卷边。

近景时再增加细丝和小尺度密度变化。

高频是否工作由观察需求决定，但粗状态和云团身份继续存在。
