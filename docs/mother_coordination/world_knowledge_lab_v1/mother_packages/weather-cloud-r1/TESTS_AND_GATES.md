# Weather / Cloud 第一批测试与门禁 R1

## Test 01 细节强度

对象：一团现有云。

固定：包络、粗密度、速度、太阳、相机、曝光、种子、时间。

唯一变量：`A_detail`。

要求：

`A_detail=0` 严格恢复粗状态。

主轮廓和明确空区不改变。

细节只出现在允许区域。

相机移动不导致细节游泳。

关闭颜色后仍能看出厚区、薄区和空区。

## Test 02 光照方向

进入条件：Test 01 通过。

固定全部密度和状态，只改变太阳方向。

要求：亮边、内部暗部和阴影变化；密度、轮廓和速度逐值保持。

## Test 03 均匀风输运

进入条件：Test 02 通过。

固定相机、太阳和包络，启用简单均匀风。

追踪一个密度团的质心、峰值、总量和边缘。

如果画面纹理在动但质心不移动，只能标记为形态动画。

## Test 04 开放边界

建立小型有限体积区域，让云团或烟状测试密度离开一侧。

要求：离开后不从另一侧周期重生。

## Test 05 光学步长

固定同一个密度场和光程，用不同射线步长计算透射。

要求：结果在记录误差内收敛，不能随着采样数量增加而无原因变浓。

## Test 06 观察带宽

固定云对象，改变镜头距离和屏幕 footprint。

要求：低频身份持续；高频逐步进入；没有对象切换、随机种子重置或大形跳变。

## 每项必须报告

输入和固定量。

唯一变量。

A=0 或恢复条件。

CPU/GPU 环境。

帧时间、显存和字段数量。

数值证据。

固定相机视觉对照。

当前 evidenceLevel。

用户视觉接受单独记录。

## 禁止升级条件

任何一项仅有单帧截图，没有恢复测试，不得升级。

任何一项通过软件构建但没有浏览器运行，不得标记产品验证。

任何一项自动测试通过但用户没有视觉接受，不得标记 visualAcceptance。

任何一项没有真实目标设备测量，不得声称性能优于其他路线。
