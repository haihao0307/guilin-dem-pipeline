# Weather Transport 与 Volume Optics R1

## 1. 状态推进

最小输运形式：

`rho_next = Advect(rho_now, u, dt) + source - sink`

速度 `u`、时间步长 `dt`、边界和源项都必须显式。

当 Weather Mother 以后加入温度、湿度、浮力或相变时，逐项新增状态，不要把所有现象塞进一个“cloudNoise”函数。

## 2. 运输正确性的最低检查

每次运输实验至少记录：

质心是否按预期移动。

总量是否在允许范围内变化。

峰值是否被过度抹平。

边缘是否不断变糊。

是否出现负密度或过冲。

离开计算域的状态是否正确流出。

相同初始状态和时间序列是否可以重放。

当前小试验已经说明：总量近似保持并不代表峰值和细节保持。线性平流可能很稳，但会削弱峰值。更锐利的修正需要额外误差和成本验证。

## 3. 边界优先于漂亮涡流

周期边界适合数学测试，不适合所有世界场景。

真实天气区域需要区分：

开放流入。

开放流出。

地形/建筑固体边界。

局部周期实验。

散度投影可以减少不可压缩速度的散度，但不能自动处理山体、建筑和复杂边界。

## 4. 体积光学

CloudOptics 不使用表面 PBR 代替。

最小物理量：

消光 `sigma_t = sigma_a + sigma_s`。

吸收 `sigma_a`。

散射 `sigma_s`。

相位函数 `phase(cosTheta)`。

太阳与天空入射光。

视线积分。

透射：

`T(s) = exp(-integral sigma_t ds)`

若密度是无量纲代理，消光尺度 `k_t` 必须承担每米尺度并通过真实云体尺寸或视觉校准确定。

## 5. 厚区、薄区和负空间

云的可信度来自三种关系同时成立：

厚区能够明显遮挡背景和直射光。

薄边仍有透射和细丝。

明确空区真的为空，不被高频噪声重新填满。

因此光学检查必须与包络检查同步。

## 6. 采样和成本

射线步长是物理长度的一部分。不能因为样本数增加就让同一均匀介质自动变得更浓。

空区允许跳过。

透射已经很低时可以提前终止，但需要记录阈值和视觉误差。

体积状态更新、光学缓存更新和最终画面刷新可以不同频率运行。

每轴分辨率翻倍意味着体素数约增加八倍，必须同时报告字段数量、双缓冲、临时缓冲和显存。

## 7. 与 Ocean 的接口

Cloud 向 Ocean 提供只读 `sunTransmittance(x,t)` 或等价的云光学厚度查询。

Ocean 可以因此得到动态云影，但 Weather 不允许直接改海面高度、法线、粗糙度或泡沫。

这个接口是环境耦合的第一条标准样本。

## 8. 与 Landscape 的接口

Landscape 可以读取日照、天空、风、降雨和云影。

Weather 可以读取地形占据、海拔或障碍边界，但不能因此修改 DEM 真值和 Landscape 主形。

未来山谷风、迎风坡和降雨等更深关系需要 Weather Mother 自己进一步查证和建模。

## 9. 视觉纪律

先在中性灰度或低色彩诊断模式检查密度与透射。

随后才加入日光、晚霞、阴天和色调映射。

泛光、曝光和色彩只能解释结构，不能掩盖结构错误。

细节需要休息区，不能让整屏高频。
