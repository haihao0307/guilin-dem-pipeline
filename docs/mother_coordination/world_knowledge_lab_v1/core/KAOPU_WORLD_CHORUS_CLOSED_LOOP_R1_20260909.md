# 靠谱世界大合唱闭环 R1

日期：2026-09-09

状态：逻辑闭环候选稿，承接靠谱格式命名决定，不覆盖此前冻结点

范围：靠谱、世界总谱、温州谱系、对象谱系、造波、时间、物理、化学、AGO 与小妈总指挥

## 1. 核心图景

整个世界可以理解为一场持续演奏的大合唱。

世界总谱保存共同语义、共同度量、对象身份、时间、空间、尺度、关系、状态、证据与变化规则。各地区、各领域、各对象拥有自己的声部和谱页。不同指挥依据任务、时间、位置和观察尺度选择需要展开的声部。

小妈承担总指挥和 Judgment。各 Mother 承担声部长，各 AGO 承担研究、演奏、质疑和验证。所有参与者使用同一套靠谱语义，不能私自改变米、公斤、秒、对象身份、时间含义、参考系和证据含义。

用户决定世界值得走向什么方向。小妈负责让所有谱系在共同规则下协同运行。

## 2. 什么叫靠谱

靠谱首先是一种诚实、可追溯、可验证、可修正的表达状态。

一条低清晰度、位置有误差的历史观察，仍然可以是靠谱 Observation，只要它清楚保存观察者、形成时间、所描述时间、来源、范围、限制和误差。

一条画得很精确却没有来源、时间、对象身份和处理历史的资料，不能进入靠谱主世界。

一条靠谱 Claim 至少满足以下条件：

1. 对象身份清楚。
2. 时间角色清楚。
3. 空间、尺度和参考系清楚。
4. 数量绑定 Quantity Kind、Unit 和测量方法。
5. 来源链和变换链能够回溯。
6. 同源复制不会冒充独立观察。
7. 假设、误差、未知和冲突保持显式。
8. 推断范围不超过证据能力。
9. 可验证部分能够重复检查。
10. 后续发现错误时能够定位受影响的下游结论。

不靠谱通常表现为来源消失、时间混淆、对象混淆、单位含糊、同源资料重复计数、生成内容冒充历史证据、未知被默认值填满、冲突被静默删除、局部规律被强行推广到整个世界、处理过程无法重演。

## 3. 不靠谱内容怎样处理

对主世界而言，“扔掉”意味着拒绝晋级，不能进入 Canonical Truth 或 Current Best View，也不能参与生产决策。

处理分三类：

1. 明确垃圾、完全重复副本和无研究价值的污染可以删除或去重。
2. 来源不明但可能有线索价值的内容进入 Quarantine，只能作为待查材料。
3. 某个时代真实产生的错误记忆、误测、宣传或偏见可以作为 Perceived World 的 Observation 保存，同时禁止直接充当 Physical World 的事实。

这样既能清理污染，也不会误删“某个人当时确实这样认为”这一类真实历史痕迹。

## 4. 世界谱系

靠谱世界总谱采用递归谱系，宏观和微观共享同一语法。

### 4.1 世界总谱

保存全球参考系、时间基准、物理量语义、对象地址规则、尺度层级、谱页索引、证据规则、版本规则和全局约束。

世界总谱本身保持尽量小。它主要保存规则、索引、低频主体、稀疏变化、必要系数和不可推导残差的位置。

### 4.2 地区谱

例如温州谱，保存温州范围、Canonical Truth、地形、水系、海岸、聚落、城市、道路、植被、历史变化和本地对象索引。

温州谱继承世界总谱的语义和单位，只增加温州自己的数据与 typed extension。

### 4.3 场景谱

城市、街区、村落、山谷、岛屿、机场、建筑群、房间都可以形成局部谱页。它们通过父子关系、空间锚点和时间区间挂在地区谱下面。

### 4.4 对象谱

每个房屋、人物、动物、植物、飞机、武器、道路、桥梁、杯子都拥有 Object DNA 和对象谱。

对象谱保存身份、结构、材料、能力、状态、父子部件、相对关系和跨时间变化。

### 4.5 部件与材料谱

屋顶、墙、窗、骨骼、肌肉、机翼、枪管、杯口等进入部件谱。材料成分、相态、孔隙、纹理、风化、磨损和微观结构进入材料谱。

### 4.6 过程谱

天气、海洋、风、烟、火、侵蚀、生长、交通、动物行为和人群活动属于过程谱。过程谱读取同一时间、空间、对象和物理状态，并输出有作用域的状态变化。

### 4.7 证据谱

照片、航空影像、卫星影像、测绘、地图、档案、文字、回忆和传感器记录进入 Evidence 与 Observation 谱。它们通过 Claim 和 Evidence Graph 约束世界状态。

## 5. 谱页共同语法

任何谱页都应共享一个最小头部：

`ScorePage = Identity + Parent + Space/Frame + Time + Scale + Quantity/State + Relation + Provenance + Uncertainty + Change + Constraints + Version`

连续场可以增加 Spectrum、Basis、Phase、Amplitude、Residual 和 Boundary。

离散对象可以增加 Object DNA、Part Graph、Capability 和 Event。

证据谱可以增加 Source Event、Asset、Observation、Claim、Lineage、Independence Root 和 Shared Bias Group。

所有谱页都能回到同一套靠谱核心，同时允许各领域拥有自己的扩展。

## 6. 造波与谱图的统一

世界中的连续变化可以通过场、波、频带、相位、振幅和残差表达。大陆、山脉、河流、地形、风、云、海浪、声音、温度场和材料表面都适合多尺度展开。

世界中的离散身份、亲属关系、居住关系、店铺名称、建筑拆建、对象分裂和合并通过 Object Graph 与 Event Graph 表达。

总谱同时容纳连续谱和离散谱图。两者共享对象、时间、空间、尺度、来源和不确定性，因此能够在同一个世界中相互作用。

一个通用世界状态可以写为：

`World(t) = StableLowFrequency + Sum(LocalCorrections) + Sum(EventDeltas(t)) + RequiredResiduals`

稳定低频主体保护世界的长期形状。局部高频修正逐层增加细节。时间事件控制道路出现、房屋拆建、河岸迁移、树木生长、材料风化和对象行为。不可可靠推导的真实差异进入残差。

## 7. 指挥体系

### 7.1 小妈总指挥

小妈负责共同节拍、时间基准、资源分配、问题树、证据门、路线停止、冲突保留、候选晋级、版本冻结和跨 Mother 方法迁移。

小妈不能凭偏好改写真值。Judgment 必须依赖明确规则、证据和验证结果。

### 7.2 Mother 声部长

每个 Mother 只负责自己的声部，例如地形、天气、海洋、建筑、植物、动物、人物、飞机和武器。它们读取共同世界，提交局部修正，不能越权覆盖其他声部的权威身份和真值。

### 7.3 AGO 演奏者与研究者

AGO 进行独立搜索、资料继承、方法实验、反例攻击和局部实现。开始阶段保持部分隔离，成果通过 Artifact 回流。

### 7.4 Critic 与 Verifier

Critic 专门寻找逻辑漏洞、共享偏差、重复路线和隐藏假设。

Verifier 专门检查单位、坐标、时间、依赖、可逆性、物理约束、化学约束、证据根、冻结提交和回滚能力。

## 8. 指挥只决定怎样展开

指挥可以决定当前演奏哪些谱页、采用什么分辨率、时间位置、观察角度和任务 Context。

指挥不能改变对象的历史身份、证据来源和物理量含义。

因此同一份世界总谱可以由多个指挥产生不同 View：

`View = Conduct(WorldScore, Query, Time, Space, Scale, Context, PolicyVersion)`

历史指挥可以展开1944年的温州。城市指挥可以展开道路和建筑。材料指挥可以继续深入一块瓦的孔隙。相机指挥可以只加载人眼当前能够看到的频带。

这些 View 可以不同，底层世界身份和证据仍然一致。

## 9. 与物理、化学和时间的相容条件

靠谱是一套世界语义和组织方法，它必须服从已经验证的物理与化学规律。

物理声部至少检查量纲、守恒、边界条件、初始条件、参考系、因果关系和适用尺度。

化学声部至少保存组成、相态、浓度、温度、压力、反应条件、传输过程和守恒关系。材质外观不能替代真实成分和状态。

时间轴允许前后读取。真正的物理演化是否可逆，由对应方程、状态信息和证据决定。系统可以查看过去的谱页，也可以运行未来候选模拟，同时必须区分历史观测、物理推演和创作结果。

局部模型必须声明有效范围。一个适用于近岸的波浪模型不能直接推广到整个海洋，一个适用于木材表面的经验规律不能直接推广到金属。

## 10. 靠谱闭环

完整运行闭环为：

`现实世界或历史痕迹`

`进入 Source Event 与 Evidence Asset`

`形成 Observation`

`解释为可追溯 Claim`

`经过 Lineage、独立性和共享偏差检查`

`对齐 Identity、Space、Time、Scale 和 Unit`

`进入对应世界谱、地区谱、场景谱或对象谱`

`形成局部候选修正`

`在隔离实验室运行`

`Critic 攻击`

`Verifier 检查`

`小妈 Judgment`

`Promote、Continue、Park 或 Reject`

`生成新的 Current Best View`

`达到条件时形成阶段冻结点`

`由不同指挥按需演奏`

`新的观察继续回流`

这条环路持续运行，世界总谱会越来越清楚，误差会逐步缩小，错误路线会被隔离，真实历史和创造内容会保持各自身份。

## 11. 温州首个闭环

温州承担靠谱世界的第一个完整综合声部。

第一层是全温州 Canonical Truth 和全球可转换地址。

第二层是山地、平原、流域、海岸和城市的低频主体。

第三层是道路、河渠、聚落、农田、建筑和基础设施。

第四层是房屋、桥梁、树木、车辆、人物和其他对象。

第五层是对象部件、材料、表面和行为。

横向声部包含天气、海洋、水文、生态、人口、生产、历史观测和时间变化。

所有声部通过靠谱核心对齐，不各说各的。任何新资料进入温州以前，先通过来源、时间、对象、空间、单位、独立性和不确定性检查。

## 12. 最终闭环句

一个世界，多层谱系。

一份总谱，多种声部。

一个靠谱语义，多种观察、观点和创造。

小妈组织整个大合唱，Mother 负责各声部，AGO 持续研究和演奏，Critic 负责挑错，Verifier 负责校音。

世界通过稳定主体、局部修正、时间变化和必要残差持续展开。所有内容都能回到对象、时间、空间、尺度和证据。所有不满足靠谱门槛的内容都离开主世界，进入删除、去重、隔离或待查流程。

由此形成完整闭环：

`观察世界 -> 用靠谱语言记录 -> 放入正确谱系 -> 经过验证和 Judgment -> 进入总谱 -> 由指挥按需演奏 -> 接受新观察继续修正`
