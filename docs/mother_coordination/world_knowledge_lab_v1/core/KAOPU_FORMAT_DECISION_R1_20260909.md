# 靠谱格式命名与高速研究节奏决定 R1

日期：2026-09-09

状态：用户明确决定，立即生效

范围：世界总谱、TLO、World Score、温州首个完整实验场、OpenAI 内部 AGO 研究组织

## 1. 正式工作名称

这套介于人、机器和现实世界之间的中性共同语义，正式工作名称确定为：

# 靠谱

机器与文件标识暂用：

`KAOPU`

“靠谱”首先指共同语义和度量体系。它不等同于某一种文件后缀、数据库、二进制布局或传输容器。

TLO、World Score、Object DNA、Observation、Claim、Evidence Graph、Current Best View 等名称继续作为靠谱体系内部的架构概念。后续编码可以变化，靠谱语义必须保持稳定并具备版本转换。

## 2. 核心定位

靠谱是一套中性的世界描述与度量语义。它只说明：

1. 对象是谁。
2. 位于哪里。
3. 处于什么时间。
4. 使用什么尺度与参考系。
5. 测量或描述了什么状态、数量和关系。
6. 由哪些 Observation、Claim 和 Evidence 支持或反对。
7. 来源链、处理链和独立观测根是什么。
8. 目前存在什么误差、未知、冲突和共享系统偏差。

靠谱不负责审美、文化优劣、政治价值或个人偏好判断。现代新建房屋、历史建筑、重建、模拟和创作都可以进入同一体系，只需清楚保存各自的对象身份、产生时间、所表示时间和证据性质。

## 3. 节奏纠正

研究单位必须进入小时级和当天闭环，不能把七天当作等待周期。

长期节奏确定为：

1. 持续学习：AGO 在有任务和可用运行窗口时连续吸收资料、拆分问题、独立探索、批评和验证。
2. 日内多轮：同一天允许运行多次小循环，每轮只处理少量可验证问题，完成后立即回流 Judgment。
3. 每日会议：每天至少形成一次知识合并、冲突检查、问题树更新和资源重分配。
4. 每周大会：每周进行一次较大的结构复盘、跨 Mother 方法迁移、失败路线清理和阶段升级。周会不构成日常研究的等待门槛。
5. 阶段冻结：任何一天只要达到明确验证条件，就可以形成新的阶段性冻结点，无需等到周末。

长期原则压缩为：

`小时级探索 + 当天判断 + 每日合并 + 每周大升级 + 随时可冻结`

## 4. 温州作为首个完整实验场

靠谱格式首先从温州开始建立真实闭环。

温州已经具备全域 Canonical Truth、世界谱页、多尺度瓦片、共享边、海岸、水系、城市和后续历史资料接入条件。它足够复杂，可以暴露真正的空间、时间、尺度、证据和对象身份问题。

温州承担首个完整试验场，靠谱核心语义保持全球通用。温州专有坐标转换、资料目录和地方对象类型进入 adapter 或 typed extension，不能污染共同内核。

## 5. 今天必须确定的靠谱最小内核

第一版最小语义确定为：

`KAOPU Core = Identity + Space/Frame + Time + Scale + Quantity/State + Relation + Observation + Claim + Provenance + Uncertainty + Change + View`

必须同时满足：

1. 单位尽量继承 SI 和既有国际标准。
2. Observation 与 Claim 分开。
3. 原始 Evidence Asset 与被描述的 World Object 分开。
4. 同源复制不能增加独立观测数量。
5. Unknown、Not Observed、Observed Absent、Not Applicable 分开。
6. 历史对象、同址新建对象、重建对象和创作对象保持各自身份。
7. Current Best View 是可重算视图，不能覆盖原始证据和冲突 Claim。
8. 冻结点永久可寻址，后续通过新版本追加修正。
9. Scale 是共同语义，Spectrum 是适用于连续场的扩展。
10. 编码可演进，语义必须稳定。

## 6. 当天交付顺序

靠谱体系不等待数周后再形成。当天工作应按以下顺序快速闭环：

1. 固定名称与最小语义核。
2. 建立 `KAOPU` 第一版机器可读 schema。
3. 将现有 World Score / TLO R1 与 OpenAI Round 01 映射到靠谱字段。
4. 选择温州一个最小真实区域或对象作为首个 fixture。
5. 写入 Observation、Claim、Evidence Lineage、时间、空间、尺度和 View。
6. 运行 Verifier，暴露字段缺口和冲突。
7. 当天形成候选修正或新的冻结点。

## 7. AGO 组织原则

当前先使用 OpenAI 自有体系内的少量 AGO。每轮采用独立搜索、部分隔离、Critic、Verifier 和小妈 Judgment。

数量服务于搜索，不替代判断。任何多个 AGO 在同一点重复循环时，小妈立即停止重复、拆分方向或挂起问题。

外部 AI、Anthropic 和 Claude Code 暂不接入。内部体系经过真实温州样例、污染攻击、回滚和多轮验证以后，再进入独立外部对练实验室。

## 9. 核心句

靠谱是一套让人、机器和现实世界能够在同一时间、空间、尺度、物理量、对象身份和证据语义中交流的中性共同语言。

它持续吸收新的独立观测，不断缩小误差，同时允许未知、冲突、记忆、推断、重建和创造保留各自真实身份。
