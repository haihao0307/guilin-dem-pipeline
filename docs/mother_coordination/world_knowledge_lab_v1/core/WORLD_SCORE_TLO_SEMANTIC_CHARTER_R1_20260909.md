# WORLD SCORE / TLO SEMANTIC CHARTER R1

日期：2026-09-09

状态：核心语义讨论第一轮收敛稿

范围：World Score、TLO 暂定语义、历史证据、Observation、Object DNA、时间与尺度、AGO 研究组织方法

说明：TLO 仍是暂定名称。本稿优先固定语义原则，不固定最终文件后缀、编码格式、数据库实现或传输协议。

## 1. 核心目标

建立一套介于现实世界、人类观察者和机器之间的中性共同语义，使不同的人、不同 AI、不同传感器、不同年代的资料能够描述同一个世界，并且能够相互比较、验证、追溯和逐步收敛。

该体系不承担审美、价值、政治、文化优劣等判断。它只负责说明一个对象是谁、在哪里、什么时候、处于什么尺度、具有哪些状态、有哪些观测支持、来源是什么、存在多大不确定性，以及与其他对象和观测是什么关系。

共同语义与观点自由可以同时存在。不同观察者可以拥有不同记忆、解释和偏好，只要底层度量和描述语义保持一致，就可以在同一个世界中有效交流。

## 2. 乐谱是语义，编码是实现

“世界总谱”首先是一套语义体系。它不等同于某一种文件格式。

文本、JSON、二进制、TIFF、MP3、MP4、数据库、GPU Buffer、未来的新容器格式都可以作为存储或传输实现。编码方式可以随技术演进而改变，只要语义保持稳定，同一个世界对象在不同编码中仍然具有相同的身份、空间、时间、尺度、状态、来源与关系。

因此长期原则为：语义稳定，编码可演进。

## 3. 尽量继承人类已经统一的标准

已有成熟标准的部分尽量直接采用，避免重新定义已有共识。

1. 长度继续采用现有国际单位体系。
2. 质量继续采用现有国际单位体系。
3. 时间、温度、压力、速度、能量等物理量继续使用已有定义。
4. 传统经纬度、投影坐标和既有地理参考系统继续保留为外部交换与转换接口。
5. 新设计集中补充现有标准缺少的部分，例如跨时间对象身份、多尺度展开、Observation 绑定、证据链、冲突观测、未知状态、历史变化与世界谱语义。

这套体系的角色接近“公斤、米、秒”在交流中的作用。它提供共同参照，不替使用者决定观点。

## 4. 世界总谱的多尺度结构

整个现实世界应可以处在同一套谱系中，从地球一直展开到城市、街区、建筑、房间、杯子，再继续到材料细节。

低频负责长期稳定的宏观主体，例如大陆、大型山系、主要流域和城市骨架。

频率逐步升高以后进入局部结构，例如道路、街区、建筑、屋顶、瓦片、裂纹和材料微观细节。

尺度变化不改变对象身份。观察者靠近时只展开更高频声部，远离时只读取低频主体。

能够由规则和低频主体重新推导的信息不重复保存。无法可靠推导的真实差异进入 residual channel。这样可以获得高压缩，同时保护不可替代的真实信息。

## 5. 时间是世界变量

时间属于世界坐标的一部分，不只属于动画系统。

一个对象可以抽象为：

`Object(t) = DNA + Spectrum + State(t)`

DNA 保存较稳定的身份、结构和关系。

Spectrum 保存不同尺度的空间组织。

State(t) 保存随时间变化的状态。

世界不需要为每一年复制一份完整快照。长期稳定部分只保存一次，变化通过稀疏事件、局部频谱变化和时间函数记录。

因此一条道路的出现、一段河岸迁移、一栋建筑增加、一次屋顶重建，都应优先记录为局部 Change，而不复制整个城市。

## 6. 历史世界是不断收敛的世界

过去无法重新完整测量，因此系统不宣称拥有一个终极完整的过去。

系统保存的是一个随着新证据不断更新、不断缩小不确定性的历史世界。

今天只有一张照片时，某个对象可能只有一个面被观测。

以后增加第二张照片、航空影像、卫星图、测绘、施工记录和独立口述以后，相同对象的约束逐步增加。

每次新增资料只更新受影响的局部对象、时间段和频带。

长期目标是不断接近事实，同时永久保留未知、不确定和冲突的合法位置。

## 7. Observation 是一级对象

照片、航空摄影、卫星影像、地图、测绘、传感器记录、人的记忆、文字记录和文学作品，都可以被视为 Observation。

它们的观测能力和误差结构不同，但都可以进入共同框架。

一个 Observation 至少需要表达：

1. Observer 或 Sensor 是谁。
2. 观测发生在什么时间。
3. 观测发生在什么位置。
4. 使用什么设备、感官或记录方式。
5. 观测范围和方向是什么。
6. 观测到哪些 Object。
7. 哪些字段是直接记录，哪些字段存在推断。
8. 可能存在什么误差和限制。
9. 原始载荷和来源链在哪里。

一张照片因此可以理解为某一时间、某一位置、某一方向对世界的一次投影观测。

一万张独立照片可以成为一万次观测。它们的观测锥在同一个世界中交叉以后，会不断增加对象和相机位置的约束。

## 8. 独立证据比文件数量更重要

验证次数不能简单等于文件数量。

如果一千份网络图片全部复制自同一张原始照片，它们仍然主要代表同一个原始观测来源。

如果二十份资料来自互相独立的航空任务、不同机构测绘、不同摄影师、不同时间的卫星、独立档案和独立口述，它们相互吻合时可以形成更强约束。

因此需要明确记录 Evidence Independence 和 Copy Lineage。

系统至少要能够区分：

1. 原始独立观测。
2. 同源复制。
3. 同源二次加工。
4. 独立交叉观测。
5. 后续推断和重建。

未来信息污染不断增加时，这一层是保护世界知识的重要机制。

## 9. 可信程度应落实到属性

不建议只给整个 Object 一个简单总分。

同一栋建筑可以同时具有不同程度的确定性。

例如位置可能被十余次航空观测确认，轮廓可能被多期影像确认，正立面可能有三张地面照片，背立面可能从未直接出现，屋顶颜色可能完全未知，居住者信息可能来自两份独立回忆。

因此可信程度应绑定到具体属性、关系和时间区间。

一个最小世界陈述可以抽象为：

`WorldStatement = Object + Time + Space + Scale + Quantity/State + Relation + Evidence + Uncertainty`

其中 Evidence 保存支持、反对和来源关系，Uncertainty 保存当前误差范围或知识状态。

## 10. 事实层与观察者层可以同时存在

物理世界状态和观察者所理解的世界需要同时保存。

一个人说“城里已经没有粮食了”，可以作为真实的历史 Observation 保存。它不自动等价于整个城市粮食库存为零。

一个老人画错了1940年代翠湖周边房屋的位置，这个空间几何可能不准确。他关于隔壁住着谁、哪家是饭馆、某个房间用途的记忆仍然可能具有独立价值。

因此同一 Observation 内不同字段可以拥有不同的可靠程度。

观察者的错误也可以成为历史事实，因为它真实记录了当时某个人如何理解世界。

这使系统能够同时保存 Physical World 和 Perceived World，并研究二者之间的关系。

## 11. 创作、重建、推断和历史证据可以共存

系统允许创作，也允许 AI 重建、模拟和假设。

关键要求是不同类型保持清楚的语义身份。

例如2027年 AI 根据1944年照片重建一座建筑，可以明确记录：

`RepresentedTime = 1944`

`CreatedTime = 2027`

`Method = AI reconstruction`

`Evidence = source set`

该重建可以非常有价值，但不会自动获得1944年原始观测的身份。

同理，2025年新建的传统风格房屋只需客观记录它的建造时间、结构、材料和参考来源。体系无需给它贴价值标签，也不会把它自动当成更早年代的历史对象。

## 12. Object DNA 与跨时间身份

同一个现实对象在不同年代应尽量保持连续 Object ID。

例如同一座寺庙可以具有：

`Temple_X(t=1943)`

`Temple_X(t=1967)`

`Temple_X(t=1980)`

`Temple_X(t=2026)`

这些状态属于同一个对象的时间轨迹。

如果2025年另外建造一栋外观相似的建筑，它拥有独立 Object ID。外形相似不能替代历史连续性。

Object DNA 负责稳定身份、父子关系、结构、材料、能力和长期约束。时间状态和局部高频修正继续挂在同一身份下面。

## 13. 世界语义的最小候选核

当前第一轮可以把最小中性语义压缩为：

`WorldMeasure = Identity + Space + Time + Scale + Quantity/State + Relation + Provenance + Uncertainty`

Identity：对象是谁。

Space：对象或观测在哪里。

Time：对象、状态和观测分别发生在什么时候。

Scale：当前陈述处于哪个空间和频率尺度。

Quantity/State：测量值、物理量或状态是什么。

Relation：与其他对象、观察者和事件是什么关系。

Provenance：来源、变换和处理链是什么。

Uncertainty：当前知道到什么程度。

Observation、Evidence、Object DNA、Change、Simulation、Reconstruction 和艺术创作都可以建立在这个最小核之上。

## 14. 六条基础宪法

1. 一个对象必须能够保持跨尺度、跨时间身份。
2. 一个世界必须拥有统一的空间、时间和物理量语义。
3. 直接观测、测量、文献记录、推断、重建、模拟和创作必须可以区分。
4. 每一个可使用结论必须能够追溯到来源和转换历史。
5. 未知、不确定和互相冲突的观察必须可以合法存在。
6. 世界必须能够通过多尺度和时间变化逐步展开，不依赖复制完整世界。

## 15. AGO 研究体系与世界总谱的关系

世界总谱解决共同语义和长期知识积累问题，AGO 体系解决如何持续研究和改进这些知识。

长期工作原则如下。

1. 任何重大问题优先继承人类、论文、开源项目、现有 Mother 和已有实验中最可靠的成果，避免从零开始重复制造。
2. 大问题递归拆成大量可以独立判断和验证的小问题。
3. 暂时解决不了的节点允许 PARKED，不阻塞其他分支继续前进。
4. 少量 AGO 先独立搜索，开始阶段保持部分隔离，避免过早形成同一错误共识。
5. 不同 AGO 从不同方向探索，成果再回流比较、批评和组合。
6. 小妈承担 Judgment，负责判断路线继续、暂停、转向、资源增加和停止条件。
7. 如果多个 AGO 在同一点重复循环，应主动拆散和改派方向。
8. 一个候选方向越有希望，越需要安排独立反例和攻击型 AGO 检查它。
9. 实验室与 Canonical Truth 隔离。实验应在独立分支、容器、worktree 或 artifact 空间运行，失败不能污染核心世界。
10. 实验成功以后，只通过带证据、作用范围、失败条件和回滚方法的 Candidate Capsule 晋级。
11. 先用少量 AGO 跑通完整流程，再逐步扩大到几十、上百个。数量服务于搜索结构，不能替代判断和验证。
12. 每个领域获得的方法都要进一步抽象，测试是否可以迁移到其他 Mother。

## 16. 稳定结构与局部高频修正

AGO 的工作方式与世界总谱使用同一种思想。

先保护稳定低频主体，再允许不同实验对局部高频进行修正。

一个新的动物肌肉结构、一个飞机零件、一块建筑材料、一条沟渠或一个天气方法，都不应随意重写完整世界。

每次改动应该有明确作用域、频带、时间区间、依赖关系和验证条件。

这使系统可以长期积累，同时保持主结构稳定和强探索能力。

## 17. Transform History 必须保留

原始证据不应被后续处理覆盖。

照片裁切、畸变校正、配准、色彩恢复、三维反演、AI 修复、缺失部分生成等步骤都需要留下转换记录。

这样未来算法升级以后，可以重新从原始证据计算，不被早期处理永久锁死。

## 18. 长期目标

该体系希望形成一种共同的世界语言，使人类、AI、卫星、相机、测绘仪和未来传感器都能够对同一个世界进行累积研究。

一个人今天增加一张照片，一个 AGO 找到对应山峰，另一个 AGO 求出摄影机位置，历史研究者确认人物身份，建筑研究者修正结构尺寸，未来新的航空或卫星资料继续加入。所有这些贡献都回到同一个对象、同一个时间轴、同一个空间和同一个证据网络中。

最终希望达到的状态是：

一个世界，多种观察。

一份总谱，多种指挥。

一种共同语义，多种观点和创造。

所有可用结论都能回到来源。

系统不替过去编造一个完整故事，而是把能够找到的真实痕迹放回共同世界，让历史随着证据增加逐步显现。

## 19. 下一阶段待讨论

本稿只固定第一轮语义骨架。下一阶段需要通过真实案例检验，而后再决定最终格式名称和编码。

优先测试案例可以包含：

1. 一处1940年代建筑，结合航空照片、地面照片、地图和后期卫星图。
2. 一个位置画错、社会关系记忆较强的历史回忆图。
3. 同一建筑跨几十年变化的时间谱。
4. 同源复制一千份与二十份独立观测的 Evidence Independence 对照。
5. 一栋现代传统风格建筑与历史传统建筑的对象身份和时间关系。
6. 同一个对象从城市低频一直展开到建筑和材料高频的谱系表达。

完成这些最小真实实验以后，再决定哪些字段必须进入 TLO 核心，哪些字段属于扩展层，哪些内容只属于具体领域适配器。
