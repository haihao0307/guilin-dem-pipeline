## S-F01 1940年代桂林北郊传统稻田知识包 V0.1

文件：`1940s_Guilin_Northern_Suburbs_Traditional_Paddy_Knowledge_Pack_V0_1.zip`

外层 SHA256：`02822db0d410fd368a187679d369dc644d133004845a27ffa2bf5cc63031ff6d`

ZIP 条目：23。

内部清单列载荷：22。

本轮校验：22/22 文件大小与 SHA256 均与 `PACKAGE_MANIFEST.json` 一致。

主要支持：

- 水田先有地形、水源和排水解释，再有田块外观。
- 活跃水田需要近水平田面、真实田埂、进水和出水关系。
- 山地沿等高线分级，平坝受微地形、沟渠、道路和历史边界切分。
- 泥化、田龄、低渗透层、田埂维修和漏水应进入状态。
- 人口、劳动力、牛力、水源和运输共同限制可维护面积。
- 北广西接近目标年代的区域资料可作为“单季稻”启动先验，但不是桂林北郊逐村硬真值。
- A/B/C/D 证据制度适合作为 Farmland 地方化研究的第一套兼容框架。

不能支持：

- 1940年代桂林北郊每块田的真实位置与尺寸。
- 当地每个村具体牛数、人口和劳动效率。
- 龙骨水车在桂林北郊的普及率。
- FAO 工程尺寸直接作为桂林乡土尺寸。

用途：`regional_historical_seed = Guilin/Northern Guangxi 1937-1949`。

## S-F02 云南人口较少民族稻作仪式探究

文件：`云南人口较少民族稻作仪式探究.pdf`

SHA256：`d76581037c1cfd85efbbcf3e1bfe22458d49e659368683c52c23c3ecf2da2caf`

主要支持：

- 稻作文化事件可以沿犁地、播种、插秧、除草、收获、入仓和尝新等农事阶段展开。
- 某些地方仪式把“开秧门”“关秧门”“秧王”“叫谷魂”“尝新”等节点与田、谷仓、道路、家庭和村寨活动连在一起。
- 文化行为可能影响劳动时序、访问规则、种子留存、储粮与共同活动。
- 文中强调不同民族仪式有共同性，也有明显差异，且会随现代化发生传承变化。

不能支持：

- 把任何一种民族仪式推广为云南所有稻区或中国所有稻区的统一流程。
- 把仪式直接编码为超自然物理作用。
- 把现代调查时观察到的文化状态直接回投到1940年代桂林。

用途：证明 `CulturalProfile` 和 `cultural_calendar` 是 Farmland DNA 需要容纳的结构，而具体内容必须按地点、族群、年代单独研究。

## S-F03 稻作文化与傣族传统伦理道德

文件：`稻作文化与傣族传统伦理道德.pdf`

SHA256：`6af8c52d353633c00d27bc50a02b90f25c950d85887207c499b21393b4cdcc49`

主要支持：

- 稻作文化可以形成劳动伦理、集体协作、生态保护、家庭知识与信仰制度。
- 大型水利和水稻灌溉可推动跨家庭、跨村寨的协作组织。
- 农业历法、长者经验、传统农具、水牛、森林与水资源可以共同进入地方农业知识体系。
- 农田的空间与生产关系会受社会制度、共同劳动和自然资源管理影响。

- 把文中的历史叙事直接当作桂林、哈尼或现代稻区参数。

用途：证明 Farmland DNA 需要 `socialInstitutions`、`knowledgeHolders`、`collectiveWorkRules` 与 `sacredEcology` 等可选层。

## S-F05 j-2607.pdf

题名：`从稻穀到桑田的演化——論何乃健散文的稻田主題`

SHA256：`a30885446cc4f3150d3978080d5c6ea04ef91a9e0c12f668f579fc2c881cd89a`

来源性质：文学研究与二次材料，其中大量引用何乃健长期稻作研究和科普写作。

主要支持的启动思路：

- 稻田可以按“作物-水土-害虫-天敌-管理”关系理解，而不是只看作物颜色。
- 单一化品种、广谱杀虫剂、焚烧残体等管理改变会影响生态关系和长期状态。
- 稻草/残体去向、天敌关系、病虫害压力和管理行为值得进入 Farmland DNA 的状态与循环结构。

不能支持：

- 把其引述中的任何马来西亚现代农业数值作为1940年代桂林参数。
- 把文学比喻视为农学直接证据。
- 未回溯原始农学来源时，不把具体技术结论提升为跨地区硬规则。

用途：`conceptual_secondary_source`，帮助下游提出待验证的农学问题。

## 本轮小妈抽象出的新知识

以下属于团队架构推导，不是上述任何一篇文献原句：

1. Farmland 应采用“复合对象”而非单对象平铺模型。
2. Generic Core 与 Regional/Historical/Cultural Profile 必须分开。
3. 地方仪式通过人类行为、日程、访问、种子和储粮等通道进入模拟，不直接改变物理法则。
4. 农田自然基底与农业人工地形 overlay 应分开保存，以保护 DEM / Landscape Truth。
5. Ocean 只在真实海岸水文连接存在时参与 Farmland，内陆稻田不应为了系统统一而强接 Ocean。
6. Farmland 的长期状态至少包含土壤/田龄/水利维护/知识传承/土地利用历史中的必要部分。
7. 农田的“边界”有两个尺度：产权/田块边界，以及更大的 Agroecological Context。

状态：`reviewed_startup_abstraction`。
