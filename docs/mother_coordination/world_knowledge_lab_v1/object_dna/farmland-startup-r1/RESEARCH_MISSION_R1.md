# Farmland Object DNA 自主研究任务 R1

日期：2026年9月7日

角色：下游 Farmland Object DNA 执行者。

目标：在小妈提供的启动框架上继续自己研究，不等待小妈把所有农业知识逐条喂完。最终把新知识蒸馏为可查询、可重建、可验证的函数和区域 Profile。

## 一，第一性问题

每次研究前先问：

1. 我研究的是自然规律、农业技术、社会制度、地方文化还是视觉表现？
2. 它影响的是田的身份、状态、约束、策略还是观察输出？
3. 它是否需要历史记忆？
4. 它是否具有明确地点、年代和族群边界？
5. 它能否变成一个带输入输出、单位、有效范围和恢复条件的函数？
6. 已有函数是否已经覆盖，还是确实遇到新情况？

只有确实超出已有有效范围时才启动高成本研究。

## 二，研究顺序

### Track A 地理与土地适宜性

优先研究：

- 地形、坡度、局部起伏、曲率、坡向。
- 河谷、冲积平原、洪泛区、喀斯特洼地、山间盆地、梯田坡面。
- 哪些地形适合水田，哪些适合旱地、果园、菜地或林地。
- 人工整平与自然地形之间的可恢复关系。

输出：`landSuitability()`、`earthworkCost()`、`parcelShapePrior()`。

### Track B 水文与灌排

研究：

- 地表汇水、泉、溪、河、塘、井、堰、渠。
- 重力灌溉、轮灌、田间分水和排洪。
- 平坝排水与山地逐级灌溉的差异。
- 泥化、田埂漏水、深层渗漏、蒸散和暴雨溢流。
- 沿海农业才研究潮汐、盐水、海岸地下水和风暴潮。

输出：`waterPath()`、`fieldWaterBalance()`、`irrigationFeasibility()`、`overflowRisk()`。

### Track C 土壤与田龄

研究：

- 水稻土发生、长期淹水和氧化还原环境。
- 泥化、犁底层、渗透、结构、养分、有机质。
- 新田、熟田、弃田、复耕的时间演化。
- 作物残体、粪肥、草木灰、沟泥等地方循环，但必须按年代和地区验证。

输出：`advanceSoilState()`、`waterRetention()`、`fieldAgeAppearance()`。

### Track D 作物生命周期

研究：

- 水稻类型、地方品种、育秧/直播、移栽、分蘖、穗分化、抽穗、灌浆、成熟。
- 温度、日长、水分、施肥和管理对发育期的影响。
- 株高、密度、行列、倒伏、稻穗形态、颜色和水面遮蔽率如何从状态产生。
- 其他农业类型需独立 CropProfile，不能让水稻逻辑支配全部 Farmland。

输出：`advanceCrop()`、`cropAppearance()`、`cropWaterDemand()`。

### Track E 生态关系

研究：

- 杂草、害虫、天敌、蛙、鸟、鱼、鸭、役畜、田埂植物和水生生物。
- 哪些关系是地方传统系统长期形成，哪些是现代农业干预结果。
- 生物多样性如何影响稳定性、病虫风险、营养循环和人类利用。

输出：`agroEcologyState()`、`pestRisk()`、`habitatRole()`。

### Track F 人口、劳动与生产力

研究：

- 户均人口、劳动人口、农忙峰值、互助组织。
- 牛、马、驴、水牛等役畜适用地区。
- 犁、耙、镰、脱粒、扬谷、运输和提水工具。
- 一户/一村可维护田面积与水、劳动、运输之间的关系。

输出：`laborDemand()`、`animalPowerCapacity()`、`maintainableArea()`。

### Track G 聚落与农业空间

研究：

- 村庄为什么位于当前位置。
- 住宅、谷仓、晒场、牛圈、肥堆、塘、井、道路与田的距离关系。
- 收获、稻草、粪肥、种子和生活用水如何在村田之间流动。

输出：`settlementFarmNetwork()`、`transportCost()`、`storageFlow()`。

### Track H 土地制度、水权与共同劳动

研究：

- 产权、继承、租佃、公共土地。
- 公共沟渠、上游下游轮灌、维护义务。
- 土地碎片化怎样从社会历史中产生。
- 战乱、人口迁移、征税、市场和技术变迁对田地的影响。

输出：`parcelHistory()`、`waterRightSchedule()`、`collectiveMaintenance()`。

### Track I 地方知识与文化

研究：

- 节令、农谚、农历、仪式、祭祀、禁忌。
- 谁掌握农业知识，怎样传承。
- 仪式如何影响农事日程、种子、村寨活动和生态保护。
- 不同民族、村寨和年代严格分 Profile。

输出：`culturalCalendar()`、`knowledgeHolderGraph()`、`behaviorConstraint()`。

### Track J 农业视觉证据

研究：

- 航片、历史照片、地图、电影、农具图、地方志图版。
- 田块尺度、长宽、方向、田埂、沟渠、道路、聚落和作物阶段。
- 固定相机和比例参照下量取，不凭“看起来像”。

输出：`imageMeasurementLedger()`、`visualPrior()`。

## 三，历史 Profile 的研究纪律

以1940年代桂林北郊为例：

优先级固定为：

同地点同年代照片/航片/地图 > 同地点近年代 > 北广西近年代 > 可靠农业机理 > 跨地区传统系统类比。

直接证据一旦解决某问题，停止继续堆积低等级泛化资料，转入参数化、对照和验证。

禁止把：

- 现代高产品种。
- 联合收割机。
- 激光整平。
- 大型电泵。
- 现代混凝土标准渠。
- 现代化肥体系。
- 著名旅游梯田的夸张形态。

默认投到1940年代桂林。

## 四，现代 Profile 的研究纪律

现代农业不能简单视为“传统系统加机械”。

需要重新研究：

- 品种。
- 机械。
- 灌排基础设施。
- 肥药。
- 劳动力外流。
- 土地流转。
- 市场。
- 生态变化。
- 水资源约束。

每个 Profile 自己有时间真值。

## 五，文化资料纪律

当看到神话、仪式、伦理或口述知识时：

先保存原文含义和来源。

再问它改变了人的什么行为。

然后映射到：时间、访问、劳动、种子、储藏、维护、生态保护、社会关系等真实通道。

不得把文化叙述直接改写成通用物理定律。

## 六，第一批自主研究成果格式

每个研究主题至少产出：

`SOURCE_NOTE.md`

`RULE_CARD.md`

`COUNTEREXAMPLE.md`

`PROBE.*`

`PROBE_RESULTS.json`

`PROFILE_PATCH.json`

内容必须有：

- 来源定位。
- 自己的解释。
- 输入输出。
- 单位和坐标。
- 时间语义。
- 证据等级。
- 有效范围。
- 反例。
- 零输入/恢复路径。
- 小试验。
- 真实产品采用状态。

## 七，第一轮自主研究任务

Farmland DNA 启动后先完成四件事：

1. 选一个目标 Profile，例如 `Guilin_North_1940s_Paddy_R1`，建立来源清单和未知项，不追求画面。
2. 建一个最小 `FieldParcel + WaterPath + CropCycle + LaborCapacity` 数据对象，证明接口能闭环。
3. 找到并验证一个真正地方化参数，例如田块尺度分布、农事月份、田埂尺度、水牛数量或传统沟渠形态。
4. 用固定条件做 A/B：没有该地方参数时与加入后有什么可解释差异。

完成后再进入 Landscape/Weather/Ocean 产品适配。

## 八，停止条件

某条知识进入函数库前必须满足：

来源清楚。

边界清楚。

变量清楚。

小试验通过。

反例已检查。

产品线没有被越权修改。

之后熟悉任务直接调用函数，只有遇到新条件才再次研究。
