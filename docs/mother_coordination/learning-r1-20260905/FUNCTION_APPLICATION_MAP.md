## 结论与本轮状态

保留少量可复用的计算方法，给各类对象配置具有含义的结构、坐标、材料参数和状态。共同的方法不要求对象外观相同，也不要求所有现象使用同一个噪声值。先解释每个输出是什么，再决定它进入几何、材质、运动还是交互查询。

本轮完成既有教材回读、英文原始来源复核和应用整理。没有新数值试验、原软件运行、浏览器/GPU测试、真实地区拟合或生产集成。没有改变小王的一处变化任务，不复发全组开工指令，不推定任何Mother已读或理解本页。本文中的配方和检查均为建议，按实际授权逐步验证。

## 组合方法：先问它附着在哪里，再问它影响什么

对象自身的纹理与微结构优先使用明确的局部或参考态坐标。环境作用从当前世界位置与共同时间取样；不可由瞬时输入恢复的状态单独保存。相机决定显示取样与预算，不修改形体身份。

候选流程为：结构与参照确定主形；把位置映射到所选参考域；组织方向、尺度与细节；用作用范围和单位限制；根据需要更新历史；最后分别生成几何、表面响应或运动候选。某些领域会双向耦合，此顺序只是制作和检查路径，不能替代真实求解流程。

对刚体材料，q_material=B_material_from_piece*q_piece，p_world=T_world_from_piece(t)*q_piece。B保存这块物质在原参考体中的坐标对应；T描述它现在在哪儿。前式用于附着的物质特征，后式用于环境查询。变形体需要已有参考态/形变映射，不把刚体逆变换套到任意皮肤或云密度上。

不要让一个移动后的碎片重新以包围盒零点随机生成原本应连续的石纹。也不要让它永远沿用原位置的降雨和遮挡。材料来源可以继承，环境输入随当前位置更新。此处只有设计推演，没有完成实际切割、内部材质或碎片运动实现。

连续世界场和相邻分块还必须共用相位、尺度和变换。每块各自重置坐标或种子可能导致接缝；重心变化、相机重置或对象创建次序不能偷偷改变材料身份。局部旋转随位置变化时需检查拼接与全部映射的导数。

## 造型与材质通过有含义的字段联系

候选共享字段包括：材料类别与稳定ID、裂隙区域、颗粒区域、结构方向、局部粗糙分布、坡面/接触信息、暴露条件、湿润或损伤状态。字段要有单位、参考域、适用时刻、出处和责任方，不能仅用一张无含义的噪声值包办所有通道。

同一条已定义裂隙可以参与几何开口的生成，也可以作为表面响应或湿润模型的一个输入。但颜色、粗糙度、法线、金属度及真实缺口分别有自己的输出函数与约束。禁止把相同灰度无差别复制进全部通道，导致暗处一律凹、亮处一律凸、所有材质都像同一种塑料。

判断材料是否湿润，需要当前形态、环境输入、材料参数和历史。裂隙是否蓄水或排水依赖具体结构与模型，不规定所有凹处必然更湿；本轮没有湿润标定。屏幕上的颜色变暗也不能倒过来作为几何已凹陷或化学过程已完成的证据。

较大的缺口、孔洞、分离岩块及厚覆盖层需要所选形态表示承载；微小凹凸可以研究着色法线和统计粗糙度。Bump Mapping只改变着色法线，不能证明轮廓、厚度、穿透和碰撞已经成立。变化几何后重查法线、接触及需要当前几何的字段；合法参考态字段则保持其语义，不能全部不加区分地重算。

## 各生产线的对应方式

Landscape：主形、峰位、鞍部、峰脚和连接关系先行；多方向函数与受约束的显微镜细节用于局部岩面。沿此前小步骤，只观察一个区域、一个函数、一个强度的关闭/开启差别。缺口与落石另查共同事件与形状来源，不用随机摆石补成已发生的地质过程。

Brick、Tiles、House：共用局部坐标、多尺度和门控方法，但保留烧结砖、土坯、石材、陶瓦与木材自己的配方。材质例子先保持几何、UV和光照，只换一个程序化通道的组织方式；需要厚青苔、掉块或新开口时，再单独进入几何问题。新纹理不能遮盖悬空、互穿或安装错误。

土壤、河岸与卵石滩：先以已有地表和可信岸线定义范围。可研究沿岸方向、距岸横向位置与高程的局部坐标，叠加分区、粒径候选分布及石块生成，真实石块再检查不互穿与承托。粒径和方向必须来自具体参照或明确的合成模型，不预设靠水总是更细、高滩总是更粗；不借此手绘真值河道。

Ocean/Coast：主海面可用解析波或频谱定义，连续噪声调制受控细节，Curl研究特定旋转速度场；泡沫按生成、输运、消散组织历史。波位移、法线、水面高度查询共享定义，横向位移涉及坐标反求。潮汐、岸形、海底和入流有明确驱动，不把全部关系当成无关联噪声层相加。

Weather/Cloud：云的候选形态以包络和非负密度为基础，多尺度与域扭曲组织边缘；实际输运与热湿过程按已选模型处理，光照沿体积独立计算。直接变更噪声时间可以产生外观变化，但不能自动证明物质沿速度场移动或质量守恒。风场可供水面、草、烟分别使用，各对象按自己的响应处理。

Human/Animal/Plant：主动作、骨骼、草根及接触关系先明确；共享节律和有界相关变化用于局部次级响应。相邻身体部位采用共同驱动和不同权重，不能逐点各自随机摇动。姿势仍由本线既有求解形成，显示不回写finalPose。运动学资料后续纳入，不在本轮造一套新运动系统。

Aircraft及既有历史数字资产：只在当前任务允许的范围内研究材料附着、粗糙度/磨损的可控变体和版本回归；沿用权威几何、UV、配置与动画边界。本轮不改变机械产品结构，不增加实体制造或功能性能用途。

真实GIS：参照、区域位置和数值具有单独的事实身份。函数拟合及必要修正需要对照已有数据验证；程序微细节标为生成结果。现有canonical、数值、AOI、哈希、零LOD/零贴图/固定几何及其他禁止项不变，不用短函数替换未验证的真实地区。

## 进入生产的最短方式

每项只填写：已有对象、当前问题、所选函数、一个可调参数、受保护内容、关闭后的恢复方式、前后对照和实际成本。共享代码由核心提供；实例只保存版本、参数、参考映射、种子及必要状态和修正。不要复制全部教材或整套第三方工程进入每个对象。

实现时把纯取样、状态推进和渲染分开。查询不修改状态；扩层不重标旧系数；材料变化不暗改几何；造型变化需更新相关依赖。缓存键只包含该输出真正依赖的版本和输入，有限更新与同输入完整重算对照，正确性再以独立参照检查。

同时保留相关性与差别：有共同原因的输出共享字段，不相关的微变化使用各自稳定通道。共享随机算法不等于共用一条按创建顺序消费的随机流；通道身份固定，统计独立性不能只靠改名字宣称。

显示按实际像素覆盖范围过滤细节；不把相机作为世界定义的输入。高频位移小仍可能影响法线和反光，需要单独处理平均贡献或统计响应。函数代码量、地区参数、必要状态、生成缓冲、CPU/GPU时间和显存分别统计。按需计算不允许忘掉已经发生的历史，也不等于零运行内存。

第一阶段继续小王的一处岩面变化。下一阶段候选是把相同坐标与门控方法迁移到砖妈的一块石材，重新选材料参数并验证；随后选择一项海面或云边缘效果。这个次序不暂停其他已批准工作，不代表现在给全部Mother追加生产命令。

先从四项检查收结果：主形/接触是否保持；一个参数的变化是否符合事前解释；换镜头/顺序/恢复后是否仍为同一对象；实际观看距离下的质量与成本。每次只扩大已验证的使用范围，不用课堂测试数量替代主画面改善。
