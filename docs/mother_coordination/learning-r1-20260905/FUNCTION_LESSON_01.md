## 六类积木，先弄清各自负责什么

1. 波与节律：从正弦、余弦、解析波入手，区分幅度、波长、方向、相位和时间。先预测只改一个参数的影响，再看结果。海面位移、颜色变化和泡沫生成分别标注，不能只因用了同一公式就混成一个量。参考[海洋函数分析](skills/ocean-function-source-review/SKILL.md)。

2. 基础变化：Simplex、Perlin及已收录的复合三角函数提供不同的变化来源。明确值域、输入尺度、种子和算法版本；同一字段按稳定身份初始化。先解释函数输出代表什么，再接几何或材质。参考[DISTILLATION_CORE的噪声基础层](DISTILLATION_CORE.md)。

3. 多尺度组合：较粗项与较细项共同组织结果。新增项时，说明原有系数是否保持；需要重新分配幅度就明确记录。层数多不自动代表形态准确，小位移也不保证法线变化小。重点读[显微镜岩体细节研究](references/MACROSCOPIC_MICROSCOPE_ROCK_DETAIL.md)的结构与应用部分。

4. 坐标组织：先确认细节附着的对象，再从世界位置转到固定的局部坐标，按需要旋转、缩放或域扭曲。旋转控制取样方向；结构保护仍靠作用范围、幅度、连续性和几何检查。改相机不能改变对象或纹理身份；静态山体的形态参数不随播放时间流动。

5. 作用范围与输出：用平滑权重限定细节出现在哪里，保护峰顶、山脊、接触面及已接受区域。既看边界位置也看方向是否突然变化。每项输出标明影响形状、法线、粗糙度、颜色还是状态；阴影中的亮暗线不自动证明有真实裂缝。参考[TERRAIN_CORE](TERRAIN_CORE.md)。

6. 时间与变化历史：共用时间单位和原点，区分直接按时刻取样与需要前一步状态的过程。循环取样、运动路径、泡沫残留分别检查。学旋度与域扭曲时，检查组合后是否仍满足所要求的边界或流动性质。参考[时间与事件](skills/realtime-stream-time/SKILL.md)及[统一核心](DISTILLATION_CORE.md)。

不按软件名复制一套又一套实现。Houdini、Blender、UE、Gaea继续作为已有来源与验证工具，具体版本及运行范围见[技能目录](SKILL_INDEX.md)。一个方法被读过、解释清楚、软件跑通、产品改善、用户认可，分别记录。
