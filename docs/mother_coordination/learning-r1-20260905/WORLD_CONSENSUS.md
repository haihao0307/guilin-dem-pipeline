# 世界共识：同一地球中的时、地、物、关系与依据

日期：2026-09-06。所属：[统一函数核心](DISTILLATION_CORE.md)。方向来自用户本轮确认；本页的字段、公式和执行约定属于小妈整理的接口草案。没有创建新生产体系，没有改变现有生产默认值、真值、权威资产、人工批准或其他Mother的任务。

## 总定义

同一地球世界中，每个对象以稳定身份存在；在明确时刻、坐标参考系与证据版本下，有可查询的状态及关系；变化服从共享的模型规则与边界；已知事实、推导结果、程序生成、未知与冲突分别记录，不能相互冒充。

本期范围只包括地球世界，月球和其他天体的对象模型留待后续。已有潮汐、日照等驱动继续作为带时间基准和来源的外部输入，不因本期不建立天体对象而取消。共享核心不要求一次模拟整个地球或全部分子，也不要求每根草逐点存档。

“时、地、人”推广为“时、地、物”，再补“关系、变化、依据”。人、狗、草、房屋、山、海以及历史数字资产，共用这些语义。噪声、shader、GIS、结构函数和局部求解器是表示与计算方法，均不能代替对象身份、历史证据或自然过程的约束。

## 一个世界的两个操作

只读查询：Q(world_id, time, region_or_frame, object_id, revision) -> 存在性、位置与朝向、状态、关系、依据与不确定性。范围查询返回相应对象或连续场；对象查询不要求用户事先知道对象位置。没有资料时返回unknown，未实现时返回unsupported，存在争议时返回conflicted，不能一律返回零、空位置或不存在。

状态推进：S(t+dt) = Phi(rule_version, S(t), external_inputs[t,t+dt), dt)。这里只约定输入输出，不声称一个公式已解决所有物理化学。物理过程、化学过程、行为过程与表示方法保持适用条件和求解精度。依赖历史的部分由状态、事件和检查点恢复；查询和画面渲染不得偷偷推进它。

每次联合计算读取同一已提交快照，各域产生修改提案，对耦合量按约定求解并检查，再发布下一快照。共享字段只有明确责任方或联合求解器可以写入。不同Mother不能各自写出互相冲突的“当前风”“当前水位”或对象位置。外部场与对象可双向作用，不能把环境永久当成只读背景而忽略反馈。

同一个版本与输入应产生一致的语义结果；跨GPU、语言和浮点平台的数值一致程度需测量并声明，不承诺未经验证的逐位相同。

## 统一时间与历史时间

运行使用一条带原点、单位与版本的共同时间轴，可用整数tick及有理步长表达。绘制帧率、求解频率和材料更新频率可以不同，但跨域交换必须指向相同快照时刻，或声明延迟及有效区间。相机停看不能重置世界，频率不同也不能让各域拥有互不对应的“现在”。

时间本身不会告诉系统人在哪里。位置必须来自观测、明确轨迹、事件或状态演化。只知道10点在家、17点在另一地点，不能把中途直线路径自动登记为事实；需要插值时标记所用假设与可用范围。

历史记录保留原始日期、当地时区或历法、时间精度与不确定范围。只有资料支持时才转换成可比较的共同时标；不能把只知年份的记录补成某日某秒。对1942年的材料不假设现代地区时区规则原样适用。

区分valid_time与recorded_at：前者描述事情何时成立，后者描述系统何时取得或修订这项认知。新发现一张旧照片改变的是对旧时刻的认识；它不意味着照片中的物体在今天被创建。缺少明确的替代记录时，不以最后写入覆盖来源冲突。

## 共同参考系中的绝对位置与动态相对关系

这里“绝对位置”指地球共同参考系中的表达，不宣称宇宙存在唯一绝对坐标。每个地区、建筑和构件可以保留本地坐标，但必须能通过明确变换连接共同参考系。坐标系标识、轴顺序、方向、单位、垂直基准和适用时间不能缺省猜测；经纬度不能直接当米做距离。

地理来源保留各自真实CRS与转换依据，不在本页擅自把所有现有数据改成一个新投影。渲染可以用局部原点保证数值精度，改原点不改变世界身份或地形。

刚体列向量约定：p_world(t)=T_world_from_i(t)*p_local。相对变换：T_i_from_j(t)=inverse(T_world_from_i(t))*T_world_from_j(t)。两个变换必须取同一世界、时刻、版本及兼容单位。形变、法线和相对速度有额外导数与约束，不能把此刚体公式直接当作全部运动求解器。

相对关系既可能变化，也可能保持。固定在飞机上的构件可以与飞机一起移动，但相对飞机保持原位；拆卸后由事件改变附属关系。一个人始终在自己的身体坐标原点，不妨碍其地球坐标随轨迹变化。

身份独立于位置。多个对象可以在同一地区，甚至具有相同记录参考点，不能据此合并身份；同一对象在一个已提交快照中不能具有两份相互排斥的权威姿态。对象还应有范围、几何或体积定义，不用一个参考点代表整个身体。连续水、风和云可用带语义的场表示，无须为每个采样点创造持久对象ID。

变换层级用于算坐标，逻辑关系图用于表示安装、接触、包含、归属、遮挡、影响等。两者不能混为一张只能有一个父节点的树。关系带有效时间与依据；邻接查询只访问实际相关对象，不预存全世界所有两两关系。

## 型号、实例、配置与存在历史

至少区分type_id、variant_id、instance_id、configuration_id及其有效区间。型号描述一类东西；实例指具体那一件；配置描述它在某一时段的组成和装配。名称变化、位置变化或重新涂装一般不自动创建新实例，身份延续规则需按对象定义。

设计出现、制造、安装、改装、退役、拆卸、损坏、遗失、收藏和销毁分别记录。退役不会自动使实物消失。某年一张照片没有看到它，也不能单独证明它当时不存在。未知制造或销毁时间保留未知，绝不按型号时间线自动补齐某个实例的生命史。

用户的1942年Aircraft/Browning M2例子用于落实上述关系：需确认具体型号、那架飞机、那件装备、当时配置、地点和来源。本轮只核对了公开博物馆资料，没有核对用户项目里某件武器的完整履历，不把“1930年代还没有、1960年代已经没有”写成整个M2家族规则。美国空军国家博物馆说明列出M2相关不同配置及延续使用；澳大利亚战争纪念馆还有约1940年制造、从二战坠机处回收的M2实物记录。型号延续、平台退役与具体物体的存续必须分开。

历史筛选同时检查日期、地方、实例及配置。某型号在1942年存在，不足以证明它就在指定飞机和机场；照片摄于今天，也不代表照片中实物制造于今天。形状配方必须绑定适用版本，不能用后期变型替换早期实物。仅处理已有历史数字资产与展示范围，不新增实体制造或性能优化用途。

## 不伪造是准入规则，共识需要可修订的证据

证据类别至少保留observed、inferred、generated、unknown。验证状态另外保存，如candidate、checked、accepted、conflicted；“大家都赞同”不能把generated升级成observed。一次视觉验收也不能证明历史归属。来源转载或多个Mother引用同一材料，不计为多份独立证据。

已知记录可核对来源和适用范围；推导结果保留前提、方法和误差；生成细节保留配方与种子；未知保留缺项；冲突保留原始主张并进入复核。记录source_id、valid_time、recorded_at、method_version、uncertainty、review_reference，组成最小可追溯链。

例如，已有DEM的某个采样值可作为该数据源的测量/处理结果记录。两采样点之间生成的细裂纹或一株草，属于标明身份的模型输出，不能宣称1942年那个位置确有该裂纹或该草。算法按物理规律构造的场景也不自动成为实际历史事件。

内部自洽是必要的检查目标，外部证据仍需独立核验。对缺少资料的状态，不通过删除分歧来制造“无矛盾”。世界共识的含义是共享定义、来源、校核方法和已提交版本，大家能看见已知与未知，能够共同修订错误。

## 共享物理化学含义，保留材料与尺度差别

各域共用单位、重力约定、水位/压力/温度/湿度等字段定义、守恒账和边界。砖、土、水、植物和生物组织保留各自材料参数及响应函数，不以同一条噪声公式包办所有过程。材料参数没有标定时写明假设，未实现化学模型时标明unsupported，不用视觉染色代签化学反应。

首个联合验证可选现有工作台里一个人、一只狗、一栋房屋、一小片草与一场雨的合成情境：所有域读取同一时刻的降雨、位置和遮挡；材料产生各自湿润响应；人物和狗的接触由原执行系统求解；不重复扣算同一物质或重复施加一个作用。此处只有试验设计，本轮没有运行该场景。

Human原创骨骼、固定骨长与finalPose权威保持；Jarvis负责高层认知和意图，不接管低层运动。Landscape/DEM真值、AOI、哈希、固定几何、零LOD/零贴图等当前有效约束保持；不恢复旧地貌或数据路线。通用原理可共享，专项求解器通过接口接入，不把全部软件锁成单一巨型程序。
