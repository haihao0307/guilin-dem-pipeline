# 属性与依赖技能卡

R1 初始样卡。来源：SKILL_INDEX.md 中 SideFX SOP、Geometry attributes 和 Volumes 官方章节。状态：来源章节已读；本项目实现、软件运行、可迁移性验证均 not_run。

## 来源中已能确认的内容

SOP 网络传递几何并组织生成与修改操作。属性可以附着在点、顶点、面及整体层级；稳定 id 与可随拓扑操作改变的元素序号不同。体积能够承载密度、距离或速度等不同语义，字段名相似不保证单位和含义一致。

## 本轮提炼的方法

把生成规则写成有类型的输入、显式依赖与可检查输出。几何结构、装配关系、材料响应和显示分别保存；共享 id 作为追踪依据。局部变化应能说明受影响节点及不应变化的对象。这是本团队实验设计，尚未证明能解决所有生产错误。

输入：对象稳定标识、参数版本、参照与未知项、单位/坐标约定、生成种子、依赖对象。输出：派生几何、接触/装配关系、独立材料参数、依赖记录和检查报告。

有限步骤：读取并冻结当前样本；建立稳定 id 与属性表；列出生成依赖；只改一个获准变量；比较结构和材料各自的变化；保留回滚入口。不得用软件节点图代替实测构造证据。

建议伪代码：read_contract(); preserve_ids(); generate_geometry(parameters); assemble_with_constraints(); derive_material(environment); check_geometry_and_contacts(); record_diff_and_recovery().

## 必须能回答的追问

若只调整表面湿度，哪些数据允许变化、哪些应保持？若节点重排导致 point number 改变，为什么不能把它作为历史对象身份？同名字段在厘米坐标与米坐标中有何风险？

## 有限验证设计

使用自建简化测试件，不碰正式真值。固定输入重复两次，比较对象 id、参数版本和几何输出。只修改材料变量，检查结构哈希和支承关系是否意外变化。再改变一个结构变量，列出真实受影响的依赖项。明确精确一致与容差比较的适用范围，不能假定跨软件和跨硬件位级一致。

正例由执行者给出有依据的合法装配。反例至少含一个悬空或互穿实例，并说明检查为何会捕获它。包围盒重叠不能独自证明真实曲面穿透或接触。验收阈值需结合参照和当前项目合同提前记录。

## 适用与限制

适合已授权的几何生成、材料分离和依赖追踪。真实 DEM 不接受本卡触发的数值重建。Human 不导入第三方权威网格。Aircraft 保护既定权威资产。无法取得正确参照的历史构造保留 unknown。
