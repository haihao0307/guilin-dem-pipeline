# 几何求值上下文技能卡

R1 初始样卡。来源：SKILL_INDEX.md 中 Blender Fields、Attributes、Instances 官方英文索引。官方搜索正文已读取；页面直读接口返回 402。全文补读和 Blender 实际运行均 not_run。

## 来源核心

Blender 的 field 表达可在几何上下文中求值的计算。不同求值位置可能读取不同或已改变的几何。实例引用与复制完整几何具有不同的数据语义；后续操作是否要求实体几何，应逐项查证。

## 本轮提炼的方法

每个依赖位置、法线、选择或 id 的操作，都记录求值时刻、几何组件、属性域与坐标系。保留实例语义，只有后续操作确实需要时才实体化，并重新检查属性和成本。

输入：来源几何、空间变换、字段定义、字段求值域、实例及其标识。输出：求值结果、实例/实体几何说明、单位与方向检查、前后数据差异。

有限步骤：冻结一个本线简化对象；画出变换前后数据流；分别在不同位置读取字段；对比结果；说明哪种结果符合任务；记录潜在法线、尺度、拓扑和属性变化。此处不要求引入外部网格。

## 理解题

同一个读取位置的字段，在平移之前与之后求值，为什么可能得到不同结果？对象局部空间和世界空间混用会怎样影响接触检查？为了省内存保留实例时，哪些修改不能直接假定只影响单个实例？

## 试验设计

执行者选择两个不同变换的自建对象，给出字段求值前的预测，再用数值读回验证。对实例化与实体化版本分别记录对象数量、几何数量、属性域、内存和视觉结果。正确性与速度分别报告。

骨骼与动画主题在本轮作为后续分卡任务：验证关节中心、局部到世界变换和连续状态，不用缩放骨骼修比例，不让显示层写回姿势权威。单帧正常不能证明坐下、起立、落地和休息转换正常。

## 失效条件

求值域、源几何版本或空间约定不明；导出后发生意外缩放/轴向变化；实例共享数据被误改；只凭渲染图确认拓扑。遇到这些情况先补记录或缩小结论。
