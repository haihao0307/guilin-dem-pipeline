# 地貌尺度与过程技能卡

R1 初始样卡。来源：Gaea 2 Erosion2 官方正文；旧 Erosion 1.3 页仅作历史对照。软件执行、本项目形态改善、跨对象复用均 not_run。

## 来源核心

Erosion2 暴露持续时间、侵蚀尺度、下切、沉积和方向降水等控制。旧 Erosion 文档描述了不同的节点参数、数据输出和并行确定性限制。不同节点代际的说明需要单独保留，不能合并为统一软件事实。

## 本轮提炼的方法

先确定对象、参照、空间尺度与主形，再引入一个可解释的过程变量；侵蚀、输运、沉积、材料显示分别保留语义。软件参数到自然过程的映射属于建模假设，需要项目证据和实测检验。

输入：非 canonical 的生成样本、范围与尺度、基础形态、岩性/降水等假设、种子和节点/生成器版本。输出：生成形态、过程标量或掩膜及其明确意义、固定视角对照与成本。

有限步骤：保留原始主形；确定一个过程变量；冻结相机/尺度/灯光；比较修改前后轮廓、峰谷组织和局部结构；检查不同分辨率下主形是否漂移；最后单独检查色彩与材质。禁止用更强噪声、浓雾或换光照掩盖主形问题。

## 理解题

生成地貌更像照片是否允许替换实测 DEM？为什么表面细节增加仍可能让喀斯特峰体显得软塌？一个 flow 或 wear 图能否直接当作真实河道或任意材质颜色？两个版本的节点同名参数是否保证等价？

## 试验设计

只用隔离的生成样本，至少保留一个无新增侵蚀的对照。一次改变一个变量并预先写出可观测预测。换分辨率时比较同一物理范围，登记地形尺度、采样间距和误差指标；不要把更密网格等同更高观测精度。准备宣称方法可复用时，另取未参与调参的峰体。

## 来源冲突与限制

Erosion2 官方页末尾 Slope/Altitude 描述疑似互换，暂不采纳这两行作为参数定义；需实际节点与其他官方说明核验。官方性能宣传未在本项目复现。对山体洞穴、悬挑等表示能力另作诊断，不预设单值地形表示能承载任意结构。

## 真值边界

Landscape 的获准程序化学习可以继续。真实桂林/温州 DEM 只按各自当前合同工作：不修改 canonical、高程数值、AOI 和哈希，不作 NoData 填洞、手工河流、30 米替代，不恢复被禁止的 Gaea 生产路线。资料学习与生产准入分别记录。
