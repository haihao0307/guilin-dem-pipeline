# 统一函数体系的地形章节

日期：2026-09-06。所属入口：[DISTILLATION_CORE.md](DISTILLATION_CORE.md)。本章将用户的新地形资料收敛为同一核心的地形表示、拟合和求值规则，不建立第二条生产系统。

## 本轮目标与范围

用户明确“无限放大”是形容，目标是实际屏幕和观看距离下的细腻表现；不新增无限精度、无限近景或无限细节的工程要求。重点研究用紧凑函数记住稳定的山体结构，按实际画面分配计算，并改善Landscape主形推进。当前为研究设计与隔离CPU诊断，没有改动真实DEM、生产代码、几何、LOD、当前工作台或人工验收状态。

## 收敛为我们自己的表示

地形主定义使用世界位置和稳定配方，不依赖相机、帧序或当前屏幕大小。普通地表可用H(x,z)表示；洞穴、悬挑及多值竖直结构按需要使用三维隐式场或既定几何表示，保持同一身份和坐标合同。任意高度差函数不能未经界限分析直接当有符号距离用于安全步进。

先保存有意义的结构，再组织细节。结构可以包含峰顶、鞍部、山脊轴线、谷线、峰脚轮廓、陡壁过渡以及它们的连接关系。每项带尺度、截面和局部作用范围。噪声、脊状组合与域扭曲应受这些结构约束；不能默认所有峰脚彼此断开，也不能因为“峰丛”名称就强行连接全部底座。

候选表达为：H(x,z)=结构函数(x,z;theta)+受约束的细节(x,z;seed)+必要修正(x,z)。局部功能可以用可组合原语实现，参数与计算代码分开。原始参考没有支持的洞穴、河道和坡度不得变成真值记录。

对于生成场景，参数由地貌参照和当前任务确定。对于已有真实坐标数据，先做逆向拟合：让数据约束函数参数，再评价误差并保存必要修正。不能只选种子后说它已经记住原数据。无损目标保留全部原值与NoData语义，剩余信息由修正编码承载；允许误差的显示版本须先明确其授权和误差界限。两者共用核心，但结果标签与用途分开。

## 屏幕决定求值精度，世界定义保持不动

将queryTerrain(worldPosition)与evaluateVisibleTerrain(camera,pixelFootprint)分开。相机决定取样位置与显示预算，不决定山峰的位置、基础高程或连接关系。不同机位、屏幕尺寸和运行时应查询同一地形。实际渲染需要正确深度、遮挡、法线和场景对象交互，不能只把山形颜色画在屏幕上作为三维完成证据。

粗到细按每一像素对应的世界范围判断贡献，允许对不可分辨细节做过滤或统计替代，避免全区提前展开。轮廓、遮挡、阴影和局部法线需要额外预算，不能只看单个高程振幅是否小于一个像素。频带切换应连续，静态几何身份不能因相机移动而漂移。

脊状项通常非零均值，截掉高频时可能要保留平均贡献或其他统计量；未经计算不能沿用零均值噪声的删项规则。细小起伏可以有较大斜率，远景光照仍需考虑聚合响应。已有零LOD/固定几何/零贴图约束继续有效，本轮仅研究函数求值与显示过滤，没有批准动态几何LOD或把DEM转为高程贴图。

简单针孔示例：画面竖直1080像素、竖直视场60度；误差平行图像平面且处于固定视线深度d时，投影误差为e_px=e_m*1080/(2*d*tan(30度))。1000米处1像素约1.069米，5000米处约5.346米。实际斜视、前后遮挡及投影深度变化需用真实相机检查，不能把这个例子当所有视角的统一阈值。

## Landscape最短改进路径

优先假设“表达原语、结构约束及验收方式不匹配”可能限制主画面，而不继续单纯加噪声层。此处是待验证的方法诊断，本轮只回读Issue 61，未审计Landscape当前运行源码或GPU结果。

下一项建议：从用户现有参照选一个小片区，把峰顶、鞍部、峰脚与遮挡关系写成简洁控制结构；在固定坐标和中性光下生成稳定三维主形；多视角核对后再加入区域细节与正式光照。最终验收仍为可交互三维页面，六视角内部检查只提供证据。不要只交线条、固定镜头雾景或截图。已有正确工作继续，研究结论不直接替换生产基线。

地形编码实验另选一块已有canonical数值样本，比较同一输出范围内的现有编码、函数拟合和函数加修正。分别测全局误差、峰/鞍/岸/谷关键点、结构连通、视图投影误差、实际包体与求值时间。字典、参数、边界、修正和运行依赖都计入成本。当前未取得该样本并执行压缩，不承诺三百MB最终变为某个固定体积。

## 本轮实际CPU诊断

源码：[core-tests/terrain_representation_probe.py](core-tests/terrain_representation_probe.py)。实际执行Python3.13.5、NumPy2.3.5。自建1.6km方形合成高度场，129x129采样、12.5m间距，以棋盘划分8321个拟合点和8320个留出点。数据不含温州或桂林观测。

六个平滑基函数拟合后，留出点RMSE约1.200878米，但最大局部误差18.068537米。补入一个预先给定位置与宽度的狭窄结构基函数后，七系数模型在留出点最大误差约1.14e-13米。源样本刻意由同一扩充函数族生成，因此后一个结果只验证定义内可重建，不能推断一般地形压缩率、自动结构发现或真实DEM无损。系数JSON往返检查通过。局部最大误差在前述5000米针孔示例中约3.38像素，说明平均误差小仍可能遗漏重要结构。

另用解析代理(1-|sin(theta)|)^2核对高频平均值。65536点的平均约0.2267604548，解析值1.5-4/pi约0.2267604553；直接删除它会丢掉非零均值。没有测真实噪声的统计量。

一个振幅0.05m、波长0.1m的正弦细节，在5000m示例中振幅只约0.00935像素，但最大斜率为pi。这只提示不能从位移不可分辨推断光照贡献也为零，没有完成材质或抗混叠渲染验证。

数学诊断不能代替主画面推进。本轮没有生成图像、地形网页或新的生产版本，未运行STTF、ISF、GLSL、浏览器、GPU或实际GIS数据，未完成水文/洞穴/碰撞/动态切换检查。
