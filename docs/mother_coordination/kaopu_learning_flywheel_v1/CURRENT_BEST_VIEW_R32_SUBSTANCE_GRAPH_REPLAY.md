# Current Best View — Substance graph replay R32 candidate

1. Substance contributes a useful parametric-graph discipline, not a replacement for KAOPU semantics or Mother production rules.
2. Separate four identities: editable SBS source, resolved evaluation context, published SBSAR/runtime evaluator, and typed derived output cache.
3. SBSAR can remain dynamic but is one-way; it cannot replace editable-source provenance or support full reconstruction by itself.
4. Graph/node/output Identifier is the machine identity. Label is presentation and may be non-unique.
5. Output size, format, pixel size, tiling and random seed participate in inherited evaluation context. Preserve both lineage and effective resolved values.
6. Physical size is scale metadata, not physical evidence. Output usage tags are interface hints, not proof of semantic correctness.
7. Static parameters may disappear after cooking; do not infer the full source control surface from a runtime package.
8. Substance `$time` is engine uptime. KAOPU world/history time requires an explicit mapping and reversible checkpoint semantics.
9. Rendered textures are derived caches. Existing no-external-texture and pure-function Mother constraints remain unchanged.
10. The R32 linter passed nine tests but no Adobe runtime executed. Candidate only; R1 remains Frozen and production Mothers are unchanged.
