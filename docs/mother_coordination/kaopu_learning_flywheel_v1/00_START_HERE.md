# KAOPU Learning Flywheel R1

This coordination area is the persistent learning state for 小妈 / Judgment.

It is not a production Mother and must not directly modify production Mother branches.

Core loop:
1. read current GitHub state and unresolved questions;
2. choose one high-value question;
3. learn from primary human sources, mature tools, public code, and external AI candidate interpretations;
4. separate independent Observation Roots and verify important claims;
5. distill transferable methods, assumptions, failure modes, tests, and tools;
6. route only relevant knowledge to the responsible Mother;
7. read Mother feedback and update Current Best View;
8. preserve Unknown, Conflict, Rejected, Candidate, Frozen states explicitly.

External AI agreement is not independent evidence by itself.
Newer is not automatically better.
Faster research is not allowed to reduce evidence quality.
