## Why this is new but not a new regression family

The fresh user correction is to preserve the current pure-function excavator in a small reusable file, including actions and excluding old teacher/reference assets.

Existing Current Best View already contains the parts of the answer:

- N285: exact dependency closure and cold replay;

## Candidate

The Task Anchor owns the exact source head, export policy, object/action inventories, behavior graph and numeric size budget. The Delivery Receipt owns only the actual export digest, manifest and observed inventories.
