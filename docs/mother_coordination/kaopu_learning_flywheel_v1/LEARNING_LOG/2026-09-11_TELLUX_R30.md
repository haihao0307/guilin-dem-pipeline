## 先判断适用范围

数字地球 Demo 成立不能推出全球语义正确、真实资料完整、手机流畅或全过程可逆。源码的现成地形入口是 quantized-mesh，不能替代冻结的 Canonical DEM。glTF、外部图像、云形状/天气纹理等路径也不自动符合我们的纯数据与外部资产约束。内部计算缓冲与外部美术资产须分别标记，不能偷换“无贴图”的含义。

WebGPU 明确不渲染体积云；HISM 文档没有单独确认 WebGPU。不能从 WebGL 功能推导 iOS/WebGPU 已具备。仓库还引用两个相邻工作区 `link:` 开发依赖，完整复现 Demo 需要补齐；本轮只运行不需这些依赖的原始 TS 函数和自写候选适配器。

## 可吸收的方法与边界

| 方法 | 固定源码证据 | 靠谱吸收方式与限制 |
|---|---|---|
| 共享请求、失败重试、版本失效 | `src/sampling/AsyncLruCache.ts`、`src/lifecycle/ResourceLifecycle.ts`、`src/tiles/HeightSamplingTilesetPool.ts` | 增加版本化 CPU 缓存候选；切换世界/数据源后旧结果不能回写。生命周期释放不能删除 Object DNA 身份和证据。 |
| 分簇、簇级 LOD、实例拾取 | `src/hism/core/HismCluster.ts`、`src/hism/spatial/clusterGrid.ts`、`src/hism/picking/HismPicker.ts` | Vegetation/Farmland/静态重复部件可按谱页局部米制空间分桶，保留稳定 Object ID。静态 HISM 不替代 NPC 骨骼与任务系统。 |
| 相机相对高低位位置编码 | `src/rendering/applyRTCInstancing.ts`、`src/utils/EncodedCartesian3.ts` | 只作为渲染精度适配器，权威位置不改。高低位减法改善精度不等于任意坐标无损；源码注释对低位范围/Float32 精确性的说法不能作为数学证明。 |
| 变形阶段由一个位置管线组织 | `src/hism/pipeline/PositionPipeline.ts`、`stages/windSwayStage.ts`、`stages/rtcPositionStage.ts` | 局部形变→实例变换→相机相对变换→投影；避免 Mother 互相覆盖 shader。GLSL 注入不能直接迁移 WebGPU。 |
| 显示预算与世界状态分离 | `src/rendering/cloudAltitudeFade.ts`、`PostProcessingManager.ts` | 淡出后卸昂贵 pass，恢复带回差；不能把云的显示淡出记录成天气消失。20/40/38 km 是该实现参数，不是各 Mother 通用阈值。 |
| 光照输入类型与单一渲染图 | `src/rendering/LightingMaskPass.ts`、`WebGPUPostProcessingManager.ts`、`AtmosphereManager.ts` | 区分 albedo、已受光 radiance、自发光，避免太阳重复计算；一个渲染图拥有最终输出，各 Mother 注册阶段与缓冲需求。 |
| 统一时钟入口但显式区分时间 | `src/Clock.ts`、`src/Viewer.ts` | 谱时间、渲染 delta 与历史积累不能混用。Tellux 天体跟随 Clock，而其他更新仍吃真实 delta；负倍率不能证明云、NPC 和历史状态可逆。 |
| 显示采样与数据采样分开 | `src/sampling/HeightSampler.ts`、`QuantizedMeshTerrainSampler.ts` | 人眼相机相对显示表面 1.600 m 与 Canonical 地形正确性分开验。量化网格的最细采样仍不是原始 DEM；无覆盖时的近邻均值和显示回退不能进入真值查询。 |

HISM 还存在需要保留的范围限制：簇中心决定 LOD，动态增删单实例需重建；当前簇 mesh 不投射/接收阴影；其基准大规模模式跳过地形采样并使用高度 0。不能用这类简化基准证明“真实地形、密林、完整阴影、手机”一起流畅。

## 实际复现与改进

直接导入锁定源文件运行，未改 Tellux：

1. 容量 2 的 AsyncLruCache，最老请求保持 pending，再完成十个 key，`size=11`。原因是 trim 遇到最老 pending 直接返回，后续 settled 无法淘汰。
2. HISM 局部经度差计算对 179.9°→−179.9° 返回约 −40,052,753 m，均值参考经度为 0°。证明该局部公式不可作全球谱地址，不证明整个 Tellux 地球渲染失败。
3. 云 pass 在 39 km 时保留或关闭取决于此前状态，下降到 37,999 m 才重新启用；说明回差逻辑成立，不是 GPU 节省实测。
4. 同步构造失败倒序清理，单项清理抛错不阻止后续释放。

`ADAPTERS/revision_cache_r30.mjs` 是本轮融入靠谱的可运行候选：sourceId+sourceRevision+queryKey 去重；pending 与 settled 分开；已完成缓存受条目数和声明字节数限制；失败允许重试；失效代际拒绝迟到结果。忽略 abort 的请求仍占并发名额，直到真的结束。超大值可返回但不缓存。

范围：字节数由调用者声明，不是进程峰值或 GPU 显存实测；不管理 GPU dispose；不提供逐消费者取消；不自动超时，loader 必须在真实接入时有超时策略。返回值视为不可变，不代表通用对象持久库。未知坐标或缺失高程不能由缓存补默认值。
