### Landscape：闭合坐标接缝不是美术问题

已读 `feature/landscape-microscope-geometry-lab-r1-20260916@4e1c893b2b07d8b32551b0144b1dbd7507113680` 的 `workbenches/landscape-microscope-geometry-r1/index.html`，blob `b1e1307a082272702251237cfbb7dcbf7c98b6e8`。

`mappedDetail`在闭合圆周参数中使用 `sin(th*2.3+y*.07)`。同一位置的 `th=0` 与 `th=2π` 因2.3不是整数而给出不同域变换。对所读数学片段，保持同一位置、默认scale/direction/warp与六层，200个样本中的最大内核接缝差约0.1294863972（无量纲场值，不是米）。这是坐标单值性缺陷；未做整张HTML/GPU或全部网格的视觉复现，不把它宣布为所有历史狗牙的唯一根因。

改用整数谐波2的候选片段，测试接缝差小于8e-16；逼近接缝时差异随间距减小，原片段则趋于非零跳变。每层共同减去的均值在该差值中抵消，探针省略它们；不能据此说原均值估计已正确，也不能说整数2就是唯一或完整修复。
