# KAOPU Learning Current Best View R1

Status: Candidate coordination policy. Not formal KAOPU R2.

1. Continuous learning must be problem-driven, not novelty-driven.
2. External AI output is a candidate interpretation, not an independent Observation Root.
3. Important claims should be checked against primary documentation, source code, papers, datasets, or reproducible experiments.
4. Learning speed is subordinate to provenance, independence, reversibility, and explicit Unknown handling.
5. Production Mother branches remain outside this coordination loop. Knowledge is routed to them; production changes remain their responsibility.
6. GitHub is the persistent state machine: learning queue, current best view, unknown/conflicts, tool registry, routing, and freeze ledger should survive any chat/session boundary.
7. Mature external systems are studied for transferable mechanisms, not copied wholesale.
8. Stable and experimental knowledge must remain separated. Candidate knowledge can move quickly; Frozen knowledge changes only by append-only versioning and explicit Judgment.
9. Determinism is an evaluation-contract property, not a bare boolean. A reproducibility claim must bind at least implementation/tool version, resolution/grid, seed, context/boundary policy, and execution mode. Cross-resolution equivalence is a separate property requiring separate evidence.
10. Every distributed world operator should expose a context/locality signature: local, neighborhood with required halo/radius, or global; normalization and seed scope must also be explicit. Independent page/tile scheduling is allowed only when the required context exists.
11. Global/world-stage work and local/detail-stage work should remain distinct. Baking or otherwise locking a world-consistent upstream result can be valid engineering, but presentation seam blending never proves shared truth continuity.
12. A focused high-resolution Region should normally remain a different evaluation/view of the same world graph/score, not a new truth identity or Observation Root merely because its resolution differs.
13. Tool/operator version migration is an evidence event. Vendor compatibility guidance is useful but insufficient for Frozen promotion; locked regression fixtures must test the actual project contract.
14. “Better noise” has no valid global ordering. Basis choice must be scoped to a task and metric such as derivative quality, tiling, morphology, runtime cost, temporal stability, sampling stability, or downstream physical semantics.
15. Evaluation footprint and filter policy are first-class field-operator properties. High-frequency procedural detail must not be allowed to alias into different apparent world structure merely because camera distance, page resolution, or sampling density changes.
16. Noise basis and spectral/fractal composition law are separate properties. Perlin/Simplex/Worley/etc. identify a basis family; additive fBM, multiplicative multifractal, hybrid, ridged, heterogeneous, or custom octave coupling identifies how scales interact. Both must be preserved.
17. Differential capability is a first-class operator capability. If an implementation natively provides gradients or a vector-field construction such as curl, that capability and its continuity assumptions should be recorded rather than silently reconstructed downstream.
18. Normalization, procedural runtime evaluation, and baking/caching must be explicit evaluation policies. A bake can be a reproducible derived cache of a locked graph, but it is never a new truth identity or Observation Root and must retain graph/tool/version provenance.
19. Atmosphere truth/state and atmosphere evaluation/rendering policy must be separate. LUTs, ray-march step size, sample count, scattering-depth approximations, fitted models, caches, and quality modes are evaluator choices, not new physical truth identities.
20. A world-scale atmosphere should be represented in an explicit planet/reference frame with physical units, reference surface/radius, vertical domain, and time. A sky dome, HDRI, or background color is only a presentation/evaluation artifact.
21. Atmospheric participating-media semantics should distinguish molecular scattering, aerosol scattering/absorption, additional absorbers, density profiles, phase/anisotropy behavior, transmittance/extinction, and single/multiple scattering. Vendor parameter names and default values are not canonical KAOPU semantics.
22. “Reflection/refraction” is not a valid umbrella replacement for atmospheric radiative transport. Surface reflection enters through boundary/surface coupling such as ground albedo; atmospheric refraction should remain a separate optional physical process until a specific observable such as astronomical refraction or refractive-index-gradient effects requires it.
23. Multiple scattering is a physical transport requirement whose numerical treatment is evaluator policy. UE, Karma, Hillaire, and Bruneton use different approximations/evaluation structures; KAOPU must preserve the distinction between the phenomenon and the method used to estimate it.
24. Clear-air atmosphere, cloud medium, radiant emitters, surface coupling, scene illumination, camera exposure, and display/color transforms must remain separable typed components. A change in exposure or tone mapping must never silently modify atmosphere state.
25. Aerial perspective is fundamentally a path-dependent radiative query, not merely a fog color. Observer altitude, view direction, finite path length, transmittance, and in-scattered radiance are therefore first-class candidates for the KAOPU atmosphere interface.
26. Agreement between mature engines is evidence of useful production-interface convergence, not independent scientific Observation Roots, because their methods can share the same underlying graphics and atmospheric-scattering literature.
27. Dimensional/unit checking and locked reference queries should be promotion gates for physical field operators. Bruneton’s tested reimplementation demonstrates the value of compile-time dimensional homogeneity checks, unit tests, configurable physical inputs, and comparison of realtime approximations against higher-fidelity spectral references.
28. The Karman line is a conventional aviation/space transition marker, not a physical discontinuity in atmosphere truth. KAOPU must not hard-cut density or composition at 100 km merely because a policy boundary exists there.
29. A renderer's finite `Atmospheric Height` or ray-march domain is an evaluator cutoff, not the physical top of the atmosphere. Whole-atmosphere semantics must allow the state to continue through thermosphere and exosphere even when a visual evaluator stops earlier.
30. Lower-atmosphere Rayleigh/Mie/ozone rendering and whole-atmosphere physics are overlapping but non-identical problem domains. Above the mesopause, temperature, species separation, ionization, solar/geomagnetic forcing, neutral winds, and plasma state can become first-class depending on task; one numerical method need not cover all regimes.
31. A "complete spectrum" belongs at the reference-semantic level as wavelength-resolved or explicitly defined spectral-basis state/provenance. RGB is allowed as a runtime evaluator compression or display-space result, but must not silently redefine the physical spectral state. Current HITRAN-style molecular spectroscopy is a candidate reference source for absorption/emission semantics, not a runtime dependency by default.
32. The simplest driveable world atmosphere should therefore be a two-level contract: rich `Reference Atmosphere State / Evidence` → task-specific `State Reducer` → minimal `Runtime Atmosphere Packet` → selected evaluator. The reducer must retain validity range, provenance, units, altitude/time domain, approximation mode, and error/Unknown contract.
33. Evaluator authority is query-scoped, not global. Every atmosphere evaluator should carry a measured validity/error envelope over observer altitude, view geometry, wavelength/spectral basis, scattering approximation, and numerical integration domain. A fast evaluator may be authoritative inside that envelope and lose authority outside it.
34. `stateSource.validityDomain`, `evaluator.validityDomain`, and `conventionalBoundary` are three different concepts. They must never be aliased. The R03 synthetic fixture showed why: a plane-parallel evaluator matched the spherical reference for a vertical ground query but produced ~96% relative transmittance error at 89° view zenith from the same state.
35. Old knowledge is not rejected merely because of age. An old authoritative model can remain valuable as a locked regression Observation Root when its role is explicit. U.S. Standard Atmosphere 1976 is a useful static reference to 1000 km; it must not be misrepresented as current weather truth.
36. Upper-atmosphere state is not a function of altitude alone. Current NRLMSIS 2.1 requires time/location plus solar and geomagnetic drivers and returns changing neutral-species composition and temperature. Extending fixed lower-atmosphere composition ratios upward for convenience is therefore not acceptable as ground-to-space truth.
37. A ground-to-space Earth fixture should be a multi-root reference suite, not one averaged profile. U.S. Standard Atmosphere 1976 and NRLMSIS 2.1 have different roles, query identities, and validity semantics; disagreement between them is not an error until a comparison contract actually aligns those semantics.
38. `ReferenceSampleKey` should be first-class. At minimum it must bind source/model and version, coordinate kind, units, altitude, and every time/location/solar/geomagnetic driver required by the selected state source. Altitude alone is not sufficient identity for a driver-conditioned whole-atmosphere sample.
39. State reduction is allowed to remove dimensions only explicitly. If a reducer converts a time/location/solar/geomagnetic-dependent atmosphere into a simpler runtime packet, it must state which dimensions were fixed, averaged, marginalized, or ignored and carry a corresponding error/Unknown contract.
40. Spectral reference checkpoints require more than wavelength and an absorption value. They should bind spectral-coordinate convention, molecule/isotopologue, line-data provenance, temperature, pressure, line-shape model, column/path state, units, and tolerance. Line-shape choice is an evaluator/property-model decision, not a replacement for spectroscopy provenance.
41. Reproducibility evidence transported through a non-authoritative mirror remains Candidate even when it appears byte-for-byte identical to an official release package. A mirror is not a new independent Observation Root; promotion requires authoritative-source execution or an authoritative hosted run.
42. Missing authenticated data is a valid Unknown, not permission to synthesize constants. In R04, no HITRAN transition parameters were invented when authenticated line retrieval was unavailable; this is the required failure mode for evidence-bearing reference fixtures.
43. `EvidenceClass` must be explicit. A direct measurement, retrieved measurement, empirical/fitted model output, physics-model output, derived cache/product, and synthetic fixture are not interchangeable evidence types even when they expose the same physical quantity and units.
44. Observation Root identity and evidence independence are orthogonal. `independent=true/false` is too coarse; at minimum preserve sample-split independence, instrument/source independence, retrieval dependence on the model under test, and shared-upstream-prior dependence. Unknown dependency edges remain Unknown.
45. A holdout split demonstrates generalization only under its sampling/source contract. It does not automatically create a new independent world Observation Root when the holdout comes from the same instrument/retrieval families used for fitting.
46. A retrieval that consumes fields from the model under test cannot be counted as fully independent confirmation of those borrowed fields. It may still contribute independent information from a new sensor, geometry, temporal coverage, or measured radiance. The dependency graph, not the product name, determines what can be counted independently.
47. Model-interface dimensionality and observational support are separate. The presence of a driver such as local time in a model signature does not prove that every modeled quantity is well constrained along that dimension. `coverageEnvelope` and `supportedDependence` should therefore be per-variable evidence metadata.
48. Primary-source contradictions should be retained at the narrowest affected claim rather than silently repaired or causing wholesale rejection. In R05, the NRL sample README and the 2022 paper disagree on the exact ensemble-15 tuning/validation boundary; that file-membership detail remains Unknown while the broader tuning-versus-validation distinction remains usable.
49. Empirical atmosphere-model output is an inferred reference state summarizing observations plus model assumptions/constraints. It can be an authoritative model output without being reclassified as a direct physical observation.

GAEA study disposition: LQ-GAEA-001 is candidate-complete after R01/R02 primary-source review. Current GAEA 2.3 documentation supports Erosion2 determinism, tiled-build context constraints, same-graph Regions, and migration testing. Exact current legacy TileGate semantics remain Unknown and are deliberately not required by the generalized operator-context abstraction.

Procedural noise study disposition: LQ-NOISE-001 remains candidate-partial after R01. Current primary sources support the contract additions above, but no production Mother has yet demonstrated measurable improvement. Its next gate remains execution of the footprint probe plus at least one Mother-domain cross-resolution fixture.

Atmosphere study disposition: LQ-ATMOSPHERE-001 is the user-prioritized active study and remains candidate-partial after R05. R01 established vendor-independent lower-atmosphere/rendering decomposition; R02 extended the candidate to continuous ground-to-space semantics; R03 added query-scoped evaluator validity evidence; R04 established a multi-root Earth reference architecture and explicit Unknown handling for unavailable authoritative numerical/spectral checkpoints; R05 adds evidence-class and provenance-dependency semantics. Current NASA CCMC still identifies NRLMSIS 2.1 as the hosted model. Primary NRLMSIS development/validation literature shows that model output is empirical inferred state, that original NO observations have limited local-time coverage, and that the later full-local-time SABER NO product reveals structure not represented by current MSIS 2.1 while itself depending on NRLMSIS 2.1 T/O/O2 during retrieval. Thus root identity, independence, coverage, and model dependence must remain separate. No implementation or parameter set is Frozen. The numerical next gate remains authoritative NRLMSIS execution plus a tiny authenticated HITRAN optical checkpoint set, now with mandatory EvidenceClass/dependency/coverage metadata.

Next unresolved study remains LQ-ATMOSPHERE-001 under explicit user priority. LQ-NOISE-001 stays open in parallel as a measurement-gated candidate rather than being silently abandoned.
