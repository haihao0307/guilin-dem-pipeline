# 靠谱（KAOPU）基础声明 R1

Status: User-approved foundational statement for the KAOPU project. This is a project declaration and interpretive foundation, not a claim of scientific final truth. Append-only; do not silently overwrite.

## 核心声明

靠谱不是对真理的宣告，而是一套让人、机器与世界保持在同一律动中，并沿着证据不断逼近真实的共同谱。

更简洁地说：

**靠谱不是一个真理库，而是一份不断向真实靠近、并让不同声部保持共同律动的世界谱。**

## 基本含义

- “靠”不是已经抵达真理，而是不断靠近。任何 Current Best View 都允许在新观察、新证据、新实验和 Judgment 下继续修正。
- “谱”不是某一种文件格式，而是让不同的人、机器、Mother 与 AGO 在不同时间仍能理解并重新演奏同一世界关系的共同语义。
- “律动 / groove”不是简单节拍，而是不同声部在保持自身差异时，仍共享同一个世界的时间感、关系和连续变化。
- 世界不是静态对象集合，而是一场持续发生的大合唱。波、场、对象、事件、关系与证据共同构成这份世界谱。
- 靠谱的目标不是声称完整占有世界，而是尽可能忠实、可追溯、可修正地保存一个地方、一个年代或一个世界状态如何一起发生，使后来者能够重新进入它的关系与节奏。
- Unknown、冲突、残差与证据缺口必须被保留；新证据推翻旧判断并不代表系统失败，而是靠谱继续向真实靠近的正常过程。

## 角色关系

- 谱：回答有哪些声部、它们是什么关系。
- 波：回答这些关系如何连续发生。
- TLO：回答在哪里、什么时候、是什么。
- Object Graph / Event Graph / Evidence Graph：承载不能强行塞入连续场的身份、事件、关系和证据。
- Mother：负责各自声部的生产与实验。
- AGO：负责独立搜索、质疑、对抗和验证。
- 小妈 Judgment：负责判断当前哪一种解释和演奏最接近证据。
- 靠谱：把以上各层放进同一个可持续修正的世界律动中。

## 约束

- 不把“完整传递”当作无条件事实承诺；只有在证据、Unknown、残差和误差边界明确的前提下，才能讨论重建完整度。
- 不把多个 AI 的一致意见当作独立证据；它们只能作为搜索和质疑信号。
- 不把 Frozen 当作绝对真理；Frozen 只是某一阶段经证据和 Judgment 接受的稳定版本，后续只能追加新版本，不得静默覆盖。
