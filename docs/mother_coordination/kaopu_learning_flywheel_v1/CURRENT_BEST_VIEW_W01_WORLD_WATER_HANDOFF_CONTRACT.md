# Current Best View W01 — World water handoff contract

Status: **Candidate partial / official-source contract and CPU continuity verified**

Cross-Mother water exchange should use an immutable directed volume-flux ledger, not a shared scalar. One authorized writer emits each flux with explicit source, destination, quantity/unit, interval, process stage and provenance. A source-measure conversion also has a unique event + interval + spatial-support key; the stage is recorded separately so relabeling a duplicate transformation cannot bypass the collision check.

Keep five layers distinct:

1. Weather forcing depth/intensity and provenance.
2. Landscape runoff/canal-routing derivation.
3. Directed boundary fluxes in volume units.
4. Farmland storage, field transfers and losses/discharge.
5. Presentation state, which is read-only and carries no mass.

The W01 two-field fixture closes both node and system balances and exposes an 18 m³ duplicate-rain counterexample. It verifies accounting structure, not physical hydrology, calibration, runtime integration or adoption.

Frozen R1, Canonical Truth and production Mothers are unchanged.
