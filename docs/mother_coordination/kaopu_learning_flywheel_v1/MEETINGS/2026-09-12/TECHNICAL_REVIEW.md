# 本轮候选技术补证单
所有新方法均为协调层候选；已运行的CPU反例与未执行的产品/编码器/设备检查分开。此文不更名R33、不修订冻结R1，不是新的完整交接包。

## Gaussian R33：先补互操作证据
现有R33九项probe只含两项真实Three加载器执行（PLY旋转/协方差，以及合成SPZv3的SH4截断）；不代表真实SPZv4编码器到r186链路通过。
随附gaussian_review_counterexamples.py由临时AI编写、主持重跑，Python调用Node保留JS语义。result.json记录的是反例再现，不是生产缺陷判定。

入站候选拒绝清单：
- shDegree必须存在且类型为数值、有限、整数、非负；运行时NaN与原始JSON非法NaN分层处理。上限和文件头/声明一致性随后检查。
- 所选v4/RUB/无扩展/SH<=3只是限定候选profile。v3不符本profile不表示r186不支持v3。
- 合法元数据仍须await真实异步解码；不能只通过声明就标整体验收。
- fractionalBits=12时int24中心范围[-2048,2047.999755859375]是存储单位。按真实舍入后的整数检查越界，不低24位静默截取。toy wrap只是风险演示，不是官方SPZ编码器实测。
- 度量误差必须有正有限metersPerStoredUnit及已验证尺度锚点；未知尺度可看外观，不能报毫米精度。
- log-scale的exp(1/32)-1约3.174%是最近值量化、未饱和的理想相对尺度量化理论界，不是协方差界，也不含Float32/exp/四元数量化等附加误差。CPU反例-11→-10误差171.828%，6→5.9375误差6.059%。
- 本CPU反例采用JS Math.round((v+10)*16)，按未裁剪整数是否在[0,255]内判断饱和；真实编码器半格舍入须核实固定实现，不假定跨语言一致；若允许有损饱和，须逐项误差/裁剪计数，不能隐去。
- 位置量化误差不包含相机求解、训练、尺度锚点误差；不存在“量化预算通过所以重建可测量”的推论。
- 坐标相似变换同步处理位置和Σ′=s²RΣRᵀ，SH1–3方向也须一致；不能只改位置。

真实v4最小fixture（未运行）：
1. 至少两个可区分splat、非均匀scale、非平凡旋转、不同opacity/DC及非零SH1–3；保存浮点输入、RUB/单位/SH排列/quaternion约定、编码器固定提交与哈希。
2. 真实编码器产出v4字节、流目录、扩展标志与日志；不可改v3头冒充v4。
3. 官方解码器与固定Three r186分别解码，比位置/协方差/RGBA/全部SH1–3；预期值不全复用受测加载器公式。
4. 独立通道容差，int24边界/越界、scale未饱和/饱和、声明头不一致、缺失/非法degree、截断流等负控。
5. 即使通过，也只提升固定编码器—加载器CPU互操作；照片重建、训练成本、GPU排序、Safari性能和用户视觉另验。
没有用户照片集时不捏造训练成果，不提议提前淘汰RealityScan。保留照片/姿态、浮点checkpoint、清理历史、交付编码的分离身份。

## Brick：因子隔离而不是一次改一切
依据固定R8源码和既有求助。保留fired对象/seed/geometry/相机轨迹/光照/曝光/viewport/DPR/同一octave身份/相位及原有grain过滤。
首轮固定现有插值vQ，建议顺序三组：A现有顶点scalar+现有过滤；B仅将scalar移至片元、保持同一vQ+现有过滤；C在B上增加候选逐octave过滤。若要测交互项再加顶点scalar+候选过滤一组。vQ本身也由非线性detailCoordinates经顶点烘焙插值；片元重算detailCoordinates(vP)属于第三变量，必须另组。这是实验设计，所有组合均未执行。
近景静止、过渡距离小幅移动、远景回原位分别输出scalar/normal/beauty、连续帧及实际耗时。新增功能关闭恢复A；高频变化不改对象身份、不累积“风化”。事先固定允许误差。
Weather可迁移的是固定谱身份与观察策略分离，不是高度阈值、相关性数值、天气渲染器或接受结论。
TF采样的高频丢失不能被片元导数重建；低频函数项保持也不保证非线性材质映射后的低频图像完全不变。源码没有证明GPU闪烁，也没证明用户评价的唯一原因。
石类仍用vQ但旁路vMM；先可观察性probe，不强塞新scalar进石材生产。pore/reduction已有部分跨通道共享，“零共享mask”不是正确事实。rubble/adobe已认可范围不动。

## Tiles：实际几何接触契约
CPU表达式反例：seed314159经实际JS seed hash并Float32化sid=8.40021800994873；函数输入u=1,t=0,meta.y=1得到dy=0.0007412158935473532源码单位。未证明GPU同值、实际存在该顶点、毫米尺度或接触故障。
最小真实输入：固定生成器/提交、对象ID、seed、完整参数哈希、细分数量、实际顶点/索引、所有实例变换、瓦/椽子/船子支承对象、共同坐标系与单位。
先定义语义支承集、被接触支承面和有依据的容差，再报告每个真实顶点ID/三角形/世界位置/支承ID/对应点/法向有符号gap/容差及pass-fail，汇总最大正间隙/穿透/输入输出哈希。
若表达式样点非实际顶点，明确说明并检测实际边/三角形；不以手工样点替换生产mesh来使测试通过。法向投影仅验证规定接触，不替代全方向碰撞。
真实CPU网格检查、GPU检查、视觉接受分别标记，不由CPU直接晋级。

## 共同边界
R31的重复filter gate不是已判定bug；必须实测累计响应。R32的材质graph/source、resolved context、runtime evaluator、derived cache身份继续分离；engine uptime不是世界历史时间。新学习不替代靠谱语义，不导入外部纹理/网格，不修改生产或冻结资产。
