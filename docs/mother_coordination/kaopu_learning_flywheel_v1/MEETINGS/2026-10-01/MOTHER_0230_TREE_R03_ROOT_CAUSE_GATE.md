## 3. 明确决定与有限方法

R04 不允许直接开始“更复杂的树”。先由协调端冻结一个最小 Tree Task Anchor，只覆盖三个可否证关系：

1. **juvenile topology**：低年龄必须减少/改变拓扑与芽状态，不能只是成年树等比缩小；
2. **independent root grammar**：根和 shoot 使用不同的分叉角、长度、直径与环境响应，关掉 soil field 时行为变化可解释；
3. **continuous collar**：Seed—root collar—trunk 在 truth layer 连续，固定剖面/多视角不得出现硬断。

每项先绑定一个来源事实、一个对照和一个否定条件。只有这三项通过，才允许继续 crown、bark、leaf、material、wind；不能用后续声部掩盖基础形体。
