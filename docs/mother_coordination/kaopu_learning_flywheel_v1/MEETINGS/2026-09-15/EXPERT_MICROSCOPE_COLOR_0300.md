## 当前最好有条件结论

### 1. B是开放任务域的语义底线，A不是天然错误

当任务不预先排除材料历史、运输、覆盖、混合或未来环境响应时，至少区分：

1. 物理表面及嵌入：`S, X:S→R³`；
2. 材料身份及其与表面位置的对应：`P, m_t:P→S_t`，并注明方向、有效域和是否允许多对一；
3. 具有稳定身份的尺度场：物理/参考尺度、方向、载体、权重和组合规则；不能以数组下标代替尺度意义；
4. 相对于明确问题、允许未来条件、时间范围和误差容限的候选充分状态 `H*`；
5. 机理变量 `Z`；
6. 材料本征光学响应 `R`（例如光谱/BSDF层面）；
7. 给定几何、照明、观察和显示变换后的颜色 `C`。

候选依赖骨架可写为：

`(历史,环境) -> H* -> Z`  
`(尺度几何场,Z) -> X`  
`Z -> R`  
`(X,R,照明,视角,显示) -> C`

这些箭头只是待举证的依赖假说，不是已确认因果律。世界坐标回答“在哪里取值”，不能单独回答“为什么具有这种材料响应”。

A可作为B的无损、冗余或压缩实现；共享坐标或共享数组本身不决定信息量。设B的相关状态为 `b`、A的编码为 `T(b)`、允许条件为 `c`、目标输出为 `O_c`，则任务内无损至少要求：

`T(b1)=T(b2) => O_c(b1)=O_c(b2)`

对全部已声明的允许条件 `c` 成立。若只检当前颜色，这不保证未来演化、历史查询或受热后的响应无损。严格任务信息等价应恢复“与任务有关的状态等价类”，不要求恢复与任何输出和演化均无关的原始编号。

### 2. 三个最小反例

**几何相同、历史状态不同。**  
固定同一表面、坐标、六尺度场和权重；两段历史留下不同且与目标光学响应相关的状态 `Z_0≠Z_1`，但不改当前几何。若A只含当前几何/坐标/几何权重，它必给相同响应，无法区分。此例只证明信息可能缺失；并不声称Landscape已有这种物理过程。历史名称不同但目标响应相同，不构成反例。

**材料相同、仅换坐标图。**  
同一物理位置以 `u=s` 与 `v=2s` 表示。若场在u图为 `f_u(u)=cos(2πu)`，正确换图是 `f_v(v)=f_u(v/2)`。机械复用 `cos(2πv)` 会令同一材料点在 `s=1/4` 处由0变成−1。错误来自把坐标数值当物理场身份；正确使用世界场或pullback的A也能通过此测试。

**当前输出相同、未来条件不同。**  
两段历史当前几何与反射响应均相同，但施加同一允许受热条件后，一个状态输出0、另一个输出1。只以当前观测定义 `H*` 会错误合并二者。反过来，若任务明确永不包含受热条件，则该差异可不保存。

### 3. 重排必须区分“记录顺序”和“物理次序”

携带完整尺度身份、参数和依赖关系后，仅改变记录排列，语义输出应不变。若层间操作代表真实事件且不可交换，必须显式记录物理偏序/时间，不能借数组位置或着色器求值顺序暗代历史。

最小算术例：从0开始，“先加1再乘2”得2，“先乘2再加1”得1。改变真实事件次序可以改变结果；仅把记录列表排序而保留原依赖关系，不应改变结果。浮点累加顺序还可能引入数值差异，须与语义差异分开。

### 4. 需要保留的检查合同

- **换图协变**：同一物理点上的标量不变；方向、向量、张量、尺度参数按相应规则变换。
- **材料重标号一致**：状态随同一材料身份续接；网格变化不得创造材料历史。
- **尺度身份稳定**：六扩十七是模型扩充，不是记录重排。每层须带尺度/方向/载体/单位或无量纲依据。
- **存储重排不变**：重排记录同时重排其身份和依赖，结果在声明数值容限内不变；真实事件次序另存。
- **网格独立**：连续语义先于顶点编号；离散结果需带误差或收敛范围。高频层可能混叠，单次加密相近仍非认证。
- **光学与显示分离**：位置颜色函数只能在固定照明、视角和可见样本下描述当前图像；镜面/方向性响应反证一般颜色不是位置的单值函数。
- **冻结边界**：上述学习不改变已确认R5.K2大形和现有六尺度候选；真实几何、求交和采样继续独立验收。

## 对A/B的最终判断

- 若任务明确固定材料状态、照明、观察和未来条件，仅需一张程序配色，B的全部历史语义并非最小必需，A可充分。
- 若不同材料历史或未来条件可能要求不同输出，A必须显式保留这些相关状态；做到这一点时，它实际上实现了B的语义分层。
- B也可能不足：状态漏项、材料对应错误、多材料混合缺比例、所谓机理变量只是代理、或光学映射错误，都会失败。“多一张表”不等于物理真实。
- `H*`目前只是定义目标，不是已找到的有限、稳定、可测、可计算状态。把巨大历史编码进一个实数不算可操作方案。

两位专家没有路线性分歧。唯一批评轮实际收紧了四点：最小性必须相对任务域；无损条件要量化全部允许条件；记录重排不等于物理事件重排；静态位置配色必须冻结照明与视角。

在不修改生产的前提下，Landscape后续若真实接收方法，可先为现有六尺度逐项填一张知识表：

- 尺度身份与单位/参考长度；
