## 5. 最小解除实验

Coral 责任端下一次只需交一个短、机器可读的 R03 阶段包：

1. Task Anchor 绑定 `taskMode=ADAPTATION_AUTHORIZED`、精确 transfer base、当前 head、`targetObject=[branch, blue]`、其它形态本阶段 forbidden；
2. 对 source snapshot tree `2086790b…` 做 readback，证明历史输入未被改写；
3. 在同一精确 head 上证明真实 `WebGL/WebGL2` context、READY、零 fatal error、一次 orbit/形态切换关键交互；
4. 同一 head 生成桌面与 390×844 evidence，并由独立 verifier 写 receipt；
5. Reference Fidelity 只比较鹿角式树状与蓝珊瑚，不把高饱和、三角面数或对象数量当形态通过；
6. 用户最终 standalone 单 HTML、物理设备与公网镜像分别验证，不拿本地 Xvfb 互相替代。

该实验通过只能把 R03 推到 `CANDIDATE_READY`；用户视觉接受后才能成为 `ACCEPTED_BASELINE`。
