- 保持原CPU海床：21,025个坐标实际运行前后相等，含620个孔洞有效点；区域之外代码逐字不变。
- 11项鱼导航确定性检查通过；继承PR81对实际三角海床、岩体/棚体净空、连通水域退避和稳定鱼ID的修复。
- 公网普通入口和完整鱼行为浏览器检查正在运行；只有最终PUBLICATION_PROOF.shareAllowed=true才可交付。
- 该改动只统一五个已有坑的定义。没有新增整片照片式礁盘，没有新增真实悬顶/拱洞、20组鱼、新珊瑚群或植物资产。现有坑深参数3.9–5.8是原创参数，不是照片中的30–50米实测洞。
- CPU双精度与GPU浮点、解析海床与渲染三角形插值仍不同；“相同坑定义”不能写成全物理/光学查询完全一致。
- GPU着色不等于真实水色机理已经验收。白沙、珊瑚/岩基底、深度、照明和水体共同影响外观；不得只用一张深浅色纹理宣称真实深洞。

## 原始资料与适用限制
- NOAA 珊瑚礁分区：https://oceanservice.noaa.gov/education/tutorial_corals/coral04_reefs.html 。礁坪、礁脊与向海外坡的通用关系，受水深、波流、光照等影响；不证明本岛每处地形。
- NOAA NCCOS 帕劳浅水底栖栖息地元数据（PacIOOS分发）：https://www.pacioos.hawaii.edu/metadata/pw_noaa_all_benthic_habitats.html 。分开地理分区、地貌结构、底栖覆盖；小于30米浅水产品、约1英亩最小制图单元，不是连续测深，也不能确认40–50米洞或细小珊瑚。
- CRRF 测深：https://coralreefpalau.org/projects/bathymetric-mapping/ 。近岸与外礁坡多波束工作可供理解测量方法；本轮未确认对用户照片具体位置的覆盖。
- CRRF 陆地环境：https://coralreefpalau.org/terrestrial-environments/ 。Babeldaob森林、红树林等监测，不能迁移成Stone Money Island具体树高数据。
- CRRF 航拍方法：https://coralreefpalau.org/research/imagery-technology/aerial-photography/ 。垂直影像用于制图、斜视用于观察形态；当前照片缺度量标定。
