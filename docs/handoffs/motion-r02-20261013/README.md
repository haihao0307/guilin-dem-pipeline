## 本轮接入

拇指修正共用于参考握拳/松握与18套拳击及12摘段，左右手分别处理，提供原手型A/B。当前掌指关节连线先投影到掌面，再做向食指/中指外侧的内收与MCP/IP屈曲；修正只动拇指链。真人动捕手指并未实测，走跑自然松手另用明确标注的作者姿态。四指紧握、掌面厚度和接触挤压仍继承原模型限制，不能称完整手部物理。

连续走：CMU16_15，完整步态174–315帧，1.175秒/周期。连续跑：CMU16_35，38–134帧，0.8秒/周期。两者取稳定前进段，尾部与原始前置帧过渡，根位移累计，不每圈归零。提供前进和原地检查；不是把停止片段反复播放。脚掌近竖直时的朝向歧义加入骨盆方向回退，俯仰轴使用同一滤波朝向。周期支撑IK后短离线平滑，最终残差另外计量，不冒称绝对锁足。

新增挥手CMU143_25及伸展CMU143_30，保留真人身体时序；为有限动作，未编造无缝循环或同步打哈欠口型。共57可播放入口，原未迁移旧R2分类继续明确列出。

## 实际核查

候选14项、公网21项通过，页面/着色器错误零。100周期位移累积与原地模式、20处接缝邻域、固定骨长、原人物位置/拓扑/存档、左右手A/B、实际播放/暂停/慢放/逐帧经过检查。20张PNG来自真实WebGL画布，不是生成图。最终走跑、手部和挥手/伸展画面已实际查看。

公网首开19.906秒；新动作准备约293–933毫秒，模型形体重算0次。先前动作/人物/面部加载费用仍存在，不能称全网页秒开。平滑引起的最大支撑踝位移：走5.76mm、跑7.36mm，是最终误差指标而非平滑前IK精度。平地/当前人物之外的地形、体型组合与碰撞未认证。

原公网检查在大量近景读回后的短时播放不足6帧，FPS字段为空且存在5.6755秒长帧；不捏造帧率。另用全新页面进行独立真实时钟采样，原始数据见CLEAN_PLAYBACK.json。其结果也不是用户真实GPU或手机实机认证。

手机仅390×844布局与控件。早先候选手机GPU读回超时保留在REJECTED_CANDIDATE_4.json；本轮没有把失败截图改写成通过。
