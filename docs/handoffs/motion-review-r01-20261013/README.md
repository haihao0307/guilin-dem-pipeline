# 人物动作检查台 R01：交付、完整清单与真实质量

人物是本轮核对的最新R04完整本体；旧总台、旧动作采样器和旧入口不改。新台不使用原动作展示中的旧简化演员替代最新人物。

## 测试与性能

实际公开页面完成65项检查，53个可播放入口；40个全身/手部/拳击入口各采样三处时间，13个面部通道检查。骨长、原始顶点、拓扑、存档、同一表皮和材质保留。报告和10张真实截图在本目录。此结果不是每个动作每一帧的人工视频审阅，也不是艺术质量或物理验收通过。

全身条目准备约34–740毫秒；缓存复用不重建人物，全身条目准备和播放的形体重算为0次。首次人物就绪23.147秒，首次面部选择额外约59.3秒。原模型资产约84MB，面部基底缓存约95.8MB；不能宣称首次秒开。

软件渲染测试约4.9FPS，P95帧间隔3200毫秒，有明显长停顿；CPU提交约0.65毫秒不等于GPU渲染流畅。尚未通过稳定60FPS验收；这也不是用户真实显卡或手机帧率。网页提供本浏览器实时FPS与帧间隔。

第二次公开复测再次完成53入口及60项检查，但最终手机尺寸截图超时，因此整轮未通过，失败报告原样保留。第一轮390×844布局检查通过；从未当作手机实机测试。

## 实际观感和边界

抽查中，行走与拳击大形能够识别，最新耳唇、头部和身体跟随。握拳紧握感仍不足；抱物抽查的手与箱体贴合、支撑感不够，而且没有负载物理。闭眼睑缘与细褶仍不自然。小跳、跑步和停止的触地/缓冲/片段重播边界需要继续验收。循环只是重播来源片段，不是无缝连续行走。

骨骼插值和快速切换不会自动修复原动作、接触、抓握、肌肉体积、服装或碰撞。旧R2的坐、躺、挥手、敬礼、负载搬运等尚未重定向到最新骨架和接触体系，本页灰色列明，不用旧人冒充完成。

- 行走 → 停步 (`walk`)：可播放。CMU 16_33：已有慢走与停止片段。不是无缝循环；观察支撑脚、结束减速及重播复位。
- 跑步 → 急停 (`run`)：可播放。CMU 16_57：已有跑/慢跑后急停。重心与足部接触仍依赖原重定向算法，不是动态平衡模拟。
