## 本轮恢复的真实失败

C4第一次38535391916虽然核心12组和15参数像素测试通过，但独立灯光像素门槛失败。原因是代码修改了被隐藏的顶层旧灯，而实际人物使用嵌套的 foldLights.key/fill/ambient。数值变了不代表画面变了。

最终修复绑定真正可见的原生灯组；在原生控制器执行前撤去上一帧的检查光覆盖，再取得原生状态，绘制时才施加中性检查光。灯光方向、可见性及耳部检查灯不改，原生灯控继续有效。中性光与原灯光可独立切换，新旧皮肤对照保持同一光照。恢复了新头部材质中的原耳部几何遮挡信息。未删除测试或降低精确往返门槛。
