## 这次做出了什么

R02 在已有 S03 后开衩铅笔裙上，把**裙长**和**既有三角后开口的深度**拆成两个独立参数。修改会进入真实纸样操作、材料网格重建、原求解器试穿和最终检查。网页把原款与本次结果并排显示，方便观察改版的实际影响。

本轮复用原项目的冻结人物、原皮肤、对应碰撞源、S03 纸样和数字胚布材料。三维展示使用实际求解后的布面顶点；没有用替身人体、整体缩放衣服或预制效果图代替试穿。

已实现的操作包括：

- **两个独立尺寸。** 裙长变化范围为相对原款 −40 至 +100 mm；开口深度变化为 −40 至 +80 mm，步长均为 10 mm。开口口宽保持 20 mm。腰头、省道、臀部曲线和横向坐标受保护。
- **原款与修改结果并排对照。** 两侧共用观察角度；可以拖动旋转、缩放，并切换正面、侧面、背面和开衩细节视角。
- **真实二维纸样。** 显示裁片轮廓、原款与当前轮廓对照，以及纸样裙长、开口深度和口宽。选择裁片时，对应三维裁片会突出显示。
- **布料与应变视图。** 布料视图保留原外观；应变视图按真实三角形的二维材料坐标到三维位置计算，蓝色表示压缩、红色表示拉伸。也可查看接缝线。
- **明确的作业状态。** 改滑块后先进入待试穿状态；点击重新试穿才计算新结果。取消作业保留上一份完整结果；还原可回到原款。过期结果不得覆盖当前版本。
- **失败结果可观察。** 检查未通过时保留这次真实三维候选，显示具体原因与相交计数，并明确标记不能作为合格试样。

这里的“裙长”是前片的垂直纸样长度，不含腰头；“开口深度”是从纸样下摆到三角顶点的垂直距离。它们不是成衣实测尺寸，也不是缝口长度。

## 怎么试用

1. 打开上方固定版本网页。首屏试样相对原款裙长增加 60 mm、开口深度增加 40 mm；对应前片纸样长度约 69.1 cm、开口深度约 12.6 cm。
2. 先拖动三维观察两侧对照，再切到背面或“开衩细节”。选择一个裁片，确认二维轮廓与三维位置的对应关系。
3. 单独调整裙长，或单独调整开口深度。滑块变化表示待提交的设计意图；当前完成的三维、纸样和诊断仍保留，避免把尚未求解的尺寸当成已完成结果。
4. 点击“重新裁剪与试穿”，等待本次计算完成。计算时间随设备和参数变化；需要中止时可以取消。
5. 完成后同时查看形状、纸样尺寸、最大拉伸、接缝分离、身体距离与相交检查。界面没有独立的“最大压缩”数值卡；需要精确压缩值时查看结果证据。色谱用于定位几何变形，不能单独决定衣物是否合格。
6. 若显示“本次检查未通过”，可继续旋转、放大和观察该候选；状态不会因为它仍可显示而变成通过。需要回到起点时使用还原。

已保存的实际浏览器样本包括裙长 +20 mm／开口变化 0 mm，以及裙长 +100 mm／开口变化 −40 mm。可以用这些尺寸探索操作，但**每一次运行仍以本次真实结果为准**，不能按参数预先指定通过或失败。

## 本轮值得进入自己系统的知识

### 1. 先把设计意图变成独立、可检查的纸样操作

“裙子加长”和“开衩加深”应分别对应明确的几何变化、保护区域和尺寸检查。未来接入自然语言时，可以先生成这样的结构化操作，再执行纸样、网格与试穿验证。当前网页尚未接入自然语言模型。

### 2. 局部改版之后，仍要检查整件衣服

纸样尺寸合法、侧缝等长或应变没有超过门槛，都不能替代最终相交检查。此次真实失败样本中，拉伸与压缩都低于 15% 门槛，仍因布面相交而失败。因此，保持腰部原始纸样控制点并不能免除整体复核，也不能只检查编辑发生的开口附近。

这些观察没有证明某个单独三角划分、某条约束或开口参数就是相交的唯一原因。需要把观察到的结果与尚未验证的因果解释分开记录。

### 3. 检查结论属于具体结果，不能只绑定参数

保存的 +60／+60 mm 案例在 Node 开发环境出现 1 对布面相交；另一次 Chromium 运行生成了不同材料哈希的结果，检查为 0 对并通过。两份结果必须分别保留，不能互相覆盖，也不能按参数给新结果套用旧的 PASS 或 FAIL。

独立对照确认，这些比较样本的三角连接关系一致，部分腰头材料坐标存在极小浮点差异。**这不证明最终物理状态等价，也没有确定差异根因。** 详细记录见 [CHROMIUM_MESH_DIFFERENCE_REVIEW.json](./CHROMIUM_MESH_DIFFERENCE_REVIEW.json)。

系统应把实际纸样与材料哈希、人物身份、操作参数、请求与修订版本、运行环境、求解结果和检查证据一起保存。每份新网格独立执行原有检查；不能修改精度或物理阈值来强求环境之间得到相同结论。

### 4. 允许操作的范围与合格结果集合分开

滑块范围只决定可以提交哪些改版，不代表其中每个组合都已验证通过。失败结果应完整保存、明确标记并可供观察，不能晋级为合格衣物。这样的失败记录本身也是可复用知识。

### 5. 显示指标必须说清楚物理含义

最大拉伸、最大压缩和最大绝对应变是不同指标。色谱显示几何应变，不能称为压力或实测面料应力。指标名称、单位、计算来源与判定用途需要一起约定，避免界面用错含义而误导判断。

### 6. 人体同源需要贯穿显示、碰撞与版本记录

本案例保持冻结人物的可视形体与碰撞源一致，这为独立试验提供了可核对的基础。它不等于已经接入新人物系统的骨架、控制节点、动态蒙皮或统一权威状态。后续合并时仍需要真实的坐标、骨架、比例版本、姿态版本及身体与碰撞身份适配。

完整知识合同与保护范围可在冻结源码中的 [KNOWLEDGE_CONTRACT.json](https://github.com/haihao0307/guilin-dem-pipeline/blob/c5c99dd6e7fb2124435653843c618bc6a4e4c47b/kaopu-tailor-workbench/clo-learning-r02/KNOWLEDGE_CONTRACT.json) 查看。

## 来源与能力边界

学习参考包括[展示帖 1](https://x.com/irinatoxi/status/2112109267788423379)、[展示帖 2](https://x.com/irinatoxi/status/2112265445193486494)以及 [CLO 官方场景接口说明](https://developer.clo3d.com/scenario.html)。展示帖没有公开完整后端，本试验借鉴的是可观察的“纸样编辑—试穿—检查”工作流；**不是原作者私有系统的复刻**，也不宣称已获得其模型、训练方法或内部架构。

本轮保留以下边界：

- 沿用原 `digital-muslin` 数字胚布，面密度 200 g/m²；材料参数尚未经过真实面料标定。
- 沿用原求解工序、迭代次数和检查阈值。工程检查包括拉伸／压缩不超过 15%、完整接缝分离不超过 0.25 mm、身体顶点最小有符号距离不低于 −0.05 mm，以及独立最终三角相交检查。这些工程门槛不能替代实测面料与制造要求。
- 当前检查针对完成后的静态姿态；不构成动态穿着、连续碰撞、自接触响应、多层服装或多人物认证。
- 开口沿用原 20 mm 口宽的三角切口，不包含新建的生产开衩结构、搭门、缝份、折边或制造工艺。
- 参数化纸样通过检查，不等于已证明腰臀合体、真实穿着舒适或可直接生产。
- R02 保持独立，不替换 R01，不合并正在使用的主线。公网验收已经完成；是否整合仍需用户查看实际网页后另行决定。
