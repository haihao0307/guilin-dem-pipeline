KAOPU Mammal Instrument R06

KAOPU_MAMMAL_K5.js is the pure digitigrade-mammal instrument. It contains no cat, dog, wolf, bear or tortoise score and no identity generator.
KAOPU_MAMMAL_PLAYER.html is an empty offline player. Without an external K5 score it creates no animal.
The four .score files are independent object descriptions.

The cat project contributes measured DNA and generic anatomical calculation methods. The dog project contributes a pinned, auditable teacher and source-rights workflow. No external teacher mesh is retained at runtime.
