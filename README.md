# 小桂林无损高程干净生产树

本目录是唯一候选源码，不包含大体量高程或 TIFF。

唯一生产高程是 guilin-canonical-elevation-store-12p5m-v1 的七个裸 int16 分片，统一行优先 SHA256 91154cbe7c29220c9da41efc98105f1d36b614a343636543f7dd230735da079a。

正常构建只读取数值高程。原始 TIFF 由用户在包外保存，本包不携带也不要求它存在。先核对 contracts/PRODUCTION_CONTRACT.json。全部高程验证运行 tests/verify_store.py；生成在线目录运行 tools/build_site.py；真实浏览器验证运行 tests/browser_qa.py。

网页采用一张连续总图，512 数据块后台按需读取。全域 768×768 是显示用原生样本子集，完整 12.5 米样本仍在 canonical 库中。不要将概览网格描述为全域原生密度。

当前修改只整理数据组织、移除旧依赖并修正重复的下游延伸调用。水系使用既有 OSM 线状快照和当前 V6 路线算法。湖泊面、水库面和人工补线均禁止。历史河宽与精细视觉效果仍需验收。

本源码树的 CI 仅构建和验证，不会自动删除线上数据或替用户做视觉批准。

当前交接包为纯数值全量 V2；数值高程仍是同一 canonical V1，七个分片哈希未变。源 TIFF 文件名和哈希仅承担追溯，不参与日常验证或构建。
