# 雨后石境 · 石灰岩 R8

R8 按本轮用户截图修整了洞口和裂隙边缘的犬牙状薄片，增加大小不均的溶窝、浅层状起伏与地面实体起伏，保留 R7 的细孔和显微微法线。入口为自包含 `index.html`，支持全貌、岩壁、显微、洞壁、坡脚、背面、剖面和石材视角；URL 可附 `#cliff` 或 `#micro`。

## 形体修改

- 既有岩体布局继续作为主形。Microscope 的嵌套余弦、对数半径、方向比值和方位角用于局部固定坐标的 5 个形体频段；种子驱动连续域偏移。单个形体核限制在 ±0.85 米，未套用原作整个径向世界，未引入时间或相机坐标。
- 从 Brick Mother 毛石中提炼断续层理和各向异性破碎的组织方式，转换为连续、浅的岩面起伏；坡脚四类源石块仍使用此前接入的原形状函数，重新求支承姿态。
- 溶窝从周期性大小交替改为确定性连续尺寸分布，子窝数量与位置独立变化；本种子登记 173 个大小溶窝候选。登记数量不是独立可见洞口数量，相交及隐没部分可能合并。
- 裂隙、洞口和脱离缺口采用圆滑体积交界。主岩体和脱落块按固定 0.4 米格距采样，再对标量格点做两轮三轴 `[.2,.6,.2]` 滤波，单轴等效 sigma 约 0.358 米，然后提取网格。这是本版固定生成配方，不是运动或距离相关降精度。小于采样能力的薄鳍在提取前被抑制。
- 土体排斥、主岩碰撞、遮蔽和剖面读取同一滤波后的主岩格点。土体为有厚度的三维网格，地面使用同源形体起伏；落石支承及来水随最终网格重算。缺口和脱落块仍共享切割事件，但圆滑侵蚀会移除材料，未声称严格体积守恒或模拟了落下轨迹。
- R7 的 17 项显微导数和细孔函数保留。仅增加稀疏、间断的晶粒细缝，并将同源近表面起伏用于土粒。微法线不代替实际轮廓和接触几何。

## 来源与解释边界

实际重读了 Yohei Nishitsuji 的[原作者文章](https://tympanus.net/codrops/2025/02/18/rendering-the-simulation-theory-exploring-fractals-glsl-and-the-nature-of-reality/)和[作者作品目录](https://yoheinishitsuji.com/)，以及本仓库 `d69783388da628f949ac2407c48e9648c6ac29e5` 的 `docs/mother_coordination/learning-r1-20260905/references/MACROSCOPIC_MICROSCOPE_ROCK_DETAIL.md`。这里只采用数学子表达与受约束的多尺度组织，不将作者的光线累计亮边当作实体裂缝，也不复制完整短码。

Brick Mother 来源仍为 `haihao0307/HOUSE@53a4b0728678e31ba4ebf2a9267a213597d8f226` 的 `experiments/atelier-r4/src/kernel.js` 与 `renderer.js`。本轮重新检查了已接入的种子、层理、各向异性 chip cutter 与表面坐标实现；宏观岩面是对这些组织原则的本地解释。

这是未标定的局部石灰岩外观样板，不是实测葡萄 DEM 或已求解的地质演化。前版用户对微细节的认可不等于本版整体美术验收。`visualApproved=false`、`productionReady=false`；未在实体手机上测性能。

## 复现与检查

`python workbenches/landscape-surface-r8/build.py` 从 SHA256 固定的 R7 生成本版。旧版、七文件核心、truth、contracts、knowledge、pipeline 和 viewer 均不修改。没有图片贴图、外部脚本、预展开网格或设备相关几何。

`node workbenches/landscape-surface-r8/geometry-qa.cjs` 检查真实主岩网格并与 R7 比较，记录于 `geometry-QA.json`。本版 674,904 个主岩三角形，边界边、非流形边、方向不一致边和退化面均为 0。相邻面夹角超过 60° 的边占比从 5.91% 降至 1.39%，超过 90° 的占比从 2.38% 降至 0.45%；这是几何诊断，不是自然程度评分。

浏览器检查运行 `qa.cjs`，通过 `NODE_PATH` 提供 Playwright、`LM_CHROME` 指定浏览器、`LM_QA_OUT` 指定源码树外的内部截图目录。它检查 GLSL 导数、真实三角面拾取、最近缩放、鼠标/触摸操作、所有机位、材质调节后缓冲不变、状态恢复和另一个种子。结果为 `QA.json`；截图仅用于内部复核。当前默认场景缓冲指纹为 `a91a59e3`，主岩位置/索引签名为 `7a795c32:4210b31d`。

七文件核心另行通过自身校验及 16 项策略测试。这些检查与本版浏览器、实体网格检查分开记录。
