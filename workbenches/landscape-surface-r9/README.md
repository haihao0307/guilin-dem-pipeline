# 雨后石境 · 石灰岩 R9

R9 按用户的 R8 截图，保留已经修好的大形与洞唇，增加更接近 Brick Mother 毛石的浅坑、碎蚀肩部和硬朗肌理，保留少量平滑面及原有显微细孔。新增“山顶”机位，可检查苔藓分布；入口支持 `#cliff`、`#summit`、`#micro` 等固定视角。

## 本轮实现

- R8 主体场继续作为底形。固定采样改为 0.32 米，同时调整标量滤波权重，维持约 0.358 米的物理平滑尺度。浅的局部碎蚀在广域平滑后、实体提取前加入，厚度保护抑制对薄岩唇的继续侵蚀。
- 浅坑采用固定三维种子、随机尺寸与方向，使用此前 Brick Mother chip cutter 的多平面组织。场增量上限 0.32 米，不等于真实法向侵蚀深度；该场不是严格距离场。小尺度肩部和孔隙另由固定数值微法线补充，不代替几何轮廓。
- R7 的 17 项显微导数和细孔继续保留。粗、细肌理共存，局部门控保留平滑区域；颜色、材质和相机操作不更改几何。
- 为防止 Float32 转换把相邻交点压成零面积面，距格边端点小于 `1e-5` 比例的交点使用共享格点键。这是固定数值焊接，不是降面或 LOD。
- 小块仍逐件计算支承；只把同类碎屑的绘制缓冲合并，顶点和三角形不删除。最终遮蔽、碰撞、支承和来水重新读取本版几何。

## 苔藓分布依据

美国国家公园资料指出，水分对苔藓生存十分重要，苔藓能在湿润岩石上生长并保留雨后水分。[Acadia](https://www.nps.gov/acad/learn/nature/moss.htm)、[Glacier](https://www.nps.gov/glac/learn/nature/mossesandliverworts.htm)。这不能推出“雨水不能直接淋到的岩面绝不生长”：物种、渗水和局部光照仍可能改变分布。

本版据此作如下未标定的外观近似：从最终表面沿四个向上方向检查遮蔽，结合网格来水；在相连表面邻域平滑受雨和坡向，抑制逐个三角面的显色痕迹。朝上的山顶、台阶及接水凹处提高保湿潜力，背雨且没有来水的面降低；日照略增加干燥，固定空间斑块决定外观的不均匀性。无连接的洞壁不会在邻域平均时交换数据。

未绑定当地物种、气候或地下渗水，也未模拟苔藓生命周期。分布潜力不是植物生物量；日照为既有固定灯光方向。苔藓属于数值表面外观，没有新增植物图片板。

## 复现与证据

`python workbenches/landscape-surface-r9/build.py` 从 SHA256 固定的 R8 构建自包含页面。前版和七文件核心均保持原样；无贴图、无 LOD、无运行时外部资产。微表面不会随相机移动而改变世界身份。

`geometry-qa.cjs` 实际生成 R8 和 R9 主岩网格，检查封闭性、方向、退化面、逆序查询和体积变化。R9 主岩有 1,086,412 个三角形，签名为 `0be170af:39f5229e`；边界边、非流形边、方向不一致边和退化面均为 0。主岩体积从 35,255.69 变为 35,032.25 个本地立方单位，变化约 −0.634%。超过 60° 的相邻面夹角占比约 1.217%，仍低于 R8 的 1.390%，没有为增加粗糙度重新制造成排尖折边。这些指标不是自然程度评分。

`qa.cjs` 通过真实 HTTP 浏览器运行，检查 GLSL、真实面拾取、鼠标/触摸、全部机位、最近缩放、材质与相机缓冲不变、状态恢复、另一种子、支承和受雨分区。Playwright 由 `NODE_PATH` 提供，`LM_CHROME` 可指定浏览器，`LM_QA_OUT` 必须指向源码树外的内部截图目录。结果记录于 `QA.json`；图片只用于内部检查，不是三维交付物。

七文件核心另行通过自身校验和 16 项策略测试。实体手机性能、当地生态及最终美术验收未获验证；`visualApproved=false`、`productionReady=false`。
