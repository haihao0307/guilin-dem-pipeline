# Coral Mother R06-T02 分类约束

本阶段不再建立自定义珊瑚类别。

## 当前对象

- Scientific name: `Pocillopora damicornis`
- Formal taxonomy: Animalia → Cnidaria → Anthozoa → Scleractinia → Pocilloporidae → Pocillopora → P. damicornis
- NOAA broad type: `Hard / stony coral`
- NOAA growth form: `Branching Coral`
- Palau occurrence evidence: `UNRESOLVED`

“紧凑团块、短粗分枝、疣突丰富、钝端”只作为形态描述；不得升级成“菜花珊瑚类”。

## NOAA 生长形态

硬珊瑚工作台只能使用 NOAA 教程名称：

- Branching Coral
- Pillar Coral
- Table Coral
- Elkhorn Coral
- Foliose Coral
- Encrusting Coral
- Massive Coral
- Mushroom Coral

软珊瑚按 NOAA broad growth forms 记录为 Encrusting 或 Branching；tree-like、bush-like、fan-like、whip-like 只作为外观描述。

## Palau 语境

CRRF：Palau 主岛群石珊瑚估计约 310 种，西南岛屿约再增加 20 种，软珊瑚详细记录接近 150 种。约 60–75 m 以下造礁珊瑚开始下降并进入深礁／坡地群落；约 90–100 m primnoid gorgonians 首次出现。

PICRC 的 coral coverage、water temperature、fish biomass、invertebrate biomass 属生态监测字段，不替代物种分类。
