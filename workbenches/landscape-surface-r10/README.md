# 雨后石境 · 石灰岩 R10

本版解决 R9 远看仍有同向重复、圆润主形中缺少清晰断面的问题。入口是自包含 `index.html`，支持岩壁、全貌、山顶、背面、洞壁、显微等机位。

## 空间组织与断面

上一版的小物件扭转带有原点附近的范围衰减，用在大岩体上时，上部的变化减弱；浅坑也主要绕单一轴旋转。R10 为大岩体建立遍及全部表面的坐标变换，使用两次不同轴的旋转和连续的空间偏移，不依赖相机、时间或离原点的距离。

实体碎蚀分成粗、细两层，采用不同尺度、相位和基底旋转，各单元再使用完整三维四元数朝向。尺寸、长宽比、深度和出现位置独立变化。材质中的四层余弦复合也各自旋转并错开倍率，降低规则条带；坡脚来源石材仍保留其既有坐标方法。

粗尺度切削用多平面肩部与平坦坑底，细尺度补充碎蚀。它们在 R9 的圆润基底场完成后、网格提取前进入实际标量体积。根据局部场梯度缩放切削增量，并向表面内部探测厚度，以保护薄岩唇。较大的转折由三维几何承担，近表面微法线不代替轮廓。R7 的 17 项显微导数和细孔函数继续保留。

固定 0.32 米采样、约 0.358 米的广域平滑尺度和共享格点焊接继续使用。碎屑逐件求支承后合并绘制缓冲，不删除顶点或三角形。受雨、来水、苔藓和遮蔽均读取本版最终表面。

## 复现与检查

`python workbenches/landscape-surface-r10/build.py` 从 SHA256 固定的 R9 生成本版；前版、七文件核心及共享真值目录不修改。页面没有图片贴图、运行时外部资产或 LOD。

`geometry-qa.cjs` 实际生成 R9 和 R10 主岩网格，检查封闭性、方向、退化面、体积和逆序查询。R10 主岩 1,129,202 个三角形，位置/索引签名 `01481684:f88c6a7b`；边界边、非流形边、方向不一致边和退化面均为 0。主岩体积约为 R9 的 97.75%。100 个实际单元旋转的正交误差最大为 `8.88e-16`，行列式为正，确认朝向不再局限于竖轴旋转。这不是重复感或美术质量的自动评分。

`qa.cjs` 使用 Playwright 和真实 HTTP 检查 GLSL 导数、实际三角面拾取、所有机位、最近缩放、触摸、材质/相机缓冲不变、状态恢复、另一种子、支承、来水和山顶/洞顶分区。用 `NODE_PATH` 提供 Playwright，`LM_CHROME` 指定浏览器，`LM_QA_OUT` 指向源码树外的内部截图目录。结果为 `QA.json`，截图只作内部核对。

核心自身校验和 16 项策略测试另行通过。场景仍为未绑定实测 DEM、生态调查或地质过程的局部样板；实体手机性能和最终美术验收尚未验证，`visualApproved=false`、`productionReady=false`。
