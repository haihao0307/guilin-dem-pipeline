# Landscape Mother · Macroscopic Karst R3

这是葡萄峰丛局部石灰岩壁的一个自包含 WebGL2 工作台。

R3 保留用户已认可的 R2 跨尺度核心，并增加受约束的真实隐式裂隙、稀疏弯曲层理、稳定矿物色差、向下湿痕，以及离散三维苔藓团簇。原作原理分支继续保留，固定 QA 机位下应与 R2 的原理输出一致。

工作台没有图片贴图、外部脚本、预展开网格或运行时网络依赖。八个样本共用一个场函数，只改变稳定相位和观察参数。A=0 继续退出团队空间弯折扩展。

尚未完成的范围包括：完整葡萄 DEM 绑定、现场裂隙测量、石灰岩矿物标定、水化学、苔藓真实生长、碰撞与导航网格、物理手机性能，以及用户最终美术验收。
