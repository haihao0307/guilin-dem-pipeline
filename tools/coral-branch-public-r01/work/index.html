来源与本次实际仿作

老师是用户提供的《分叉生长——自然界的神奇现象》24.400秒原片。“输出一/输出二”为本台对应两段可见结果的入口命名，分别对照14.800秒银白团簇与22.733秒浅蓝分枝（后者是延展段中的一个对照阶段，不冒充24.4秒终帧），不把两段误写成原作者公开了两套最终算法。

本次已经生成：三个起始枝体、连续主/子枝曲线、出生先后、向端头延伸、连贯分叉表面、银白与浅蓝两段形态、3D厚度和实时视角。生成参数为按画面拟合的本台参数；源片未提供的最终C4D工程/规则不冒充找到了。

“只看生长线”显示当前实体使用的相同分枝图；“重播生长”逐次从曲线和时间重算体表，非缩放整棵已成形对象。透明效果为双面近似，不是原作者的离线光线追踪材质。此仿作尚未获得用户一比一验收。

本模块独立接入Coral Mother，不改变已经认可的芽簇形态、配色、镜头或花盘。原片、关键帧、生成代码和检查记录在配套包中。
