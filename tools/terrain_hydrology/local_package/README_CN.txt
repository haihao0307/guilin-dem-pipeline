三地区真实地貌与水系工作台 v1.0

使用方法：

1. 完整解压 ZIP。
2. 双击 START_WORKBENCH.cmd。
3. 浏览器会自动打开工作台。
4. 启动窗口需要保持打开。结束使用时在窗口中按 Ctrl+C。

当前内容：

桂林：已带入真实 12.5 米高程片区，可旋转、平移、缩放和单独查看。
温州：权威源已校验，精确片区实体生成前保持锁定。
昆明：权威源合同已登记，源文件挂载前保持锁定。

资料输入：

页面设有三地区共用入口，以及桂林、温州、昆明三个地区入口。可以输入文字、选择参考图、查看缩略图和导出 JSON 入库包。

浏览器中的图片和文字只在当前电脑暂存。需要小华读取原图并写入 GitHub 时，请把原图或导出的 JSON 入库包上传到 ChatGPT 对话或 Codex。

生产范围：

地形、台地、阶地、坡面、沟谷、河道、河岸和水面边界。
植被、树木、竹林、灌木、草地和农作物由独立植被生产系统处理。
