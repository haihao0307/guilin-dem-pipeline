## 观察和测量：参考动画

92 nodes，1 skin/68 joints，6 个鱼分支，1 条 `All Animations`、10 秒、190 通道，全部 LINEAR 关键帧。根节点的旋转/平移与位置偏移产生群体路线；附件没有邻近查询、分离、对齐、聚合或避碰代码。烘焙群体动画不是自主群聚算法。

首鱼主链 `28→29→30→31→32→33`，次链 `34→35→36`。主链相邻长度约 `[.023560,.022546,.029284,.024454,.020652]`（参考坐标单位）。统一到共同根坐标后，主链约 1 Hz，摆角振幅约 `[11.28,19.91,19.96,20.03,19.91,20.02]` 度，展开相位约 `[-101.92,-161.89,-222.19,-281.92,-341.89,-281.92]` 度。前五骨约逐段滞后 60 度，末骨回到第四骨相位；禁止写成六骨等间隔后向波。第一骨局部主轴 X，后续多为 Z，跨资产必须先对齐坐标。

首鱼身体网格 3936 顶点，3934 单骨 100% 权重，仅 2 双骨；另一个 612 顶点网格全部单骨。它的形体、硬权重和角度不能直接复制给我们的高密度鱼。迁移的是根运动与局部轴向节律分层、稳定时钟、相位传导，以及真实骨骼播放后的对照方法。

`local-r08/src/herring-reference.js` 解码原始 glTF/accessor，重放层级、逆绑定矩阵、原蒙皮、四元数最短弧插值；单鱼模式去除当前根的群体路径并对齐固定参考坐标，鱼群模式保留原路径。没有重画参考形体。内部截图/录屏与实际 WebGL 检查位于该版本 evidence。

## R07 缺陷的两个原因

1. **位移撕裂**：继承的鳍 chart 区域包含躯干皮肤。臀鳍典型所谓尖端 `t=1` 实际在后段体侧。共享源位置一侧 pid6/full fin weight，另一侧 pid0，接缝分别接受鳍变形和纯脊椎变形。TURN_LEFT 稳态检查 15512 组近共享位置，1070 组分离超过 0.2 毫米，最大 1.7348 毫米。纯身体两侧仅约 0.1 微米。
2. **无效法线黑线**：鳍根 ray 为零或与弯曲方向平行，GPU `normalize(cross(T,U))` 产生无效值；即使转角为零，乘零仍传播无效法线。静止也出现黑线。旧 GPU 检查只读位置，不能捕获该错误。

## R08 工程规则与函数归属

- `scripts/derive-fin-skin.mjs`：从原表面及原鳍根测量有符号向外距离。胸鳍 ±Z、背鳍 +Y、腹/臀鳍 −Y、尾鳍 +X；`t` 由向外距离排序，不能使用任意 chart 边界或欧氏长度来代表鳍尖。负向距离所含身体皮肤不响应鳍驱动。
- 鳍根与 mixed-domain 接缝使用五次平滑函数 `6t^5-15t^4+10t^3`，带宽 0.006 体长是工程过渡参数，非生物测量。共享源地址以 0.2 微米容差识别；共享地址共用绑定，混合 body/fin 边界归零；相邻皮肤在窄带内平滑退到边界。
- 原位置、索引、法线、UV、图集、源数据 chunks 完全保留；追加 derived bindings（存为相对源绑定的无损 XOR+gzip，解码字节与直接保存完全一致），禁止焊接改坐标、删鳍尖或用覆盖面填洞。
- `src/instrument.js` 的 `transportSpine`：固定原 X 材料地址，完整正交截面由连续中心脊椎搬运，身体不混合 body/head 权重。
- `src/app.js` 的 mesh shader：仅在有效轴和非零角度/权重时旋转法线，鳍根保留源法线。GPU 位置与法线必须一起验证。
- 七组鱼鳍仍独立响应，尾鳍读取渲染尾柄运动；眼球独立。R07 的后向轴向波、推进强度与播放倍率分开保留。参考硬蒙皮不进入本鱼的变形基线。

## 必跑回归与验收

`local-r08/REGRESSION_SURFACE_CONTINUITY.json` 对应用户纠正。数值门禁：所有同源边界、16 模式、鳍倍率 0/1/1.8、不同相位、模式切换后接缝误差保持源重建精度；七鳍尖完整可动，身体不受鳍倍率影响。GPU 门禁：实际 shader 全顶点位置和法线有限、法线单位长度、CPU/GPU 位置一致，尤其 REST 的零 ray。视觉门禁：同视角静止/巡游/转向的原色、白模、法线以及侧面/俯视实拍；参考单鱼骨骼动画同时播放。

交付封装采用完整内嵌 runtime 的 gzip+安全可打印编码，解压后仍是同一实时三维工作台，不增加外部核心请求；编码往返和派生绑定解码均按字节验证。它只解决接口上传限制，不改变模型精度。

测试通过只代表技术门禁；`visualAcceptance`、`motionAcceptance`、`productionReady` 必须保持 false，直到用户验收。推进估计未标定，不宣称流体仿真或真实游速。单鱼修好后，后续生态将 world root 路线与 local gait 分离，并另做真实邻近/避碰验证；本轮没有提前实现鱼群 AI。
