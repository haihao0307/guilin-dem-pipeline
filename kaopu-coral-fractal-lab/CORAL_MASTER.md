### 形态与分类 / Morphology is not taxonomy

1. 枝状硬 / 软：可共用分枝语言，但硬骨架和软组织不是同一种物性。无树根、树皮、树叶、木质年轮。
2. 海葵：单体体柱、口盘、足部附着与环绕触手；不是石珊瑚，也不是每一触手一棵草。纳入同一生产界面并不改其分类。
3. 脑珊瑚：块状群体上连续的壁、谷与隔片；不是标准球贴脑纹。R01 的三维迷宫函数改变临时表面，是工程形态假设，不是已验证的脑珊瑚发育机制。
4. 卷心菜：有厚度的薄层沿生长边缘扩展与卷曲，不拷贝植物叶片。R01 仍有规则层叠与潜在片间相交，必须继续校准。
5. 桌面：支撑、横展分枝与上向小枝需要分别表达。R01 用方向场影响生长步，不通过压扁成年树作弊；枝条融合尚未实现。

### 三系统边界 / Authoring · Score · Instrument

制谱 / Authoring：收集带来源的物种和多视角观察，标注可证明与不可证明的内容，调整谱并留验收证据。R01 为人工参数制谱入口，未宣称自动视觉拟合已经完成。

谱 / Score：`scores.json` 含独立的规则参数、算子选择、种子、初始条件与证据状态。不含展开顶点、索引、贴图和成品模型。不同研究谱是用户可读的数据，不是乐器内部藏好的物种网格。

乐器 / Instrument：`coral-functions.js` 只解释 branch / radial / sheet / massive 共用算子；不按物种名称查模型。`app.js` 是与冻结母台的适配和观察界面，不承担物种知识。

运行 / Runtime：临时函数采样与显示可分离。R01 并未完成游戏运行包的轻量化验收，不以参数字节数代替全部函数代码、临时几何与运行内存的成本。

### 生态接入合同草案 / Habitat handoff, not completed integration

### 树到珊瑚的实际关系

- 根系改为岩石表面的浅附着层；不生成向地下分枝的根。岩石为程序化演示支撑，不补造老师未知基底，也不是世界场景。
- 骨架逐段增生：固定已长出的路径，从既有接点增加分枝长度；局部已生长时间控制增粗，不用整株缩放冒充生长，不把刚性骨架当草摆动。
- 主枝长度、第一处分叉位置、基部粗细、张角、侧枝数、弯曲与局部增粗为可调形态参数；没有声称所有珊瑚到固定高度必分叉。
- 蓝珊瑚不等于蓝色鹿角：保留用户的宽厚共同片体、指状突出、钝圆末端与空隙观察，使用非圆截面与共同实体。本版是形态草样，未逐视角复刻 `blue_coral.zip` 老师。
- “没有年轮”须精确为没有木质年轮；部分珊瑚骨骼有年度密度带。本轮不模拟内部密度带，不因此阻断游戏形态制作。

### 实现、继承与成本

`r03-core.js` 继承冻结母台的 seed/hash、forward/wave、parent/join、路径采样，增加局部沉积、扁平截面、附着层与临时隐式融合显示。`r03-catalog.js` 为两份明文形态谱；乐器不按物种名称查成品模型。`r03-app.js` 延续原台相机、WebGL 着色与触控合同，同页放入珊瑚知识。`r03-worker.js` 在工作线程求值，快速切换只接受最后请求。

没有外部模型、贴图、字体或 CDN 依赖。函数关系是描述层；显示使用临时三角化，不把它说成 GPU 完全无三角形。当前默认鹿角样件约 24.3 万临时三角面，蓝珊瑚约 22.6 万；这是生产观察台，尚非已经优化完毕的轻量游戏运行包。几百字节的谱不代表总体内存和求值成本。
