# 鸟状与鱼状：两个不同的三维结构候选

源于用户指定的《飞起来！》和《未来的艺术，该是什么样》可见结构。原 C01 弧形、08/09 原式保持不变。本目录为 C02 鸟状／C03 鱼状独立结构学习候选，接入原海羽工作台；仍待用户形态审阅，不能把通过数值测试称为参考外观验收。

## 可见事实与采用的设计

鸟状参考在 0 秒已经完整：长前段节链、较短且深的躯干笼架、躯干前上方伸出的左右翼、下面两条弯折悬垂肢架、较短后段。4.5–6 秒翼明显上抬，随后回落；6 秒能辨认翼的主梁和重复支架。长前段末端并没有足够清楚的完整鸟头，未补眼、喙、爪或真实解剖身份。

鸟候选有独立的肩位—中间关节—远端关节主梁链，翼肋挂在翼主梁上；18 对胸部弧架只分布于躯干，双肢挂于后部。翼从同一躯干站点分出后拍动，绝非把整排胸肋一起旋转或只改名字。10.5 秒周期和关节驱动为我方近似设计，不宣称作者绑定或精确频率。

鱼状参考 0–3.6 秒有长而弯的细节段结构，连接到明显膨大的笼架。6.1、8.6、16 秒能见宽部的多层大弧支架、外伸扇架以及外围细链；25.8 秒以后主要是放大的局部结构。观看方向和录屏镜头在变，不能据此证明具体游动驱动，也不能可靠指定所有末端的头尾解剖身份。

鱼候选采用 38 对沿长轴分布、从窄段骤然扩大到宽腔的环弧；宽腔另有数个独立轴地址的外弧与背侧扇架。没有鸟式肩肘腕翼链和悬垂双肢。默认静止；非零运动明确称为“我方侧摆试验”，不是视频运动恢复。

## 当前差距

只研究中性骨架、可追溯附着和空间层次。未复刻参考的厚骨片、空洞拓扑、表面细节、外围点链装饰、原光照和拍摄；没有表皮或材质。局部框架沿用已验证的离散最小旋转工具，未宣称原作者也使用该方法。没有真实解剖、动力学或全局碰撞保证。

代码分别生成 bird 和 fish 包；共享的是坐标框架与查看器，不共享同一排扇模板。270 个选定组合验证真实父对象地址、附着误差、翼/肢骨段长度以及结构组区别；可见形态必须另看真实浏览器三视和时序截图。
