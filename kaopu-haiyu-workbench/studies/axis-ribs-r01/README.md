# 海羽 C01｜稀疏轴—成对支架候选

C01 是海羽原工作台内的独立结构检查入口。它不是老师模型、真实生物骨架或受力仿真。08/09 二维原式和旧基线独立保留；本阶段不加入表皮、复杂材质或物种造型。

## 学到了什么，尚未做什么

用户给出的 Momogi 山海鱼视频能看到中心连续结构、沿其分布的重复构件和两侧展开。我们只采用这些可见的组织关系，不复制作者形状、资产、拓扑或程序。上传的“飞起来”片段从片头已是完整形体，不能据此宣称老师演示了“逐层生成”。

当前复用海羽R17自己的轴方程，并建立新的最小旋转输运与支架。它没有把08/09二维点场反演成3D；二维谱到轴弯曲、站点分布、支架长度的逐参数映射仍是下一阶段工作，不用替换预设冒充映射。

## 坐标与生成关系

X为根到尖的长向，Y为两侧展开方向，Z为深度。视图采用XY（沿Z看）、XZ（沿Y看）、YZ（沿X看）标签，不套用人体正/侧/顶名称。主画面为同一世界几何的可旋转投影；它不是平面图片、视角变形或视频。

- 轴 A(s,t) 复用 R17 experiment/instrument.mjs 内的 featherAxis 方程
- Rodrigues rotate 直接复用 R17 curve-math.mjs；既有代码与旧案例不改写
- 沿轴选2–24个成对站点，默认12对；每根支架保留 stationId、side、root 和局部坐标
- 左右跨度、曲率和4秒相位是明确的自有设计参数，不是视频测量值
- 运动是轴函数、框架与局部支架共同更新的运动学；没有质量、刚度、惯性或受力求解
- 暖/冷色只区分两侧支架，不冒充光照

## 框架方法与边界

采用相邻切线的离散最小旋转输运，是连续RMF的数值近似。未实现论文的双反射法，也不声称连续RMF精确解。方法对照：[Wang等，2008，Computation of Rotation Minimizing Frames](https://www.microsoft.com/en-us/research/publication/computation-rotation-minimizing-frames/)。

108组选定状态（4幅度×9时刻×3支架数）检查有限数、正交性、单位长度、手性、站点根部和确定性；另检验4秒周期的241个时刻。默认12对支架，共729个曲线顶点。

- 直线、近平行切线和旧参考轴阈值跨越样例通过
- 零长度切线、初始法向与切线平行明确报错
- 相邻切线反向、单步转角超过60°明确报错，要求重采样/修轴
- 闭合路径明确不支持；没有闭合扭转/holonomy修正
- 不把选定测试通过推广为任意曲线、任意速度或任意拓扑稳定
- 尚未证明连续时间的全局无穿插，也没有厚壳或碰撞体

## 真实浏览器证据

官方Playwright Chromium已经在母台内实跑：同源三视、手动旋转、正交视图缩放、参数修改、运动与暂停、返回旧案例、重复进出、PNG导出、离线整台重开。跨Node/Chromium比较保留1e-12数值容差并记录实际误差，拓扑与数量严格检查。实体设备、Safari和Firefox未测试。

见 verification.json 和 tests/browser.cjs。geometry-report.json来自纯数值脚本，它的 browserVerified=false 只表示该脚本不执行浏览器；不要拿数值结果代替浏览器证据。

入口：原海羽首页 ?module=axis-ribs-r01，内部stage19。独立iframe退出时销毁，重新进入默认暂停。旧08/09源码、旧D资源、原实验脚本及原站回退入口均保持独立。
