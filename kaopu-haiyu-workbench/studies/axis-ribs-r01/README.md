# 稀疏轴—成对支架候选 R01（本地研究，未上线）

这是海羽自有的程序化结构实验。未接入原台、未覆盖R24、未改08/09，未复原Momogi作品代码或独特形状。显示少量支架是为了检查结构关系。

坐标定义：X为根到尖的长向，Y为两侧支架展开方向，Z为厚度/深度。视图用XY（沿Z看）、XZ（沿Y看）、YZ（沿X看）标注，不用人体语义的正/侧/顶名称。所谓根/尖只是这个候选的参数方向，不认定为特定生物。

重用R17 experiment/instrument.mjs内的featherAxis方程以及原curve-math.mjs的Rodrigues rotate。未复制鱼数字形体、鱼运动或作者资产。新建离散最小旋转输运，是连续RMF的数值近似，不是精确RMF，也没有实现论文的双反射法。方法对照：[Wang等，2008，Computation of Rotation Minimizing Frames](https://www.microsoft.com/en-us/research/publication/computation-rotation-minimizing-frames/)。

已验证：108组选定状态（4幅度×9时刻×3支架数）有限数、正交性、单位长度、手性、站点根部、确定性、投影前后生成数据不变。默认12对支架，729个曲线顶点。另验一整个4秒周期中241个时刻的帧法向连续性。

测试边界：
- 直线和近平行切线通过
- |T.y|跨越旧参考轴选择阈值的样例通过，不发生参考轴切换
- 零长度切线、初始法向与切线平行明确报错
- 相邻切线反向、单步转角超过60°明确报错，要求重新采样/修轴
- 闭合路径明确不支持，未实现闭合扭转分配/holonomy修正
- 以上不是任意曲线、任意速度或任意拓扑的稳定性证明
- 没有厚壳、骨骼真实解剖、材质或受力仿真；没有证明连续时间的全局无穿插

three-view-proof.svg/png是同一世界空间数据的程序投影证据，不是浏览器截图。geometry-report.json把browserVerified固定为false，等待真实浏览器通过后才能改变。所有运动来自明确的4秒相位和站点函数，是运动学，不是力学传导。
