# C01 弧形收拢修正：独立形态候选

用途：按用户形态反馈，为原母台的单一 C01 入口提供弧形包拢检查形态。原 C01 源码目录及 fec0ee1 发布证据保留为回退锚点，08/09 原式保持原字节。无表皮，不代表视频成品、真实解剖或用户最终验收。

用户接受 XY 顶视展开，指出 YZ 轴端应该中轴在左右之间，上背下胸，两侧成对弧形向胸侧弯回并收拢。本次直接修改局部支架坐标，保留 C01 原主轴、参考架、站点、相机投影与颜色。黄为负 Y 侧、蓝为正 Y 侧；YZ 轴端保持黄左蓝右。

## 唯一几何改动

站点参考架为 T、N、B。本次设计定义 +B 为背、−B 为胸。原 C01 支架在 +B 侧向上掀；改为从根部连续延伸、向两侧张开再向 −B 侧弯回的椭圆弧：

- θ = 收拢角 × u，u 从 0 到 1
- T 位移 = 0.22 × span × u（与原值完全相同）
- N 位移 = side × span × 宽度 × sin θ
- B 位移 = −span × 深度 × (1 − cos θ)

默认收拢角 2.40 rad，宽度 0.94，深度 0.50。最大展开宽度约为原 C01 的 94%；末端横向距离约为最大宽度的 68%，因此真实几何向内回收。此处没有相机翻转。背胸是设计方向，非解剖验证。

允许范围：收拢角 2.10–2.75 rad，宽度 0.85–1.00，深度 0.35–0.75。动画沿用 C01 的显式函数，仅供后续检查附着；本轮优先静态形态。
