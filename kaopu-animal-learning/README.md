# 动物方法学习 R02

这是独立的方法学习与结果检查入口，不是完整 Animal Atlas 的公开部署。

三位老师：RAPID（花纹个体再识别）、4DEquine（马科视频四维重建）、AnimalLift（单图规范形体、纹理与毛发）。逐卡保留输入输出、方法流程、适用边界、许可、论文与当前代码差异，以及“权重未下载／推理未运行／真实效果未复现”状态。

真实轻量功能：本地图片人工点位记录、像素坐标和 JSON 导出；本地 OBJ 数值、索引及包围盒检查。文件不上传、不持久保存。人工点位不是 AI 识别，OBJ 可解析不是三维形体验收。

`index.html` 是自包含薄页，无核心网络依赖，无模型权重，无作者照片、视频或模型，无原 Atlas 载荷。所有流程图都是明确标识的自绘方法示意。

构建：`node tools/build.mjs`
静态与数值检查：`node tests/static-numeric.mjs`
真实浏览器：`python tests/browser_qa.py`（Playwright 1.55.0 / Chromium）

浏览器测试中的 PNG 和三角形 OBJ 只在执行时生成，明确标记 TEST_FIXTURE_ONLY，不是动物结果或生产资产。

旧工作入口从既有总览保留：8 个公开入口；私有帕劳站点仅保留名称与私有状态，不公开其地址。未发布条目不编造网页链接。旧质量状态未在本轮重验。

许可边界：RAPID GPL-3.0；4DEquine 当前 BSL-1.1 且无额外生产授权；AnimalLift 代码未见许可证，权重为 CC BY-NC 2.0，数据为 CC BY-NC-ND 4.0。本项目只保存方法摘要和指向官方来源的链接，不收录第三方实现或资产。

## 新增：视频参考动作实验

[原帖](https://x.com/Graalitoo/status/2106536651883421934)引用了[教程](https://www.youtube.com/watch?v=evK-Y83Qlco)。卡片区分：教程创作者说明的动物固定视角拟合流程；原帖实际视频的正/侧同屏、青/粉左右分区人形实验；本工作台未来承接建议。教程播放与转写未完整取得，不声称逐帧复现。

核心是已有角色与骨架，通过参考视频逐帧摆骨、渲染和轮廓对比迭代。轮廓吻合不能确定深度；同屏多视角不自动等于同步、标定或三角测量。新拟合器未找到公开代码、权重、许可或硬件配置，原帖作者早期 Mixamo/GVHMR 项目不得混作此流程实现。

新增内容是方法卡、边界和可下载的学习 JSON；没有调用 Seedance/Tripo，没有运行摆骨求解，没有动作导出或通用动作制作器。旧三老师、原路由、8 个公开入口以及人工点位和 OBJ 工具保持。
