# 靠谱 · 香港道路函数工作台 R01

这是可编辑的三维道路教学样段，不是现场复原、工程施工图或道路合规认证。

## 组织与生成

唯一主轴是 Time → Location（含环境）→ Object.Road。Road 的各组件拥有自己的材料、造波、状态和来源。Material 和 Component 不作为平行世界根类。

RoadMother 返回函数规则、参数、从属树及通行语义，不返回三角网格或点云。renderer.mjs 使用解析函数场求交和法线；顶点着色器仅生成一个覆盖屏幕的三角形作为像素显示载体，不构造道路对象。没有道路顶点缓冲、对象三角索引、外部三维模型或纹理文件。

横断面随中心线参数展开。基准车行道高度为 0.24 − 0.025 |x|。材料微观变化由多频函数波生成，损伤由局部连续下凹场生成。路缘用有界截面函数，灯杆以空间单元定位最近实例，避免数百实体全扫描。曲线模式使用横向抛物线偏移展示同一 Mother 的变量变化，不是完整缓和曲线或曲线超高设计。

## 已实现

- 可旋转、缩放的 36 m 样段，鼠标和触摸操作。
- 车行、两侧行人、独立单车、路缘、标线、排水、灯杆，以及施工表面与围护组件。
- 同一形体切换组件分色 / 造波材质；点选和列表均可检查从属、函数、材质、状态、资料来源。
- 教学时间 T0 完好、T1 局部损伤、T2 局部施工封闭；封闭不是贴图，它也改变道路节点的局部通行限制。
- 同一 Mother 的直线与缓弯样例；车道数、车道宽、行人宽、单车宽可调整。
- 可编辑和下载 TLO 知识 JSON。编辑后仅提取 parameters，再由 Mother 重建一致的树。

## 来源与限定

香港 TPDM 2（August 2026）3.4.1.1 是 2.5% 一般横坡的依据；曲线超高等例外须另行处理。其余预设尺寸、独立单车组件、标线间距、锥桶排布为自主教学示意，不能据此宣称已通过香港规范验证。场景不对应九龙钟楼或任何特定街道。

尚未实现交叉口、高架、隧道、土路、小径、桥梁结构、交通仿真、完整香港设施细部，以及工程级碰撞/寻路。横向排水用可见沟槽/格栅场示意，并不模拟水流。施工段为局部表面覆盖，不声称完成开挖工法。

## 运行

使用任意普通静态文件服务器打开 index.html；浏览器需 WebGL2。无安装依赖，无第三方脚本。测试文件用于 Node 静态/语义检查及 Playwright 桌面与手机视口浏览器验证。手机视口测试不是物理手机性能测试。
