# 共用 Building Mother

基础、标准层、围护是同一装配函数；实例只存参数，类型选择楼梯规则，不复制每层生成器。Room R06与Tower R01共用shared-core/mother.mjs、原primitive-kernel。

Tower为方形绕核心回旋：四次90°转向升一层，8个使用层的地面标高0至7h，屋顶标高8h。八段连续楼梯至顶，屋顶不是第九个使用层。楼板出生即带开口，平台/门窗位置/护栏从关系生成。高层外墙端口为窗，只有首层对地门；不加屋檐、新材质或门窗实体。

各尺寸均为示意，梯板/平台连续连接未做结构计算。路径测试是保守站立体净空和中心落脚连续几何，不是步态、承载、消防或无障碍认证。

施工播放只对一次生成的完整模型按依赖显隐，基础→联系梁→首层板→每层柱/梁→上层板→楼梯及到达护栏→围护。可暂停、逐步拖动和从基础重播，不每帧重新生成楼层。基础深度0.8+0.05×(层数−1)×层高仅为教学演示，土质、荷载与工程基础型式未知。旧R05保留原固定基础；新Room除基础变深外保持原几何规则。
