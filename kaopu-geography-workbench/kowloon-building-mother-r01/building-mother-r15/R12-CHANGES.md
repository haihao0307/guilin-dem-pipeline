# R12 · 截面、可使用空间与用途关系检查候选

保留 R11 和原三栋源外形、层数、高度，不将草图尺寸套入实楼。

## 本轮已定位的问题

1. 剖切射线从既有实体内部开始时只找原实体出口，剖切平面没有成为命中候选，造成有厚墙显示如薄片。增加显示切平面与解析实体的真实交集，保留宿主身份；不加厚墙、不封零厚原源面，也不把洞口填实。
2. 低楼凹轮廓被宽泛房间范围裁出分离片段，但旧测试只走七个房间中心，遗漏整块可站立空间。全层空间审计不再把房间中心通达当完整空间通达。
3. 龍總待定位平面候选的核心与户型楼板边界存在图像解析缝，语义 opensBetween 不等于实际连续楼面。修正仅在设计门槛连接范围，原图单元边界不移动。
4. 用途事实与设计假设分开：低楼资料为私人住宅，但当前内部七房分区不是实楼图纸；龍總按学校、商会、住宅平面分层证据；仓库区分人员、车辆装卸、货物转运与待核服务门。
5. 原入口厅镜头为室内朝内，不是门外核照。新增按当前设计门法线推导的门外复核镜头。门位、方向、1×2.1米门洞仍为候选假设，不能据图透视或用途猜测改成实测。

## 验证边界

解析截面 CPU 反例检查已运行；最终浏览器、空间修复回归结果以本版本单独结果文件为准，不继承 R11 通过结论。全层栅格检查存在采样分辨率，不是连续碰撞证明、消防或无障碍认证。井道、楼梯竖向孔洞、结构空腔不是普通房间，不要求任意从楼面走入。

真实门窗净尺寸、室内房间分布、龍總平面到源楼壳配准、仓库全部实门与人员/货运实际流线尚未完成核准。这不是三栋一比一完成版。
