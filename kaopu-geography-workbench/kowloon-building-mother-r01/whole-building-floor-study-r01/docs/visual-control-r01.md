# Isolated visual control, not an accepted public building

Runtime derives from frozen 9251f513. The later 56559f29 validation-pass experiment passed correctness but showed only 1.5% paired warm improvement and 2.17% colder first frame. Its extra pass is rejected, archived, and not imported here. The old experimental test file remains as historical source but is not a test of this reverted runtime.

This experiment preserves geometry, aperture motion and optical ray solver, source exteriors, material recipes, camera, fixed lights and 640×544 sampling. It changes only:
- Clearcoat masking uses its own roughness. An explicit comparison switch retains the old bug for controlled before/after images.
- Raw authored material-color diagnostic bypasses illumination, Reinhard and exposure, then encodes linear RGB to sRGB exactly once. This is a display convention for these authored receiver values, not a claim that real material reflectance was measured. Normal rendering keeps its old tone mapping.
- A separate finite-distance structural-shadow pass reads exact existing rectangular wall fields from Unit A. Twenty-five segments retain the original doorway voids and lintels. Thirty-three stable wall/floor IDs receive the unchanged key-light visibility. The fill light and ambient remain unchanged. The visibility ray is limited to 2 m, fading smoothly from 1.6 to 2 m. It is not full-scene visibility, sunlight simulation, ambient occlusion or a structural/material survey.

The shadow query uses all selected walls for both primary and secondary hits, never a primary-camera culling list. It uses original orthonormal frames and dimensions, no proxy boxes, meshes or triangles. Rectangle certification rejects holes, skew frames, non-cyclic loops and walls too thin for the 0.2 mm geometric-normal offset. Only the exact convex receiver is excluded from self-shadowing. Moving doors, window leaves and glass are not included as shadow blockers. Other five units and the enclosing outline are not part of the shadow subset. This limitation is deliberate and must not be described as complete room lighting.

Control gates: same divider on both sides and a doorway must be respectively lit/blocked/lit; CPU/GPU visibility, color encoding and coat masking must agree. Primary raw hit/identity/normal/local buffers must remain byte-identical with controls off/on; changed final pixels are expected and reviewed. Measure the extra pass separately and paired total time. Real Actions Chromium/SwiftShader is not an iPhone benchmark. Fixed plans remain independent plan-local coordinates, not registered into the authoritative measured building. Interior finishes are editable design, not a faithful photographed interior.
