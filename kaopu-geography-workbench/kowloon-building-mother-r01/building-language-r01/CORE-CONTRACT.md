# Building Language R01：纯核与持久实例契约

## 实际执行链
`buildRecord(parameters) → growFromRecord(record) → recipe-first context → evaluateRecipe(IR) → 派生解析几何/显示缓存`。
门窗宿主、铰链坐标系、支承和通行关系在规则发出时同时登记；不是从成品网格反推归属。`context` 发出 prism/capsule 参数记录时不展开平面或包围盒；只有 evaluator 执行展开。
原有楼层与楼梯规则复用；层数是一项实例参数。形态母体为矩形棱柱、带内外边界环的有限棱柱、有限线段胶囊体。孔为原生定义域，不是网格后加工。扶手沿已验证分段路径生成；不声称任意通用扫掠或精确 SDF。

## 持久层、检查层与显示层
默认持久 JSON 为 `mother-instance.json`：353 B 运行 JSON，文件354 B（末尾一个换行）。这已经含104 B形态参数，不能再加104 B。
根记录只含共享规则版本、参数组引用、实例身份以及未知的 parent/placement/time/region；这些未知值为null，非补零世界坐标。默认不存localOverrides。
唯一演示例外为 `instance.localOverrides[instance.id]={origin:[2,0,0]}`，由实际求值驱动所有子实体；它是已声明局部示范基准变换，不是世界摆放，也不自动处理碰撞。当前仅支持各轴±10m内根平移。
248构件、84参数组、296局部帧是规则运行生成的可检查语义IR，默认紧凑序列化299313 B；不是每栋楼必须永久保存的248份库存。此IR可完全丢弃，由353 B根记录和共享规则重建。
派生解析几何缓存206546 B（primitives/roundMembers），亦可丢弃。它不是母体真源，也不写回持久记录。运行内存对象开销、UI和显示程序另计；上述数字不是RAM或下载总量。

## 验证与等价边界
- 72组旧新回归：203472个坐标，185592个位级相同；最大差8.881784197001252e-16m，阈值1e-11m。因局部重心转换有浮点舍入，不能声称旧新所有值位级无损。
- 原身份、图关系、楼梯/门通行元数据逐项精确相同。
- JSON序列化IR→求值，与本版缓存位级相同；紧凑根记录JSON roundtrip→重新生成IR和缓存，也位级相同。
- root +2m驱动全部子实体；单墙父帧变更仅驱动该墙域后代。生成先于展开及透明玻璃属性持久在源记录均有断言。
- 624几何参数组合通过：13层高、1/2层、0/1地下层、门闭开、窗0/.35/1及扶手噪波边界。通行验证为保守身体盒与有限落脚采样，不是结构、无障碍、逃生或连续步态认证。
- 测试辅助函数已修正旧假设：洞口局部环需经origin/u/v转换到世界坐标，不能直接当世界XZ；未修改生产几何以迎合测试。
- 重复/缺失引用、非有限或非正尺寸、无效局部轴、伪造世界摆放及无效例外被拒绝。仅验证本生成器支持域，不保证任意输入多边形无自交或任意装配合法。
