# R04：同一母体，两层围护与内侧楼梯

只计算生成函数，不含显示/灯光/材质/UI：
- primitive-kernel.mjs：3134 B
- stair-rule.mjs：6924 B
- building-mother.mjs：7064 B
- 共 17122 B（17.122 十进制 KB）；较 R03 16574 B 增加548 B。
- 默认实例 mother-instance.json：85 B，含末尾换行；较 R03 不变。这是默认差异参数，不是完整展开几何。

母体只计一次。一个标准层和一个围护函数按层数/高程复用；上层前侧端口角色为窗，不制造没有阳台的高空可通外门。圆杆通用公式只定义一次，实例存端点与半径，不导入整个旧案例。显示与检查时生成的实体不是逐栋永久存储的重复母体。

删除无调用的方杆函数；圆/棱柱共用身份与支承登记。圆扶手段和立杆由有限线段扫圆生成，圆端在共享端点相交，删除16个方接头。复用 R06原 r07/field.mjs closestOnLine 距离规则和 whole-building-r01/rails.mjs 的 distance-radius；仅提取需要的公式，未将两个旧大模块导入纯核心。不是多边形假圆，也未声称本版实现圆弧倒角。

楼梯步高/薄梯板/踏步公式沿用。跑长2.4不变，单跑宽1→0.9、间隙0.2→0.16，双跑占深2.2→1.96（约减少11%），位置移至后内侧。代码总量没有变小：增加的圆管表示/双层围护接口有真实代价，未靠压缩或隐去依赖伪报。

半层额外平台梁移除，主框架梁保留。平台与上下薄梯板连续连接是未计算的结构假定；没有验证钢筋、承载、消防或无障碍。通行检查从门内到二层，保守连续上身净空、脚下接触采样；不是完整人体动力学认证。
