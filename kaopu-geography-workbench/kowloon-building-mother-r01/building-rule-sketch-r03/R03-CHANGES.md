# R03：洞口、直接电梯接口与明确的纵向生长

独立规则草图，不是香港实楼或施工方案。R01/R02及三栋实际建筑保留。

## 用户纠正后改变

- 普通门默认只生成有宿主的空洞，不装普通门扇；窗洞有单独类型、窗台、宽高，不借用落地门洞。
- 电梯井紧贴本层板边，门槛连续；删除旧0.65米外接桥与额外普通门，保留电梯层门与轿门关系。
- 默认显示完整多层案例。加一层、减一层和层数同时可见，独立原型单开间仍为1层，非将实楼改高。
- 本轮检查2–8层；骨架、梯段、楼板洞、各层入口与停层共同重生成。不是自由缩放旧壳。
- 桌面扩大三维区，另有“放大工作区”；移动端全宽，保持原生分辨率策略，不以糊化换速度。

## 验证边界

数值与浏览器实际画面分别验证。电梯仍是离散停层示意，不是完整设备控制或安全认证。所有尺寸和基础均为教学假设，无真实楼层/高度修改。半透明是显示检查，不改变实体与归属。8层是本轮检查范围，不声称城市建筑高度极限。
