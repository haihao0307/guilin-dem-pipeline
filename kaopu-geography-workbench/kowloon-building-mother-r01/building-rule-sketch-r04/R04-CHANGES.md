# R04：四层支承关系与复用电梯控制

独立教学草图；R01–R03和真实三栋建筑不变。基础、层高、尺寸是示意参数，不是结构施工或消防合规证明。

- 地梁跨度和底板保留；首层柱芯从基础顶贯通地梁节点到上部柱，不再把地梁角部空缺当有效支承。
- 梯转角平台以后墙内面为几何边界，同时明确平台梁到框架柱的支承关系，不把填充墙当承重墙。
- 墙/板接口共用标高、检查真实接触；不把所有合理构造缝填实。
- 楼梯连续扶手与支承节点由梯段/平台路径派生。
- 默认四层；保留2–8层规则检查，所有层的连接随变量重生成。
- 原 elevator-mother-r02/model.mjs 和 controls.mjs 原样复用，通过楼层绑定适配当前井道。复用的是既有控制状态机、呼梯与门联锁，以及 controls.panelFields 生成的实际楼层/呼梯/开关门面板规则；当前草图轿厢形体仍来自本草图函数，不冒称完整原轿厢模型已搬入。电梯是教学控制，不是实机安全系统。

实际浏览器需检查四层外形、基础接头、墙板、转角平台、扶手与电梯运动/到站。软件显卡绘制慢时状态仍按小步进求解，不将绘制帧率称为实时性能保证。
