# R03 生成核心与显示分离

一个标准层函数，`floors: 1 → 2`；楼梯由相邻层关系产生，不存在第二套“二楼函数”。

纯函数合计 **16574 B**（未压缩，含注释和校验）；默认实例 JSON **85 B**（含末尾换行）。母体一次保存，每个实例只存差异参数。

依赖图：`building-mother → primitive-kernel + stair-rule`；后两者零 imports。没有旧案例、楼梯以外整座教学建筑、GLSL、灯光、相机、标签或材质模块进入此纯生成闭包。

显示层另行引用保留的 R02/R06 渲染器与标签；显示引擎仍有历史混合依赖，**不宣称整个网页已压成这些字节，也不宣称全体系已净化**。运行时展开出的实体描述是显示/测试缓存，不按每栋楼另存一份源码。

薄梯板、三角踏步、连续扶手公式来源于既有 R06 `sketch-model.mjs`（仓库 haihao0307/guilin-dem-pipeline，固定共享基线 0df6843e5d124ff4574c531613310b79dfc96651），只提取本次需要的规则，旋转到无窗左墙。基础/棱柱计算亦是相同自有解析规则；没有外部网格。

扶手噪波默认零，仅在 ±0–2mm 改截面宽度，固定种子，主路径、杆高、孔洞与连接不变。它不是随机结构，更不是代替扶手几何的图案。

验证：72组生成参数，21,344旧底层占据对照点，12组基础通行检查及独立审查覆盖全部UI层高的52组门内至上层连续保守上身/净空扫掠，脚下射线为明确采样；实际GPU 81条斜棱柱阴影查询与CPU精确射线一致，另有双侧剖切局部验证。此为几何规则示意，不是结构或规范认证；云浏览器无WebGL2 Float32，未冒称整场视觉验收。
