# R05：双开间平台梁、框架柱与平台结构边

范围仅 connected 双开间规则示意，默认四层；不是任何真实建筑的测量、配筋或承压验算。单开间两个旧原型入口链接回 R04，不在本轮节点修改范围。

## 旧关系问题
平台梁后边绑定墙内面 z=4.94，梁轴在 z=4.815；框架柱轴在 z=5。因此偏心0.185m，梁柱截面仅在z向重叠0.08m。旧测试仅验证体积相交，不能说明采用了清晰的居中节点。

## 新统一接口
梁按支承柱轴 z=5 定位，保持0.25m梁宽和0.32m梁高；梁平面范围z=4.875–5.125、x=0–4，仍跨接两根柱。平台结构后边由可见墙内面4.94延到梁轴5，在0.12m厚墙内部嵌入0.06m，不越墙外面5.06。平台底与梁顶标高不变，各层1.64、4.94、7.94m。

平台与梁的平面重叠深0.125m是教学几何连接，不是安全承压数值。平台右侧1.35m外露梁仍保留，因为它继续连接右侧柱；不能截掉而让梁端悬空。底板、楼梯、扶手、电梯和门窗参数不变。

## 检查与回退
检查梁柱轴线、梁端截面投影、平台覆盖范围、无新台阶、墙内嵌边界、后窗不被堵、层数/层高重生成和回退。实际浏览器验证之后才记录成功；旧R04及此前版本不变。
