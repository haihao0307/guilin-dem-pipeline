# R17 检查边界

- 实际入口仍是 growBuilding(seed, parameters)。源外壳/楼层来自保留案例，并非重新测绘。
- Time → Location/环境 → Object → Building 是外部组织原则。当前 buildingMother.graph 只是单栋编译依赖关系，尚不是完整世界树序列化。造波属于对象表面/材质变化，不改变结构身份。
- 低楼通过 ordinaryDoorSystem='shared-function' 启用已有 r07 门函数；14个原洞口身份保持。龍總的 attachKccUnitDoors 在 growBuilding 后给既有设计分区补144门；不是已核A–F户型落位。
- 電梯复用原 controller、轿厢和门联锁。28个设计停层为 P01–P04、T01–T24；B1建筑节点保留但未加入电梯停站。设计序号1/4/28不宣称实楼门牌层号。
- 数值检查：关门/锁闭状态、完整到层退出、出口到目标房路线与其他闭门反例。路线为本模型采样检验，不是建筑消防、结构或无障碍认证。
- 浏览器演示使用加速状态推进和实际渲染截图，不能冒充实时流畅录像。已得的全精度优化等价测试只说明相同像素/命中结果；目前软件GPU逐帧仍需数秒。
- 窗台、内退、墙深为可更换设计参数。各面窗的位置由两配准候选承载，朝向歧义及真实窗框尺寸未消除。
