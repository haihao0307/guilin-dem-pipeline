# KAOPU 道路母体 r01 · 独立接口实验

状态：已接入香港地政总署 / CSDI 官方公开道路中心线中的 3 条，构建一个钟楼附近 T 形共端点的独立函数场实验。宽度、车道、设施与材质仍是设计假设。浏览器 QA / 发布状态以 evidence 报告和实际部署为准。

## 输入证据门槛

至少提供源文件可读内容、出处/许可、稳定道路 feature ID、折线坐标和坐标参考系。本实验使用 EPSG:2326，原点 E=835636.0250000004 / N=817300.9477000013；X=E−originE，Z=originN−N，单位米。原始坐标与变换均保留在 scene.json。官方 ELEVATION 字段是相对层级，不能直接当米制高度。

宽度、车道数/通行方向、路肩、人行道、路灯设备高度与位置分别标记 observed（证据观测）、inferred（推定）、design（可编辑方案）。取到真实中心线仍不等于取到这些字段。未知通行连接不得因平面线段相交自动生成。

## 实现

- core.mjs：二维中心线的里程/横向框架，有限厚度道路直接隐式场与射线求交，同源碰撞查询，车道语义、显式连接图、确定性材质函数、路灯锚点和示意相位状态。
- compileRoad 返回函数查询，不返回三角 mesh。无老师网格、贴图、程序依赖，无动态联网依赖。
- 当前只支持每个道路条目的常宽、常标高与折线段胶囊并集。圆角端帽是算法设计，不是已测绘路口轮廓；不能拿它宣称路口已重建。可变断面、超高、坡道、桥墩、真实路口轮廓均未实现。
- 程序噪波为确定性的自有设计噪波，尚无实测材质标定，不能称为“验量出来的真实香港噪波”。
- 灯控只是无冲突两组示意状态机，未匹配真实 movement、无香港实时输入，不是交通安全证明。

## 可视实现边界

WebGL 仅用全屏三角形承载像素着色器，**这不是道路形体三角网格**；道路 footprint 直接函数判定、平面解析求交，灯杆为解析圆柱/盒体求交。横断面控件同步修改语义参数与可视场。当前可视模型是水平表面实验，不宣称完整桥梁/纵坡/缘石工程实体。路灯杆姿态和造型为自有简化设计，所有高程为平路推定。表面噪波仅设计噪波，未实测标定。
