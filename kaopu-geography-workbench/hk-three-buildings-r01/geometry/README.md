# 香港三栋建筑：实测平面与轮廓谱 R01

本轮为可执行的局部研究 adapter，不是已冻结的全球 KAOPU 格式，也不是完整楼层、窗户、房间或建筑生长语义。

## 三栋真实来源

1. `B367642137201063C0`：33 La Salle Road，复杂低层屋顶，原几何约 14.789 × 19.102 × 10.913 米。已关联的入伙纸日期为 1957-08-01；当前模型不能据此被称为 1957 年外观。
2. `B359971994401063C0`：翼状高塔，约 24.477 × 31.930 × 70.203 米。名称、用途、年代、楼层数未核，不以视觉猜测补齐。
3. `B369121858401063C0`：宽体斜屋面，约 66.094 × 65.123 × 37.707 米。名称、用途、年代未核。源屋面有一个内部边界孔，本次保留并测试面积。

每个 `original/ID/` 下的 glTF 和 BIN 都是原件的逐字节副本，原下载文件不动。`*.provenance.json` 保存哈希、源图幅、节点矩阵和权利来源。数据来自香港特别行政区政府地政总署 / CSDI Portal，原始权利归政府及相关机构。条款：https://portal.csdi.gov.hk/csdi-webpage/doc/TNC 。不是 CC0，也不是政府认证的历史复原。

## 实际提炼了什么

- 应用 glTF 的完整场景节点变换，不忽略父子矩阵。
- 保持完全相同的源位置身份，只合并邻接、近共面的三角形，不焊接彼此接近但独立的点。
- 法线点积至少 `0.99999999`，相对组首平面的偏离不超过 `0.00025 m`。边界的共线清理阈值为 `0.00001 m`。实际最大拟合偏差记录在报告中。
- 删除内部三角化对角线，保留外边界和内部孔洞；由共享生成函数重新三角化。
- `wallStrip` 是墙边、下高和上高；`wallProfile` 是墙平面坐标、随高度的倾斜量和二维边界；屋面/下向面是高度平面与二维边界。接近竖直的面不当作屋顶，也不使用病态的高度函数。
- 通过几何法线推定墙/屋面/下向面角色，属于推断，不等于真实材料测量。没有推断楼层或窗门。
- 复杂低楼仍有许多小平面和边界例外。这是真实残余复杂度，本轮不为了体量合并掉真实差异。

`reconstruct.mjs` 只读取谱，不读取原件、source-preview 或提炼审计。它生成新的顶点、法线和三角形。源法线/颜色属性未逐位保留，重建几何法线并接已有程序材质，因此不能称为原 glTF 的无损文件编码。

## 接入与编辑

案例根目录相对路径写在 `buildings.json`。入口：

```js
import {buildGeometry} from './geometry/reconstruct.mjs';
const geometry = buildGeometry(score, THREE);
```

材质组：`0=墙`、`1=上向屋面`、`2=下向面`。返回标准 Three.js BufferGeometry。共享 Three.js 的 ShapeUtils/Earcut 保留多边形孔洞。

谱中可编辑每个墙带的端点和高度、各平面的轮廓与方程；这些底层参数相互有接触约束，单独改一点可能产生缝隙，当前没有自动约束求解器。界面安全编辑采用 `score.edits.scaleEast / scaleNorth / scaleHeight`，范围 0.25–3，统一作用于全栋，默认全为 1。改变这些参数属于明确的创作变形，不能继续声称与实测原件尺寸一致。任意非法值和未知生成器版本会被拒绝。

本地谱轴为东、北、上，米单位。输出几何轴为 X东、Y上、Z南。每栋保留原始地理锚点：水平 EPSG:2326，垂直 mPD。场景展览并排摆放仅用于观察，不改变谱里的真实地理定位。没有加入或重复携带 DEM。

## 运行测试

依赖：Python 3 + NumPy、Node.js、案例自带 Three.js。首次外部源提取使用当前工作区的保留源；交付包已有 `original/` 和来源收据，可直接从其重建谱，不需要下载全香港。

```bash
python geometry/extract_scores.py
node geometry/test_reconstruction.mjs
python geometry/verify_geometry.py
```

测试默认读取 `viewer/vendor/three.module.js`，也可设置 `THREE_MODULE` 为已有模块绝对路径。

## 已测结果与边界

`geometry-validation.json` 保存同口径字节比较、包围尺寸、双向表面抽样距离、多个水平截面抽样距离、孔洞面积、面法线方向、源哈希与重建确定性。

- 原几何每个三角形和重建三角形各取 10 个重心/边/顶点样本，计算到另一方三角面的最近距离。
- 在源高度事件之间的中点及总高 5%、20%、50%、80%、95% 做水平截面。各线段取端点及四分点，与另一截面的线段集合比较。
- 上述是明确采样验证，不是严格全表面 Hausdorff 最大误差证明。毫米以下数值吻合不能代表数据原始测量精度达到毫米，更不能代替视觉、历史或真实性验收。
- 原源面法线与重建方向对应检查；孔洞保留通过投影面积检查，并由独立 QA 再验。
- 相同谱在当前 Node/Three 平台产生相同几何哈希；并未声称不同 GPU 的像素逐位相同。

同 raw DEFLATE level 6，原 glTF/BIN 分别压缩，谱单独压缩：

| 建筑 | 原件 | 新谱 | 新谱/原件 |
|---|---:|---:|---:|
| 复杂低楼 | 5,232 B | 7,997 B | 152.8% |
| 翼状高塔 | 1,364 B | 1,060 B | 77.7% |
| 宽体斜屋面 | 1,455 B | 1,633 B | 112.2% |

共享重建器、Three.js、程序材质、证据索引、原件对照与展开后的 GPU 资源另算。数字以报告为准。本轮证明可以获得独立、可编辑、准确重建的平面谱，但三栋中的两栋没有压缩收益，不推演 2.3 万栋总压缩率。
