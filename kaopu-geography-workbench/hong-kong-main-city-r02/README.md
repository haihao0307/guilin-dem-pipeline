# 香港主地图 R02：全港外围与已就绪建筑谱

独立新增 `hong-kong-main-city-r02/`，保留公开 R01。既有地图、88线路、1970启德显示、44m钟楼＋7m避雷杆均沿用固定依赖。仍是同一 WebGL2 画布，未增加另一张独立地图。

## 当前交付范围

- 原官方完整目录113幅、23,414对象，其中1个源文件损坏，23,413可用。另加入两个图幅的494个严格历史选择子集；现在115个目录项不等于115幅完整普查。
- 已有5,386份谱，其中3,462规则谱、1,924含显式残余。17个高程控制矩形允许5,276个完整bbox入场，另110虽有谱仍待高程；18,137对象总体待高程、18,027待谱。
- 5,386份谱是本地档案总量，5,276是高程资格，不是历史入场数量。公开包只包含严格年代与高程双门禁通过的原谱对象；晚期、1997年日期边界、unknown离场。本轮存档713个年代/高程合格对象＝原219＋新494；默认场景只启用原219，新494全部待地面接触核验，不默认请求其块。谱包合计713，595规则谱＋118显式残余，29 gzip块4,924,435 bytes；全部数据目录5,946,233 bytes。历史对象具体ID见 `city-buildings/age-evidence.json`。实际送画数、驻留数、目录数分列。
- 本批无纹理，带图样本未接。33 La Salle原带图参考存在，谱UV映射与纹理转译尚未完成。
- 新外围覆盖113.79–114.50°E、22.10–22.65°N，保留官方30m水体类别和单节点小岛。DSM含树冠/建筑，不能称裸地DTM或精细岩礁模型。

## 铁路纵断面

现平面线路与4站里程逐值保留，改用共享解析纵断面：站内平段、五次平滑坡度过渡、区间常坡。游戏上限15‰可在 `rail-profile/game-design-constraints.json` 编辑后重载；当前解析最大5.41693‰，站内0。原线贴DEM曾达662.167‰，原件保留但默认不再驱动车轨。

轨道网格、车体俯仰与120Hz动力学重力坡度均取同一函数。Node实际驱动测试已验证坡向重力与分帧一致性；不是仅换一张平顺轨道外观。固定站高是作品设计值，不称铁路实测；参数冲突会报错，不能回退原不受限纵坡。

桥、隧道、路堑仅按相对地形提出候选，结构与衬砌未建。保留原role剖视逻辑，新增潜入山体区尚不等于已有完整隧道。平面折角仍待用户调整，纵向连续不代表平面切向已经连续。

## 共享相机与深度

七条路径统一同一帧 `cameraData` 的 `clipNear/clipFar`。far=150,000m；地图模式 near=clamp(distance×0.02,0.15,3000)m；跟随/站台等近处模式仍0.15m。Three实际相机值在 `HKTrain88.getState().render.clipNear/clipFar/clipProjectionMatrix`，用于核对raw GL。

原固定0.15m和初始100m上限在140km全域镜头下深度不足。独立量化对照复现低岛与海面相同D24码，所以采用共享动态near。该数值检查不等于GPU场景已验收；实际浏览器结果另附。

“全港含离岛”按屏幕比例自动拟合原始全域角点。极窄屏幕在55°视角与150km far约束内无法完整放下时，明确提示横屏，不偷偷裁岛。正常鼠标/触控操作保留。

## 外围显示缓存与海面

共享 `height-spectrum.mjs` 以240/120/60/30m分层线性基＋必要残差求值；显示网格是可重建缓存，不是更名原网格。当前驻留块统一30m高度级与完整30m水体mask，不用不同LOD拼缝或垂直裙边。

外围178个非全海显示块缓存合计72,731,940 bytes、2,871,122三角，已做CPU全块检查。单陆节点周围全部四个支撑单元保留。旧owned区域内不生成新地形三角。

海面仍使用原R03波浪、反射、泡沫与光照母函数，只扩已有高空矩形的空间域。旧域优先原mask；域外读官方30m水体分类的无损整图缓存（57,130 gzip bytes，4,968,652 decoded bytes）。未改旧湖河删除、旧海岸与旧高度数组。纯海不造地面，未知水类不猜海。

外侧120m接边为显式显示参数：仅新点与旧边界都为已知陆地时应用1−smoothstep权重，120m外归零。旧源样本与函数谱系数不改。原新旧边界最大3.203m差保留记录；此衔接不是高程测量或基准修正。

## 加载与内存边界

城市GPU96MiB、外围GPU96MiB，另全域海mask约4.97MB；既有宿主GPU另计，不能把增量预算称整页总内存。城市只并发解码1块，外围并发2块；异步过期结果不能分配GPU。

公开城市包只选有严格早期证据且合法datum覆盖的对象，保留每个原谱全部值。完整5,386份谱及310块大归档仍在本地，未发布块无HTTP依赖。先按小历史侧表过滤块，再在重建前逐对象核证据，未知/晚期不下载到GPU。没有量化、删谱字段或切三角；重新组合JSON包不是重新提炼几何。GPU预算不等于浏览器JSON解析峰值。

## 地面接触限制

新增494默认全部离场，其中493个处在30m背景DSM；离线中心采样诊断有15个bbox楼顶低于地形、443个底低于地形超过2m。中心点与bbox底不是基础接触面，且DSM含现存建筑/植被，不能据此挪楼或把正确mPD转换硬贴地。该批仍需实际浏览器剖验，不代表713个都完整可见或已贴地验收。原2m DTM首批仅4点对照，亦不是全楼基础验证。

## 年代与证据

默认严格早于1997-01-01，仅有可信建成日期或正向入伙纸记录的候选可入场。1997年内日期边界、晚期候选、未知年份在离场审计清单中，默认地图不画。现有数据无可靠建成年字段，不能把早期入伙候选称为历史精确复原；当前外形起始仍unknown。数据更新时间和照片日期不参与存在年代门禁。

四条Tower/裙房旧关联以独立证据补充更正，原几何谱原值不改。`HKCityBuildings.stats().agePolicy.submittedObjects` 是本帧实际提交绘制的ID、证据日期/类型/出处，便于独立核对，不只是UI数字。公开包不提供未发布现代归档的在线显示开关；源档案完整保留以便复核后恢复。

设施按源语义分类。路灯应是独立可编辑对象，但本批没有可靠语义、位置及安装年代，仍待提取；不能从纹理或未分类网格猜灯。码头/港口及地面道路网络也未完成。已定架空轨道、站和桥属于作品设定，单独保留，不自动套政府模型的年代过滤。


区域DSM2021发布，东西源雷达采集窗口2011–2014，逐像元日期unknown；局部CEDD DTM为2020产品、采集2019-12-20至2020-02-02。现代建筑更新日逐楼记录，建成/入伙/形状采集/照片/架空游戏时间各自分列。2026装配日期不代表建筑年代。
