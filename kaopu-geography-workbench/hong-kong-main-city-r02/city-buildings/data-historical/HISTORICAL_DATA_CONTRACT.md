# Strict historical object subset

Only complete, unmodified recipe objects with evidence strictly before 1997-01-01 and whole-object datum coverage are shipped. This package retains metadata for the original 113 complete source tiles plus two additional selected-subset tile entries, but an index exists only for tiles with selected active objects and contains only those active objects. Tile modelCount remains the full source count; activeHistoricalModels and index.modelCount state the selected count.

The full 5,386-ready archive and 23,413 usable source indices remain local, not downloadable from this package. Pending and 1997-boundary objects are offstage. Occupation permits are evidence of prior existence, not construction years or proof of unchanged historical exterior. Four separately sourced Tower/Podium join corrections are required in ../age-evidence.json; apply them to an ephemeral score before age evaluation, never change the raw recipe.

The two runtime modules are unchanged. Shared Three.js ShapeUtils/Earcut is supplied by the caller. No source glTF/BIN, raw archive, source texture or modern full-archive toggle is needed at runtime. Source HKPD values require the existing explicit datum transform; do not snap to terrain or extrapolate.

HKSAR Government, Lands Department / CSDI Portal. Source terms: https://portal.csdi.gov.hk/csdi-webpage/doc/TNC . Keep source attribution and distinguish residual exceptions from extracted rules.

The two added tile entries contain 494 selected historical parts only, not an exhaustive official tile census. Original archive counts (5386 recipe-ready / 5276 datum-alignable) remain separate. The public union contains 713 unique parts in 29 chunks.
