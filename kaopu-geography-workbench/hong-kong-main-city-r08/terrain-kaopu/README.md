- 两者合计17,993,792 B。相对转换前20,334,602 B减少2,340,810 B，约11.51%。内区30m包减少7.61%，旧5块细节包减少26.24%。

口径：这是所有压缩数据文件的准确字节数，包含共享复用的地形数据，不是首屏网络流量。外围按视野选择加载，320块里178块符合外围地形绘制条件。新共享清单196,023 B、轻宿主195,710 B、已有外围清单972,267 B及已有九龙清单54,752 B、外海掩码清单876 B另计；运行代码、建筑、火车等不计入地形数据。JSON/HTML可能由服务器另行压缩，HTTP实际传输以浏览器Resource Timing为准。

## 本次实际转换什么

旧宿主内嵌的30m背景与5块细节2m/5m高度数组，转换为与现有香港CEDD谱相同的加法可分离双线性hat基函数：节点步长8、4、2、1，末级保留精确残差。共享生成器重建高度，宿主继续生成可丢弃的显示网格；不把TIN或完整mesh伪装成函数化文件。

沿用现有 kaopu.hk.cedd-local-height-spectrum/0.1 的数学定义及累计顺序。本包是局部传输适配 schema kaopu.hk.height-spectrum-bundle/0.1，新增通用网格步长、显式掩码/来源权重通道和无损稀疏存储。不是另行宣称统一KAOPU万能格式。

编码严格为：非零Float64系数位图 → 非零系数的8个字节平面 → 原UInt8掩码/权重 → gzip。只省去位模式为正零的系数；负零及所有非零位均保留。解码后先验原Float64系数SHA，再验重建Float32高度SHA与掩码/权重SHA。不是改后缀，也没有新增高程量化。

外围320块原本是 kaopu.hk.hierarchical-height-spectrum/0.1；九龙4块原本是CEDD局部谱，均按原版本复用，不重复转换或重复载入。外围原Float32谱已有最大约0.0000038147米数值重建差，不将其重新说成逐位无损。

## 精度和覆盖边界

11个转换字段全部通过Python与JavaScript全量往返；当前Float32高程逐位相同，水陆掩码和来源权重逐字节相同。0.5m是原始CEDD测绘源间距；当前场景是2m/5m显示、局部覆盖，仍有源窗外合成过渡及旧作品地形。不是全线0.5m载入，更不是原始测绘0.5m的无损复制。原始数据、坐标、高程基准、历史填海/作品编辑标记、来源与未知精度均保留。

## 加载慢的原因和改动

旧14,691,672 B宿主中有14,497,556 B地形base64，32个数组顺序解压；然后启动时同时构建两档细节网格。R07把宿主减到195,710 B，地形压缩包并行下载，用一个模块Worker逐包重建，避免解码阻塞UI和多个最大系数展开同时驻留。浮点缓存仍是显示派生结果。

云Linux Node测试11包依次解码/校验共约403毫秒，最大包约137毫秒。这不是用户设备首屏时间，也不是FPS测试。浏览器会记录load/decode、worker模式和每个请求可用的传输指标，具体看HKKaopuTerrain.stats()与同版浏览器QA。

内区高度/掩码/权重数组仍约20.71 MB。原渲染一次顶点/索引约177.78 MB，海岸/隧道裁剪和临时副本另计；外围按视野分配，GPU预算96 MiB。因此压缩文件变小不等于GPU内存同比下降或FPS自动提高。此版保留成熟地形裁剪和洞口链，不以降精度换体积。

## 接入与回退

调用loadKaopuTerrainHost()，返回已由原patchDynamicVerified('r03')验证过的动态投影宿主。其非数组元数据仍内联，以保留原站点/标签补丁锚点。之后照旧执行机场、CEDD、海岸闭合、隧道裁切等R07补丁；不要再次执行r03动态投影补丁。

旧R06及全部旧依赖保留不改。地形转换可通过继续使用R06回退。

复现：在包含相邻固定旧版本的工作区，运行tools/convert.py（Python+NumPy），再运行tools/build-host.mjs，最后运行tests/roundtrip.mjs。转换器只接受SHA54487b03…的原发布R03宿主。包内测试验证所有新数组、损坏包拒绝和宿主轻量化；完整海岸/洞口/列车浏览器验收由同版R07总测试承担。
