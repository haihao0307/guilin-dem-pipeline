# 香港主地图：渐进式建筑谱层 R01

入口 `index.html` 直接在既有香港地图的同一 WebGL2 画布中加入建筑；鼠标拖动、滚轮拉近，右侧选图幅或点楼查看来源与年代。

## 冻结数据与当前可见范围

- 113 幅已下载源索引，23,414 个原对象，23,413 个可用。1 个原始损坏文件隔离，2 幅本来为空。
- 本轮冻结 11-NW-15B 的 464 栋谱：380 完整规则，84 含显式残余；81 个原始退化面保留诊断，不进入 GPU。
- 464 栋可重建不等于全体可对齐。现有官方转换控制矩形使首幅 354 栋完整 bbox 可对齐；110 栋等待高程控制，不生成猜测位置。
- 全源对象中 5,276 栋 bbox 可完整进入现有 17 个合法控制矩形，18,137 等待转换控制；此数与待谱转换分别列账。全量谱仍在逐批提炼。
- 本轮 manifest SHA256：`4509fd4934eedba1145e8bc92b4cc4a345756fbc2fa4a4ead6d4109ea136dd04`。所有已引用压缩谱、索引保留长度与 SHA256。
- 灰色外观仅便于检验几何。没有加入摄影贴图、虚构窗格或冒称实测立面。当前游戏年份为架空待定。

## 保留的地图层

来自最新本地 train88-kaitak-r01 宿主：哈希锁定已发布 R03 的 DEM/海面/原线路、现有 88 列车、1970 启德参考复建、已校准 44 m 钟楼加 7 m 避雷杆。原 R03 入口和所有旧文件未改。该本地组合此前未发布，本轮需独立浏览器验收。

已有失踪部门候选的有限缓存保留。九龙城寨对照原工程仍在，但同版本地图缓存缺失；本入口明确显示未载入，不重造替代物。已有设计站棚尺寸不升级为历史实测。机场/站楼参考复建不能当作现代建筑源采集日期。

## 几何与共享函数

游戏建筑仅请求 `city-buildings/data/` 中的 KAOPU 研究谱，重建用同一 `runtime/reconstruct-robust.mjs` + 原 `reconstruct.mjs` 与 Three ShapeUtils CPU 三角化。原 glTF 只用于离线提炼和独立验核，运行时不请求原件。

总账包含共享程序一次、每对象规则参数、显式三角残余、退化诊断、地图缓存。不能把单对象谱压缩率当作整个共享体系压缩率，也不为压缩丢失洞、朝向或例外。此适配器仍为研究格式，未声明全局 KAOPU 标准已冻结。

按视野渐进下载，每次最多 2 个块，实际建筑 VBO 总预算 96 MiB。相机切换后过期异步块不会分配 GPU；不再需要的块释放。每块合批一次绘制，共用一个检查材质程序。GPU 缓存可从谱重建，不冒充谱本身。

## 坐标与年代

源 EPSG:2326，mPD；地图原点 E=834000、N=827000，X向东、Z向南。通过既有官方 LandsD 转换控制与本地 EGM2008 geoid 链，将每顶点 HKPD 变为 EGM2008_model。仅允许整个对象 bbox 位于一个验证过的控制矩形；没有域外外推、常量猜高或 hkHeight 贴地。覆盖线只是索引标注。

高程基准一致性不等于绝对精度，也不等于逐楼地面接触已核验。区域 DSM 可能含屋顶；本轮地面逐栋验核计数为 0。

UI 分开列 DSM 2021 发布/采集未知、CEDD DTM 2020（2019-12-20 至 2020-02-02 采集）、逐栋资料更新、形状采集、建成、入伙纸、照片、游戏日期。缺证据为 unknown。入伙纸不能用作当前外形年代。

## 测试与接口

`node tests/data-contract.mjs`：精确快照哈希、113 索引及3谱块校验、464重建的有限值/重复哈希/分账、354高程门禁和拾取数学。结果写入 `provenance/LOCAL-CONTRACT-RESULT.json`。

真实浏览器由独立 `qa/browser.cjs` 和只读 `qa/workflow.yml` 检查。同画布、首图、实际滚轮、开关、既有图层、内存预算与移动布局均需真实图确认。CPU 合同通过不表示视觉验收完成。

调试 API：`HKCityBuildings.ready` 仅表示索引准备；`stats()` / `getState()` 返回实际加载/可见/预算/失败计数；`focusTile(id)`、`selectTile(id)`、`setEnabled(bool)`、`selectObject(sourceID)`。首图等待 `visibleModels > 0 && loadingChunks === 0`。
