# R05 · 道路断面与金属连接

状态：写实质量待验候选。数值、渲染与交互通过不等于 AAA 艺术验收；未作为正式成熟资产入库。

独立新增四案例：旧水泥、旧沥青、镀锌晾衣架、油漆招牌钢框。R01–R04及原始母本保留；此版不是全材质重做或结构认证。

## 由代码和网格确认的旧问题

- R03道路是平整盒体；裂纹来自4段直线距离，−2mm高度仅进入法线，没有断面位移。
- 晾衣架墙座离墙46mm；后两条横杆端部比斜挑杆轴高约100.47/50.85mm；两根下斜撑缺墙座。
- 招牌墙座离墙5mm；后横杆端距框侧17.5mm；面板后距支承24.5mm；面板螺栓离面板30mm。

新金属几何的实际三角形连接、墙座接触、锚杆穿板入墙、同轴套座、框体对接由 qa/metal-geometry.test.mjs 验证；不是只检查包围盒。

## 道路因果场

复用 KST1 水泥母体的噪声、颜色、粗糙度与微高度方程，外接新自主程序破裂场。连续域扭曲、特征竞争和局部激活产生连通分叉、变化宽度及侵蚀；没有绘制裂纹线段或导入纹理。

同一场驱动可见尺度网格下陷、边缘剥落、断面轮廓、骨料显露、微高度和粗糙度。几何采样以下的颗粒/裂隙用连续滤波的微表面补充，不冒充全部是真实三角形。施工缝独立于随机裂纹：水泥案例有实体缝宽和退下的密封/填料。

路政署 H1105 图纸记载 June 1994 修订，作为20mm膨胀缝及密封构造学习来源：https://www.hyd.gov.hk/en/technical_references/standard_drawings/hyd_standard_drawings/doc/section_1/pdf/h1105.pdf 。本例尺寸、混合料与损伤不是某条历史街段的实测还原。普通标线用白色；不推断具体1997年前线型。

## 金属构造与分层

原KST1派生跨度、挑出关系及招牌框尺寸延续。新增完整墙座/锚杆、套接、焊缝与空心截面。每个实际连接位置输入材质场，长期积污和下淌从连接处发生。

招牌面漆、底漆、裸钢和氧化物的权重由一个连续损失场求得；涂层厚差、蚀坑、颜色、金属度和粗糙度同步。裸钢按金属响应，漆/底漆/锈按介质响应。晾衣架采用镀锌层、白色腐蚀物、局部露钢与钢锈，没有硬套油漆底漆。

FH88 原始 mt_kh/mt_kn/mt_kfb 方程保留于 metal-surface.mjs；其余层损失、接头驱动与微高度是R05新研究。M+约1978森美餐厅招牌资料列锌、钢、油漆，只支持材料类别，不能把拆卸后运输支架当原装结构：https://www.mplus.org.hk/en/magazine/collecting-neon-signs-from-hong-kongs-streets/ 。

## 坐标、显示和边界

- 全部米制局部结构坐标；两侧同光照，右侧控制损伤，左侧保持完整基准。
- 中景、近景、断面/连接侧景、旋转、湿润及诊断通道；静止按需停止重绘，几何变化重算阴影。
- 微表面梯度与像素足迹过滤保留；材质程序不是水动力、化学腐蚀或应力破裂求解器。
- 几何接触正确不代表承载力、焊接强度或施工规范合格。
- 金属涂层微高度是微表面近似，未生成每一片翘起漆皮；分层颜色不代表化学成分已标定。
- 原玻璃、墙面微孔未改。不同石种、云母质感和木门榫卯连接保留为后续检查，不在本轮冒称完成。
