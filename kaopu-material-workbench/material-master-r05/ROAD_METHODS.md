# R05 道路接收体：柏油与 KST1 水泥

## 冻结与范围

独立新增 `road.mjs`、`road-field.mjs`、`road-material.mjs`。R02、R03 的文件及来源快照保持原样。两个案例均为程序研究，不是特定街道的扫描重建、工程路面设计、年代还原或结构寿命模型。

旧 R03 的已核查缺陷：裂缝由四条相连直线段计算，磨损只改变颜色、粗糙度和最多约 2 mm 的法线高度；接收体是未随损伤变化的长方体。R05 不继续以直线遮罩冒充自然裂缝，也不只增加颜色老化。

## 母体与新方法

- 水泥保留 KST1-surfaces-2 / ST_FAMILY 8 的原始噪声、0.63 / 3.7 / 127 频率、颜色及细高度方程。机械 GLSL 转写来自 R02 的 `sources/concrete-kst.mjs`，SHA-256：`e0eb596c2d3b38526c2bcecadb2baa10b197e8cf9669fab37c9654cdad3f1d5d`。数值测试核对冻结源哈希；不声称 WGSL 与 GLSL 已逐浮点位证明等价。
- 柏油是独立自有程序研究，不用煤、黑塑料或水泥换色代替成熟柏油母体。较暗沥青结合料与分散石粒有不同颜色和高度；剥蚀提高同一位置的骨料暴露率。
- 新裂缝来自整数晶格特征竞争、连续域扭曲和低频应力激活。无手绘线段、裂缝贴图、教师材质、受限照片或付费资产。此类场形成不规则连通分支、宽度和深度变化；“应力”仅是可审查控制场，不是受力求解。
- 同一 `roadPotential` / `roadDamage` 算术用于 CPU 顶面、截面顶缘、GPU 裂缝/剥蚀/修补遮罩、颜色和粗糙度。磨损影响真实几何；当前水膜与累积车流历史独立，不改变断裂几何。

## 实体尺度与检查角度

默认样段 3.4 × 4.8 m，顶面 y=0。柏油实体厚 0.14 m，水泥实体厚 0.18 m；底下增加 0.075 m 示意支承层。它们是可近看、侧看、绕看的完整顶面、四边截面和底面，非无限平面。支承层是简单示意实体，不声称逐颗粒几何。

默认顶面网格间距不超过 18 mm。宽侵蚀沟、损伤凹陷及边缘下落为真实顶点位移；亚网格裂缝开口和骨料仍是细法线，不是独立石粒，也不是贯穿开口。着色器从完整宏观高度中减去插值网格高度，再补细法线，避免宏观位移被重复计算。细梯度采样间距 0.7–3 mm，并按像素的米制足迹滤除不可分辨粒级；裂缝和标线边缘使用 fwidth/米制足迹抗锯齿。

水泥分成两个真实板体，中间有 20 mm 分离、下凹密封槽和填料实体。施工缝与自然断裂是不同来源和不同几何。结构参考为香港路政署 [H1105](https://www.hyd.gov.hk/en/technical_references/standard_drawings/hyd_standard_drawings/doc/section_1/pdf/h1105.pdf)，研究同伴核对其 June 1994 修订记录。此处没有因此声称混凝土板尺寸、密封配方或整个构造已满足该图全部规范。没有新增井盖案例。

白色标线默认开启，可用 markings=false 关闭；仅为常规白色标线研究片段，不虚构具体年代、街道、法定宽度或完整行车组织。

## API

`buildRoadCase(THREE, {family:'asphalt'|'concrete',variant:0|1,wear,history,wet|wetness,repair,mode,width,length,spacing,markings,seed,topY})` 返回 Group。

- `userData.update(next)` 原位更新。wear/repair/variant 更新真实顶点和法线；wet/history 仅更新光学状态。family/width/length/spacing/seed/topY 属结构变更，明确报错要求重建，避免 GPU 与几何不同步。
- variant=0 的基准不随磨损、修补、水膜或历史滑杆变旧。
- `userData.metadata` 提供尺寸、截面底高、网格间距、来源与限制；`userData.audit()` 提供顶点/三角形/高度统计；`userData.sample(x,z)` 可直接检查实际使用的场。
- `userData.dispose()` 幂等释放本模块自有几何和材质。外部传入的 material 不由模块销毁。
- 模式：0 最终、1 宏观高度、2 粗糙度、3 裂缝/边缘损伤/修补 RGB、4 骨料/标线/结合料 RGB、5 着色法线。

固定近景目标（seed=23, wear=.65）：柏油 local [0.10, −.009, .60]；水泥 local [.28, −.006, 1.18]。自然水泥裂缝不与 z=0 的施工缝混淆。地台需要低于 y=−.255 m 才能看见整个截面。

## 本轮证据与待验收范围

- `node qa/road.test.mjs`：22 项通过。包括冻结母体哈希、场与实际顶点一致性、有限法线、实体高度变化、历史/水膜独立、基准不变、原位更新、真实施工缝、场连续性、非恒定裂缝宽度与释放。
- 默认网格：柏油 54,596 顶点 / 102,764 三角形；水泥 56,152 / 103,164。wear=.8 的采样：柏油裂缝核心面积约 4.87%、侵蚀边带约 14.36%；水泥核心约 1.15%、边带约 3.50%。不是实测道路统计。
- `node qa/road-shaders.mjs`：实际修改后的 Three r170 标准材质顶点/片元着色器，在原生 Mesa EGL / ES3 编译与链接均通过。该检查直接复用只读 R04 EGL 测试器，不启动 Chromium。
- 不把编译成功、CPU 测试或统计当作视觉验收。实际浏览器、PMREM/阴影变体、近中远侧构图、手机布局、性能与视觉质量由集成 CI 继续检查。当前没有宣称成品视觉已通过。
