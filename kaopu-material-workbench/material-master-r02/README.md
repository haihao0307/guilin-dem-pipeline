# KAOPU 材质大师 R02：街道物件与道路

独立研究案例。R01 墙/石/砖和原材质工作台 R18 保持原样。

## 五个实际用途样例

- 油漆钢制灯杆：底板、螺栓、检修盖、接缝、弯臂与灯罩；约 3.8 m。
- 香港挑出式晾衣架：1.8 m 跨距、约 1.29 m 挑出、斜撑、墙锚及有垂度的晾衣杆；少量布片只提供用途/尺度线索。
- 招牌金属框：框边、撑杆、斜撑、锚板、紧固件和背面承杆；空白牌面使检查集中在金属构造，不使用受限字体曲线或商业图样。
- 柏油道路：6.6×9 m 双车道研究样段，程序骨料、定向轮迹、局部油污、连通裂缝、补丁、标线和排水格栅。
- 水泥道路：保留 KST1 水泥母体方程，叠加伸缩缝与道路使用层。

左侧新制状态固定；右侧使用状态实时变化。近看、侧看、旋转、缩放均可操作。遮罩 RGB：金属为涂层破损/向下水痕/修补；道路为裂缝/积累污痕/补丁。

## 因果与边界

金属破损遮罩共同决定漆层消失、裸基材/氧化物比例、粗糙度和微高度；氧化物按电介质处理。镀锌晾衣架使用偏白氧化层，并只在连接与明显磨损处混入钢铁锈色。历史水痕沿重力方向，从接缝附近向下延伸；当前湿润独立控制，不用 wet 参数替代长期锈蚀历史。

道路裂缝由相连线段构成，修补与裂缝共享位置；轮迹沿车道方向，油污是局部来源，标线保持米制宽度/长度并随旧化磨损。颜色、粗糙度和微高度共享相同原因遮罩。

这些是可审查的研究参数，不是实测腐蚀律、镀层寿命模型、工程标线标准或香港道路标准。主要损伤目前只改微表面法线与光学响应，没有真实腐蚀截面损失、深坑、结构强度或路面破坏几何。仅底座、杆件、框架、路板/路缘等宏观构造是真实网格。
