## 两处有界增量

1. 水泥：同一3D体积颗粒场切出顶面与断面，浆体退蚀、粒料相对显露、孔隙、微高度和粗糙度联动。KST1母体噪声与原道路网格/裂隙场保留。粒料仍主要是微表面，不冒称逐颗真实几何；裂缘原网格折面未全部消除。
2. 金属：剥层横向过渡使用米制约束，与涂层垂直厚度分开；原FH88噪声保留，氧化成熟度与保留/接头场联动。独立累计各相漫反射贡献和F0，减少原先先混色再混metalness的交叉污染；粗糙度仍是单一Three近似，不是完整多相BSDF求和。
