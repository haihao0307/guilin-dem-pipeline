## 操作与后续规则入口

左侧选择材料分类，顶部切换原有配方，中间使用原生工作台；来源面板能核对材料类别、单位、固定提交及能力边界。一次只运行当前材料的iframe和原生Worker，切换引擎会回收旧实例；同引擎切换配方不重复下载运行包。

规则草稿区已建立材料身份、来源版本、单位以及颜色、粗糙度、各向异性、纤维光泽、透射、厚度、法线、位移通道。支持本地保存、刷新恢复、JSON导入导出与版本冲突拒绝。表达式仅作为文本保存，不执行、不自动改动任何原生着色器。

后续开发入口：私有源仓库的 `registry.json`、`SHADER_RULE_CONTRACT.json` 和 `native-bridge.js`。纤维、织法和染整分开登记，后续统一规则仍需针对各原生引擎适配；本轮没有把全部材料改成同一个着色器或物理解算器。
