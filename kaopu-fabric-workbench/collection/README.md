## 本轮统一了什么

材料目录、纤维/织法/染整分类、原生版本追溯、按需切换、单活动引擎及规则草稿入口。保留原生参数和试验，退出引擎时回收其iframe与Worker。

规则草稿有独立版本、材料身份、来源、单位和颜色/粗糙度/各向异性/纤维光泽/透射/厚度/法线/位移通道。支持本地保存、JSON导入导出、刷新恢复与冲突拒绝。表达式只作为文本保存，不执行，不自动改变任何原生着色器。

## 仍未完成的统一工作

没有将全部材料改为同一个着色器，没有统一各引擎的物理解算或实测标定。毛衣/丝绸使用源仓库已有的EB1适配；牛仔/皮革保留选中版本的原生照明，因此不是跨引擎同光逐像素对照。

毛衣/丝绸保留原有光学查找表，运行包约73 MB，首次选择仍有下载和内存成本。本轮没有开发动作缓存、新的距离分档LOD或性能调度器。

测试使用Chromium软件渲染；毛衣截图使用原生参考几何、手动渲染、暂停、1倍像素，关闭测试用时间累积及2倍静态超采样，实际发布默认质量与纱线几何未改。测试不是用户显卡帧率认证，也不是手机实机认证；手机只检查390×844 CSS视口。
