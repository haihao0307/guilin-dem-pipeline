## 真实渲染边界

不是纯噪波。使用P02参数化结构、可编辑噪波、结构化随机弯曲毛丝与光照。纱线本体保留R03的80段曲线场近似；毛丝采用原SourceFibres的根部、方向、弯曲方法作为来源，转成GPU内按固定种子生成的8段曲线投影，具有真实纱线深度遮挡。毛丝相互透明合成采用光学深度加权近似，不是逐层精确排序。独立毛丝不参与物理。
