# 毛衣距离噪波 R03

本实验比较距离直接控制噪波频段与像素覆盖控制频段。A 的策略输入仅为世界距离 uniform，不读取纱线像素直径、画面尺寸或 FOV。B 用相邻射线与承载平面的交点差估算覆盖范围，不是普通光栅片元 fwidth 性能基准。C 固定六层。第四路以 A 同样权重强制算全部层，检查跳过零贡献层的收益。

三路使用同一 P02 针织中心线来源、相同三维扫掠场与新体积绒毛场。针目28×54、针距11.6mm、名义半径1.72mm；曲线以共享80段近似，1360采样中的中心线偏差最大约0.026889mm。这不是整个表面、遮挡或绒毛精度的认证。新绒毛不是旧工作台960根独立毛丝的一比一复刻。单块静态布片，没有布料物理。

没有应用层纱线三角形绘制，没有整体表面点云，没有生成图片或视频代替三维。网站由真实WebGPU compute输出。允许旋转、连续改变距离、修改FOV、实际像素和绒毛强度。主线与R02未改动。

## 测量边界

完成耗时等待GPU完成，不包括结果回读和截图。GPU判断与渲染分别计时。软件适配器按8行分批；硬件路径保持原命令提交。分批不减少像素或样本，不禁用浏览器保护，不选择CPU回退。软件额外提交等待计入完成时间，不能据此推算实体显卡FPS。网页不预填旧测量，访问设备当场重测。

本版仍通过共享曲线场寻找表面、处理阴影并积分体积绒毛。即使控制规则便宜，后续渲染仍可能昂贵。因此这里只能比较控制规则与跳算机制，不能声称完整的纯噪波毛衣已实现或已被证明无效。近景观察仍有纱线偏硬、绒毛偏弱的问题，质量未晋级。
