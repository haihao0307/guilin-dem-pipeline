这是设计形体展示，不是 GarmentCode 裁片的物理缝合结果。形体与原纸样通过参数及来源身份关联，不是三维面片与原裁片顶点逐点对应。展示褶皱是程序化几何，不是实时布料模拟。尚未认证任意搭配的相互碰撞、无穿模、动态穿着、材料应变、缝份或制造可行性。现有 R07.4 的成衣物理门槛和失败记录继续保留。physicalFitAccepted=false、dynamicWearCertified=false。
