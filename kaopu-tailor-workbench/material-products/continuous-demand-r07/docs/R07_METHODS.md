# R07 闪烁与卡顿定位及修复

任务起点 2026-10-15 07:17:52 UTC；三小时上限 10:17:52 UTC。本地 R06 基线 `e5c3878`，公开 runtime tree `96863267eab7922b4b7c8bc72f1d8519ac9fb8fb`。独立 `candidate-r07` 保留全部 R06、早期失败研究与源资源。

## 确认的问题

R06 固定镜头走路时仍按每帧衣片深度的向上取整值重建纱线。基线 12 秒内上衣重新采样 21 次，显示帧间隔 P99 约 50.1 ms，约 49.5 FPS。重建包含新几何、MRT 形变缓存和旧资源释放，不能用平均 FPS 掩盖帧间停顿。

`solid-helpers` 的实例几何直接共用了模板的 BufferAttribute 和 index；固定 Three r170 的 `WebGLGeometries.onGeometryDispose` 会无引用计数地移除这些属性的 GPU 缓冲。现改为独立 BufferAttribute 对象并共享不变 CPU 数组，避免释放生命周期交叉。单独修复的视觉影响没有被独立量化，不将全部改善归给这一项。

画布的 antialias 不会覆盖原生皮肤管线的离屏 half-float beauty target。服装先画进这个单采样目标，再合成到画布，细纱线的亚像素覆盖已在此前丢失。

## 实现

- 按投影误差加入迟滞。固定镜头动作可必要细化，不反复粗化；镜头稳定后或暂停检查仍能调整。保留原针目数、股线和源曲线，未使用模糊贴图或减少画面分辨率。
- 暂停时的迟滞到期由一次性计时器唤醒，不能依赖物理继续推进，否则拉近后不会恢复细节。回到全身后允许释放自身大缓存，避免近景细节永久拖慢后续动作。内存紧张的粗化在下一次 beauty/shadow 绘制前原子替换；没有空白中间帧。
- 对原生 HDR beauty target 启用颜色与深度格式共同支持、最多 4 个覆盖样本。Three r170 解析颜色/深度后，原生面部辅助通道读取其已解析 framebuffer，保留相同遮挡。完整皮肤和灯光继续使用原实现。
- Worker 按下一个固定物理步截止时间请求，减少零步往返。原固定步和单调钟表目标不变，不丢弃累计时间。

## 核对方法

帧间隔来自整个提交帧 GPU timer 的 begin 时间，不是最后全屏三角形的 `renderer.info`。闪烁代理指标冻结身体和衣物，在 0.75 像素范围内用 4×4 相机偏移，读取上衣区域线性 half-float beauty 亮度的相位 RMS。开关顺序为关、开、关、开，结果重复。此指标反映受控亚像素覆盖波动，不是所有动作全部闪烁消除的认证。

拉近以实际裁片顶点为观察点，检查采样增加、原纱线数量、显存有界以及返回全身后的回收；暂停期间模拟时间不推进。物理解算、原生动作和区域耦合模块字节未变，本轮不新增自由布料、完整自碰撞、CCD 或裁缝生产验收。

最终公开版、录像和集合切换的结果以 `qa/R07_EVIDENCE.json` 为准；`r07-first` 是较早的本地性能对照，最终发布还应核对本次全部修改。

## 实际集合入口的第二轮修正

较宽的集合画布仍出现帧间停顿。4/2 覆盖采样的交替测试没有稳定显示降为 2 有益，因此最终保留 4。尝试过有界实时姿态插值（原骨长、同时间衣物端点），但主线程增加约 3.4 ms，实测仅约 42.3 FPS，已撤回；失败代码保存在 `qa/rejected-r07-presentation`，不在运行时中使用。

最终由主光生成实时阴影，冷暖轮廓光和补光仍保留颜色、强度及方向，不为轮廓光重画第二套服装阴影。同页按双阴影/单阴影/双阴影/单阴影交替，两个单阴影窗口约 59.94 / 59.31 FPS，P99 约 16.8 / 21.4 ms；对应双阴影约 56.57 / 57.69 FPS，P99 约 33.4 / 33.6 ms。未关闭主光阴影或移除纱线。
