# MP05-GPU-R02 · 最新人物、原生动作、EB1 与 GPU 试衣候选

**状态：人物与灯光接入可检查；实时服装性能与快速动作稳定性未完成。** 这是独立开发候选，原 MP05 页面和 R01 基线保留。

## 本轮结果

- 人物来自人物总工作台 `d413d108704af47cf531ee8c25d93f682c3176e3` 的完整生成运行时。没有把最新人物换成导出的静态替身。原生 104 根骨骼与完整权重参与 GPU 蒙皮；同拓扑新体型采用显式裁片放码，原裁片来源与新放码散列分别记录。
- 动作接入 `8d0860881f34cd6d459b1099028f56dfc7b70a2c` 的 CMU 16_15 走路、16_35 跑步、16_01 跳跃，以及其肩臂连续性和手指修复。走跑在原地观察，跳跃保留垂直位移。本人物显示与求解绑定抽样误差小于 0.00004 mm，骨长变化小于 0.00019 mm。
- 灯光采用 EB1 1.1.0 原代码，固定来源 `haihao0307/Humanoid-Rig-Lab-Next@beb3dda0a28f732e1e387dd68cc0d90f27ce8b7b` 的 `lighting/eb1/eb1.js`；统一冷暖默认配方保留，另有冷主暖边、中性商品、窗侧柔光和单灯表面检查。
- 新 WebGPU WGSL 后端实际计算距离、二面角、应变保护、当前人物三角面及上下装接触；保留 1/60 秒外部时钟、240 Hz 子步、16 轮主求解、12 轮保护和原顶点／边中点／面内样本。图着色避免并发修改同一物理节点。旧 WebAssembly 后端只作初始化不支持 GPU 时的回退，最新人物快速动作的回退路径尚未认证。
- 原缝线改用三个 GPU 帧场，顶点与阴影共用原路线和闭合截面。1869 个参考采样的中心误差最大 0.000075 mm、基底误差最大 0.000107；浏览器无着色器错误。整页测得主线程更新中位约 0.2 ms。
- 固定身体的上传、法线及 BVH 复用只在身体未改变时成立；重置、适配、动作和失败均失效。90 步消融对照的全部控制点与速度差为零，独立求解范围中位 25.6 → 23.6 ms。没有停止衣物求解。

## 性能与稳定性边界

修正静态身体复用之前，实际 1440×1000、DPR 1 的三轮各 60 秒 K04 整页测试：已完成绘制约 27.5–27.8 帧/秒，物理单步中位 35.3–35.4 ms，GPU 时间中位 26.7–26.8 ms，实际模拟／钟表时间约 0.458–0.461。**这是失败的实时目标，不能称为 60 Hz。** 静态复用之后再测三轮各 60 秒：实际绘制 28.5–29.2 帧/秒，单步中位 33.5–34.0 ms，GPU 中位 26.3–26.5 ms，模拟／钟表比 0.476–0.486；仍未通过实时目标。不将独立求解器用时当作整页帧率。

走、跑、跳的实时穿衣会在腋下等挤压区触发 1.45 倍拉伸保护。失败步回滚位置、速度、历史状态、约束乘子、人体姿态、腰带绑定与时间；保留上一帧并停止。当前不能保证快速动作不穿模，不能标为稳定交付。

“检查人物动作”明确隐藏衣物、暂停物理，单独查看同一最新人物的原生动作；它不算服装物理通过。“实时试衣”仍使用当前物理状态，没有衣物动作回放。

当前采用 WebGPU 计算读取到 CPU，再交给既有 WebGL 人物和纱线渲染，**不是零拷贝或单设备完成的最终架构**。需要后续继续处理统一渲染、接触可行性和误差约束；没有用降低重力、改慢模拟时钟、减少针目或删除碰撞来伪造结果。
