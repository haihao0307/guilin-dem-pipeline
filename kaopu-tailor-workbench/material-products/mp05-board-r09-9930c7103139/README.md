# MP05 R09 · 服装案板

打开先选上衣和下装版型，再分别选材质，最后确认试穿。四款上衣、三款裤装沿用七份原裁片记录；版型目录与材质目录分开管理。案板中的轮廓来自原二维材料边界。配方保存在当前浏览器，包含独立材料细节。

修复三种裤装非共形侧缝中漏掉的中间约束，保留材料面积、独立边长和原纸样轮廓。局部接触检查作用于实际人物与物理裤片；裆部闭合腿间隙采用随人物运动的材料前后方向寻找真实身体外位置。没有添加遮挡布片。实时接触查询仅在人物表面与布点坐标都完全未变化、且净空已经满足时复用。

R08 的牛仔六倍织纹、浅洗起伏、远距摩尔纹过滤及当前人物、动作、灯光保留。来源、结构审核和方法见父级 `docs/R09_BOARD_AND_CROTCH.md`；真实画面及帧率见父级 R09 QA 记录。本轮是既有混合角色布料预览维护，不新增完整自由布料、全自碰撞、CCD 或七阶段成衣工艺验收。
