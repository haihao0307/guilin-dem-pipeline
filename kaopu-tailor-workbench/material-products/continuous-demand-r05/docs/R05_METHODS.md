# R05 方法核对与模型边界

2026-10-15。R02 的 GPU 全自由布料仍会在腋下超出应变保护，且实际模拟仅约钟表速度的 48%。仅修复测试 UI 没有解决用户要求。本轮不再把逐帧测试视作连续动作交付。

尝试过完整粗控制面 XPBD：材料图连通簇、原 UV 距离、边界关键点保留、曲面偏移碰撞样本。实测在腋下于 0.35–2.6 秒失败或细面重建拉伸过大；保留实验文件与失败记录，没有提高原 1.45 阈值冒充通过。`candidate-r04` 为未发布研究草稿。

最终独立 `candidate-r05` 采用显式角色服装混合模型；不把它标成原全自由布料验收通过。构造来源和原始裁片没有替换；这里只提供持续穿衣动作及松动区域的次级动力学。

## 资料如何实际使用

- 原 MP05 交接：复用有界邮箱与回滚快照，分开模拟时钟与画面提交；保持原 GPU 表面绑定。每个必要物理步继续推进，显示只提交最新完整状态。
- RayWave 布料库 R15：核对了稳定身体区域身份、接触候选裁剪、状态事务回滚的实现。本轮新实现稳定的手/前臂代理与穿着区域排除，复用原三角面 BVH。没有复制其丢弃累计时间的旧调度方式。
- 鞋履 R09：核对原制鞋项目 `physicalSolver:false`，没有虚构鞋底实时求解器。人物动作桥已有实际左右鞋底/脚底采样、落地校准、接触窗口及根部高度修正，继续使用。裤脚地面约束使用当前人物的同一地面高度。
- 表面复杂度：保留源三股纱线和闭合管截面，用原控制纹理与顶点 Shader 驱动；没有把针目加入物理自由度，也没有删针目换速度。
- 区域物理：材料图相邻区域形成较小动态图；贴身参考负责大范围人物动作，动态偏移负责松动区域的重力、惯性、耦合与交互。
- GPU 流水：限制为至多两个已提交帧，解决单帧等待完成后错过下一次刷新时机的问题。实际单帧 GPU 时间与已完成绘制帧率单独采集。

## 保留限制

完整自由布料、二维应变认证、全自碰撞、高速 CCD、实测材料标定以及所有设备稳定性未完成。区域位置约束是角色服装工程近似，不能当作服装生产或数值研究的真实材料试验。

最终性能与因果测试以 R05 最新源码 SHA 和报告为准；较早 r04、r05-final、r05-overlap 的截图和数字仅为中间定位，不替代最终接触版与公开页测试。

区域动态偏移采用 4–79 mm 的支撑范围，参考加速度在 120 m/s² 内处理；这是角色服装工程模型的明确限制，不是自由布料材料响应。原静态裁片面积与面密度聚合为区域质量，相邻耦合采用对称边刚度。

补充修复：人物深度通道与可见蒙皮统一；数据纹理缓存尺寸纳入存储身份，修复 512×94 → 512×111 上传；原 R06 皮肤需要三个方向光，EB1 两灯外增加低强度中性补光，解决集合页切换/尺寸变化时的绑定错误。跳跃镜头使用原动作实际高度包络。
