# R05 实测记录

后台 Chrome，保持用户桌面鼠标不动。独立页面与集合页分别检查。

`R05_EVIDENCE.json` 为阅读入口；完整原始数据存为 `.json.gz`，解压后的 SHA-256 记录在入口中。本地同名 `.json` 为原始数据。

K03 长测分别覆盖走路、跑步、重复跳跃；K04、D01、L04 也完成各三种动作，衣物全程可见。物理来源为 live，没有预录衣物动画，也没有按绘制速度放慢模拟时钟。额外测试验证重力、拨动、刚度、故障回滚与恢复。

单帧 GPU 提交限制最初导致约 30–36 FPS，改为有界两帧后约 58 FPS。保留上下装、地面和手臂接触后仍约 58 FPS。最早录像的额外画布复制有开销，交付录像使用原 WebGL 画布直接捕获，不插帧、不改速。

修复人物阴影停在原姿态、初始化纹理尺寸越界、集合切换时原 R06 三灯绑定错误，以及跳跃最高点截头。最终集合页零页面错误，模拟与钟表同步。

早期 variants 的摄影机比较没有等待在途 Worker 完成。最终集合页在 pause + idle 后比较，时间与步数都不变；最终结果才作为摄影机不重置物理的证据。

当前为角色服装混合模型，不作为完整自由布料、二维应变认证、全自碰撞或高速 CCD 通过。普通设备和手机尚待另测。固定 HTTPS 地址最终状态以证据 JSON 与 RELEASE_STATUS.json 为准。
