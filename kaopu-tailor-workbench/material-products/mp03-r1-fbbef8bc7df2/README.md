# MP03-R1 — 双层针织、皮革粒面与真实重力候选

本目录接续 MP02 实体材料工作台，不覆盖 `mp02-s1-23c34ca5699e` 或更早的裁缝网页。人物、七件原裁片、十二套搭配与原缩略图均沿用并保留。

## 本轮实际实现

- 针织保留闭合三维纱线，并支持针距、线径、线圈深度、单层/双层和双层间距参数。双层模式生成错开半针的第二套实体纱线以及领口、下摆的有限包边连接，不使用不透明背板遮挡孔隙。
- 远景仍保留实体纱线截面和物理针距，仅低通过滤亚像素屈曲与股线细分；近景恢复三股结构。
- 缝边按原裁片登记的活动接缝生成连续几何线迹，不再沿所有外轮廓绕线。共享物理节点保持配缝边闭合。
- 皮革保留内外表面、厚度和封闭切边，在原裁片毫米坐标中计算粒面、高光、粗糙度与涂层响应；不载入外观图片替代皮革。
- 重力采用 XPBD 距离及二面角约束，重力常量为 9.81 m/s²。人体接触使用原共同人物的离散 SDF，并增加顶点、边中点和面内采样。
- 物理运行放在 Worker 中；超出安全应变或数值范围时拒绝坏帧并保留上一帧。

## 验收边界

双层针织的两套纱线目前共用同一个合规布壳求解面，不是两层之间逐纱独立碰撞。针织、牛仔和皮革的力学系数是工程参数，尚未使用实体试样做实验标定。离散 SDF 采样不是高速连续碰撞，也不是整件服装绝对无自穿模的数学证明。

网页中的“手机”检查仅是 390 × 844 浏览器视口，不冒充实体手机测试。普通桌面、独立显卡、集成显卡和手机的持续帧率、显存与热稳定性仍需分别实测。

## 主要检查

`test-physics.mjs` 检查七件原服装的来源、缝合、重力、应变安全门、二面角梯度和人体接触采样。`qa-browser.cjs` 在真实 Chromium/WebGL 环境加载人物与服装，检查十二张原缩略图、K04 双层针织、重力坐标变化、单层粗线参数、L01/L04 皮革和移动视口；公开发布后必须再次从固定 HTTPS 地址执行同一浏览器检查。
