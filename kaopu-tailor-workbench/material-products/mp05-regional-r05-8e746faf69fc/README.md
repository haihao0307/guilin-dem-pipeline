# MP05 R05 · 角色服装分区实时动力学

这是针对人物穿衣运动的混合模型候选。初始服装仍从既有真实裁片、接缝和材料状态适配到最新人物；运动时贴身参考随原人物完整骨骼权重变化，松动区域持有独立位置偏移与速度，由隐式动力学持续计算。没有衣物顶点动画缓存，也没有按摄像机远近冻结物理。

这与 R02 的全自由服装 XPBD 有明确区别：R05 不是完整二维布料应变认证，不宣称满足原交接文件中全部自由布料验收条件。用户本轮提出的“少量物理计算带动复杂外形、按区域分配物理”是这一角色服装方案的直接依据；原 R02 与基线保留。

## 计算与显示

- 原材料图、纸样、原接缝共享点及全部外观控制面保留。只把同一材料图相连、直径小于 75 mm、至多 24 个原控制点组成一个动力学区域，没有按空间距离合并两条裤腿或不同裁片。
- 领肩、腰口等贴身参考与松动衣摆、袖口、裤腿分别设置运动权重；不是整件衣服停止求解。区域权重目前是依据原服装坐标的工程规则，材料参数尚未进行实物标定。
- 固定 60 Hz 外部物理时钟、240 Hz 子步；每子步 8 轮隐式速度求解。保留重力、惯性、阻尼和相邻区域耦合（从原裁片面积及面密度聚合质量，采用对称边刚度）；弯曲滑杆改变实际求解，摄影机需求不乘入重力、刚度或时间。
- 8 点连续权重把区域动态偏移传给原全部控制点。已有 GPU 表面绑定、真实三股纱线、闭合截面、针目及深度 Shader 继续读取同一状态。没有换成普通衣服贴图或新几何壳。
- 动态状态、速度、重力、扰动与时间均来自实时计算。单步失败恢复区域位置、速度、历史参考、人物姿态和时钟；预分配备份复用。
- 三槽 Worker 结果邮箱保留，只在首次传索引；最新人物只传骨骼矩阵。显示合并旧快照，模拟累计时间不丢弃。
- 两帧上限的 GPU 提交队列允许 CPU/GPU 重叠。保留单个待显示快照，超过能力时报告滞后，不放慢动画时间。
- GPU 只用于初始全裁片适配及复杂视觉。约数百至一千个区域自由度在 Worker 内求解更快，持续过程没有 GPU→CPU 物理读回。这不是“全物理改到 GPU”的宣传。

## 接触范围

当前人物局部参考面保持离体间隙；手与前臂的外来接触代理由同一人物实际网格和骨骼生成，并排除静止时已属自身穿着区域的代理。裤脚保留区域地面约束及显示控制点的地面修正。上衣区域控制点查询当前真实裤装三角面，保留上下装离散接触。

上述均为工程近似。没有完整布料自碰撞、全局无穿插证明或高速连续碰撞认证。参考蒙皮可能在极端姿态挤压布片，二维材料应变不能沿用 R02 的旧通过标记。

人物动作继续使用 CMU 16_15 / 16_35 / 16_01。原动作重定向实际读取本人物左右脚底点，进行落地校准和接触窗口处理；鞋履 R09 本身是静态制鞋工作坊，源码明确没有动态鞋物理求解器，不能冒称已从它移植了现成运动求解器。

## 人物与灯光

人物总工作台来源 `d413d108704af47cf531ee8c25d93f682c3176e3`，动作来源 `8d0860881f34cd6d459b1099028f56dfc7b70a2c`，EB1 来源 `beb3dda0a28f732e1e387dd68cc0d90f27ce8b7b`。原完整人物、104 根骨骼与未截断权重保留。

修复原转接层只在可见材质执行人物蒙皮、阴影仍停在静止姿态的问题。人物深度和距离材质使用同一完整绑定与当前骨骼纹理。附属外观矩阵从固定参考姿态计算，避免每帧累乘。人物运行时的数据纹理缓存同时加入宽高作为存储身份，修复初始化时 512×94 存储承接 512×111 上传的越界；具体来源与改动见 `PLATFORM_ADAPTER_PATCHES.json`。

## 测试

完整实测及录像在源分支 `continuous-demand-r05/qa`，本地 `qa/r05-*.json`。性能必须同时给出实际绘制帧率、单步耗时、模拟/钟表比；独立 Worker 耗时不作为整页帧率。录像来自当前浏览器真实渲染，不是布料缓存或人工插帧。

初始载入仍需约 40 秒生成完整人物与材料；这不是持续运动帧耗时。普通电脑与手机尚待另测。
