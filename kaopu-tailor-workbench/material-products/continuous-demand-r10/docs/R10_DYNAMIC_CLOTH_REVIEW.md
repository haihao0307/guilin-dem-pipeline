# R10 动态布料复查：未通过

2026-10-16。用户要求实际检查裤裆、折叠与拉伸。UI 检查和动作帧率不能代表衣物变形正确。测试使用当前固定 R10 的真实衣物、原二维材料 UV、最新人物与动作；后台 Chrome，不操作桌面鼠标。

## 实测

三种裤型 × 走/跑/跳 × 15/30/45/60 帧，共36个固定物理步采样。每块原材料三角形计算当前第一基本形式相对于原二维 UV 的广义特征值，得到两条主拉伸；同时相对于同版初始试穿比较压缩。统计按初始布面面积加权，不将极细三角形的单个极值当作整体结论。测量函数通过刚体旋转/平移、已知各向异性伸长和已知剪切的独立例子验证。

跑步第45帧的裆部：

| 裤型 | 对原二维纸样的最大主拉伸面积加权95分位 | 比初始试穿压缩超过30%的区域面积 |
| --- | ---: | ---: |
| P01 | 1.643 | 9.2% |
| P02 | 1.832 | 9.9% |
| P04 | 1.709 | 8.6% |

1.0表示原长度。这些数值不符合稳定牛仔布面预期，**未通过变形验收**。阈值不是实物面料标定值，不据此宣称生产合格。脚口的折叠、裹脚和局部塌缩另有真实问题帧及 `r10-fold-review.json`，不能以接缝间隙为0替代布面审核。

## 代码根因

1. `reduced-cloth.mjs` 的邻域弹力计算的是区域位移 delta 的差，骨骼参考形状本身的拉伸没有被原二维材料度量约束；每帧由人体最近表面重建细网格，会把参考形变直接带入布面。
2. 原 `cloth-physics.mjs` 有材料边与二面角约束，但实时 `ReducedCloth.step` 没有执行该完整材料膜/二面角求解。区域弹性不能当作已实现的真实折叠弯曲。
3. `lower-body-contact.mjs` 的细接触逐点/逐三角形推出身体，之后没有统一检查原材料主应变，身体接触为正和接缝闭合都不能证明布面没有过拉。细化节点独立绑定最近身体点还会放大邻接三角形的局部误差。
4. `expand` 对细节点逐个执行地面高度截断；粗节点地面约束与该硬截断之间缺少布面的一致折叠约束。
5. 运行时只有上下衣接触与人体接触，`allSelfCollision:false`；裤子自身折叠层之间没有完整自接触。不能称折叠稳定，也不能称连续碰撞。
6. 真实纱线截面不会随失控的材料拉伸无限变宽，所以过拉还会在显示上张开纱线间距。加遮洞层或把纱线加粗掩盖问题不能修复原布面，未采用。

## 已实际试验并拒绝的方案

- A：在现有材料边上补工程应变界限并保留细节点修正。极端细节点拉长下降，但大腿出现新的明显穿出，裆部95分位反而变差；拒绝。
- B：使用原 UV 的三角形主拉伸/剪切约束，并交替处理传输后的人体局部平面。跳跃改善，跑步过拉和压缩仍不合格；拒绝。
- C：在三角形主应变与实际下身三角面接触之间反复交替。跑步仍有明显过拉/塌缩，单步主要阶段约100–130ms，远超16.7ms；拒绝。
- D：让裆部新增重心节点随原父三角形插值传输，避免各自选择人体表面。部分极端局部误差下降，但没有解决完整布面度量和折叠问题；拒绝单独作为修复。

A/B/C/D均为独立本地试验，没有替换公开运行时或主入口。源代码补丁在 `qa/r10-experiments`，原试验文件夹在工作区保留。完整采样和计时在各自 JSON；没有通过加大容差、隐藏人体、补遮洞面、预烘焙动作或降低真实模拟时间来冒充通过。

## 下一步必须替换的求解职责

保留已完成的界面、人物、动作与光照；将高应变裆部、膝弯和裤口作为真实材料膜/弯曲求解区域，区域间保持同一材料网格与连续约束。参考随动只可提供预测与实际穿着固定，不能覆盖求解后的布面。材料拉伸/剪切、弯曲、人体接触、地面和局部自接触必须在同一步协调，不再按“先变形、最后推开身体”孤立执行。

性能验证同时记录实际模拟/墙钟、已完成绘制帧和关键区域主应变；完整布面的人体接触采样须与接缝检查分开。需要 GPU 或分区计算时先验证同一约束的结果与时间，不以 Shader 名称或多子步数作为实现证据。

**当前结论：界面可用；动态衣物未通过，尚未修复完成。**

## 全裤面接触与脚口补查

用物理帧实际 skinMatrices 重建同一套 NativeMotion 人体，按每种裤型/每种动作第45帧的全部下装显示顶点和三角形重心查询实际人体网格，而非只查询裆缝。九组均发现离散负距离；P02 跑步的最小三角形重心距离约 -43.06 mm，53 个重心、29 个显示顶点进入人体。它不能再被裆缝附近距离为正的旧结果掩盖。此为离散采样，不是 CCD 或全部三角交叉认证。完整结果 `qa/r10-whole-contact-review.json`。

P01 第45帧脚口区域，相对于初始试穿在至少一条主方向压缩超过30%的布面面积：走路约36.5%、跑步26.9%、跳跃44.3%。三角形面积和材料长度同时发生明显塌缩，不能把这些都当作自然褶皱。详见 `qa/r10-fold-review.json`。

`R10_actual_surface_P02_run45.png` 为诊断图：仅将同一个实际物理网格换成不透明诊断材质，以区分纱线间隙与网格穿插；没有新增几何层，产品代码与公开版本未加入遮洞层。对应真实纱线图同帧保存。
