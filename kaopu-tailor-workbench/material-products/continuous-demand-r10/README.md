**界面通过不等于布料变形通过。三种裤型的36帧复查确认：裆部过拉、布面塌缩和折叠仍未通过；四种物理试验均被拒绝，尚未修复完成。** [复查详情](docs/R10_DYNAMIC_CLOTH_REVIEW.md)。 快速运行时为骨骼随动加区域次级物理，并非完整自由布料、CCD 或自碰撞；原二维材料的动态主应变约束也未获得认证。R09 接缝与接触的离散采样结果不能替代这些检查。
