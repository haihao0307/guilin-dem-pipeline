# R08 牛仔织纹与绘制优化

任务开始 2026-10-15 08:31:29 UTC；三小时截止 11:31:29 UTC。基线为本地 `71bde8d` / R07 runtime tree `527117f28a680730aceceb5293160f3c53585122`。集合基线 `work/wardrobe-studio-20261014` / `b08e312014f41008a87949a37ef9600ba9d9b6e2`。R07 完整保留。

## 问题与初测

牛仔原始经纬间距 0.42 / 0.64 mm，在全身视角被逐纱平均，3:1 斜纹也随之丢失。D01 双牛仔的同机基线约 6.3–6.5 FPS，原实现提交约 12.6 亿纱线三角形，且大量纱线无法进入 384 MiB 帧缓存，落到昂贵的直接求值路径。这里的数值来自真实 beauty frame 提交和 GPU 完成门，不是物理步数冒充画面帧率。

## 实现

- 提供牛仔织纹大小 1–8 倍，候选默认 6 倍。只放大材料经纬间距和横向纱宽，衣物裁片、缝线、成衣尺寸、厚度、质量及物理求解不按比例放大。保留原间距和当前比例供审计。
- 3:1 斜纹由相同材料坐标及经纬方向计算；使用周期函数积分平均当前像素覆盖，保留仍可辨认的斜纹，远到连一个斜纹周期也不可分辨时才收敛到 3:1 均值。没有导入图片、另造衣壳或遮洞背板。
- 经纬纱交织起伏按投影误差连续低通，误差记录为 `maxCrimpErrorPixels`。原来的“每一个交织永远至少四段”改为按投影曲率需要分段；初始化使用八段 / 48 mm 的闭合纱线，避免先分配巨额细节再因预算不足永久停在昂贵路径。近看恢复交织。
- 牛仔截面至少为偶数六边形，以保留两侧纱宽。旧三边形内接截面的横向覆盖只有直径的 75%，放大后可见透底和摩尔纹。该三边形试验已拒绝，截图与代码保留在 QA 研究目录。适当提高经纬紧密度至 1.08；不是通过遮挡人体掩盖问题。
- 棉纤维两个信号权重恰好都为零时提前返回，跳过无贡献的噪声。相关屏幕导数在分支前计算；不在新的逐像素发散分支里调用导数。

## 验证与边界

在独立后台 Chrome 中串行测量，避免多个 GPU 页面互相影响。每个动作预热后计时 12 秒，记录实际完成画面、帧间隔、求解耗时、缓存、纱线数与 GL 错误。全身材质比较使用相同视口、相同重置姿态、正面镜头和中性棚光；近景与人体隐藏对照用于发现覆盖缺陷。

早期放大四倍但未改采样时约 57–58 FPS；采样优化试验约 58–59 FPS。这些是研究过程，不冒充最终默认六倍版的结果。最终数值以 `qa/R08_EVIDENCE.json` 为准。

本轮只维护已有角色服装材料预览，不推进完整成衣工艺验收。完整自由布料、全自碰撞、CCD 和材料标定没有因此完成。物理源码及原裁片保留；原生人物、动作、皮肤、针织和皮革不换资源。

材料参数的“应用”沿用旧流程：重新生成材料、重建并初始化物理控制器，不保留原模拟时钟。缩放检查确认参数和纱线数变化，静态衣物位置一致；`sameClock:false` 是记录到的现有行为，不能记为“保留时钟”通过。近远镜头检查则全程保留暂停时钟不变。

## 浅色视觉反馈后的调整

用户指出浅色纹理太平、缺少牛仔质感。提高浅洗款的蓝白经纬层次只是配套；核心调整为独立显示纱束厚度 2.4 倍（名义纱线包络 1.68 mm），保留更多纱束法线响应，并提高棉质柔光、细微粗糙度变化与材料坐标上的染色损失。物理厚度仍为 0.7 mm、质量和碰撞求解未改变；不能把显示厚度当作材料标定。

连续斜线式的斜纹平均模型容易变成条纹布，已改为原 4×4 的 3:1 离散经纬格覆盖积分。40 个随机材料坐标矩形与每例 512×512 直接离散采样比较，最大绝对覆盖误差约 0.00156；完整周期仍为 0.75 经纱覆盖。该检查只验证材料轴向方框过滤，不证明所有投影足迹没有误差。

初版 R08 runtime tree `49ec7c0beaa585fc925936e63495ba8c4c1151f7` 仅为浅色反馈前的中间预览，不能作为本次最终浅色效果。最终发布使用新内容树。

直接保留较多逐纱法线的方案会带回细小高光变化。最终保留微量逐纱响应，并对 3:1 浮长带的第一频带按真实屏幕像素进行积分，再从高度导数构造法线；近景仍使用实际闭合纱线。与直接强化法线方案在相同暂停姿态和 4 重覆盖采样下对照，相位 RMS 从 0.03540 降到 0.03188（约 9.95%）；水平空间梯度能量没有降低。该指标不是所有运动闪烁已经消除的声明。

R07 与最终 R08 浅洗款在同一重置姿态下手动推进走路 120 步：衣物位置最大差 0、身体姿态/时钟/质量/物理厚度一致。这验证显示纱束起伏未悄悄改变当前物理。

## 远距离摩尔纹的补充处理

用户要求检查远距离摩尔纹。像素方框积分仍存在奈奎斯特频率以上的旁瓣，因此将 3:1 斜纹颜色和浮长带法线在 0.32–0.50 周期/像素之间连续衰减；不能只过滤颜色而保留逐纱高光。逐纱法线在纱束不可分辨时完全收敛到布面法线，水洗和粗糙度信号各自按投影足迹过滤。近处仍使用闭合纱线、实际截面和原经纬方向。
