# MP05-R1 · 快速启动与已解算动作复用

继承 MP04.4.2 固定运行源码 4158ad94b0ac0a92ed67fcd770c3a4a8cf56dcb1；旧目录、旧网页、其他工作台和原人物均保留。

默认十二套衣形在发布阶段使用原参考求解器准备，网页不再每次执行八轮松弛。动作缓存按原款、材质类别、厚度、重力、弯曲、柔度、阻尼和间隙区分，颜色、灯光和镜头不再误使缓存失效。当前 K04/L04/D01/D04 三种动作共享九个原始已验证动作文件。压缩资源按摘要保存在当前浏览器；内存压缩资源最多24条，持久资源最多32条，解码动作最多3条。失败可重试。

播放采用正常墙钟时间，不再用每次最多三帧将六秒动作拖慢。实际GPU完成帧数独立测试，不把RAF数量当真实帧率。

普通视距采用原服装细网格有限厚度曲面、外侧/内侧属性图与原连续缝线；原人物、顶点顺序、纸样、厚度和实算帧不替换。点击特写才建立原生逐纱几何，聚合曲面退出显示。聚合显示是明确近似，不是逐像素相同的微观纤维，不是刚性蒙皮或额外遮洞背板。

## 重要边界

标准动作是已验证物理解算帧回放，不是在线自由布料求解。缓存之外组合不自动启动整段解算，按钮明确禁用；自由物理、提衣摆、改变重力仍保留为慢速参考模式。任意身材/参数即时布料、任意动作物理连续过渡、自碰撞、CCD、全设备60FPS仍未完成。

本地减少迭代/粗代理试验出现过度拉伸和厘米级互穿，已撤回，未发布该求解器。不能用高帧率抵消穿模。

读取 Human-Fabric-Workbench 的 R15.md，迁移按显示尺度聚合、细节按需准备和分别记录物理/显示时钟的方法；未发布私有完整源码，未声称完整R15毛羽渲染接入。该专项自身物理墙钟也尚未实时。皮革R15对应粒面核与这里R13核blob相同；牛仔保留R11原生近景核，不含R12破口独立受力。
