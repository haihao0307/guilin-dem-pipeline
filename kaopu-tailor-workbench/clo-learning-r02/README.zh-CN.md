## 本轮推进

R01 只改变裙长。本轮在同一 S03 后开衩铅笔裙上增加独立的开口深度，验证两项改版不会意外联动，并让每次结果都重新生成纸样、网格和诊断。

**裙长与开口深度 → 受限材料空间操作 → 新纸样与网格 → 原缝合/物理解算 → 本次静态检查。**

网页使用已有真实人物、皮肤、纸样、材料身份和求解器。新增开口深度滑块、原款/修改后的深度对照、纸样尺寸标注和“开衩细节”相机。两个参数同时参与请求与结果身份核对；取消后保留上一份完整结果，重新计算失败时展示真实失败候选和原因。

首屏代表为本次构建重新计算的裙长 **+60 mm**、开口深度 **+40 mm**：前片纸样长约69.1 cm，后开口深约12.6 cm。此处长度都在二维纸样上测量，不是身体尺寸、三维投影长度或实物成衣规格。

## 操作契约

实现：`src/design-operation.mjs`；版本：`kaopu-s03-length-and-opening/2`。

| 项目 | 契约 |
| --- | --- |
| 来源 | 固定 S03 原纸样；完整来源字节及 recipe/geometry hash 均校验 |
| 裙长 | 相对原款 −40 至 +100 mm，步长10 mm |
| 开口深度 | 相对原款 −40 至 +80 mm，步长10 mm；原深86.104103057 mm |
| 裙长改变时 | 下摆与开口整体平移，开口深度保持用户选定值 |
| 深度改变时 | 仅提高/降低后片现有开口尖端；裙长与开口宽度不变 |
| 保留 | 原人体/姿势、放置、腰头、腰部缝线、省道、臀线、横向宽度、20条源接缝身份 |
| 开口形式 | 原有20 mm宽的三角形材料缺口；两条开口边未缝合 |
| 重新生成 | 边界采样、面积、材料网格、缝合、物理结果和全部诊断 |
| 失效处理 | 不继承旧PASS或原始oracle；错误/过期请求不得覆盖最新完整结果 |

这是针对固定源款的显式改版，不能称为完整通用制版器。它没有新增后中缝、搭门、衬料、包边或加固工艺，没有自然语言模型调用，也不是CLO的网页移植。

范围表示允许提交的操作域，**不表示其中每个组合都通过物理检查**。默认试样必须完整通过才允许构建；用户的新试样按真实结果标记为通过或需复核，失败结果不能晋级为合格衣物。

## 失败案例与新知识

开发中，裙长+60 mm、开口深度+60 mm的新解产生1对布面相交，原阈值下判定未通过。独立复核定位在后裙片与后腰头收褶接缝附近，未定位在开口本身。该结果必须保留，不能靠提高阈值或忽略检测变成通过。

这揭示了一条实际知识：**局部纸样编辑会影响整体重新网格化与缝合状态。二维尺寸合法、侧缝等长、应变低于门槛，都不能替代最终相交检查。** 网页明确显示失败原因，CI用真实计算验证这条路径。

机器可读的学习/整合边界见 `KNOWLEDGE_CONTRACT.json`；案例及审查见当前版本的 `evidence/`。性能审查作为后续建议，未实施调度优化，不能宣称本轮加速。

## 人物、材料与衔接

仍锁定与S03碰撞数据一致的原生人物：25,417顶点、50,624三角形。显示与碰撞同源，不替换人物或缩放替身。本页是冻结姿态下的单件静态试穿，未完成Humanoid Rig Lab Next的SMPL24/28控制节点、SkinnedMesh动画或SharedWorker项目协议适配。

材料仍为原digital-muslin数字胚布，200 g/m²，未新增实物标定。应变色谱表示真实材料三角形的几何变形，不是压力或实测应力。沿用原阈值：拉伸/压缩≤15%、完整接缝分离≤0.25 mm、最小身体顶点距离≥−0.05 mm，以及最终相交检查。动态、连续碰撞、多层叠穿和生产认证尚未完成。

新母本要求比例、骨骼、姿势、动画与显示状态分层，以GitHub当前状态为代码事实。本轮不改变人物结构或借用并行窗口分支；未来整合需明确比例/姿势版本、坐标和绑定映射，不能把冻结显示包称为已接通统一人物系统。

## 复现

```sh
npm ci --prefix build-tools
python download-sources.py
node prepare-worker.mjs
node tests/design-invariants.mjs
node run-solve.mjs 60 40
node build.mjs
```

`SOURCE_MANIFEST.json`锁定46个原运行时/纸样/碰撞/许可文件、人物原包及vendor校验值。原求解工序、迭代次数、材料参数和检查阈值不变。`run-solve.mjs <裙长变化mm> <开口深度变化mm>`产生真实结果，正负例均记录。

单体HTML包含脚本、WASM、人物、原款、当前构建新试样和碰撞资产，核心不依赖CDN/远端求解服务。主线程按需渲染，物理在Worker中执行；修改参数不直接缩放旧三维。任意修改仍需等待实际求解，首屏载入速度不代表重新试穿耗时。不新增固定距离LOD或动作缓存。

`tests/design-invariants.mjs`验证尺寸独立、面积关系、保护区、接缝和失效规则。`tests/browser-smoke.mjs`在CI用真实指针/键盘验证桌面、手机视口、成功/失败重算、取消、还原、来源身份与离线核心；不能替代手机实机测试或用户视觉认可。
