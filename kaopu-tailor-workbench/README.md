# KAOPU 裁缝工作台：接缝学习增量 R1

这是原创小布片实验台，不是完整裁缝系统、完整短裤或人物试身成品。旧模块、旧纸样和旧阶段不被替换。

## 打开与复验

从仓库根启动静态服务器 `python3 -m http.server 8765`，打开 `/kaopu-tailor-workbench/`。运行 `cd kaopu-tailor-workbench && npm run check` 可复验数值与反例。浏览器无外部库、模型权重、数据集或运行时请求；无需安装后端。

依次点击：校验并冻结裁片 → 激活接缝 → 观察残差 → 拆除接缝 → 向两侧轻拉。修改纸样立即废弃旧裁片及求解。可以导入/导出本工作台 JSON；不支持官方 GarmentCode 或 PatternGSL 格式直接导入。

## 原创结构

- 两块原始矩形布料，毫米材料域；10 mm 接缝外材料真正参与网格，尚未翻折、收边或压烫
- 任意裁片身份与有向边引用；当前示例 374 点、640 三角形；针脚保留两个独立材料点，不焊接材质域
- 结构校验：schema、来源、单位、材料、非零三角形、边界自交、网格边界、接缝引用、方向、剪口、显式吃势和工序依赖
- 原始二维度量冻结。摆片只有保距刚体变换，三维结果来自时间积分与约束，无成衣外壳、回退映射或额外补洞
- 小样 XPBD 距离约束；渐进收紧、每个子步独立乘子、材料边长约束、弱弯曲距离近似
- 顶点—球体和台面接触，释放托持与拆线行为测试
- 导出包含原纸样、材料、工序、摆片、当前点位置和未知验收项。FNV 指纹仅用于变更失效，不是密码学完整性保障；发行清单另用 SHA-256

## 明确未完成

距离弯曲是粗略近似，材料未经实测标定。大载荷/吃势可能超过固定 5% 伸缩应变门槛，UI 明确报告失败。球体只检查顶点，不是连续三角形接触，也没有自碰撞或人物试身。因此 `productionReady=false`，数值直缝通过不能转为成衣合格。当前不支持不同采样数量的接缝重采样，也不支持复杂曲线、收省、翻面、领袖与腰头工艺。材料网格检查并不等于完整自重叠检测。

## 来源与许可边界

代码与纸样均为本轮独立实现；没有复制 GarmentCode 或 PatternGSL 代码/模型/样例，也没有包含既有私有短裤资产或人体数据。研究事实及精确链接见 `LEARNING.md`。算法论文用于方法学习，不复制论文图表。此目录不能被描述为这两个研究项目的官方浏览器复现。

## 浏览器验证

`tests/browser.cjs` 覆盖 Chromium 与 WebKit 的桌面/窄屏布局、键盘/触控、激活/拆缝/释放、改版失效、导入导出和错误反例。云容器本地 Chromium 启动失败，所以通过专属只读 GitHub QA 分支运行；以该提交的 CI 结果为准。自动化窄屏和 Linux WebKit 不等于真机 iPhone 验收。
