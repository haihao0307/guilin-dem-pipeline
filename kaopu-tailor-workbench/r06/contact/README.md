# R06.3 contact trial — clothing not accepted

Continues Draft PR #175 on an independent branch. The additive same-workbench entry is `r06/contact/`. Original R06.2 modules, all older workbenches, three legacy garments, body assets, 23 styles and 122 fields are retained. No solved garment is loaded: paper generation and sewing run live.

The original f64 XPBD kernel, 12 integration substeps and 6 main iterations remain unchanged. Six additional original principal-strain/body relaxation passes precede each contact event. Final seam-only tightening is removed only for the new analytic trial. Original analytic curves, original polygon vertices and all real material lengths are preserved; remeshing samples those curves without metric normalization. Seams with more than 2% original length mismatch retain sparse needle sites and free intermediate material, rather than a common-length dense equality edge. Needle rest gap is the original 0.8 mm and original equality elimination remains active.

Swept linear vertex-face / edge-edge conservative advancement uses an additional collision-only f64 WASM kernel. It runs every original integration substep (720 Hz). Body vertex paths use bounded interpolated-SDF advancement when motion exceeds 0.5 mm. Only identical points and exact paired needle sites are excluded. No entire panel or gathering band is excluded. This is not certification of full nonlinear CCD. Iteration exhaustion is counted; excessive spatial sweeps or candidate sets above 250,000 fail explicitly rather than silently skipping primitives. Final strict BVH audit is independent and does not check coplanar overlap.

Spatial buckets may be reused only when every new swept triangle and edge box is contained in its corresponding padded cached box; otherwise all buckets are rebuilt. Every candidate list uses current substep bounds. Integer-stamp deduplication preserves the independent Set-reference candidate order, including rollover. Original source seam IDs/indices are preserved while physical endpoint ordering is stabilized before stage construction.

Temporary shoulder supports now lift 80 mm above their original SDF-derived target, sweep horizontally, and lower to that unchanged target over the original four seconds. This avoids the original anchor path entering the 3.5 mm body clearance. The temporary supports are released when the original shoulder sewing stage starts, after placement and center assembly, so their fixed targets do not remain in competition with the material constraints. Gravity still starts only in the original final release stage. This is assembly motion from flat material, not an authored or cached clothing pose.

The collision-only kernel is reproduced with AssemblyScript 0.28.9 (`asc contact-kernel.ts -O3 --noAssert --outFile contact-kernel.wasm`); the existing Apache-2.0 license is at `../../unified/licenses/ASSEMBLYSCRIPT-APACHE-2.0.txt`. Tests include VF/EE tunnelling, separating motion, a thin body slab, independent JS/WASM agreement, free gathering candidates, conservative bucket containment, stable physical seam ordering and temporary support motion.

Real Chromium QA saves preview and actually sewn paper separately, final original-UV diagnostics, front/back/side/full/without-body screenshots, all 23 default paper checks, 122 fields, legacy baseline preservation, altered-recipe regeneration, pause/resume/cancel and a 390×844 viewport. A mobile viewport is not a physical phone. Failed trial receipts remain in `qa-reports/`. A finished solve or green functional workflow is never clothing acceptance. Material calibration, finite seam allowance/thickness and moving-body fitting remain unaccepted.
