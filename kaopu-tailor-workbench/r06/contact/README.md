# R06.3 targeted contact repair (not accepted clothing)

Continues PR #175. Original R06.2 entry, baseline application, body, UV dimensions and all old workbenches remain unchanged. New same-workbench entry: `r06/contact/`.

Original f64 XPBD cloth kernel and its 12 integration substeps/6 iterations are retained. Six additional material/body relaxation passes do not rescale rest UVs. The final unconditional seam-only tightening pass is removed only for the new analytic contact trial. Ordinary zero-width equality sewing remains progressive, not baked. All seams retain the original equality elimination and 0.8 mm pre-weld distance target; rest UVs are unchanged. Contact candidates are rebuilt for every original integration substep, with one response sweep; candidate lists are never reused over subsequent nonlinear relaxation motions. Final body correction may reopen contact: independent final audit is mandatory.

Swept broadphase includes old/current VF and EE bounds. The collision-only f64 WASM narrow phase uses conservative advancement for linearly interpolated primitives, mass-weighted response and aggregated solver aliases. Only identical material/solver points and exact paired needle sites are intentional adjacency. Graph-neighbour exclusions are removed because they hid free gathering vertices from waistband contact. Whole panels and gathering bands are never excluded. Contacts run every original integration substep (720 Hz); geometry between these events is treated as linear. Body vertex segments use bounded interpolated-SDF advancement when displacement exceeds 0.5 mm. Neither is certification of full nonlinear CCD. Iteration exhaustion is counted. Broadphase over-budget fails rather than silently skipping primitives. Final strict BVH audit remains independent and excludes stitched adjacency but does not check coplanar overlaps.

The extra kernel is built with AssemblyScript 0.28.9, Apache-2.0 (existing license at `../../unified/licenses/ASSEMBLYSCRIPT-APACHE-2.0.txt`). Build: `npx --yes --package=assemblyscript@0.28.9 asc contact-kernel.ts -O3 --noAssert --outFile contact-kernel.wasm`. Workflow reproduces and compares bytes. Independent JS reference tests include VF tunnelling, EE tunnelling, a thin body slab, separating motion and f64 WASM agreement.

Complete browser QA saves current recipe/material inputs, final diagnostics, camera views, uncloaked geometry without the body, all 23 paper generation checks, 122 fields, old baseline garments, pause/resume/cancel and a 390x844 browser viewport. Mobile viewport is not a physical phone. Material calibration, finite seam allowance/thickness, moving-body fitting and nonlinear CCD remain outside accepted capability. A completed solve is not a quality pass.

The new analytic adapter orders seams by their physical endpoint references before meshing/stage construction, retaining all upstream IDs and source stitch indices. This removes observed nondeterministic source-list ordering without changing UVs, curves or triangles. Contact candidate sets above 250,000 pairs fail explicitly rather than silently omitting collisions or allowing unbounded memory growth.

The relaxation contact sweeps advance from the freshly corrected post-contact history, not from the entire previous integration trajectory on every pass. Repeated reuse of that trajectory caused a failed trial to rewind impulses and diverge during waist closure. Browser evidence now saves the paper actually regenerated by the sewing button, separately from the preview paper.

After the failed 120 Hz trials, contact cadence now matches all 12 original integration substeps (720 Hz). Original principal-strain/body relaxation precedes each contact event. Length-mismatched seams above 2% (including the original 2.65% shoulder and 7.47% side ease) use sparse needle sites with free intermediate original material, rather than forcing every material sample to a common-length welded edge. No original curve or material dimension is rescaled. This is still a numerical sewing model, not calibrated seam allowance.

Spatial bucket acceleration caches padded boxes, not contact candidates. Every new VF/EE candidate list uses the current old/new substep bounds. Buckets are reused only if every current swept triangle and edge box remains contained in its corresponding padded cached box; otherwise the entire hash is rebuilt. Thus reuse cannot omit an overlapping primitive, and never assumes a bound on future constraint motion. A regression exercises both contained reuse and mandatory rebuild after leaving the cached boxes.
