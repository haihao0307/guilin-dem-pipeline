# R06.3 targeted contact repair (not accepted clothing)

Continues PR #175. Original R06.2 entry, baseline application, body, UV dimensions and all old workbenches remain unchanged. New same-workbench entry: `r06/contact/`.

Original f64 XPBD cloth kernel and its 12 integration substeps/6 iterations are retained. Six additional material/body relaxation passes do not rescale rest UVs. The final unconditional seam-only tightening pass is removed only for the new analytic contact trial. Ordinary zero-width equality sewing remains progressive, not baked. All seams retain the original equality elimination and 0.8 mm pre-weld distance target; rest UVs are unchanged. Four contact sweeps alternate with the original material/body constraints using one conservative candidate set. Final body/strain corrections may reopen contacts: independent final audit is mandatory.

Swept broadphase includes old/current VF and EE bounds. The collision-only f64 WASM narrow phase uses conservative advancement for linearly interpolated primitives, mass-weighted response and aggregated solver aliases. Only identical material/solver points and exact paired needle sites are intentional adjacency. Graph-neighbour exclusions are removed because they hid free gathering vertices from waistband contact. Whole panels and gathering bands are never excluded. Contacts run every six integration substeps (120 Hz); geometry between these events is treated as linear. Body vertex segments use bounded interpolated-SDF advancement when displacement exceeds 0.5 mm. Neither is certification of full nonlinear CCD. Iteration exhaustion is counted. Broadphase over-budget fails rather than silently skipping primitives. Final strict BVH audit remains independent and excludes stitched adjacency but does not check coplanar overlaps.

The extra kernel is built with AssemblyScript 0.28.9, Apache-2.0 (existing license at `../../unified/licenses/ASSEMBLYSCRIPT-APACHE-2.0.txt`). Build: `npx --yes --package=assemblyscript@0.28.9 asc contact-kernel.ts -O3 --noAssert --outFile contact-kernel.wasm`. Workflow reproduces and compares bytes. Independent JS reference tests include VF tunnelling, EE tunnelling, a thin body slab, separating motion and f64 WASM agreement.

Complete browser QA saves current recipe/material inputs, final diagnostics, camera views, uncloaked geometry without the body, all 23 paper generation checks, 122 fields, old baseline garments, pause/resume/cancel and a 390x844 browser viewport. Mobile viewport is not a physical phone. Material calibration, finite seam allowance/thickness, moving-body fitting and nonlinear CCD remain outside accepted capability. A completed solve is not a quality pass.

The new analytic adapter orders seams by their physical endpoint references before meshing/stage construction, retaining all upstream IDs and source stitch indices. This removes observed nondeterministic source-list ordering without changing UVs, curves or triangles. Contact candidate sets above 250,000 pairs fail explicitly rather than silently omitting collisions or allowing unbounded memory growth.

The relaxation contact sweeps advance from the freshly corrected post-contact history, not from the entire previous integration trajectory on every pass. Repeated reuse of that trajectory caused a failed trial to rewind impulses and diverge during waist closure. Browser evidence now saves the paper actually regenerated by the sewing button, separately from the preview paper.
