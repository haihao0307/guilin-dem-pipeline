# R06.3 targeted contact repair (not accepted clothing)

Continues PR #175. Original R06.2 entry, baseline application, body, UV dimensions and all old workbenches remain unchanged. New same-workbench entry: `r06/contact/`.

Original f64 XPBD cloth kernel and its 12 integration substeps/6 iterations are retained. Six additional material/body relaxation passes do not rescale rest UVs. The final unconditional seam-only tightening pass is removed only for the new analytic contact trial. Zero-width equality sewing remains progressive, not baked.

Swept broadphase includes old/current VF and EE bounds. The collision-only f64 WASM narrow phase uses conservative advancement for linearly interpolated primitives, mass-weighted response and aggregated solver aliases. Sewing sites and their two-ring material neighborhood are intentional adjacency; whole panels are not excluded. Contacts run every six integration substeps (120 Hz); geometry between these events is treated as linear. Body vertex segments use bounded interpolated-SDF advancement when displacement exceeds 0.5 mm. Neither is certification of full nonlinear CCD. Iteration exhaustion is counted. Broadphase over-budget fails rather than silently skipping primitives. Final strict BVH audit remains independent and excludes stitched adjacency but does not check coplanar overlaps.

The extra kernel is built with AssemblyScript 0.28.9, Apache-2.0 (existing license at `../../unified/licenses/ASSEMBLYSCRIPT-APACHE-2.0.txt`). Build: `npx --yes --package=assemblyscript@0.28.9 asc contact-kernel.ts -O3 --noAssert --outFile contact-kernel.wasm`. Workflow reproduces and compares bytes. Independent JS reference tests include VF tunnelling, EE tunnelling, a thin body slab, separating motion and f64 WASM agreement.

Complete browser QA saves current recipe/material inputs, final diagnostics, camera views, uncloaked geometry without the body, all 23 paper generation checks, 122 fields, old baseline garments, pause/resume/cancel and a 390x844 browser viewport. Mobile viewport is not a physical phone. Material calibration, finite seam allowance/thickness, moving-body fitting and nonlinear CCD remain outside accepted capability. A completed solve is not a quality pass.
