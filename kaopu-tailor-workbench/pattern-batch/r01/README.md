# 服装版型整批处理 R01

用户在 2026-10-15 要求整批推进版型，随后处理叠穿和布料；不再以四款为一轮。此模块接续原裁缝台的 60 款配方，不改原人物、原纸样生成器、原物理、MP05 或既有入口。

直接打开 `版型总览.html`，可离线查看全部款式、精确二维曲线、配对缝边和自由边，缩放/平移，导出单款 SVG、完整版型或全部 60 款。网页不加载网络、不使用生成图片、不显示专业调参滑块。

## 本轮实际结果

- 原 60 款全部重新执行固定版本的 GarmentCode：上装 18、裤装 10、半裙 14、连衣裙 12、连体裤 6。共 498 块展开裁片、1,635 条源接缝；不是 60 个新基础拓扑。
- 60/60 通过本轮二维来源/结构检查。同一数值后端独立重建官方对象，检查原解析曲线端点、独立积分边长、非零解析面积、边界闭合、唯一缝边、方向、吃势、收省和连接图；原始源检查仍执行。不把离散交叉检查描述为连续几何域证明。
- 新增 1,007 个原多边接口缝合组：保留各自操作归属、原有边引用、原材料长度、正反方向、分段抽褶和裁片身份，便于后续按衣物分别装配与叠穿。它们是源程序的两阶段（收省/装配）结构，尚非完整现实制造工序单。
- 从原 `SkirtLevels` 和 `PantsHalf` 构造代码及当前配方恢复 11 项抽褶声明。源代码以 `level_ruffle` 扩宽下一层，或用 `top_ruffle` 缩窄脚口带，却未在最终接口保留该系数；新工艺计划分别记录，原裁片、旧系数和原针脚配对均保留。
- 裁片和接缝冻结导出附有参考量体身份、配方/几何/内容散列以及确定的缓存键。导入仅恢复本批已复核记录；被改过的内容必须重新制版复核，不能凭旧散列放行。

## 留给后续试缝与布料的事项

20 款仍有原接口组投影配长差异超过源程序的 3 mm 提示阈值，按款显示“待试缝”，原值随导出保留。其他若干组总长匹配而源分段仍不匹配，`perPairPartitionReviewRequired` 单独保留；不能仅凭接口总长匹配把逐针配对当作合格。这里不改变原材料来消除差异，也不编造这些余量都已得到设计者确认。

这是“全部版型生成与连接结构批次”，不是全部款式可穿验收。缝份仍为原输入的 0；真实布纹采用原适配器约定，未经实物核对。领口/袖口等自由边保留，不代表包边、折边完成。三维网格、缝制求解、人体/自碰撞、动态和材料均未在本轮执行。旧 R0434 的 38 款静态失败逐款绑定保留，不能从本轮 60/60 二维结构通过推翻。

叠穿后续使用各款独立的 `upper/lower/full-body` 槽与版本身份；层序保持未分配，衣服间不能通过跨衣物缝合混成一件。共同人物的重新量体、穿着余量、衣层顺序和接触属于下一阶段，本轮没有缩放人物或另造三维外壳。

## 来源与复现

基线：`haihao0307/guilin-dem-pipeline@ca6f090c5652bbe848e909f755b0ac5e80b4c969`，即 `perf/tailor-mp05-fast-runtime-20261013` 本轮读取的头提交。固定 GarmentCode 源：`d449629979028123a5c4dc9e732a2ec19b7fce31`。原 MIT 许可及依赖说明继续位于 `../../garment-pattern-catalogue-r01/`，本轮没有新增第三方模型、成衣或纹理。

`SOURCE_LOCK.json` 锁定原生成适配器、精确源运行包、60 配方、参考量体和历史布料报告；每次构建重新验证，并逐文件核对解包运行源码，拒绝被修改的源。并行采用独立 Python 进程，隔离源生成器的工作目录状态，保留全部原数值参数。

在仓库根用独立环境安装 `requirements.txt` 后：

```text
python kaopu-tailor-workbench/pattern-batch/r01/build.py --workers 4
python -m unittest discover -s kaopu-tailor-workbench/pattern-batch/r01 -p test_pattern.py -v
node kaopu-tailor-workbench/pattern-batch/r01/package.mjs
node kaopu-tailor-workbench/pattern-batch/r01/qa_browser.cjs
```

换人物须通过 `--body` 提交完整 `kaopu-tailor-body-measurements@1` 量体记录；非参考人物须有 `bodyGeometrySHA256`。不从胸腰臀或身高猜缺失尺寸。构建单独输出失败原因，不回退成旧衣壳。

当前机器四进程重建全部 60 款、完成独立曲线及源对象复核和操作组提取约 19.3 秒，不包括首次安装依赖与界面打包；不是浏览器或在线布料模拟耗时承诺。
