# 从研究到可验证的裁缝能力

核查日期：2026-10-06。研究学习与软件/数据许可分别核对；不声称已经完全掌握或复现全部论文系统。

## 一手来源

1. [GarmentCode 官方源码与文档](https://github.com/maria-korosteleva/GarmentCode) 当前根许可证为 MIT。它提供参数化裁片与组件体系；代码许可不能自动覆盖外部身体模型、数据集或各自依赖。
2. [GarmentCodeData 官方项目页](https://igl.ethz.ch/projects/GarmentCodeData/) 与 [ECCV 2024 论文](https://igl.ethz.ch/projects/GarmentCodeData/GarmentCodeData-A-Dataset-of-3D-Made-to-Measure-Garments-with-Sewing-patterns-ECCV-2024-Korosteleva-et-al.pdf)。学习重点是量体、纸样生成、落布各自独立，按质量门槛排除失败。作者也报告了初始碰撞、滑落、材料/层数覆盖与人体来源的局限；其方法不是现实服装合格证明。
3. [GarmentCodeData v2 数据记录](https://doi.org/10.3929/ethz-b-000690432)。本轮此记录直接读取遇到 403，未凭代码 MIT 推断数据集许可，未下载或转载数据。
4. [PatternGSL 官方项目页](https://lagrangeli.github.io/PatternGSL/)：层次化 JSON 将裁片、边/曲线、摆片与针脚连接表示为结构，再做有效性处理。网页介绍单图预测与 300K 配对样本，但这不是本实验已经具备的能力。
5. [PatternGSL 已核查源码树](https://github.com/Lagrangeli/PatternGSL/tree/8348a844e9d6353923332c58f7aaa8cf02811523)。全量非截断 tree 只有项目网站、网站测试及规划文档；未发现训练/推理实现或权重。根 Apache-2.0 不等于未发布权重或所有训练数据已获使用授权。论文下载链接本轮读取失败，因此这里没有假称逐条复现论文细节。
6. Macklin、Müller、Chentanez：[XPBD 原论文](https://mmacklin.com/xpbd.pdf)，2016。此实验独立实现带顺应性与累积乘子的距离约束。没有搬用 GarmentCode 的 Warp 管线，弯曲采用较简单的距离代理，因此不能套用原研究的服装性能或成功率。

## 学习进入代码的位置

| 学习点 | 本轮实现 | 验证边界 |
| --- | --- | --- |
| 材料二维坐标是来源 | `src/core.mjs` 的独立 UV、网格和冻结裁片 | 没有任何派生衣壳；纸样不被求解回写 |
| 接缝是数据与约束 | 显式有向边、实际 17 个双点针脚 | 激活后收敛，拆除后受外力分开 |
| 合法性先于求解 | 单位/引用/方向/剪口/吃势/阶段检查 | 反例直接阻止，不静默修复错误 |
| 量体、结构、落布分验 | 合成实验输入 + 运行时单独门槛 | 无人体量体，不冒充人物服装 |
| 质量过滤，而非挑好看的截图 | 1.2 mm 残差与固定 5% 主伸缩门槛 | 大载荷失败保留；未测碰撞标未知 |

## 接回完整系统的顺序

1. 提升材料核：三角应变约束、可标定弯曲、各向异性、曲线缝与按剪口分配吃势；逐项用反例、时间步和网格收敛测试验收。
2. 适配既有裁片：保留毫米净缝线、独立材料点、缝份与版本依赖；不能把旧焊接网格作为初始成衣。
3. 完整裤装工艺：前后中心缝、独立裆片、腰头与穿脱开口按依赖激活；每一步报告形变、残差和交叉。
4. 人体接口：必须使用有版本、完整度明确的人体网格重新量体；先连续人体/布片接触，再静态五视图、最后动作验收。
5. 图像辅助：只有获得明确可用的实现、权重及数据授权后，才评估图像→候选结构。候选仍需人工/数值校验，不能直接输出“可生产”。

这是一份可执行的迭代路线。第一轮交付只通过小样约束因果测试，其余未完成门槛保持未完成。
