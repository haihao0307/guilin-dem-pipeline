# PatternGSL 方法学习 · 手工规范编辑

本案例是原创结构语言与曲线网格编译器，没有照片输入、预测模型、官方权重或第三方训练数据。它借鉴显式裁片/曲线/针脚/阶段的研究思路，不声称官方 PatternGSL 复现。

入口为 `../structured.html`。两片直缝基线仍在 `../index.html`。

## 真正不同于第一案例的能力

默认源规范包含 A/B/C 三片、四条二次曲线侧边、两条曲缝和两个依赖工序。编译结果为 459 个独立材料点与 768 个三角形。8 mm 缝份按采样曲线切线法向生成材料条带，前后断面保持开放边语义，未模拟翻折/压烫。

编辑 JSON 的曲线控制点确实改变二维材料点；新增/删除裁片及针脚确实改变材料数与约束图；不存在隐藏几何补片。任何源编辑立即作废旧裁片和求解。导出结果保留源语言、编译版本、原毫米坐标与来源指纹。

先缝左段，再在前段小样残差与应变通过后缝右段。已开始针脚有独立激活时间，第二工序不会重开第一工序。拆除全部接缝清除所有工序激活状态。

## 当前支持边界

- 2–8 个纵向条带，侧边支持直线与二次曲线
- 起点 y=0，二次控制点的 y 限定半高；不支持任意自由闭合轮廓或孔洞
- 每片 4–32 行、3–16 个横向区间，缝份 2–15 mm；曲线离散弦中点误差超过 0.5 mm 时拒绝
- 当前匹配边须有相同采样数量；N1/N2 是统一参数 1/4、3/4 的对应标记
- 相邻净缝边长差必须等于显式吃势，方向和引用错误直接拒绝
- 法向缝份在采样点为标称宽度，曲线间采用折线；未做工业曲线裁切认证或复杂角点工艺

小样通过不代表整衣完成。面料未标定、弱弯曲距离代理、自碰撞/连续接触未实现和原短裤未完成状态均保持不变。压力测试失败仍使用固定 5% 门槛，不放宽。

## 复验

`npm test` 包含第一案例回归以及 `tests/structured.test.mjs`。`tests/structured-browser.cjs` 检查真实曲线改版、删片、错误方向、工序门禁、导入导出、旧状态失效与 1440/390/320 宽布局；支持 Chromium、Linux WebKit。自动化触控不等于真机 iPhone 测试。
