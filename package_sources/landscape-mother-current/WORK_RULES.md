# Landscape Mother 工作规则

## 一、母版绝对锁定

`039d3a7...` 的复杂异型水蚀岩体是唯一母版。峰体、主洞口、峰脚、土体和落石关系不得被替换。新知识只能改善这个对象，不能借“升级”重新造一个对象。

每轮必须先做固定相机下的母版回归检查。宏观轮廓、主开口或峰脚关系一旦变化，该候选直接判失败，不进入材质评审。

## 二、喀斯特是活的过程

外部水沿节理、裂隙、孔洞和低势路径进入，水路先决定湿润、停留和溶蚀强度，再逐步扩大溶沟、孔腔和洞口。不得用随机噪声瞬间替代这个因果过程。

洞内渗水形成稳定或间歇滴点。滴水携带的溶解矿物在局部条件改变时沉积：洞顶向下形成钟乳石，洞底向上形成石笋，长期可能连接为石柱。沉积必须读取同一套水路、滴点和矿物账本，不能成为与外部溶蚀无关的装饰。

最小状态链：

`waterInput → infiltrationPath → dissolution → transportedMineral → caveDrip → deposition`

第一阶段只做可观察的过程点、无量纲状态和守恒代理；没有真实速率标定之前，不把模拟时间冒充地质年代。

## 三、Microscope 方法

两个固定旋转可以合并为一个固定旋转，因此“多转几次”本身没有独立价值。有效方向必须稳定依赖：

`rockId + mineralZoneId + localWorldPosition + seed + algorithmVersion`

先生成连续低频局部方向框架，再在其中展开多尺度细节。邻近位置缓慢变化，区域边界平滑过渡；禁止依赖相机、帧号和实时随机数，避免细节漂移。

降低可见重复的方法：多尺度非整数频率关系、稳定域弯折、局部相位、稀疏事件、作用区门控和主形保护。目标是在预定观察尺度内消除可感知的模板和周期。有限确定性程序不能诚实保证数学意义上的“无限唯一”，因此验收依据是看不到机械重复，而不是口头宣称无穷不重复。

## 四、结构先于材质

固定依赖顺序：

1. 主体高度与轮廓。
2. 层理、边缘、孔腔、裂隙、崩边和破损。
3. 最终法线、曲率、凹腔、凸边、遮蔽、汇水和矿物区。
4. 由结构派生颜色区域。
5. 粗糙度独立读取孔隙、晶粒、湿润、断面和风化状态。

颜色、凹凸和粗糙度可以共享成因，但不得复制同一个随机信号。颜色不能冒充几何，噪点不能冒充侵蚀。
