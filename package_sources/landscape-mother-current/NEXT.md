# 下一步

## 1. 母版回归门

先固定相机对比母版与新候选。顶点、索引、主洞口、峰脚、土体和落石关系必须不变。未通过，不做后续评审。

## 2. 活的喀斯特过程点

在现有形体内增加外部入水、渗流路径、溶蚀强度、洞内滴点、溶解矿物和沉积点的诊断显示。钟乳石和石笋只能从稳定滴点与矿物账本生长，不可随机撒布。

## 3. 表面自然度

消除可见周期、同形孔洞和机械层理。方向稳定依赖石块、矿物区和局部位置。湿痕、苔藓和色差读取水路、遮蔽与结构，不喷黑、不喷绿。

## 4. 明确不做

- 不重做宏观峰体。
- 不换工作台体系。
- 不引入外部模型或贴图。
- 不把合成样板称为真实 DEM 或地质调查。
- 不在 canonical handoff 分支直接开发；各组在自己的功能分支继续。
