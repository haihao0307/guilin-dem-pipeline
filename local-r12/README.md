# R12：30条三维动态鱼群

用户要求沿真实鱼群研究继续，并将数量提高到30条。本版保留R11完整源表面、微弱蓝灰配色及KFE1眼球/自然注视；改变群体组织与运动衔接。独立交付为 `dist/KAOPU_FISH_SCHOOL30_R12.html`，全部资源内嵌、无需服务器；重建命令 `node local-r12/scripts/build.mjs`。

`school.js` 不再有永久slot/逐鱼圆周目标，初始化为有安全间距的三维椭球分布。局部邻居贡献方向协调和聚合，近场避让检查全部方向并预测靠近；共享巡游方向仅提供弱引导。每鱼速度与加速度有界，朝向根据自身速度平滑变化，并有轻微俯仰/侧倾；身体shader与独立眼球使用同一旋转。个体邻居关系可随运动交换，30条不会作为一个刚性网格一起旋转。

身体仍沿原中心脊椎与连续鱼鳍权重传导，单鱼/静止检查保持旧solver。群游根据每鱼体长归一的速度与加速度，平滑调节尾摆频率乘数和推进幅度输入，独立phase/tempo继续保留；眼睛节奏不与该新乘数共用快进时钟。位置运动是有界运动学模型，未求解CFD或把推进估计当作真实推力。

研究对应与未知：海洋鱼类三维邻居关系及海鲈速度相关尾摆见项目 `knowledge/fish-motion/README.md`。7邻居、距离、速度、转弯/俯仰限制、初始化体积、反应时间与幅度乘数均为本轮可验证工程参数，不是海狼鱼物种标定；具体物种与无剪辑尺度视频仍未知。没有将绕威胁/球形压缩或涡旋变成默认巡游，没有改模型形体、鳞片、纹理分辨率或采用LOD。

30条共享一套497701顶点、964285三角、源图集和GPU表面buffer；只增加运动状态与姿态行，HTML仍约30.11MB。每帧完整鱼体三角提交约2893万，GPU成本真实增加，需要实际帧率检查，不能把资源共享误称为绘制开销不变。R10静态CPU副本释放及44字节尾尖包保留。

QA：`verify-school.mjs` 对3种seed各120秒并重放确定性、间距、非平面高度、速度/加速度/转弯、邻居交换和接触修正进行检查；`verify-runtime.mjs` 验证离线与公网桌面/手机、30状态、16种动作、单鱼和资源；`capture-school.mjs` 连续24秒检查群游、画面范围、帧率及第30条眼睛；独立验证须绑定实际HTML与生产提交。首次有限体积拒绝采样多seed失败已按排点密度根因修复扩大初始体积，不放宽运动门槛。
