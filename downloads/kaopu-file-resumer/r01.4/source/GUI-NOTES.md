# Windows 桌面窗口

- 需要已安装 Python 3.12，安装项包含 Tcl/Tk。程序仅使用标准库，不自动安装软件。
- 将本文件夹解压到固定的、可写的位置。双击 `launch.vbs` 启动深色单窗口界面。启动器优先检查注册表与常见安装路径，再使用有超时限制的 Python Launcher 查找 3.12；主界面由 pythonw 运行，不长期保留命令行窗口。
- 想在桌面启动：主动双击 `create-shortcut.vbs`。它只创建该程序的桌面快捷方式，已有同名快捷方式会先询问。移动程序目录后请重新创建快捷方式。
- 如果 Windows 禁用了 VBScript，可在终端用 `py -3.12 app.py` 启动；`diagnose.cmd` 用于显示启动错误。
- 在输入框 Ctrl+V 或点击「粘贴并入队」即可提交多行 HTTPS 下载链接。仅响应用户主动粘贴，不监听剪贴板。手动输入后点击「加入队列」。
- 默认同时 3 个下载，可调整 1–6。无进展看门狗可选 10 或 30 分钟。任务列表显示已下载大小、总量、速度及估算剩余时间；未知总量或无速度时不虚构 ETA。
- 选择任务后使用「暂停」「继续」「更新下载链接」。登录和短效签名链接过期需回到来源网站重新获取同一文件的新链接。程序不读取浏览器 Cookie、不绕过登录、不保证某个站点支持续传。
- 「打开来源登录」只打开已选任务的 HTTPS 来源站点首页，不向浏览器传入带查询参数的签名链接；来源下载主机不一定是实际登录页，可返回原浏览器页面操作。
- 「导入旧分段」需要用户明确选择目录并确认复制；原目录和旧版本不修改。大文件可能需要等量额外空间和较长时间，导入在后台进行。
- 本地任务状态保存在程序目录下 `data`。其中可能含有效下载链接，建议保留在自己的账户目录，不将其公开或放入共享盘。

## 安全续传边界

- 跨连接续传要求服务器支持 Range，并提供可核验的强 ETag。不能核实文件版本时会停止，避免把不同版本拼成损坏文件。
- 不自动追随重定向。遇到跳转请在浏览器核实最终下载链接，再为最终链接新建任务；只有同一站点同一路径的查询密钥刷新才能更新原任务。
- Windows 使用系统 DPAPI 保护保存的下载 URL，供同一 Windows 用户重启后恢复；非 Windows 环境不保存下载 URL，重启需重新输入。
- 更新链接时界面会先暂停任务；正在处理的连接可能需约 20 秒才退出。若提示仍有连接，请稍后重试。
- 关闭窗口时会后台等待连接停止并保存检查点；窗口显示「正在保存」，不要强制终止。
- 当前构建环境无图形显示服务，未在这里进行真实 Windows 窗口、快捷方式与 DPAPI 集成验收。交付前通过 Python 语法检查，Windows 首次启动应按说明自检。

## r01.4 多选移出

主列表支持Ctrl/Shift多选和Ctrl+A全选。底部“更多”提供“移出选中任务（可恢复）”与“已移出任务 / 恢复”，紧凑布局保持可达。暂停/继续作用于所有选中项。任务详情、更新链接、打开来源使用首个选中项。

确认移出只改变列表状态，不删除下载文件。活跃工作线程会被跳过；即使显示暂停也需等连接真正结束。恢复面板可多选和全选，未完成任务恢复后暂停。关闭恢复面板可重新打开，不创建多个恢复窗口。
