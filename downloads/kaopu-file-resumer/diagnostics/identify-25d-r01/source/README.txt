匿名残片只读辨认 · 11-NW-25D（不是25C）

1. 全部解压本包。
2. 保持现有下载文件与Chrome不动；双击 run-diagnostic.cmd。
3. 将工具旁新生成的 download-diagnostic-25d-日期时间.txt 发回。无需上传Chrome数据库或大文件。

脚本仅查询当前Windows用户Chrome标准配置的下载记录，对比25D、25C、5A和匿名编号58495、367748、489918。没有网络请求，不读Cookie，不上传数据，不复制/改写Chrome数据库，不删除/改名/续写任何下载文件。不会自动退出Chrome。

recorded_mapping代表同一条Chrome下载记录将匿名current_path与目标文件名或URL末段关联。它不是现有文件字节身份或完整连续前段证明；移动/替换文件后历史记录可能滞后。脚本始终将continuous_prefix_verified标为false。

如果只找到目标名没有匿名路径，或一个记录出现互相冲突的文件名，不能判定是哪份残片。没有记录也不能用文件大小、日期或排除法猜测。

完整网址和查询密钥不输出；Windows用户名隐藏。脱敏输出显示在终端，并以新的时间戳文件保存到工具旁，不覆盖之前的报告。若报告数据库忙/锁定/WAL附属文件，且没有仍在进行的Chrome下载，可自行正常完全退出Chrome后重跑；不删除附属文件、不修改权限、不强制结束Chrome。若仍打不开，请回传状态，不绕过限制。

已测试模拟数据库：25D精确关联、URL关联、匿名无来源不猜、冲突不猜、无数据库改写/附属文件、锁定停止、WAL跳过及敏感URL不输出。尚未在用户电脑运行，不代表已经辨认当前残片。

范围：只查询downloads、downloads_url_chains、downloads_slices三类下载元数据及schema；不查询浏览网页urls表、Cookie、密码或其它资料。只对匹配下载路径读取文件大小，不读取或改写残片内容。
