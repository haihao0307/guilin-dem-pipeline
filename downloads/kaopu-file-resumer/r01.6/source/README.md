# KAOPU File Resumer · r01.6

Python 3.12 标准库本地工具。统一深色窗口，默认 3 个任务并行（可选 1–6），可随时粘贴多个 HTTPS 下载链接。每个任务独立保存检查点，断网退避重试，完成后自动补上排队任务。无需 pip 或第三方运行库。

## Windows 启动

1. 将 ZIP 全部解压到固定、可写、仅自己使用的文件夹。不要直接在压缩包里运行。
2. 双击 `launch.vbs`。它查找已有 Python 3.12，使用 pythonw 启动，不需要打开 IDLE。
3. 需要桌面图标时，双击一次 `create-shortcut.vbs`。只在你运行后创建，不添加开机启动或计划任务。
4. 默认保存到用户 Downloads 下的“靠谱文件续传”；可在粘贴前选择其它目录。
5. Ctrl+V 粘贴或点“粘贴并入队”即开始。不会后台监听剪贴板。

若系统禁用 VBScript，可运行 `py -3.12 app.py`；`diagnose.cmd` 用于排查。缺 Python 时启动器只提示官方网站 python.org，不静默安装。已安装 Python 3.12.10 通常可直接使用，但需要 Tcl/Tk 组件。

## 迁入目前的香港 ZIP 进度

不要删除原脚本、Chrome 残片或“恢复工作副本”。先停止旧工具，避免两个工具同时处理源文件。

在新窗口点“导入旧分段…”，选择旧工具的“恢复工作副本”（或其父目录），阅读一次复制/完整性提示，再粘贴对应原文件的当前官方 HTTPS 链接。可先导入一份，再导入另一份。

仅支持旧工具已记录的 `11-NW-25C.zip`、`11-SW-5A.zip` 检查点。新工具核对固定文件身份、原前段 SHA256、每个已提交块 SHA256，再复制至独立子目录，从已有偏移继续。额外空间约等于已下载部分，最终两份约需 3.1 GiB 新空间。原目录及第三个残片不修改。没有可信检查点的任意 `.crdownload` 不会按大小猜测接续。

截图中的第二个窗口是 IDLE 重复日志，第三个窗口是旧工具的试恢复确认。新版本不需要反复开 IDLE，也不会在每次网络重连弹同样确认；身份变化、CRC失败、认证失败会停在“需要处理”；证书失败会等待严格TLS重检，不绕过验证。

## 续传、重启与安全

- 只接受 HTTPS（测试服务器仅测试代码显式启用 localhost HTTP）。TLS正常验证。
- 续传要求强 ETag、Range/206、准确 Content-Range、Content-Length 和 identity 编码。200 响应绝不追加；不自动重定向。
- 每块 1 MiB：完整收到后刷盘并原子提交检查点；未提交尾块可安全丢弃。恢复前核验已提交块，不靠文件尺寸认身份。
- 网络超时约 20 秒，短期指数退避（2 秒至约 4 分钟）；连续 8 次失败后按看门狗间隔（默认 10 分钟，可选30分钟）低频重试。手动暂停、移出、403/登录/验证码、身份变化及文件校验失败不会被看门狗重新启动。证书失败会重新尝试完整严格TLS验证，详情见r01.5说明。
- 完成 ZIP 必须通过所有条目的 CRC；其它文件校验长度和本地块 SHA256，不冒称与源站独立发布的哈希一致。
- 最终文件放在独立任务子目录，避免同名覆盖。需要处理的旧进度原地隔离保留；不会悄悄整包重下。
- Windows 使用当前用户 DPAPI 加密保存完整下载 URL；日志不写 URL 查询密钥。队列在程序目录 `data`。不要公开 `data` 或有效下载链接。跨 Windows 账户/机器迁移时可能需重新粘贴链接。
- 关闭再开会恢复排队/重试任务，手动暂停仍暂停。非 Windows 测试环境不持久保存 URL，重启需更新链接。
- 更新链接只支持同一站点和同一路径的查询密钥刷新；不同文件/跳转到不同路径请新建任务，旧进度保留。
- “打开来源登录”打开默认浏览器的来源站首页，不是内置登录系统。浏览器登录状态不会自动共享给 Python；请获取新的直接下载链接。程序不读取 Chrome Cookie/密码，不绕过登录或验证码。
- 主程序保持打开时自动恢复；关闭后不后台运行，不创建定时任务。

## r01.4 多选移出与恢复

- Ctrl / Shift 多选任务，Ctrl+A 或“更多 → 全选任务”选择全部。暂停、继续作用于全部选中任务。
- “更多 → 移出选中任务（可恢复）”：确认后从主列表隐藏任务。已下载文件、分段、检查点与受保护链接全部保留，没有永久删除功能。
- 仍有下载/校验/导入工作线程的任务会跳过，不会打断它。需要提前移出时先暂停，等待当前连接完全结束（通常最多约20秒，但本地校验可能更久），再移出。也可等下载完成后操作。
- “更多 → 已移出任务 / 恢复”：多选恢复。已完成的任务仍为已完成；未完成的一律保持暂停，需要手动继续。没有URL可用时需更新链接。
- 移出后重启仍隐藏且不会自动下载。相同链接再次入队不会建立重复任务，请在已移出列表恢复。
- 紧凑窗口同样能从“更多”访问移出/恢复，不增加底部按钮宽度。批准四彩图标保持不变。

## 升级与队列（先等当前下载结束）

1. 不要在当前下载过程中替换、搬动或复制正在写入的队列。等本次下载结束，正常关闭旧窗口并等进程退出。
2. r01.6 ZIP 全部解压到新的独立文件夹，保留r01.3/r01.4完整目录。
3. 将旧版整个 `data` 文件夹复制到r01.6目录，之后只启动r01.6。文件仍使用原下载位置，不复制或删除大文件。不要同时运行两个版本处理同一批任务，也不要移动原下载目录。
4. 首次读取旧v1队列，自动在新data中保存原始 `queue.r01.3-backup-随机ID.json`；之后写为v2格式，防止旧版把已移出任务当排队任务执行。
5. r01.3不能读取新版v2队列，请勿将新版queue覆盖旧版。需要回退时先关闭r01.6，保留新旧data和下载文件，请勿用过时队列直接续传已经在新版本变化的分段。迁移前备份只能代表迁移时的进度，不代表后来下载进度。

旧版目录和旧队列不修改。备份与队列同样含本地下载信息和DPAPI密文，不要公开。Windows同用户可读取受保护链接；跨账户或机器可能需要重新粘贴链接。

程序必须全部解压。脚本先检查必需代码/图标，缺失会给出中文提示，不创建坏快捷方式；临时目录仅给建议与确认，不误拒用户刻意选择的位置。

启动失败会写startup.log并给出提示；pythonw不常驻黑色控制台窗口，不联网安装软件。

## r01.5 自动续传与严格TLS重检

截图中的“TLS证书验证失败”不同于普通网络闪断。旧版停在需要处理；本版会自动重新验证证书，但不会关闭TLS验证、忽略证书、修改系统CA、绕过警告或重用未经验证的响应。证书本身一直无效时不会继续下载，也无法保证等待会修好源站证书。

- 普通超时、断网、EOF/握手中断：指数退避，继续使用正常严格验证的HTTPS连接。握手中断不再统称证书错误。
- 明确证书验证失败：60、120、240、480秒后重检；之后每10分钟一次。每次都是新的严格TLS验证，验证仍失败则不写入数据。
- 仅在TLS通过，且强ETag、Range/206、总长度与已有块SHA256核验都符合时继续；完成ZIP仍执行完整CRC。
- 状态栏显示“证书重检 MM:SS”或“自动重试 MM:SS”；任务详情显示原因。重启保留等待截止时间，避免启动后密集重试。
- 手动暂停、移出、鉴权/验证码/403、源文件身份变化、文件校验失败不自动继续。移出和恢复保持r01.4行为，恢复未完成任务仍暂停。
- 原始网络异常文本不写日志或队列；只保存受控错误类别，不泄漏签名URL查询密钥。Windows完整URL仍用当前用户DPAPI保护。

### 从r01.3迁入当前停住的任务

先等正在下载的任务完成，或正常关闭并等连接与进程完全退出，再复制整个data到r01.6。不要复制正在写的队列，不要同时运行新旧版本，也不要重新粘贴同一文件创建新下载。

仅当旧任务为“需要处理”（attention），并且错误文案精确为“TLS证书验证失败；没有绕过安全警告。”或“TLS证书验证失败。”，且已有加密URL能读取时，升级会安排60秒后的严格TLS重检。不需要额外点继续。旧版将某些SSL握手错误统称证书失败，因此首次采用保守的证书等待；新请求会重新准确分类。

如果已手动暂停，或曾移出任务，新版不会替你取消暂停，需要手动继续一次。若链接缺失/不能解密，则需更新同一文件链接。其它旧“需要处理”原因保留原状态，不自动猜测恢复。

测试为Linux可控HTTP/HTTPS环境，含真实证书验证失败和测试CA下的严格验证成功。测试用临时CA仅用于测试服务器，产品不添加CA。Windows证书环境、界面、DPAPI、VBScript仍需实机验收。


## r01.6 固定任务颜色与放大图标

- 每个任务保存独立的颜色编号。柔和深色行底+明亮小色块帮助追踪同一文件；暂停、继续、重启、移出和恢复不会换色。新任务不会占用已移出任务的编号。
- 颜色代表任务身份，不代表成功/失败。下载状态、进度数字、倒计时仍单独显示，不能只靠颜色判断状态。选中高亮覆盖行底时，左侧小色块保持任务原色。
- 旧队列按当前任务顺序首次分配颜色，并随队列保存。颜色为确定性分配；测试验证前64个任务色块互不相同，更多任务可能出现近似色调，请继续核对文件名。
- 原批准四彩节点图按原比例放大显示：96 DPI常规标题前约57px（目标56），紧凑工具栏约41px（目标40），150%/200% DPI按比例适配。使用原图整数等比采样，未换图、未拉伸、未裁切；系统窗口/快捷方式图标不改。
- 小窗隐藏大标题时，紧凑图标显示在“粘贴入队”前；暂停、继续、设置和更多菜单保留。宽度计算预留任务色块列。
- 包含r01.5严格TLS自动重检和r01.4多选移出/恢复。用户当前下载、原目录和旧版本均不自动改动。升级仍需等旧程序正常退出后复制data，禁止同时运行两个版本处理同批任务。

颜色/布局与图标显示在本环境做了控制器、持久化、对比度和尺寸测试；没有显示服务器，尚未做Windows实际截图验收。
