# KAOPU Crab Triad R01 — 螃蟹制谱师／乐谱／乐器生产工作台

本项目是在现有动物工作台审计之后新开的独立生产线。它不复制任何一只现成动物，也不把“螃蟹”当作名称预设直接调出完成形。

## 三个系统的固定关系

### 1. 制谱师（KAOPU Crab Composer / KCC1）

制谱师只负责看懂老师、记录证据并写谱：

- 接收用户指定的老师模型、图片、测量或视频；
- 固定来源、版本、SHA-256、许可与可证明／不可证明事项；
- 读取完整表面位置、三角连接、法线、UV、材质分区和部件层级；
- 区分背甲、腹甲、腹部、眼柄、触角、口器、螯足、步足与末端结构；
- 将完整表面拟合为可重演的参数曲面与关节链；
- 生成 Source Score、误差报告和最终 Resolved Score；
- 不拥有隐藏的“螃蟹生成器”，不替乐器生成完成形。

### 2. 乐谱（KAOPU Crab Resolved Score / KCS1）

乐谱保存这一个对象的事实与差异，而不是保存完成网格：

- 世界坐标、真实尺度与左右方向；
- 完整表面图表、接缝、邻接、区域归属与拟合误差；
- 背甲、胸板、腹部及所有附肢的对象级参数；
- 每一条腿、每一段节肢、关节轴、活动范围和左右不对称；
- 螯、眼柄、触角、口器、刺、刚毛、颜色、材质与微形态；
- 绑定、接触目标、步态相位和动作条件；
- 证据、置信度、未知项和用户验收状态。

乐谱不得依靠物种名称去调用乐器中的现成螃蟹，也不得把老师网格或原始 XYZ 顶点缓存当作运行时真相。

### 3. 乐器（KAOPU Crab Instrument / KCR1）

乐器只提供蟹形十足目对象可共用的计算声部：

- 连续曲面图表求值与接缝拼合；
- 刚性外骨骼区域与分段附肢装配；
- 谱定义的关节坐标系、限制与父子链；
- 左右镜像以及谱中明确的不对称覆盖；
- 螯钳闭合、眼柄和触角驱动；
- 足端接触约束与蟹行相位求解；
- 外骨骼材质、刺、刚毛和微形态；
- 验证、测量、指纹、快照、重演和释放。

纯乐器必须保持零身份预设、零示例谱。空播放器在没有导入外部 Resolved Score 时不得生成任何螃蟹。

## 从现有动物工作台继承什么

- 鸟类三系统：继承独立制谱师、谱、乐器与发布证据结构；不继承任何鸟体形态。
- 鱼类三系统 R01：继承 Base／Source／Resolved Score、来源账本和独立重演结构；不继承已作废的稀疏截面造形。
- 鱼类完整表面 R02：继承“完整表面是唯一静态老师”“静态形体验收前不得绑骨”的硬门。
- 猫狗哺乳 R06：继承“乐器只放公共运算、对象差异全部在外部谱、空播放器不产生动物”的边界。
- 旧 Animal K3：只保留空播放器与离线重演的工程经验；不继承以 B／E／T 标签选择完成原型的身份分发方式。
