# R07 后向脊椎波与尾部推进

本轮先录制并检查 R06 的巡游与转向，再修正轴向传导。原来位于体长31.8%的单驱动源向头、尾双向传播；稳态头端摆角约6.96度，尾柄约2.27度，尾鳍另读全局载波。新版本采用沿节段向后传递的激活目标、前段低幅度和逐渐增大的后段摆幅，由原有耦合脊椎动力积分与完整材料截面搬运。

尾鳍读取原始几何根部位置处的渲染场角度及固定步角速度。推进响应读取同一材料变形函数求出的最远尾鳍点速度；动力系数仍未针对真实个体标定，因此页面明确写“推进估计”，不宣称实测游速或CFD结果。检查视角固定观察姿态；累计距离状态供后续生态接入使用。推进强度调节摆幅和频率，播放倍率仅改变观察时间。

模型位置、拓扑、法线、UV、权重绑定、全部鳍尖和原始图集均继承R06，完整payload逐字节不变；眼睛和七组鱼鳍独立权重保留。鱼鳍驱动目标限幅，合法极值组合已加入回归。

构建：`node scripts/build.mjs`。验证：`verify-motion.mjs`、`measure-gait.mjs`、`verify-extremes.mjs`、`verify-browser.mjs`。前后截图与视频由`capture-gait.mjs`从真实WebGL运行时采集；内部证据不是三维交付的替代品。最终单文件在`dist/KAOPU_FISH_TAIL_DRIVE_R07_WORKBENCH.html`，独立发布目录为`kaopu-fish-r07/`。

详见`RESEARCH_AND_DIAGNOSIS.md`。人工visualAcceptance、motionAcceptance和productionReady保持false。
