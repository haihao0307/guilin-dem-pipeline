## 无压缩权威主文件规则

从本版本开始，昆明 DEM 的权威工作主文件必须满足：

- `float32`
- `COMPRESS=NONE`
- 不使用 DEFLATE、LZW、ZSTD、JPEG、WEBP 或其他压缩
- 不建立内部金字塔或 overview
- 不进行重采样
- 不降低栅格尺寸
- 裁切前后对应像元值必须逐值完全一致
- 必须记录输入窗口与输出栅格的原始像元数据 SHA-256

原始 COG 中的 DEFLATE 属于无损文件压缩，没有改变 float32 高程值。新的裁切工作主文件仍按更严格要求写成完全不压缩的 GeoTIFF。任何网页、缩略图或预览文件只能作为派生查看资产，严禁回写、替代或冒充权威 DEM。

## 生成无压缩裁切主文件

```text
python scripts/crop_authoritative_dem.py <原始COG路径> <输出未压缩GeoTIFF路径>
```

推荐输出名：

```text
KUNMING_BASELINE_RESET_CROP_12P5M_FLOAT32_UNCOMPRESSED.tif
```

脚本先核验输入 SHA-256、CRS、像元间距、尺寸和边界。输出后继续验证 `COMPRESS=NONE`、无 overview、无重采样、像元数组 SHA-256 完全一致。任何一项不匹配都会立即停止。
