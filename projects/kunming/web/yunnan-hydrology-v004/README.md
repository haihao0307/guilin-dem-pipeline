# 昆明 DEM 云南色彩与真实水系 V004

V004 在稳定的 V003 三维底座上推进两项内容：

1. 以高程、坡度、坡向、局部起伏、区域起伏、谷地湿润度和双向山体阴影确定性生成更接近云南山地综合色彩的浏览器地表图。
2. 将现代 OpenStreetMap 河道中心线、湖泊、水库和宽河面蒸馏为一张 RGBA 水系知识场，避免旧版 Float32 二进制错位，同时保持河流中心线、湖岸和下游方向固定。

水系知识场通道：

- R：到固定 OSM 河流中心线的归一化距离
- G：固定 OSM 湖泊和水库边界
- B：水路线记录的下游方向
- A：水路等级和显示基准宽度

网页没有总览、俯视、朝北等镜头预设。用户直接通过鼠标旋转、平移和缩放。河宽滑块只改变中心线两侧的显示宽度，湖面波浪不改变湖岸。

权威主文件继续是无压缩 float32 DEM，网页资产均为可删除、可重新生成的显示缓存。
