## 数据源顺序

1. 海底地形采用 GEBCO_2026 Grid，并同时取得 GEBCO_2026 TID Grid。TID 用于区分多波束、单波束、海图测深、卫星重力预测和算法插值等来源类型。
2. GEBCO 原始子集以 15 角秒 WGS84 数据保存。项目坐标系中的 100 米网格只用于模型对齐，元数据必须继续标注原始 15 角秒来源。
3. 潮汐谐波优先采用 FES2022b 和 PyFES。TPXO10 atlas v2 用作独立比较，不能无记录地替换主模型。
4. 坎门验潮站作为近区观测验证锚点。必须保留站点代码、基准面关系、时间范围、缺测和质量控制记录。
5. 河流和海岸线几何必须有明确来源、抓取时间、许可和 SHA256。河宽只改变横向边界，不能改动中心线坐标和长度。

## 分层顺序

1. 冻结权威陆地 DEM。
2. 下载并验证 GEBCO_2026 海底地形与 TID。
3. 生成独立的 EPSG:32651 沿海模型网格和质量层。
4. 建立海岸线、岛屿、河口和潮沟拓扑。
5. 提取 FES2022b 潮汐谐波，生成潮位与潮流边界。
6. 使用海底地形、海岸线和潮位生成可回滚的湿润干出层。
7. 接入河流中心线、汇水区、河口与入海口。
8. 后续接入流量、季节、盐淡水混合、泥沙和历史状态。
9. 最后接入同一连续世界中的网页运行时和浏览器 QA。

## 数据保护

1. 权威陆地 COG 的字节数和 SHA256 在所有阶段保持不变。
2. GEBCO 浅水区可能混用不同垂直基准。未完成基准统一和验潮站校准前，成果只能标记为区域海底参考和潮汐建模底图。
3. 海底原始数据与对齐后的模型网格分开保存。
4. 程序化潮沟、河床或河口加深只能进入独立重建层，必须记录规则、幅度和掩膜。
5. 未取得真实潮汐模型文件时，禁止用正弦动画、固定水位或随机波动宣告潮汐完成。
