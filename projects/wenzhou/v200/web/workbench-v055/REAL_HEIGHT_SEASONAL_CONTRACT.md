# 小温州 V0.5.5 真实高度与四季天气契约

## 1. 永久垂直真值

温州地形、海平面、云底、云顶、飞机高度和地面观察高度统一使用米制世界坐标。

```text
worldVerticalScale = 1
terrainVerticalScale = 1
cloudVerticalScale = 1
cloudAltitudeOffsetM = 0
visualLift = false
visualVerticalCompression = false
manualCloudBaseTopControls = false
```

任何全域观察、地面观察、低空观察、云中观察、飞机观察、截图模式和性能模式都不得改变上述值。显示性能只能通过步进数、采样分辨率、绘制频率和空间裁剪改善，不得压扁、抬升、下沉或重新缩放云层。

## 3. 四季控制器职责

四季控制器负责：

1. 读取归档的月尺度气候背景。
2. 读取日期、本地太阳时和确定性天气相位。
3. 选择适合当前背景的云属与天气过程候选。
4. 驱动一天循环和一年循环。
5. 持续检查当前云底、云顶、垂直比例和高度偏移。

四季控制器不得：

1. 改写云底或云顶。
2. 根据相机距离改变云层厚度。
3. 从月平均数据伪造具体台风、暴雨、雷暴、降雪或历史天气事件。
4. 将规则模型标记成观测、探空、再分析或预报。

## 4. 数据身份

月尺度背景由构建流程从 NASA POWER 官方接口读取。每次成功构建必须同时保存：

```text
完整接口地址
经纬度
参数名称
接口原始响应
提取后的十二个月数值
UTC 获取时间
原始响应 SHA-256
单位
浏览器 QA
公开网页回读 QA
```

如果接口数据缺失、超出合理范围、月份不足十二个或文件哈希无法建立，构建必须停止，旧数据不得无标记回填。

## 5. 状态标签

当前 V0.5.5 的月尺度背景属于来源明确的气候资料。云属选择属于确定性显式规则模型。当前尚未接入温州逐时探空、历史天气再分析和实时天气观测。

```text
historicalObservation = false
liveObservation = false
radiosondeConnected = false
reanalysisConnected = false
visualApproved = false
productionApproved = false
```

## 6. 发布门

公开 HTML 必须在发布前和发布后分别通过：

1. 十云属逐项云底云顶回读。
2. 十二个月逐项驱动检查。
3. 24 小时循环与一年循环检查。
4. 2560 × 1600 绘图缓冲检查。
5. 一个主画布、一个主相机、零 iframe 检查。
6. 控制台错误、页面错误和资源失败检查。
7. 公开入口与关键文件精确字节回读。

未通过其中任何一项时，旧公开版本继续保留，新版本不得替换或宣称上线。
