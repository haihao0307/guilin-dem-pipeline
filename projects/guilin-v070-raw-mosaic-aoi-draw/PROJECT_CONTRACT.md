# 桂林 v0.7 原始 12.5 米联合拼接与在线选区

## 用户最终决定

本项目从零重新开始。旧四核心板块、旧核心按钮、旧裁切图、旧 DEM、旧 GAEA bridge 和旧 v0.6 页面全部退出活动路线。

当前阶段只做一件事：

1. 读取 `canonical/guilin-dem-12_5m-core/data/raw/asf/` 中的 12 张新 12.5 米 DEM。
2. 按真实仿射位置拼成一张未经裁切的联合 DEM。
3. 保留源片自然突出的边缘、凹入边缘和 NoData 缺口。
4. 不补洞，不插值，不裁边，不做侵蚀，不做水系，不做植物。
5. 生成一个在线选区网页，让用户直接在整张联合拼接上绘制多边形或矩形。
6. 网页导出 WGS84 GeoJSON、EPSG:32649 坐标和 WKT，供下一阶段精确裁切。

## 真值规则

- 12.5 米源 DEM 只读。
- 水平和垂直单位均为米。
- 拼接使用最近邻落格与 first-valid 策略，记录源片顺序。
- NoData 保持透明。
- 当前联合外框不等于最终项目边界。
- 用户绘制并确认 AOI 之后，才裁切唯一连续 DEM。

## 网页要求

- 一个连续影像，不显示四块浮板或四个核心点。
- 可平移、缩放。
- 可绘制多边形、矩形、编辑和删除。
- 显示绘制面积。
- 可下载 GeoJSON 和 WKT。
- 可选显示 12 张源片范围。
- 明确显示源片数量、像元尺寸、CRS、联合范围、有效覆盖率和 NoData 比例。

## 发布要求

- 原始联合 DEM 作为 GitHub Release 资产保存。
- 预览和选区页面发布到 `gh-pages/guilin-v070-selection/`。
- 在线地址预期为 `https://haihao0307.github.io/guilin-dem-pipeline/guilin-v070-selection/`。
- 提供全页截图、控制台零错误结果、QA JSON、实际 commit SHA 和 Release 标签。

## 当前阶段禁止项

- 旧四核心区域。
- 旧独立核心 DEM。
- 旧 AP_10613 单片作为底图。
- 30 米 DEM。
- GAEA bridge。
- 侵蚀、材质、水系、生态和植物。
- 自动裁切。
- 对 NoData 进行伪造填补。
