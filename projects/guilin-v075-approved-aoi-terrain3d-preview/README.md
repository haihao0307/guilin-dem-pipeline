# Guilin DEM v0.7.5 Accepted AOI Terrain 3D Preview

本目录是浩哥在 v0.7.4 正北裁切页确认矩形之后的下一页。页面按截图中的活动矩形直接锁定 AOI，并生成可旋转、缩放和平移的三维数字高程预览。

## 已锁定 AOI

* 状态：`ACCEPTED`
* 面积：页面报告 `33,113.874 km²`
* EPSG:32649 边界：`[380331.8, 2705928.1, 530128.2, 2926987.2]`
* WGS84 边界：`[109.79960479808928, 24.462357030555296, 111.30224176414697, 26.46292757634923]`
* 几何 SHA256：`36b750be56ae0dea906996258068eaf9aaa71e01667eb328b9ce6bd1b48cbe80`

## 三维页合同

1. 来源保持 12.5 米、EPSG:32649、垂直比例 1.00。
2. 当前网页从 12.5 米来源生成的 1024 × 1110 数值预览网格中裁取确认范围。
3. 页面按底层预览网格中的 NoData 生成前缀掩膜。只要显示单元覆盖范围中出现 NoData，该单元就不生成三角形。
4. 禁止插值、补洞和 30 米替代。
5. 页面不依赖外部 JavaScript、CDN、卫星图或照片贴图。
6. 默认垂直比例为 1.00。1.50 和 2.00 仅改变观察显示，不改写高程数组。
7. 支持总览、正北俯视、低角度和桂林方向视角。
8. 支持鼠标和触屏旋转、平移与缩放。

## 数据层级说明

当前页属于快速视觉验收用的数值三维裁切预览。正式全分辨率裁切 TIFF、完整哈希收据和后续 1 米程序地形蒸馏继续作为独立生产成果，不用网页预览网格替代。
