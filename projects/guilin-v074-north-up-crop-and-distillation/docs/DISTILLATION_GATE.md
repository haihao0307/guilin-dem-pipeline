# Distillation Gate

程序地形蒸馏当前为关闭状态。

放行前必须同时满足：

1. 浩哥从正北裁切页导出唯一 AOI。
2. AOI 文件已入库并计算 SHA256。
3. 状态已进入 `PENDING_USER_CONFIRMATION`。
4. 浩哥明确说出“这个范围可以”。
5. AOI 状态已更新为 `ACCEPTED`。
6. 原始联合 TIFF 哈希冲突已经完成实体化复核。
7. 正式裁切输出继续保持 12.5 米、EPSG:32649、垂直比例 1.00、NoData 不填充。

放行后的 1 米含义固定为程序字段计算间距。它不代表原生 1 米测绘 DEM。真实 12.5 米 DEM 负责宏观高程与坡势，程序层只能在批准的父级掩膜内生成可回滚的微地貌增量。
