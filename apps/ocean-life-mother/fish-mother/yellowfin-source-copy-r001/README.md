# YELLOWFIN-SOURCE-COPY-R001

Status: **LOCKED — NO GEOMETRY YET**

This directory is intentionally a scaffold only.

The first source-copy build may begin only after the Yellowfin 3D study gate has direct source evidence for:

- fixed-view silhouettes;
- head/jaw/eye/operculum geometry;
- all major fin roots and free edges;
- dorsal and ventral finlet count/spacing/tilt/root width/height rhythm;
- caudal peduncle minimum cross-section and keel positions;
- pectoral reach relative to second-dorsal base;
- visible material/color boundaries.

R003 generic generation is not a baseline.
R003 mixed-coordinate measurements are invalid.
R004 frame-safe measurements are the active measurement basis.

When unlocked, this build must copy FISH-REF-002 first. It may not improve, stylize, simplify or biologically correct the source during the copy pass.
