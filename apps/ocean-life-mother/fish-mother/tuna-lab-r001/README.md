# Fish Mother / Tuna Lab R0.01

This is the first rapid Tuna laboratory workbench after the R09R4 handoff.

Layout is intentionally fixed to the Bird Mother comparison method requested by the user:

1. top: read-only high-fidelity FISH-REF-002 source reference;
2. middle: independently generated Tuna candidate;
3. bottom: live parameters, source facts, historical R09R4 metrics and non-compensating gates.

The generated candidate does not load the source GLB. The source Sketchfab embed is reference-only.

This is a rapid R001 geometry iteration, not a visual-acceptance claim. Materials, natural motion, jaw/operculum acceptance, fin-root acceptance and source-to-candidate distance QA remain closed.
