# 珊瑚生长实验 R02

独立编写的 JavaScript 三角膜生长实验。学习真实 Houdini 开源案例中的点松弛、差异伸展与逐步重网格，再加入曲率、方向和近似自遮挡生长场。没有搬运教师节点代码或缓存；没有购买工程依赖；没有沙粒模拟。

## 使用

由静态 HTTP(S) 服务器打开 index.html。Web Worker 真实计算 0–180 次迭代，时间轴展示计算结果。更改参数后点击重新生长；相同参数与种子可复现相同几何。鼠标拖动 / 单指转动，滚轮 / 双指缩放。OBJ 导出当前计算网格。

## 文件

- growth.mjs：独立求解器、三种生长场、排斥、适应性边分裂
- worker.mjs：在后台计算完整生长序列
- app.mjs：实时 WebGL 观察与交互
- provenance.json：一手来源、固定 commit、原文件哈希、方法与限制
- vendor：three.js r170，MIT 许可

## 验证边界

Node.js 实际运行求解器；真实浏览器 WebGL、交互与截图另由 Playwright 检查。没有运行 Houdini，因此不宣称 HIP cook 通过或输出与教师原例一致。近邻点排斥不是完整面片自碰撞，R02 以单值曲面安全域保持角向次序和投影三角方向，排除翻折层叠；它是稳定单体基准，尚非参考原片的繁密群体终态。该项目不是生物学预测模型。

原案例入口和代码必须保留。此新案例目录外只允许增加母台入口，不能覆盖已有运行器或案例资产。

R02 使用随圆周长度分配采样的连续尖底杯体，边缘活跃带主导伸展。默认展示第90次迭代；原色为自有材质，中性灰用于检查几何，网格模式可查原始求解三角形。显示细分与求解网格严格区分。
