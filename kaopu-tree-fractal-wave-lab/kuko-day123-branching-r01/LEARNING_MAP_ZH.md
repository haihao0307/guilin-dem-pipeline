# KuKo Day 123 对“分形造波”体系的学习映射

## 先纠正一个容易产生的错误认识

这段代码画出来像三棵会摆动的植物，但它当前并不是三维树模型，也不是从根、干、枝、叶随时间真实生长出来的生物系统。它是一个二维片元着色器：对屏幕上的每个像素，沿着一条由整数编号决定的分枝路径，连续做逆仿射变换，再用 SDF 判断该像素是否属于枝段或叶端。

因此，本环节能教给“分形造波”的是高效、确定性的分枝表达语法；不能单凭这张图证明真实植物结构、三维连接、受力传导或生态正确性。

## 五个可继承声部

### 1. 分枝路径寻址

`TOTAL / BR / off / dec / path` 把一个整数 `c` 解码成每一层的分枝选择。它本质上是以 `BR` 为基数的路径编码，可用于稳定枚举分枝，不需要把所有节点预先存成数组。

### 2. 逆仿射变换链

`R()` 与 `disp()` 组合出每一级分枝的局部坐标变换。代码不是把枝条一根根正向画出来，而是把当前像素逐层变换回局部枝段，再查询 SDF。

### 3. SDF 合并

每一级枝段由 `sdCylinder()` 表达，叶端由圆形距离场表达，再用 `min()` 做并集。颜色和光晕只读取距离值，不需要展开网格。

### 4. 视域剪枝

`if (y - k*l > 0.0) { c += off - 1; break; }` 会跳过当前像素不可能触及的一整组后代分枝。这个思想对运行期轻量化非常重要，但它是屏幕空间查询剪枝，不等同于三维 LOD。

### 5. 局部风相位

`wind0`、`wind1` 使用不同相位，插入特定路径的变换链。它展示了“运动进入语法节点”的方法，而不是把最终画面整体平移。

## 下一阶段的正确路线

1. 保留本版作为老师回归锚点，任何改写都要与它并排比较。
2. 把路径寻址与变换链提取为独立函数，先证明输出分枝拓扑与老师一致。
3. 建立正向节点图，验证每条二维枝段的父子连接、长度、角度和相位。
4. 再把二维局部坐标扩展为三维局部框架，而不是直接把屏幕图案挤成立体。
5. 三维版必须补上截面、半径传递、连接连续性、受力与风传播；老师本身没有提供这些事实。
6. 最后才决定它进入树、珊瑚、羽毛或其他分枝对象的哪个乐器声部。

## 冻结结论

当前 R01 的职责只有一个：原样演奏老师。任何参数面板、三维化、材质化和创新都不得混入这个回归锚点。
