## 已经真正学会并抽出的声部

1. `TOTAL / BR / off / dec / path`：把枝号解码为每层的分枝选择。
2. `R() × disp()`：用局部变换链表达分枝走向。
3. `sdCylinder + min()`：用距离场查询枝段与叶端并集。
4. `c += off - 1; break`：一次跳过不可能命中的整组后代。
5. `wind0 / wind1`：把不同相位插入具体语法节点，而不是整体移动最终画面。

综合工作台中的“分枝谱地址解码器”直接运行第一项逻辑。它不是图片注释：选择中央、左、右老师树和任意枝号，可以现场看到对应的基数路径。

## 2026-10-03 新增学习原则：先学会“演奏技巧”，再判断物种适配

KuKo 老师的分枝语法现在明确作为“可调用声部 / 演奏技巧”保存，而不是作为 Pandanus 或任何树种的默认生长规则。不同树种可以调用完全不同的分枝声部；一个老师语法即使复刻得百分之百正确，也不能因为视觉上像树，就被强行安装到另一种树上。

因此，后续树种构建必须增加“适配判断”这一步：物种谱先描述真实的分枝型、主轴优势、分枝位置、角度分布、年龄变化、承载关系与器官位置，再选择合适的声部组合。声部库负责“会多少种演奏方法”，物种谱负责“这棵树该演奏哪一种”。

## 第一层二维→三维 Lift 已建立

新增独立实验声部：

- `kuko-day123-3d-lift-r01/`
- 老师的二维路径、长度计划、平面角度、风相位和叶端平面位置继续作为锚点。
- 先把老师的逆查询链重建成正向节点图。
- 三维化时不直接“挤厚画面”，而是固定所有老师导出的 X/Y，再给局部节点增加独立 Z。
- 子枝的 Z 起点从父枝同一连接位置插值得到，保证连接连续。
- `Z=0` 时全部节点能够压回老师平面，因此三维假设可撤销、可回归。
- 当前 Z 规则只是一种三维提升假设，不是老师提供的事实，也不代表任何树种的真实结构。

这个边界非常重要：二维老师并不能唯一决定三维结构。存在许多不同的三维结构会投影成同一张二维图。因此我们当前只冻结“二维投影必须保持一致”，把深度作为单独可更换的声部，后续再用真实对象资料筛选合适的三维规律。
