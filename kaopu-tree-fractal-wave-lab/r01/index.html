能力工作台 · 非树种复刻

同一事实，驱动几何与色彩

树皮不是贴图；叶片不是 Plane。Mask 从 branch age / ridge / crevice / vein / edge 等结构事实产生，再同时驱动色彩和表面响应。
Substance 式关系：
AGE + RIDGE + CREVICE → Bark BaseColor / Roughness
MIDRIB + VEIN + EDGE → Leaf Color / surface response

Microscope：纵脊与折皱直接改变枝条截面；不是只画明暗。叶片由 midrib + lateral veins 支撑一张有拱度、扭转的三维曲面。
