# R13：30条大型鱼互动群游

学习用户指定的 https://threejs-fish.vercel.app/，在 R12 的完整源采样鱼体上加入鼠标视线局部避让、点击径向扰动、邻鱼受惊传递和恢复。参考实际 WebGPU 画面为6144条鱼，已在后台浏览器连续观察移动、按下、松开；不是从截图猜测规则。本版保留30条，每条保持原完整几何、图集、中心脊椎、鱼鳍权重与KFE1眼睛。

鼠标移入附近鱼会逐渐避让；点击或轻触产生一次扰动。触摸拖动保持局部避让，松开结束。Alt＋左键拖动旋转、右键／Shift拖动平移、滚轮缩放；单鱼模式仍直接拖动旋转。“中央扰动”按钮便于触屏检查。暂停、静止动作、关闭互动、单鱼和重置不会积压新扰动。

`school.js` 仍按局部近邻协调方向、距离和三维队形，无永久格点。参考把鼠标换为三维相机射线，并取到射线的垂直距离；点击点投到鱼群中心深度，径向作用随距离及时间衰减。受惊量从上一时间步的邻鱼读取，衰减传递，暂时减弱聚合并提高巡游偏好速度。所有外力先与原局部避碰合并，再限加速度，朝向跟随自身速度；输入事件不会直接改位置或速度。速度上限恒定，避免受惊退去时突然截断速度。来源与选择见 `knowledge/fish-motion/R13_REFERENCE_POINTER_SCHOOL.md`。

大型鱼适配为工程参数：加速度上限0.20m/s²、水平yaw转速0.28rad/s、速度安全范围0.16–0.64m/s、鼠标射线半径1.8m、点击半径4.5m、点击衰减率2.4/s、受惊衰减1.1/s、邻鱼传递0.82。正常巡游偏好约0.34m/s，受惊最多增加0.18m/s；不是海狼物种实测。没有复制参考的植物、场景、小鱼模型、自动电影镜头或旋涡队形。30条使用CPU局部协调；参考GPU网格索引是数千鱼的加速方法，后续规模增加再另行评估。

完整源payload与R12逐字节一致，497701材料地址、964285三角、145chart、残差、UV、法线、鳍绑定与图集均保留；鱼体/眼球shader、变体蓝灰色及眼睛时钟不变。单文件约30.12MB，资源全部内嵌；共享完整表面不等于GPU工作量消失，30条每帧仍提交约2893万鱼体三角。保守包围球只用于群游安全，不是精确网格碰撞或水动力求解。

构建：`node local-r13/scripts/build.mjs`。`verify-school.mjs` 检查3个seed正常/互动各180秒及重放；`verify-runtime.mjs` 检查离线和公网桌面/手机视口、16动作及原资源；`verify-pointer.mjs` 检查射线投影、局部作用、输入生命周期、触摸、相机配合及恢复；连续群游/眼睛捕获与独立验证绑定冻结源码和HTML。所有帧率是本工作站后台浏览器测量，390×844视口不是实体手机性能测试。
