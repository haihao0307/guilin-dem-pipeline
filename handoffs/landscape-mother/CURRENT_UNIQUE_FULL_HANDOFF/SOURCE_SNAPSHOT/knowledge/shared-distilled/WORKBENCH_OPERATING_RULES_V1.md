# 三地区真实地貌工作台共同运行规则 v1.0

## 来源

```text
用户确认日期: 2026-08-26
知识范围: 桂林、温州、昆明共用
负责人: 小华
状态: user-confirmed
```

## 核心目标

桂林、温州、昆明各维护一块真实地貌小片区，统一进入同一个工作台。真实高程片区负责约束后续地形、台地、阶地和水系细节，防止程序化生成偏离地区特征。

## 生产边界

本工作台负责：

```text
真实 DEM
山体和坡面
台地与阶地
坡脚与崖坎
沟谷与汇流
河道与支沟
河岸与水面边界
侵蚀、沉积和其他可逆地形增量
```

植被、树木、竹林、灌木、草地、农作物、冠层、风场和生态实例由独立植被生产系统负责。地貌线只输出植被系统可以使用的坡度、湿度、河距、地貌单元和硬禁入掩膜。

## 真实片区门槛

每个地区目标片区为 10 km × 10 km、100 km²。片区需要来源、SHA256、CRS、像元间距、像元窗口、输出网格、边界、NoData 和高程范围。

程序化细节在真实片区上分层生成。真实片区缺失时，工作台保持锁定并公开阻塞原因。预览图、低分辨率底图和合成山体不得进入真值层。

## 资料输入结构

工作台设置四个资料入口：

```text
三地区共用
桂林专用
温州专用
昆明专用
```

每个入口支持文字、参考图、主题标签、缩略预览和标准 JSON 入库包导出。地区资料只进入对应地区收件箱。共同资料进入 `shared/inbox`。

## 小华与 GitHub 的关系

```text
原图或文字上传
→ inbox 原件与收据
→ 小华读取、标注来源、检查冲突、提取规则
→ distilled 知识条目
→ 任务合同、参数模板、程序节点和 QA
```

原始资料和蒸馏结果分层保存。蒸馏结果引用原始 intake ID。出现资料冲突时并列保存，等待人工决定。

## 上传渠道

对话和 Codex 中上传的原图可以由小华直接读取并完成入库。静态工作台中选择的图片先在当前浏览器中预览，随后通过导出的 JSON 入库包交给小华或 Codex。工作台不保存 GitHub 凭据。
