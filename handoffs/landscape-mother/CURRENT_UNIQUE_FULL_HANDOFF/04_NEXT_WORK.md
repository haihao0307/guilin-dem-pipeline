# 下一轮直接执行

## A. 先加“活的喀斯特”过程点

在不改大形的前提下，新增一条最小因果链：

`降水/渗入 → 含 CO₂ 弱酸水 → 裂隙与孔腔溶蚀 → 洞顶滴水点 → CO₂ 脱气/过饱和 → 方解石沉积 → 钟乳石/石笋缓慢生长`

第一轮只做少量可追踪滴水点，不铺满整个洞体。每个滴水点必须绑定上方入渗路径、局部汇水和洞顶位置。

## B. 再处理机械重复

- 以石块身份、矿物区身份和连续局部位置共同决定局部方向框架。
- 使用多尺度、非整数频率比、域弯曲和独立相位，避免可见周期。
- 同一位置必须可复现；相邻位置必须连续；不同石块可以明显不同。
- 先做诊断视图，再合入彩色材质。

## C. 材质顺序

`结构高度 → 边缘/破损 → 法线/曲率/凹腔/汇水 → 岩性色区 → 湿润与沉积 → 独立粗糙度`

## D. 每轮必须输出

- 固定提交公网工作台
- 母版与候选的宏观轮廓差异检查
- 洞口、峰脚和落石锚点不变检查
- 近景前后对照
- 当前状态 JSON；未获用户批准不得把 `visualApproved` 改为 true
