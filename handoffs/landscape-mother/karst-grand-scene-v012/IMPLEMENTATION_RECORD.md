# Landscape Mother 喀斯特峰林大场景 V012 实现记录

日期：2026-09-03
状态：实现候选，等待用户视觉验收
前序研究：R009 地形光照与材质，R010 大场景整体可读性与旋转一致性

## 本轮目标

只制作一片可环绕观察的喀斯特峰林与峰丛样板。其他地貌继续暂停。画面不使用远山、雾、云、图片背景或外部场景填充。展示重点是大场景结构、真实三维孔洞、石灰岩材料和手机观察。

## 几何

* 七个主要峰体，混合孤立峰林、连基峰丛和峰链关系。
* 一个主要岩桥、一个次级拱洞、三个主要洞腔和多个局部溶蚀孔穴。
* 连续谷地、三处洼地和六十四个独立闭合崩积岩块。
* 主体使用米制三维有符号距离场和等值面提取。
* 近零面积三角面通过共享顶点折叠清理，再次验证水密与绕序。
* 最终固定网格共 124,615 个顶点、249,002 个三角面，65 个闭合组件。
* 所有组件水密，绕序一致，小于 1e-9 平方米的三角面为 0。

## 数值字段

每个顶点携带材料身份、湿润、生物覆盖、径流、新鲜断裂、天空可达度、粗糙度、太阳可见度、铁质沉积、矿物变化、高度与曲率，共十二个字段。字段通过顶点缓冲传递，不使用运行时纹理采样。

当前径流、生物和矿物字段是这个独立样板的程序化形成代理，不冒充实测水文、生态或地质年龄。

## 材料与光照

石灰岩按非金属介质处理，金属度为 0，默认介质 F0 为 0.04。着色器在线性空间组合 GGX 高光、直射太阳、天空漫反射、地面反射、太阳可见度和天空可达度，再执行色调映射及一次 sRGB 输出。

方解石灰白、长期风化暖灰、铁质黄褐、水迹深色、新鲜断面和苔藓地衣由不同形成字段驱动。照明变化不重写材料身份，镜头变化不重新生成地貌。

## 大场景展示

默认采用按秒计时的缓慢相机巡览。用户触摸后巡览暂停。提供全景、峰林、侧面、岩壁和俯视五个固定镜头。侧面镜头经过独立调整，避免暗面和洞腔投影形成误导性圆形轮廓。

手机端使用同一固定几何，限制画布像素倍率，不减少顶点或三角面。支持单指旋转、真实双指缩放和平移、安全区布局，以及最小 44 CSS 像素的按钮高度。
