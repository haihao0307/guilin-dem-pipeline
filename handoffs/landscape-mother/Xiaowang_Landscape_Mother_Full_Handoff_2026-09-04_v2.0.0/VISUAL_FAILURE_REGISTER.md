# 视觉失败登记

## V014 R3

状态：技术基线，视觉未通过。

主要问题：峰冠宽平，峰脚厚，整体像矮台地；默认镜头过高；平原面积与亮绿过强；石灰岩材料和洞穴关系不足。

允许继承：权威十二点五米高程读取、来源峰位、局部基准面、浏览器运行框架、数据收据。

禁止继承：峰体最终轮廓、默认构图、综合色彩和表面细节。

## V015 P1

状态：内部失败。

主要问题：在 V014 旧网格上收窄后出现低矮圆石化，视觉倒退。

结论：旧网格二次变形路线终止。

## V015 P2

状态：内部失败。

主要问题：强制收窄产生大量极小三角面，数字陡峭度增加，峰体仍显矮胖。

结论：坡度统计不能替代轮廓审查。

## V016 HERO R1

状态：用户明确否决，严重视觉失败。

用户可见问题：

1. 五个白色旋转柱体，像奶油裱花、软胶尖塔和陶瓷摆件。
2. 横向等距波纹像打印层纹。
3. 纵向黑线像接缝或拉链。
4. 峰冠统一收成尖嘴，缺少断脊、偏峰、双峰、崩口和不规则岩墙。
5. 洞口是贴面黑椭圆，缺少岩唇、顶板厚度、内部空间和坍塌关系。
6. 地面碎石为圆球，缺少母岩结构。
7. 平原均匀、明亮、荧光感强。
8. 石灰岩接近石膏或蜡，缺少真实风化、裸岩、植被和水蚀分区。

保留目的：失败复盘、代码追溯、避免重复相同路线。

禁止动作：在 V016 上继续加颜色、青苔、孔洞、灯光或 UI 来挽救主画面。
