# 大场景与手机展示合同

## 大场景完成感

大场景的细腻感依靠信息层级和空间一致性：

1. 主峰、次峰、平原和通道形成明确层级。
2. 峰群疏密、高低、宽窄与前后关系具有节奏。
3. 大块安静表面和局部复杂区域相互平衡。
4. 地表颜色、粗糙度、植被和水痕与峰体位置配准。
5. 中尺度明暗帮助识别脊、壁、凹槽、洞口和坡脚。
6. 完整环绕中同一地点保持同一材料身份和形成历史。

## 观察合同

地形和环境保持固定，相机围绕稳定目标移动。自动巡览使用时间步长，不能按帧固定加角度。用户触摸后立即暂停巡览。

相机改变只影响投影、遮挡和视角相关反射。相机运动不能重建地形、重新随机材质或改变物理尺度。

## 手机合同

1. 竖屏 390 × 844 为强制检查尺寸。
2. 单指旋转，双指缩放，双指平移。
3. 主要按钮触控目标至少四十四 CSS 像素。
4. 处理顶部与底部安全区。
5. 面板默认收起，不能遮住主峰。
6. 手机与桌面使用同一三维资产和同一地貌精度。
7. 加载失败、WebGL 失败和资源缺失需要明确错误信息。
8. 页面静止时采用按需绘制，巡览与手势时恢复连续更新。
