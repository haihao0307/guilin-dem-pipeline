# 喀斯特身份、尺度与形成合同

## 来源支持的桂林峰林约束

《桂林喀斯特地貌及地质过程》将峰林定义为冲积岩溶平原中的孤立石灰岩丘陵。峰体较陡，局部垂直，通常呈尖锥状或塔状。桂林以南至阳朔遇龙河上游和阳朔周边分布大量峰林，阳朔县葡萄乡峰林平原区石峰最密集。论文记录峰林坡度大于四十五度，相对高度六十至二百米，洞穴高度发育，几乎每座峰林都发育洞穴。

论文还记录桂林中泥盆统至早石炭统碳酸盐岩厚约三千米，可溶性碳酸盐矿物约占百分之九十八。湿润气候、断裂与裂隙、长期多阶段构造演化和连续缓慢区域隆起共同提供发育条件。

## 环江锥状峰丛对照

环江论文记录锥状峰丛的峰体共享基座，峰间有封闭洼地、谷地和峡谷。典型锥峰平均坡度约四十三至四十八度，相对高度约一百至五百米。降雨垂直入渗、裂隙和管道流、地下河、竖井与多层洞穴构成重要过程。

该体系用于建立负面边界：葡萄乡峰林不能生成共同基座与大面积封闭洼地语法。

## 独立生成合同

### 地貌身份

`identity = fenglin_plain + isolated_towers + high_cave_development`

### 区域结构

`regional_state = plain + tower_footprints + open_passages + drainage_base_level`

### 峰体结构

`tower = foot_recession + lower_cliff + middle_wall_system + upper_contraction + broken_crown`

### 岩壁结构

`wall = major_planes + concave_recesses + oblique_breaks + fracture_network + solution_grooves + collapse_faces`

### 洞穴结构

`cave = fracture_skeleton + hydraulic_level + enlarged_passages + chamber + entrance_lip + collapse_debris`

### 时间状态

`state(t) = initial_carbonate_body + tectonic_history + hydrologic_history + dissolution + collapse + transport + deposition + ecology`

这些表达式属于项目独立工程合同，没有声称恢复任何外部软件源码。

## 禁止形态

统一圆锥、旋转柱体、同宽截面、等距环纹、统一尖嘴、贴面洞、圆球崩积、峰脚互连和大面积平顶均属于失败形态。
