# 下一阶段：R5.K3 Living Karst

在 R5.K2 不改变宏观几何的前提下，加入最小可验证的“活喀斯特”状态链：

`water input → infiltration path → dissolution → transported mineral → cave drip → calcite deposition`

第一轮只增加少量可追踪过程点：

- 3—5 条稳定入渗路径；
- 与裂隙/孔腔连通的湿润和溶蚀代理；
- 2—4 个洞顶滴水点；
- 滴点下方对应石笋生长点；
- 洞顶钟乳石与洞底石笋共享同一水量/矿物账本；
- 时间前后可逆；
- 不改变用户确认的峰体、洞口和峰脚。

验收先看因果关系是否清楚，再看视觉丰富度。不要一次把洞穴铺满。
