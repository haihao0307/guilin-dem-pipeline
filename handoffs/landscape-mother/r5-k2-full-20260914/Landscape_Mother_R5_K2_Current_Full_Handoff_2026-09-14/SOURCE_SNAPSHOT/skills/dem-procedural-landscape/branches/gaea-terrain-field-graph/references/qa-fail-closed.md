# QA 与失败关闭清单

## A. 真值 QA

- [ ] DEM 文件、大小、SHA256 与收据一致
- [ ] AOI、CRS、像元大小、仿射变换一致
- [ ] nodata 和有效覆盖统计已记录
- [ ] 水系、湖岸、岸线、水深使用权威来源
- [ ] 没有旧资产、30 米回退、手工河流或无来源填洞

## B. 确定性 QA

- [ ] 同图谱、同种子、同参数输出哈希一致
- [ ] 改颜色种子不会改变高程
- [ ] 改微细节种子不会改变河网
- [ ] 改地质种子只影响批准的增强层
- [ ] 瓦片顺序变化不影响输出

## C. 地形结构 QA

- [ ] 峰位、主脊、主谷和盆地位置保持
- [ ] 河网连通保持
- [ ] 水面没有被地形穿透
- [ ] 岸线没有移动
- [ ] 增强幅度在预算内
- [ ] Macro、Meso、Micro 三个尺度可单独查看

## D. 接缝与 LOD QA

- [ ] 高程边界数值连续
- [ ] 法线边界无亮线
- [ ] 颜色边界无接缝
- [ ] LOD 切换无高度跳变
- [ ] 微细节远景平滑衰减

## E. 色彩 QA

- [ ] 色彩由 Data Maps 驱动
- [ ] 岩石、湿润、土壤、植被和暴露区可区分
- [ ] 宽尺度色块先于细噪声
- [ ] 没有连续蜂窝线、等高线色带和重复环纹
- [ ] 高饱和颜色只在局部事件出现
- [ ] linear-sRGB 计算和 sRGB 输出明确

## F. 性能 QA

- [ ] 桌面和移动分别测试
- [ ] 每个采样窗口独立通过
- [ ] GPU 纹理和缓冲可释放
- [ ] Worker 可取消
- [ ] 大范围页面支持渐进加载
- [ ] 无网络时仍能打开本地候选页面

## G. 视觉证据

```text
固定相机全景
近景岩面
河谷与水面
瓦片边界
LOD 切换前后
最终颜色
各 Data Map
参数 JSON
种子 JSON
控制台日志
```

## H. 失败关闭

任何关键门失败时：

```text
productionReady = false
visualApproved = false
truthApproved = false
```

保存失败截图、日志、参数和哈希。禁止自动换用低精度数据，禁止跳过失败通道，禁止用平均值掩盖单项失败。
