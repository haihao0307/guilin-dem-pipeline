# 当前桂林示范失败基线

## 1. 失败结论

当前在线 `桂林阳朔喀斯特蒸馏示范区` 在浏览器和自动 QA 层面可以运行，视觉结果仍未表达阳朔漓江典型喀斯特。

用户看到的主要问题：

```text
山体像宽缓土山
缺少塔状峰体
缺少近直立石灰岩壁
峰脚不清楚
漓江与峰体关系不完整
沿江低地和稻田关系缺失
近景没有持续增加真实结构
```

## 2. 技术原因

1. 片区自动选择只考虑局部高差和水系提示，没有先验证典型阳朔漓江地貌关系。
2. 原始高程仍是 12.5 m。增加三角面只改善连续性。
3. ±1.2 m 候选增量只适合小型表面扰动。
4. 几何层没有形成 `z_macro_delta_m`。
5. 材质基色偏棕褐，石灰岩灰白、层带、溶蚀和湿润差异不足。

## 3. 封存要求

1. 保留现有页面和 QA 作为失败基线。
2. 增加 `failed-visual-baseline` 状态。
3. 后续 A/B 必须同时显示旧失败基线、真实 DEM 和新候选。
4. 禁止继续微调旧片区并宣告完成。
