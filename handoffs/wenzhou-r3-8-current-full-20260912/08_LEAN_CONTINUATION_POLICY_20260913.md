# 小温州 · 轻量接续规则 · 2026-09-13

从本文件之后，小温州默认交接不再采用“解压上一版 1.03 GB 全量重启包，再叠加当前版本”的滚雪球方式。

## 保留但不随身携带

以下内容继续作为永久证据/冷档案保存，不删除历史 Release，也不再嵌入新的默认交接包：

- R3.1 / R3.2 全量重启 ZIP；
- 完整无损 DEM 归档；
- 原始/对齐 WorldCover、JRC、OSM、SoilGrids 证据 ZIP；
- 历史固定网页版本；
- Windows Python 离线依赖与其它恢复用大文件。

恢复时按固定 Git commit、Release tag、asset 名、bytes、SHA-256 精确取回。

## 默认随身包只带

- 当前状态与下一步；
- 单一世界总谱规则；
- 来源/Release/哈希锁；
- 当前 R3.8 关键源代码；
- 当前 QA / 构建脚本的文本部分；
- 少量必要记录。

默认禁止携带浏览器二进制栅格和历史全量底包。轻量交接包设 8 MiB 未压缩硬上限，超限即构建失败。

## 关于“两个土壤二进制”

当前每个 SoilGrids `property × depth` 有两个语义不同的声部：

1. `Q0.5`：属性中位预测值；
2. `uncertainty`：模型相对不确定性。

它们哈希、单位和含义不同，不属于重复，不能按重复文件删除。后续如需进一步缩小运行载荷，应通过运行时编码/分块/量化方案优化，而不是静默丢弃 uncertainty。

## 重复清理原则

- 相同 SHA-256 且语义身份相同：默认只保留一份活动副本，其余改为引用；
- 相同来源但不同语义/统计量：不是重复；
- 历史冻结版本不物理删除，只退出活动工作集；
- 新交接包不得再次嵌套已经永久锁定的大型 Release 资产。
