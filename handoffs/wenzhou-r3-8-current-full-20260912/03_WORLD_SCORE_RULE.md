# 单一世界总谱规则

用户在本轮明确：不要把土壤、WRB、JRC、土地覆盖、道路、建筑等做成很多彼此独立的“谱”。

正确结构是：

- 世界只有一份共同的总谱 / 大合唱。
- DEM、海岸/河流、WorldCover、SoilGrids、WRB、JRC、OSM、未来植被/建筑/Object DNA 都是这份总谱中的不同声部或观察证据。
- 证据源必须独立保存来源、时间、尺度、置信度、冲突和哈希；独立保存不等于独立世界。
- 造波/生成时由同一世界谱统一解释当前 Time / Location / Object 和观察尺度，再按需调用需要的声部。
- 不把所有数据一次装进运行时。世界应保持小而完整：稳定低频主体常驻，高频/局部/专题证据按位置、尺度和任务展开。
- 一个地点最终可以回答“这里是什么地形、什么土壤、土地覆盖、水体历史、道路/建筑映射证据”等，但答案来自同一地点身份下的多声部组合，而不是切换到多个互不相干的世界。

## 土壤具体规则

土壤最终应表现为同一地点的一个统一土壤语义对象/声部，例如：

- 表层属性：clay / sand / silt / SOC / pH / bulk density / coarse fragments / water retention；
- WRB：官方 MostProbable + 30 类发生概率；
- 深度：0–5、5–15、15–30、30–60、60–100、100–200 cm；
- uncertainty：保持为模型相对不确定性，不与属性物理量混写；
- 来源/尺度：SoilGrids 250 m model prediction external observation；
- 本地校准：农田/工程/现场尺度仍需真实局部证据。

这些不是 8+30+6 套独立世界层。底层可分文件，语义上必须归并到同一地点的 Soil voice，并由总谱按需演奏。

## 大合唱原则

像听大合唱：各声部必须独立可辨、不能互相伪装，但最终听到的是一场完整作品，而不是几十场同时播放的小演出。
