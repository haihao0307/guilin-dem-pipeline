# 嘴唇合成 R02：先诊断，允许撤销自己的改动

当前状态：两轮额外着色／唇缘效果均未通过独立图审，已从生产源码彻底撤除。最终只保留旧唇色源头阻断与完整肤色单次合成，正在进行与当前源码绑定的浏览器和公网验证。**这是局部合成修正，视觉收益较小；整体嘴唇质感仍未达标。**

## 已经看到的主要问题

| 问题 | 实际表现 | 本轮状态 |
|---|---|---|
| 颜色缺少组织 | R01 纯底色近似整片灰粉色，完整材质仍有填色感 | 未解决；新增色斑不能替代可信的组织关系 |
| 唇缘衔接生硬 | 唇红与口周皮肤像连续填色的边界 | 已定位并修正重复着色／早期肤色覆盖；视觉收益较小 |
| 细纹与形体层次不足 | 成组纵纹、较光滑的大面，外观仍依赖反光 | 本轮保持原值以隔离颜色原因；未解决 |
| 动作暴露内缘问题 | 说话／噘嘴的折段内缘、尖收束口角及大片浅色内部 | 未解决；须先定位形变阶段与表面材质身份 |

R01 已减少 R07 的下唇强亮斑和部分长划痕，并使上唇轮廓更清楚；这些不计入 R02 新成果。缺少人物目标参照时，不把唇峰、厚薄或左右对称偏好判为解剖错误。详见 AUDIT_FINDINGS.md。

## 最终保留什么，为什么

1. **在入口阻止旧唇色染入皮肤。** 原流程先混入旧唇色，最后再以新唇缘范围覆盖；两个范围不一致。R02 只阻断旧着色，保留毛孔、胡茬和粗糙度依赖的原区域字段。
2. **在皮肤全部颜色层完成后合成一次。** 原流程使用早期肤色快照，可能覆盖后续口周色彩，还重复使用边缘覆盖率。R02 保留完整最终肤色，与原 R01 组织颜色按原生唇缘单次合成。

R01 的颜色配方、几何、法线、细纹、湿润、粗糙度、灯光和镜头保持一致。R07 是更早对照，它的几何主沟幅度不同，不能把 R07→R02 全部变化算成本轮收益。

## 实际对照如何推翻两轮试验

首轮源码 bf235cbb741de1eb21f469c9e020b95a65f24040 增加空间色彩变化与内缘加深，真实微距／斜侧图却出现大块红灰斑驳。root 和独立图审均否决，已撤除整段处理。原始记录见 ITERATION_01_REVIEW.json 与 INDEPENDENT_VISUAL_REVIEW_01.json。

第二轮源码 331b5c469ce822d989a10193d2292c17b94e346a 比较 R01、仅合成修正、合成修正加额外外缘过渡三组。独立审阅 14 张完整材质／底色图后，认为额外过渡主要洗浅外缘、使唇红看起来略微收窄，普通整脸尺度没有清楚收益。**额外过渡也已撤除，开关和着色代码不再保留。** 仅合成修正与 R01 很接近，没有明显新色斑或纹理损失，不能声称整体质感明显提升。

内部 spatialColour 兼容字段固定为 false；尝试开启已撤销效果会在状态变化前报错。旧 R01 档案缺少此字段时按 R01 对照恢复；未发布试验档案若带 true 会明确拒绝，避免静默改画面后声称精确还原。原生人物校准代码沿用冻结 R01，不覆盖 PR303 的并行恢复工作。

## 检查器本身也接受审核

首轮错误要求外缘原生皮肤带内至少 10% 的旧羽化，实际最大约 4.58%，在皮肤响应测试之前停止。第二轮使用已发布 R01 旧唇色 0／1 正对照选点，却把另一种 regionalColor 参数也限定在这个支持区域：它在 6,392 个原生皮肤点中有 109 点响应，却仅命中原 64 个旧唇色点中的 3 点，低于 4 点门槛。

不能把这判为已经证明丢失肤色，也不能把门槛从 4 降至 3。第三轮在独立加载的已发布 R01 上前置正对照，发现薄旧羽化交集自身只有 4 个可观察点、每点仅一个 8-bit 色阶，候选尚未启动便早停。它否定了该薄交集的测量前提，不能判为候选失败，也不能改写成通过。

最终经独立方法复核，明确缩小区域色证据的声明：regionalColor 在原定的整个原生近口皮肤带建立自身正对照，原系统实际有 107／6,392 点响应；不再额外限制为薄旧羽化交集。相机、几何、距离带和侧向范围不变，不扩大全脸。仍要求至少 8 个原基线可观察点，候选在这些冻结坐标至少 4 点响应；候选成功点不参与选点。beardShadow 仍检查旧羽化交集。**不再声称区域色在薄交集的响应已被定量验证，也不声称幅值或全域逐像素保真。** 完整肤色参与合成的路径由独立源码审支持。没有改变曝光、放大信号或降低门槛。

首轮 GPU 关闭超时保留原始记录；第二轮排空已提交渲染后正常关闭。任何清理失败仍阻止完成。三轮失败不改写为通过。

## 怎样判断完成

- 技术：公开 R01 基线精确匹配；旧唇色在 R01 影响输出，在 R02 不再影响；后续口周肤色层仍有实际响应；湿润不改底色；法线／粗糙度／几何不变；原生嘴部范围外像素不变；比较、复位与档案往返有效。
- 视觉：同相机完整材质和底色的整脸、微距、斜侧实际图审，允许否决已写好的处理。像素变化或参数响应不算整体质感通过。
- 交付：固定 HTTPS 精确回读，与被验证源码绑定；真实三维比较和视角操作有效。390×844 仅代表浏览器视口，不代表真手机性能。
- 限制：未证明明显整体视觉收益；颜色组织、细纹组织和动态内缘尚未解决；没有本人校准实拍或测得光学参数。visualAcceptance=false，productionReady=false。

## 后续改造应先取证的原因

先确定浅色内唇属于哪些三角形和材质，再记录张口、局部唇动作、上下缘约束、口腔包络投影各阶段的顶点变化，定位折段第一次出现的位置。包络离散采样、轨道连接和材质分区只是待证候选，不能靠压暗内部或磨圆口角宣称修好。
