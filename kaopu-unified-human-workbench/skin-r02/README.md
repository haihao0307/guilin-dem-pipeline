# 共同人体 · UH 文档关系融合 R02

本目录继承 `skin-r01` 已交付皮肤，显示的仍是原 Anny / GNM / MHR 共同参数人体。没有复制 Universal Human 的商业节点、贴图或模型，没有改写原人体位置、三角索引、骨架、教师参数、颈部连接或原网站主入口。

## 使用

载入共同模型后，点击“新分层处理 / 上一版处理”切换同一相机与灯光下的材质。原白模按钮继续保留。“皮肤近看”只改变镜头，不换人物。

“分层参数与对照”包含肤色底层、基底覆盖、扫描颜色混合、局部血色、掌侧色素、粗糙度和微结构联动、分区油脂、唇部颜色/光泽、均匀哑光覆盖、RGB 扩散宽度以及前臂/手部张力实验。自然、哑光和深暖是材质配方，不是三个人体，也不是三张新的扫描贴图。

颜色、实际粗糙度、微表面法线、区域遮罩和张力可独立检查。材质保存、恢复和 JSON 导入导出独立于原人物档案。

## 源码与重建

`UHLayer.mjs`：公开关系的独立实现，参数验证、区域遮罩、张力、材质和界面。

`assemble.cjs`：校验并继承已验证的旧皮肤源文件，生成本版 `SkinLayer.mjs` 和构建器。原教师代码未被重写。

`review.cjs`：保留本轮实拍审查修正，限制唇部遮罩外扩；只为旧回归测试更换精确的按钮选择器，不删除旧断言。

`unit.mjs`、`qa.cjs`、`native-regression.cjs`、`qa-pages.cjs`：数学约束、实际材质像素、原人体求解器和发布网页测试。

重建顺序：`node review.cjs` → `node assemble.cjs` → `node build.cjs --source-only` → 测试。生成固定预览时设置 `ASSET_COMMIT=<40位提交>` 后执行 `node build.cjs`。预览包含完整原生参数工作台，不使用测试快照替代运行时人体。

## 重要边界

这是学习公开输入/输出关系后的 WebGL 实现，不是 Universal Human 原版移植，也未完成其官方样片等级的视觉验收。仍沿用先前512像素皮肤样本和米制静止表面坐标；没有完整精绘全身贴图、专门雕刻的表情皱纹或 Cycles 随机游走光传输。眼睛、眉毛仍保持原平台状态；全身薄部透光继续禁用。

张力只联动材质，不产生新的几何皱纹或真实血流。改变体型使旧中性参考失效；带动作时改变体型会先清零张力，回到中性才重新校准。

研究来源、明确的实现公式、许可限制和未读到的内容见 `RESEARCH.md`。真实通过的运行范围见 `VERIFICATION.md`。自动化通过不代表影视级视觉质量或手机实机性能。
