## 已查明的原因

R03 使用头部参考坐标中的长方体范围判定耳部。这个范围不等于耳朵：同侧耳后的头皮也被选中。耳部形变及 Loop 平滑均可能修改该范围内的显示顶点，材质也沿类似方框取样。仅限制外展角度不能根治，默认形态本身就会污染头皮。

原始绑定/拓扑缓冲区不变，并不保证派生显示表面不变。旧版测试只验证原始缓冲区与另一耳，没有同侧耳后头皮保护回归。本版在同一上游显示表面、同一人物参数上重新运行原始 R03 类，实际复现旧问题，而非凭图片猜测：1,586个耳域外显示顶点发生位移，其中测试定义的同侧头部采样788个，最大位移1.228527779毫米。详见 `acceptance/candidate/report.json` 的 `oldFailure`。

进一步检查确认：保留的 GNM 数据没有独立耳朵语义标签，耳朵和部分头皮均使用未分区值255。不能把255直接解释为耳朵。本版不编造不存在的语义标签。

## 底层修改

`EarDomain.mjs` 在原生 GNM 拓扑上定义两条经过逐边校验的闭合耳根环，每侧42个边界点。由耳廓种子沿三角网格连通关系获得每侧511个内部顶点；耳根边界和头皮固定。作用范围绑定在原拓扑，不随人物姿势重新用空间距离选点。

在耳廓内部沿表面边计算到耳根的距离，使用0.7毫米固定领圈和10毫米五次平滑渐变。此尺度定义在原生模板上，随当前头部比例映射；不是临床测量。权重由原始 canonical recipes 及已有显示细分规则传递，不在姿势更新时用最近邻猜测。这是原生拓扑上的作者定义作用域与图上距离场，不是统计耳形分割、真实组织仿真或有界双调和权重求解器。

`EarSurface.mjs` 取消该层的 Loop 平滑位移，改为耳内单级共边中点细分。源顶点不因细分而移动，耳根外的显示位置和法线均保持上游值。保护区一旦位移非零立即报错。不是通过加模糊、压低光照或生成图片隐藏鼓包。

`EarMath.mjs` 删除空间方框选耳规则。外展围绕原生耳根的倾斜轴旋转，影响权重只在耳廓内部过渡；耳根锚点不跟着耳廓外展旋转，另一侧不受单侧编辑影响。固定是相对当前人物头部；头部本身仍可随原有绑定和动作运动，不会被锁在世界坐标。-9 / 0 / +12度是相对原生耳形的控制增量，不是实际耳颅夹角，也不是人体关节活动测量值。

`EarMaterial.mjs` 让耳部颜色、毛孔、粗糙度和扩散使用同一绑定权重，避免头皮被材质方框重新染出边界。耳部主体表面保留 R03 效果；唇材质源码与 R03 的SHA-256相同：`de2162e3fe44e185571ae0c17253fb022bbefd29b860a23ed1e5ac661e58add5`。

## 使用

打开新页后点「贴头」「自然」「外展 / 招风」，也可用「外展增量」滑块。选择左右同步、仅左耳或仅右耳。新滑块进入原有耳部编辑/撤销链，不另存一份冲突状态。

「显示作用范围」显示真正参与着色器和几何的绑定权重，绿色是耳廓内部，暗色为无作用区域；状态行报告保护区位移。「恢复材质」退出诊断。左耳根、右耳根、耳后均可直接查看，原唇色检查和整脸入口保留。下方继承的「原版对照」是关闭耳增强层后的原生表面，不是重新运行 R03 错误。

移动耳廓会改变投射到头皮上的阴影；阴影变化不代表头皮顶点移动。几何隔离以实际显示数组检查为准。

## 档案与兼容

耳部档案升级至 `kaopu/ear-structure@3`，可读旧@1/@2并保留参数，但新生成器结果不承诺与旧版逐像素一致。旧 R03 不支持反向读取新@3；旧网页和旧档案保留。原36项耳部控制、8种耳形、左右独立与人物完整档案继续保留。

## 仍需明确的边界

本修复针对当前固定原生 GNM 拓扑，不是任意外部头模的自动分割器。换拓扑需重建耳根环和映射，不能直接复制索引；检测不匹配会拒绝运行，而不是退回有问题的空间方框。

局部三角面/采样片间距保护不是全局碰撞。极端形态组合可能被限幅；耳道、软骨实体物理、实测多层组织散射与影视级全部细节不在本次完成定义中。保留8种耳形不等于本轮穷举了它们的所有组合。

本轮完成定义是：报告中的标准外展范围、参数和人物测试下，耳廓实际变化，同时被保护的耳根及同侧头皮显示位置不被拖动；不能把功能PASS延伸成所有耳部外观已经最终认可。
