# 单人动作连续性：研究与实现约定

更新：2026-10-14。人物仍为 human-integrated-r04 的原生人物。R04 单人动作源保持冻结；本轮实现位于 motion-review-r05。核对的 LAFAN1 官方仓库版本：`94084601bacdf9cc3764b5c73daaeccae6035fac`。

## 已阅读的第一手资料

- Ubisoft [LAFAN1 官方仓库](https://github.com/ubisoft/ubisoft-laforge-animation-dataset)：77 段、5 位参与者、496,672 帧，30 fps。它是过渡研究数据集及基线评估工具，不是可直接装入网页的训练好的人体控制器。
- Harvey, Yurick, Nowrouzezahrai, Pal. **Robust Motion In-betweening**, ACM TOG 39(4), 2020. [作者论文全文 v1](https://arxiv.org/html/2102.04942v1)，[Ubisoft 项目说明](https://www.ubisoft.com/en-us/studio/laforge/news/1ERUZiYmmtUBYZ4KvVvmFP/robust-motion-inbetweening)。
- 官方 `evaluate.py`、`lafan1/benchmarks.py` 与 `license.txt`。官方基线是根位置 LERP 与关节四元数 SLERP，另有零速度基线；测试过渡长度为 5、15、30、45 帧。

论文的实际方法是对抗训练的递归网络，包含过去上下文、目标、剩余时间嵌入和目标噪声调度。我们没有训练/运行这个网络，没有复制其代码，也没有将解析过渡声称为论文复现。

数据与仓库按 CC BY-NC-ND 4.0 发布。当前公开工作台没有加入 Ubisoft 动作数据、改编 BVH 或第三方复现代码。学习方法后，在现有 CMU/原生动作与自有人体求解器上独立实现本轮功能。原先动作来源说明继续有效。

## 从研究中转化的工程要求

| 资料中的事实 | 我们的工程转化 | 当前边界 |
| --- | --- | --- |
| 3.1 使用局部四元数、根速度、固定骨偏移与 FK | 同时保存当前/前一姿势，按固定原生骨长恢复全身；比较世界空间足、膝、腕、头位置及速度 | 原生骨架 104 骨；没有修改成人骨长或权重 |
| 3.1 对上下文归一化朝向，生成后恢复世界变换 | 新动作按当前人物位置及朝向放置；转弯后下一动作沿新朝向继续 | 水平地面、单人；没有导航或避障 |
| 3.3 明确剩余到达时间，避免末段停顿/跳变 | 过渡时间由姿势/速度差决定；衰减函数在结束时归零，暂停/拖动时间轴不消耗过渡 | 独立解析函数，不是神经时间嵌入 |
| 3.1/4.4 足与趾接触用于 IK 修正 | 沿用现有接触置信度；匹配步态阶段并短暂保留旧支撑足锚点 | 接触来自现有动作求解器/估计；不是网络预测或力学保证 |
| 全局位移与 FK 位置必须进入评估 | 检查切换位置、速度、骨长、脚底、步态、暂停重现和实际画面 | 本地工程验收，不冒称 LAFAN1 测试集分数 |

步态候选搜索属于本项目为现有小型动作库选择的工程方案；论文 2.1 将 motion matching 作为相关工作讨论。它不是该论文提出的网络结构。

## 函数归属与坐标约定

- `Continuity.mjs / MotionContinuity.raw`：只读 R04 姿势缓存，按源采样率插值，展开循环根位移。内部原生 Z 向上、米；显示仍由原有绑定转换至 Y 向上。
- `configure`：搜索至多 96 个循环步态阶段，比较 FK 地标位置、速度及左右接触。首选方案的逐帧转角过大时，再检查至多 8 个分散阶段的完整短过渡，避免首帧很像、过程中却膝盖突变。有限动作从起点播放，避免跳过蹲下、跳起或挥手的语义。
- `aligned / place`：仅在根节点施加水平刚体变换。骨骼尺寸、模型、材质与皮肤权重由 R04 保持。
- `sample`：独立五次衰减偏移。旋转在最短弧旋转向量空间计算；根位置同时匹配初始位置和速度。衰减结束后精确跟随目标源片段。
- 过渡长度初选为 0.32–0.65 秒；若整段检查仍有大转角，再比较 1.2、1.4、0.85 倍时长（限制在 0.28–0.9 秒）。这些是本动作库的工程参数，不是论文结论。相位选择和时长检查都只在切换时执行。
- `support`：复用项目原生两段腿 IK；按旧支撑置信度、当前新动作接触、起始软启用与结束软释放加权。脚底代理来自本人原生加权表面；过渡中增加地面下限。膝盖弯曲平面从前后动作连续传递，减少接近伸直时的翻面。原生主关节跨越辅助骨，解析求解使用当前有效跨度，最终仍经不可变原生骨偏移 FK。没有在空中固定脚，也不把每一帧强行钉在地面。
- `Workbench.mjs`：单人 UI、播放时间、连续演示、普通混合对照、诊断。过渡不依赖后台墙钟推进。播放墙钟只负责推进动作时间。
- `../motion-review-r04/`：原人物绑定、动作重定向、来源数据、表面传输，全部只读复用。

## 关键修正与拒绝的做法

1. 仅有零速度缓入混合，会在切换时丢失已经存在的速度。保留普通混合作为可检查对照，默认使用包含初始速度的偏移。
2. 将停止目标钉在切换瞬间的根位置，会使人物先向前走又倒退回去。新目标加入半个过渡时长的速度差位移，提供真实制动距离。
3. 用 `performance.now()` 独立消耗过渡时间，暂停等待后会改变姿势。改为纯动作时间采样，重复 seek 同一时间获得同一姿势。
4. 不直接插值皮肤矩阵；使用单位局部四元数与固定骨偏移 FK，避免骨长伸缩。
5. 不将某个足接触阶段的骨骼误差视作最终皮肤穿透验收。记录实际足底检查和新截图，保留继承的肩腋/手指形态问题。
6. 只按切换第一帧的接近程度选相位，曾产生约 27° / 120 fps 的膝关节单帧转角；加入完整候选过渡检查后再选阶段。脚底代理穿地曾达到约 12 cm，不能因端点连续就通过验收。

## 验收与后续

`verification/continuity-qa.cjs` 检查站走、走跑、跑走、转后继续走、走接转、跑接停步、蹲起及姿势中断，记录同一场景普通混合的速度误差，并播放真实连续序列。每次结果必须绑定 `preview.html` SHA256。

`verification/phase-sweep.mjs` 使用从原人物提取的本地原生骨架/权重夹具，在走→跑、跑→走、走→站、跑→站各选 24 个不同源阶段，共 96 个过渡。它用于发现少数时刻的膝部问题，不将 18 个浏览器例子当成所有切换时刻的证明。夹具与大型人体资产不重复发布。

尚未具备：任意长缺失动作生成、Ubisoft 神经模型、碰撞/平衡/肌肉物理、地形适配、双人接触，以及真实 Mixamo 库动作的视觉认证。特别是空中/深蹲任意强制切换，仅提供连续的姿势衔接，不构成可信的运动决策系统。
