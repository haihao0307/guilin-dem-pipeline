## 这次修复的实际问题

R01 顶部的嘴唇保存入口已经写入 `lipRealism` 参数及两份原生唇纹校准。保留在旧皮肤面板中的完整人物保存、载入按钮，以及头部和全身皮肤的公开档案 API，却仍调用较早捕获的 R02 函数。通过这些入口保存会漏掉嘴唇内容。

R01.1 只把这些遗留的完整人物入口接回当前档案函数。原本通过人物控制器动态调用的眼、耳、原生嘴唇和形态存档保持其工作方式。局部参数记录与模型导出不属于这次重定向范围。

生产修改位于新目录的 `LipSurface.js`。原 R01、冻结 R07、皮肤工作线及另一条 `lip-control-contract-r01` 审核支线不变。档案 schema 沿用 `kaopu/lip-realism@1`，没有校准段的旧档案继续使用兼容路径。
