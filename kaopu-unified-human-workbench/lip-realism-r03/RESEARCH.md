# R03：只修细纹的重复感

## 对象与证据范围

工作对象是 R01.1 已验证工作台中的原生人物，不是重新生成的人物。基线源码为 `489eb0b1520603bb3ddb65f0ec5f12140a2e7e97`，分支交接头为 `57cfade66fb37c260df1dcd836f5cd239cccef41`。基线没有获得用户最终视觉认可，只是完整存档和运行链已验证。

本轮直接观察了 run `39095533327` 的 `original-default.png` 和原 `lrFolds`。原函数每个 1.05 mm 横向格都产生一条相近长度的主沟，每条恰有一个短分支；有限的抖动没有消除拓扑上的重复。实际画面中，上下唇仍以相似的纵向细线为主。这是本轮要纠正的生成器缺陷。

## 原始研究与实现的边界

1. **Seo et al., 2024**, *Image-based investigation of lip aging features in a large number of Korean women*, DOI [10.1111/srt.13563](https://onlinelibrary.wiley.com/doi/full/10.1111/srt.13563)。研究把照片中的唇纹分为上下唇、横向与纵向分量。它支持同时考虑不同方向，不能提供本人物的沟槽形状、深度或个体纹理。不会把人群年龄相关结果转换成某个预设人物的确定规则。查阅日期：2026-10-18。

2. **Epic Games, Digital Humans, UE4.27**, [官方材质说明](https://dev.epicgames.com/documentation/en-us/unreal-engine/digital-humans?application_version=4.27)。其中把中尺度与微尺度法线细节分开讨论，并将细节随表情变化的方式与底色区分。这里只采用通道分离的工程原则；没有导入该项目的扫描、贴图、网格或渲染器。查阅日期：2026-10-18。

3. **本项目原生坐标与控制合同**：继续使用唇缘 rails、`vFRest` 和 ET19 strain。所有新沟槽附着在继承的静息表面上，按原生应变衰减。唇形、粗沟几何和口腔结构均不从这些论文推断。

## 本轮可见差异的依据

新函数只纠正原函数强加的规则性：允许主纹长度不同、局部间断、斜向细节，以及有或没有分支。工程参数保持在现有低振幅法线细节的数量级，并随像素覆盖滤波。长短比例、间距和幅度是待视觉验证的制作参数，**不是论文测量值、逐人扫描或临床模型**。

保留原函数作为真正的 R01.1 对照。相同状态下的底色、粗糙度、湿润反射、canonical/displayed geometry 必须相同；强度为零时，两种细纹函数不应造成任何画面差异。不能靠染色、加深口缝、改光或提高湿润来掩盖细纹问题。
