## 本轮实际修正

上一版 FoldMath 只用布尔判断保护眼口，保护边界外仍非零的隆起、收拢和下垂被突然切断。R02 增加五次平滑过渡，对三个分量一起衰减到零；没有为保护区取消保护。算法极值扫描复现的旧口周边界跳变量约0.557毫米、眼周约0.305毫米，只是程序测试，不是真人测量。对应新边界有限差分降至数值零附近。

鼻唇与下颊从窄双脊改为更宽的单侧软组织隆起，谷底更浅、两端渐弱；鼻唇曲线用局部斜率修正距离，减少方向改变导致的宽度变化。眼下第二条细褶减弱，外眼角支持区改为在衰减完成后才结束。形体仍直接写显示顶点，保留灰模和关闭新增褶皱对照；没有用色彩图或暗线取代真实起伏。单条截面补偿不等于整张脸体积守恒。

妆感不再把全脸粗糙度拉向一个固定值。保留分区差异，轻微增加粗糙度，减弱窄高光和表面清漆分量；向平滑法线混合的最大系数从0.42降为0.08，减少微结构损失。这些是着色器系数，不代表测得的毛孔保真百分比或真实化妆品。

换肤预设不再重置用户选好的灯光、曝光和灰模诊断。形体滑块仍在松手时提交，避免拖动期间不断重建待机。旧 @1 档案的参数允许导入，新保存明确使用 `kaopu/geometric-skin-folds@2`；公式改变后不承诺旧参数生成完全相同像素，精确旧外观应使用冻结 R01。

## 缓存与真实成本

FoldSurface 准备缓存逐值检查源坐标和源法线，命中后复用细分、底面平滑及法线准备。不是仅比较指针、版本号或不验碰撞的哈希。最终褶皱及其法线仍计算，颜色诊断也更新。每个显示源最多两条准备记录，释放表面时清理。

最终同机、同参数、同一显示表面测试：关闭缓存的三次 CPU 更新为263.3、260.6、260.7毫秒；命中缓存为50.1、48.2、48.9毫秒。中位数260.7 → 48.9毫秒，约减少81%的这一阶段耗时。缓存开启和关闭的最终顶点、法线逐字节一致。

这不是每帧 GPU 时长、完整待机烘焙、首次打开耗时或消费显卡 FPS。换人物、改原始身份等改变源数据时仍需要完整准备；形体提交后的原生待机基底重建仍存在。当前表面两条缓存共22,015,080 bytes，约22.0 MB / 21.0 MiB，属于额外内存而不是整个应用内存。多个显示源分别有缓存，不能把此数当整个页面上限。

显示几何仍为205459顶点、410424三角形，和 R01 相同，没有为本轮软化再加面。默认保留已实现的双方向光、单遍显示；不把上一轮关闭多遍散射的收益重复算成本轮发明。首次加载仍使用原有固定在线资源。

## 源码与重建

当前权威是本目录可读 `.mjs` 源文件。`iteration/skin-folds-r02/install.py` 仅保留首轮引导历史，当前 workflow 不再执行它，避免抹掉后续审核过的 R02 修改。不要把该脚本当成最新版安装器。

从含固定父模块的完整仓库快照运行：

```sh
npm install --no-save --package-lock=false playwright@1.58.2 esbuild@0.25.11
node kaopu-unified-human-workbench/skin-folds-r02/test.mjs
node kaopu-unified-human-workbench/skin-folds-r02/fair-test.mjs
node iteration/skin-folds-r02/test-r02.mjs
node kaopu-unified-human-workbench/skin-folds-r02/build.cjs
```

构建环境 Node 22。`verify.cjs` 用 PREVIEW_URL 指向固定公网；`iteration/skin-folds-r02/extra.cjs` 同时使用 BASELINE_URL 和 PREVIEW_URL 做同机对照。不能只复制本目录就当成完全独立、离线可重建的项目。
