# KAOPU · SkinVariationDNA 自然皮肤变化知识库 R01

> 文档类型：方法参考 / 视觉知识库；不是运行时代码、皮肤贴图资产或视觉验收报告。  
> 2026-10-15。面向 KAOPU 人物总台、皮肤、毛发、面部及渲染工作台。  
> 原则：保留原有基础皮肤、SSS、毛孔、眼唇耳、人物拓扑及统一灯光；只补充自然生活痕迹。  
> 当前阶段：**KNOWLEDGE_ONLY；尚未完成 R01 七图实现、三人物预设或用户视觉验收。**

## 一、一句话逻辑

真人感不是“增加噪点”，而是 **稳定身份皮肤 × 解剖位置 × 生物学上合理的原因 × 生活事件 × 材质通道的正确响应**。

参考生成关系：

**CharacterIdentity + AnatomyFields + SharedFollicleField + Exposure/State + SparseEventHistory + Seed → SkinVariationDNA → PBR/SSS 通道增量 → 原基础皮肤材质**

其中：
- 身份层决定肤色基线、个人斑点倾向、毛囊密度倾向，但不强制把年龄、性别、肤色类别与疾病绑定。
- 解剖层决定事件在哪里“可以发生”和概率权重；先有眉、眼睑、鼻翼、鼻背、颊、口周、颏部、颌缘、耳、发际等可持续的脸部区域。
- 状态层决定血色、油脂、干燥和剃须的短期变化；生活史层决定雀斑、色沉、痘印与旧疤等长期特征。
- 生成的痕迹优先为有位置、类型、阶段、大小、形状、方向和固定 ID 的稀疏事件，而不是每帧变化的纹理噪声。
- 随机数只能改变一个合理事件域内的个体差异，不能替代解剖规则；左右相关但不镜像。
- 本系统是**视觉合成参考**，不是医学诊断、皮肤病模拟器，也不把艺术参数伪称为人体测量值。

## 二、从参考研究真正学到什么

### 1. lo-th/head：学习“通道分工”，不搬贴图

原仓库公开可见 skinM1~M4、skinW1~W4 头部资源，存在各自的颜色、法线、粗糙度及其他皮肤外观纹理；README 明确使用 Three.js、TSL 和 MeshSSSNodeMaterial。可迁移的是**同一个面部区域在颜色、微法线、粗糙度、SSS 中分别表达**的组织方式，而不是纹理像素、UV、扫描网格或其灯光。

不能仅凭资源文件名推断所有后缀的精确物理意义；参考资产逐项授权也未完成审查。因此只提炼思路，**不直接复制第三方贴图**。

### 2. BioSkin：底色由生物物理层解释，生活痕迹独立叠加

Meta BioSkin 研究的是从漫反射 RGB 推断与编辑皮肤生物物理性质，并进行光谱重建。它支持把肤色思考为色素与血液等贡献的组合；**不等于**它能直接生成痘坑、胡茬、雀斑的事件历史，也不等于当前工作台已经获得生理标定。

### 3. 皮肤科与测量资料：同样深浅的“点”未必属于同一类

- PIE 炎症后红斑主要是红 / 粉红残留；PIH 炎症后色素沉着偏褐色/灰褐，通常为平面颜色变化，**不是凹陷疤痕**。
- 真正的萎缩性痘疤有凹陷结构；活动性丘疹/脓疱与痊愈残留必须分成不同事件类型。
- 眼周暗色存在 pigment、vascular 和 structural 以及混合类型：**结构性阴影来自几何和光线，禁止烘焙为黑眼圈底色**。
- 雀斑常较小、与日晒相关；日光性黑子常更持续、边界较明确，不能简单用同一套褐色噪声替代。
- 鼻部通常比颊部多油，但受环境、个体与状态影响；T 区强度是**概率先验**，不是每个人永远固定的亮度表。
- 小样本毛囊研究发现毛囊密度和皮脂输出不宜简单等同，因此胡须域与皮脂域可相关，却不能当成同一张图。

## 三、七类知识条目 / 语义地图

| DNA 知识条目 | 解剖与分布逻辑 | 主作用通道 | 必须避免 |
|---|---|---|---|
| **VascularMap** | 鼻翼、鼻周、颊局部、少量下眼睑及耳部，允许左右细微差异；红晕小尺度叠加在既有血色上 | albedo 中血色分量；必要时影响 SSS/vascular | 全脸统一加红、整片鼻翼鲜红、把光照暗角当红斑 |
| **MelaninVariationMap** | 雀斑、晒斑、轻微自然斑驳与 PIH 分离成不同事件族；位置参考日晒与个人历史 | albedo/pigment | 整脸脏斑、将所有暗斑解释成年龄、随意抬高几何 |
| **SebumRoughnessMap** | 鼻部较高、额头/下巴次之、外颊较低；保留个人和状态覆盖 | roughness、specular lobe | 通过调白底色假装油亮、全脸塑料反光 |
| **UnderEyeMap** | pigment=柔和褐灰；vascular=局部蓝紫/粉色；structural=泪沟、眼袋、眼窝几何产生的真实明暗 | pigment、vascular/SSS；structural 只指导几何/灯光检查 | 画一圈均匀黑色、把结构阴影烘焙进 albedo |
| **AcneHistoryMap** | 稀疏、轻微成簇、不同形状和愈合阶段：丘疹、脓疱、PIE、PIH、旧凹坑 | 活动性痕迹局部 pigment+roughness+微法线；PIE/PIH 主要颜色；真凹坑才允许真实凹陷/位移 | 颗颗等距、同红同大；PIH/PIE 默认隆起、所有斑点都有深坑 |
| **FollicleAndBeardMap** | 唇上、颏部、颌缘、颊部胡须区按共同毛囊根点和密度场；毛茬随剃须长度、角度和色素变化 | follicle/hair、局部 pigment、微结构、剃须刺激 roughness | 嘴巴外围一整块黑色、胡茬位置与实际毛根不一致、越过唇/眼睑 |
| **DrynessAndFlakeMap** | 鼻翼外侧、口角、少量颊部等可出现局部干燥，必须低覆盖；受状态影响而非全年固定 | roughness 上升、micro-normal、小范围颜色变化 | 全脸撒白点、粗糙度和油脂强度同时满格、远景闪烁 |

**通道分工不变：**
- albedo / pigment：颜色和色素事实，不包含光照、AO 或环境影子。
- roughness / sebum：表面油脂与干燥的反射状态，不直接改肤色身份。
- normal / microstructure：毛孔旁、活动丘疹、微脱屑等微小表面坡度。
- displacement / scar：确有几何凹陷且网格精度足够时才进入；法线近似不能声称真实位移。
- SSS / vascular：血色与皮下光学响应，不随意覆盖原 SSS 标定。
- follicle / hair：毛囊根点和短毛方向，必须复用毛发系统的空间根点数据。

特别约束：**七张“Map”首先是七个逻辑数据域，不强制成为七张独立常驻 4K RGBA 纹理。** 渲染端可按实际需要打包、缓存、局部合成、复用稀疏事件数据，须报告真实显存和采样开销。

## 四、统一生产逻辑：从“事件”而非从“贴图”出发

1. **固定基底**：读取同一人物、同一拓扑、同一原生 rest-space/标志点、原皮肤光学参数和毛孔/毛囊资产；不修改原皮肤材质文件。
2. **创建解剖场**：鼻翼、面颊、颞部、额头、上下眼睑、眼眶、胡须域、唇、耳、颌部都具有平滑、可追溯的遮罩；不同个体的面型变化后仍能跟随语义锚点，不让外部 UV 承担唯一真值。
3. **生成潜在原因场**：色素倾向、血色倾向、皮脂水平、干燥状态、UV/年龄/生活事件、毛囊密度。原因场稳定、具个体 seed，并受到解剖区域的约束。
4. **生成离散事件**：一颗活动小丘疹拥有红晕半径、中心半径、发生位置和愈合阶段；一处 PIH 拥有色素深浅但没有起伏；一个痘坑才有凹陷剖面。事件按局部簇/排斥距离产生，不用规则点阵。
5. **做空间关联**：同一事件同时驱动需要的颜色、反射、法线，但**不是所有通道同步加同一张噪声**；毛囊根点和胡茬必须与真实毛发系统使用同一密度场及对应空间变换。
6. **执行通道合成**：按颜色、反射、微结构、真实凹陷、血色/SSS、毛发六类输出增量；禁止 AO/灯光/鼻翼假阴影混进颜色。
7. **完成诊断**：能单独查看七类 semantic mask 和六类材质增量；启停变化不修改原人物的几何哈希、骨骼、原毛孔与灯光。
8. **统一视觉检查**：同一个人、同一焦距/镜头和统一冷暖光，先基线 OFF，再 ON；先正常观察距离后微距，再转头侧光检查纹理是否跟随皮肤而非屏幕。

这里区分三个空间尺度：
- **区域尺度**：鼻、面颊、眼周等缓慢的肤色与反射变化。
- **事件尺度**：痘印、雀斑、血丝、旧痘坑、剃须刺激，有独立位置与生命周期。
- **微结构尺度**：毛囊点、极小脱屑、毛孔边缘，不产生宏观脏斑。

禁止仅靠 96 mm 或其他固定周期平铺噪声代替事件坐标；基础噪声可平铺，但明显痕迹必须避免接缝和周期重复。

## 五、三种参考人物预设（未来开发契约，当前未实现）

所有预设使用**相同的人物几何、基础肤色、原始毛孔、镜头和灯光**；只切换 SkinVariationDNA。预设不是特定人群的生理标准，允许每项显式覆盖。

| 预设 | 主观视觉目标 | 默认事件逻辑 |
|---|---|---|
| **Young / Subtle** | 近看有生命气息、远观很干净 | 少量稀疏粉刺、低强度颊部血色、可选轻微胡茬、少量局部皮脂 |
| **Adult / Lived-in** | 日常真实、有轻度生活痕迹 | 轻度 PIE/PIH、少量斑驳和色斑，眼周少量 pigment+vascular，不烘焙泪沟阴影 |
| **Mature / History** | 成熟但不是“病态或脏皮肤” | 稍明显的色素变化、有限血管特征、零星旧凹坑；毛孔变化交还原皮肤工作台处理，不在本层重做 |

可调核心变量：seed、整体强度、血管浓度/红斑/左右差异、色斑数量/半径/边缘/深浅、日晒与历史、T 区皮脂权重、眼下三分量、五类痘史的数量和阶段、毛囊密度/剃须长度/皮下阴影、局部干燥/脱屑。数值范围仅是归一化视觉控制，不标注为医学单位。

## 六、对当前 R02 / R03 候选的明确复盘

**已核实的源码事实：**
- 固定 R02：b97e65823d1103d96c78d82fe351fa2d8802a125。其 paint-effective.js 已有语义头部区域、血色/色素、皮脂/粗糙度与胡须广域遮罩；但活动粉刺、PIE/PIH、旧痘坑还没有完整事件语义分离，胡须底色容易被看成大片连续阴影。BUILD.json 标记 userVisualAccepted=false。
- 现存 R03 候选：848ec5b5a13855184a747a2a90466ab283dcfd6d。在 R02 上增加稀疏事件、诊断控制与粗糙度/微法线关联；BUILD.json 同样标记 userVisualAccepted=false。
- R03 已发布包标记 5 层 1024×1024 RGBA8（未含 mipmap 基础数据约 20 MiB）；R02 标记 3 层（约 12 MiB）。这是**声明的纹理数据预算，不是显卡总占用或手机 FPS 实测**。
- 目前不能把 R03 的“痕迹贴图”当成未来 SkinVariationDNA 已完成的证据：它没有正式七语义层契约、PIE 与 PIH 的独立资产级管理、与毛发系统共享的权威毛囊根点，也没有完成三预设统一视觉验收。
- 当前可见测试图表明默认差异较细微；是否达到“近看有痕迹、正常距离仍自然”必须由目标浏览器和用户的实际视觉复核决定。

**必须改进的设计错误：**
1. 不要使用一个均匀冷色遮罩代替整个眼周四类成因。
2. 不要把蓝灰胡根阴影涂成嘴周单一色块；毛囊场必须可被毛发模块复用。
3. 不要把色素残留映射为默认凹陷。
4. 不要把“7 张图”理解为“7 张整脸全分辨率纹理”，否则显存和采样无谓增加。
5. 不要让三种预设同时改变肤色、光、几何、曝光，再声称比较出了 SkinVariationDNA 的效果。

## 七、未来接入验收的判定

- 原皮肤、SSS、毛孔系统 OFF/ON 后数据不变；SkinVariationDNA 单独启停可恢复。
- 从正面、左右 3/4 和侧面观察，血色、眼周和胡根不出现人工涂色边、穿越嘴唇或移动纹理。
- PIE/PIH 的几何高度恒为零；旧痘坑出现时必须区分真实位移、法线近似与材质暗色。
- 毛茬根点与毛发领域数据一致，剃须程度只改变可见短毛与皮下影，不重新随机决定胡根分布。
- 可逐个开关七类 DNA，六个材质通道在诊断面板可分离检查。
- 同一人物、同一镜头、同一冷暖光的 OFF/ON 对照必须包含三种预设；远看是正常人物，近看有稀疏可信的个体痕迹。
- 不得以“测试通过”“诊断色块可见”“演示页面可开”代替用户视觉通过。
- 不额外复制外部网格、贴图或不明版权素材。引用研究方法要保存原始文献及许可证说明。
