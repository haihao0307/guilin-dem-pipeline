## 使用

打开后默认进入双眼近看。可切换单眼特写、斜侧毛流、侧看离肤、完整面部、完整人物。鼠标拖动旋转，滚轮缩放。

四个预设：自然深棕、清淡细眉、浓眉短睫、柔弯长睫。同灯光对比按钮可以隐藏新增眉睫，查看完全同一原人物，而不是换人或换灯光。眉毛和睫毛可分别开关。

“准备闭眼检查”读取原人物的原生眨眼，之后用 0–100% 滑杆检查闭眼，也可以点“眨一下”。首次准备仍继承原总台的初始化成本，不是即时完成：本轮软件渲染测试约 50.8 秒，实际设备时间未认证。静态眉睫不必等待这一步。再次闭眼不重建毛囊或重新准备完整动作。

高级参数可调密度、眉带宽度、长度、睫毛弯曲、单根粗细、粗糙度，支持保存/载入版本化眉睫配方。右上角可以返回保留的原人物参数界面。这里是同一完整 R06 的独立副本，尚未推广到总平台全部人物或合并主分支。

## 保留来源与实际新增

冻结来源 HUMAN-INTEGRATED-R06 C3，宿主源码 68b26263c5c09ab0aa0782c48e895b23e59fb230，宿主构建 f5017cb7cb9c2024df6a08328564c3f4ae502509。原完整人体、眼球、耳 R06、唇 ET19、皮肤、灯光及旧网页不替换。构建逐段验证宿主原可执行脚本哈希不变。浏览器另外验证换眉睫预设前后原始位置数组、面索引、皮肤材质对象不变。

眉毛按眉头、眉身、眉尾构建连续方向场，逐根曲线有弯曲、长短、粗细、色深差异，左右随机身份不同，根点固定在实际表皮三角形。上下睫毛分别生成，根部参照原皮肤与眼球的可见深度边界，长短、排数和扇向独立。不能明确确定的眼角根点跳过并记录，不能猜测后冒称绑定正确。

每根毛是有锥度的三维曲线分析式条带，不是整眉贴图，也不是圆柱网格堆叠。反射是各向异性表面近似，不是 Disney 完整毛发散射模型。最终近远景采用连续像素覆盖，没有固定距离高低模切换；像素滤波修复没有关闭皮肤深度测试，也没有更换原灯光。

## 实测与证据

5 项数学/数据单元测试通过。固定公网在 Linux Chromium + SwiftShader 下完成 26 项功能检查，保存 18 张真实浏览器截图。包括首屏、真实画布像素 A/B、四预设、参数变化、配方往返/异常拒绝、原人物不变、五个闭眼位置、手机尺寸布局、零页面异常/零着色器错误/零请求失败。手机尺寸只是 390×844 视口，不是手机实机。没有消费级显卡帧率认证。

默认左右合计：1,040 根眉毛、230 根上睫毛、93 根下睫毛，3 个合并绘制批次，新增 32,712 三角形。几何数组/索引占 2,889,560 bytes；这不是总内存，绑定临时数组另占 6,386,352 bytes，还不包含宿主人物、JS 对象和渲染目标。

绑定复用 2,829 个需要的表皮顶点、3,468 个三角形框架。40 次暖态测量中，只有表皮绑定采样的 CPU 中位数约 3.95 ms，95 分位约 5.5 ms。不是整帧耗时或 FPS。原网页冷启动至专项就绪约 18.0 秒，原生眨眼首次准备约 50.8 秒，均为该 CI 环境单次观测。

根部相对绑定三角形的最大设计偏移约 0.012 mm，五个闭眼检查维持此范围。此数值只验证根部贴合，不证明整根毛之间、毛与皮肤之间全部无碰撞。

## 本轮视觉判断与尚未完成

人工检查了最终公网单眼、侧面、半闭/全闭及完整面部截图。细线明显断点已通过实际像素过滤诊断减轻；眉毛有独立弯曲与毛流，睫毛具三维轮廓并跟随眼睑。实际原人物仍有眼睑闭合弧线偏夸张、眼周褶皱和皮肤层次不足的问题；根点跟随正确不能修复宿主眼睑的解剖形态。极近景眉毛仍有梳理较整齐、细节层次不足，尚不应称顶尖影视自然度。

未完成：高质量纤维内部透射/多重散射、真实毛发微阴影、全段碰撞/闭眼轮廓校正、全部 36 人与完整身体动作回归、通用拓扑变化、总状态中心/撤销历史完整接入。默认沿用宿主关闭的阴影设置；不可宣称默认已实现微阴影。

研究与原始来源见 RESEARCH.md。外部老师只用于方法学习，不分发对方人物网格、眉睫资产或受限贴图；继承的原项目资产许可和声明仍适用。

下一轮优先修闭眼方向与睫毛扇向、眉毛区域密度/细毛过渡，以及原眼睑/皮肤的联合视觉质量。不要直接增加毛数来掩盖这些结构问题，也不要替换用户原人物来制造漂亮截图。
