## 真实原因与修改

先重放R05固定构建`63e5dfddf2b5ca0d686651804beeba3333b2f41e`，检查实际中性光、逆光、底色、法线和灰模。异常亮弧没有对应的白色底色条带，也不能通过单纯改唇色或耳部毛孔解决。对下耳甲的表面点追踪后方灯，发现光路被耳内折面或头部挡住；旧着色器仍把这盏灯计入直接反射，产生蓝白色亮弧。

`EarVisibility.mjs`以当前耳廓和原生头部作为遮挡几何，区分表面直射/镜面光与穿耳后的外部通路。透射必须先从耳廓退出，再检查到灯的通路；从头骨退出不算薄耳透光。`ContinuityMaterial.mjs`只在绑定耳廓域内应用这些结果；没有绘制暗条、换头、关闭灯、压平耳甲或修改皮肤底色。

初次候选`8393d49762cf918ce37f81f0a48399dfd1e57956`虽通过功能测试，实际截图仍出现按三角网格分布的硬阴影边缘，因此未作为最终合并候选。最终增加`PenumbraFilter.mjs`，沿当前耳廓相邻边以毫米尺度柔化离散可见性场，避免把光照采样网格印到皮肤上。只过滤光照数据，不过滤毛孔法线，不平滑几何，不越过零权重耳根/头皮。

## 成本和适用边界

默认光路查询63,220个遮挡三角面，4,166个原显示采样顶点，五方向采样共62,490次查询；再按原R04中点关系插值12,320个新增点。曲面光照预滤波涉及16,486个耳廓顶点，零个保护区顶点；sigma为0.65毫米，10轮正权重平均，是有限分辨率近似，不是实测半影或组织散射。

可见性数组3,906,696字节，预滤波临时数组1,953,348字节；这不是总人物GPU/CPU内存，还不含BVH等。该软件浏览器的一次默认光路更新约800毫秒，仅是这一步的样本，不能宣传成交互全帧耗时或稳定帧率。相机移动不重算；耳形、头部遮挡几何或灯光方向变化需要重算。连续动画下的性能优化/Worker迁移仍未完成。

逆光预设位于头部另一侧时，耳内会比R05更暗，因为光路实际被头部挡住。没有通过提高曝光、把整耳染红或绕开遮挡伪造“更透”。R05基于模型外壳的厚度估计和未知处保守策略仍存在；没有实测多层皮肤、完整体积组织散射、任意外部物体遮挡、完整耳道、全局自碰撞或极端参数所有组合认证。当前绑定三盏方向灯；新增灯需显式扩展绑定。

超近景耳屏、上耳轮与耳垂附着仍有偏软/带棱角的原生造型，原头部方向性纹理也未在本次耳部光路修复中改掉。本次交付完成定义是“被遮挡灯引起的耳甲亮弧及离散光场过渡修复”，不是影视级最终耳资产或总人物系统完成。`productionReady:false`和`visualAcceptance:USER_PENDING`据此保留。
