## 打开后检查什么

## 眉毛生长范围的依据与限制

研究详见RESEARCH.md。Goldstein/Katowitz2005对男性眉毛的实测描述了眉毛与瞳孔、眼角及眶上缘的关系；Dagi Glass等2014研究说明外侧眉尾位置存在年龄、性别及人群差异。Gupta等2017临床技术文章的解剖部分区分眉头、较宽密的眉身和收细的眉尾。这里只学习其结构描述，不把美容整形的“理想眉形”当成所有人的自然毛囊边界。
