## 怎么审这一版

1. 用“张口检查”切换“嘴部斜侧”，观察内侧浅色楔面及口角。
2. 在相同动作、镜头和灯光下切换“本次修复 R04 / 修复前 R02”。
3. 查看“内唇表面范围”：紫色对应原人物的连续 oral-skin 语义，牙齿仍属于原生独立材质。
4. 再看自然闭口、说话和噘嘴，区分内侧局部改进与仍保留的外唇填色、细纹、口角折痕。

保存内容包括 R04 状态及原生人物/唇纹校准。镜头和灯光不是新人物档案字段；验证时会明确对齐它们，不能宣称文件保存了未存储的视图。
