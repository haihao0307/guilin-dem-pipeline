## 实际改了什么

原人物已经通过 `oral_skin_ids → l19Oral → l19State.x` 标记口腔内侧皮肤。替换外部皮肤片元时，原生内侧材质职责丢失，产生了浅色内壁。R04 使用这条连续语义，接回现有原生口腔颜色、粗糙度、水膜反射和有界内部可见度近似。15 个原生参数保持同一对象，原有控制仍作用于这块表面。

同姿态版本切换与范围诊断帮助定位修复；顶部、头部和身体三个保存入口统一保存当前完整人物、本版状态及唇纹校准。启动时把同一段同步设置中的中间绘制请求合并，再执行正常原生绘制。

生产版本保留原网格、原形变与 R02 外唇算法。原生材质归因实验支持内侧职责修复；四姿态中 nativeRim 在牙齿避让阶段位移为零，49 对唇缘采样各自独立，因此没有凭这两种假设修改几何。剩余的口角形变原因仍需要阶段渲染对应证据。
