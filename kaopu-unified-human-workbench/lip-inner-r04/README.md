## 诊断依据

原生系统已保留口腔回折皮肤的语义，经过 `l19Oral` 和显示细分进入 `l19State.x`。后加的程序化皮肤按皮肤类型和覆盖域分配材质，没有继续使用这一语义保留独立内唇材质。这个源码断点值得实测；不能直接推断任意浅色截图像素都属于内唇，也不能用整个 cavity 的顶点数代替内唇计数。

材质实验只把当前显示几何中三个顶点均为皮肤且 oral≥0.999 的三角形暂时交还已有原生材质。它保留全部顶点数据、完整有向三角集合、动作、相机和灯光；结束时恢复原索引对象及材质分组。混合边界仍使用原路径。这是归因实验，不是最终生产方案。

几何采样依次记录细分、原生唇形、局部动作、闭唇约束、牙齿包络、细沟和最终显示。使用同一批原生顶点及邻边，不把多个不同阶段或不同顶点误作前后对比。
