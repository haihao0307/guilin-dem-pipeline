## 修复的理由

R04 说话画面中的上唇内缘有分段的细条。去掉程序凹凸后，细条仍在；只显示底色时，小台阶仍然可见。移除局部动作会明显改变细条，但也失去原有抬唇、下压表达，因此不能把关闭动作作为修复。

对应几何投影显示，同一块上唇内返面的采样同时出现上下唇方向标签。R05 从固定张口参考建立连续的局部跟随关系，在原求解器完成局部动作和闭合阶段时，补上归属改变所对应的方向差值。原动作、闭合、牙齿避让、法线及细节流程继续执行。

这是一项有边界的几何修复。投影三角在抗锯齿边缘存在不确定性，连续权重也是工程构造；没有把它称为测量得到的组织解剖或完整生物力学。

## 工作台行为

- 在同一人物、动作、镜头和灯光下切换 R05 / R04。
- 保留自然闭口、张口、说话和噘嘴预设，增加动作进度以检查中间形态。
- 自定义动作会停用进度滑块，避免用旧预设覆盖当前编辑。
- 人物或唇形改变使旧跟随参考失效时，返回原生行为；重新启用 R05 时根据当前人物建立参考。
- 顶部、头部和身体保存入口统一保存完整人物。半程动作存档保留动作种类、进度及 R05 状态。

R04 原始页面字节完整保留，本版只追加原生求解器修正和操作层；没有引入替代网格、生成图片或新材质。

## 如何自审核

| 问题 | 约束和证据 |
|---|---|
| 修复是否针对原因 | 凹凸、底色、局部动作和闭合的消融图，与原生阶段及可见几何对应 |
| 是否靠减弱表情换取好看 | 保留原动作流程和系数，并核对说话实际几何及像素仍区别于单纯张口；视觉幅度另行审核 |
| 是否改变了对照条件 | 人物、拓扑、材质、实际编译 shader、镜头和灯光保持一致 |
| 是否可退回旧版 | 独立打开固定 R04，核对它与 R05 关闭状态的实际画面 |
| 是否能继续制作 | 实际点击三个保存入口，新浏览器环境恢复下载档案，核对完整状态、画面和半程动作控制 |
| 是否已经改善整体质感 | 独立图审评判局部收益；外唇蜡感、口角牵拉和口腔细节仍单独记录 |
