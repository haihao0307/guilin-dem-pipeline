# Studied knowledge versus actual integration

Review date 2026-10-10. This is an explicit ledger, not a claim that all supplied teachers have been completely learned or reproduced. Existing R01 sources and licenses remain documented in `../RESEARCH.md`.

| Primary source | Useful lesson | Actual state in our system |
|---|---|---|
| [Pixar / Leif Pedersen, reviewed by Christophe Hery](https://renderman.pixar.com/photorealistic-head) | Separate surface frequencies, roughness, layered reflectance and scattering; review several lights | R01 filtering implemented; R02 region-specific roughness/film candidate. PR197 separately explores two lobes. No new RenderMan asset/runtime imported |
| [Epic Digital Humans](https://dev.epicgames.com/documentation/en-us/unreal-engine/digital-humans?application_version=4.27) | Diffuse, specular, scatter, micro/meso normals are separate; unresolved normal detail should affect roughness | R01 pore filtering implemented. R02 lip-groove filtering implemented. Full normal-to-roughness/animated wrinkle maps are not implemented here |
| [Kobayashi and Tagami 2004 original study, abstract](https://pubmed.ncbi.nlm.nih.gov/15030342/) | Lip surface hydration/barrier differs from cheek in the studied cohort; a single face-wide hydration assumption is inadequate | Independent lip surface control and border film fade. This paper supplies no GGX coefficient; all rendering coefficients remain artistic, not measured physiology. No image or paper reproduction |
| [Lee and Hwang 2002 original regional skin-thickness study, abstract](https://pubmed.ncbi.nlm.nih.gov/12375070/) | Thickness differs substantially by anatomical region | Preserve distinct native periorbital region. No thickness values are inferred from region weight, and no fake red backlighting is labelled physical transmission |
| [Khronos GLSL ES 3.00](https://registry.khronos.org/OpenGL/specs/es/3.0/GLSL_ES_Specification_3.00.pdf) and [PBRT texture filtering](https://pbr-book.org/4ed/Textures_and_Materials/Image_Texture) | Compute derivatives in valid continuous domains; filter before point-sampled detail aliases | R01 array mip isolation and continuous gradients; R02 unconditional lip-phase derivatives and analytic footprint attenuation |
| [Unity Digital Human](https://github.com/Unity-Technologies/com.unity.demoteam.digital-human) | Skin attachments/tension/deformation are data-backed systems | Studied source interfaces; no Unity Companion code ported to unrelated WebGL. No full tension solver |
| [USC Digital Emily 2](https://vgl.ict.usc.edu/Data/DigitalEmily2/) | Separate diffuse/specular/scatter reference channels and microgeometry | Validation discipline adopted. No restricted reference imagery/model/textures copied |
| [Disney graph-based micro-wrinkles](https://studios.disneyresearch.com/2023/07/03/graph-based-synthesis-for-skin-micro-wrinkles/) and [dynamic wrinkles](https://studios.disneyresearch.com/2024/04/26/fast-dynamic-facial-wrinkles/) | Pores and wrinkles have structured directionality; deformation changes width/depth | Methods studied, not a complete optimizer/stress solver. PR197 separately implements an authored fold profile, not this paper's full method |
| [Separable SSS](https://github.com/iryoku/separable-sss/blob/master/SeparableSSS.h) | Diffusion blur and thickness-dependent transmittance are separate | Existing licensed host diffusion retained. True thickness-aware light transport remains unimplemented |

The nasal local-film rule is an explicit authoring extension of the existing native T-zone oil semantics, not an empirical sebum map. The 2025 ultrasound page encountered an access challenge; only its search summary was available and it is not used as a source for numerical coefficients.

No material can substitute for eye/lip geometry, correct scale, validated skin data and lighting. Next integration gate: inspect regional masks on extreme user-created face shapes, agree ownership with PR197, combine with stabilized PR196 eye optics, then rerun pixel rollback and multi-light closeups. Dynamic animation and true scattering are separate remaining deliverables.
