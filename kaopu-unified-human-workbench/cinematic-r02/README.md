# ET21 Skin Fold R02 — 真实褶皱与肤质工作台

冻结父版：`ccf5a1ed9ddde8803e292f1e62d777b141ff52d8 / cinematic-r01/preview.html`。本目录独立新增，父版、原人物、眼球、嘴唇、身体、绑定与动作源码均不改。`BUILD.json` 记录源码提交、构建输入摘要及页面 SHA-256。用户视觉验收与代码测试是两件事。

## 本次结构

`FoldKernel.mjs` 生成软卷折剖面、浅附着槽、面内收缩和颊部松垂。`FoldSurface.mjs` 以原生 68 个模板地标为锚，在原显示网格上使用固定-rest 自适应细分。不是导入另一张老人头，也没有用皱纹位移贴图；位置缓冲和法线真正变化。色彩、毛孔和雀斑不承担褶皱深度。

五项主要控制是松弛、局部聚拢、拉紧展开、柔软宽度和颊部下垂；五个区域分别为额头、眼下、外眼角、鼻唇颊部和下颊。上眼睑开口、眼球、唇红、耳朵和原生身体顶点不加入褶皱形变。显示网格新增顶点预算为 42,000。实际位移与新增数量由运行报告记录，不把参数毫米当作医学测量。

灰模、纯几何法线与线框三种检查路径直接绕过整个皮肤着色链；在同一机位关闭/恢复褶皱，可以核查深度并非贴图假象。默认材质保留原眼唇着色，只接入独立的光学皮肤层。

`CineSkin.mjs` 为非皱纹色素建立独立缓存，明确清零旧身份贴图的六个皱纹通道；旧纹理和人物档案不被覆盖。色素预设包括自然细皮、熟龄、松皮、鼻颊雀斑、痣与痘印和清晰底妆。痘印默认是平面色素，不等同痘坑。痣的颜色与有限几何隆起分别控制。底妆改变覆盖和微表面粗糙度，不对最终成像进行模糊。

为减少原颊部的碎面感，`SurfaceFairing.mjs` 在增加褶皱之前，对派生颊部表面做最多 0.32 mm 的有界几何整理；不改原生人物位置、眼口开口与身体。静态基面与法线被缓存，拖动褶皱参数不重复细分和邻接整理。

`CineRig.mjs` 从同一冻结提交的 `kaopu-hair-workbench/qa/gnm-study/src/app.js` 复用早期冷暖光方向和 #ffb473 / #7caaff 配色理念；不是复制当前高开销的面积灯。默认中性配方，两个方向光加环境光、无投影阴影、单次成像。冷暖配方保留原方向，把原色与线性白光混合，避免直接照皮肤时过橙。提供中性肤色、掠射和柔和人像配方；主光投影与旧版 RGB 多通道扩散是明示开销的可选项。颜色光会影响对肤色的判断，检查雀斑和底妆应同时看中性光。

褶皱滑块只重算派生表面，不重新运行全部原生人物推理。已有小幅待机差分可继续使用；真正更换人物形体仍按旧架构重新校准。这个实时近似不是肌肉应力驱动的完整表情褶皱求解。默认进入暂停的外观检查状态，保留原待机播放按钮。

## 证据与限制

`probe.cjs` 复测了原 ET20 固定页面：1280×900、DPR1 的 Chromium 软件渲染环境；固定机位、暂停待机后，扩散开启每帧6次绘制、901,278个累计提交三角形；关闭扩散后1次绘制、300,424个三角形。单次抽样的 CPU/GPU 时间不可当作用户电脑帧率，且场景面积改变会影响耗时。

第一轮源码 b4cd673e0f6b130418fe09381025d14dd5d44278 的12组浏览器测试通过，Actions 38340433657，artifact 11786644451。真实几何灰模对照中76,807个显示顶点变化，最大约1.55mm，身体零变化；显示192,459顶点、384,424三角形。默认单次成像1次绘制；可选扩散为6次、1,153,278个累计三角形。此后又根据真实截图加入颊部整理、降低冷暖光色偏和基面缓存，必须重新验收其最终构建，不能直接把第一轮截图当最终版。

`test.cjs` 检查卷折/浅槽、收缩与拉伸、非法参数和原子拒绝。`verify.cjs` 在真实 Chromium WebGL 页面检查预设像素响应、无纹理灰模、真实顶点位移、原身体不变量、灯光、绘制次数、滑块、保存、待机与手机尺寸视口。`public.cjs` 另外核查固定公网字节摘要、真实公网渲染、灰模对照、档案恢复和重复交互。手机尺寸视口不是手机实机。

仍然不是有限元皮肤、全肌肉系统、离线路径追踪或随机游走体积散射。原生模型头形、眉睫毛缺失、眼睑边界和嘴角质量仍影响最终写实感；本次不擅自更换人物来隐藏这些限制。原在线原生资产和既有待机缓存开销仍存在。性能的下一步瓶颈需要以实际设备和镜头分辨率核验，不承诺任意设备60 FPS。
