## 真实修复

唇色不是只换一个红色数值。旧耳部版仍接 ET17 唇材质，嘴角缺少横向截止，且面部色斑/胡茬/贴图残差还会覆盖唇红。本版补齐嘴角与退化厚度限制，排除这些面部叠层，保留原色值与线性颜色链，加入克制的上下唇深浅、局部色差与边缘过渡，并减轻局部扩散造成的唇纹糊化。未将测试过的色值响应称为实测人体反射率。

耳形修复了头部坐标基准：当前原生模型的 Z-up 坐标要按 `[x,z,-y]` 转为显示坐标，参考表面本来就是 Y-up，不再混用二者。加强连续对耳轮分叉、耳甲艇/腔层次、耳屏与入口凹陷，调整耳垂下缘。Y形脊线使用平滑最大值而不是把三条脊线叠成结节。局部细分从两级改为一级并减少平滑，保留形面，同时减少显示顶点。

耳部独立使用毫米尺度微表面，不再套面颊 XY 细节。耳甲、耳轮、耳垂分别调节粗糙度/油光/色差；细毛孔与有限长度细褶有视距过滤。降低耳部屏幕扩散权重；薄区逆光仍是受限近似。表皮保持不透明，没有新增透明壳体或耳道黑色堵片。
