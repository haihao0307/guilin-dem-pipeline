本目录是原完整平台的独立皮肤测试入口，不替换 `kaopu-unified-human-workbench/index.html`。显示的仍是原三教师共同参数人体，不是 R02 扫描头或新的替身模型。

- 原平台源码基线：`c713eb1353cbf75ca57e1d9a80c6a9d0222d55ee`。

- `SkinLayer.mjs`：仅在本入口的浏览器上下文包装 CommonViewer 的显示和释放。原 CommonViewer 文件不改写。

- `build.cjs`：校验原模块 SHA 后组装同平台入口及固定版预览。
- `qa.cjs`：原平台与皮肤版实际运行对照，比较默认状态及代表性参数的几何数组、归档和 GPU 像素。

原 `full/ui/browser-app.mjs`、`full/ui/Viewer.mjs`、全部教师模块、参数档案、骨架和颈部算法仍由原平台拥有。本分支不是三教师整合主线的新权威，不把旧原模块覆盖到主线。

## 材质映射

原显示网格没有 UV。直接使用扫描头 UV 会把眉毛、嘴唇和胡须放错位置。因此这一版只提取原扫描的无毛皮肤片段，用固定参考表面坐标进行三向投影。没有将肖像图片贴成三维人物。

材质参考坐标对应原模型自己的固定顶点 ID。当前模型移动或形变时，微表面方向由变形后的导数转换。材质不会写入位置、索引或骨骼数组。加载时检查共同拓扑和顶点数量。

原共同网格为 25417 顶点、50624 三角面。外层连通表面的20062个顶点为皮肤候选；其余5355个眼部、牙齿、舌等内部顶点排除，头部再按 GNM 原生 material_id 校核。保留原眼部白模，不擅自制造虹膜或改眼球。

## 继承的 R02 渲染

颜色纹理采用 sRGB，微表面数据保持线性；真实扫描的中频和高频法线分别参与微表面扰动。物理材质保留粗糙度和表层油光。漫反射、镜面和颜色分开渲染，使用原 R02 的25采样 RGB 扩散核和深度/皮肤覆盖保护，防止把镜面高光一起模糊。薄部透光读取原主灯方向的几何深度差，仍是实时近似。

原平台灯光、摄像机和背景保留。皮肤关闭后、打开线框或颈部检查时使用原白模显示，不更改参数来源。未增加第二个人体网格，没有皮肤几何位移或新毛发。

## 使用

打开入口后点击“载入共同模型”。教师资源和皮肤数据就绪后自动显示皮肤。下方“原白模对照”只切换显示，不重建人体。“材质参数”提供粗糙度、油光、扫描细节、色素、散射、扩散尺度和薄部透光控制。原三教师的参数面板保留。

## 当前边界与成本

使用512×512的原扫描无毛片段处理循环接缝，不是每个身体部位独立绘制的全身4K纹理。65毫米覆盖尺度是估计值，未作生物测量标定。眉毛、胡须、痘印、唇色、掌纹、足纹与眼睛细化不在本轮范围内。

屏幕空间皮下散射和额外渲染目标有显存及像素开销；并不承诺所有设备60FPS。教师权重的首次加载沿用原平台，不因材质接入消除。本轮保留原桌面布局；窄屏或软件渲染测试不能称为手机实机和用户显卡性能验收。

## 重建

`python prepare.py <原共同人体浏览器快照.json> assets`。

`node build.cjs --source-only` 生成调试入口；提交完整材质资产后，以 `ASSET_COMMIT=<40位固定提交> node build.cjs` 生成公开预览。原教师模块的资产 URL 固定到原基线，皮肤数据固定到材质资产提交。使用 `git add -f` 时只限定本目录的生成纹理和坐标数据，核对暂存内容摘要，不全仓库强制加入忽略文件。
