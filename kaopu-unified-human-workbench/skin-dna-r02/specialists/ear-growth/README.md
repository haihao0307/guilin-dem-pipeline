## 新的形态控制

每耳 36 项：29 项形态、7 项表面。左右同步或分别调整。三个区域生长量分别为软骨分区、耳甲腔和耳垂，连到卷轮、上部轮廓、对耳轮上下脚、三角窝、舟状窝、耳甲艇/腔、耳屏、对耳屏、切迹、附着与游离耳垂。耳垂面积/长度预算独立，不由软骨缩放代替。

提供 8 种人工编排的结构预设，以及可复现种子；同一对耳朵共享主体形态，只增加小幅双侧差异。该模型是依据外部可见解剖关系编写的程序化表型生成器，**不是生物发育过程、遗传推断或经人群训练的统计模型**。增加参数不自动等于增加解剖准确度。

## 实现与边界

`EarParameters` 管参数、预设与种子；`EarMath` 生成相关联的区域变形；`EarSurface` 对原表面局部细分并以头部参考系施加；`EarGuard` 对单侧三角面方向、面积/边长比例与采样前后片间距做回退；`EarState` 负责严格档案校验和旧版字段迁移；`EarMaterial` 处理静止参考坐标上的微表面、粗糙度、油光与逆光近似；`EarUI` 保留视角、原版对照、撤销/重做、完整人物保存恢复。

耳形几何修改直接更新现有耳部显示层，不为每次拖动重新计算身体；材质滑块仅刷新着色参数。原人物姿势改变时仍通过原 viewer 更新，不能改骨长、权重或绑定层级。观察模式可折叠总台入口，展开后原人物预设和其他模块仍可使用。

局部约束可能主动缩减某些组合，界面显示实际采用比例。它不是全局自碰撞检测，不能保证任意组合绝不穿插；尤其原模型薄区、极端头形与小年龄体型仍须视觉复核。没有完整耳道、实体软骨有限元、软组织接触或实测多层散射。近景质量尚需用户验收，不宣称影视级无瑕。

旧 schema @1 可读入，保留已存数值并补齐新字段；因生成器改变，不保证与旧渲染逐像素相同。旧网页依旧是准确的历史视觉基线。
