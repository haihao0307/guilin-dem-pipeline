## 自然规律与已落地方法

固定规范见同目录 `NATURAL_SKIN_RULES.md`（NSR-01，七项规则）。规则逐项标注来源、已实施内容、未实施内容和拒绝条件，不能把论文名称当作实现证明。

本版肤色不再使用R01自拟RGB吸收染色公式。构建时实际执行Meta BioSkin官方固定版本 `6cca1a76ac3f53077579c4249983ec91d855801d` 的光谱解码器与颜色转换，形成33×17线性RGB查找表；浏览器只查表，不逐像素运行神经网络。官方OpenCV输出BGR已明确重排成RGB，许可和权重/源码校验见 `BIOSKIN-LICENSE.txt` 与 `BIOSKIN_PROOF.json`。

1024个独立参数点的查表验证：最大线性通道绝对误差0.003508871078843845，平均0.00019062320726731888。这个数字验证查表接近官方模型输出，不是皮肤自然度或医学精确度评分。当前仅为五维模型的二维固定截面，不是完整五维生理编辑、个体医学测量或光谱体积路径追踪。

删除本版新增的随机噪声刻纹、随机雀斑岛、年龄云斑；继承的附加几何折纹默认强度为零。切换六套肤质不改变显示几何。原生微表面和曲面毛孔候选仍是继承的近似，区域光泽系数仍未经过真实皮肤扫描标定，不能说这些内容都由BioSkin学习获得。

因此两个名字也纠正为“浅色微红”和“干燥柔光”，不再把没有生成的雀斑或没有实现的几何衰老当功能。全部六套为：细腻中性、浅色微红、暖色日晒、深色缎面、干燥柔光、润泽混合。

NSR-01采用测量反射分层、Disney方向相关应变皱纹及真实皮肤扫描风格等知识，但本轮没有移植Disney完整应变皱纹生成或扫描风格迁移。程序和几何可以承载自然规律；被拒绝的是没有参考尺度、区域和因果约束的随意造形，而不是把所有几何计算一概排除。可见轮廓改变和皮肤叠压最终仍需实际几何/接触，不能靠法线图冒充。
