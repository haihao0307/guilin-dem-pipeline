## 一、先区分观察事实与原因

截图直接可见：下颌到脖子出现锯齿形色调/反射分界；面部有毛孔与层次，颈部和肩胸明显平滑；耳根有暗边；眼周、鼻翼、耳部色差不足。截图本身不能证明这些全部是几何错误，也不能由两张照明图像倒推出真实组织厚度、色素或血液浓度。

冻结公网浏览器探针：Actions 38543147818。同一个原生 mesh 使用 fRest、csRest、csRegion、csExtra、csType、eTissue 等属性。fRest 在身体顶点上全为零，只有头部有效；csRest 则覆盖全身。头部参考坐标与全身参考坐标相差 canonical.headTransform.translation 转换后的 [x,z,-y]。因此直接将旧头部材质扩到身体而不改坐标，会在身体得到不正确的常量纹理。

旧代码还用“整个三角形三点均满足头部高度/皮肤语义”区分新头材质和旧身材质。C2 在头材质内部做的高度混合，并没有取消跨三角形的材质分组边界。R02 将所有原生皮肤三角形分为同一个程序材质组，非皮肤仍留在原材质；不删三角形、不叠加第二张皮、不改变规范索引或原始顶点。程序参考坐标改为全身连续 csRest 减去从人物自身读取的头部坐标偏移。

## 二、生物学与渲染证据（原始研究 / 官方技术资料）

1. Donner & Jensen, A Spectral BSSRDF for Shading Human Skin, 2006。分层皮肤、黑色素、血红蛋白和表面油脂影响不是同一项“红色”。研究入口：https://cseweb.ucsd.edu/~henrik/papers/skin_bssrdf/ 。Eurographics 记录：https://diglib.eg.org/items/f7be9101-7b4c-4a57-ba69-eedd90acd23d 。
2. Weyrich et al., Analysis of Human Faces using a Measurement-Based Skin Reflectance Model, 2006。测量分离反射特性、漫反射底色与散射；不能把照片阴影烘焙成通用肤色规则。研究团队入口：https://visualcomputing.ist.ac.at/publications/2006/AnalysisOfHumanFaces/ 。
3. NVIDIA GPU Gems 3, Chapter 14, Advanced Techniques for Realistic Real-Time Skin Rendering。薄耳透光、线性色彩、局部粗糙度和表面/皮下响应的分离：https://developer.nvidia.com/gpugems/gpugems3/part-iii-rendering/chapter-14-advanced-techniques-realistic-real-time-skin 。
4. 原始眼下色差观测研究（PMC4560538）：https://pmc.ncbi.nlm.nih.gov/articles/PMC4560538/ 。眼下外观与色素和血液光学特性有关；不能推广为“所有下眼睑都应该一圈鲜红”。
5. 原始身体区域生物物理测量（PMC3317612）：https://pmc.ncbi.nlm.nih.gov/articles/PMC3317612/ 。不同部位的皮脂、色素、红斑等指标存在差异；这些测量不构成可直接复制到任意个体的固定 RGB 表。

以上用于设计可解释的外观参数；本版没有把外观滑块标记为真实血红蛋白浓度、医学诊断或临床厚度。本次没有下载上述作品的模型、贴图、测量数据集或代码作为新皮肤资源。

## 三、逐区观察与程序规则

| 区域 | 本轮记录与实现 | 避免的错误 / 边界 |
|---|---|---|
| 额头、眉弓、太阳穴 | 额头很弱的暖黄倾向；太阳穴弱冷色；继续使用原头皮肤油脂/粗糙度体系 | 不把额头统一涂黄；眉弓真实轮廓仍由原几何决定 |
| 下睑、内眼角 | 使用原人物头部坐标的窄而柔和血色域；降低旧版广泛暗圈；内眼角独立小范围过渡 | 不制作均匀红眼圈、不把泪沟阴影写入底色；没有新建泪液几何 |
| 鼻尖、鼻翼 | 鼻翼与鼻尖分开的弱暖血色；保留 T 区油脂和较显著毛孔差别 | 不将整个鼻梁染红；鼻孔体积仍是原几何 |
| 面颊 | 低频、低幅、相关而非随机彩噪的暖色与色素变化 | 不使用腮红圆斑，不把高频黑点当全部毛孔 |
| 嘴唇及边界 | 保留获认可的 ET19 唇形和 C4 湿润/唇纹；小幅上下唇层次 | 不覆盖旧唇几何，不做整齐红色边框 |
| 口周、下巴、下颌 | 仅提供默认很弱的毛根底色参数；头颈由同一材质连续覆盖 | 毛根底色不等于真正胡须，个体不必存在浓胡青；不将阴影染进肤色 |
| 耳轮、耳垂、耳甲 | 局部而非整耳统一血色；透光另由光方向、原生几何厚度/可信度及原生出射光遮挡场控制 | 不是固定发光材质；耳根暗边可能仍受原几何/遮挡影响，不能承诺着色修复全部 |
| 颈前、颈侧、锁骨 | 从头部平滑延伸低频肤色和微纹理；可调两条极浅、连续的颈部细褶 | 本轮细褶是外观高度场，不宣称动态皮肤力学或自动颈部解剖重塑 |
| 胸、背、腹、四肢 | 同一个稳定全身坐标、同一皮肤函数；降低身体毛孔半径、增加间距；低频层次连续变化 | 不把脸部毛孔等比例铺遍全身；远处按像素足迹连续过滤，不切换整个人高低模 |
| 肘、膝等关节 | 利用原平台干燥区域属性，增加可调弱色素/粗糙度差别 | 不无条件把关节涂黑；形态及弯曲褶皱仍依赖原人物 |
| 手掌、足底 | 利用掌部语义和足底坐标抑制毛囊孔，改为细浅脊纹倾向，弱色调差异 | 不是指纹重建，不是高精度手掌扫描 |

## 四、耳透光的实际计算边界

复用已存在的 eTissue.x（几何路径毫米）、eTissue.y（路径可信度）、R06 vE6Deep（耳部出射路径与头部遮挡）及当前 uE6WorldDirections。随背光侧的法线点积、路径长度和 RGB 有效衰减变化。路径差或方向不匹配不增加透光。它比固定红色贴片更受几何与灯光约束，但仍不是多层组织体积光输运或光谱测量拟合，不能宣称真实皮下血管模拟。

## 五、现实约束与成本

整个身体沿用原人物的规范几何；低分辨率身体轮廓、肩胸折面、颈部轮廓、眼角/鼻孔/耳根结构，不能由增加表面纹理自动修成扫描质量。需要明确区分“皮肤延伸完成”和“所有解剖结构达到摄影真实”。

全身材质覆盖增加片元计算面积；毛孔使用连续像素足迹过滤，不新增每个毛孔的几何物体，不声称零开销。原平台加载的模型/眼球资产、初始化与浏览器 GPU 兼容性仍有成本。软件 Chromium/SwiftShader 的运行和截图不能证明用户 Windows 显卡 60fps，也不能冒充真实手机、Safari 或 Vision Pro 验收。
