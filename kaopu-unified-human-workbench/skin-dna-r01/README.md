## What is available

The top-right panel switches six appearances on the same retained person and camera: 01 细腻中性 / 02 浅色雀斑 / 03 暖色日晒 / 04 深色缎面 / 05 成熟偏干 / 06 润泽混合. These are optical/material recipes, not six different heads and not a complete geometric age transformation.

SkinProfile.mjs validates a versioned identity recipe independently from temporary flush, sweat and dryness. CharacterSkin.mjs derives a stable recipe from an application character ID; skinDNA.forCharacter(id, style) applies it. The 36-record numerical test is NOT a visual certification of all 36 native people.

SkinMaterial.mjs separates base pigmentation/vascular colour variation from regional oil, roughness, seed-selected surface-pore candidates and bounded inherited micro-normal detail. It does not paint pores as dark dots or load an external replacement head. Its absorption model is a bounded RGB artistic surrogate, not measured tissue concentrations, a medical model or spectral volumetric transport. The mature recipe's fine relief is shading-level; this layer does not introduce new wrinkle geometry or biomechanical tissue ageing.

The identity profile and temporary state are independently serializable. The top panel offers recipe save/load, deterministic seed, original/new surface comparison under the same lights, face/cheek/full-person views, and albedo/roughness/normal/pigment diagnostics. The full-person archive contains the skin, lip and ear records. The public test proves skin-recipe round-trip and presence of the full-person sections; do not expand that into an unperformed exhaustive full-person import/render certification.

EB1 has its own non-persistent/non-broadcast store here. Switching the skin does not reauthor another workbench's lighting settings. Original R04 lighting is separately selectable. Default is the fast single-pass shallow approximation; optional static face diffusion separates diffuse from specular and is significantly more expensive. It is face-only, screen-space and not full-body volumetric SSS.

## Visual review status

Functional first review candidate: available. User visual acceptance: pending. Film-closeup / production-ready acceptance: NOT established.

The six recipes visibly differ beyond a single base-colour slider. However, outdoor and mature recipes still have conspicuous larger-scale mottling; the mature appearance can read as patchy rather than naturally aged. In the cheek close-up, some inherited directional marks and freckle-edge regularity remain visible. The existing lip/eyelid/ear geometry and lip colour boundary still contribute synthetic appearance. More colour variation alone does not establish biological realism, and neither extra noise nor more shine is a substitute for it.

Keep these limitations visible. Do not promote this R01 as the completed photorealistic reusable skin system or silently integrate it into the original character platform. This page is the user's requested first independent set of skins to inspect before choosing a later refinement/integration direction.
