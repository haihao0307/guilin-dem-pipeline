## 本轮可以查看什么

左侧「00 接触交互 R03」：下蹲→起身、下蹲并保持、从蹲姿起身、地面拾取→起身持物、把物品递给另一人。前3项是同一动作的整体/分段检查，不称3份新动捕。原来的「握小球」「抱箱」两个入口改成当前手掌表面校准版本；总目录从57到62可播放入口。连续走、连续跑、拳击和旧条目保留，旧R2尚未迁移的类别仍明确标记。

右侧「显示掌心 / 指面接触点」显示当前手面测量位置；点可能被物体遮挡，诊断标记以穿透显示，不能把标记本身当作实体皮肤。选择左右手近看和慢放可检查包覆。递交动作有真实第二位同版本R04人物、独立骨骼状态以及同一个物体。取消「接收者准备好」时保持原持有，不按计时强行松手。头部/身体仍是本轮冻结的完整R04，非旧简化演员。

## 掌面定位的实际变化

旧手部控制主要用腕点与固定偏移，原握球校准仅有部分顶点的物体距离与拇指/食指范围；它不能证明掌面/指腹贴合。R03从当前原生手部三角面射线求出掌心和远端指面锚点，记录三角顶点及重心坐标，完整原生蒙皮权重用于评估手面。每种手/物体组合只拟合一次，逐帧播放不重造人物。

手指与物体按接触/穿入代价共同校准；接近、闭合、持有、松开和撤回分阶段处理。候选2虽通过功能检查，实际网页近景却有严重折腕，未作最终推荐。最终把前臂旋转、肘部方向与手腕方向一起处理，保留原骨长；另修正下蹲时自由手姿态及地面/箱体观察镜头。最新10张公网WebGL图已逐张查看，不是生成图片。

原小球与箱子尺寸不变：当前人物小球直径约5.403cm，箱体约24.366×16.951×19.069cm。地面拾取另用直径约7.564cm的新球体示例，不冒充已验证任意小物品拾取。抬箱当前是台面接近→抓住→抬起→持有，不是新增负重行走或完整搬运路线。

## 不能混淆的接触量

掌心中央通常是凹面；掌心中央距离、最近掌面支撑区距离、各指远端中心距离、选定指面接触点距离分别报告。选定指面点接近物体不代表所有指尖/拇指腹中心都贴合，更不等于真实握力。

独立同一R04数值夹具，旧控制器3秒稳定持有对比新控制器4秒稳定持有：小球掌心中央间隙约26.51→2.11mm，最近掌面区11.32→0.50mm；箱体左掌中央49.62→16.13mm，最近掌面区13.45→3.31mm。箱子仍不是整片掌面压平贴住。新小球拇指远端中心仍约12.97mm离物体，新箱约8.36mm；与物体更近的是另一些指面区域，不把它称为完美指腹接触。

该比较使用冻结原R02控制器与最终R03源码，当前R04夹具gzip摘要 d9ed00ecd841467fa97b37c26c48ec7adda80406b13d36b32d1a37ec97af1d74。最终 SurfaceContact.mjs SHA256 30a6cd8afccbdbfe773462adc2041ee8a2f0635f4f1dc94ef223768b21748d21；InteractionRig.mjs SHA256 c85c52e5a2528725a4ec049500800b4e37f6ae4b3cdbf4a0479881770ca27b80。比较不是原动作所有帧的对照视频，也不是手部临床测量。

## 真实验证范围

候选22项、公网29项检查通过，页面/着色器错误零。新7个交互入口分别以左右手配置检查：按60Hz缓存的整段手面顶点SDF、稳定接触点、阶段转换与抽样骨长；原始人物坐标、拓扑、存档和同一主表皮/材质保持。真实按钮检查含接触点、接收者状态、暂停、慢放、逐帧及旧走跑/握拳回归。手机390×844仅DOM布局和控件检查，非手机实际GPU。

新交互整段已采样手部顶点对物体最大穿入约0.336mm；稳定持有的选定指面点间隙上限约2.134mm，最近掌面区约3.313mm。手掌其他凹面与远端中心可能距离更大，如上。此范围不是所有三角面/手指自碰撞/全身接触/任意体型组合的无穿模证明。当前仅平地、固定人物与指定球/箱尺寸。

公网首次就绪28.384秒，第一次交互准备含各手/物体拟合约5.039秒；已完成拟合后，新动作缓存准备约92–1302毫秒，人物形体重算0次。未消除原模型约84MB资产、面部按需基底和双人完整绘制成本。短时软件渲染采样只有1个间隔，约2344.6毫秒，FPS字段为空，不能计算可靠帧率或声称稳定60FPS。该环境是Chromium/SwiftShader，不是用户真实显卡；但现有证据同样不能作为流畅验收通过。报告见 acceptance/public/qa.json，原始稀少采样保留。

## 参考与实现边界

CMU官方有限原始记录：22_14 alternating squats；115_06 knee-bending box pickup；22_13/23_13 paired passing。原ASF/AMC、官方标签及SHA256收据在 references/。下蹲使用22_14实际下降/上升高度时序，并自行完成固定骨长/双脚目标/接触编排，明确不是完整真人骨骼动作重定向。拾箱/递交记录用于姿态与阶段参考。CMU手指并未实测，本版手指为当前手面校准，不伪称真人手指捕捉。

ContactOpt（https://arxiv.org/abs/2104.07267）参考接触感知优化思想；GRAB（https://grab.is.tue.mpg.de/）参考全身/手/物体协同。没有导入其外部人物网格、训练数据或模型权重，也不宣称复现其学习模型。

当前使用接触约束运动学：没有质量、摩擦、肌肉力、软组织挤压或衣物物理。交接门槛针对缓存中的已校准场景与明确接收状态，不是任意实时移动物体的自主抓取规划。更换人物比例、物品尺寸/形状、地形或接收者距离必须重新求解并验证；不能把这几个成功示例直接视作通用能力。

The data used in this project was obtained from mocap.cs.cmu.edu. The database was created with funding from NSF EIA-0196217.
