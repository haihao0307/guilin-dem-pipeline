# 单人基础动作 R04

本版从动作 R03 的冻结源码 `fde66f8246cc49f604e5deb24fcc4128d8c9772b` 接续，优先检查同一完整 R04 人物的单人动作。旧 R01/R02/R03、原人物和动作源保持原样。双人交互不进入本版目录。

## 可操作内容

14 个练习入口：自然站立、轻微呼吸姿态、连续行走、连续跑步、走停、跑停、走步左转/右转 90°、下蹲起身、下蹲保持、从蹲姿起身、小跳落地、挥手、伸展。分段练习不算新的独立动捕。

支持暂停、慢放、逐帧、拖动时间轴、重播、原地/前进观察、固定视角和轨道镜头。视野按整段动作测量，包含抬手与跳跃最高点。本地 FBX 导入只读取文件中的骨架动画，外部人物不进入生产场景，文件不会上传。

## 来源边界

默认走跑、跳跃、挥手及伸展沿用已有 CMU 采集。蹲起沿用 CMU22_14 的高度时序并编排固定骨长姿态；待机和弧线转向为本项目编排。默认目录没有新增 Mixamo 库片段。Mixamo 的官方流程、骨架绑定学习和本地文件对接见 [docs/MIXAMO_BINDING.md](docs/MIXAMO_BINDING.md)。

导入入口面向 Mixamo 标准骨架的 `Without Skin` FBX，限制单片段 60 秒、文件 64 MB。导入后的脚接触来自位置/速度估计；独立手指旋转尚未迁移。不宣称任意骨架、跳跃片段、鞋底、地形或所有体型已经通过视觉验收。

## 主要修正

- 对所有源帧及根位移施加同一个初始朝向变换，统一正面。
- 用原生上臂方向与肘部弯曲平面建立完整旋转框架，低屈曲时保持稳定参考，校准手掌与前臂轴向。
- 每段动作的起点归零，避免切换时沿采集片段原始起点滑移。
- 转弯后重新建立中段支撑脚跟/脚尖锚点，并计算骨盆可达性。旧的首次接触锁点方案会锁住尚未落稳的脚，已弃用。
- 有界离线四元数平滑后单独记录支撑偏移，不把平滑前的零误差当成最终结果。
- 相同完整网格、266098 显示顶点、531702 三角形、104 原生骨、全部 CSR 权重、原人体档案和材质保留。

## 构建与检查

从仓库根目录运行 `npm ci --prefix tooling`，再运行 `node kaopu-unified-human-workbench/motion-review-r04/build.cjs`。构建核对原人物 HTML 摘要，输出 `preview.html`、`BUILD.json` 和 `CATALOGUE.json`。

`verification/` 包含启动、实际浏览器检查、原生夹具提取与 FBX 接口测试。查看 [docs/QA.md](docs/QA.md) 了解运行顺序和证据边界。文件语法、数值检查、真实渲染与用户视觉接受分别记录，不互相替代。

## 尚未解决

原人体肩腋轮廓、手指表皮及一些关节褶皱仍有精修空间。转弯是行走路径编排，不是新采集的原地转身；最终平滑仍留下毫米级支撑偏移。没有新增肌肉、刚体平衡、重量、摩擦、衣物或双人接触物理。本版为可审查的单人候选，用户视觉尚未接受。
