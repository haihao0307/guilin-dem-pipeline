# R03 development failures and corrections

These are development diagnostics, not production-review evidence. The final accepted numerical evidence is only MOTION-NUMERIC-QA.json plus its matching runtime/source hashes and the explicit browser-review gate.

1. Arm reach hard clamp inherited from R01 produced a sharp change near full extension. A 30 Hz exploratory all36/two-program run measured up to 581.85 rad/s² local-joint acceleration, principally lowerarm01.L. Replaced the arm-only distance clamp approach with a C2 tanh soft reach envelope from 82% of segment reach toward the existing upper extension cap. Leg IK remains exact. A subsequent 60 Hz all36/two-role single-program run measured 254.81 rad/s² peak. Final library-wide maxima are in the final report; these different exploratory sample sets are not an apples-to-apples benchmark or a visual acceptance.

2. Epsilon probes found an actual pose discontinuity hidden between ordinary frame samples. New programs can punch while stepping; inherited R01 code compensated rear-toe pivot only when a foot was planted. A switch into swing could therefore jump the leg target, up to 0.0523 maximum matrix-element difference around an epsilon interval. The same toe-pivot compensation now applies during both planted and swing phases, and thresholded toe counterrotation was removed. After correction, 8,032 event/landing/seam probes across four representative shapes and all18 programs/both roles passed; worst epsilon matrix delta was about 2.70e-6. Final all36 validation repeats all those boundaries per shape and role.

3. Early shared reset timing left a 2.25-second interval in which all18 arenas had the same paired phase labels. Authored phrase timing and late reset-distance probes were revised without random phase offsets. The final 0.25-second timeline sample has a 0.5-second maximum uniform paired-phase run at the loop's neutral end. This is an action-state coverage diagnostic, not image-based motion-diversity acceptance.

4. Two parallel complete numeric partitions were killed with exit code 137 before completion. They produced no accepted final report. They were restarted with explicit Node heap limits; only complete matching-hash partitions are mergeable. No timeout or process kill is treated as a numerical pass.

Exploratory pilot JSON reports were generated while implementation and harness design were still changing. They explain the above findings only. Do not use their hashes, subset status or thresholds as final source/shape/role-bound production QA.

5. Parent review caught reversed torso response signs. The earlier overlay bounds test checked finiteness, bone lengths, foot locking, caps and child suppression but did not check directional causality. Actual FK on an adult at guard confirmed that ±X/±Y input displaced head and torso opposite the supplied direction. Corrected native Z-up rotation intent to cross(up, offset) = (-dy, +dx, 0), so pitch = -dy and roll = +dx. The new directional test evaluates actual head/spine01 bone-center displacement projected onto the requested direction. It contains 65,280 adult positive-projection samples and 32,640 child/teen suppression samples; all pass. Its 12,240 unforced probes produce exactly identical old/new skin matrices. The complete 1,296 base numerical records, overlay bounds, and transport bindings are rerun/rebuilt under the corrected source rather than replacing the old source hash in old records. The pre-fix archive and reports are local diagnostics only and must not be deployed as current evidence.
