## 保留与新增

- 保留原有36个R02预设与36个旧R01对照、原生参数、头龄体格联动和皮肤。
- 在人物总台根入口及 `full/` 入口增加拳击观察入口。返回原页仍是原有编辑器。
- 18台同时运行36个完整共同人体，每人25,417顶点、50,624三角面；没有静态GLB、代理人、减面、隐藏角色计算或自动LOD。
- 每个预设先由 `CommonPerson.compute(state)` 实际求值。全部36个中性网格SHA256与此前公网R02实测记录逐一相等。随后GPU按原生全部CSR影响蒙皮（46,623影响/人，最大9影响/顶点），身体保留joint-conditioned rest contributions，头部使用原有头部权重。
- 原生Anny骨架104骨保留，行列约定为row-major、metre、Z-up；显示转为Y-up。Anny rotvec是度，不将GNM弧度轴角误当成同一接口。

## 学到的原则与实现边界

1. [Daniel Holden 2026脚接触/IK](https://theorangeduck.com/page/inverse-kinematics-foot-locking)：显式支撑/摆动接触时段，脚趾接触锚，解析两骨IK，平滑解除与恢复。运动自身有root motion；不会按每帧人体bbox最低点归零。本文实现为自有代码，没有复制示例动作。教师代码可见[MIT仓库](https://github.com/orangeduck/GenoView-InverseKinematics)。没有使用LAFAN1。
2. [Ready-to-React](https://zju3dv.github.io/ready_to_react/)：把对手的出拳状态作为防守和下一步反击的条件。当前是独立、确定性的规则状态机，未运行其神经网络，未导入DuoBox、受限权重或研究代码。不能将此处规则动作称为该研究模型推理结果。
3. 18台分三种有解释的攻防配置：刺拳/侧闪回击、直拳/下潜回守、交叉攻防/抢时反击，各6台；不只是同一动作随机错相。各台还具有不同相位和速度。
4. 儿童、少年形态仅用于比例覆盖，以低强度非接触目标练习展示。所有年龄预设保留，不是实际训练建议。

## 仍有限制

- 无刚体接触/碰撞冲量/平衡控制器；不声称物理拳击或研究模型已迁移。
- 沿用原有完整中性头身和皮肤。中性颈部修正随蒙皮运输，未每帧重跑颈部公平化/动态形变修正。
- 当前运动由自有规则与IK生成，未使用真实专业拳手动捕。
- 简单不透明运动服覆盖是独立材质分区，不是布料模拟。手套为辅助护具，不替代手部网格；头发、布料二次动态未实现。
- CPU数学与CI软件GPU测试不能替代真实手机/硬件GPU测试。390×844仅为手机视口。
