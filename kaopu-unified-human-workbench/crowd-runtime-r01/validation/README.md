## 性能数字的解释

记录的 `submittedFrameFPS` 按完整更新及 CPU 渲染提交完成的相邻间隔计算，表示运行提交速率；没有使用 GPU 完成计时或显示器呈现时间。`stepMeanMS` / `stepP95MS` 是统一步骤的实际经过时间，亦非 GPU 执行时间。`simulationPerWallSecond` 明确给出实际模拟速度，不能把每次推进 1/60 秒称为达到了实时 60 Hz。

人数切换会自动改变构图距离；原服装会按连续像素误差调整采样。不同场景的热身状态也不同。因此这些首轮记录用于稳定性与瓶颈观察，不能用其中 4 人高于 2 人的提交速率推断扩展效率。CPU 的衣物等待与头发计算有时间重叠，二者不能直接相加。

## 显示部件与受力范围

首轮真实 P01 的衣物使用 211 + 294 个区域粒子和 2,334 + 3,323 个可视控制点，实体纱线由原表示生成；受力计算为原 `ReducedCloth` 区域二次运动及身体/上下装接触，没有逐纱线受力、完整自由布料、完整自碰撞/CCD 或任意叠穿。头发保留全部 114,171 根显示发丝，以原 43 × 25 导向节点求解；没有把显示发丝根数当作独立物理杆数量。

当前鞋继续使用每只 39 个原 R14 部件及原材质，通过静态整体三轴配尺和摆位包容真实足部，再跟随 foot 骨骼。鞋底厚度也随整体高度比例改变。截面统计检查原控制顶点与原内层三角，不构成连续全表面碰撞、舒适度或完整显示网格的无穿模证明。没有鞋材、足底压力或动态弯折求解，亦没有头发/衣物、跨人物之间的力学耦合。完整外观及穿着效果仍需用户验收。
