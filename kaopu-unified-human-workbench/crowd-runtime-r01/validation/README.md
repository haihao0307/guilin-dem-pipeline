## 性能数字的解释

记录的 `submittedFrameFPS` 是完整更新与渲染提交结束的间隔；没有使用 GPU 完成计时或显示器呈现时间。`simulationPerWallSecond` 明确给出实际模拟速度，不能把每次推进 1/60 秒称为达到了实时 60 Hz。

人数切换会自动改变构图距离；原服装会按连续像素误差调整采样。不同场景的热身状态也不同。因此这些首轮记录用于稳定性与瓶颈观察，不能用其中 4 人高于 2 人的提交速率推断扩展效率。CPU 的衣物等待与头发计算有时间重叠，二者不能直接相加。

原服装求解中当前 P01 使用 211 + 294 个区域粒子和 2,334 + 3,323 个可视控制点；不是逐纱线受力求解。头发使用原 43 × 25 导向物理节点。鞋目前为原模型与脚骨绑定，未新增鞋底受力或跨人物接触碰撞。完整外观及穿着效果仍需用户验收。
