# 完整人物多人运行台 R01

同一三维场景中运行 1 / 2 / 4 位完整人物，保留原 P01/R07 身体、原动作、F13 完整发丝及导向物理、原 T03/P02 实体服装与 R14 鞋。

## 运行方式

打开本目录 `public.html` 的固定 HTTPS 发布入口。准备完成后，可切换人数、行走/跑步/跳跃/静止，开始、暂停或单步；拖动旋转视角，滚轮缩放，选择人物后近看与移动。测量按钮记录当前配置的 60 个完整求解步骤。

测量期间锁定人数、动作、物理设置和视角；可以点击“暂停并中止”结束本次测量。记录会区分中止和完整的 60 步，不混合两种配置或把中止写成测量完成。

每人只有一个最终骨骼姿态来源。衣物先完成原来的 48 步联合拟合，再进入各自 Worker 的动态求解。头发保留每人 114,171 根显示发丝和 43 × 25 导向物理节点。鞋采用原模型、原材质，并绑定真实脚骨。

固定身体/头发/同款鞋几何及材质输入可以共享；可变姿态、衣物求解和头发形变保持独立。使用原实体服装表示；未以简化人体、服装替代壳或低密度发型冒充原模块。

## 测量与范围

记录包含动作计算、头发求解、衣物等待、CPU 渲染提交、帧间隔及绘制提交数。CPU 提交结束不等同于 GPU 完成或屏幕真正呈现。模拟时间与实际经过时间分别列出，不把慢速模拟误写成实时运行。

- 当前为整合试验；穿着与最终视觉验收仍待用户确认。
- 头发选用此前公开的 F13 密发候选，未宣称更新的头发结构线已验收。
- 鞋为真实脚骨跟随，尚无独立鞋底受力求解。
- 未实现跨人物衣物/头发接触碰撞或 NPC 生活行为。
- 原求解安全门槛保持；发生拒绝时暂停，避免继续显示身体与衣物不同步的状态。

## 可重建源码

`src/` 为本次接入与调度源码。原始依赖在固定 SHA 清单中记录，构建时按原字节恢复：

```bash
npm install
python3 build/prepare-sources.py
python3 src/cloth/prepare-upstream.py
node build/main-bundle.mjs
python3 build/pack-app.py
```

构建依赖 Node 与 esbuild。`CROWD_ESBUILD_PATH` 可指定安装后的 esbuild 模块路径。网页加载时校验原 F13 运行包以及本轮运行包的完整 SHA-256；不从移动分支读取人物内容。

各适配器目录的 `verification.json` 记录其独立验证；公开浏览器证据单独存放。局部测试通过不等于完整画面已验收。

此目录独立于 NPC 生活观察、服装叠穿修复与更新的头发结构分支，提交为 Draft PR，不合并主干。
