## 使用

进入后右侧顶部是新外观面板：新灯光＋新肤质、原版对照、只改灯光、只改肤质。四种对照不移动镜头，也不重建人物几何。整脸、三分之四、嘴唇特写及全身按钮用于改变观察范围。

表皮微结构、肤色细微变化、表皮粗糙度、自然唇色、唇内湿润与散射近似可以独立调节。灯光区提供主光、轮廓光、环境反射、曝光、主光方向以及中性／侧掠／逆光预设。检查通道提供底色、粗糙度、法线、散射分区估计和皮肤／嘴唇归属。

新灯光开启时，照明由新面板统一管理。旧的影视灯光、耳部补光等照明工具请在原版对照模式下使用，不将多套灯光同时叠加。当需要检查原始耳、唇或人物结构时，先切原版对照；旧版独立工作台也始终保留。

## 构建与数据

Profile.mjs 管理版本化参数校验及整个人物存档扩展。Material.mjs 组合现有 ET19、耳部和区域皮肤材质，分离颜色、细节、粗糙度与散射近似。Studio.mjs 管理可关闭的双灯棚拍与一次生成的预过滤环境。UI.mjs 提供原位对照、特写、诊断和整个人物保存。build.cjs 只在内存中适配冻结 R03 构建，不修改其源码。test.mjs / verify.cjs 检查参数、兼容、真实画布、存档、动作及公网入口。
