## 查看方法

页面有细腻缎面、浅色微红、暖色细纹、深色柔光、干爽微纹、润泽混合六种配方。先切换预设，再用“肌理近看”与“掠射检查”观察；“对照”在相同人物、配方、相机和灯光下关闭/恢复新增表面层。九个滑块分别控制色素、血色、部位色差、孔口深浅、孔口宽度、微纹、微表面起伏、油膜和干润。配方可以保存、导入及按固定种子重建。

## 已实现的边界

自有确定性孔节点和微纹场，先生成多通道高度导数，再进行纹理过滤与表面梯度输运。新增一个片元采样器读取双层自生成纹理数组，基础像素8MiB；不拷贝lo-th/head皮肤图，不改几何，不把大沟槽当皮肤。继承原BioSkin二维颜色查表和EB1。

保留完整人物的266098显示顶点、531702三角面。三份通过报告中的位置与索引摘要相同。工程尺度不是扫描/医学数据，也不是完整Disney优化器、全体积皮肤散射或动态组织皱纹。此版本为效果候选，userVisualAccepted=false；不能以编译、更多滑块或69张图宣称已经达到影视级或超过参考。
