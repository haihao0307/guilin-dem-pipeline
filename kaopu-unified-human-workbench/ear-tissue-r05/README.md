## 真正改变的底层逻辑

### 曲面采样，而不是平面撒点

R04 毛孔使用 `vFRest.zy` 投影。R05 在已绑定的耳廓三角面上按表面积选择面，用重心坐标记录采样中心，并在三维空间拒绝过近样本。默认双耳共 6,381 个采样点，固定种子可复现。中心随当前耳形移动，毛孔半径/深度保留毫米尺度，形状在局部切平面按圆形核求值，不沿单个投影方向拉长。平面采样代码只保留在显式 R04 材质对照路径。

毛孔不再加入底色黑点，而是轻微改变受光微表面；缩小到像素以下时过滤并转入粗糙度。它不是布尔挖孔或新增毛孔实体网格，也不是实测毛孔数据库。种子最小间隔、半径与深度都是人工生成参数，不能用于生物测量。局部切平面圆形核是微尺度近似，并不等同于全曲面精确测地圆。

### 当前模型厚度参与透光

`TissueField.mjs` 在当前耳形的三角网格上建立加速结构，从表面向内求射线与另一侧的交点。正向法线未命中时，使用有置信度标记的圆锥方向估计；依旧未知的区域采取保守不透光处理。只平滑光学数值，不改耳朵顶点。

这个厚度是模型外壳之间的距离，不是分别测得的真皮、脂肪、软骨厚度。默认 7,572 个法线命中、5,025 个圆锥估计、3,889 个未知顶点；界面会显示未知数量。模型有缺口、折叠或不准确的后表面时，厚度也会受影响。不能把当前网格的厚度中位数当成真人耳组织尺寸。

透光随光线方向、估算路径长度和置信度变化；使用分通道衰减，并区分耳垂、耳轮、耳甲区域的颜色、粗糙度和微表面强度。没有降低 alpha、加透明外壳或让整个耳朵自发红光。散射系数仍是人工校准的实时近似，不是实测光谱，也没有完整多层体积传输与全局遮挡求解。

### R04 不回退

运行时直接继承已验收的 R04 耳形/耳根范围和细分显示层，未重新引入空间方框选取或移动头皮。R05 的唇材质与 R04 字节一致；旧耳部、眼球、身体、绑定和动作源码不改。增加的内容只在本目录和三个 R05 专用工作流内；资产审计工作流只读下载并验证原有固定资产。

## 已观察到的限制

已检查同相机新旧材质、正侧/逆光、毛孔诊断及保留的嘴唇画面。R04 那种密集黑色针点减少，逆光出现随区域变化的暖透光，但耳甲下侧仍有异常偏亮的弧形折线；上耳轮、耳根与耳垂附着仍有偏软或带棱角的形面。原头皮/面部本身的方向性纹理问题不在本次耳部材质修改范围内。本版不是影视级最终耳朵，也不能宣称泥塑感和全部高光问题已经消除。

新增采样查找纹理默认约 1.11 MB，指这部分 GPU 数据，不是整个人物总显存。形状变化会重新计算模型厚度和查找表，成本高于普通材质滑块；当前没有实体软骨/软组织物理或完整耳道。未知厚度采用保守不透光，局部效果可能偏弱。旧版档案按已存在的耳 schema @3 迁移规则读取；不承诺旧 R03 能反向读取新档案。
