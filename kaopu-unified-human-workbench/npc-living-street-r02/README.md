# 街角日常 · KAOPU Living Street R02

六个完整原生 R07 人物生活在一条 26 × 14 米的街道中。三男三女分别使用原人物目录中的六种体型与 P01–P06 面孔；男性短发或寸头，女性长发或中长发。复用用户仓库的完整衣物、鞋、头发和已有动作系统。R01 只保留工程外壳与资产打包经验，不作为用户已否决外观和动作的验收基线。

这是可观察因果的自主生活实验。瓶子由事件分派器优先分配，其余活动根据当前需求、性格、距离、天气和设施状态选择。没有预先安排每个人依次播放什么动作。

## 可操作的生活

- **放一只瓶子**：在所选人物附近的可达位置放置真实物件。每 0.35 秒模拟时间寻找合适的可用居民，单人认领；正在执行的接触动作先完成，坐着的人先确认站稳。认领与捡到分别记录。
- **面包店打烊 / 开门**：检查营业、库存、零钱和实际交接。交易提交前打烊，不扣钱、不增加面包。
- **下点雨**：保留已认领瓶子的工作，安排可达窗把手的人关窗，六人各有实际屋檐下的避雨位置。雨停后可以重新活动。
- **吹一阵风**：改变环境风和窗户需求。窗扇只在真实掌心达到实际把手后移动。
- **花坛缺水了**：降低土壤湿度，由居民到固定水阀旁，转开、保持浇水、再关阀；达到动作接触条件后才完成浇花。
- **换成黄昏**：改变天空、环境光、日光色与街灯发光。
- **打断当前活动**：取消未提交的动作；坐下或起身中的人必须安全站稳才能释放座位。失败后保留座位与姿态，释放待捡瓶子，避免把失败误记为站起来。
- **全景 / 走近 / 跟随**：观察全街或所选居民。暂停、两倍模拟速度、重置和需求滑块可用于检查选择。

所有模拟状态保存在当前页面内；刷新和重置开始一轮新的日常。两倍速度是模拟速度，不代表设备帧率。

## 模块责任

`LifeSimulation` 管需求、选择、导航、资源租用、物品归属和原子交易；时间走完不会自动增加物品或钱。`NativeMotion` 使用原动作和不变骨长，在实际原生手掌、脚底和座椅上检查接触。每个居民完成装配后，`assessCapabilities()` 重新测量整条把手路径，只提供实际可达的活动。

`ItemWorld` 使用真实刚体及有限力抓取检查瓶子、面包和交接位置。`EnvironmentWorld` 要求当前任务 token、原生姿态有效、真实手掌接触与完整操作过程，才移动窗扇或完成水阀操作。过期、重复或被阻塞的回执不能提交世界状态。

服装使用完整衣片的原身体三角绑定和全部 CSR 权重，加上姿态后的接触修正。头发根部使用真实原生头皮三角的完整权重；未增加不透明头罩或替代人头。鞋底来自完整原鞋生成结构。

## 可复现构建

```sh
node prepare.cjs --all-native
node src/life-tests.mjs
node build.cjs
```

prepare 只从锁定源下载并核对字节/Git blob/SHA256；服装派生模块与 worker 可重复生成，不提交多兆重复数据。网络页在 `dist/index.html`；原生 packet 使用同源、原字节和原校验值。

当前六人实际浏览器启动后记录 observed packet；`prune-observed.cjs` 使用当前 sourceHead 的观测，检查六人所需集合。R01 的旧 18 包证据不得用于本版。然后 `node build.cjs --offline` 生成内部完整 standalone。真正的 `file://` 启动和禁止网络下的交互必须另行验证，不能以 HTTP 服务或文件存在代替。

## 验证与实际范围

语义测试中的执行回执明确标为 `TEST_FIXTURE_ONLY`，仅证明选择、互斥、导航和交易合同。动作数值 fixture、原生构造器检查、衣片接触抽查、真实浏览器连续动作、手机视口、离线页面和当前 head 的固定公网页面分别形成证据，不能互相代替。

这是基础实验：抓取、身体和设施动作包含运动学辅助；水流是与阀门一致的可见指示，没有流体求解。服饰不是完整自由布料模拟；长发保留原作者形状，动态肩部/衣物碰撞尚未被完整认证。完整六人装配的加载和帧耗必须由真实运行报告，不预先承诺设备帧率。最终用户视觉验收与生产就绪均保持待定。

R02 使用独立分支及固定发布目录，保持 R01、其它人物工作台及其它 Pages 内容不变。
