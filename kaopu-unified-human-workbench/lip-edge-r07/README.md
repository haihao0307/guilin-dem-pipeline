## 最初的问题与候选假设

真实 R06 的三个截面都存在连续的外唇到口内回折。问题不是已经证明“缺少厚度”，而是已有回折的峰部集中转角：张口约 49.79° / 71.39° / 50.46°，说话约 63.27° / 71.41° / 64.02°。这些是实际三角面的相邻法线转角，不是组织厚度。

两项备选原因已被本次诊断排除为该目标的主要原因。关闭程序凹凸后，目标区域最大只变化 1 DN；牙齿避让在说话样本移动 0 个顶点，张口只移动一个上侧点约 0.005 mm，目标下缘没有该阶段造成的位移跳差。

证据在 `evidence/diagnosis-02/`。原始 QA SHA-256 为 `98301a388d4a5c0cb32bfa7d6518309ce0a35eb274431f2e6bdc96ba6bbf2501`，固定诊断代码提交为 `2b2664f9fab33e85a9e5497a501fef81bd0484b9`，原始证据提交为 `cf81159b770ac4b2c78a163d32389ac15a1a0df8`。失败的先前尝试保留在各自目录，未改写成通过。

## 候选如何工作

在完整原索引和静止坐标上建立邻接，以原有 49 对接触点的上下两组最短图距离识别下唇归属。实际观察到的下唇峰部，其旧 `upper` 标签为 true，因此候选不把这个标签当作下唇身份。

仅对中央负 v 的下唇内返带求一个局部平顺位置场。工程平顺长度为 1 mm，单次提案位移上限为 0.6 mm；只写口部坐标系的 up/front 分量。外唇主体 `v >= -.015` 和原接触点的一圈原索引邻接保持固定。全部收敛、有限数、位移、三角面方向和保护域检查通过之后才写入。

修正在原生第一次法线重建前执行一次，随后原微几何、最终法线和所有祖先动作步骤照常执行。使用连续 `smooth(.08,.24,jawOpen)` 工程范围，当前闭口和噘嘴直接沿用 R06。该范围不被解释为生理阈值。

R05 的说话归属修复与 R06 的口角修复继续保留。原始形状、牙齿、拓扑、材质、镜头、灯光不作为补偿手段。版本、动作进度和完整人物进入同一份存档。无效档案在修改人物前拒绝；求值出错时，控制层卸载 R07 并重新求值、显示继承人物。

## 接受条件

技术验证包括同状态 R07/R06 对照、独立固定 R06 页面、25% / 50% / 75% 张口、三个实际保存入口、半进度人物的新页面恢复，以及真实 GPU 读回。最终外唇主体、非皮肤几何和原 98 个接触样本位置必须精确保持；闭口和当前噘嘴的完整状态与画面也必须精确保持。

视觉接受另行判断：张口正面、斜侧和说话正面的原始画面，应能读出更连续的短内回转。单纯让角度下降、产生像素差，或者挡住更多牙齿，都不自动构成改善。全唇体积、全局碰撞、生理厚度、其他人物和实体手机性能仍未验证。

分支 `feature/lip-edge-r07-20261020`、Draft PR #318 保持隔离；所有推进只做快进，不合并或改写旧版历史。
