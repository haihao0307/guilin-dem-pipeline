This isolated test keeps the existing KAOPU engine, animation/expression contract and body. It applies one shared artistic head-identity delta to R64, retaining R65 revision 2 camera, expression, lighting, cosmetics, eye surface and hair settings. Each static groom is rebound to its actual current geometry. It does not replace the face with an external model.

The observer reads manually reviewed visible facial arcs with explicit uncertainty and exclusions. Midpoint arc-length integration prevents repeated endpoints and differently split fragments from receiving extra weight. Screen-space normal errors use actual perspective silhouettes refreshed from the native mesh. Camera alternatives remain hypotheses. Integration samples are not extra independent observations.

Only a consistent coarse vertical relationship below the eye plane was proposed; uncertain global face-width changes were not prescribed from one focal length. The 24 broadest existing head PCA controls are available with a bounded prior; eyes/teeth identity coefficients and expressions stay unchanged. A 5 mm maximum predicted native step bounds this diagnostic proposal. That bound is not a claim of 5 mm anatomical measurement. Actual output must be checked separately from the response prediction.
