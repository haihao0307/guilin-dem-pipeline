# R60: one static eye-shape trial on the existing native face

A is the R57 lower-face candidate with the already rendered R58 eyebrow profile. B changes only four existing Anny static eye-height fields. Both share the original 25,417-vertex native body/head system, existing procedural eye surface, brow source, hairstyle recipe, original perspective cameras, lighting and per-view expression. R52/R54 remain untouched. There are no source photographs, photograph target coordinates or external model weights in this directory.

The R59 fixed-perspective component pass showed that height2 negative contracts both upper and lower visible boundaries and height3 negative preferentially contracts the outer half. Its 4x eye-only crop run was 38350764829 at 2ba961a61eed8bb3524922529a134f17e8149309. This supports the control direction, not resemblance. The single R60 combination is height2 .20→.10 and height3 -.22→-.42 bilaterally, holding scale/corners/fold/gaze and expression constant. The hypothesis can fail: smaller apertures may worsen the reference eye shape, and existing optical/lid boundary limitations may dominate.

Three pure archive tests verify the bounded change. The actual original-engine run separately verifies every axis changes vertices; captures neutral oblique/other angle/profile and the existing small-smile front view; audits full native topology, degenerate/reversed faces, eye/skin intersections and visible rays; then restores the entire original archive and native mesh hash. Contact counts include buried surfaces and are not equated to visible defects. Actual images and baseline-relative visibility must be reviewed before keeping the trial. Baseline body/eye bit equality is diagnostic rather than a requirement for a new identity trial.

Only one original hairstyle is constructed per identity and expression, then reused for the three neutral cameras. Hair parameters are unchanged; this is not a hair development task. R58 surface-bound brows are rebound to the current neutral skin with the same profile, which is restored immediately after binding. This avoids dead legacy outerLift options. Real drawings use the canvas's own exact 797×590 buffer and synchronous render capture, avoiding element screenshot rounding.

No candidate is automatically accepted, merged, deployed or sent to the user by this test. Success means an inspectable comparison exists. It does not certify likeness or eye-system maturity.
