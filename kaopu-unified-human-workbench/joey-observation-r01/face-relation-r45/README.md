# One native R45 face-relation candidate

This is one provisional shared-identity candidate, with two independent authored reference-like camera/light/expression conditions. Only original Anny local-shape axes change; complete before/after values are in changes.json. Upper-lip visible height and volume, cupid-bow spacing, restrained mouth width, a small static corner adjustment, brow gap and temporal eye curve are targeted. The small static mouth-angle adjustment remains uncertain because both available comparison photographs are smiling. It is not accepted neutral anatomy.

No chin, jaw, nose or ear axis changes. The old eye bridge is retained: no new eyelash layer, iris-size control, refraction or ET16 system is claimed. Hair geometry/material options and skin surface state stay unchanged. Brow coverage retains real native surface binding, with less heavy head/tail coverage and a modest curve correction.

Native left/right smile effects are measured before applying bounded per-image asymmetric strengths. Image side is not assumed to equal anatomical label. The pose still uses a conditional focal solution from the prior camera study, not a uniquely recovered photographic camera. Lighting is authored near-axis fill/key with real self-shadow support; it approximates observed shadow character and does not recover source illumination, exposure or reflectance.

Only current candidate images are intended for viewing. Old R44 exists as Git rollback and internal regression input, not as a simultaneously loaded production model. Source photographs and private target coordinates are absent from the project. Production pages are not changed by this isolated test.

The run captures the two matched conditions and extra oblique/profile views. It checks native geometry, eye/skin contact witnesses, brow support, body coupling and full R44 rollback. Statistical likeness is not claimed. Pixel3DMM was not run; this is original native QA/observation code.
