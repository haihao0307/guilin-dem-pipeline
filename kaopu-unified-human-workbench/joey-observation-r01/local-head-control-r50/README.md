# Local original-head control feasibility

Uses all 170 existing GNM head identity axes inside the already licensed and pinned native runtime. All 12,466 component-0 vertices are included; unknown semantic regions are protected by default. The old 20-region summary covers only 4,592 vertices and must not be treated as the full head. Existing eye and tooth identity coefficients remain fixed.

The source neutral R45 bind surface defines triangle area and adjacency. An authored geodesic lower-chin/front-jaw field supplies three unit response directions: down, forward, and bilateral narrowing. These are no-photo feasibility probes, not anatomical measurements or three new likeness candidates. Regionwise and whole-surface Gram matrices, target RHS and target norm are exported; raw model weights and private reference images/observations are not. Graph Laplacian acts on displacement, not existing geometry.

These sufficient statistics cannot certify maximum displacement, normals, edge strain, full HeadTransfer behavior or eye/teeth contact. Any selected coefficients require direct complete-vertex checks in the same native runtime, then one bounded rendered candidate with rollback. A failed fixed set of regularization settings would not prove the whole 170-dimensional space impossible. No production update.
