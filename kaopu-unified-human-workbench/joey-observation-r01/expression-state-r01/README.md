# R44 expression-state comparison, not a new identity

The user requested continued work on the same native character. This bounded experiment addresses the mismatch between the existing reference photographs' closed-mouth smile and the frozen R44 zero-expression render. It does not claim improved identity, calibrate a smile from photographs, or publish those photographs.

All stages clone R44 `brow-tip-r44/B-brow-tip.json`. Static identity, local morphology including brow/nose values, body, gaze, native engine, R44 eyebrow coverage/material, head-hair, light and three cameras remain fixed. A and F are the original GNM-owned neutral state. C switches only to the existing Anny expression owner with the same five action keys at zero. B sets mouthSmileLeft/Right to .25 and cheekSquintLeft/Right to .06; jawOpen stays 0. These are authored test strengths, not fitted or accepted values. Zero jaw opening does not by itself guarantee visibly closed lips.

The extra C control is necessary: the existing native Anny expression path also embeds tongue and oral attachments at zero actions. Its neutral result must be measured rather than assumed identical. The live label catalogue is checked before any state is applied. No arbitrary GNM expression coordinate, blink or new eye system is used.

The runner verifies original R44 geometry and bare pixels against run38131368879 at commit e70e5370186883b9211229e323174212959f82d2. It captures actual bare and fixed-hair front/oblique/profile images of all four states, preserves original root/guide bytes, checks exact archive/geometry/pixel restoration and compares actual native skin/eye triangles. The predeclared body and eyeball preservation budgets are each .1 mm; no new degeneration or face-normal reversal is accepted by the structural gate. Contact pairs are not visible defect counts. Camera-visible contacts and actual images require interpretation, including any hidden oral changes from the owner switch. Reference photographs and native model arrays are not included in the output.

The existing isolated contents:read CI runs Ubuntu24.04 and official Playwright1.57 Chromium/SwiftShader with the original fixed engine and head-hair checkouts. This branch-only test does not deploy or alter a production page. At source commit time, actual rendering and visual judgment remain pending. One state recipe is tested, then the experiment stops for review.
