# R52 — one native face/brow candidate

R45 remains the rollback identity. R51 A supplied a visible longitudinal direction but worsened nosebase level; C supplied a mouth-width direction with an adverse lip-to-chin tradeoff. This candidate combines only six existing Anny local axes, including nose translation to test that adverse direction. It is an authored hypothesis, not a measured portrait reconstruction or accepted likeness.

The new brow adapter derives from the existing MakeHuman centreline adapter at be92fc5ec93336bc555e85af5abee334d3913d47. Only Mindfront CC0 style 3 centreline coordinates are included; its thumbnail and original head mesh are excluded. The existing independently authored skin BVH is reused without external guide data. Full attribution and original source hashes are retained.

The neutral current native head defines an orthonormal eye/brow frame. Every root and every fibre support must map to an exact, same-oriented GNM source triangle present in the combined mesh. Expressions deform those fixed barycentric supports; they do not re-run nearest projection. A changed identity requires a new binding. The 20 micrometre root lift is distinct from support error. This is an appearance adapter, not an eyelid replacement.

Hair keeps the original R30 style, source root seed, 8000 strands and original settings. It is rebuilt on each actual head using the original native guide/root projection instead of reusing world-space arrays from another identity. This is static routing and support, not hair physics or a new hairstyle.

The isolated runner uses the unchanged R05 native engine, real Chromium/SwiftShader, fixed per-reference cameras/lights and the same expressions for both identities. R44 archive, geometry and original pixels must restore exactly. CPU tests cover real source mapping and frame contracts; real renders, geometric contact diagnostics and manual multi-view review are still required before any visual claim.

No private reference photographs, image target coordinates, scans or recognition embeddings are in this directory. Camera/light settings and artistic control values are permitted by the owner's explicit approval. No production page or other workbench is changed.

The first real R52 render (37c15d8, run 38202620867) rejected the new brow appearance: using piecewise native five-point carriers made visible slope breaks and an excessively narrow band. The binding itself was correct. A bounded adapter correction replaces only that carrier with a single smooth least-squares quadratic and uses the existing thickness control at 120; the six face axes, cameras, expressions, eye material and hair settings remain fixed. The source centreline variation is retained. This correction needs another actual render; it is not evidence of accepted likeness.

A subsequent bounded eyebrow-only correction replaces the automatic native five-landmark XY carrier with an explicit shared native brow-band profile. Visible upper/lower eyebrow bands from E04 and U07 were reviewed locally; the partly hidden E04 far brow is excluded and U05 is reserved from this eyebrow fit. Photographic points/rays remain private. Runtime contains only the permitted native artistic profile and the CC0 source-centreline normalization. Source transverse spread is normalized using its own style-3 root field, and inner/outer density fades retain stable source-curve selection. Native landmarks now only provide an initial depth hint before actual supported-skin projection; they no longer choose the entire brow silhouette. Face/eye/hair/camera/expression fields remain fixed. This is a camera-conditioned appearance fit, not measured 3D anatomy.

Projection review caught a separate binding-frame error before accepting the band: eye-to-brow-ridge was about 30 degrees forward of the longitudinal face direction, which made depth projection reintroduce a hooked tail. The corrected explicit convention uses eye horizontal and eye-centre-to-chin longitudinal axes; profile coefficients are refit in this same frame and checked by convention identifier. Face geometry remains identical. Actual surface reprojection and a brow-depth perturbation regression test distinguish this correction from another free shape tweak.
