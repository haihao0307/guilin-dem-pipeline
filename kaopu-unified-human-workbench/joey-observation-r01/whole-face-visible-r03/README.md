# Whole-face visible anatomical fit R03

Independent unaccepted research candidate, preserving R64/R65 and all published pages. Same native GNM/Anny/body/rig; no external face replacement.

The local private solve normalizes eye, nasal-base, lip and jaw observations per region, uses a bounded 18-dimensional subspace derived from the exact composed-model gradient, and applies the same zero-jaw dental rule throughout fitting and rendering. The 58 native inner-mouth boundary vertices are separated into 29 upper and 29 lower vertices. True anatomical opening and upper-incisal support constraints replace reliance on lipstick-mask edges alone.

The current source-image camera is retained for controlled comparison; its focal length and depth are estimates. This is a single-view experiment without an independent view holdout. It does not run or recreate Disney’s unpublished dense detector. The fitting code and private pixel targets remain local.

Only the authored native archive, current surface binding parameters, existing CC0 brow/lash source, and own renderer/test code are committed. No reference photograph or source-image coordinates are included. Actual native geometry and material rendering must be inspected before any portrait promotion.

ClosedJawDentition is explicitly a zero-jaw single-frame compatibility experiment, not clinical bite verification or a general jaw animation solution. Iris appearance and gaze remain the existing system; measured iris projection differences are diagnostic, not evidence that the eye system was replaced.
