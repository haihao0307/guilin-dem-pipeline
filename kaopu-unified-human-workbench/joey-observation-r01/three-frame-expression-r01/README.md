# Three-frame native identity exercise

Independent QA only. Original R64/R65/R52 archives and live pages stay unchanged.
A fresh shared GNM head identity starts at zero with 13 documented ocular/lip compatibility controls. Native facial actions and perspective camera are estimated per panel. The complete composed native engine is differentiated, then every final vertex is independently recomputed in its original JavaScript engine before rendering.

This is an original observation/optimization implementation, not the unpublished Disney dense detector. The soft-focus source triptych and manually observed pixels remain private. None is included in this directory. Only our artistic archive, camera, actions and tests are published to the existing QA branch. There is no measured frame timing, independent heldout view or demonstrated likeness improvement. Three render jobs each capture exactly one real model state. Existing hair/eye quality limits remain.

Private reusable computation modules, observation roles, fixed source hashes, finite/native forward checks and the final visual receipt are kept with the local experiment. The shared identity is identical across all three rows; there are no three independently sculpted faces.
