# Single photograph native identity exercise

One isolated native rendering exercise on the existing QA branch. This does not replace the preserved R64/R65, the rejected previous triptych, the model, rig or production page.

A new head identity starts at zero with the previously documented 13 ocular/lip compatibility controls. One perspective camera seed and native facial-action response are fitted to privately reviewed visible photo observations. The same composed gradient and original JavaScript engine are used. This is our own sparse observation/optimization implementation, not the unpublished Disney detector or an independent proof of likeness. All observed pixels and reference images stay private.

Only the resulting artistic archive, camera/lighting/actions and our QA renderer are present here. The task is one real model screenshot showing face proportions and a slightly open mouth with upper teeth. The original photograph's true focal length and lighting are not known. Existing hair/material quality is unchanged. Numerical convergence alone is not acceptance.
