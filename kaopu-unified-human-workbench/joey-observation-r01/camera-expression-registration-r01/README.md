# Frozen R44 camera/expression registration study

This stage changes no identity or shape coefficient and does not deploy a new face. It first verifies and exports only the existing native 68 three-weight affine landmark outputs on the final common mesh, their three-vertex supports, exact rendered projection and small original Anny action responses. No original photograph, private target landmark set, native model weights or full mesh arrays are uploaded or included in output.

The original R44 Float32 geometry and baseline pixels must reproduce before any response probe. The original GNM-owned neutral state, Anny-owned neutral state, symmetric mouthSmile .2, cheekSquint .1, eyeSquint .1, jawOpen .04 and the already rendered .25/.06 smile state are bounded diagnostic samples, not accepted new expressions or identities. The extra samples provide local response directions; a linear combination is only a local approximation and must later be checked against the real native forward pass. Zero or one control cannot be used to absorb arbitrary identity error. The original R44 archive and geometry are restored.

Private image analysis will first verify semantic point correspondence, solve per-image relative camera pose at several fixed effective focal lengths, and then fit a small expression subset with that pose held fixed. Ambiguous/occluded points are absent, not mirrored in. Actual same-engine re-render and held-out point checks are required. Unknown cropping, camera principal point, focal length and expression mean this is projection registration against an assumed frozen R44 shape, not measurement of the real person's millimetric anatomy or a unique calibrated camera.

Evidence anchors distinguish multi-view supported, provisional and unavailable records; a correct model binding does not itself confirm resemblance to a photograph. The private records retain source photo identity, semantic point, 3D support, pose/expression conditions, uncertainty, conflicts and revocation history. No trained Gram/DINO loss is claimed.

At this source commit, this is only the first native landmark/response probe. Photo-pose fit, expression matching and the second-view verification remain pending. The existing read-only isolated CI uses official Playwright1.57 on Ubuntu24.04/SwiftShader and the same fixed R05 engine. All frozen R43/R44/smile checkpoints remain available.

The first probe exposed original rounded weights with sum .999, e.g. [.037,.216,.746]. The original GNM evaluator does not normalize these values. The diagnostic preserves the exact original weighted output and records its sum. It separately labels an explicit normalized diagnostic point, checking positive convex weights, a matching actual common-mesh triangle and nonzero area. The distance between original and normalized output is retained. No asset or runtime evaluator is changed. Semantics stay unreviewed even when this geometric binding is valid. The numbered overlay colors distinguish verified geometric support from unsupported support, not photo agreement; it is not the green/yellow evidence-acceptance overlay.

Phase 2 renders two conditional camera cases with Anny-owner neutral versus a bounded native mouthSmile. Identity, skin, eye system and hair remain frozen. Seven manually read eye/nose points informed each private relative pose fit. Unknown intrinsics remain ambiguous; the visual example uses f=2*maximum original image dimension, a declared representative condition rather than a recovered true focal length. The complete .5–8 focal grid remains in the private audit. Mouth-corner height relative to lip center and eye aperture were fit in an eye-line coordinate frame. These mouth/lid points are expression-fit diagnostics, not independent holdout points. Nasal base center and chin are unused in both fitting stages. The second image repeats the frozen-identity conditional check; it is not full leave-one-photo-out reconstruction validation.

The fitted expression uses symmetric mouthSmile bounded to .35 and cheekSquint bounded to .1, with jawOpen and eyeSquint zero. The available observations selected zero cheekSquint; a control is not added solely because it exists. One example reaches the mouthSmile bound and retains unresolved mismatch. No identity correction is inferred from that bound. Exact native forward computation, matrices, rendered landmarks, expression linearization error, face/eye contact diagnostics and complete R44 restoration are recorded. Actual images still require visual review. This is original KAOPU/SciPy observation work and does not execute or reproduce the learned Pixel3DMM model.
