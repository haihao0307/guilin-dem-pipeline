## 参数化生成与展开缓存

首次在独立 Worker 中运行原 F12 生成模块。全部原模块、固定规则/种子、43 簇、98,358 根、每根 49 点不降低。生成器的运行环境外壳由 Node 文件输出改成 Worker 消息与 ArrayBuffer；几何公式与碰撞规则不变。用完整二进制摘要 `4ad0fbca025556ee24624088af6aaa657b84b043081683643ed70d4177fc322b` 对照已验证 R23，摘要不同即停止。

约 61 MiB 是展开后的完整发丝缓存，不是伪装的参数包。它首次由设备计算，随后在允许时写入本机 IndexedDB。缓存摘要检查通过才能复用；浏览器禁止存储或存储不足时显示说明，不暗中减少发丝。改变当前页面材质/眉毛参数不重新生成头发。首次计算可能需要数分钟，手机与低内存设备存在实际启动和显存负担。

主页面约 230 KB，内含当前界面、原生场景适配和 Worker 生成代码；原人物引擎、已有模型资源和有权发布的眼睛纹理仍通过已用公开来源加载。不是全离线包，也不是仅 230 KB 总网络传输。真实首次/重复请求量及时间应查看 `evidence/QA.json` 的测量，不从 HTML 大小推断。

## 真实性与安全边界

- 使用原生完整人物、拓扑和表面绑定，没有替代简化人，也没有图片旋转冒充三维。
- 全发丝 GPU 根点和路径核验；材质着色器实际编译后才显示“已就绪”。
- 外部请求不含原参考照片、私人观测、用户令牌或登录信息。
- 页面不请求摄像头、麦克风、位置或新持续账户权限。
- 明确停止按钮终止当前页面，失败不自动重试；重新载入由用户选择。
- 手机尺寸检查是浏览器视口检查，不代表实体 iOS 认证。

## 验证及固定入口

`verify.cjs` 从固定提交的公开 HTMLPreview HTTPS 页面启动，不使用请求拦截。检查原始生成、完整发丝/原生形状摘要、真实控制事件、相机拖动缩放、保存载入参数、重置和重复本地缓存加载。首个候选验证通过后再记录固定交互入口，不能用源文件存在代替公网成功。

所继承 R23 的迁移范围和限制见相邻 `full-material-r23/VERIFIED-SOURCE-REUSE.md`。本页是交互封装，不会把七图层皮肤或高密 LipRails 未迁移部分称作已集成。

## 源码复现

在本仓库对应目录安装锁定的开发依赖 `npm install --ignore-scripts`，运行 `npm run build`。构建器使用同仓库既有 `full-material-r21/eye`、`full-material-r23` 和 `hair-f13-static-r17` 原模块；`vendor/brows` 为本交互版使用的原眉毛适配与安全调参入口。`GENERATOR-SOURCE-LOCK.json` 逐项记录未改动生成模块摘要。`native-template.html` 来自既有 R54 原生页面，不包含私有参考素材。

运行 `npm run test:public` 时设置 `GITHUB_SHA` 为目标提交，或显式指定 `PUBLIC_URL`；测试必须打开真实发布地址，不允许拦截请求替代线上文件。测试截图是 GitHub CI 的 Chromium/SwiftShader 画面。
