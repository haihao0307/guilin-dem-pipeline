# Original native multiview fitting experiment

This bounded experiment freezes R45 and uses its verified native finite-difference responses. It compares three sequential states under each exact saved R45 camera and light: frozen R45, independently fitted expressions on R45, and one shared mouth-position increment plus independently fitted expressions. Only `mouth-trans-up` is eligible as shared identity; mouth width, static mouth angle, head hair, eyes, brows, materials and other shape controls are locked. Each expression update owns only its own image's two smile actions.

The CPU solver is original NumPy/SciPy code. Shared identity and separate per-image nuisance parameters are general mathematical ideas studied from multiview reconstruction; no Pixel3DMM, Ava-256, GOHA or MediaPipe model inference ran. No third-party neural code or new model weights are included. Private reference photos and target coordinates are absent from this directory.

The local fitting protocol was fixed before fitting. It separates fitted points, new held-out outer-lip observations, and old regression points. Held-out observations are never solver inputs. Their semantic boundaries are provisional because lip pigment and shading are ambiguous. The true renderer checks the native forward pass against the linear prediction, full original geometry, complete eyes, case-specific R45 geometry and exact rollback. An Actions success is only execution/structural evidence, not likeness acceptance.

The first numerical solution hit the shared-axis local bound and one expression trust-region bound. Its U07 full weighted training error did not improve over the expression-only control, despite improvements in mouth-only residuals. Real rendering is being used to verify this failure, not to promote a new accepted identity or expand the bounds. Camera sensitivity includes local principal-point nuisance; the separate focal-grid experiment still fixes old R44 principal points and does not exhaust all camera uncertainty. No production page is modified.
