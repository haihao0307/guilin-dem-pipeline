# Original native lower-face relation R57

One independent whole-face outline candidate after the rejected R55/R56 crease experiments. R52 is preserved, and the local crease function is not installed.

The hypothesis is that the current cheek-to-jaw outline narrows too quickly and the chin base is too pinched. Three existing Anny controls are combined: head fullness −0.10 → +0.12, chin width −0.68 → −0.32, mandibular contribution −0.50 → −0.35. The latter remains deliberately restrained to avoid a square or overly heavy jaw. Head height and mouth position/width remain unchanged. The exact effective forward response of each control is checked on current R52 before the combined candidate is rendered.

Photographic comparisons and manual observation coordinates remain private. Approximate projected ratios are not true anatomical measurements. No reference image is deployed. E04 and U07 private observations guide this bounded hypothesis; U05/profile are additional fixed native view checks.

The complete 25,417-vertex native body/head remains the production source. The head identity basis, expressions, owner scheme and rig are retained. Existing hairstyle parameters are reused with roots rebound to the current evaluated head; no new hair/eye development is included. Native eye/skin contacts, mesh degeneracy and inversions, per-region movements and actual multiview appearance are reviewed. Small eye/neck movements under an identity change are reported and assessed with organ relations; the legacy exact-frozen-coordinate threshold is not itself a likeness criterion.

Eight actual frames show the same four cameras/lights/expressions before and after. Exact archive and native-coordinate restoration are required. Full-canvas pixels are measured separately because earlier trials isolated residual differences to the existing hair/eye appearance lifecycle; that fact does not excuse geometry drift. No automatic promotion or likeness percentage is produced.
