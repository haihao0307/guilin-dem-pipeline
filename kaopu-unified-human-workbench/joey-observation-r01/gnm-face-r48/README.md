# R48 native whole-head experiment

One shared head identity candidate on the original fixed KAOPU engine. The previous R45 archive remains the rollback; no production page is changed.

GNM has 170 head, 3 eye and 80 teeth identity coefficients. Only the head coefficients change. Ten conservative macro combinations are derived from native region-mean responses without any photograph targets. The coarse similarity constraint also discards mixed shape directions; it does not establish unique camera/shape separation.

The local/private objective uses dynamic image contours from two previously examined references, with fixed per-photo expression, camera and lighting. No photographs, reference coordinates, detection targets or third-party embeddings are in this directory. Before/after screenshots use the same native engine and same view settings. Small residuals are not likeness acceptance.

The old strict frozen-body/frozen-eye geometry report is retained. This whole-head experiment additionally checks all body vertices outside the source-defined neck transition, full topology, degeneracies, normal reversals, an 8 mm author displacement budget and actual globe changes. Eye/skin contact witnesses require visual and geometric review. These are conservative author limits, not calibrated population priors.

No new hair, eye system, material, body parameters, Anny local shapes or expression fitting. R45 is retained until the true rendered candidate has been reviewed. GitHub Actions uses software WebGL; it is not a physical GPU performance claim.
