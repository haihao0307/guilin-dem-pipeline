# R07 independent whole-face preserving research

This is an unaccepted original-model candidate, not a delivered likeness. The original R64/R65 anchors and production remain unchanged. R04/R05/R06 are archived failures, not comparison targets for promotion.

The current candidate uses the existing 170 GNM identity channels and original Anny local shape controls on the same 25,417-vertex composed head/body. No replacement face, final-mesh warp, foreign weights, original photograph, or image target is included in the public render request. All 52 expression labels and existing body rig remain available.

The new solve penalizes differential deformation within the rounded R64 chin instead of allowing the R04 sharpening. Visible whole-face contour and eyes are fitted together, and lip-rest morphology is investigated at zero jaw action. It does not repeat the failed R06 six-row expression patch.

Native neutral replay is finite and has no reversed baseline normals or new degenerate faces. Sampled mouth gaps are about 1.40 / 1.60 / 1.41 source pixels; these are camera-dependent diagnostics, and actual lip readability requires rendering. The diagnostic visible-tooth raster is zero. After remeasuring the native piecewise controls at the candidate, final prediction differs from native replay by up to 0.0040 mm. Only actual native replay controls QA. Native organ/neck changes and eye contact pairs are retained for image inspection, not hidden behind zero-displacement legacy gates. Small smile, jawOpen 0.05 and brow lift add no orientation warnings. The blink probe retains 18 inherited warning faces and adds none; this is not a global clean-animation claim.

Three native frames compare frozen R64, the new shape with identical display, and a reversible brow-only display test. Camera, light, pixel dimensions, skin setup and old hair stay fixed. The third test gives the two brows independent artistic profile offsets on the existing barycentric skin binding; it does not change the skin. Every native geometry hash is checked before and after display assembly.

These engineering checks do not prove likeness, closed-mouth anatomical collision correctness or expression-quality acceptance. The next decision depends on same-camera actual pixels, face-wide proportional improvement, preserved rounded chin, eye/brow response, lip readability, and absence of new visible contacts. No similarity percentage is claimed.
