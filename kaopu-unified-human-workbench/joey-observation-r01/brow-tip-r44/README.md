# R44: one native brow-root coverage and nose-tip trial

This continues frozen R43 (7467692082dbe807adb4fac1caea8161c95bae02) in the original KAOPU person engine. It is an isolated research candidate, not accepted likeness or a deployed replacement. R30 and R43 remain available. Source reference photographs stay private/local and are not uploaded here.

Three original references U01/U04/U07 were actually reviewed against R43's actual front/oblique/profile images. The actionable visual hypotheses are an overly even/thick brow head-to-tail band and a round nose-tip/alar grouping. Camera pose, lighting and expression differ in the photographs; no photographic millimetres or similarity percentage is inferred. Eye presentation remains a known gap. This candidate does not use expression/blink to disguise it.

Only one native shape value changes: Anny `nose-point-width-incr` −.24→−.44. The fixed exporter uses a separate negative-direction basis for negative input, not the negative of its positive basis. Old response scripts include this axis, but the new composite candidate must be tested on the actual final common mesh before any effect is claimed. All other native archive fields remain identical to R43.

The eyebrow change reuses the existing R17/R42 original GNM component-0 triangle/barycentric root pool and guide supports. It keeps the root pool, counts, seed, original sampling mask, guide walking and fibre material unchanged. `BrowBandProfile.mjs` defines a bounded target head/tail distribution. The ratio of target/original mask weight controls deterministic draw-range thinning of existing strands; rejected roots are never redistributed or refilled. The main middle band remains identical. The target values are head width floor .60, head coverage floor .36, tail width reduction .84 and tail coverage reduction .60. Defaults exactly reproduce R42's original smooth mask. This is an authored grooming-coverage control, not a new anatomical basis. Surviving full guides can still extend beyond the target root band; actual images determine whether the visible contour improves.

Broad face shape, eyes, expressions, body controls, GNM identity, the 8000-strand head-hair code/settings, materials, lighting and three saved cameras are held fixed. Native coupled deformation may still move other final coordinates slightly; those displacements are measured rather than claimed zero.

The renderer first reproduces R43's full native Float32 position hash and all three recorded bare-render pixel hashes from run38118734837. It compares raw bytes of original root/guide triangle indices, barycentrics and template guide points across baseline/candidate/restoration. It captures actual WebGL images, verifies deterministic rendering, finite surface-bound brows, reduced active strand count and exact archive/geometry/pixel rollback. The independent native geometry helper measures real triangle contacts and saved-camera visibility. Before measurement, the renderer sets a 0.1 mm maximum body/eye displacement budget for native cross-layer coupling, and a 1 micrometre ray occlusion tolerance. This is an authored preservation budget, not a physiological safety standard. Exceeding it fails the run and is not silently relaxed. Pair counts are not visible defects; final screenshot review remains required. Open native eye surfaces do not define a solid penetration depth.

The existing isolated read-only GitHub Actions runner is reused: pinned Ubuntu24.04 / Playwright1.57 / SwiftShader, fixed R05 engine and fixed prior hair checkout. No production publication, secrets, permission expansion or other project changes are included. At commit time, local mask tests and source checks have passed; actual CI and image assessment remain pending. Test success alone will not establish likeness acceptance.
