# 人物总平台 · 分层皮肤与嘴唇 R02

在已发布 R01 人物总平台上增加分层组织的颜色传输、区域血色、独立表面脂质和唇红湿润区。界面仍只提供预设与对照；用户审核外观，内部数值由开发者维护。

- 表面脂质/水膜独立控制反射；角质屏障、活性表皮、乳头真皮、网状真皮、皮下散射背景分别参与计算。
- 81 个可见光采样离线生成颜色表，运行时保持原有 16 个片元采样器预算。
- 嘴唇使用较薄的角质屏障、独立上皮/含血结缔组织和肌性背景，不套用脸部油脂或毛孔。唇体结构继续由 ET19 原模块负责。
- 参考用户指定的 [lo-th/head](https://lo-th.github.io/head/) 实际画面，学习柔和外缘、内外干湿分区、细纹和高光的关系；没有复制该站的脸、皮肤贴图或实现代码。
- 「对照上一版」在同人物、同视角、同灯光下切换 R01/R02；人物存档保留组织预设与对照状态。

本机审核入口：http://127.0.0.1:8904/ 。固定公网入口及最终摘要见发布后的 `PUBLICATION.json`。

## 重新构建

安装依赖后运行 `npm run build`。所需色度和血红蛋白数值保存在 `research-data`，正常构建不访问研究站点。`platform.html` 是完整构建页，发布时同字节命名为 `preview.html`；模型继续使用已固定的上游地址。

`HUMAN_ASSET_CACHE` 可指定已校验模型缓存，然后运行 `node serve-local.cjs` 供本机离屏检查。缓存、教师站点下载副本和研究截图不提交。

医学/光学依据、参数类别、失败尝试和函数归属见 [皮肤知识记录](docs/skin-knowledge/README.md)。这是研究启发的实时外观近似，区域厚度和血管分布是本项目估计，不是个体医学测量。测试通过与用户美术验收分开记录。

原人物整合来源见 [SOURCES.md](SOURCES.md)。CIE 数值及衍生颜色表按 [CC BY-SA 4.0](licenses/CIE-DATA-NOTICE.md) 标注，其他既有许可继续有效。
