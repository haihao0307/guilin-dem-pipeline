## 资料台账与阅读范围

1. **Steven L. Jacques, Skin Optics, OMLC, 1998**：[原文](https://omlc.org/news/jan98/skinoptics.html)。已读表皮/真皮部分、公式及其局限。采用色素吸收、含血真皮和波长相关约化散射的近似；原作者明确提示个体差异，部分基线来自离体/新生儿或动物数据，不能当成本人物测量。
2. **Scott Prahl, hemoglobin compilation, OMLC**：[说明](https://omlc.org/spectra/hemoglobin/)、[数值表](https://omlc.org/spectra/hemoglobin/summary.html)。已读换算和数值列。按 `2.303 ε c / 64500 / 10` 从摩尔消光系数换算到 `mm^-1`；150 g/L 是参考设定。构建使用数值 CSV，不分发网页正文。
3. **CIE 1931 2° observer**：[数据 DOI](https://doi.org/10.25039/CIE.DS.xvudnb9b)。已读取原 CSV 和元数据、核对原 MD5/SHA256，使用色匹配函数。
4. **CIE D65**：[数据 DOI](https://doi.org/10.25039/CIE.DS.hjfjmt59)。已读取原 CSV 和元数据并核对校验摘要，使用标准日光谱。以上两组及衍生数值表按 CC BY-SA 4.0 标注。
5. **Gomi & Imamura, 2019, upper lip vermilion vasculature**：[全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC6594803/)。已读组织观察、上层真皮定义和局限：血管/上皮界面关系支持单独处理唇红；样本为 14 位女性供体，不能推广成全部人群的精确参数。
6. **2004, vermilion surface function study**：[摘要](https://pubmed.ncbi.nlm.nih.gov/15030342/)。仅通过索引摘要读取屏障/保水差异，不声称阅读全文。用于区分唇红屏障与普通面部皮肤。
7. **Facial thickness studies**：[2022, 118 人超声研究](https://pubmed.ncbi.nlm.nih.gov/35710358/)、[2005, 三名供体组织学](https://pubmed.ncbi.nlm.nih.gov/15861089/)、[2025/26, 45 人高频超声](https://pubmed.ncbi.nlm.nih.gov/41375703/)。已读摘要。用于确认部位差异及测量方法差异，不把任一总体均值映射为本人物真值。眼睑/颞部薄、鼻/额部较厚的场仍属项目估计。

## 数据与计算

`TissueLayers.json` 保存组织次序、物理单位、厚度设定、来源、预设和估计标签。厚度使用 mm；吸收和约化散射使用 mm⁻¹。cm⁻¹ 到 mm⁻¹ 必须除以 10。色素与血液量的艺术控制先转为描述性的体积分数范围，不把 UI 档案中的 0–1 数字当成临床浓度。

`spectral-transport.cjs` 在 380–780 nm 以 5 nm 间隔处理 81 个采样。每层采用本项目自主实现的有限平板双通量近似：K=μa，S=μs′/2；`a=1+K/S`、`b=sqrt(a²−1)`，由有限厚度求 R/T，再将底层返回光逐层合成。S=μs′/2 是本项目的闭合选择，不是从所引医学资料中复现的精确输运。只把单个对称平板放在顶层，使用 `Rtop + Ttop² Rbottom/(1−Rtop Rbottom)`；这不是完整相函数、折射边界或 Monte Carlo 输运。

按 CIE 1931 与 D65 积分得到 XYZ，再转线性 sRGB。用于屏幕颜色的是 81 波长结果；GLSL 中三个代表波长仅估计角度扩散宽度，不再直接充当皮肤 RGB 颜色。

计算表包含色素、表浅血液量、相对厚度、深层微脉强度四个连续维度，另有三个组织预设与皮肤/唇红两种组织类型，共 98,304 个 texel。RGB 以 16 位定点保存。`SpectralTable.mjs` 解码到 Float32 后追加到已存在的 512 宽毛孔表尾部，不覆盖原毛孔或 BioSkin 行，不增加纹理采样器；手工四维插值。

**外观校准**：无个体测量，不能把绝对双通量颜色视作真实肤色预测。本版以原 BioSkin 的中性肤色作为身份锚点，用分层光谱结果相对于中性部位的比例来调整各区域。膜反射、角度扩散和微起伏独立计算。这是明确的外观校准，不伪装成医学复现。

## 本轮失败尝试与修正

- 三个波长直接当 RGB：实拍偏灰、唇红偏紫，弃用可见颜色路径。失败观察保留在本节；初轮临时截图随后被后续捕获覆盖，不作为最终交付证据。
- 未校准的 81 波长双通量绝对颜色：实拍过浅偏橄榄色，不能当作真实个体预测；加入明确的中性身份锚定。
- 第一次共享表接线：编译器报告采样器声明顺序错误；移到使用之前并去重。最终重新捕获，不用失败构建证明结果。
- 唇红直接替换底色时丢失原外缘淡化：恢复 ET19 过渡，再增加较干外侧的平滑混合，避免像整片上色。
