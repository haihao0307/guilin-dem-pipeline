## 实际合并方式

`r06-preview.html` 是固定 R06 运行时，SHA256 为 `b33c0a651570f2671ac61ea546279abfe06ebb07c966a70964e428df966420fd`。`build-platform.cjs` 先校验它，再对精确锚点接入无损眼材质兼容层、皮肤和新 UI。读取既有原生权重，不替换人物网格或眼球。

`integration/merge.mjs` 是适配入口：

- 眼睛三个原 PNG 解码逐像素摘要保持一致，合为三层数组。血丝仍单独读取，减少两个片元采样器。
- BioSkin 表附加到已有毛孔 Float32 表尾部，毛孔记录保持不变。重新生成毛孔表时继续附加，人物切换后不会丢失肤质数据。
- 皮肤档案接入完整人物保存/恢复。眼色和唇部选择在切换人物时保留，避免按钮与实际结果不同步。
- 摄影视角不调用会重建人物的调试归零入口。保留同一人物实例。
- 采用 R03.1 的中性环境、三灯与摄影构图。补光不额外产生阴影图，避免突破常见 16 片元采样器预算；不叠加原 R03 局部皮肤着色器。
- 沿用皮肤 R02.1 的耳部灯光适配方法：R06 耳廓遮挡与透光场按实际三盏摄影灯重算，而不是继续读取已经隐藏的旧灯组。

## 前台界面

`platform.js` 与 `platform.css` 为可读 UI 源码。前台没有滑杆或数值调整框，仅保留人物、眼色、唇部、体型、肤质、灯光和状态预设，观察视角，以及人物/PNG/审核记录保存。审核文件在浏览器本地下载，填写内容不会自动发送到外部服务。

`portraits.json` 中的卡片缩略图来自本轮真实三维画布，未使用生成图片或第三方人像。主画面始终是可旋转三维人物。

## 构建与检查

1. 使用 esbuild 将 `integration/merge.mjs` 打包为 `integration/merge.bundle.js`。
2. 运行 `node build-platform.cjs`，输出 `platform.html`；发布时同字节保存为 `preview.html`。
3. 运行 `qa-extended.cjs`。其测试使用离屏浏览器，不接管桌面鼠标。GitHub 下载代理仅供本机验收；发布页面保留原固定 HTTPS 模型地址，不依赖代理。
4. `QA_BACKEND=d3d11-warp` 可检查 Windows 的实际 16 片元采样器环境。测试报告与截图应对应最终 HTML 摘要。

测试不等于用户美术验收。原眼睑、唇缘、耳根及极近景的几何和皮肤近似仍可根据用户审核继续改善；不将合并完成描述为影视级或所有显卡认证。

## 许可与资产边界

继续沿用既有原生模型、眼部纹理、皮肤与 Three.js 的许可和署名；原分支中的来源及声明仍有效。新增适配不引入新的外部头模或皮肤贴图。BioSkin 为原皮肤分支已经离线生成的固定二维切片，不是完整光谱输运或生理测量。

## 本轮追加：毛孔、柔透组织与皮下微脉

`integration/DermalOptics.mjs` 为本轮原创视觉实现。毛孔与细微表皮起伏使用固定原生坐标、确定性空间种子、像素足迹过滤及有界法线斜率；不通过画黑点代替毛孔。新增微孔半径 24–40 微米、起伏上界约 8 微米均为艺术配置，不是真人测量。既有表面采样毛孔同时保留。

柔透预设结合已有的 25 tap RGB 漫反射扩散与分色角度展宽。扩散只处理面部漫反射，高光保持独立；耳部继续使用 R06 的组织厚度/遮挡场。皮下微脉是原生静止空间中、带深度模糊和色素衰减的柔和曲线吸收，主要分布在颞部与上颊，不抬高网格或制作表面凸管，也不是实际血管解剖重建。新增光学层没有增加纹理采样器。

前台提供自然肌理、柔透组织、薄肤微脉三组质感预设，与六种基底肤质独立组合。默认柔透组织。原皮肤对照会同时退出新扩散，恢复新皮肤时按所选组织预设重新启用。新增质感选择随人物档案保存、恢复。

研究依据只用于方法原则：NVIDIA 的[实时皮肤渲染章节](https://developer.nvidia.com/gpugems/gpugems3/part-iii-rendering/chapter-14-advanced-techniques-realistic-real-time-skin)说明表面反射与漫反射扩散的分离；Disney 的[次表面输运工作](https://disneyanimation.com/publications/practical-and-controllable-subsurface-scattering-for-production-path-tracing/)用于核对扩散近似与体积路径追踪的区别。这里采用有界实时 RGB 外观近似，不宣称是完整皮下组织输运或医学模拟。
