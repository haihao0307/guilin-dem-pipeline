# 展示台镜头与对照规则

记录日期：2026-10-21（北京时间）  
适用版本：蕾丝工作台 R02 起。  
约束来源：用户对正常美术透视、观察方式与质感对照的明确要求。

## 1. 需求含义与范围

用户要求正常的**近大远小透视**。本轮展示改动的中心是相机投影、取景、缩放及对应尺度说明；页面布局与已有结构、材质控制沿用。

本文件作为今后展示台的默认镜头与验收约定，供接手者复用。本轮只在本项目记录并落实相应规则；没有创建全局个人技能，也不代表其他展示台已经更新。

## 2. 默认镜头

| 项目 | 默认要求 |
| --- | --- |
| 投影 | `PerspectiveCamera` |
| 垂直视场角 | 固定 **38°** |
| 近远关系 | 相同真实尺寸的物体，距镜头近时投影更大，远时更小 |
| 缩放操作 | 改变相机与观察目标之间的距离 |
| 观察模式 | 整体、微距、侧面、背面共享同一透视相机及相同 FOV |
| 模式差别 | 可改变观察目标、距离与角度；投影性质保持一致 |
| 窗口尺寸变化 | 更新 aspect 与 projection matrix，保持38°垂直FOV |
| 模型尺寸 | 缩放观察不改变材料坐标、线径或模型真实尺寸 |

当未来明确需要正交测量模式时，应作为单独标识的测量工具加入；默认外观观察继续采用上述透视镜头。不得把正交相机的视域变化标为正常透视。

初始取景可先根据观察平面的目标可见高度计算距离：

\[
d=\frac{H_{view}}{2\tan(38^\circ/2)}.
\]

这是相机目标平面上的估算。旋转、弯曲和有厚度的物体需要依据包围体增加取景余量，并检查近裁剪面；不能只按平面高度设置距离后任由近端被裁掉。

## 3. 观察模式与交互连续性

整体视图负责呈现完整形态和疏密关系；微距负责线体截面、填充方向及细网；侧面负责厚度和交叠；背面负责同一结构的反面。每个模式保持真实透视。

滚轮与触控缩放使用距离变化。拖动、平移、模式切换之后，观察目标与取景距离应有连续、可预测的关系。不得用持续扩大FOV来替代靠近物体，否则透视强度会随缩放无意改变。

用户改变线径或材料参数时，保留当前镜头以便判断变化；选择不同尺寸的花型预设、整体视图或重置时重新取景。保存观察配方记录 FOV、可恢复距离的取景高度、中心偏移和方向，保证同一结构能够恢复相同观察条件。

## 4. 尺度标注的边界

透视画面不存在覆盖整张屏幕的单一“像素/毫米”比例。屏幕尺度尺须标明：

> 中心参考平面尺度

它表示通过当前观察目标、与视线垂直的参考平面上的长度。相同标尺不能直接用于弯曲布样的近端、远端或倾斜区域。

对位于相机前方距离 \(d\) 的该平面，垂直可见范围是

\[
H=2d\tan(38^\circ/2).
\]

平面的水平范围为 \(H\times\mathrm{aspect}\)。页面布样尺寸及线径仍以材料坐标计算；这些真实尺寸不依赖镜头。倾斜或弯曲表面的精确测量需要结合该处表面位置与相机投影，不能直接套用中心标尺。

## 5. 可重复对照协议

每次比较先记录源码版本、生成器版本、完整配方、seed、颜色、线径、花型尺度、曲率、相机参数、灯光、曝光、背景、画布尺寸、设备像素比及浏览器环境。

**镜头变化和材质变化分别验收。**镜头对照检查同尺寸物体在近远位置的投影变化；材质或花型对照统一使用38°透视镜头、相同目标点、距离、角度和灯光。不能把近端放大后更容易看见细节，算作材料本身提升。

对照时仅改变待验证项，至少观察整体、微距和侧面。一次调整了多个因素时，应明确记录，避免把结果归因给其中一个滑块。

旧版若只有正交截图，可作为历史参考；它不满足相同投影条件的材质对照。需要在统一镜头下重新呈现旧版结构/材质，或明确列出比较条件的差异。

## 6. 三类证据分别记录

| 证据 | 能支持的结论 | 需要保留的边界 |
| --- | --- | --- |
| 二维结构图或 Canvas 缩略图 | 花型、路径分布、空隙和语义层关系 | 不能验证三维厚度、光学、阴影或实际GPU质感 |
| 数值与自动化检查 | 单位、配方恢复、有限数值、路径/几何统计、投影关系 | 不能仅凭通过数量宣布视觉达标 |
| 实际浏览器三维渲染 | 当前版本的光照响应、侧面厚度、主要交互及可见问题 | 需记录浏览器、渲染后端和验证范围；一次观察不代表全部设备 |

实际浏览器观察需辨明渲染后端。软件渲染截图仍可用于排错，但不能标为硬件GPU性能证据。手机视口模拟也不能标为手机实机验证。

效果结论必须与对应版本和观察条件绑定。未经观察的模式、性能指标、移动设备或布料物理不填写通过。本轮具体执行结果由 `VALIDATION.md` 单独记录；本文件不预写验收结果。
