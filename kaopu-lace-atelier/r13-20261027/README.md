# R13 蕾丝质感候选 · 2026-10-27

打开 `index.html` 是完整三维工作台；`qa/compare.html` 是可拖动的新旧截图对照，`qa/cut-end-compare.html` 是真实裁切线端的三维对照。所有运行依赖均内嵌在各自 HTML 内。R12、R08 及其他旧目录未改动。本轮只推进外观和相关调节，物理保持后续阶段。

## 本轮完成的效果

1. **针群走向**：完整花瓣、叶片内部的针路按同一个连续场成组转向。默认 0.65；不再只是逐针加弯。当前玫瑰藤蔓覆盖 27,914 / 30,576 根填针（91.29%），保留所有原端点、Z 高度、线径和采样数量；裁切花片保留旧针路。侧光下规则排杆感有所减轻，仍有明显程序化排列特征，未达到实布验收。
2. **纤维整体柔和度**：逐层独立调节。柔棉填绣默认 0.8；丝光 0.2；细网 0.3。柔棉圆柱式受光变柔，丝光保留顺线亮部，细网保持细线和孔隙。棚光下棉与丝的区别仍较克制；掠射光下棉可能更亮，不能声称所有光照都更均匀。它是受光与纤维方向的外观代理，未完成实测 BSDF。
3. **裁切线端闭合**：仅闭合生成器明确标记的裁片截断端，消除近察中的空心管口。自然针脚端、未标记开口和闭合线环保持原状；不声称整布拓扑封闭。默认玫瑰藤蔓新增 2,117 个端面、15,560 个绘制三角形。
4. **控制与证据**：新增参数参与完整保存/载入、旧配方中立回退、预算失败恢复。加入馆藏结构资料及授权来源。三种材质 × 三种微距布光均保存 R12/R13 原始截图；另有整布、线体、侧背面、其他花型和真实端面对照。

## 使用调节

- 结构 → **针群走向**：0 保留 R12 针路，0.65 为当前建议值；不改变花瓣边界附着点。
- 线材 → **纤维整体柔和度**：即时修改当前层受光；0 恢复旧模型。调节不会增加毛羽根数或几何。
- 线材 → 光泽、纱束与毛羽 → **裁切线端闭合**：只重建当前层线芯，毛羽缓存可保留。
- **R12 质感基线 / R13 针群候选**：在当前花型和相同镜头、布光下切换冻结 R12 材质 + 针群 0 与 R13 材质 + 针群 0.65。它不是完整旧版默认页面重播。切换材质预设会保留独立结构调节；需要完整候选时再点 R13。

最终测试 174 / 174 通过。完整花型与三材质的针群及裁切端数值检查通过；毛羽附着继续使用实际线体采样。默认玫瑰藤蔓柔棉提交 4,226,048 个三角形，保留几何缓冲 179,470,784 字节，相比 R12 的 178,141,328 字节增加约 0.75%。这是几何缓冲统计，不是总显存或帧率。
