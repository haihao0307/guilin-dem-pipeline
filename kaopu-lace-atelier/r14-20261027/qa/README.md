# R14 预览证据

`r14-interlace-comparison.png` 比较相同叶片、柔棉、镜头和掠射光下的原针脚与密交织；`r14-weave-materials.png` 比较同一交织结构的柔棉、丝光和细网。对应原始整页截图同目录保存。

`r14-atlas-desktop.png`、`r14-reference-expanded.png` 展示参考图集和布样旁的参考；`reference/ATLAS-SOURCES.json` 包含馆藏来源与图片授权。

交织成本与扫掠结果保留在 `r14-interlace-cost.json`、`r14-interlace-sweep.jsonl`、`r14-interlace-large.jsonl`；`r14-leaf-studies.md` 记录未采用的尝试。测试与可复现工具位于 [固定源码版本](https://github.com/haihao0307/Human-Fabric-Workbench/tree/1c984dc0825388aed4d1ceb5d0751ee8132bc9fc/experiments/lace-visual-r14-20261027)，不包含在本预览包。

本机 HTTP 预览与静态依赖检查通过。由于浏览器 URL 安全策略阻止，单文件 `file://` 双击直开未验证。画面与几何检查不能代替同尺度实物、工艺连接、动态稳定性或成衣物理验收。
