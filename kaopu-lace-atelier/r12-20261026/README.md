# R12 · 柔棉、丝光与细网分化

独立交付文件：`index.html`。所有运行模块、Three.js、着色器、样图与样式已封装在同一文件。工作台内有 R11/R12 材质切换、分层参数和完整 JSON 保存恢复。

本轮按“视觉优先、物理次要”推进，保留 R11 与之前目录。此目录是研究候选，未做真实样布验收；不合并或部署替换旧版。

## 已完成与效果

1. **线体轮廓与柔棉填绣。** 新增 `bundleProfile`，在原纱线表面上添加有界的宽瓣纱束包络，最大半径变化 ±12%，不额外增加采样或三角形。柔棉填绣截面厚度 .48→.32、粗糙度 .78→.86、高光 .22→.14。展示配方填线 .14→.17 mm、针距保持 .18 mm，减少填绣中分隔细条的观感。截面变化本身较微弱，连片感主要来自明确的展示线径和棉线配方调整。
2. **三种材质的差别。** 丝光新增归一化的定向反射集中分布；柔棉保留宽而弱的高光；细网使用实际半径减细。当前名义填线直径分别为棉 .170、丝 .164、细网 .113 mm，底网分别为 .075、.074、.053 mm。差异在微距/侧光中较清楚，棚光整布下棉与丝的差异仍较克制。新控件均可按层调整；名义线径旁明确提示局部包络会改变宽度。
3. **验证与可复查交付。** 149 项检查通过；18 张最终后台浏览器原始截图均为静止 32 样本。提供独立截图滑动对照 `qa/compare.html`、三材质摘要和完整数值记录。实际保存再载入恢复截面 .43、减细 .31、集中度 .63；故意超预算后保留成功布样、已生效参数及 .18 mm 针距。

R11 按钮冻结的是历史材质参数，应用于**相同当前结构**；它不重现 R11 完整历史默认场景。完整旧版仍在相邻版本目录。新增字段为 0/缺失时，纱线/两种毛羽表示的缓冲区及相关着色器分别与冻结 R11 精确一致。

## 技术证据与限制

- 实际生成→摆放→绑定→Float32 扫掠的 72 组局部检查无新增朝内、倒走、反向、退化或非有限缺陷。继承的极端裁切轮廓缺陷仍记录，未翻法线隐藏。最终完整 botanical 三材质四层未检出这些缺陷。
- 最终完整 botanical：239,869 段，75,053 根棉毛羽，4,205,592 个提交三角形，178,141,328 B 几何缓冲。相同当前结构的 R11 材质对照具有相同数量/字节成本；这不是显存或帧率测量。未宣称提速。
- 新包络保留中线/种子/采样与索引数量；高曲率、极短段按整个路径衰减或保留原外形。毛羽共用真实表面采样；减细到 55% 时附着残差检查也通过。
- 试过 .14 mm 针距，但完整 botanical 触发已有 250,000 段预算，候选被明确拒绝，没有提高预算、缩小布样或暗中简化。
- 丝光集中分布改变方向，不增加总相函数积分；仍是艺术化纱束代理，不是实测 BSDF。线芯孔口、工艺连接、真实背面载纱仍未完善。
- 浏览器通过 HTTP 验证。既有 `file://` URL 安全策略阻止实际双击测试，未绕过；静态内嵌检查不能代替实际双击运行验收。
- 物理仍是观察弯曲，没有新增重力、接触、碰撞或拉伸解算。

## 后续路线

1. 优先处理仍存的规则针条感：连续纤维、针脚分组和局部组织，在整布尺度复查，避免只添加微距噪声。
2. 用有尺度的真实柔棉/丝光/细网样布做同光照对照，进一步校准棉与丝的区别。
3. 处理裁切开放端面、明确的工艺连接和背面载纱；再做运动闪烁、多设备性能和实际双击验收。
4. 外观稳定后再接入成衣重力、接触、碰撞与拉伸物理。
