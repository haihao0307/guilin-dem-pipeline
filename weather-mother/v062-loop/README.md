# Weather Mother V0.6.2 Loop

在线入口：https://haihao0307.github.io/guilin-dem-pipeline/weather-mother/v062-loop/

本版本基于用户反馈“目前来看效果还是可以的，基本上是OK的”的 V0.6.1 HQ r3 继续制作。V061 的四个运行文件保持原样，可用于回看、比较与回退。用户对 V061 的基本认可不等于最终 3A 质量认证。

## 本轮已实现

同一种子在连续周期内演化，周期 12 至 300 秒，默认 60 秒；变化幅度、循环进度、形态冻结、回到起点均可操作。形态周期位于云的局部空间。风引起的世界位移、晨昏、雨雪及飞机拥有各自时钟，因此形态闭合不等于整个动态画面的所有元素同时闭合。全局暂停可以冻结这些时钟。种子切换保留，十种云属和原工作台控件保留。

保守空区缓存由原密度数据的非零支持域生成，加入覆盖细节形变和插值的扩张量，提前排除确定无云的样本。开关对照保留完全相同的图像分辨率和射线步数。本轮未实现距离场 DDA 大步跳跃，也未宣称所有显卡都会获得显著提升。

细节按照当前采样所能分辨的尺度平滑；时间重建在形态变化较快时降低旧帧权重，在闪电事件时拒绝旧光照。这些改动需要继续接受高分辨率、快速相机运动和真实 GPU 的视觉检查。

闪电采用确定性的局部事件，包含主放电通道、分支通道和云内照亮。可调事件频率、亮度，也可单次触发。普通晴日默认不启用闪电，雷暴案例启用。它是图形近似，没有电荷分离或放电物理求解器。

## 已完成的检查

构建与公开网址分别完成 34 项自动检查。公开发布的五个运行文件均返回 HTTP 200，并与构建哈希一致。

固定外部时钟和相机后，0% 与 100% 形态循环的实际浏览器画面逐像素一致。0% 与 50% 有可测变化。保守空区开关前后的测试画面逐像素一致。十种云属、浓度、独立云速、全局暂停及闪电实际像素变化通过检查。

检查环境为 Chromium 151 和 SwiftShader。这里只把它用于功能、数值和发布检查，未将其帧率当作用户显卡的帧率。

`QA.json` 保存部署前检查，`PUBLIC_QA.json` 保存公开网页检查，`PUBLICATION_RECEIPT.json` 保存公开字节与哈希。`PERFORMANCE_AB.json` 保存同场景、同采样和同分辨率的开关对照；measurementRevision 2 才强制等待每个窗口的新完成帧，前一测量版本不可用于推断速度增益。

## 体量与资产

五个运行文件的未压缩代码合计 66,157 bytes。运行时的密度、噪声、光学深度与占用缓存另占浏览器内存，不计为源文件体积。仓库没有新增云照片、HDR 图片、噪声图片、成品云模型或生成图。截图只在测试进程内存中比较，提交的 QA 为数值记录。

## 气象规则

`WEATHER_RULES.json` 记录对流、层状、高空冰云、山地及光学规则。台风的眼、眼墙、螺旋雨带、外围云盾和高空外流仅建立规则，台风渲染和流体模拟尚未实现。真实天气接入、大世界分块流送、完整地形风场和飞机气动力求解同样未完成。
