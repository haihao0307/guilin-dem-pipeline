# Weather Mother 光影工作室 0.1.1

在线入口：https://haihao0307.github.io/guilin-dem-pipeline/weather-mother/method-v100/lighting/

本目录是 method-v100 最小积云样本的展示层扩展。完整 Clean V1.0 天气工作台、冻结交付 ZIP、Ocean Mother、地形和权威数据保持原样。它没有替换所有云属和天气案例的生产渲染。

## 本轮内容

五组可切换照明：日光体积、清晨暖光、黄昏透光、逆光银边、冷色月光。它们是工作室灯组预设，未宣称地理太阳历或真实气象校准。

主光、辅光、轮廓光均可独立开关，并调整相对强度、方向、仰角、sRGB 颜色和柔光角。灯组旋转及展示曝光单独保存。旋转灯组不推进湿度历史或改写云体数据。

工作室阴影采用细节近距离采样与标量源场远距离光学厚度近似。多重散射使用有界的外观近似，减少补光把内部层次洗白的现象。柔光角采用确定性的锥形采样，当前没有真实面积光源、lux、Kelvin 或光谱校准。

## 检查模式

中性检查保留原来固定相机、灯光、曝光和色彩处理。工作室具有独立的高动态范围色调处理。诊断提供光学厚度、对象 z=0 浓度剖面、云内加权深度，并显示图例。

标准、精细和特写的工作室射线样本数分别为 144、224、384。原中性和诊断检查仍用 144。页面明确显示原生像素与页面显示尺寸。精细档原生上限为 1440×900，特写上限 1920×1200；不以 CSS 放大宣称增加原生渲染细节。
