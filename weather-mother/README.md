# Weather Mother

公开入口只有 `https://haihao0307.github.io/guilin-dem-pipeline/weather-mother/`。

默认进入 World，并运行受保护的 `v110-full` 原云与天气系统。界面关闭时只保留一个 WM 按钮。打开菜单后，点击 Rain 会直接进入 `liquid-rain-v130`，中间不再出现 Rain 子菜单和 Liquid Rain 二次选择。

Fog、Snow、Cloud、Storm 继续使用 `v110-full` 已有天气案例。

常规交付只向用户发送一个已完成公网与浏览器验证的直接网址。只有用户明确索要时才发送包、附件、截图、哈希或 QA 资料。
