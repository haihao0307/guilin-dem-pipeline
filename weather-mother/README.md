# Weather Mother

公开入口只有 `https://haihao0307.github.io/guilin-dem-pipeline/weather-mother/`。

默认进入 World，并运行受保护的 `v110-full` 原云与天气系统。界面关闭时只保留一个 Liquid Glass WM 按钮。点击 Rain 会直接进入 `liquid-rain-v130`。

iPhone Max 竖屏使用底部面板，横屏自动转为右侧面板。两个方向都处理安全区、触控尺寸和画面遮挡。Rain 调节分为降雨、云源、地面水、湿玻璃、屋瓦砖墙、镜头六组。

Fog、Snow、Cloud、Storm 继续使用 `v110-full` 已有天气案例。常规交付只向用户发送一个完成公网与浏览器验证的直接网址。
