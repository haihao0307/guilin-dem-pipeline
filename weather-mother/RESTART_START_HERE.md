# START HERE

1. 阅读 `HANDOFF.json`。
2. 阅读 `CANONICAL_BASELINE_LOCK.json`，确认 `v110-full` 原云系统未被改写。
3. 阅读 `REJECTED_ROUTE_GUARD.json`，禁止恢复已清除的替代路线。
4. 从 `index.html` 进入 Weather Mother，默认模块必须是 World。
5. 从侧边 Weather Mother 抽屉进入 Rain、Snow、Fog、Cloud 和 Storm。
6. Rain 的当前候选只有 `liquid-rain-v120`。
7. Fog、Snow、Cloud 和 Storm 沿用 `v110-full` 已有天气案例，未得到用户明确要求前不得另造系统。
8. 后续真实环境验证继续使用交接中登记的桂林与 GAEA 入口。
