# START HERE

1. 读取 `HANDOFF.json`、`CANONICAL_BASELINE_LOCK.json` 和 `REJECTED_ROUTE_GUARD.json`。
2. 从 `index.html` 进入 Weather Mother，默认模块必须是 World。
3. `v110-full` 原云系统受保护，未经用户明确要求不得替换。
4. 界面默认收起，手机只保留 44 px WM 按钮。
5. 菜单层级固定为 Weather Mother → Rain → Liquid Rain → 参数分组。
6. Rain 当前候选只有 `liquid-rain-v130`。
7. Fog、Snow、Cloud、Storm 沿用 `v110-full` 已有案例。
8. 常规交付只发一个已验证的公开网址。
