# START HERE

1. 读取 `HANDOFF.json`、`CANONICAL_BASELINE_LOCK.json` 和 `REJECTED_ROUTE_GUARD.json`。
2. 打开 Weather Mother 必须默认进入 World，`v110-full` 原云系统继续受保护。
3. 界面默认收起，只保留 48 px Liquid Glass WM 按钮。
4. 点击 Rain 必须一步进入 `liquid-rain-v130`。
5. iPhone Max 竖屏使用安全区底部面板，横屏使用右侧面板。
6. Rain 调节分为降雨、云源、地面水、湿玻璃、屋瓦砖墙、镜头六组。
7. Fog、Snow、Cloud、Storm 沿用 `v110-full` 已有案例。
8. 常规交付只发一个已验证的公开网址。
