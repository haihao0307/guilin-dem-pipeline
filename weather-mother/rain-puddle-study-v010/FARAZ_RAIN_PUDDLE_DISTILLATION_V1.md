## 2. 源码明确支持的结构

### 2.1 统一的五秒降雨渐入

`src/useMakeRain.ts` 用一个共享的 `rainProgressRef` 在五秒内线性从 0 变化到 1。渲染、地表材质和声音都读取同一个进度值。

蒸馏规则：天气事件先有统一状态，再由视觉、材质和声音分别读取。各通道允许使用不同响应曲线。

### 2.2 雨滴

`src/Rain/Drops.tsx` 使用 1000 个实例化平面。平面朝向相机，逐帧下降，到达地面后重新随机生成。片元着色器用不均匀胶囊距离函数生成细长水滴轮廓，透明度再乘降雨进度。

蒸馏规则：

- 大量降水应使用实例化。
- 雨滴轮廓需要软边和细长非均匀形状。
- 粒子循环与相机朝向分离。
- 透明度应随天气状态渐入。

Weather Mother 的改进：演示版将长度绑定到终端速度与快门时间，并拆出近景、中景和远景雨幕。

### 2.3 水洼材质

`src/Floor/PuddleMaterial.tsx` 在道路 PBR 材质上追加自定义着色逻辑：

- 使用 sFBM 噪声形成不规则水洼区域。
- `roughnessProgress` 在降雨进度 0 至 0.75 之间推进。
- `normalProgress` 在 0.75 至 1.0 之间推进。
- 水洼区域先降低粗糙度，随后才逐渐加入水面法线和涟漪。
- 涟漪在 3 × 3 邻域内使用哈希随机中心、独立相位和传播半径，累积为法线扰动。

蒸馏规则：

- 湿润、积水和涟漪必须分阶段出现。
- 水洼边界由连续噪声场生成，不能铺满规则圆环。
- 每个涟漪有独立中心、相位、半径和衰减。
- 水面效果应接入原地表材质，避免用完全独立的透明平面替换地面。

### 2.4 飞溅

`src/Rain/Splashes/index.tsx` 使用 1000 个实例化平面和 4 × 5 翻页图，使用加法混合。`useSplashPositions.ts` 遍历场景网格，构造 `skyWeight`，只把法线朝上的顶点作为表面采样权重，再用 `MeshSurfaceSampler` 分配飞溅位置。

蒸馏规则：

- 飞溅位置由可受雨表面的几何方向决定。
- 每个飞溅拥有独立生命周期。
- 动画相位与位置分离。
- 顶部朝天只是基础筛选，生产版还需要遮挡、雨量通量、材质和坡度约束。

Weather Mother 演示版用程序化飞溅轮廓替代原 4 × 5 翻页图，避免复制资产。

### 2.5 声音

`src/Rain/index.tsx` 使用 Howler 同时启动循环雨声与夜间环境声。两条声音在用户开始降雨后才播放，符合浏览器的用户手势要求。雨声增益使用 `min(progress, 0.5)`，夜间环境声使用 `min(sqrt(progress), 1)`，说明声音共享同一状态，但响应曲线不同。

`src/Rain/Thunder.tsx` 把一段雷雨音频切成两个音频 sprite，在 5 至 20 秒的随机间隔触发。雷声播放期间，Simplex 噪声控制高亮环境面板的透明度，形成声音与闪光的同一事件。

仓库内还存在 `howling-wind-14892.mp3`，当前源码没有引用它，因此不能把风声描述为原运行版已接入功能。

蒸馏规则：

- 声音必须在用户手势后启动。
- 雨、环境、风、滴水和雷声应分层。
- 同一天气状态可以通过不同曲线控制不同声音层。
- 雷声与闪光属于同一个事件对象。
- 雷声触发间隔需要随机化。

Weather Mother 的改进：本演示不使用原 MP3。Web Audio 程序化生成雨噪、积水击打、低频环境、风和雷声。闪光后根据距离与声速计算雷声延迟。

### 2.6 光照与画面整理

`src/Lights.tsx` 使用上海外滩 HDR 作为环境；雷暴闪光嵌入 Environment。`src/App.tsx` 使用轻微 Bloom、ToneMapping、对比度、饱和度、亮度和三层 CSS 渐变进行最终分级。

蒸馏规则：

- 水面质量高度依赖可读的环境反射。
- 闪电应改变环境光，不只画一条电弧。
- 细雨需要在高亮反射和暗背景之间获得可见性。
- 后期分级应作为明确的一层保存。

## 3. 本次独立演示

目录：`weather-mother/rain-puddle-study-v010/`

实现：

- 世界空间近景与中景雨带。
- 三层远景雨幕。
- 终端速度与快门时间控制雨线长度。
- 湿润先行、水洼随后、涟漪最后出现的阶段状态。
- 不规则连续水洼场。
- 多中心、多相位、多半径涟漪。
- 程序化飞溅。
- 金色与冷色环境反射。
- 程序化路面颗粒与散落物。
- 程序化雨声、积水击打、夜间底噪、风和雷声。
- 闪光与按距离延迟的雷声事件。
- 手机进入后控制面板默认关闭，调节完成后自动进入纯画面。

## 4. 当前边界

- 本演示是结构蒸馏样板，没有宣称复刻原作者画面或商业级真实流体。
- 没有真实 HDR、道路扫描材质或录音，环境与声音均由程序生成。
- 原源码对飞溅的筛选只读取表面朝向，本演示还没有接入完整的建筑遮挡和真实地形雨影。
- 人工视觉批准、3A 批准、生产批准保持关闭。
