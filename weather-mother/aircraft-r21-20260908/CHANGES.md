# R21 云间驾驶

新增第三人称三维飞机，银边积云/层叠云海两场景可驾驶。开始飞行或按驾驶键起飞；W/S 改速度，A/D 侧倾转弯，Q/E 升降，拖动环顾完整一圈，空格暂停，Home 返回起点。屏幕控制支持按住。原 R20 观云、R14 自由飞行及原天气页面保留。

渲染范围：远景由原 R20 艺术云场作连续方向映射，属于远处环境，未将原图中每团云完整重建成可碰撞三维实体；近场复用 R14 米制三维密度，2 km 观察范围内平滑淡出，飞机实体深度截断体积积分，前方云雾参与遮挡。飞机运动没有旧 R20 相机的小范围限制。R14 云域边界有限，离开云域不生成无限新气象。云密度为形态/消光代理量，不是已标定液水质量密度。

飞机为项目原创可编辑低翼通用小飞机：make-aircraft.py、aircraft-mesh.json、cloud-tourer.glb。实际 WebGL 渲染 2292 三角形、一次飞机几何绘制，无外部模型或贴图下载。运行顶点数值保留五位小数。螺旋桨旋转、侧倾、俯仰为运动学控制；没有真实发动机、失速、升阻力或碰撞求解。驾驶速度 108–414 km/h；高度 40–15000 m 是本地模型坐标，没有地理锚点。

验收：本机 RTX 4060 Laptop GPU / Edge，1280×800 时稳定采样的完成帧间隔约 33.3 ms。连续右转约 48.9 s 完成 360°，返回初始位置附近（运动学过渡导致约26 m偏差），无 WebGL 错误。双场景前进、侧倾、爬升、四方向视角、浓云、隐藏暂停、回到原观云、390×844 控件及 WebGL 上下文恢复验证。移动视口测试不等于已在低端手机验证。初始化光照缓存有短暂停顿。

制作与验证文件保留在本地本版本目录。公网最终验收另记 PUBLIC_QA.json。旧版固定地址不覆盖。
