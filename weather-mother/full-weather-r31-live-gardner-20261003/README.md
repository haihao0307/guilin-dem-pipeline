# Weather Mother R31 — live Gardner cloud workbench

This version retains the six R29 weather and teacher entries and adds a live WebGL2 Gardner shader lab. The supplied shader formulas run unchanged in teacher mode. A switchable recording comparison pauses when closed. A separate analytic-cloud weather experiment binds density, drift and deformation time to three clouds and a blue sky.

The original volume-weather module has legacy / deformation-aware / no-history choices. The new candidate uses elapsed-time decay, opacity-edge/change reaction and internal evolution trust. Its visual improvement and equivalent-quality performance are not accepted yet. R27 Cloud DNA remains the formal foundation.

Measured locally at 1576 x 898, each live lab mode reached about 60 FPS over one 8-second window; these are different representations, not equivalent-quality benchmarks. The original volume-weather remained about 30 FPS in exploratory observation.
