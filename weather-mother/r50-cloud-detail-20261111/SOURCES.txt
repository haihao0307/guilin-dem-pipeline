Weather Mother R34 sources

Current cloud modules were extracted from the user's Weather Mother R32 local workbench, derived from the supplied R29 sources; rejected Cloud DNA module removed. Original source comments and attributions are retained in src/.
Gardner textured ellipsoids: user-supplied GLSL, exact source in src/gardner_source.glsl; associated IQ noise comments include CC BY-NC-SA. Retaining source does not relicense it. Reference/derivative modes remain research code.
Tiny Clouds: source formula lsBfDz is retained in src/tiny.html for attribution and comparison; the R34 running shader replaces image sampling with src/noise.glsl. It is NOT an exact replica and does not use the former tengbao/vanta PNG.
Protean: original attribution remains in src/protean.html.
New scalar-noise implementation: project code in noise.mjs/noise.glsl, standard hashed value lattice and quintic interpolation. This does not establish independent authorship of the surrounding teacher cloud formula.
Noise.KaoPu is a local Weather Mother schema implementing the existing KAOPU Noise Generator design direction, not a claimed universal frozen format.

R35 wave-cloud source in src/waves.html is a new project experiment using analytic sinusoidal bands and volumetric integration. Retained R34 sources are unchanged. WaveCloud.KaoPu records coordinate, time, sampling and evidence boundaries.

R36 changes only waves, original weather quality tier and lazy delivery. Analytic support uses the standard ray/ellipsoid quadratic intersection idea seen in the retained lab; no teacher GLSL copied into waves. Other source modules unchanged.
