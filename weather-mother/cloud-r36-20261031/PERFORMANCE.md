# R36 实测与限制

本机 AMD Radeon 780M，Edge headless，1280×900 CSS 像素，DPR=1。不是实际手机测量。

原天气云默认档：R35 为 1152×724、192 步，完成帧率约 32.98 FPS，GPU 中位 23.88 ms；R36 为同分辨率、144 步，约 39.90 FPS，GPU 中位 19.36 ms。来自各 6 秒浏览器采样，运行条件会波动。减少积分步数存在画质权衡，不构成等质量算法加速证明。旧高画质选项继续可用。

慢的来源：每个命中云体的采样点需要噪声、密度、阴影与散射计算；原默认 192 步，且高 DPR 可使像素数增长。着色器首次编译与本地云体生成还影响初次等待。缓存命中会改变编译时间，不能拿连续两次启动的等待差异作优化收益。

原天气本地生成密度 15,728,640 字节；新旧密度与噪声 GPU 存储估计 33,226,752 字节；该测试尺寸下渲染目标估计 40,034,304 字节，阴影体估计 15,728,640 字节。这些是运行时数据/显存估计，不是下载流量，亦非浏览器总内存。

R35 入口未压缩文件 393,914 字节，包含全部场景；R36 将各场景拆开按需请求。实际线上压缩后的传输量、缓存命中和 CDN 等待可能不同，以浏览器请求记录为准。观察窗口内动画未额外请求网络云纹理或视频，blob worker 是本地脚本。并未观察到持续消耗大量网络流量的证据。

新云与原天气采用不同的密度模型，因此不能按两者 FPS 宣称等画质优劣。新云属于外观候选，不是气象模拟；自然程度仍待用户验收。解析边界减少包围盒空区采样，云内部依然体积积分，不使用历史帧涂抹。
