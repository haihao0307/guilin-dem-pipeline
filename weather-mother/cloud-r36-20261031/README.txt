Weather Mother R36 · 云体修正与解析边界融合（研究候选）
不覆盖 R34 已接受基线或 R35 历史版本。其他场景内容保留。

修改范围：
1. 新造波云：按窗口宽高比配置缓冲，保持像素预算；取消固定 16:9 拉伸。
2. 改用十个有上方向的局部云团及多尺度三维噪声侵蚀，去掉固定方向波纹。
3. 融合解析云的边界先行思想：解析求射线/椭球交点，用保守支撑限制体积积分。
   不是把单个椭球表面充当云，也不是复刻解析实验原代码。
4. 调整日照与四点近光遮挡，压低白边与大片死灰。
5. 原天气仅增加默认 144 步、约 92 万像素上限的流畅细节档；旧 192/320/480 档仍在。
   云体数据、天气、风向、云速、雨雪雷电公式未改。
6. 公网入口仅加载当前场景；standalone.html 是附加的离线整合产物。

构建：python build.py
验证：python ../scripts/check_r36.py 与 ../scripts/browser_r36.py。
已携带公共交付规则及 Mother 对象定义原件。
性能观察及边界见 PERFORMANCE.md。最终公网结果见 delivery/R36/browser-public.json。
