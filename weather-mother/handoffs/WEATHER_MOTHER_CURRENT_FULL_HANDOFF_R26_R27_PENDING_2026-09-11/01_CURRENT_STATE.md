# 01 · 当前状态与完成边界

## 当前主线

最后实际完成并有固定页面的版本是 R26，不是 R27。

R26 继承关系：

- R22：完整 Weather Mother 总工作台包装。
- R23：移动端 cloud-first，解决真实 iPhone 只剩纯色背景的问题。
- R24：移动端飞机独立安全直绘层。
- R25：飞机按云密度执行连续 Beer-Lambert 光学衰减；仍不是共享深度。
- R26：观察带宽；近处完整频带、远处稳定低频前缀，减少细节跳变和移动端成本。

## R26 已完成能力

- 单文件公网工作台。
- 手机 WebGL1 云体可见路径。
- 飞行位置、航向、俯仰、滚转和速度状态。
- 银边积云与层叠云海两个临时飞行测试场景。
- 飞机在晴空、云缘、厚云内部的连续透明度变化。
- 观察带宽：近距完整细节、过渡距离渐退、远距只读低频主体。
- 390×844 自动化布局和输入测试。
- R26 QA 记录的大尺度相关性为 0.9974314080；远近切换没有替换主体。

## R26 未完成能力

- 观云与飞行仍未真正共享一套十云属密度场。
- `silver` 和 `sea` 仍是移动飞行路径中的临时场景，不是正式 Cloud Object DNA。
- 飞机与云仍为两个渲染层；`sharedDepth=false`，`depthFBO=false`。
- 飞机模型仍是移动端程序化直绘候选，不是 R21 原三维飞机的完整恢复。
- R0.2 十云属尚未接入同一飞行世界。
- 用户可编辑 Cloud Seed / Detail Seed 尚未实现。
- R26 尚无用户真实 iPhone 视觉批准。
- 尚无生产级气象输运、湿度、凝结、浮力、降水微物理。

## 用户已经批准的下一步方向

1. 银边只是光学结果，不是一个独立云种。
2. 观云、地面看云、飞机远看、飞到云缘、进入云内和穿云出去，都读取同一 Cloud Object。
3. YOHEI 只继承方法，不继承可识别画面。
4. 引入两级确定性种子：Cloud Seed 管大形身份；Detail Seed 管局部侵蚀和细节。
5. 十云属真实性能必须重测，不能以小画布软件 QA 替代目标设备帧率。
6. 云中自由穿行必须渐进初始化，避免启动时一次构造所有 3D 纹理、光照缓存和历史缓存。
