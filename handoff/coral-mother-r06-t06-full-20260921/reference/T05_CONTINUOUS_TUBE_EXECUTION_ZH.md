# Coral Mother R06-T05 — 连续管状生长函数

状态：执行中

## 当前问题

T04 的每条图边独立生成一个圆柱，局部坐标框架也逐边重建，因此枝体在视觉上会出现分段、截面扭转和珠串式节点。这个结果不符合珊瑚由连续生长轴形成管状枝体的观察。

## T05 函数合同

1. 从正式枝图中提取 junction-to-junction / junction-to-tip 的最大连续生长路径。
2. 每条路径经过 Catmull-Rom / Hermite 连续采样，不再逐边独立造柱。
3. 截面采用 parallel-transport frame 沿路径传播，避免每段重置导致的扭转和接缝。
4. 半径沿弧长连续插值，并保留由粗到细的渐变。
5. 枝端使用连续半球收口，不再叠加独立球体。
6. 分叉节点使用一次平滑连接场覆盖，不在每个图节点堆球。
7. Pocillopora 的疣突作为附着在连续母管上的短连续侧芽；Microscope 只负责珊瑚杯、杯缘、细脊和骨骼颗粒的表面尺度。
8. 页面不再以三角面作为用户概念或指标；工作台展示生长路径、管环采样和连续连接状态。
