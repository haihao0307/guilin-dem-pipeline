# Coral Mother R06-T07 直接执行令

本任务接在 R06-T06 后面。不要重新规划，不要先讨论验收清单，直接修改函数、跑浏览器门禁并发布固定在线地址。

## 目标

把当前“参数变化不明显”的 T06，推进为“形体和微表面变化肉眼可见”的 T07，同时保持连续管逻辑、轻量运行和官方分类边界。

## 1. Microscope 必须进入形体

当前 Microscope 主要是片元明暗和法线扰动，用户判断看不出形体变化。T07 必须加入低成本的真实顶点／管环半径位移：

- 输入：路径弧长、环角、局部半径、枝序、种子。
- 三个频带：corallite 杯体、杯缘／细脊、骨骼颗粒。
- 位移方向：局部管环法线。
- 位移幅度必须受局部管径限制，避免细枝爆裂。
- `Microscope 尺度` 只控制图形尺度／频率。
- `Microscope 凹凸` 控制真实位移幅度，0 必须恢复平滑管体，1 必须肉眼可见。
- 继续保留 shader 细节，但不得用 shader 明暗冒充形体位移已经完成。

建议函数：

`r'(s, θ) = r(s) × [1 + A(r, order) × F_cup(s,θ) + B × F_ridge(s,θ) + C × F_grain(s,θ)]`

要求函数连续，不能在管环之间跳变。

## 2. 枝端钝化必须可见

当前 tip 参数变化过弱。改为显式控制末端半径曲线和闭合长度：

- 低值：较快收尖，但不得出现针尖。
- 高值：较长的钝圆端、较大的末端帽半径。
- 同一枝端从最低到最高必须在 A/B 中明显可辨。
- 不得增加独立球体帽；仍由连续管自身闭合。

## 3. 表面起伏／U 图幅度扩大

- `表面起伏` 应影响中尺度管壁轮廓，而不只是颜色。
- 0 时接近平滑骨架。
- 1 时应出现明显但不破坏物种包络的中尺度起伏。
- 与 Microscope 分工：表面起伏是中尺度，Microscope 是微尺度。

## 4. 疣突、骨骼颗粒、杯口深度

- `表面疣突`：提高短钝侧芽的数量／半径／长度反馈，拉动后立即可见。
- `骨骼颗粒`：进入高频形体位移和粗糙响应，不能只改亮度。
- `杯口阴影`：允许更深；同时通过杯形微位移提供真实凹陷暗示。
- 所有参数都必须存在 0 与高值的明确视觉差。

## 5. 细枝保留的拓扑门禁

最低保留值不只是按半径随机删除；必须保证剩余结构从附着基底可达。

执行顺序：

1. 识别 attachment/root 节点。
2. 按保留规则选择候选路径。
3. 对候选图做 root-connected traversal。
4. 删除所有不与 root 连通的孤立节点、孤立路径和悬空侧芽。
5. 修剪后重新生成连续管路径。

硬门槛：任何显示枝体都必须存在一条连续父路径连接到共同附着基底。

## 6. 性能边界

- 不做逐个珊瑚杯的独立对象。
- 优先在现有管环采样上计算半径位移。
- 2560×1080、1536×960、390×844 均需浏览器检查。
- JavaScript 错误为 0。
- 保持 0 GLB、0 texture、0 fetch。
