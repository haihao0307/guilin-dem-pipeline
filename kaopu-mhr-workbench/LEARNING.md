## 先跑原版，再迁移
1. 原始 TorchScript 通过 torch.jit.load 在 CPU 实际运行，不替换模型
2. 提取模型原始 float32 张量，精确的 0 才使用稀疏存储；不量化、不阈值裁剪
3. 45 个身份基、72 个面部基、204 个参数变换、127 个关节、全部蒙皮影响均保留
4. 完整姿态修正：125×6 旋转特征、3000 隐层、ReLU、4,451,976 个非零输出权重
5. 浏览器中按原版前向顺序计算：身份和表情 → 骨架状态 → 神经姿态修正 → 线性蒙皮
6. 全部 342 测试输入逐顶点对比：45 身份、72 表情、204 骨架、基线以及 20 混合状态

## 验证
原生 LOD1：18,439 顶点 / 36,874 三角形 / 127 关节。
完整顶点审计最大误差 0.000183105 cm，即 0.00183105 mm。
误差来自浮点累加次序，未以精度降低替代算法。
CI 同时保留每案例 257 个确定性采样点，检查后续实现未漂移。

## 浏览器尺寸
核心权重 `model.bin.gz` 为 23,931,058 字节；无损解压为 42,116,120 字节。
按需加载官方 LOD 映射；无外部推理服务，无收费后端，无个人资料上传。
JavaScript 模块、Three.js r170 与 OrbitControls 随页面一起交付。

## 必须保持清楚的边界
- 身份轴为 PCA 方向，不能直接命名成独立的胖瘦、年龄、性别或肌肉旋钮
- 体型 A / B 是身份第 0 轴 ±2 的可复核例子，不声称官方语义映射
- LOD1 原生求值，其他 LOD 使用官方 Web Viewer 同样的重心映射；未声称运行各 LOD 的独立原生模型
- PyTorch 自动微分、优化器、SMPL/SMPL-X 转换、原生各 LOD 以及学术批量接口仍在官方 Python 代码
- 2D/照片重建属于 SAM 3D Body 等其他项目，本工作台没有伪装这一能力
- 本站不是 Meta 官方服务；人物联合实验不能逆向污染此独立教师基线
