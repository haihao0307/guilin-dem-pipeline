# KAOPU Score Instrument R01

这是一个从零开始、与既有 Fish、Coral、Bird、Landscape、Object DNA 等生产线隔离的可证伪实验。

目标不是先证明“任何对象都能被极短谱子完整记录”，而是先验证：

1. 谱与乐器能否彻底分离；
2. 同谱能否稳定复述；
3. 对乐器已经掌握的语法，谱能否只保存对象之间的差异；
4. 谱体量、乐器体量和展开结果能否同时被准确计量；
5. 成功以后，语法能否从基本几何逐步扩展，而不是直接跳到真实物种。

## 必须先纠正的前提

信息不会凭空消失。极短谱子成立的条件，是大量共同知识已经固化在乐器中。

因此：

- 谱越短，乐器承担的先验、默认值、生成算法和对象语法越多；
- “谱只有几十字节”不能单独证明系统很轻，必须同时记录乐器体量；
- R01 只能证明已经进入乐器语法的几何可被少量参数展开；
- R01 不能证明鱼、珊瑚、鸟、树、地形已经能被同样长度的谱精确复述；
- 真实对象还需要测量、结构语法、材料语法、运动语法、环境条件和独立验证器。

## K1 谱格式

谱必须带版本头：

```text
K1|<节点>;<节点>;...
```

### 基本几何

```text
b宽,高,深       方体
s半径           球体
c半径,高度      圆柱
n半径,高度      圆锥
t主半径,管半径  圆环
p宽,深          平面
```

所有尺寸单位为米，Y 轴向上。尺寸可以省略，乐器使用 K1 固定默认值。

### 可选属性

```text
#颜色        例如 #d69a5a 或 #da5
!粗糙,金属   例如 !.7,.05
@x,y,z       位置，单位米
/x,y,z       欧拉旋转，单位度
%x,y,z       缩放
```

属性顺序固定为：颜色 → 材质 → 位置 → 旋转 → 缩放。未写出的属性使用 K1 默认值。

### 逻辑算子

```text
A数量,半径{子谱}  围绕 Y 轴的环形阵列
L数量,间距{子谱}  沿 X 轴的线性阵列
```

逻辑算子可以包含多个子节点，并可以嵌套。

### 示例

```text
K1|b#d69a5a
K1|s.62#5b9bd5
K1|c.45,1.25#6ea870
K1|t.68,.19#c87883
K1|A12,1.2{c.10,.65#e7b34e@0,.15,0/25,0,0};s.32#f4e2b8
```

## R01 边界

- 不加载 GLB、纹理、图片、外部 JSON 或旧项目代码；
- 谱中不保存顶点、三角面或最终几何结果；
- 不引入鱼、珊瑚、鸟、植被和地形的专用知识；
- 相机、灯光、地面属于世界乐器，不混入对象谱；
- 简单几何成功不得升级为真实物种成功；
- 最终构建只有一个自包含 HTML；
- `file://` 双击核心运行所需网络请求为 0；
- 在线镜像只服务同一份 standalone HTML。
