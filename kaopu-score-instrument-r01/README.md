## 理论边界

`K1|b`、`K1|s`、`K1|c`、`K1|n`、`K1|t`、`K1|p` 各为 4 个 UTF-8 字节，但依赖共享乐器已经掌握的语法、默认尺寸、材质和生成算法。完整 HTML 的原始字节数另行显示，包含 Three.js 与界面。浏览器/GPU/系统字体也属于执行环境，未计入 HTML。

短谱只证明这个有限对象族可用少量差异参数表达，不证明任意自然对象的全部知识或不可预测细节能被极短代码无损表示。三角面/字节是展开密度，不是压缩率；多分面不等于更多事实。

同谱复述目标是几何与材质语义一致。球、圆柱等在 GPU 上显示为固定细分的近似网格，不是无限精度曲面。不承诺不同 GPU 和浏览器逐像素一致。

## K1 固定约定

单位 m，Y↑；本地未变换物体底部 y=0。旋转 XYZ（度），圆环初始位于 XY 平面。
基本节点：b宽,高,深；s半径；c半径,高；n半径,高；t主半径,管半径；p宽,深。
默认：b=[1,1,1]；s=[.5]；c/n=[.5,1]；t=[.65,.18]；p=[1,1]。
可选属性严格按 #颜色 !粗糙度,金属度 @位置 /旋转 %缩放 排列。默认粗糙度=.66，金属度=.06，位置/旋转=0，缩放=1；单个缩放参数为统一缩放。部分尺寸仅替换前面的参数，不代表统一尺寸。
默认色：b=d69a5a，s=5b9bd5，c=6ea870，n=b98a62，t=c87883，p=6f7d8c。
A数量,半径{子谱} 为 Y 轴环阵，首个槽位在 +X，槽位绕 Y 旋转为 -angle；L数量,间距{子谱} 为沿 X 居中的线阵。默认数量=6、A半径=1、L间距=.5。多个节点以分号分隔。
资源上限：4096 字节、8 层、每算子最多 256 次、总计最多 1200 个 Mesh；数值绝对值不超过 10000，正尺寸/缩放/阵列距离至少 .0001。先完整解析并核算预算，再创建几何。错误输入保留上次有效输出，未演奏草稿不污染结果账本。
