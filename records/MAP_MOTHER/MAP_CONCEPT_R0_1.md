# MAP-CONCEPT R0.1 — Map Mother 时空总谱与操作概念

更新：2026-09-15

来源：用户通过小妈回流的 2026-09-14 手机端原始讨论整理。原讨论任务：`6aa75731-ffec-83e9-b288-d033ed05e9e4`，北京时间 21:49—22:06。

本文件是当前小温州任务的知识接续入口。它定义 Map Mother 的概念与操作边界，不声称已存在独立 Map Mother 程序、统一数据库或完整跨域运行平台。

## 1. 用户定义

Map Mother 负责空间和时间上的组织、地图证据解释、状态查询与各领域共同对齐。DEM、历史地图、海洋、土壤、道路、河流、建筑和移动对象属于同一世界总谱，但使用适合各自语义的表达：连续地形用场/曲面，岸线用曲线与区域，路网用连接关系，对象用身份，土壤用属性与深度域，年代变化用状态或事件。

地图资料进入系统的目标不是堆积原文件，而是提取为可理解、可求值、可追溯的世界知识。历史状态必须可回溯：切到过去不显示后来才出现的要素，切回现代能恢复现代状态；不得覆盖掉其他已知年代。

当前实例从温州和 1940 年代短时间窗口开始，先把这一段做可靠，再扩展其他年代。

## 2. 必须保留的边界

- 图上记载、测得数据、推导结果、设计补全必须分开标记。推测可以形成候选，但不能自动提升为真值。
- 同一空间载体不等于所有实物身份不变。桥梁替代、道路改线、河流分汊等要保留对象与连接变化。
- 同坐标不等于同时间。版次/出版年、资料描述时间、入库修订时间必须区分。
- 1953 来源不能未经说明直接改名为 1940 年代事实；它可以作为邻近年代控制、约束或候选依据。
- 旧图未画某个小对象不能自动推出其不存在，尤其对 1:250,000 图幅。
- 原图提取完成后应退出日常运行负担，但是否长期保存原图取决于是否已保全所需信息、是否仍需复核以及来源是否可恢复；不得把“永久冷藏所有原图”当默认规则，也不能在尚未完成提取时把原图删除。

## 3. 操作流程

1. 接收：登记来源身份、版本/年代含义、范围、比例尺或采样间距、参考架、入口、当前可用性和本次提取目标。
2. 对齐：映射到共同坐标/对象域，记录有效域、误差和变换依据；更细资料不自动无条件覆盖旧证据。
3. 解释与入谱：提取地形规则/必要残差、岸线与水陆区域、道路河网连接、土壤属性、对象和年代主张；冲突可并存。
4. 形成年代状态：由锁定共享基底与适用变化求值；有依据的历史对象状态与推测补全分别记录。
5. 给领域使用：按地点、时间、属性、尺度/用途输出必要分谱和适用条件。
6. 核对与修订：只改真正受新证据影响的局部，记录旧判断修订原因和未核范围。

## 4. 共享基底、年代变化与体积

“空间母体 + 年代差分”是当前温州实例的主要轻量策略，但不是整个 Map Mother 的绝对规则。

- 年代状态可概念化为：`锁定基底 + 适用变化`，但道路显隐、连接替换、海陆分类等不是简单数值加法。
- 每份变化必须绑定具体基底版本、坐标/单位和方法版本。基底被更正或分辨率改变后，旧差分不能无条件复用。
- 稳定公共部分优先复用；但必要检查点、原生快照或在某些情况下代价更小的完整表达允许保留。禁止把“绝不允许任何年代完整 DEM”当普遍规律。
- 用户认可的约 2.x MB 是温州当前轻量行为的参考，不是未经重新核定的硬字节真值。后续分别报告共享基底、单年代增量、索引/残差/状态、必要依赖和显示缓存成本。
- 大图不进入日常运行负担。先蒸馏，再决定原图退出策略；若原图未来不可得，要明确哪些结论将失去重新核查能力。

## 5. 当前温州任务适用项

当前目标：1940 年代，目标年 1942；1953 图幅作为邻近年代控制来源，不能自动等同于 1942 真值。

本任务直接采用：

- 正常三维画面不显示无意义的工程参考线；后台证据与真正海陆形态变化分开。
- 高速、高铁/现代快速交通、大型现代桥、明确现代围垦、海堤、现代水库/坝体等按证据进入历史状态删除/替换候选；现代状态必须可恢复。
- 海底缺失部分可按用户授权形成可替换派生候选，记录范围、约束、方法与未知；不伪造置信百分比，不冒充观测海底真值。
- 先消化当前图幅和局部城图，再接收下一批细图。该节奏是当前温州实例的工作安排，不是整个 Map Mother 永久关闭资料入口。
- 新图优先修改局部变化，不复制整个温州世界。

## 6. 各 Mother 关系

Map Mother：地理来源、空间身份、时态、跨域引用与查询组织。
Landscape：地形方法与求值。
Ocean：海洋、海岸、水体领域能力。
Soil/Farmland：土壤与农田属性和过程。
Weather：天气与时间状态。
建筑、人物、动物等保留自己的对象身份，通过位置、参考架和关系接入共同场景。

Map Mother 不因概念命名而自动接管这些生产线；当前小温州只在既有温州任务中应用该概念。
