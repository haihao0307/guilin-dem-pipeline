温州靠谱区域核心 R01 — 2026-10-26

用途
将当前温州范围内的现代岸线、土壤和土地覆盖资料组织成有身份、坐标参考架、有效域、属性/深度/年份、来源及查询规则的数据层。不是一个完整物理生成器，不以改文件名代替知识提取，也不宣称所有自然细节能由几个函数推出来。

范围
EPSG:32651，E=[190475,411250]，N=[2991275,3241862.5]。这是既有项目矩形，含海域，不是温州市行政边界。
岸线额外保留1000米支持余量。WorldCover原生瓦片保留该矩形在原参考架中的包围窗口及2个原生像元余量，不继续保存无关地区。

持久定义
岸线：有来源的陆地区域、孔洞、真正海岸边界及区域包含规则；人工裁切边界不是海岸。WKB只是这些区域和曲线的编码，未作形状简化；没有持久三角网格。
土壤：模型观察场，属性、深度、统计量、参考架、有效性和单位分别保存。Q0.05、Q0.5、Q0.95、mean、uncertainty均保留；不拿网页只使用的中位数与uncertainty替代其他成果。
土地覆盖：2020与2021的类别场，保留原有10米对齐格和区域内原生格；类别用所属格查询，不平均类别编号，不把类别当作个体树木或建筑。
WRB：官方类别和各类概率分数分别保留，不强制概率和为100%。旧bilinear指控已在R3.8文档纠正；原报告用词和目前查询规则分开。

实际实现
CATALOG.json将863个数据层（包括原生/对齐表示及支持掩膜）挂在同一WENZHOU_WORLD身份下。
同值块、掩膜和坐标映射共用。部分对齐场保存为“原生场＋共享的固定整数格映射＋必要修正量”，其余保留更小的直接无损编码。整数映射是存储预测器，修正量保障原值，不冒充新的物理规律。
所有保留数值及有效掩膜在导入时逐字节核对；生成式重建层另核完整SHA256。稳定整数映射不依赖未来GDAL/PROJ重投影细节来解码原值。
温州之外的WorldCover区域未保留，不能把区域内数值无损称为全球文件无损。旧GeoTIFF容器、overview和历史压缩字节不作逐字节复原承诺；原始文件身份和必要元数据留在provenance中。

使用
运行环境：Python、numpy、pyproj、shapely；本次核验版本记录于requirements.txt。rasterio用于原始文件导入和独立源数据对照，不是固定整数场解码的必需依赖。
  from field_core import RegionalWorld
  world = RegionalWorld("本目录")
  field_id = world.select(property="clay", depth="0-5cm", statistic="Q0.5")[0]
  result = world.query(field_id, 300000, 3120000)
  coast = world.land(300000, 3120000)
超出域返回未知；不会自动选年份、深度或把缺测补成零。
  python verify_core.py
  python verify_core.py --full

build_fields.py、build_coast.py和源数据对照脚本记录本次导入方法；清理旧输入后不应把它们当作日常启动器。正常查询、解码和核心完整性验证不需要全球海岸ZIP或已被替代的五个源ZIP。

验证凭据
COAST_BUILD_QA.json：区域形状、有效性、与已有岸线的取整边界对照。
FIELD_BUILD_QA.json：原始导入的全部保留数值和掩膜一致性。
FINAL_FIELD_QA.json、STENCIL_QA.json：中间表示和存储选择记录；最终大小以PACKAGE_RECEIPT.json为准。
QUERY_QA.json：独立原文件坐标查询比对。
CORE_INTEGRITY_QA.json：不依赖旧来源ZIP的完整性与重建核验。
