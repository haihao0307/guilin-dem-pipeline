# 小温州 · 1942/1953 历史预清理清单 R3

目标不是宣称已经复原 1942，而是从当前温州基线中持续做高置信现代要素减法。用户提供的历史地图是本线的权威历史控制源；更细历史图覆盖其局部范围时，局部图优先于全域图。

当前两级控制源：

1. 1953 `YUNG-CHIA (WENCHOW) / NH 51-13 / Series L500 / 1:250,000`：全域地理控制，图幅边界 120°00′E–121°30′E、28°00′N–29°00′N。用于主要道路、海岸、围垦、水库、主要聚落和主水系的大尺度判定。登记见 `HISTORICAL_1953_CONTROL_SOURCE.json`。
2. 1945 `YUNG-CHIA / WENCHOW / 1:12,500` 城市图：城区局部精修控制。该图明确显示老城水网仍有局部桥/过水连接，因此不能把所有 `bridge=*` 一刀切。

比例尺边界：1:250,000 图上“没有”对大型现代工程是强负证据，但不足以单独否定小村路、小桥、田埂路、小沟渠或单栋建筑。

| 类别 | R3 动作 | 当前依据 | 后续规则 |
|---|---|---|---|
| `motorway` 高速主线 | **删除/隐藏** | 明确现代高速系统 | 已确认删除 |
| `motorway_link` 高速匝道 | **删除/隐藏** | 明确依附现代高速系统 | 已确认删除 |
| `construction` 道路 | **删除/隐藏** | 当前 OSM 明确标记为当代“建设中”状态，不可能作为 1953 历史道路真值 | 已确认自动删除 |
| 高铁 / 铁路 | **当前无需动作** | 当前浏览器 OSM bundle 没有 railway 层 | 若后续运行层出现现代高铁则删除 |
| 主要道路上的 `bridge=*` | **删除/隐藏** | 仅处理 `trunk/trunk_link/primary/primary_link/secondary/secondary_link` 且带 bridge flag 的 part；对应用户明确删除跨海桥、大桥 | 已确认删除 |
| `tertiary / tertiary_link` 桥 | **暂时保留** | 1945 城图显示旧城存在局部桥；仅凭今天的等级不能确定年代 | 等更细图 |
| 三级以下本地桥、村桥、小桥 | **保留待判** | 不能把历史小桥与现代大桥混为一类 | 等更细图 |
| `trunk / trunk_link` 非桥路段 | **暂缓** | 当前道路等级不能证明路廊在 1953 不存在 | 与 1953 道路骨架配准后逐段判定 |
| `primary / secondary / tertiary` 非桥路段 | **暂缓** | 可能沿袭历史道路 | 与 1953/局部细图逐段判定 |
| 普通住宅/服务/乡道/路径 | **保留待判** | 1:250k 不足以否定小路存在 | 等更细图 |
| OSM 建筑 footprint | **暂缓** | 当前包无建筑年代 | 等城市/乡镇细图 |
| 水库 / 大坝 | **进入下一阶段回退** | 用户明确现代水库不要；1953 全域图作为主要存在/缺失控制 | 先隐藏现代库水与坝体，再恢复库前谷地/河道 |
| 围垦 / 填海 / 海堤 | **进入下一阶段回退** | 用户明确按 1953 海岸与湾区格局清除后期围垦 | 以历史海岸/滩涂为控制重建，不只关对象显示 |
| 港区硬化岸线 / 现代码头 | **进入下一阶段回退** | 大尺度现代硬化岸线与历史海岸冲突时应退出历史态 | 等海岸配准后处理 |

## R3 技术边界

- 现代 R3.9.1 固定候选保持不动。
- 历史预清理通过独立入口启用，原始 OSM 证据、SHA、历史候选和永久 Release 不删除。
- R1：过滤 `motorway / motorway_link`。
- R2：新增过滤主要道路上的 `bridge` parts，保留 `tertiary` 及以下小桥。
- R3：新增过滤 `construction` 道路，并把 1953 全域图正式登记为最高优先级全域历史控制源。
- 1953 图的道路、海岸、水体等还需做地理配准/矢量控制层；在配准完成前，不用“图上未画”去误删小尺度对象。
- 该版仍是“历史预清理”，不是完整 1942/1953 历史真值。
