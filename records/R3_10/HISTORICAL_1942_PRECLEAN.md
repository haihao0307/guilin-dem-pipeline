# 小温州 · 1942 预清理清单 R1

目标不是宣称已经复原 1942，而是先从当前温州基线中做“不会后悔的高置信减法”。用户提供权威历史地图后，再进入海岸线、围垦、水库、旧河网、旧道路和聚落的证据校正。

| 类别 | R1 动作 | 当前依据 | 用户后续判定 |
|---|---|---|---|
| `motorway` 高速主线 | **删除/隐藏** | 当前 OSM 道路包有独立 class code=1；作为现代高速系统高置信删除 | 待确认 |
| `motorway_link` 高速匝道 | **删除/隐藏** | 当前 OSM 道路包有独立 class code=2；依附高速系统 | 待确认 |
| 高铁 / 铁路 | **当前无需动作** | 当前浏览器 OSM bundle 只包含 `highway` LineString 与建筑 footprint，没有 railway 层 | 待确认是否后续另有铁路数据 |
| `trunk / trunk_link` | **暂缓** | 不能仅凭今天的 OSM 等级判断 1942 是否存在同一路廊 | 待用户历史图 |
| `primary / secondary / tertiary` | **暂缓** | 可能包含沿袭旧路的现代分级，整类删除风险过高 | 待用户历史图 |
| `bridge=*` 道路 | **暂缓** | bridge flag 只说明当前映射属性，不提供建造年代；不能一刀切 | 待用户历史图或年代证据 |
| 普通住宅/服务/乡道/路径 | **保留待判** | 很多可能继承传统道路、村路或山路 | 待用户历史图 |
| OSM 建筑 footprint | **暂缓** | 当前包没有建筑年代；无法可靠区分 1942 与现代建筑 | 待用户历史图 |
| 水库 / 大坝 | **暂缓** | 删除水面还需要恢复建库前谷地和河道，不能只关一个显示层 | 待用户历史图 |
| 围垦 / 填海 / 海堤 | **暂缓** | 需要重建历史海岸与滩涂，不等于删除一个对象 | 待用户历史图 |
| 港区硬化岸线 / 现代码头 | **暂缓** | 需要与历史海岸、旧港口证据一起判断 | 待用户历史图 |

## R1 技术边界

- 现代 R3.9.1 固定候选保持不动。
- 1942 预清理通过独立入口启用，只过滤 `motorway` 与 `motorway_link` 的道路 parts。
- 原始 OSM 证据、SHA、历史候选和永久 Release 都不删除；过滤发生在当前历史视图的运行态。
- 普通道路、桥梁、建筑、水库、围垦、海岸线本轮不擅自改。
- 该版只叫“1942 预清理 R1”，不叫“1942 历史真值”。
