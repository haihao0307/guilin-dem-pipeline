# 小温州 · 1942 预清理清单 R2

目标不是宣称已经复原 1942，而是先从当前温州基线中做“不会后悔的高置信减法”。用户提供权威历史地图后，再进入海岸线、围垦、水库、旧河网、旧道路和聚落的证据校正。

用户补充了一张 1945 年温州（Yung-Chia / Wenchow）1:12,500 城市图。该图支持一个重要边界：老城水网中存在局部桥/过水连接，因此不能把所有 `bridge=*` 一刀切；但现代跨海桥和主要现代大桥不应保留在 1942 预清理视图中。

| 类别 | R2 动作 | 当前依据 | 用户后续判定 |
|---|---|---|---|
| `motorway` 高速主线 | **删除/隐藏** | 当前 OSM 道路包有独立 class code=1；作为现代高速系统高置信删除 | 已确认删除 |
| `motorway_link` 高速匝道 | **删除/隐藏** | 当前 OSM 道路包有独立 class code=2；依附高速系统 | 已确认删除 |
| 高铁 / 铁路 | **当前无需动作** | 当前浏览器 OSM bundle 只包含 `highway` LineString 与建筑 footprint，没有 railway 层 | 若后续另有铁路层则删除现代高铁 |
| 主要道路上的 `bridge=*` | **删除/隐藏** | 只处理 `trunk/trunk_link/primary/primary_link/secondary/secondary_link` 且带 bridge flag 的道路 part；对应用户明确要求删除跨海桥、大桥 | 已确认删除 |
| `tertiary / tertiary_link` 桥 | **暂时保留** | 1945 图显示旧城仍有局部桥/过水连接；三级道路桥不能仅凭当前 OSM 属性判定年代 | 待历史图进一步比对 |
| 三级以下本地桥、村桥、小桥 | **保留待判** | 不能把历史小桥与现代大桥混为一类 | 待历史图 |
| `trunk / trunk_link` 非桥路段 | **暂缓** | 不能仅凭今天的 OSM 等级判断 1942 是否存在同一路廊 | 待用户历史图 |
| `primary / secondary / tertiary` 非桥路段 | **暂缓** | 可能包含沿袭旧路的现代分级，整类删除风险过高 | 待用户历史图 |
| 普通住宅/服务/乡道/路径 | **保留待判** | 很多可能继承传统道路、村路或山路 | 待用户历史图 |
| OSM 建筑 footprint | **暂缓** | 当前包没有建筑年代；无法可靠区分 1942 与现代建筑 | 待用户历史图 |
| 水库 / 大坝 | **暂缓** | 删除水面还需要恢复建库前谷地和河道，不能只关一个显示层 | 待用户历史图 |
| 围垦 / 填海 / 海堤 | **暂缓** | 需要重建历史海岸与滩涂，不等于删除一个对象 | 待用户历史图 |
| 港区硬化岸线 / 现代码头 | **暂缓** | 需要与历史海岸、旧港口证据一起判断 | 待用户历史图 |

## R2 技术边界

- 现代 R3.9.1 固定候选保持不动。
- 1942 预清理通过独立入口启用。
- R1 已过滤 `motorway` 与 `motorway_link`；R2 新增过滤 `bridge` flag 且道路 class 属于 `trunk / primary / secondary` 及其 link 的 parts。
- `tertiary` 及以下 bridge parts 本轮明确保留，避免误删历史小桥。
- 原始 OSM 证据、SHA、历史候选和永久 Release 都不删除；过滤发生在当前历史视图的运行态。
- 水库、围垦、海岸线、普通道路和建筑仍等待用户权威历史图校正。
- 该版只叫“1942 预清理 R2”，不叫“1942 历史真值”。
