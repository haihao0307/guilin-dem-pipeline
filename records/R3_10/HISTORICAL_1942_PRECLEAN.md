# 小温州 · 1942/1953 历史预清理清单 R4

目标不是宣称已经完整复原 1942，而是从当前温州基线中持续做高置信现代要素减法。用户提供的历史地图是本线的权威历史控制源；更细历史图覆盖其局部范围时，局部图优先于 1:250,000 全域控制图。

当前历史控制体系已经形成三张 1953 L500 图幅 + 一张 1945 城市细图：

1. 1953 `YUNG-CHIA (WENCHOW) / NH 51-13 / 1:250,000`：120°00′E–121°30′E、28°00′N–29°00′N。控制温州主体、海岸、主要道路、水库/围垦冲突。记录：`HISTORICAL_1953_CONTROL_SOURCE.json`。
2. 1953 `JUI-AN / NG 51-1 / 1:250,000`：120°00′E–121°30′E、27°00′N–28°00′N。作为南侧连续控制图幅。记录：`HISTORICAL_1953_CONTROL_SOURCE_NG51_1.json`。
3. 1953 `SUNG-MEN / NH 51-14 / 1:250,000`：121°30′E–123°00′E、28°00′N–29°00′N。与 NH 51-13 在东经 121°30′ 拼接，控制温州东侧海域、岛屿、岸线和大型海上/沿海工程冲突。记录：`HISTORICAL_1953_CONTROL_SOURCE_NH51_14.json`。
4. 1945 `YUNG-CHIA / WENCHOW / 1:12,500` 城市图：城区局部精修控制。该图明确显示老城水网仍有局部桥/过水连接，因此不能把所有 `bridge=*` 一刀切。

1953 atlas 索引：`HISTORICAL_1953_CONTROL_ATLAS.json`。三张 1:250,000 图幅的权威覆盖是各自矩形的并集，不把未提供图幅的区域误当成已覆盖历史真值。

比例尺边界：1:250,000 图上“没有”对大型现代工程是强负证据，但不足以单独否定小村路、小桥、田埂路、小沟渠或单栋建筑。

## 已发布的历史水域控制

- `HISTORICAL_1953_WATER_CONTROL_NH51_13.geojson`
- `HISTORICAL_1953_WATER_CONTROL_NG51_1.geojson`
- `HISTORICAL_1953_WATER_CONTROL_NH51_14.geojson`

这些 GeoJSON 由历史扫描图蓝色水域做粗分割、连通域/形态清理，并按图幅整饰线进行线性地理配准。用途仅限**大尺度海岸、开阔水域、岛屿、围垦、水库冲突控制**；不是测绘级岸线，也不用来否定小沟渠、小池塘等地图未表达对象。

## R4 技术边界

- 现代 R3.9.1 固定候选保持不动。
- 历史预清理通过独立入口启用，原始 OSM 证据、SHA、历史候选和永久 Release 不删除。
- R1：过滤 `motorway / motorway_link`。
- R2：新增过滤主要道路上的 `bridge` parts，保留 `tertiary` 及以下小桥。
- R3：新增过滤 `construction` 道路。
- R4：1953 atlas 扩展到 `NH51-13 + NG51-1 + NH51-14`，三张图幅均建立水域/海岸粗控制，其中 NH51-14 明确扩展东侧海域与岛屿判断范围。
- 下一阶段优先用这些控制层识别大型围垦、硬岸和现代库区冲突，然后再做主道路骨架提取；没有更细证据时继续保守保留小尺度对象。
- 该版仍是“历史预清理”，不是完整 1942/1953 历史真值。
