# 温州R3：测量、曲面、坐标和三维显示知识合同

版本：WZ-3D-KNOWLEDGE R0.1，2026-09-09。本轮按用户最新要求继续温州R3，仅提供可实施、可验证的知识指导。温州承担数值解码、实验、三维和公网交付；小妈没有运行这些实现。本篇不处理其他项目清理，也不将其列为温州前置。

## 1. 先指出方案中容易出现的逻辑跳跃

当前方案可以成立：固定数字样本与规则作为持久依据，按需生成显示网格。以下条件必须明确，否则“有曲面规则”仍可能掩盖错误。

| 可能的推断 | 问题 | R3采用的判据 |
|---|---|---|
| 解码SHA相符，所以地形准确 | 哈希只校验约定字节，未证明来源测量、原始拼接或高程基准 | 数据恢复与物理准确性分别报告，后者缺证据保持未知 |
| 12.5m格网或插值得更密，所以获得12.5m或更高真实分辨率 | 重采样和插值不增加原始信息；既有来源约30m信息不能由更密格距升级 | 分开写原始来源尺度、当前格距、插值规则和显示采样密度 |
| 双线性曲面用四角连两个三角形就精确显示 | 一般双线性片不是平面，两个平面三角形只近似它 | 权威求值器与显示近似分开，声明并测量显示误差 |
| 12个查询点都能贴到地表，所以它们是地表部件且原高程就是曲面值 | 它们是查询位置；原高程为所在像元取值，新曲面是另一种求值 | 原记录不改，新加曲面求值/显示锚定关系；组成和连接不由贴地推断 |
| 粗LOD角点有效，所以中间都能画地表 | 中间可能有NoData孔洞，粗网格会跨越未知区 | 有效域覆盖随LOD传播，粗化不填洞、不把缺失变成海平面 |
| 默认不夸张，所以是地球真实三维 | UTM是投影平面，垂直基准还未知；此模型是区域高程场表示 | 默认水平/垂直使用相同比例，称为未增强的投影地形显示，不宣称完整地球曲率或绝对实物精度 |

现实的主要资源约束也明确：当前有354,070,114样本，完整int16阵列约708MB；若每样本都做一个Float32三维顶点，仅位置约4.25GB，完整格网约708,064,812个三角形，其uint32索引约8.50GB，尚未算其他缓冲。这是按尺寸推算的存储量，不是运行测试。因此按视域、层级和缓存预算生成显示是必要条件，不能将全域原始网格一次塞入浏览器。

## 3. 格心、像元范围和插值域

索引transform是`[a,b,c,d,e,f]=[12.5,0,190475,0,-12.5,3241862.5]`形式，不能原样作为GDAL的GT(0)…GT(5)顺序传入。相应GDAL顺序为`[190475,12.5,0,3241862.5,0,-12.5]`。GDAL以左上像元外角为(0,0)，格心位于(0.5,0.5)。[GDAL Geotransform官方定义](https://gdal.org/en/stable/tutorials/geotransforms_tut.html)

全局0基行r、列c的格心：

`E(c)=190475+12.5(c+0.5)`

`N(r)=3241862.5−12.5(r+0.5)`

因此栅格外缘范围为E∈[190475,411250]、N∈[2991275,3241862.5]；格心极值范围为E∈[190481.25,411243.75]、N∈[2991281.25,3241856.25]。两者相差半格，不能互相冒充。以下新曲面选择以数字值在格心作为插值支撑；这是R3派生规则的约定，不证明源产品在现实中逐个格心实测。

连续中心索引：`q=(E−190475)/12.5−0.5`，`p=(3241862.5−N)/12.5−0.5`。曲面最大矩形参数域为q∈[0,17661]、p∈[0,20046]，实际有效域还要扣除无完整有效支撑的单元。

第一版建议不外推半格、不跨NoData补值。单点原值查询与曲面查询分别提供：一个有效孤立格心可有原值，但没有足够邻域形成二维曲面。边界取值和单元归属用明确约定；落在最外有效格心边界时可选内部相邻片，域外请求先拒绝，不通过clamp伪装域内。

## 4. 第一条有边界曲面规则

建议采用`wz-dem-bilinear-centres-r1`这一类明确版本化规则，至少保存：surfaceId/revision、固定源与掩膜引用、参考架/单位、格心定位公式、参数域、插值公式、片归属、有效性/缺失规则、导数范围及误差含义。无需给每个临时三角形创建持久对象。

对于有效单元左上角全局索引(r,c)，四个值为h00=h[r,c]、h10=h[r,c+1]、h01=h[r+1,c]、h11=h[r+1,c+1]，u=q−c、v=p−r：

`h(u,v)=(1−u)(1−v)h00+u(1−v)h10+(1−u)vh01+uvh11`，u,v∈[0,1]。

曲面为`S(u,v)=(E(c+u),N(r+v),h(u,v))`。任一必需角点无效，则该二维片无效；返回NoData及所需样本范围，不以重归一化剩余权重悄悄改变规则。内部样本可按原值查询；有效曲面的格心恢复应与原值一致。

共享角点的相邻片在共同边上给相同高程，因此可C0连续；一般不保证坡度/法线连续。分块只是存取与显示组织：跨512边界的四角仍来自同一全局网格，至少读取所需邻块边/角，不能把每个编码块边缘误当真实地形边界。最后不满512的块按真实宽高处理。

双线性曲面不能无条件等同于两个三角形。纸上反例：四角为0、0、0、1时，中心双线性值为0.25，选择两种对角线的平面三角形在中心可为0.5或0。细分只减少显示误差；权威查询仍用声明的曲面公式。对完整一片、同四角的两三角形近似，其高度差上界为`|h00−h10−h01+h11|/4`；这是该单片构造的代数界，不能直接套给跨许多格的粗LOD。

若需要法线，先区分曲面导数与美术平滑法线。片内`h_E=((1−v)(h10−h00)+v(h11−h01))/12.5`，`h_N=−((1−u)(h01−h00)+u(h11−h10))/12.5`；共享边处分别按片或明确单侧约定处理，不声称处处光滑。

## 5. EPSG:32651到局部显示架

权威位置保存E、N、H及其各自基准状态。选一个固定显示原点(E0,N0,H0)；可采用栅格外框中点E0=300862.5、N0=3116568.75，H0为声明的显示参考值。H0=0只是对源数值零点作显示选择，不意味着已知海平面。

采用右手显示架X向东、Y向上、Z向南。令s为每显示单位对应的米数，α为起伏增强系数：

`x=(E−E0)/s; y=α(H−H0)/s; z=−(N−N0)/s`。

逆变换：`E=E0+s·x; N=N0−s·z; H=H0+s·y/α`，α>0。默认α=1，水平/垂直使用同一个s；α仅影响显示，原始H、曲面规则、查询和测量不变。全局正的统一缩放不改变比例，单独调高度必须明确为增强；复位恢复α=1及约定相机。

CPU以足够精度计算并先减原点，再送局部Float32显示数据；避免把百万量级北坐标先转低精度后相减。相机绕转只改变视图，北/东和对象查询不改变。Y向上时片内朝上法线与`(−h_E,1,h_N)`平行；增强显示后的法线应来自增强后的表面，不能反写为原地形坡度。

EPSG:32651的水平量是投影坐标。横轴墨卡托保持局部角度而有位置相关的比例因素，因此“未增强”准确表达的是投影水平单位与源高程单位按同比例显示，不是全域地面距离、曲率或重力方向都已精确复现。[PROJ Transverse Mercator说明](https://proj.org/en/stable/operations/projections/tmerc.html)

## 6. 未知基准、对象关系和12个查询位置

未知高程基准与物理误差保留unknown及原因；不能填0、默认MSL/椭球高，不能把源零值直接当海岸或把显示底板称作海面。可以显示同一源版本的相对起伏和源数值；不能据此与潮位作水深相减。数值恢复误差、坐标往返误差、插值模型差异、LOD显示误差和物理不确定度分别记录，前几项小不证明最后一项小。

| 对象/关系 | 建议表达 |
|---|---|
| 数字DEM场 | 数值/网格/掩膜与来源身份，区别于真实地貌对象 |
| 地表解释 | 独立surfaceId，derivedFrom固定DEM场及规则；是有界高度场，不等于完整地质体，也不能描述任意悬挑/内部结构 |
| 分片 | patchOf或参数域分区；不声称每块是自然实体组成或物理连接 |
| 坐标父架 | EPSG:32651或显式局部架/变换；不承担compositionParent含义 |
| 片间关系 | 相邻域/共享边及连续性约束；是数学连接，不自动是实体接触或工程连接 |
| 查询位置 | 保持query-location身份和原E,N；在数据记录中引用采样/曲面求值关系，通常不适用实体组成 |
| 标记与UI | 显示对象，anchoredForDisplayTo相应位置/曲面；可见性抬升或引线不是地形高程和物理连接 |

本轮逐项读到12条elevation.method均为`containing-cell lookup, no interpolation`。既有值应保留为sourceCellHeight，并保留row/col及方法；R3若在原E,N用双线性规则得到surfaceHeight，应另列规则版本和状态，不覆盖原值，也不强行要求两者相等。

可把标记放在新曲面的surfaceHeight，再加显式视觉偏移避免闪烁；显示增强时标记、引线、地表使用同一变换。源位置不可悄悄吸附到格心。曲面在该点无有效支撑时，保留平面查询位置和缺失状态，不能给它造一个0高程落点。拾取粗网格后，应反算E,N，再调用权威曲面/原像元查询；显示碰撞点的高度仅是近似显示结果。

12点的原行号范围只有23—1185，而全域有20047行。它们能检查对应记录和用户点选，不能代表全域地形/边界验证。全景相机按有效地形范围确定，不能只按这12点的包围范围框取。土壤值仍是独立资料场的预测和空间共置，不因标记贴地就成为该时刻的物理土层或耦合模型。

## 7. 缺测边界和显示层级

建议先有全域粗预览，再按屏幕误差/视域请求细片；每片缓存记录来源、掩膜、曲面规则、采样层级和显示参数版本。权威样本保全与临时显示分辨率分开，缓存可从声明依赖恢复。

粗单元不能只检查角点：其内部覆盖若含未知区域，应保留缺测边界、进一步细分或整块不画，不能跨洞铺坡。透明空洞、无数据底色或单独辅助边框均可使用，但不伪装真实地形。外框截断不是崖壁，NoData边界不是海岸线。

相邻LOD须共享边界位置或有明确拼接约束，检查视角移动中的裂缝/跳变。裙边等视觉遮缝如使用，只属临时显示，不转为地形立面，也不得拿来填跨NoData的大片未知区域。正常曲面锐折与LOD裂缝区分处理。

一个可实施的初始显示目标是约1—2屏幕像素的近似误差预算，再按实际设备检查；这是工程选择，不是测量精度结论。每层仍需记录相对权威曲面的高度/边界误差与检查范围。未经证明的随机抽点不能称全域最大误差；双线性和分片线性组合可通过完整分区内的极值分析或保守界验证，成本不足时如实标为抽检。

首屏直接出现可操作三维，保留旋转、缩放、复位和显式起伏增强。来源、单位和未知放在简明辅助说明；完整证据查看不取代三维。不要为“看起来够高”默认放大Z/Y，也不要把更密的视觉细节称作新增实测地貌。

## 8. R3的最小验收表

| 检查 | 可判定的完成条件 |
|---|---|
| 源与解码 | 载荷/索引锁相符；块范围/长度/编码合同一致；逐块及整网格恢复比较通过，掩膜/有效零/负值/边块/空槽无遗漏，损坏输入明确失败 |
| 定位 | 首末格心、四个边界、指定行列与E,N一致；显示前后双精度往返可设≤10^-6m的数值目标并报告实际结果，明确不是物理精度；相机变化不改位置 |
| 曲面 | 支撑格心回到原值；片内公式、共享边、跨编码块边/角、最外格心边、NoData邻域有检查；域外不外推；双线性与三角显示误差分开 |
| 缺失与LOD | 含内部孔洞的粗块不会跨洞补面；相邻层边界对齐，缩放/旋转/切层无错误连面；报告采样或有界验证范围 |
| 12点 | ID/E,N/原像元值与原方法不变；新surfaceHeight单列；标记和增强地形同变换；缺失时无假落点；不把源像元值强制等于插值值 |
| 默认比例 | α=1，水平/高程同尺度；起伏增强显式、可复位，不改查询数据；相机覆盖真实数据域而非仅12点 |
| 对象知识 | 源场、曲面、分片、查询位置、显示标记身份明确；组成、父架、数学邻接和物理连接不混用；未知基准/误差保持未知 |
| 公网与体验 | 固定R3 HTTPS实际打开；版本/资源、首屏三维、旋转缩放复位、增强、点选、缺测和必要设备范围实际检查；HTTP 200或本地成功不代签 |

以上均是温州应落实的判据，本篇未代签通过。实施优先次序可为：数值与掩膜恢复 → 格心/坐标闭环 → 小范围有效片与跨片边界 → 分层全景 → 12点和交互 → 固定公网实测。无需等所有地貌语义或物理高程基准补齐才呈现有边界的数字地形；对尚未支持的物理查询明确返回未知。
