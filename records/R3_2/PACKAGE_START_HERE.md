## 精度边界

**1.6 米不是地形测绘精度。** 它只描述相机与当前显示曲面的几何关系。继承的 DEM 格距仍为 12.5 米，来源信息尺度约 30 米；高程基准、独立实测误差和统一观测时间仍未确认。不能因为相机降到近地视角，就声称已经获得道路、石块、建筑、植被、河床或其他米级地物真值。

海岸仍是 FOSSGIS/OSM 预处理陆地区域，不是即时潮位。河流仍是 2026-08 混合归档的地图曲线；河宽、水位、河床、流向和完整物理连接未由 R3.2 新增测量确认。

## 完整恢复与验证

本包由已发布的 `Wenzhou_R3_1_FULL_RESTART_20260909.zip` 作为底座生成。生产过程先核对该底包 SHA-256，再运行底包 `tools/verify_package.py`；叠加 R3.2 后重新生成 `MANIFEST.json`，再运行一次同一验证脚本。因而底座完整性与新包完整性分别检查。

解压后：

1. 使用 Python 3.12：`python tools/verify_package.py`。
2. 如只需查看网页，使用上面的固定提交公网预览；本地 HTTP 仅用于开发/恢复，不作为最终用户预览。
3. 如需恢复完整 DEM，继续沿用包内 R3.1 的 `tools/rebuild.py`、完整无损 DEM 归档、原始海岸/河流输入和离线依赖；R3.2 没有改写这些底层恢复材料。
4. R3.2 相机与交互的静态合同可运行：`python tools/r3-2/validate_eye_static.py`。

R3.2 是 R3.1 的追加版本，不是对历史版本的覆盖。R3、R3.1 保持原样；R3.2 的新文件位于 `site/dist/r3-2/`、`records/R3_2/` 与 `tools/r3-2/`。用户需要回看历史时继续使用原固定版本。
