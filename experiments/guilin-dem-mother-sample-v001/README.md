# 桂林阳朔 1 km² 地貌母体实验样板

本样板是 DEM 地貌母体系统的首个小范围试验，按 DEM-M03 的首阶段约 1 平方公里测试瓦片执行。

## 固定真值

- 唯一来源为桂林原生 12.5 米高程真值。
- 使用 `native-r07-c02` 中 81 × 81 个整数源像元。
- `z_truth_m` 全程只读。
- 垂直比例固定为 1.00。
- OSM 线状水系保持不可变，不添加手工河道与合成补线。

## 本轮验证

- 真实坡度、曲率、局部起伏与低地关系。
- 真实水系距离驱动的湿度场。
- 河谷稻田适生、地块种子、田埂与灌排微地形。
- 岩壁、森林与湿润竹林适生诊断。
- 世界坐标稳定随机种子。
- 真实高程与程序层一键分离。

生态点样只用于观察适生场，不构成正式植被运行时。人工视觉验收与生产批准均保持关闭。
