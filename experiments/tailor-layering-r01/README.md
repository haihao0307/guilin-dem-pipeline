# 独立衣物叠穿 R01 · 接触研究

本研究将已有高领内搭与 V 领外层放到原生人物上检查上身两层叠穿，同时保留原款短裤。默认组合为三件独立衣物。目标是保留各件衣物的版型、材料、网格和变形状态，再由共同的模拟步骤处理衣物之间的作用。

**本轮范围：两种指定上衣与原款短裤、静止人物、上身两层叠穿，以及有限的轻拉/轻推与风力试验。** 原款短裤也参与同一模拟流程。不据此宣称任意衣服组合、任意人物动作或连续防穿插已经成立。公网运行、交互与视觉验收结果在本文末尾单列，由发布者依据实际证据填写。

## 2. 为什么需要独立衣物与共同求解

单件衣服能够与人体碰撞，并不能推导出两件衣服也能相互阻挡。若两套布料只各自检查人体，内搭与外层可以相互穿过；即使初始位置看似正确，拖拽、风和重力仍可能破坏关系。

每件衣服必须保留自己的身份、点位、速度、质量、三角形、原始裁片尺寸、缝合关系与材料。不同衣服不能共享同一段可变位置数组，也不能因为一起穿着就建立未经设计的缝合约束。`src/layer-contact.mjs` 对衣物身份重复和可变位置内存重叠设有明确的输入检查。

共同模拟步骤只负责统一时间、调用各件内部约束、检查人体接触，再交换衣物之间的接触修正。接触修正按参与点的逆质量分配；外层与内层都可以受到影响。共同调度并不改变各件衣物的所有权，也不要求将它们焊成一个网格。

SideFX 的官方角色布料流程同样先为各 cloth shape 建约束、指定唯一名称和打包，再组织进共同流程。这为独立资产和统一模拟管理提供了可核对的参考。[Houdini：Attaching cloth to agents](https://www.sidefx.com/docs/houdini/crowds/cloth.html)

## 3. 穿衣顺序与 localOrder

衣服的初始摆放、运动中的接触、局部的里外关系需要分别描述。

CLO 官方建议用 Layer 帮助裁片排好里外：外层数值较大；整理完成后，全部回到 0，再进行稳定模拟。这说明层序可用于初始化，但不能只用一个永久向外偏移替代实际接触。[CLO：Use Layer](https://support.clo3d.com/hc/en-us/articles/115000294487-Use-Layer-Drape-Additional-Garment)

Vellum 的 Layer Shock 则在碰撞求解时增加内层的有效质量，使外层较容易退让；一般动力学质量不受这个偏置改变。`layer` 只比较大于或小于关系，不依照编号差距倍增。这是一种处理耦合强弱的机制参考；本轮接触代码不能因为借鉴了层间接触思路，就被称为完整的 Vellum 实现。[Vellum Solver](https://www.sidefx.com/docs/houdini/nodes/sop/vellumsolver.html) · [Vellum attributes](https://www.sidefx.com/docs/houdini/vellum/vellumattributes.html)

后续的 `localOrder` 应描述**某个接触区域的里外关系**，而非只给整件衣服一个全局层号。例如：

| 区域 | 需要表达的关系 |
|---|---|
| 衬衫下摆与裤腰 | 下摆位于裤腰里面 |
| 内搭袖口与外套袖口 | 接触范围内，内搭袖口在里面 |
| 翻出的衬衫领尖 | 领尖可以在背心领口之外 |
| 敞开的外套前襟 | 左右前片是具有自由边界的不同区域 |

这张表是扩展要求，**不是本轮已经支持的功能表**。当前原型在接缝焊接后，按短裤→内搭→外层执行一次性排层：对下层实际三角面作有限范围外侧放置，交替纸样和人体约束。采用24轮、45 mm搜索范围、每次最多3 mm修正及仅初始化使用的1.5 mm附加间隙；如果违规数量和最大残余没有同时改善，就恢复输入并记录尝试结果。之后动态模拟恢复双向质量加权接触，不保留向外吸附。新增衣物会重新排层并同步初态，卸下则只移除该物件和接触历史。尚未实现通用 `localOrder` 图、自动塞衣角、翻领规划、任意衣服的自动穿着和深度相交解缠。

## 4. 额外接触余量的准确含义

当前实体针织包含有体积的纱线。不能用“1.5 mm 接触厚度”覆盖它本身更大的几何包络，再假称可见表面已经安全隔开。

本轮已核对的源几何总包络约为：

| 源材料标识 | 原纱线几何包络 | 加入 0.35 mm 建模余量后的总接触厚度 |
|---|---:|---:|
| `knit-fine-0` | 约 6.130 mm | 约 6.480 mm |
| `knit-soft-0` | 约 7.144 mm | 约 7.494 mm |
| `denim-raw` | 0.700 mm | 1.050 mm |

这些是项目现有实体几何的包络参考，**不是现实织物的实测厚度**，也不能解释成承受压力后的真实压缩厚度。源生成参数改变时应重新计算；最终接触所用数值以运行时设置与发布记录为准。

UI 中 `thickness` 的语义现在是“额外接触余量”：范围 `0…6 mm`，步长 `0.1 mm`，默认 `+0.0 mm`。界面文本明确提示：“按实体纱线包络计算基础间隙；此处只增加接触余量。”

宿主向接触核传入的是各衣物的**建模接触包络总厚度**：

```text
衣物总接触厚度 = 原纱线几何包络 + 0.35 mm 建模余量 + 所选额外余量
两中面最小间距 = (厚度 A + 厚度 B) / 2 + 求解器接触余量
```

核内部以米计算，UI 以毫米显示。原针织着色器会把纱线整体移出载体表面。本轮将求解位置定义在纱线包络中面，显示时将不可见载体反向移动同等法线距离：T08 约 3.415 mm，T03 约 3.922 mm，P02 0.670 mm。这样避免把载体面误当纱线中面。复杂褶皱处仍需核对几何包络，不能仅凭总厚度数字就认定两侧全部覆盖。未实现每一根纱线之间的逐段碰撞，也未完成现实材料厚度和摩擦的实验标定。

CLO 官方分别定义 Rendering Thickness 和 Collision Thickness；视觉挤出的厚度本身不产生碰撞。这正是需要让可见实体结构与接触间隙相互核对的原因。[Rendering Thickness](https://support.clo3d.com/hc/en-us/articles/44177925839897-Rendering-Thickness) · [Collision Thickness](https://support.clo3d.com/hc/en-us/articles/115002798068-Adjust-Collision-Thickness)

## 5. 本轮采用的数值范围

`src/layer-world.mjs` 复用原裁片的 XPBD 距离与二面角约束内核；`src/layer-contact.mjs` 增加不同衣物之间的离散点—三角形接触。原始纸样的尺寸仍由每件自己的内部约束维护。

当前衣间接触使用空间筛选，在有限邻域内查找候选，对两个方向的点—三角形关系进行检查，并在最后重新计算该检测范围内的残余量。三角形内部可以参考之前的表面侧关系；最近点位于三角形的边或顶点区域时，采用最近特征的无符号距离。当前代码没有按衣物拓扑区分内部共享边与衣物开口边。

必须保留以下边界：

- **离散检测，不是 CCD。** 一个时间步内快速穿越表面的过程可能被漏检；增加子步不能构成完整的连续无穿插证明。
- **没有完整边—边检测与全自碰撞。** 点—三角形检测数量不能代替完整三角形相交审核。
- **不是通用解缠器。** 深度相交、错误初始层序与复杂自由边界不能仅靠局部推开可靠恢复。
- **摩擦为近似。** 当前是有界的切向相对位移阻尼，不是经过布料测试标定的静/动摩擦本构，也不能把滑杆数字直接当成现实布料摩擦系数。
- **没有任意动作保证。** 人物保持静止；轻拉、轻推与风力是本轮限定交互，不能用来证明跑、蹲、抱臂等动作已通过。
- **没有把细节烘成一件服装。** 各件几何与身份保留。工程上的布壳接触近似，不等于已计算全部纱线之间的真实接触。

XPBD 的参考价值在于让多种材料共用时间步时，更有依据地描述约束刚度；具体数值结果仍会受到离散化、迭代预算和未收敛误差影响。C-IPC 展示了要获得严格厚度和连续接触保证，需要把相关条件落实到求解和碰撞推进中。ContourCraft 则提醒我们，初始就相交的衣服还需要独立的解缠能力；“防止新相交”不能代替“恢复已相交状态”。

### 冻结原人物数值夹具的初始化对照

真实 P02/T08/T03 纸样配合原冻结人物（old body = current body），共有9,402个物理粒子、18,280个衣物三角形和50,624个人体三角形。一次性初始化将点—三角形厚度违规从4,824项降为93项，初始最大残余由7.486 mm降为2.739 mm。随后两个动态步的残余分别约0.471、0.740 mm；未作这项排层的对应值为10.308、6.596 mm。每步为1/120秒，两步累计仅推进1/60秒物理时间，未验证长时间稳定性。证据由`tests/world.test.mjs`实际运行输出。

这些数值只覆盖上述夹具和离散查询范围。接缝间隙为0、全量物理顶点没有落入人体内部，但最大局部边长比仍约1.55–1.58，不能当作制版或材料验收通过。网页当前原生人物的残余量、视觉与交互结果另行检查，不能套用这组冻结夹具数值；计算也仍慢于实时。

## 7. 界面检查路径

1. 查看高领内搭、V 领外层与原款短裤分别出现在衣物列表中；上身呈两层叠穿。
2. 逐件选中、单独查看、显示全部、卸下与重新穿着，核对对象独立性。
3. 先在静止视角检查肩膀、领口、腋下和衣摆；再开始布料模拟。
4. 使用“轻拉所选衣摆”“轻推外层”，或在支持的浏览器里按住 Shift 拖动布料施力。普通拖动用于旋转，滚轮用于缩放。
5. 调整所选衣物的额外接触余量，观察接触行为及可见间隙；不得把明显悬空的结果当作优质叠穿。
6. 切换“显示残余接触样本”和衣物间碰撞开关，比较同一条件下的差异。“本批接触约束”计数来自最近一批求解遇到的数值约束；橙点来自本步最后一次人体投影后重新测量的残余样本，两者不一一对应。计数不等于独立物理接触斑块数量，未显示样本也不能证明全部表面没有相交。

“单独查看”和“分开查看衣层”属于检查工具。它们的显示变化不能被用作物理接触成立的证据；真实卸下后的重新平衡应另行检查。
