# 靠谱 / KAOPU — Wenzhou Real Score R01 — Longwan Tide Gauge

Status: **candidate experiment only**. This is not formal KAOPU R2, not production-ready, and not visually accepted.

This first real Wenzhou seed deliberately uses one small, source-clear real object: the **Longwan (LW) tide-gauge station**. It connects a time-varying continuous field (relative mean sea level), one discrete object, two physically independent Observation Roots (in-situ gauge and Copernicus satellite altimetry), a real cross-root discrepancy, explicit Unknowns, one typed-wave node, a public Current Best View policy, and an immutable rollback point.

The key anti-error rule is that copies of one source do not count as independent roots. Likewise, the gauge and satellite trends are not forced into a false contradiction: they observe different reference semantics and spatial supports, and the cited analysis uses their difference to estimate vertical land motion.

Immediate open gates: exact station coordinates; primary raw tide-gauge asset pin; primary Copernicus product identifier and checksum; typed-wave phase and residual reconstruction; independent verifier that recomputes values from pinned primary data.
